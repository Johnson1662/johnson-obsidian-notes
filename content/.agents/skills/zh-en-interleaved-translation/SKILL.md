# 中英对照翻译（一段英文、一段中文）

交付形态是**交错的段落对**，不是文末附一份完整译文。用户说「一段一段来」时要的就是这个。

## 步骤

1. **读全文**。行被截断到 768 字符时会看到提示，用 `read` 的 `:N:raw` 补读那几行；先排出段落顺序（标题 / 正文段 / 接口名 / 图片 / 引语）。
2. **frontmatter 原样保留**，只动正文。
3. **整篇重写**（`write`），每个段落对按固定顺序：
   ```
   英文段落
   中文段落
   <br>
   ```
   段与段之间空行，`<br>` 单独一行。最后一个段落对后面不加 `<br>`。这样 Obsidian 阅读视图里对与对之间才有间距。
4. **标题一行双语**：`## Don’t adopt a pet / 别养宠物`、`### Acknowledgements / 致谢`。不要上下两行各写一个标题。
5. **图片保持原位**，不加译、不改 URL；中文放在图前那段英文之后，图后接下一个英文段。
6. **原样不动**：链接 URL、代码与接口签名（`` `execute(name, input) → string` ``）、粗体引导语（`**The harness leaves the container.**` → `**harness 离开容器。**`）、斜体（`*process, file*` → `*进程、文件*`）、英文原文的 typographic 引号与空格。
7. **译文**：简洁清晰、一句一义；术语首次出现给极短解释（如「harness（调用 Claude 的循环）」），之后沿用英文术语不硬译；数字、`p50/p95`、百分比原样。

## 坑

- 别在文末另起 `## 中文翻译` 整段——那是另一种形态，会被要求重做。
- 手写或脚本替换中文时容易带进零宽字符 `\u200b`（症状：「状状态」这种重复字）。写完清一遍：`python3 -c 'p="f.md";s=open(p).read();open(p,"w").write(s.replace("\u200b",""))'`。
- 只加翻译，不顺手改英文用词与结构。

## 验收

```bash
grep -n "^## \|^### " "Clippings/x.md"      # 标题都是 "English / 中文"
grep -c "^<br>$" "Clippings/x.md"           # 约等于段落对数
```
抽查首段、一个章节标题、结语三处：英文段后紧跟的就是它的中文。图片 URL 与 frontmatter 未变。
