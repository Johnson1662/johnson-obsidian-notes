# 并行算法设计

## 并行算法设计概述

### 如何进行并行计算

- **应用问题本质**：计算密集？数据分析？是否可以分解为可并发执行的子任务？
- **并行算法分析与设计**：需结合问题特性和硬件平台
- **可用计算资源**：现有平台硬件参数？自行定制平台？
- **设计和实现解决方案**：使用商业/开源软件？基于中间件开发？从底层设计？

### 并行算法的定义

- **算法**：解决特定问题的一组明确定义的规则或流程（IEEE定义）
- **串行算法**：单一指令序列
- **并行算法**：可同时执行的计算任务集合，通过分工合作求解问题

### 并行算法设计思想

- 并行算法设计不是串行算法设计的简单进阶
- 串行算法基于冯·诺依曼架构，指令逻辑顺序清晰；并行硬件无统一体系结构
- 并行算法中可包含串行计算，串行算法也可部分并行化
- 并行算法设计与问题本身及硬件平台均相关
- 问题类型与硬件平台组合形成设计模式
- 并行算法类型：计算密集？数据密集？数据结构与算法密不可分

### 设计并行算法的一般策略

1. **串行算法的直接并行化**：发掘现有串行算法的并行性，直接改造为并行算法（最常用，但非所有算法适用）
2. **从问题描述出发设计**：根据问题固有属性从头设计全新并行算法（难度高，但通常更高效）
3. **借用已有并行算法**：借助现有并行算法求解新问题

> 主要参考资料：《并行计算-结构-算法-编程》，陈国良

## 基本的并行算法设计方法

### 串行算法的直接并行化

#### 方法

发掘和利用现有串行算法中的并行性，直接将其改造为并行算法。

#### 特点

- 最常用的方法之一
- 不是所有串行算法都可以直接并行化
- 好的串行算法未必能并行化为好的并行算法
- 许多数值串行算法可并行化为有效的数值并行算法

#### 示例1：数组求和

- **数据分解方式**：
  - 按块均分：将数组均匀分给各处理器
  - 分治（平衡树）：递归对半分，逐层归约求和
- 平衡树方法：叶子节点为数组元素，非叶子节点为子节点之和，自底向上并行计算

#### 示例2：并行排序

排序是常用操作，大数据量下单处理器串行执行耗时久，需并行化。

**并行排序关键问题**：

1. **数据分配**：待排序元素分布到各处理器
   - 按编号取模分配
   - 要求排序结果在各处理器均匀分布（小编号处理器元素均小于大编号）
2. **跨处理器元素比较**：两个元素位于不同节点时的比较与交换
   - 方法1：P1发送元素给P2，P2比较后返回较小/较大值
   - 方法2：双方互换元素，各自比较后保留相应值（需注意精度一致性）

**枚举排序（串行）**：
对每个元素统计小于它的元素个数，确定最终位置，时间复杂度 $O(n^2)$。

```
输入：a[1]…a[n]
输出：b[1]…b[n]
Begin
  for i = 1 to n do
    k = 1
    for j = 1 to n do
      if a[i] > a[j] then k = k + 1
    end for
    b[k] = a[i]
  end for
End
```

**枚举排序（并行）**：
使用n个处理器，每个处理器负责一个元素的定位：

```
输入：无序数组a[1]…a[n]
输出：有序数组b[1]…b[n]
Begin
  (1) P0播送a[1]…a[n]给所有Pi
  (2) for all Pi (1≤i≤n) para-do
        k = 1
        for j = 1 to n do
          if a[i] > a[j] then k = k + 1
        end for
  (3) P0收集k并按序定位
End
```

计算复杂度 $O(n)$，通信复杂度 $O(n^2)$。

**冒泡排序（串行）**：
顺次比较相邻元素，时间复杂度 $O(n^2)$。

```c
void BUBBLE_SORT(int n) {
    for (int i = n-1; i >= 1; i--) {
        for (int j = 1; j <= i; j++) {
            compare_exchange(a[j], a[j+1]);
        }
    }
}
```

**冒泡排序并行化（流水线）**：
内循环的下一次"冒泡"可在前一次完成前开始，开发流水线并行。

**奇偶置换排序（串行）**：
分奇操作阶段（奇数索引与右邻居比较交换）和偶操作阶段（偶数索引与右邻居比较交换），n个阶段完成排序。

```c
void ODD_EVEN(int n) {
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 1) { // 奇阶段
            for (int j = 0; j <= n/2-1; j++)
                compare_exchange(a[2*j], a[2*j+1]);
        } else { // 偶阶段
            for (int j = 1; j <= n/2-1; j++)
                compare_exchange(a[2*j-1], a[2*j]);
        }
    }
}
```

**奇偶置换排序（并行）**：
每个处理器对应一个元素，根据当前阶段与相邻处理器通信比较：

```c
void ODD_EVEN_PAR(int n) {
    int id = processor_id;
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 1) { // 奇阶段
            if (id % 2 == 1) compare_exchange_min(id+1);
            else compare_exchange_max(id-1);
        } else { // 偶阶段
            if (id % 2 == 0) compare_exchange_min(id+1);
            else compare_exchange_max(id-1);
        }
    }
}
```

### 从问题描述开始设计并行算法

#### 方法

从问题本身描述出发，不考虑相应串行算法，设计全新的并行算法。

#### 特点

- 挖掘问题的固有特性与并行的关联
- 是一项富有挑战性和创造性的工作

#### 示例：求前缀和

给定数组 $A = \{a_0, a_1, ..., a_{n-1}\}$，求前缀和数组 $B = \{b_0, b_1, ..., b_{n-1}\}$，其中 $b_i = \sum_{k=0}^i a_k$。

**串行算法**：

```
b[0] = a[0]
for(i = 1;i < n;i ++)
	b[i] = b[i-1] + a[i]
```

$$
\begin{aligned}
b[0] &= a[0] \\
\text{for } (i = 1; i < n; i++) &\\
b[i] &= b[i-1] + a[i]
\end{aligned}
$$

每次迭代依赖上一次结果，无法直接拆分循环。

**并行算法1：平衡树方法**
类似于数组求和的平衡树，自底向上计算前缀和，时间复杂度 $O(\log n)$。

**并行算法2：递推方法**

```
for (i = 1; i < n; i++) {
    A[i] = A[i] + A[i-1]
}
// 并行化：
for (j = 0; j < ceil(log2(n)); j++) {
    for (i = pow(2,j); i < n; i++) do_in_parallel {
        A[i] += A[i - pow(2,j)]
    }
}
```

外循环次数为 $\lceil \log n \rceil$，内层循环自第 $2^j$ 个数开始并行执行。

### 借用已有算法求解新问题

#### 方法

- 找出待求解问题与已解决问题之间的联系
- 改造或利用已知算法应用到新问题上

#### 特点

- 创造性的工作，需深入理解问题本质和算法特性

#### 示例：3PCF（三点相关函数）

**定义**：点集D、R，求满足条件的三元组 $\langle a_i, b_m, b_n \rangle$ 数目：

$$
|a_i - b_m| = r_1 \pm err \quad \text{且} \quad |a_i - b_n| = r_2 \pm err \quad \text{且} \quad |b_m - b_n| = r_3 \pm err
$$

**直接解法**：对D中每点 $a_i$，在R中找距离为 $r_1$ 的点集 $R'$ 和距离为 $r_2$ 的点集 $R''$，再在 $R' \cap R''$ 中找距离为 $r_3$ 的点对，累加计数。

**并行优化**：

- 阶段一：遍历D中每点，在R中找距离 $r_1$ 和 $r_2$ 的点，生成矩阵DR1和DR2；遍历R中每点，找距离 $r_3$ 的点，生成矩阵RR
- 阶段二：结果矩阵 = DR1 × RR × DR2ᵀ

## 小结

- 并行算法设计是复杂且仍在发展的学科，目前尚无普遍适用的系统设计方法学
- 本章介绍的三种方法（串行直接并行化、从问题出发设计、借用已有算法）是三种基本思路，不能涵盖全部
- 算法设计灵活无定规，需结合问题特性和硬件环境不断探索
