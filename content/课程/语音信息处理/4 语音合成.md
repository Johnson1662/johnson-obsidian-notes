# 4 语音合成

一句话：语音合成是识别的**反方向**任务——把文本里的语言信息**调制**到声学信号上；整章分两段：**前端**（文本分析 + 韵律分析）+ **后端**（声学模型 → 声码器），主流技术从波形拼接走到**统计参数合成**（HMM → DNN），再走到**端到端**（Tacotron2 / FastSpeech / VITS / VALL-E）。

## 总览（思维导图）

$$
\text{文本}\ \to\ \text{前端}\ \to\ \text{后端}\ \to\ \text{语音}
\begin{cases}

4.4\ \text{展望}:\ \text{Tacotron2、FastSpeech、Grad-TTS、VITS、VALL-E、个性化与情感}
\end{cases}
$$

| 系统   | 组成                                                          |
| ------ | ------------------------------------------------------------- |

# 4.1 语音合成概述

## 4.1.1 语音合成的基本概念

| 概念 | 内容                                                                                                   |
| ---- | ------------------------------------------------------------------------------------------------------ |
| 定义 | 语音合成（Speech Synthesis）：通过机械的、电子的方法产生人造语音的技术；TTS 即自动将**文本转换为声音** |
| 目标 | **可懂度**（Intelligibility）+ **自然度**（Naturalness）                                               |

| 目标   | 含义                                                                                          |
| ------ | --------------------------------------------------------------------------------------------- |
| 可懂度 | 语音中有意义的语言单元（单词、单句等）内容的可识别（可被理解）程度，可通过人工或 ASR 系统测评 |
| 自然度 | 合成语音与人类语音听起来的接近程度；**尚未有唯一的客观指标**来评价                            |

广义的语音合成研究内容：

| 方向         | 内容                                           |
| ------------ | ---------------------------------------------- |
| 语音转换     | 说话人转换、语音到歌唱转换、情感转换、口音转换 |
| 歌唱合成     | 文本/歌词到歌唱转换（如 VOCALOID 引擎）        |
| 可视语音合成 | 合成与语音配合的视觉（口型等）信息             |

TTS 流程与人的朗读过程对比：文语转换的功能模块涵盖了人的朗读过程的主要要素，但**没有考虑两个最重要的要素——文本理解和意图表达（speech skill）**。

### 评价指标

| 类型        | 指标                                    | 说明                                                                                        |
| ----------- | --------------------------------------- | ------------------------------------------------------------------------------------------- |
| 主观·绝对值 | MOS（Mean Opinion Score，1–5 或 0–100） | CCITT 推荐的主观评价方法                                                                    |
| 主观·相对值 | CMOS（Comparative MOS，$-3\sim3$）      | 每次听两条相同文本的音频，用 $[-3,3]$ 打分评价后者相对前者：3 远优于、$-3$ 远差于、0 无差别 |
| 主观·相对值 | ABX Test                                | 类似 CMOS：在 A、B 两条音频中选音质更好的，或认为无差别（X）                                |
| 客观        | **MCD**（梅尔倒谱失真）                 | 与真实音频（Ground Truth）之间的距离度量                                                    |
| 客观        | F0 均方根误差、时长均方根误差           | 同上                                                                                        |

MOS 五级参考（CCITT）：

| MOS 分值 | 等级 | 语音质量                                             |
| -------- | ---- | ---------------------------------------------------- |
| 5        | 优   | 流畅自然，无瑕疵                                     |
| 4        | 良   | 失真不明显，不注意听感觉不到                         |
| 3        | 一般 | 明显失真，但自然度和清晰度尚可忍受，听起来没有疲劳感 |
| 2        | 差   | 严重失真、不自然，听起来有疲劳感                     |
| 1        | 劣   | 语音质量极差，听觉无法忍受                           |

梅尔倒谱失真（客观指标）：

$$\text{MCD}_K=\frac{1}{T}\sum_{t=0}^{T-1}\sqrt{\sum_{k=1}^{K}\left(c_{t,k}-c'_{t,k}\right)^2}$$

主观评测的实验流程注意事项：足够的、合理的测听人员与人数；测听设备差异；是否对测听人员培训；每个 session 的时间安排；**统计有效性（Significant test）**。

## 4.1.2 语音合成的方法回顾（了解）

| 阶段         | 方法                                                                                                                                                             |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 机械合成     | Von Kempelen（1791）语音机：第一台复制人的发声器官及其作用并发出"语音"的机器，**再现了声源—滤波器机理**；Homer Dudley 的 Voder（1939）需复杂键盘手动操作、训练难 |
| 参数合成     | **线性预测合成**：基于全极点声道模型假定，采用线性预测分析原理合成语音                                                                                           |
| 波形拼接     | 从自然语音抽取语音基元组成语料库，合成时按文本查找合适基元，经**拼接、韵律修饰**得到语音                                                                         |
| 统计参数合成 | SPSS：对语音做参数化表征，基于统计模型进行声学参数建模，再构建合成系统                                                                                           |

LPC 语音合成的源—滤波器结构：

$$x(n)=\hat{x}(n)+Gu(n)=\sum_{i=1}^{p}a_ix(n-i)+Gu(n)$$

其**激励参数**由增益常数、浊/清音开关信息和基音频率组成，**声道参数**用 LPC 参数控制。

| 方法         | 优点                                                                                     | 缺点                                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 波形拼接     | 音质自然（直接拼接真实语音）                                                             | 需要大规模精心设计的语音数据库；库中缺少类似音素样例时质量差；**不易控制韵律**；可扩展性差、不易维护 |
| 统计参数合成 | 无需大规模精心设计的语音数据库；合成语音质量稳定；**可以控制韵律**；可扩展性好、易于维护 | 参数化带来的过平滑等问题（见 4.3.1）                                                                 |

## 4.1.3 语音合成的典型应用（了解）

语音交互（家居、出行、客服、旅游等场景）、特殊人群（发音障碍、视力障碍）服务、虚拟主播、有声读物。

# 4.2 语音合成的原理

## 4.2.1 语音合成的整体框架（重点掌握）

语音是"通过语言调制、由人类发声器官产生的声学信号"，因此语音合成的原理就是**把语言信息调制到声学信号上**：

| 处理线   | 内容                                |
| -------- | ----------------------------------- |
| 语言处理 | 句词切分、文本归一化等              |
| 声音处理 | **韵律参数预测** + **声音波形生成** |

一些研究把文本分析和韵律预测（分析）阶段合并称为**语言分析**。

| 阶段     | 职责                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------ |
| 前端处理 | 从原始文本提取多种可被声学模型识别的**语言学特征**，即在音标和韵律信息方面提供文本的符号语言表征 |
| 后端处理 | 将语言学特征转换成**声学特征**，进一步转换成**语音波形**                                         |

## 4.2.2 语音合成的文本分析（了解、基本概念）

### 分词与词性标注（了解）

| 项       | 内容                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 目的     | 标注词语边界、词语词性                                                                                                       |
| 分词     | 把句子（中文是连续的汉字序列）按一定规范重新组合成词序列；不正确的分词会影响合成语音的自然度（如"南京市长江大桥"的歧义切分） |
| 词性标注 | 为分词结果中每个词标注正确词性，可用于**预测韵律边界**和**多音字消歧**                                                       |

两种分词方法：

| 方法            | 要点                                                                                                                                                                                                     |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 最大前向匹配    | 从待分词句子左边向右搜索，先规定词的最大长度，每次按该长度与字典匹配，没找到就缩短长度，直到命中字典词或成为单字                                                                                         |
| 统计模型（CRF） | 条件随机场：给定输入序列条件下输出序列的**条件概率分布**模型；四个标注 B（词的开始）/E（结束）/M（中间）/S（单个词）；$n$ 帧、$k$ 种标签时路径数为 $k^n$，按输出概率与转移概率用**维特比算法**求最佳路径 |

| 对比项 | 基于规则（字典）                                                 | 统计模型（CRF 等）                                       |
| ------ | ---------------------------------------------------------------- | -------------------------------------------------------- |
| 优点   | 查询效率高、可扩展性强、可维护不同用户字典与领域、能快速修改错误 | 依赖上下文语境、泛化能力强；对歧义词和未登录词识别能力强 |
| 缺点   | 过于依赖字典；对未出现的词分词能力低                             | 增加模型训练时间；不能快速修改错误                       |

解决方法：**结合基于规则和统计模型的分词方法**。

### 文本归一化（了解）

目的：把非标准词转换成发音明确的口语单词，否则合成语音会出现语法错误、语义不完整。

| 例子      | 归一化后       |
| --------- | -------------- |
| 前方 120M | 前方一百二十米 |
| 拨打 120  | 拨打幺二零     |

方法：基于规则转换；规则转换与深度学习结合。

常见类型（了解）：

| 类型              | 原始文本                | 正则后文本                 |
| ----------------- | ----------------------- | -------------------------- |
| 专有名词/特殊姓氏 | 曾国藩曾经              | 曾（zēng）国藩曾（céng）经 |
| 单位              | 这块黄金重达 324.75 克  | 三百二十四点七五克         |
| 日期              | 出生于 86 年 8 月 18 日 | 八六年八月十八日           |
| 数字              | 编号 27149              | 二七一四九                 |
| 电话              | 固话 0421-33441122      | 零四二一三三四四一一二二   |
| 西文字母开头      | α 粒子、B 超            | (alfa lìzǐ)、(B chāo)      |

### 字音转换与句法分析（了解）

| 项         | 内容                                                                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 字音转换   | 给出每个字符对应的发音，并进一步处理**协同发音、多音字消歧、儿化音标注、变调**（例：古都{du1}、都{dou1}有；理解{li2 jie3}）；方法有字典、HMM、神经网络 |
| 多音字消歧 | 基于词典的方法、基于神经网络的方法                                                                                                                     |
| 句法分析   | 分析句子中词与词之间的关系；输入是词的序列（可能含词性等属性），输出是句子的**句法结构**；弄清词间关系对随后**韵律参数生成**至关重要                   |

## 4.2.3 语音合成的韵律分析（基本概念、了解）

韵律结构通常分为三个层级：**韵律词 → 中间短语（韵律短语）→ 语调短语**。

| 概念 | 含义                                                                 |
| ---- | -------------------------------------------------------------------- |
| 语调 | 说话的腔调，一句话里快慢轻重的配置和变化，体现说话人的态度或口气     |
| 声调 | 又叫字调，语言音调的变化；普通话四个声调：**阴平、阳平、上声、去声** |
| 重音 | 也叫重读；在口语表达中有强调重点、突出主要情感的作用                 |

韵律的特征（基本概念）：

| 角度     | 内容                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 语音信号 | 韵律是**超音段**的声音物理属性信息，例如音高、音长、强度                             |
| 语用功能 | 韵律编码多种语音意图：表达信息焦点、对话连贯性、言语行为类型、说话人态度和情感状态   |
| 关系     | 韵律是**句法和发音的接口**，受语气类型、词汇语义或句法关联、组合节奏、篇章连贯性影响 |
| 感知     | 反映节奏、强调、语音速率等                                                           |
| 生成     | 通过音高（$F_0$）、持续时间、能量等的变化实现                                        |

中文韵律结构标注（了解）：

| 层级 | 标记 | 结构                                                                                                     |
| ---- | ---- | -------------------------------------------------------------------------------------------------------- |
| 音节 | L0   | 音素（LP）→ 音节（L0）→ 韵律词（#1）→ 韵律短语（#2）→ 语调短语（#3）→ 子句子（#4）→ 主句子 → 段落 → 篇章 |

例句：`九零后#1为中华人民#1共和国#2成立七十周年#3准备了大礼#4`

| 边界类型     | 停顿时长                       | 前后音高特征                       |
| ------------ | ------------------------------ | ---------------------------------- |
| 韵律词边界   | 不停顿或从听感上察觉不到停顿   | 无                                 |
| 韵律短语边界 | 可以感知停顿，但无明显的静音段 | 音高不下倾或稍下倾，韵末不可做句末 |
| 语调短语边界 | 有较长停顿                     | 音高下倾比较完全，韵末可以作为句末 |

韵律结构边界的预测（了解）：

| 方法                    | 说明                                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------------------------------- |
| 基于规则                | 使用语言学经验知识，简单直观但局限多                                                                    |
| 基于机器学习            | 把韵律预测转为分类问题，代表性方法：决策树、HMM、最大熵、条件随机场                                     |
| 神经网络                | RNN 可预测韵律短语但未考虑语义特征；把 **word2vec 词向量**作为语义特征加入 RNN 韵律层级预测模型后有提升 |
| 深度学习 + 传统模型结合 | 可以更好地描述韵律层级的多样性                                                                          |

**BLSTM + CRF** 的边界预测（了解）：输入 one-hot 特征/词对应的 word embedding，输出三个类别 **B / NB / O**（边界、非边界、others），网络结构为 FFNN + BLSTM + CRF（CRF 考虑输出之间的联系）。不仅是韵律边界，TTS 前端的**分词、词性标注、多音字消歧都依赖更长的上下文**，因此 LSTM/GRU 对整个 TTS 前端文本分析性能都有很大提升。

语调分解与控制（了解）：语调包括三个要素——**声调**、连续语音声调相互影响形成的**中性语调**、表达说话人情感或态度的**情感语调**。

| 模型          | 内容                                                                                                                                                        |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fujisaki 模型 | 把句子的 $F_0$ 曲线分解为**短语成分和声调成分**，分别由**短语命令**和**声调命令**控制；Fujisaki（2004）通过引入**负的声调命令**把它扩展到声调语言的韵律表征 |

基频、时长、能量的生成（基本概念）：语调调型隐含于基频模型，句子的基频曲线根据当前音节的拼音、声调与上下文环境，由语料库中的基频统计模型得到，其语调可以认为是语料库中语调的平均；**时长与能量**也是重要的韵律信息；生成方法有基于规则、基于数据（传统统计模型、深度神经网络）。

# 4.3 语音合成的主流技术

## 4.3.1 基于 HMM 的语音合成（基本概念、掌握）

统计参数语音合成（SPSS）：基于统计模型生成声学特征，进而合成语音波形。声学模型的演进是 **HMM（2000 年~）→ 基于神经网络的模型（2013 年~）**。

### 为什么是 HMM

| 理由               | 说明                                                                                                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 语音识别成功的启发 | HMM 适合为时序信号建模（HMM 早在 20 世纪 80 年代中期就用于语音识别声学模型）                                                                                                         |
| 结构契合           | 语音的产生可以理解为一个**双重随机过程**：气流经由过程无法观测，而发出的语音可观测；HMM 同样是双重随机过程——隐马尔可夫链输出的状态序列（无法观测）+ 随机过程输出的观察序列（可观测） |

### 识别与合成的对应关系（掌握）

| 任务     | 数据流                                          | 训练阶段                                                       | 解码（生成）阶段                                      |
| -------- | ----------------------------------------------- | -------------------------------------------------------------- | ----------------------------------------------------- |
| 语音识别 | 声学特征 $O$ → HMM（$\Lambda$）→ 语言学特征 $L$ | $\hat\Lambda=\underset{\Lambda}{\arg\max}\ P(L\mid O,\Lambda)$ | $\hat L=\underset{L}{\arg\max}\ P(O=o\mid L,\Lambda)$ |
| 语音合成 | 语言学特征 $L$ → HMM（$\Lambda$）→ 声学特征 $O$ | $\hat\Lambda=\underset{\Lambda}{\arg\max}\ P(O\mid L,\Lambda)$ | $\hat O=\underset{O}{\arg\max}\ P(O\mid L=l,\Lambda)$ |

$O$ 为声学特征、$L$ 为文本信息。模型训练用 **Baum-Welch 算法**（最大期望算法的快速实现），解码用基于动态规划的 **Viterbi 算法**——与语音识别章节完全相同。

### 系统框架与训练流程（掌握）

| 阶段 | 步骤                                                                                                                                                          |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 训练 | ① 数据处理，提取文本特征与声学参数；② 模型训练（训练数据为 ⟨文本特征, 声学参数⟩）：a) 单音素训练 → b) 上下文相关 HMM 训练 → c) 决策树聚类 → d) 聚类后模型训练 |
| 合成 | ① 文本处理，得到输入文本特征；② 基于**似然最大化准则**通过 HMM 生成声学参数；③ 利用**声码器**把声学参数转换为最终语音                                         |

文本特征提取（前端 → 语言学特征）：

| 特征                       | 内容                                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------------------ |
| 音素                       | 包含发音信息                                                                                     |
| 时长信息                   | 当前音素发音时长                                                                                 |
| 声调信息                   | 记录韵母的声调                                                                                   |
| 音节信息                   | 当前音节在词语、短语、语句中的位置、数目信息                                                     |
| 词性、韵律词、韵律短语信息 | 主要记录韵律相关信息                                                                             |
| **上下文信息**             | 当前音素临近音素的对应特征；包含音素系统发音、变调、韵律结构等信息，是语言学特征中极其重要的部分 |

情感合成还需标注整句与各短语的情感特征，风格合成需标注重读、倾向等。

上下文特征举例（了解）：例句"卡尔谱陪外孙玩滑梯"，音节为基本单元，转成拼音带声调后，按**上下文语境问题集**编码成 A–F 六组特征：

| 组  | 含义           | 具体信息                                                                                                       |
| --- | -------------- | -------------------------------------------------------------------------------------------------------------- |
| A   | 声调信息       | a1 前一音节、a2 当前音节、a3 后一音节的声调                                                                    |
| B   | 音节位置信息   | b1 到语句开始字的距离、b2 到语句结束字的距离、b3/b4 在词中的位置（正序/倒序）、b5–b8 在韵律词/韵律短语中的位置 |
| C   | 词性和音节数目 | c1–c3 前/当前/后一个词的词性，c4–c6 前/当前/后一个词的音节数目                                                 |
| D   | 韵律词信息     | d1–d3 前/当前/后一个韵律词的音节数目，d4/d5 当前韵律词在韵律短语中的位置（正序/倒序）                          |
| E   | 韵律短语信息   | e1–e3 前/当前/后一韵律短语的音节数目，e4–e6 韵律词个数，e7/e8 当前韵律短语在语句中的位置                       |
| F   | 语句信息       | f1 语句的语调类型，f2–f5 语句的音节/词/韵律词/韵律短语数目                                                     |

声学特征：主要是**谱参数**与**基频（$F_0$）参数**。

### HMM 合成的训练阶段

| 模型类型     | 适用情况   |
| ------------ | ---------- |
| 简单模型     | 数据充足   |
| 复杂模型     | 数据不足   |
| 聚类复杂模型 | 解决过拟合 |

**方差下限估计**：上下文属性可能的组合远大于训练数据数目，模型方差接近零；为避免方差过于接近零需预先设定方差下限，且不同参数需设不同的方差下限。

| 训练环节        | 内容                                                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 单音素模型训练  | 对所有单音素 HMM 初始化并训练（Baum-Welch，理论基础是 EM 算法，与语音识别相同），所得模型用于上下文相关模型的扩展与初始化 |
| 上下文相关训练  | 考虑前后音素、韵律边界等上下文；用 `/l-c+r/` 表示"左音素-中间音素+右音素"，如 `/#-c+a/`、`/a-t+#/`                        |
| 决策树聚类      | 训练后参数产生过拟合；为消除样本过少问题、让鲁棒性与数据量达到均衡，采用基于决策树的 HMM 聚类                             |
| 聚类后 HMM 训练 | 与单音素、上下文相关训练相同，仍用 Baum-Welch 算法                                                                        |

参数生成（了解）：基于 EM 的参数生成算法（Tokuda et al. 2013）解决"如何使初始子状态序列尽可能接近最优子状态序列"，即给定一组 HMM 与要合成的文本，确定最可能的语音参数矢量序列：

$$o_{\max}=\underset{o}{\arg\max}\ p(o\mid\lambda_{\max},w)\approx\underset{o,q}{\arg\max}\ p(o,q\mid\lambda_{\max},w),\qquad q_{\max}=\underset{q}{\arg\max}\ p(q\mid\lambda_{\max},w)$$

于是 $o_{\max}\approx\underset{o}{\arg\max}\ p(o\mid q_{\max},\lambda_{\max})=\underset{o}{\arg\max}\prod_{t=1}^{T'}N(o_t;\mu_{q_{\max},t},\Sigma_{q_{\max},t})$。前一个问题由**状态时长概率分布**解决，后一个问题在给定状态序列下对 $o$ 求最大化。

### HMM 的缺陷（掌握）

| 缺陷         | 原因                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------- |
| **过平滑**   | HMM 合成的过平滑问题导致合成效果平淡、音质不好                                               |
| 状态独立假设 | HMM 基于建模假设各状态之间独立，状态参数分布是**统计平均**的结果                             |
| 浅层线性模型 | 决策树作为浅层线性模型无法建模复杂映射关系，对输入特征和数据空间的线性分割会降低模型泛化能力 |
| 短时相关     | 特征的短时相关特性未被建模                                                                   |

## 4.3.2 基于神经网络的语音合成（了解）

| 模型     | 输入                                                                         | 输出                        |
| -------- | ---------------------------------------------------------------------------- | --------------------------- |
| 时长模型 | 由文本分析（从 HMM 系统的抄本）转换出的 one-hot 特征 + 数值特征              | 音素时长 + 其状态时长       |
| 声学模型 | 时长模型的输入按时长转换得到的 **frame 级信息** + 与状态及帧数相关的位置信息 | 谱参数、基频、清浊音（u/v） |

经声码器得到语音。输入特征表示（了解）：① 数值特征保留原值（如"当前音节含 5 个音素"就在对应维度写 5）；② 类别特征用 **one-hot**（如音素共 66 个、当前音素排第 2，则第 2 维填 1，其余 65 维填 0）；③ 增加状态信息（如 7 状态建模、当前帧处于第 5 个状态 → `0 0 0 0 1 0 0`）。时长模型的输入数与音素数相同，参数生成模型的输入数与帧数相同。

| 模型 | 要点                                                                                                                                                                                            |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DNN  | 文本转成输入特征序列 $x_n^t$（含上下文特征与音节时长等），经前向传播映射到输出特征 $y_m^t$（谱参数与激励参数）；用训练数据中的 ⟨上下文特征, 语音特征⟩ 对训练                                    |
| RNN  | 用时间上连续的结构模拟人的发音过程；输入完整句子时从句首到句尾、从句尾到句首**双向**处理上下文信息；使用深度双向 LSTM（DBLSTM）；输入输出特征由 HMM **强制对齐**，若未强制对齐也可结合 CTC 建模 |

HMM 与 NN 语音合成对比（了解）：

| HMM 合成                   | 说明 | NN 合成                    | 说明                             |
| -------------------------- | ---- | -------------------------- | -------------------------------- |
| 训练速度快                 | 优点 | 更好拟合参数               | 优点（但只预测均值，没有多样性） |
| 模型小                     | 优点 | 拟合长依赖特性             | 优点                             |
| 合成速度非常快             | 优点 | 合成速度快                 | 优点                             |
| 音质不好，有机械感         | 缺点 | 时长模型与声学模型分开建模 | 缺点                             |
| 模型平均，没有准确预测参数 | 缺点 | 依然使用源—滤波器声码器    | 缺点                             |
| 依赖源—滤波器 vocoder      | 缺点 |                            |                                  |

## 4.3.3 声码器（了解）

**源—滤波器模型（Source-filter model）**：声音由**激励（excitation）**和相应的**滤波器（vocal tract）**组成；声道模型把声道看作谐振腔，即"共振峰模型"。

| 激励类型 | 机制                                                                 | 简化激励信号   |
| -------- | -------------------------------------------------------------------- | -------------- |
| 浊音     | 气流通过紧绷的声带、对声带冲击而产生振动，使声门处形成准周期性脉冲串 | 周期性脉冲激励 |
| 清音     | 声带处于松弛状态、不发生振动，气流通过声门直接进入声道               | 随机白噪声     |

这种**二元激励模型**把复杂的产生激励过程简化为两部分，大大简化了声门激励特征，但**合成语音的自然度较低**。

参数对应关系：**F0/pitch** 对应激励部分 $e(n)$ 的周期脉冲序列与白噪声的叠加；**spectral envelope** 对应声道谐振部分的 $h(n)$；**aperiodicity** 对应激励 $e(n)$ 中的非周期序列。

WORLD 声码器（了解）三步：

| 步骤 | 做法                                                                                                                   |
| ---- | ---------------------------------------------------------------------------------------------------------------------- |
| 1    | 输入 wave，通过 **DIO** 算法估计出 F0 contour（基频）                                                                  |
| 2    | F0 与 wave 作为输入，由 **Cheap Trick** 估计出 spectral envelope（频谱包络）                                           |
| 3    | 输入 F0/谱包络/wave，用 **PLATINUM** 估计得到 aperiodic parameter（非周期参数）                                        |
| 使用 | 作为声码器使用时只需关注模型后半部分：声学特征（F0、谱包络、非周期参数）由声学模型预测，**WORLD 负责把特征还原成波形** |

# 4.4 语音合成的技术展望

## 4.4.1 端到端的语音合成（了解）

端到端（E2E）TTS 直接读取文本作为输入、**不使用任何中间表示**、直接输出语音波形；优化目标是整个系统而不是一个个子系统，从而减少人工假设与多阶段建模导致的性能损失。

| 类型         | 内容                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------ |
| 前端的端到端 | 把韵律预测模型、持续时长模型和语音特征模型统合到一个模型里，直接读取上下文无关的符号预测语音特征 |
| 后端的端到端 | 读取语音特征作为输入，直接产生声音波形，因此也称为**神经声码器**                                 |

目前最成熟的端到端模型是 **Tacotron 2**（Shen et al., 2018），把前端的端到端模型（Tacotron）和后端的端到端模型（WaveNet）结合在一起，合成质量堪比自然语音。

| 模型       | 要点                                                                                                                                                                                                                                                                                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tacotron 2 | ① 结合注意力机制的**循环序列到序列**特征预测网络，从输入字符串预测梅尔谱参数帧序列；② WaveNet 改良版，基于预测的梅尔谱产生时域波形。编码器把字符序列 $X=[x_1,\ldots,x_T]$ 转为隐式特征 $H=[h_1,\ldots,h_T]$，经嵌入层 $\bar E(x)$、3 层卷积网络、双向 LSTM：$f_e=\text{ReLU}(F_3*\text{ReLU}(F_2*\text{ReLU}(F_1*\bar E(x))))$，$H=\text{BLSTM}(f_e)$ |
| FastSpeech | 针对自回归模型（Tacotron2）**生成速度慢、鲁棒性差（跳词/重复）、可控性差**的问题；把文本（音素）序列作为输入，**非自回归**地生成梅尔频谱，利用文本与语音的**单调对齐**加速：采用 Transformer + 1D 卷积前馈网络并行生成；**时长预测器**直接预测时长、不需注意力学习对齐，避免跳词重复；**长度调节器**解决序列长度不匹配并控制语速与部分韵律            |
| Grad-TTS   | 基于**去噪扩散概率模型**的声学模型；text encoder 把 $x_{1:L}$ 转成文本表示，时长预测器预测蒙特卡洛对齐得到帧级表示，再送入扩散模型：$dX_t=\frac{1}{2}(\mu-X_t-s_\theta(X_t,\mu,t))\beta_tdt$，$s_\theta$ 为神经网络参数，可用向后一阶欧拉法求解                                                                                                       |
| VITS       | 实现**声学模型与解码器统一建模**，避免两段式框架中共用的梅尔谱中间表征引入的误差；三部分：**先验编码器**（获取文本先验分布的均值 $\mu_\theta$ 与方差 $\sigma_\theta$）、**后验编码器**（用线性谱而非梅尔谱以提供更高分辨率信息）、**Flow 标准化流**（在简单分布与复杂分布间做可逆变换）                                                               |
| VALL-E     | 把语音合成看作**条件语言模型**任务而非连续信号回归；用 60k 小时数据训练，具有上下文学习能力——对训练集中未见过的说话人，只需 **3 秒**音频提示即可合成高相似度音频；预训练模型 EnCodec 的码本分层，**第一个码本用自回归（AR）预测，其余码本用非自回归（NAR）预测**                                                                                      |

声码器（了解）：

| 声码器   | 要点                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| WaveNet  | 不需任何假设直接生成声音波形，质量优于传统声码器；对给定外部输入 $y$ 建模条件概率 $P(z\mid y)=\prod_{t=1}^{T}p(z_t\mid z_1,\ldots,z_{t-1},y)$，条件序列 $y$ 可以是文本、说话人信息等；使用**扩张因果卷积**处理长时关联，获得更大时间接受野（扩张系数 1、2、4、8 时接受野为 16）                                                                                                                                                         |
| LPCNet   | WaveRNN 用 RNN 建模提高效率，但复杂度比传统 DSP 高两个数量级，原因是需同时建模声源与滤波器；LPCNet 把语音生成分为**基于 LPC 线性预测的线性部分**与**神经网络建模的非线性部分**：$\varepsilon(n)=s(n)-\sum_{i=1}^{p}a_is(n-i)$，$a_i$ 表示声道滤波器属性、残差与声源相关。特征提取以帧为单位（10 ms、160 pt），语音生成以采样为单位；网络分为**帧率网络**（提供条件矢量，一帧一次且帧内不变）与**采样率网络**（核心），外加 LPC 计算模块 |
| HiFi-GAN | 采用**生成对抗网络**的高速声码器，速度与音质兼顾；用**转置卷积**（反卷积）上采样，每次上采样后接**多感受野融合（MRF）**残差网络以缓解棋盘效应、提升生成质量；与 WaveNet（带洞卷积、逐样本点生成、推理慢）相比，交替使用带洞卷积与普通卷积以在保证音质的同时提高推理速度                                                                                                                                                                 |

## 4.4.2 语音合成前沿任务（了解）

| 任务     | 定义与要点                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| 语音克隆 | 利用**少量目标人语音数据**，构建具有目标发音人音色特征的语音合成系统                                       |
| 语音转换 | 不同于语音合成：对输入的**源说话人语音**做转换，把音色换成目标发音人的音色，而**保留源语音的文本内容不变** |
| 共同点   | 都要利用目标发音人的少量语音，训练具有目标音色特点的语音生成模型                                           |

| 方向                       | 做法                                                                                                                                                                                                                                                                                      |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 个性化（Jia et al. 2018）  | 基于 Tacotron2 与迁移学习：① 说话人编码器抽取说话人嵌入；② 合成器基于 Tacotron2 生成声学特征；③ 声码器用 WaveNet 重构波形；说话人 ID 任务的损失函数最小化同一说话人嵌入的**余弦距离**、最大化不同说话人嵌入之间的距离                                                                     |
| 多风格（Wang et al. 2018） | 基于 Tacotron 框架的**全局风格标记（GST）**模型：把韵律嵌入矢量分为固定数量的风格符号集合；训练时参考嵌入（RE）作为注意力模块的询问矢量，学习 RE 与随机初始化嵌入集合中每个标注的相似度；推理时风格嵌入可由参考语音序列获得，也可直接设置文本编码器的标记（实现不依赖参考信号的风格控制） |
| 情感（Lee et al. 2017）    | 基于结合情感标注的 Tacotron 模型做端到端情感合成；考虑**平静、生气、害怕、高兴、悲伤、惊讶**六种情感；情感标注经 pre-net 编码后引入解码网络，合成时给定文本与情感标注即可                                                                                                                 |
| 抗噪                       | 嘈杂环境下人们采用不同发音策略：说话人改变 $F_0$ 与 $F_1$，并提高相关共振峰能量避免被噪声掩蔽，即**朗伯德效应（Lombard effect）**；结果是能量在 **3 kHz** 处增强（与歌声共振峰相关、属耳朵敏感度区域）                                                                                    |
