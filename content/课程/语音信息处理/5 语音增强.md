# 5.1 语音增强概述

## 5.1.1 语音增强的基本概念

### 从鸡尾酒会问题说起

| 因素       | 来源                         |
| ---------- | ---------------------------- |
| 目标语音   | 目标说话人                   |
| 干扰说话人 | 其他说话人引起               |
| 混响       | 障碍物反射引起的声音持续传播 |
| 背景噪声   | 环境噪声                     |

### 语音分离与语音增强

| 概念     | 定义                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 语音分离 | 将目标语音从背景干扰中分离出来的任务，是语音信息处理的核心算法之一                                                           |
| 分类     | 按背景干扰类型分为三类：**语音去噪**（语音与非语音分离，狭义增强）、**语音去混响**、**说话人分离**（多说话人分离，狭义分离） |

本章重点是**广义的语音增强**，且主要聚焦**单说话人场景**。

| 模型             | 公式                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------- |
| 单说话人受损语音 | $y(n)=x(n)*h(n)+v(n)$；$h(n)$ 为物体反射形成的**房间脉冲响应（RIR）**，$v(n)$ 为加性噪声 |
| 语音增强定义     | 将受损语音中的**背景噪声和混响**去除，得到目标干净语音                                   |
| 加性噪声情形     | $y(n)=x(n)+v(n)$（本章 5.2 只考虑加性噪声）                                              |

| 目标       | 说明                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 提升质量   | 提高语音质量                                                                                                                           |
| 提升可懂度 | **可懂度（语音清晰度）**：听者能听懂通过一定传声系统传递的语音信号的百分率；不少增强技术在减少噪声的同时会引入语音失真，进而损伤可懂度 |

| 范围         | 内容                     |
| ------------ | ------------------------ |
| 狭义语音增强 | 移除**加性噪声**         |
| 广义语音增强 | 移除**混响（乘性噪声）** |

| 概念 | 定义                                                                                                                                                                                                                         |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 混响 | 一种室内声学现象：声音从声源发出后在空气中传播，在房间界面上产生反射、吸收、扩散、透射、干涉、衍射等波动效应，形成复杂的室内声场，使人产生混响感；当室内声场稳定、声源停止发声后，声音由于多次反射或散射而继续发出，称为混响 |

对比（了解）：背景噪声与干净语音的**相关性更低**；混响语音与干净语音的**相关性更高**。

### 语音增强的目的与类型

| 目的     | 场景                                                 |
| -------- | ---------------------------------------------------- |
| 人类感知 | 提高语音可懂度，使人听起来更清晰；助听器、会议系统等 |
| 机器感知 | 提高语音识别（ASR、说话人识别等）的性能              |

| 分类维度 | 类型                                               |
| -------- | -------------------------------------------------- |
| 通道数   | 单通道增强 / 多通道增强                            |
| 方法类型 | 传统增强 / 基于神经网络的增强                      |
| 处理域   | 时域增强 / 频域增强                                |
| 噪声类型 | 语音去噪（加性噪声）/ 去混响（乘性噪声）/ 两者兼具 |

### 常用度量指标（了解）

| 指标                  | 含义                                    |
| --------------------- | --------------------------------------- |
| PESQ                  | 感知语音质量评估                        |
| STOI                  | 短时客观可懂度                          |
| Segmental SNR         | 分段信噪比                              |
| 对数似然比 / 倒谱距离 | 基于谱距离的客观指标                    |
| SDR / SIR             | 信号失真比 / 信号干扰比（语音分离常用） |
| SRMR                  | 语音混响调制能量比                      |
| WER                   | 单词错误率（下游任务指标）              |

| 指标     | 要点                                                                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PESQ     | 需要带噪的衰减信号和一个原始参考信号；两条语音经电平调整、输入滤波、时间对准和补偿、听觉变换后分别提取参数，综合时频特性得到 PESQ 分数，最后映射到 **MOS**；得分范围 $-0.5\sim4.5$，越高越好 |
| SNR      | 含噪语音中语音与噪声功率之比取对数：$SNR=10\log_{10}\dfrac{P_S}{P_N}$（$P_S$ 信号功率、$P_N$ 噪声功率）                                                                                      |
| 分段 SNR | 语音是缓慢变化的短时稳定信号，不同时间段信噪比应不同，故分段计算以改善问题                                                                                                                   |
| 倒谱距离 | $CD=10/\log_{10}\sqrt{2\sum_{i=1}^{p}\{C_x(i)-C_y(i)\}^2}$（课件原式）；$C_x,C_y$ 是干净语音与失真语音的倒谱系数（LPCC 或 MFCC），$p$ 为维数                                                 |
| SDR      | $SDR=10\log_{10}\dfrac{\lVert s_{target}\rVert^2}{\lVert e_{interf}+e_{noise}+e_{artif}\rVert^2}$，语音分离中常用的评价指标                                                                  |
| SIR      | $SIR=10\log_{10}\dfrac{\lVert s_{target}\rVert^2}{\lVert e_{interf}\rVert^2}$，反映增强后干扰的程度                                                                                          |

其中 $e_{interf}$、$e_{noise}$、$e_{artif}$ 分别是**干扰、噪声和伪影误差（musical noise）**项。

## 5.1.2 语音增强方法的回顾（基本概念）

发展历史（了解）：

| 时间 | 方法                                | 特点                         |
| ---- | ----------------------------------- | ---------------------------- |
| 1976 | 基于信号处理：谱减法、维纳滤波器    | 高泛化能力                   |
| 1988 | 基于统计的语音增强（HMM、GMM、NN…） | 性能较高但低泛化             |
| 2012 | 统计与信号处理 + NMF、SVM、掩蔽…    | 较高性能                     |
| 2013 | 基于深度学习的**频域**分析          | 高性能但低泛化和高计算成本   |
| 2017 | 基于深度学习的**时域**分析          | 进一步提高质量但计算成本更高 |

### 基于传统信号处理的流程（掌握）

传统语音增强系统的目标是**抑制增益**，而抑制增益依赖两个核心步骤：**静音检测（VAD）**和**噪声估计**模块——只有准确估计噪声谱才有可能准确估计抑制增益，通常利用 VAD 来进行噪声估计。

| 方法                 | 要点                                                                                                                                                                                                                                                                                                |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 维纳滤波（了解）     | 最早起源于二战期间为解决军事上对空射击的控制问题，由 Norbert Wiener 提出；从带噪观测信号中提取所需干净信号，是**统计意义上的最优滤波器**（波形的最优线性估计器）；以估计结果与真值间误差的**最小均方值**为最佳准则；运算复杂度较小、降噪性能不错                                                    |
| 基于统计模型（了解） | 使用统计模型与优化准则，重点研究**幅度谱的非线性估计器**，把噪声与语音频谱系数的概率密度函数显式考虑在内（有时用非高斯先验），常与考虑**语音存在概率**的软判决增益修改结合；代表方法有**最大似然（ML）估计器**与**贝叶斯估计器**（MMSE、最大后验 MAP）；另外 NMF、SVM、浅层神经网络等也带来较大提升 |

### 基于深度学习的流程（基本概念）

分**训练阶段**与**增强阶段**：训练用大规模数据训练深度学习模型参数，增强阶段用该模型做增强。特点是性能佳，但**计算量大、容易过拟合**。

（了解）语音分离方法 **SpEx++** 在公开数据集 WHAMR 上的分离效果（Ge et al., ICASSP 2021）。

# 5.2 单通道语音增强

| 方法类型     | 特点                                                               | 典型算法           |
| ------------ | ------------------------------------------------------------------ | ------------------ |
| 传统信号处理 | 计算量小、通用性强；**最重要的是噪声估计**                         | 谱减法、维纳滤波器 |
| 神经网络     | 深度神经网络具有很强的回归能力；性能高，但**计算量大、泛化能力差** | DNN、LSTM 等       |

## 5.2.1 基于传统信号处理的语音增强（基本概念）

### 谱减法

定义：用带噪信号的频谱减去噪声信号的频谱，得到干净信号频谱的估计。

噪声估计的两个前提假设：

| 假设         | 说明                                                                                      |
| ------------ | ----------------------------------------------------------------------------------------- |
| 静音段可估计 | 当语音信号不存在时可以估计和更新噪声谱；一般假设输入的一段语音中**前 $n$ 帧**作为静音时间 |
| 噪声平稳     | 假设噪声是平稳的或缓慢变化的过程，并且噪声谱在更新周期之间没有显著变化                    |

增强信号由估计信号频谱的**反离散傅里叶变换**得到。

时频表示与推导链：

| 步骤                   | 公式                                                                                                                                                                     |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 时域（只考虑加性噪声） | $y(n)=x(n)+v(n)$                                                                                                                                                         |
| 频域                   | $Y(\omega)=X(\omega)+V(\omega)=\lvert Y(\omega)\rvert e^{j\theta_y(\omega)}$                                                                                             |
| 不相关假设             | $\lvert Y(\omega)\rvert^2=\lvert X(\omega)\rvert^2+\lvert V(\omega)\rvert^2$                                                                                             |
| 谱减                   | $\lvert\hat X(\omega)\rvert=\left(\lvert Y(\omega)\rvert^2-\lvert\hat V(\omega)\rvert^2\right)^{1/2}$，$\hat X(\omega)=\lvert\hat X(\omega)\rvert e^{j\theta_y(\omega)}$ |

干净语音估计值的**相位谱用带噪语音的相位谱粗略表示**——因为在一定程度上相位不会严重影响语音质量。

广义谱减法（避免出现负功率谱值，并可对功率谱或振幅谱做一般化操作）：

$$\left\lvert\hat X(\omega)\right\rvert^{2n}=\max\left(\lvert Y(\omega)\rvert^{2n}-\alpha\cdot\left\lvert\hat V(\omega)\right\rvert^{2n},\ \beta\cdot\lvert Y(\omega)\rvert^{2n}\right)$$

| 参数     | 含义                                                   |
| -------- | ------------------------------------------------------ |
| $\alpha$ | 噪声**超估计**因子                                     |
| $\beta$  | 频谱**下限**系数，用于防止产生负的频谱结果             |
| $n$      | 任意指数参数；$n=1$ 为 powerSS，$n=0.5$ 为 magnitudeSS |

| 优点                                         | 缺点                                                                                                               |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 比较简单，只需正反傅里叶变换，实时实现较容易 | 适用信噪比范围较窄，低信噪比时对可懂度损伤较大；频谱直接相减会产生"**音乐噪声**"，具有一定节奏性，听上去类似音乐声 |

（了解）谱减法也可用于混响消除。

### 维纳滤波

| 项         | 内容                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 滤波器定义 | 从连续的（或离散的）输入数据中滤除噪声和干扰以提取有用信息的过程称为滤波，相应装置称为滤波器                                           |
| 原理       | 寻找系数为实数的线性滤波器，使滤波后信号与原干净语音信号之间的**均方误差最小**（直接估计干净语音信号），也称最小二乘（最小平方）滤波器 |
| 工程地位   | 传统维纳滤波器基于 VAD 等算法进行噪声估计进而设计滤波器；运算复杂度较小、降噪性能不错，在工程领域一直很重要                            |

传输函数与功率谱估计：

$$H(\omega)=\frac{\hat X(\omega)}{Y(\omega)}=\frac{P_x(\omega)}{P_x(\omega)+P_v(\omega)},\qquad P_x(\omega)=E\left[\lvert X(\omega)\rvert^2\right],\quad P_v(\omega)=E\left[\lvert V(\omega)\rvert^2\right]$$

（短时平稳假设下，$E[\cdot]$ 表示对频谱求统计平均；平稳噪声一般假设每帧的噪声功率已知，即由该帧前面的"静"时段估计出噪声功率谱。）

$E[\lvert X(\omega)\rvert^2]$ 的两种估计方法（了解）：

| 方法 | 做法                                                                                                                                                                               |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 一   | 先将数个含噪语音帧 $Y(\omega)$ 平方的平均值作为 $E[\lvert Y(\omega)\rvert^2]$ 的初估值，再减去静音段得到的 $E[\lvert V(\omega)\rvert^2]$ 作为 $E[\lvert X(\omega)\rvert^2]$ 的估值 |
| 二   | 先将数帧中平滑的 $\lvert Y(\omega)\rvert^2$ 作为 $E[\lvert Y(\omega)\rvert^2]$ 的初估值，再减去 $E[\lvert V(\omega)\rvert^2]$ 作为 $E[\lvert X(\omega)\rvert^2]$ 的估值            |

得到 $H(\omega)$ 后，每帧频谱按 $\hat X(\omega)=H(\omega)Y(\omega)$ 得到，时域信号由傅里叶逆变换得到，**相位部分设为 $Y(\omega)$ 的相位**。

### 传统方法总结与主要问题

| 方法     | 优点                                                     | 缺点                               |
| -------- | -------------------------------------------------------- | ---------------------------------- |
| 谱减法   | 实现简单、运算量小                                       | 效果较差，容易出现刺耳的"音乐噪声" |
| 维纳滤波 | 原理较复杂、运算量较大，但性能更好，**极大消减音乐噪声** | 与干净语音仍有较大差距             |

频谱减法与维纳滤波器的主要问题：**不擅长处理非线性噪声（混响等乘性、卷积噪声）**；**不擅长处理非平稳噪声（时变噪声）**；**引入"音乐噪声"**；性能不佳、噪声消除不干净。

## 5.2.2 基于深度学习的语音增强（掌握）

为什么要用深度学习：

| 优势                                 |
| ------------------------------------ |
| 非线性变换能力                       |
| 强大的回归能力                       |
| 擅长处理非平稳噪声                   |
| 增强后的语音更自然，**没有音乐噪声** |

分类：**频域**（本章重点，增强语音频谱的幅度）与**时域**（直接增强语音波形）。

### 频域增强的三步流程（掌握）

| 步骤     | 做什么                                                     |
| -------- | ---------------------------------------------------------- |
| 特征提取 | 将时域信号转换为频域特征                                   |
| 特征增强 | 利用神经网络增强频谱图的振幅                               |
| 波形重构 | 将增强的频谱图振幅和**噪声相位**信息转换（重构）为时域波形 |

### 两种框架：映射 vs 掩蔽

| 框架            | 出处与思路                                                                     |
| --------------- | ------------------------------------------------------------------------------ |
| 映射（mapping） | Xu et al., 2015：把语音增强视为**多变量回归**问题，非线性回归函数由 DNN 参数化 |
| 掩蔽（mask）    | Wang et al., 2017：受**听觉掩蔽现象和听觉场景分析**启发，以掩蔽为主要目标      |

共同优点：相对传统谱减、维纳滤波等方法效果有极大提升；**对非平稳噪声有很好的抑制作用**（掩蔽框架还广泛用于语音降噪、多说话人分离）。

基于映射的主要步骤（掌握）：

| 阶段 | 步骤                                                                                                                                       |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 训练 | 用 STFT 提取含噪音频与干净音频的语谱图特征（前者为输入、后者为目标），用深度学习学习含噪语谱图到干净语谱图的**非线性映射**，训练并保存模型 |
| 增强 | 将含噪音频语谱图输入训练好的模型得到干净音频特征，把干净语谱图与**原始相位**做 ISTFT 变换，重建去噪音频                                    |

基于映射的训练损失（基本概念）：**均方误差（MSE）准则**

$$J_{MSE}(W,b;\mathbb S)=\frac{1}{M}\sum_{m=1}^{M}J_{MSE}(W,b;o^m,y^m),\qquad J_{MSE}(W,b;o,y)=\frac{1}{2}\lVert v^L-y\rVert^2=\frac{1}{2}(v^L-y)^{\mathrm T}(v^L-y)$$

$\{W,b\}$ 是模型参数，$o$ 是观察向量，$y$ 是相应输出向量；通过学习（**误差反向传播 BP**）最小化损失函数。

基于掩蔽的主要步骤（掌握）：

| 阶段 | 步骤                                                                                                                                                                             |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 训练 | ① 特征提取：用 STFT 提取含噪音频与干净音频的语谱图特征；② **计算掩蔽值**（从含噪音频到干净语音的掩蔽值，即 label）；③ 模型参数更新：学习含噪语谱图到掩蔽值的非线性映射并保存模型 |
| 增强 | ① 用 STFT 提取含噪音频语谱图；② 输入模型得到掩蔽值；③ 把含噪语音语谱图与掩蔽值**相乘**，得到干净语音语谱图的估计值；④ 信号重构：与原始带噪相位做 ISTFT，得到增强语音             |

### 四种掩蔽目标（训练损失，了解）

| 掩蔽                  | 定义 / 公式                                                                                                                                    | 损失函数  | 备注                                               |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | --------- | -------------------------------------------------- |
| 理想二进制掩码 IBM    | $IBM=\begin{cases}1, & SNR(t,f)>threshold\\ 0, & otherwise\end{cases}$：把每个 T-F bin 标记为**目标主导型或干扰主导型**                        | 交叉熵 CE | 基于噪声信号的二维时频表示                         |
| 理想比率掩码 IRM      | $IRM=\left(\dfrac{X(t,f)^2}{X(t,f)^2+V(t,f)^2}\right)^{\beta}$，$\beta$ 为可调参数（一般取 **0.5**），可看作 IBM 的**软版本**                  | MSE       | 适用于加性噪声，**不适用于混响**                   |
| 相位敏感掩模 PSM      | $PSM(t,f)=\dfrac{\lvert X(t,f)\rvert}{\lvert Y(t,f)\rvert}\cos\theta$，$\theta$ 是 T-F bin 中干净语音与带噪语音的**相位差**                    | —         | 增加了相位信息，比不加相位性能有提升               |
| 复数理想比例掩蔽 cIRM | $cIRM=\dfrac{Y_rX_r+Y_iX_i}{Y_r^2+Y_i^2}+i\dfrac{Y_rX_i-Y_iX_r}{Y_r^2+Y_i^2}$，$\hat X=cIRM*Y$（复数域理想掩蔽，可直接从含噪语音重建干净语音） | —         | 有实部与虚部可分别估计；用 DNN 学习后经 ISTFT 重建 |

听觉掩蔽现象（了解）：当一个声音的感知受到另一个声音的影响时就会发生**听觉掩蔽**，是听觉感知中的一种基本现象；粗略地说，**在临界频带内强音掩盖弱音**。

# 5.3 多通道语音增强

## 5.3.1 固定波束形成（基本概念）

多通道语音增强处理的是**使用麦克风阵列录制的音频**：它考虑了音频通道与**声源位置信息**之间的信息差，因此具有更好的抑制**方向性噪声**的能力。

| 阵列类型     | 参数                                             |
| ------------ | ------------------------------------------------ |
| 均匀线性阵列 | $L$：阵列长度；$d$：相邻麦克风间距               |
| 均匀圆形阵列 | $R$：圆形阵列半径；$d$：实际的相邻麦克风直线间距 |

**波束形成（Beamforming）**是主要的阵列处理技术之一，技术成熟较早，早期主要用于雷达等定位系统。

波束形成的基本思路（掌握）：对各个麦克风单元接收到的语音信号进行**加权求和**，加权系数决定增强效果；通过调整加权系数，达到对**目标声源方向增强、其他干扰方向抑制**的效果，使整个麦克风阵列对目标方向形成**聚焦**。

| 类型           | 划分依据与特点                                                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 固定波束形成   | 一旦设计好滤波器后，**加权系数不再改变**；优点：计算简单、容易实现；缺点：环境适应性差、对噪声不具有自适应性；经典算法：**延迟求和 DSB**、滤波求和 FSB |
| 自适应波束形成 | **加权系数具有自我调节能力**；优点：性能好、环境适应性好、对噪声有自适应性；经典算法：**MVDR**、线性约束最小方差 LCVM、广义旁瓣抵消法 GSC              |

### 延迟求和波束形成（DSB，掌握）

DSB 是经典而简单的固定波束形成方法，主要包含**延迟补偿**与**加权求和**两个处理：延迟补偿使每个麦克风信号在**时间上对齐**，再经加权求和得到增强后的输出信号。

麦克风信号模型（基本概念）：

| 量         | 含义 / 公式                                    |
| ---------- | ---------------------------------------------- |
| $\xi$      | 声程差：$\xi=d\sin\theta_s$                    |
| 信号关系   | $x_2(t)=x_1(t-\tau_s)$                         |
| TDOA       | $\tau_s=\xi/c=(d\sin\theta_s)/c$（到达时间差） |
| $c$        | 声速                                           |
| $\theta_s$ | 到达方向 DOA                                   |
| $d$        | 麦克风间隔                                     |

线性阵列：$x_i(t)=x_1(t-(i-1)\tau_s)$。

DSB 公式（了解）：

$$y(t)=\sum_{i=1}^{M}w_ix_{si}(t-D_i),\qquad D_i=D_0-(i-1)\hat\tau_s,\qquad \hat\tau_s=(d\sin\hat\theta_s)/c,\qquad i=1,2,\ldots,M$$

$x_{si}(t)=x_{s1}(t-(i-1)\tau_s)$；$w_i$ 为第 $i$ 个麦克风的权重，等权重时取 $1/M$；延迟补偿后 $x_{si}(t-D_i)=x_{s1}(t-(i-1)\tau_s-D_i)\approx x_{s1}(t-D_0)$，即各通道对齐。

### TDOA 与 DOA 的估计（掌握）

思路：利用两个信号之间的**互相关与自相关特性**：

$$\phi_{12}(\tau)=E[x_1(t)\cdot x_2(t+\tau)]=E[x_1(t)\cdot x_1(t+\tau-\tau_s)]=\phi_{11}(\tau-\tau_s)$$

$\phi_{12}(\tau)$ 是互相关函数，$\phi_{11}(\tau)$ 是自相关函数。当延迟为零（$\tau-\tau_s=0$）时自相关函数 $\phi_{11}(\tau-\tau_s)$ 的值最大，因此

$$\hat\tau_s=\underset{\tau}{\arg\max}\ \phi_{12}(\tau)=\underset{\tau}{\arg\max}\ \phi_{11}(\tau-\tau_s),\qquad \hat\theta_s=\sin^{-1}(c\hat\tau_s/d)$$

即增强从方向 $\hat\theta_s$ 到来的语音信号。

**基于相位变换的广义互相关（GCC-PHAT）**（了解）：

$$\phi(\omega,t)=\frac{X_i(\omega,t)X_j^*(\omega,t)}{\lvert X_i(\omega,t)\rvert\lvert X_j(\omega,t)\rvert},\qquad C(\tau_{ij},t)=\int_{-\infty}^{+\infty}\phi(\omega,t)e^{i2\pi\omega\tau_{ij}}d\omega$$

其中 $X_i,X_j$ 是麦克风对接收信号的频谱，$t$ 表示语音帧索引；把这些 $C(\tau_{ij},t)$ 沿 $t$ 求和得 $C(\tau_{ij})=\sum_{t=0}^{T-1}C(\tau_{ij},t)$，最终 TDOA 由 $\hat\tau_{ij}=\underset{\tau_{ij}}{\arg\max}\ C(\tau_{ij})$ 计算。

## 5.3.2 自适应波束形成（了解）

自适应波束形成：加权系数具有自我调节能力，性能好、环境适应性好、对噪声有自适应性；目前已广泛应用于麦克风阵列语音增强。经典算法：MVDR、LCVM、GSC。

| 项         | 内容                                                                                                                                |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| MVDR 定义  | 基于**最大信干噪比（SINR）**准则的自适应波束形成算法：自适应地将麦克风阵列输出在所需方向的功率最小化，并最大化信干噪比以抑制噪声    |
| 应用与实现 | 军事领域（如水面舰艇与潜艇之间的水声无线通信）；采用自适应波束形成中常用的**采样矩阵求逆（SMI）**算法，在信干噪比下具有较快收敛速度 |

**后置滤波**：波束形成后依然会有残留，为进一步抑制噪声，大多数波束形成后都会加一个后置滤波。

| 要点 | 内容                                                                                                                                |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 分工 | 波束形成抑制**波束指向之外**的噪声与干扰；与波束指向**同方向**的噪声则用后置滤波消除                                                |
| 做法 | 估计语音、噪声及干扰的**功率谱密度**，据此对波束形成（DSB、FSB、MVDR、LCMV 等）的结果再作一次增益处理，主要用于抑制同方向噪声与干扰 |

# 5.4 语音增强技术的展望

## 5.4.1 前沿深度学习模型（了解）

| 模型/技巧          | 要点                                                                                                                                                                                                                      |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| LSTM               | 可以利用上下文信息进行增强；相对 DNN 通常有更好的性能                                                                                                                                                                     |
| 对抗神经网络       | 利用生成模型进行语音增强，并用判别器判断生成语音的质量                                                                                                                                                                    |
| 集成学习           | 联合不同网络：CNN 可同时学习上下文与频域信息，LSTM 善于学习上下文信息，DNN 适合做非线性映射                                                                                                                               |
| 多目标训练（掌握） | 很难断定映射与掩蔽哪个更好，尤其在噪声脚本不可见时；**不同 SNR 水平下映射与掩蔽框架有很强的互补性**，故可多目标联合训练                                                                                                   |
| 多任务学习（掌握） | 语音的其他任务（如 ASR、声纹 ASV）可提供丰富的语义或说话人信息作为增强的互补信息；增强后的语音对识别任务也有帮助                                                                                                          |
| 时域增强           | 频域增强受**相位信息**限制难以进一步提高；时域模型可用 DNN 且无需提取特征（端到端）。**Wave-U-Net**：U-Net 对一维时域信号的变形，通过一系列下采样/上采样块（1D 卷积）在多个尺度与时间分辨率上计算特征，直接作用于原始波形 |

## 5.4.2 说话人分离（了解）

多说话人现实场景模型：

$$y(n)=\sum_{i}^{M}\left(x_i(n)*h_i(n)\right)+v(n)$$

$M$ 为说话人数量。

| 机制             | 说明                                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------ |
| 人耳的解析能力   | 人类依靠**耳蜗**对声音频谱进行最初分析，并通过大脑**自下而上刺激驱动**与**自上而下任务驱动**的组合选择特定听觉物体 |
| 自下而上刺激驱动 | 被动接收听觉刺激，通过**声源间的差异**进行分离（对应**盲源分离**方案）                                             |
| 自上而下任务驱动 | 主动选择性倾听特定声音，**聚焦注意**特定声源（对应**目标说话人提取**方案）                                         |

| 方案                       | 要点                                                                                                                                                                                                                                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 盲源分离（自下而上）       | 数据驱动直接构建混合信号与各源信号之间的非线性映射；面向复杂声学场景引入环境信息估计或系统融合可提升鲁棒性；多说话人交互场景中 **DPCL、PIT、TasNet** 较有效                                                                                                                                 |
| 置换不变性训练 PIT         | 直接用语音增强做语音分离会有**置换问题**；PIT 直接汇集混合源的所有可能排列，用**误差最低的排列**更新网络                                                                                                                                                                                    |
| 时域分离 TasNet            | 频域增强网络的三个问题：STFT 不一定是最优的分离变换、STFT 转复数域但难以处理相位谱、需要高频高分辨率否则产生时延；TasNet 提出时域端到端方法，分**编码器、分离、解码器**三步，直接对时域语音分离                                                                                             |
| 目标说话人提取（自上而下） | 通过给定的目标说话人信息（现实应用中用户**注册**）提取目标说话人特征，关注其声源、抑制其他干扰声源；**SpEx+**：用**时域**分离替代频域以移除相位估计问题，并把目标说话人特征与混合信号特征映射到**同一空间**以减缓特征空间不匹配；**SpEx++**：参考语音较短时引入**多阶段**目标说话人提取策略 |
| 多模态（视听一致性）       | 视觉信息能改善仅基于听觉信息的掩蔽语音感知：视觉语音提供关于时间和听觉语音**振幅包络**的信息，还携带发音信息并影响听觉分流；视听方案常用**视觉信息导向注意**做目标源分离                                                                                                                    |
| 空间模型（麦克风阵列）     | 声源空间位置是促进听觉场景分析的重要线索（双耳振幅、相位或时间差异）；常除空间特征外额外引入目标源方向、脸部/嘴部特征、目标说话人特征，**结合自适应波束形成**做到目标源分离                                                                                                                 |
