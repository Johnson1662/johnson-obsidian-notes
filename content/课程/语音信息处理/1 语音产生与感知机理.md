# 1.1 语音产生的机理

## 1.1.1 有声语言（语音）的形成（了解）

| 概念 | 定义                                                                                                                        |
| ---- | --------------------------------------------------------------------------------------------------------------------------- |
| 声音 | 振动产生的声波，通过介质（空气、固体、液体）传播并能被人或动物听觉器官感知的波动现象                                          |
| 语音 | 声音的一种，是人在言语交流过程中由**发音器官产生**、由**听觉系统感知**的语言载体                                              |
| 言语 | 考虑有声语言的"语言信息"时用"言语"，作为物理信号处理时用"语音"；不引起混淆时不做严格区分                                      |

声音的三个环节：

| 环节 | 机制                                                                                       |
| ---- | ------------------------------------------------------------------------------------------ |
| 产生 | 由振动产生，引起介质（空气等）粒子的简谐（正弦规律）运动，形成波动                            |
| 传播 | 空气分子的简谐振动使周围空气产生疏密变化，形成疏密相间的**纵波**进行传播                      |
| 感知 | 耳蜗将中耳传来的机械运动转为淋巴液的波动，所含频率在基底膜对应位置引起谐振，分解后传入大脑    |

### 谐振频率公式（会套用）

| 声管 / 弦的形式            | 谐振频率                             |
| -------------------------- | ------------------------------------ |
| 两端同类型（两端关或两端开）| $f_n=\dfrac{nc}{2l}$                 |
| 一端关闭、另一端开放       | $f_n=\dfrac{(2n-1)c}{4l}$            |

其中 $f_n$ 为第 $n$ 次谐振频率，$l$ 为管长，$c$ 为音速。**谐振**：一物理系统在特定频率和波长下，比其他频率和波长以更大振幅振动的现象。

套用例子（后面外耳道会用到）：外耳道 $l=2.5$ cm、$c\approx350$ m/s，按一端封闭：

$$f_1=\frac{350}{4\times0.025}=3500\ \text{Hz},\qquad f_2=\frac{3\times350}{0.1}=10500\ \text{Hz}$$

### 语音及语言的形成、发音器官的进化（了解）

| 项         | 内容                                                                                   |
| ---------- | -------------------------------------------------------------------------------------- |
| 语言的形成 | 手势语言出现在人类开始站立、双手解放之后；用声音加动作交流对人类和动物都很常见           |
| 类人猿     | 面部突出，舌头扁平，喉部气囊，舌骨和喉粘结                                               |
| 人类       | 口腔短，咽腔长，弯曲声道，舌骨和喉**分离**（这是能发出复杂语音的形态学基础）             |
