# 3 语音识别

一句话：把语音变成文本——整章就是三段式**声学模型 + 语言模型 + 解码**：声学模型从模板匹配（DTW）演进到统计模型（HMM → GMM-HMM → DNN-HMM），语言模型给解码提供语法约束（N-gram → 神经语言模型），解码器（Viterbi → WFST）在两者的乘积空间里搜最优词序列；最后是端到端与工程挑战。

## 总览（思维导图）

$$
\text{语音}\ X\ \to\ \text{声学模型}\ \to\ \text{解码（语言模型约束）}\ \to\ \text{文本}\ W
\begin{cases}
3.1\ \text{概述}:\ \text{定义、分类、WER、方法演化}\\
3.2\ \text{声学模型}:\ \text{HMM 三问题} \to \text{GMM-HMM} \to \text{DNN-HMM}\\
3.3\ \text{语言模型}:\ \text{N-gram、平滑、神经语言模型}\\
3.4\ \text{解码}:\ \text{Viterbi beam 搜索、WFST（HCLG）}\\
3.5\ \text{展望}:\ \text{CTC、Attention、复杂场景与低资源}
\end{cases}
$$

## 3.0 回顾：倒谱分析与 LPC 的区别（开场页）

| 方法 | 与源—滤波器模型的关系 | 做什么                                                             |
| ---- | --------------------- | ------------------------------------------------------------------ |
| LPC  | **直接**利用          | 预测自回归模型的线性预测系数（$H(z)=\dfrac{G}{1-\sum a_iz^{-i}}$） |

# 3.1 语音识别概述

## 3.1.1 语音识别的基本概念

| 概念 | 内容                                                                                            |
| ---- | ----------------------------------------------------------------------------------------------- |
| 定义 | 自动语音识别（ASR）：机器把人类的**语音信号转变为相应的文本**的技术，是语音信息处理的最核心方法 |
| 用途 | ① 作为最终输出（转写 Dictation）；② 作为自然语言处理（对话系统、机器翻译）的输入                |

### 分类（按三个维度）

| 维度       | 类别                                                                                                                               |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 发音方式   | **孤立词**（isolated words，如"打开空调"）；**连接词**（connected words，词间有停顿）；**连续语音**（continuous speech，自然连读） |
| 词汇表大小 | 小词汇表 10~100 词条；中词汇表 100~1000 词条；大词汇表 1000 词条以上                                                               |
| 说话人     | **特定说话人**（speaker-dependent，只能识别固定某个人）；**非特定说话人**（speaker-independent，能识别任意人）                     |

### 评价指标：单词错误率 WER

$$\text{WER}=\frac{100\times(\#\text{Insertions}+\#\text{Substitutions}+\#\text{Deletions})}{\text{Total Words in Correct Transcript}}$$

课件对齐示例（REF 与 HYP 逐词比对，插入 1 + 置换 2 + 删除 0）：

$\text{WER}=100\times(1+2+0)/6=50\%$

## 3.1.2 语音识别方法的回顾

| 时期                | 主流方法     | 特征             |
| ------------------- | ------------ | ---------------- |
| 70 年代中期以前     | **启发式**   | 基于规则、陈述式 |
| 70 年代中—80 年代中 | **模板匹配** | 确定式、数据驱动 |
| 80 年代中期以后     | **统计模型** | 概率式、数据驱动 |

| 方法     | 要点与缺点                                                                                 |
| -------- | ------------------------------------------------------------------------------------------ |
| 基于规则 | 利用语音学、音韵学、语法、语用学规则指导识别；缺点：难以表达规则、难以知道如何提升系统性能 |
| 模板匹配 | 把输入模板与参考模板比较，查找最相似的模板                                                 |

### 动态时间弯折/归正（DTW）

问题：两个矢量序列 $X=\{x_1,\ldots,x_I\}$、$Y=\{y_1,\ldots,y_J\}$ 长度不同（$I\ne J$）且对不准。

DTW 是**把时间归正和距离测度计算结合起来的非线性归正技术**，用动态规划（DP）把全局最优化问题转化为逐步的局部最优化问题。

| 要素     | 内容                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------- |
| 代价函数 | $g(i,j)$：从 $(1,1)$ 出发到达 $(i,j)$ 的最小代价路径的累计距离                                      |
| 递推     | $g(i,j)=\min\{g(i-1,j)+d(x_i,y_j)W(1),\ g(i-1,j-1)+d(x_i,y_j)W(2)\}$                                |
| 加权     | 一般取 $W(1)=W(3)=1,\ W(2)=2$（权重与局部路径有关）                                                 |
| 约束     | 起点/终点限制、连续性限制；常用**平行四边形区域**约束（两顶点在 $(1,1)$ 与 $(I,J)$，斜率 2 和 1/2） |

路径搜索三步：

| 步骤   | 内容                                                                                        |
| ------ | ------------------------------------------------------------------------------------------- |
| 初始化 | $i=j=1,\ g(1,1)=2d(x_i,y_j)$；约束区域外的 $g$ 取 huge                                      |
| 递推   | 对 $i=2,\ldots,I$、$j=2,\ldots,J$ 且 $(i,j)\in\text{Reg}$ 递推，并把回溯信息记录在 $p(i,j)$ |
| 回溯   | 由 $(I,J)$ 沿 $p(i,j)$ 回溯到 $(1,1)$；求平均模板或聚类中心时必要，识别过程往往不必         |

DTW 的缺点（引出统计模型）：

| 缺点                                               |
| -------------------------------------------------- |
| 很难区分非常类似的模板（**硬匹配**）               |
| 输入与模板声学条件不同时性能急剧下降（缺少多样性） |
| 没有充分利用语音信号的时序动态信息                 |
| 不利于大词汇表连续语音识别（LVCSR）                |

### 基于统计模型的语音识别框架与噪音通道模型

| 概念     | 内容                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 系统框架 | **前端处理**（Front-end processing，特征提取）+ **后端处理**（Back-end processing）    |
| 噪音通道 | 源句子经噪音通道生成"噪音句子"，解码得到猜测的句子：搜索所有可能句子、找最优解         |
| 本质     | 求 $\underset{W}{\arg\max}\ P(W\mid X)$：给出声学特征 $X$，查找最匹配的单词序列 $W$    |
| 贝叶斯   | $\underset{W}{\arg\max}\ \dfrac{P(X\mid W)P(W)}{P(X)}$；$P(X)$ 与 $W$ 无关，可去掉分母 |

其中 $P(X\mid W)$ 是**声学模型**，$P(W)$ 是**语言模型**。

声学模型的演化：

| 时期       | 系统                | 组成                                        |
| ---------- | ------------------- | ------------------------------------------- |
| 1990s–2009 | GMM-HMM 混合系统    | 语音 → GMM + HMM + 词典 + 语言模型 → 词序列 |
| 2009–      | DNN-HMM 混合系统    | 用 DNN/CNN/RNN 替换 GMM                     |
| 2014       | CTC 端到端          | LSTM/BLSTM RNN + CTC（+ 语言模型）          |
| 2016       | 编码器-解码器端到端 | Encoder-Decoder（LSTM/BLSTM、Transformer）  |

## 3.1.3 语音识别的典型应用（了解）

| 应用     | 内容                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------- |
| 语音转写 | 语音转写系统、语音输入法                                                                                    |

# 3.2 声学模型

## 3.2.1 隐马尔可夫模型 HMM（掌握）

### 马尔可夫链

| 概念           | 内容                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------- |
| 马尔可夫过程   | 状态空间中从一个状态转移到另一个状态的随机过程，具有**无记忆（无后效性）**性质：下一状态只由当前状态决定 |
| 马尔可夫链     | 离散状态的马尔可夫过程：状态空间有限或可列、离散时间、具有马尔可夫性质                                   |
| 一阶马尔可夫链 | $P(q_t=s_j\mid q_{t-1}=s_i,q_{t-2}=s_k,\ldots)=P(q_t=s_j\mid q_{t-1}=s_i)$                               |
| 齐次马尔可夫链 | 转移概率 $a_{ij}(t)$ 与时间 $t$ 无关；满足 $a_{ij}\ge0$、$\sum_{j=1}^{N}a_{ij}=1$                        |

### HMM 的定义与参数

实际问题中**观察到的事件并不与状态一一对应**，而是通过一组概率分布相联系。HMM 用**双重随机过程**描述：一个是 Markov 链（描述状态转移，**不可见**），另一个随机过程描述**状态与观察值之间的统计对应关系**（可见）。HMM 由 Baum 等人于 20 世纪 70 年代提出。

| 参数                     | 含义                                                                        |
| ------------------------ | --------------------------------------------------------------------------- |
| $S=\{s_1,\ldots,s_N\}$   | 状态集合，$N$ 为可能的状态数目（不可直接观测）                              |
| $V=\{v_1,\ldots,v_K\}$   | 可观测值集合，$K$ 为每个状态对应的可能观察值数目                            |
| $\pi=[\pi_1\ldots\pi_N]$ | 初始状态概率矩阵，$\pi_i=P(q_1=i)$                                          |
| $A=[a_{ij}]$             | 状态转移矩阵，$a_{ij}$ 表示 $t-1$ 时刻状态为 $s_i$、$t$ 时刻为 $s_j$ 的概率 |
| $B=[b_j(k)]$             | 观测值概率矩阵，$b_j(o_t)=P(o_t=v_k\mid q_t=j)$                             |

参数组：$\lambda=(S,V,\pi,A,B)$，简写 $\lambda=(\pi,A,B)$。

课件例子（了解）：天气（状态：晴/云/雨；观察值：干燥/干枯/潮湿/湿透）、掷骰子（观察值概率 $P(\text{Blue}\mid S_1)=0.7$、$P(\text{White}\mid S_1)=0.3$、$P(\text{Blue}\mid S_2)=0.2$、$P(\text{White}\mid S_2)=0.8$，求 $P(\text{Blue}\cdot\text{White}\mid\lambda)$）。

### HMM 的三个基本问题

| 问题           | 内容                                                                 | 解法               |
| -------------- | -------------------------------------------------------------------- | ------------------ |
| 1 模型概率计算 | 已知 $\lambda$ 与观察值序列 $O$，计算 $P(O\mid\lambda)$              | 前向算法、后向算法 |
| 2 模型解码     | 已知 $\lambda$ 与 $O$，确定最佳状态序列 $Q^*=\{q_1^*,\ldots,q_T^*\}$ | Viterbi 算法       |
| 3 模型参数估计 | 给定观察值序列集合，调整 $\lambda$ 使 $P(O\mid\lambda)$ 最大         | Baum-Welch 算法    |

**直接计算法**（了解）：$P(O\mid\lambda)=\sum_{\forall Q}P(O,Q\mid\lambda)$，计算量 $2TN^T$；当 $N=5,T=100$ 时达 $10^{72}$ → 必须用前向/后向算法。

### 前向算法（掌握）

前向变量：$\alpha_t(i)=P(o_1o_2\cdots o_t,\ q_t=i\mid\lambda)$（到时刻 $t$ 为止观测序列为 $o_1\ldots o_t$ 且状态为 $s_i$ 的概率）。

| 性质 | 公式                                                                   |
| ---- | ---------------------------------------------------------------------- |
| 初值 | $\alpha_1(i)=\pi_ib_i(o_1)$                                            |
| 递推 | $\alpha_t(j)=\left[\sum_{i=1}^{N}\alpha_{t-1}(i)a_{ij}\right]b_j(o_t)$ |
| 终止 | $P(O\mid\lambda)=\sum_{i=1}^{N}\alpha_T(i)$                            |

计算量为 $N^2T$ 量级：$N=5,\ T=100$ 时只需约 **2500 次乘法**。

### 后向算法（重点掌握）

后向变量：$\beta_t(i)=P(o_{t+1}o_{t+2}\cdots o_T\mid q_t=i,\lambda)$（从 $t+1$ 到 $T$ 的部分观测序列、且状态为 $i$ 的概率）。

| 步骤 | 公式                                                                     |
| ---- | ------------------------------------------------------------------------ |
| 初值 | $\beta_T(i)=1$                                                           |
| 递推 | $\beta_t(i)=\left[\sum_{j=1}^{N}\beta_{t+1}(j)a_{ij}\right]b_j(o_{t+1})$ |
| 终止 | $P(O\mid\lambda)=\sum_{i=1}^{N}\pi_ib_i(o_1)\beta_1(i)$                  |

计算量同样是 $N^2T$ 量级。

### Viterbi 算法（解码问题）

目标：求 $Q^*=\underset{Q}{\arg\max}\ P(O,Q\mid\lambda)$；定义 $\delta_t(i)=\max\limits_{q_1,\ldots,q_{t-1}}P(q_1\cdots q_{t-1},q_t=i,o_1\cdots o_t\mid\lambda)$。

| 步骤     | 公式                                                                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 初始化   | $\delta_1(i)=\pi_ib_i(o_1)$，$\varphi_1(i)=0$                                                                                                    |
| 递推     | $\delta_t(j)=\max\limits_{1\le i\le N}[\delta_{t-1}(i)a_{ij}]\,b_j(o_t)$，$\varphi_t(j)=\underset{1\le i\le N}{\arg\max}[\delta_{t-1}(i)a_{ij}]$ |
| 终止     | $P^*=\max\limits_{1\le i\le N}\delta_T(i)$，$q_T^*=\underset{1\le i\le N}{\arg\max}\,\delta_T(i)$                                                |
| 路径回溯 | $q_t^*=\varphi_{t+1}(q_{t+1}^*),\quad t=T-1,T-2,\ldots,1$                                                                                        |

### Baum-Welch 算法（参数估计）

思路：先取初始模型 $\lambda$，求一组新参数 $\hat\lambda$ 保证 $P(O\mid\hat\lambda)>P(O\mid\lambda)$，递归改进直到收敛。

| 要点     | 内容                                                                                                                                                                                                                                                                       |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 本质     | **EM 算法的一个特例**，用于观测序列与隐状态序列都未知时的参数估计                                                                                                                                                                                                          |
| 辅助函数 | $L(\lambda,\hat\lambda)=\sum_{Q}P(Q\mid O,\hat\lambda)\log P(O,Q\mid\lambda)$                                                                                                                                                                                              |
| E 步     | 求给定参数下 $L$；用到 $\xi_t(i,j)=P(q_t=i,q_{t+1}=j\mid O,\lambda)=\dfrac{\alpha_t(i)a_{ij}b_j(o_{t+1})\beta_t(j)}{\sum_i\sum_j\alpha_t(i)a_{ij}b_j(o_{t+1})\beta_t(j)}$，$\gamma_t(i)=P(q_t=i\mid O,\lambda)=\dfrac{\alpha_t(i)\beta_t(i)}{\sum_j\alpha_t(j)\beta_t(j)}$ |
| M 步     | 更新 $\hat a_{ij}=\dfrac{\sum_{t=1}^{T-1}\xi_t(i,j)}{\sum_{t=1}^{T-1}\gamma_t(i)}$，$\hat b_j=\dfrac{\sum_{t=1}^{T}\gamma_t(j)\ [o_t=v_k]}{\sum_{t=1}^{T}\gamma_t(i)}$，$\hat\pi_i=\gamma_1(i)$                                                                            |
| 局限     | **未必能求得全局最大值**，可能收敛到局部极值点                                                                                                                                                                                                                             |

典型结构（基本概念）：语音识别常用**从左向右 HMM**（Left-to-right HMM）+ 离散随机变量概率分布（DiscreteDistribution）。

## 3.2.2 基于 GMM-HMM 的语音识别技术

连续特征的概率怎么算？特征向量是连续数值：

| 思路         | 做法                                                        |
| ------------ | ----------------------------------------------------------- |
| 矢量量化 VQ  | 把特征向量聚类到有限（离散）的类——离散分布 HMM              |
| 概率密度函数 | 经典模型：**混合高斯模型 GMM** 计算观测值概率——连续分布 HMM |

| 模型         | 内容                                                                                                                                                                |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 单高斯       | 一维：$x\sim N(\mu,\sigma^2)$                                                                                                                                       |
| 多元高斯     | $P(x\mid\theta)=\dfrac{1}{(2\pi)^{D/2}\lvert\Sigma\rvert^{1/2}}\exp\left\{-\dfrac{1}{2}(x-\mu)^{\mathrm T}\Sigma^{-1}(x-\mu)\right\}$，$D$ 维输入如某帧的 MFCC 特征 |
| GMM          | 由 $M$ 个单高斯组合：$P(x\mid\Theta)=\sum_{m=1}^{M}c_mN(x\mid\mu_m,\Sigma_m)$，$c_m$ 是混合权重且 $\sum c_m=1$                                                      |
| 语音中的 GMM | $b_i(o_t)=\sum_{m=1}^{M}c_{i,m}N(o_t\mid\mu_{i,m},\Sigma_{i,m})$，表示状态 $i$ 下观测 $o_t$ 的概率                                                                  |

### 从孤立词到连续语音

| 任务       | 要点                                                                                                      |
| ---------- | --------------------------------------------------------------------------------------------------------- |
| 孤立词识别 | 建模单元为孤立词或子词（音素等）                                                                          |
| 连接词识别 | 典型例子是数字串识别：0–9 共 10 个数字，采用**从左至右无跨越 HMM**，串接形成一个新的 HMM，用 Viterbi 解码 |
| 连续语音   | 大词表连续语音识别（LVCSR）是最有挑战性的课题                                                             |

LVCSR 特有的问题（基本概念）：词（模式）数量太多、语料不够；发音相近内容多、误识严重；句子中单词数不确定；单词边界难以确定；发音变化（受**协同发音**影响严重）。

LVCSR 统一框架分三层：

| 层次        | 作用                                                                                     |
| ----------- | ---------------------------------------------------------------------------------------- |
| 声学—语音层 | 系统底层，接受输入语音，以"**子词**（Subword）"单位输出，每个子词对应一套 HMM 结构和参数 |
| 词层        | 规定词汇表中每个词由什么音素—音子串接而成（需要一部**字典**）                            |
| 句法层      | 规定词按照什么规则组合成句子（**语言模型**：每个词条以一定概率出现，与前一个词条有关）   |

连续语音识别需要解决的 5 个主要问题：

| 问题                       | 对应模块 |
| -------------------------- | -------- |
| 声学建模单元（子词）的选择 | 声学模型 |
| 如何由子词构成词           | 字典     |
| 如何训练子词模型           | 声学模型 |
| 如何有效利用语言学知识     | 语言模型 |
| 如何识别得到最优单词序列   | 解码算法 |

### 建模单元的选择

| 原则         | 内容                                                                                                                 |
| ------------ | -------------------------------------------------------------------------------------------------------------------- |
| 为什么用子词 | 以词为基本单元建模不合理，会造成大量冗余存储与计算；一般采用音节、半音节、音素等**子词**识别基元                     |
| 权衡         | 单元越小，数量越少、训练工作量越小；但单元越小，**对上下文越敏感**、越易受相邻影响产生变异，类型设计与样本采集更困难 |

**协同发音**：语流中音段并非静止、分离的声音，音段会对相邻音段产生影响。解决方法是用**三音素**建模，表示为 `l-c+r`（$c$ 中心单元，$l$ 左相关，$r$ 右相关）。

$N$ 个音素需要 $N^3$ 个三音素，参数量巨大 → 用**决策树**进行三音素建模（依赖单音素建模后的对齐）。

词层字典（了解）：最简单实用的方案是每个词由若干子词单元串接而成；发音变化必须体现——**替换**（某音子被相似音子替换）、**插入和删除**（增加或删除非本词成分的子音子）。

如何训练子词模型（了解）：**分段 K 均值算法** —— ① 初始化：把训练语句线性分割成子词单元、再把子词单元线性分割成状态；② 聚类：对每个子词单元的每个状态，用 K 均值对所有训练语句段中的特征矢量聚类；③ 参数估计：由聚类结果计算均值、各维方差与混合权值系数；④ 分段：用新的子词模型通过 Viterbi 重新分割，迭代直到收敛。

从单音素到三音素 GMM（基本概念）：始于单音素、EM 训练 → 把高斯分布复制到三音素 → 创建决策树并对高斯分布聚类 → 复制并混合训练 GMM。

## 3.2.3 DNN-HMM（基本概念、了解）

| 阶段            | 内容                                                                                                           |
| --------------- | -------------------------------------------------------------------------------------------------------------- |
| 20 世纪 80 年代 | 开始尝试结合 ANN（用 ANN 替换 GMM、用 BP 训练），受算力与多层网络训练复杂性限制，效果不理想（过拟合）          |
| 2010 年         | 深度学习开始对语音识别产生重要影响，错误率显著下降；这也是深度学习在工业界的**第一个成功应用**，具有里程碑意义 |

| 概念 | 内容                                                                                                                                                      |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DNN  | 输入层与输出层之间有**多层（超过一层）隐含层**的人工神经网络；经典做法先用 DBN 预训练，再用 BP 微调                                                       |
| 前向 | $a^l=W^lh^{l-1}+b^l$（$1\le l\le L+1$），$h^l=f(a^l)$（$1\le l\le L$），激活函数如 $f(a)=\dfrac{1}{1+e^{-a}}$                                             |
| 损失 | 分类任务用**最小交叉熵**：$J_{CE}=-\sum_{i=1}^{C}y_i\log h_i^{L+1}$，其中 $h_i^{L+1}=P(i\mid o_t)=\dfrac{e^{a_i^{L+1}}}{\sum_j e^{a_j^{L+1}}}$（softmax） |

DNN-HMM 框架与建模能力：

| 要做的   | 内容                                                                                                    |
| -------- | ------------------------------------------------------------------------------------------------------- |
| 训练流程 | 用 DNN 替换 GMM、用 DNN 计算观察值概率；用 GMM-HMM 分割语音内容；在分割结果上训练 DNN；识别性能大幅改善 |

| DNN 的优势（建模能力）                                          |
| --------------------------------------------------------------- |
| 不需要对声学特征所服从的分布做假设                              |
| 输入可采用**连续的拼接帧**，更好利用上下文信息                  |
| 训练可用随机优化算法，训练数据规模大时也能高效训练              |
| 在发音模式分类上，**鉴别式**模型比 GMM 这种**生成式**模型更合适 |
| 无监督预训练                                                    |

| 项   | 内容                                                                                                                                                  |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 输入 | 更底层的**滤波器组（FBK）**声学特征（Mel 滤波器组在功率谱上滤波并取对数能量）；目前 **FBK 比 MFCC 有效**；DNN 会做**拼接帧**（如每 7 帧构成一个输入） |
| 输出 | 维度对应 HMM 状态个数，通常每维对应一个**绑定的 triphone 状态**                                                                                       |
| 标注 | 用事先训练好的 GMM-HMM 在训练语料上做**强制对齐**（Force alignment），基于 Viterbi 给每帧打一个 HMM 状态标签，再据此训练 DNN                          |

| DNN 训练的问题与解法                                                                                              |
| ----------------------------------------------------------------------------------------------------------------- |
| 用 BP 直接训练往往效果不佳（早期 ANN 混合模型失败主因）；多层网络参数优化是高维**非凸**问题，易收敛到较差的局部解 |
| **梯度消失**：误差从输出层向下指数衰减，靠近输出层的隐层训练得好、靠近输入层的几乎得不到有效训练                  |
| 解法：**预训练** —— 用受限波尔兹曼机（RBM）逐层训练构建深层置信网络（DBN）作为初始化，再用标准 BP **微调**        |
| 其他：海量数据避免过拟合；Dropout 提升泛化；ReLU 激活函数与 CNN 结构缓解梯度消失                                  |

# 3.3 语言模型

## 3.3.1 语言模型的基本概念

| 项   | 内容                                                                                                             |
| ---- | ---------------------------------------------------------------------------------------------------------------- |
| 定义 | 用来计算一个句子概率的模型；从词表任选若干同音词构成的序列不一定合乎句法，人类识别时利用了这种约束               |
| 作用 | 大词汇量系统中用统计语言模型实现**句子约束**，与声学模型结合判决，减小误识（例："棠园餐厅"易被误识为"堂源餐厅"） |
| 分类 | 基于文法的语言模型；基于统计的语言模型（**N-gram**）；基于深度学习的语言模型（**神经语言模型**）                 |

评价指标——困惑度（Perplexity）：

$$PP(W)=\sqrt[N]{\frac{1}{P(w_1w_2\cdots w_N)}},\qquad P(w_1^N)=\prod_{n=1}^{N}P(w_n\mid w_1^{n-1})$$

衡量模型拟合测试数据的程度：用模型分配给测试集的概率、取倒数并对句子长度归一化，即"预测下一个词时的加权平均**分支因子**"——**越低越好**。

## 3.3.2 N-gram 语言模型（掌握、了解）

| 步骤        | 公式                                                                                                                            |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 链式法则    | $P(w_1^n)=P(w_1)P(w_2\mid w_1)P(w_3\mid w_1^2)\cdots P(w_n\mid w_1^{n-1})=\prod_{k=1}^{n}P(w_k\mid w_1^{k-1})$                  |
| N-gram 近似 | $P(w_1^n)=\prod_{k=1}^{n}P(w_k\mid w_{k-N+1}^{k-1})$：假设词 $w_k$ 出现的概率**只与前 $N-1$ 个词有关**，即 $N-1$ 阶马尔可夫模型 |

| 模型    | 例子                                  |
| ------- | ------------------------------------- |
| Unigram | $P(\text{phone})$                     |
| Bigram  | $P(\text{phone}\mid\text{cell})$      |
| Trigram | $P(\text{phone}\mid\text{your cell})$ |

所需参数数量随先前上下文词数**指数增长**；一个 N-gram 模型只需 $N-1$ 个上下文词。

概率估计（相对频率）：

$$P(w_n\mid w_{n-1})=\frac{C(w_{n-1}w_n)}{C(w_{n-1})},\qquad P(w_n\mid w_{n-N+1}^{n-1})=\frac{C(w_{n-N+1}^{n-1}w_n)}{C(w_{n-N+1}^{n-1})}$$

为得到一致的概率模型，每个句子附加唯一的开始 `<s>` 与结束 `</s>` 符号，并视为附加单词。

课件复杂度实验（《华尔街日报》WSJ，3800 万词训练、词表 19979，150 万词评估）：

| 模型       | Unigram | Bigram | Trigram |
| ---------- | ------- | ------ | ------- |
| Perplexity | 962     | 170    | 109     |

（思考题：不使用语言模型即 0-gram 时，困惑度等于**词表大小 19979**。）

### 平滑技术（基本概念）

为什么需要：可能的词序列组合数巨大，许多罕见但并非不可能的组合在训练中从未出现，**最大似然估计 MLE 会错误地把许多参数赋值为 0**，测试时一旦出现新组合，整个序列概率为 0。做法是把参数**平滑（正则化）**，从已见事件"折现"出一部分概率分给未见过的事件，保持和为 1。

| 方法     | 内容                                                                                                                                                                                          |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 加法平滑 | 每个事件的出现次数加 $\delta$：$\dfrac{c(\cdot)+\delta}{\sum_{w_i}c(\cdot)+\delta\lvert V\rvert}$，$0<\delta\le1$，$\lvert V\rvert$ 是 Unigram 词表大小；$\delta=1$ 称"加 1 法"；**性能较差** |
| 线性插值 | 用低阶模型对高阶模型线性插值：$P_{interp}(w_i\mid w_{i-N+1}^{i-1})=\lambda P_{ML}(w_i\mid w_{i-N+1}^{i-1})+(1-\lambda)P_{interp}(w_i\mid w_{i-N+2}^{i-1})$                                    |

### N-gram 的问题：长距离依赖（了解）

很多情况下最有用的预测线索来自**远程依赖**而非本地上下文：

| 类型       | 例子（"树旁的那个人/鸟……"）                        |
| ---------- | -------------------------------------------------- |
| 语法依赖性 | The man … is tall / The men … are tall             |
| 语义依赖性 | The bird … flies rapidly / The man … talks rapidly |

需要更复杂的语言模型来处理这种依赖关系。

## 3.3.3 神经语言模型（了解）

| 特点   | 内容                                                                                                                                     |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 能力   | 可以对文本的**长距离依赖**建模                                                                                                           |
| 词表示 | 不同于基于类的 N-gram 模型，神经语言模型能识别两个相似的词，同时不丧失把每个词编码为彼此不同的能力；共享一个词（及其上下文）与其他类似词 |

| 时间 | 进展                                                      |
| ---- | --------------------------------------------------------- |
| 2003 | Bengio 等提出前向神经网络（FNN）语言模型                  |
| 2010 | Mikolov 等将循环神经网络（RNN）用于语言模型               |
| 2013 | Graves 等提出基于长短期记忆（LSTM）循环神经网络的语言模型 |
| 2014 | Bahdanau 等首次将注意力机制用于 NLP 任务                  |
| 2016 | Tran 等和 Mei 等证明注意力机制可以提升 RNNLM 性能         |

RNN 语言模型：RNN 是处理序列数据的神经网络，对应单词的前后顺序；**构建的历史长度不受限定**，具有更强的记忆能力。

# 3.4 语音识别解码算法（了解）

连续语音解码的目标（在词序列与时间边界上联合搜索）：

$$P(W\mid Y)=\underset{\{w_1^N\}\{t_1^N\}}{\arg\max}\left\{\sum_{n=1}^{N}\log P_{acoust}(y_{t_{n-1}+1}^{t_n}\mid w_n)+\lambda\cdot\sum_{n=1}^{N}\log\left(P_{lang}(w_n\mid w_{n-1})+\delta\right)\right\}$$

$P_{acoust}$ 为声学模型似然，$P_{lang}$ 为语言模型似然，$\lambda$ 为权重，$\delta$ 为插入惩罚。

| 要点     | 内容                                                                                  |
| -------- | ------------------------------------------------------------------------------------- |
| 本质     | 从各种可能的子词序列形成的网络中，找出最优的一个或多个子词序列——属于**搜索/解码**问题 |
| 困难     | 搜索过程中路径数急剧增加，**全搜索几乎不可能**，因此采用基于裁剪的算法                |
| 两类算法 | 基于 Viterbi 的解码；基于加权有限状态自动机（**WFST**）                               |

Viterbi beam 搜索：**广度优先的帧同步算法**，在每一时刻有效地剪裁低得分路径。

| 步骤   | 内容                                                                                                                                   |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 初始化 | 初始化活动路径（最高层）                                                                                                               |
| 递推   | 对帧 $t=1..T$：对每一层次（语言与声学模型）→ 对 HMM 每个活动状态 → 把每个活动路径后扩一帧到所有可达状态 → 执行 Viterbi 计算 → 裁剪路径 |
| 终止   | 选择最可能的路径                                                                                                                       |

由于 LVCSR 中 N-gram、词典与三音素建模的存在，不能简单使用 Viterbi，需要工程优化：**剪枝（Pruning）**、**多阶段解码（Multi-stage decoding）**、**语言模型超前使用（Language model Look-ahead）**。

WFST（加权有限状态转换机）：

| 概念 | 内容                                                                                                                                                  |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 结构 | 由状态节点与边组成，边上带输入、输出符号及权重，形式 $x:y/w$；权重可定义为概率或惩罚；所有权重沿路径累加作为路径分数；完整路径必须从起始到结束状态    |
| 组合 | 连续语音识别利用多个知识源：$\text{HCLG}=H\circ C\circ L\circ G$                                                                                      |
| G    | 语法或**语言模型**接收器的概率                                                                                                                        |
| L    | **词典**（音素或字或词）                                                                                                                              |
| C    | **上下文相关转换机**（把上下文相关音素转成上下文无关音素）                                                                                            |
| H    | **HMM 转换机**                                                                                                                                        |
| 求解 | $W'=\underset{W}{\arg\max}\ P(X\mid W)P(W)$，转换成在一个大的解码图 $H\circ C\circ L\circ G$ 上搜索：$W'=\underset{W}{\arg\max}\ X\circ(\text{HCLG})$ |

# 3.5 语音识别技术的展望

## 3.5.1 端到端语音识别（了解）

### CTC（Connectionist Temporal Classification）

为什么需要 CTC：传统声学模型训练中，**每一帧都需要知道对应标签（三音素）**，必须先训练一个 GMM-HMM 声学模型再自动对齐标注；对齐准确性严重依赖 GMM-HMM 的可靠性；两阶段都要反复迭代、非常耗时——**分阶段训练不合理**。

| 要点 | 内容                                                                   |
| ---- | ---------------------------------------------------------------------- |
| 关键 | 引入 `blank` 符号                                                      |
| 输出 | 对一段语音，CTC 最后输出只是 spike（尖峰）序列，如 `--a-bb` → `ab`     |
| 概率 | 每个 CTC 输出序列的概率实际上是多个填充 blank 后输出序列概率的**总和** |

### Attention / Encoder-Decoder

| 项                   | 内容                                                                                                                            |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 模型                 | 编码器把输入序列映射到指定长度的向量，解码器把该向量解码为真实标签；2014 年把 Attention 加入 Encoder-Decoder 并成功用于机器翻译 |
| 端到端优点           | 直接把声学特征映射到更大的单元序列（不是音素或初始序列）；字级输出对下游 NLP 任务很容易                                         |
| Encoder-Decoder 问题 | 长序列对编码器网络压力巨大；解码器要从固定长度编码向量中找当前时刻相关内容，压缩信息过多时会找不到                              |
| Attention 优点       | 实现端到端训练、能把整个系统训练到最优；与 CTC 相比**不需要每帧独立的假设**                                                     |
| Attention 缺点       | 噪声环境下很难训练到好的效果，通常比 CTC 差；常用解法是 **CTC 与 attention 联合训练**，用 CTC 损失对下层 Encoder 做强制对齐     |

## 3.5.2 主要挑战（掌握、了解）

| 挑战                   | 问题与现状                                                                                                                                                                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 复杂声学场景（掌握）   | 训练声学模型的场景与真实复杂场景差异过大，性能大幅降低；训练时的噪声、混响可穷举可模拟，现实中无法穷举导致训练/测试集不匹配；需获取有效人声，远场还面临**回声干扰、室内混响、多信号源干扰、非平稳噪声**；现状是研究新的声学信号处理技术或**声学处理与识别联合优化** |
| 低数据资源（了解）     | 全世界共使用 5651 种语言，多数语种语音资源匮乏（可能只有几十小时）；特定人群（非母语学习者、构音障碍患者、少数民族人群）数据难获取；现状是研究**迁移学习、模型自适应**                                                                                              |
| 多语言与跨语言（了解） | 多数系统只针对一种语言，每种语言单独训练成本太高；**多语言**只能识别训练集中出现过的语言，**跨语言**能识别从未见过的语言；挑战包括建模单元选择、词汇量大导致标签稀疏、发音字典依赖语言专家、部分语言难获取                                                          |
| 语种混杂（了解）       | 中文语境夹杂英文（Code-switch），如"这里有 Wi-Fi 吗"被识别成"这里有外海吗"；挑战：嵌入语受主体语影响的非母语口音、不同语言音素构成差异、带标注混合语音数据稀缺；现状是端到端算法逐步应用                                                                            |
| 多口音（了解）         | 说普通话时受方言母语发音强烈影响（发音不准/错误）；挑战：不同方言背景说话人发音差异大、多口音训练数据极其稀缺；现状是改进声学模型以适应口音变化                                                                                                                     |

声学模型与语言大模型的联合建模（了解）：以"海河·谛听"言语交互意图理解大模型为例——**Encoder** 要兼顾声学与语义信息提取、充分利用海量无标注数据；**Decoder** 要更好融合声学与文本特征、从声学特征中分解出语言/非语言/副语言信息、引入海量文本知识。
