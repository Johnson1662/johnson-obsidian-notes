# 6.1 声纹识别概述

## 6.1.1 声纹识别的基本概念

| 项   | 内容                                                                                                         |
| ---- | ------------------------------------------------------------------------------------------------------------ |
| 定义 | 声纹识别（说话人识别）是**生物识别**（指纹、掌纹、人脸、虹膜等）的一种，根据说话人的**声音特性**进行身份辨识 |
| 输入 | 语音                                                                                                         |
| 输出 | 说话人身份                                                                                                   |

与其他语音处理方法的区别：

| 任务     | 输出的是                     |
| -------- | ---------------------------- |
| 语音识别 | 语音携带的**文本信息**       |
| 情感识别 | 语音携带的**情感信息**       |
| 语种识别 | 语音所属的**语种**           |
| 语音合成 | 由文本输出语音               |
| 声纹识别 | 语音携带的**说话人身份信息** |

说话人身份信息相关的语音属性：

| 级别         | 与什么相关         | 具体属性                   |
| ------------ | ------------------ | -------------------------- |
| 低级（生理） | 发声器官的生理方面 | 声道频谱；**共振峰轨迹**   |
| 高级（行为） | 说话方式的差异     | 韵律；口音；话语中词的选择 |

### 分类

| 维度     | 类型                             | 特点                                                                                                                                              |
| -------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 输入模式 | **文本相关**（Text-dependent）   | 注册与测试话语共享（至少部分）相同内容；目的是分析给定语音语境下的说话人特征；**性能更高**                                                        |
| 输入模式 | **文本无关**（Text-independent） | 注册与测试话语可用任意文本（甚至不同语言）；不使用口语内容的先验信息；**便利性更高**                                                              |
| 输出模式 | **说话人辨认**（Identification） | 判定待识别说话人来自注册集中的哪个说话人；**1 : N** 对比；来自未知说话者的样本与一组标记样本比较，识别为最匹配的说话人                            |
| 输出模式 | **说话人确认**（Verification）   | 判定待识别语音是否来自注册集中的某个说话人；**成对或 1 : 1** 对比；未知说话人提出身份声明，与声称身份的注册样本比较，匹配足够好（通过阈值）则接受 |

> **辨认任务可以分解为 $N$ 对说话人的比较，因此验证任务更为基础。**

### 评价指标：等错误率

| 指标 | 定义                                                                           |
| ---- | ------------------------------------------------------------------------------ |
| FRR  | 误拒绝率：**被错误拒绝的有效身份声明**的比例                                   |
| FAR  | 误接受率：**错误接受冒名顶替者身份声明**的比例                                 |
| EER  | 等错误率：调整阈值使 $FRR=FAR$，此时的 FAR 与 FRR 值即 EER                     |
| DET  | 检测—错误—均衡曲线（Detection Error Tradeoff），画 FRR 与 FAR 随阈值变化的曲线 |

## 6.1.2 声纹识别方法的回顾（了解）

技术演化：

| 时期          | 方法                                                                  |
| ------------- | --------------------------------------------------------------------- |
| 1970s 及以前  | 长期特征平均（long-term feature averaging）                           |
| 1980s–1990s   | DTW、矢量量化 VQ、隐马尔可夫模型、早期神经网络——**都根植于 GMM**      |
| 约 1995–2005  | 1996 年起有 NIST SRE；GMM；关注**文本无关**模型；**通用背景模型 UBM** |
| 2005 至今     | GMM 超向量、联合因子分析 JFA、i-vector、**PLDA 打分**、深度神经网络   |
| 当前/新兴范式 | BNF、Tandem、**x-vector**、端到端                                     |

声纹识别系统基本框架（掌握）：

| 模块     | 作用                                                                                         |
| -------- | -------------------------------------------------------------------------------------------- |
| 特征提取 | 将原始语音信号转换为**以说话人信息为主**的特征向量序列                                       |
| 注册     | 建立说话人模型，用以与测试段对照，判断访问者是否与其声明身份相符                             |
| 测试     | 从待测语音提取特征向量，与每个注册说话者的存储模型比较，按**相似度（或似然度）**做出识别决策 |

## 6.1.3 声纹识别的典型应用（了解）

| 应用        | 内容                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------- |
| 访问控制    | 访问房间、建筑物和物理资产；身份和凭证认证                                                    |
| 说话人日志  | **谁在什么时候说话**（Diarization: who spoke when）、会议转录、会议分析（不同参与者的积极性） |
| 搜索 / 索引 | 索引多媒体档案；情报、反恐                                                                    |

# 6.2 传统声纹识别算法（GMM-UBM）

## 特征提取

| 项       | 内容                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| 目的     | 保留说话人信息；去除噪声和其他干扰信息                                        |
| 声学特征 | 梅尔频率倒谱系数 MFCC、线性预测倒谱系数 LPCC                                  |
| 完整前端 | 还包括**语音活动检测**（丢弃非语音帧）与**后处理**（如倒谱均值归一化 CMN 等） |

## 基于 GMM 的说话人建模

注册：说话人模型由该说话人的注册语音构建；每段注册语音是一个特征向量序列 $\{x_t\}_{t=1}^{T}$。

$$p(x\mid\theta)=\sum_{k=1}^{K}w_kN(x\mid\mu_k,\Sigma_k)$$

$K$ 表示高斯分量的数量；参数集合 $\theta=\{\mu_k,\Sigma_k,w_k\}_{k=1}^{K}$；权重 $w_k$ 对所有 $k$ 的和总为 1。

GMM 的 EM 训练（了解）：

| 步骤 | 内容                                                                                                                                                                                          |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| E 步 | 计算每个特征向量属于第 $k$ 个高斯分布的程度：$\lambda_k(x_t)=\dfrac{N(x_t\mid\mu_k,\Sigma_k)\cdot w_k}{\sum_{i=1}^{K}N(x_t\mid\mu_i,\Sigma_i)\cdot w_i}$，且 $\sum_{k=1}^{K}\lambda_k(x_t)=1$ |
| M 步 | 基于每帧的 $\lambda_k(x_t)$ 更新均值 $\mu_k$、协方差矩阵 $\Sigma_k$ 和权重 $w_k$                                                                                                              |

$\theta$ 的最大似然估计用 EM 算法获得，从随机初始化开始迭代更新参数。

## 识别（辨认或确认）

测试语音与说话人模型的匹配程度用**平均对数似然**：

$$s(Y\mid\theta)=\frac{1}{T}\sum_{t=1}^{T}\log p(y_t\mid\theta)$$

| 任务 | 决策方式                                                            |
| ---- | ------------------------------------------------------------------- |
| 辨认 | 选择**得分最高**的说话人模型                                        |
| 验证 | 基于**对数似然比**：$\Lambda(Y)=s(Y\mid\theta)-s(Y\mid\theta_{bg})$ |

## 最大后验（MAP）自适应与 UBM

| 问题           | 说明                                                                                                                                                      |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 为什么需要 UBM | 实际场景中每个说话人的语音数据很少，无法训练出高效的 GMM；复杂声学环境和信道下，训练与测试语音存在**失配**                                                |
| 解决办法       | 用 EM 算法训练**说话人无关**的领域模型/通用背景模型（UBM），再基于 UBM 通过自适应算法（如 **MAP**）得到目标说话人模型                                     |
| 为什么用 MAP   | UBM 作为初始模型，可减少注册新说话人所需语音的时长/数量；说话人相关 GMM 与 UBM 具有**相同的模型复杂度**，可计算出更好的对数似然分数；使用高斯选择可以更快 |

MAP 自适应步骤（了解）：

| 步骤     | 公式                                                                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 相似度   | $\lambda_k(x_t)=\dfrac{N(x_t\mid\mu_k,\Sigma_k)\cdot w_k}{\sum_{i=1}^{K}N(x_t\mid\mu_i,\Sigma_i)\cdot w_i}$                                                |
| 统计量   | 零阶 $N_k=\sum_{t=1}^{T}\lambda_k(x_t)$；一阶 $F_k=\sum_{t=1}^{T}\lambda_k(x_t)\cdot x_t$                                                                  |
| 均值更新 | $\mu_k'=\alpha_k\left(\dfrac{1}{N_k}F_k\right)+(1-\alpha_k)\mu_k$：新信息与 UBM 均值向量的加权折中                                                         |
| 适应系数 | $\alpha_k=\dfrac{N_k}{N_k+r}$，恒有 $0<\alpha_k<1$，控制新信息与旧参数的平衡；每个高斯分量不同，取决于与其对齐的帧总数 $N_k$ 和相关因子 $r$（通常取 0–20） |

几何含义：**均值适应**导致高斯分量偏移；**协方差适应**导致高斯分量的**大小（不确定性）**发生变化。

GMM-UBM 识别（掌握）：把说话人验证转换为似然比测试，$H_0$：测试段 $Y$ 来自假设说话人；$H_1$：测试段 $Y$ 不是来自假设说话人。

$$\Lambda(Y)=\log\frac{p(Y\mid H_0)}{p(Y\mid H_1)}\approx\log\frac{p(Y\mid\theta_{spk})}{p(Y\mid\theta_{UBM})}=s(Y\mid\theta_{spk})-s(Y\mid\theta_{UBM})$$

其中 $s(Y\mid\theta)=\dfrac{1}{T}\sum_{t=1}^{T}\log\sum_{k=1}^{K}w_kN(y_t\mid\mu_k,\Sigma_k)$。

## GMM 超向量、JFA 与 i-vector（了解）

**GMM 超向量**：GMM-UBM 范式下，对每个说话者基于相同的 UBM 估计说话者相关的 GMM；说话人相关的 GMM 由**均值向量唯一表示**——只调整均值向量，而**权重和协方差矩阵保持与 UBM 相同**，于是拼接所有均值得到 supervector。

**联合因子分析（JFA）**：

| 项   | 内容                                                                                            |
| ---- | ----------------------------------------------------------------------------------------------- |
| 目的 | 在 **GMM 超向量空间**中进行**信道补偿**                                                         |
| 实现 | GMM 超向量 $m_r$ 被建模为**说话人分量与信道分量的总和**（加上残差）                             |
| 注册 | 联合估计说话人因子 $y_r$、信道因子 $x_r$ 与残差 $z_r$；信道补偿通过**丢弃信道分量** $Ux_r$ 实现 |
| 测试 | 从测试段估计信道因子 $x_{test}$，再计算说话人验证分数                                           |

**i-vector（身份向量）**：

| 项   | 内容                                                                                            |
| ---- | ----------------------------------------------------------------------------------------------- |
| 目的 | JFA 估算出的**说话人子空间与信道子空间存在互相掩盖**的问题，故不严格区分说话人空间与信道空间    |
| 思路 | 简化版 JFA：信道和说话人子空间形成一个**总变化空间（Total Variability Space）**                 |
| 含义 | i-vector 包含人的语音特征（来自说话人子空间）和信道因子（来自信道子空间）                       |
| 计算 | ① 通过 EM 算法迭代计算全局差异空间矩阵 $T$；② 利用 $T$ 计算 $w_r$ 后验分布的**均值**即 i-vector |

## PLDA（概率线性判别分析，了解）

| 项   | 内容                                                                                                                                                                                                                                                        |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 定义 | 嵌入表示（i-vector、x-vector）中既含说话人信息也含信道信息；PLDA 根据**说话人身份和信道效应**解释观测到的嵌入表示，实现对说话人因子的"**提纯**"；可看作 **LDA 的概率形式**                                                                                  |
| 模型 | $\eta_{ij}=\mu+Vy_i+Ux_{ij}+\varepsilon_{ij}$                                                                                                                                                                                                               |
| 参数 | $\eta_{ij}$ 是第 $i$ 个说话人第 $j$ 段语音的嵌入表示；$\mu$ 为全局均值；$V$ 为说话人空间矩阵（**Eigen Voice**）；$U$ 为信道空间矩阵（**Eigen Channel**）；$y_i,x_{ij}$ 是对应子空间内的因子（服从高斯分布）；$\varepsilon$ 是残差项（协方差为对角阵的高斯） |
| 训练 | 模型参数共 4 个（均值 $\mu$、$V$、$U$、噪声协方差）；含隐变量，用 **EM 算法**迭代求解                                                                                                                                                                       |
| 测试 | 说话人确认中每组试验都需要目标说话人与测试说话人，分别提取 i-vector/x-vector，用 PLDA 模型计算两者的**似然度评分**                                                                                                                                          |

# 6.3 基于深度学习的声纹识别算法（基本概念）

现代声纹识别系统主要基于**说话人嵌入**，包括三部分：**特征提取 → 说话人嵌入 → 打分**。

## 基于 x-vector 的深度说话人嵌入（掌握）

x-vector 是一个包含**四个函数块**的深度神经网络，也是"深度特征提取 + 池化 + 嵌入 + 分类"的量产范式：

| 函数块                   | 内容                                                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 帧处理器（深度特征提取） | 用多层神经网络提取深度特征，例如**延时神经网络 TDNN**；输入通常是 MFCC 或对数 mel-filterbank 系数                        |
| 池化层                   | 把特征向量序列转换为**单个固定维向量**；最常用**时间池化**（取均值和标准差）                                             |
| 嵌入提取                 | 由若干相互连接的网络层组成，其中一层设计为**瓶颈层（Bottleneck layer）**，其输出（非线性层之前）就是 x-vector 说话人嵌入 |
| 说话人分类               | 根据说话人标签对训练音频进行分类                                                                                         |

### TDNN 中的时间上下文

TDNN 对时间上下文信息的提取取决于**感受野的宽度**（感受野：影响网络特定单元的输入空间区域）。要获得更广泛的时间上下文视野，可用**空洞卷积**（以一定步长跳过输入值），或**堆叠更多的空洞一维卷积层**。

### 池化层

时间池化通过平均实现（计算均值和标准差）：

$$\mu=\frac{1}{T}\sum_{t=1}^{T}h_t,\qquad \sigma=\sqrt{\frac{1}{T}\sum_{t=1}^{T}h_t\odot h_t-\mu\odot\mu},\qquad h_t=g(W^{\mathrm T}f_t+b)$$

$h_t$ 是第 $t$ 时刻变换后的特征向量；$f_t$ 是前馈层输入，后跟非线性激活函数 $g(\cdot)$；$W$ 为权重矩阵，$b$ 为偏差向量。

| 池化方式             | 说明                                                                                               |
| -------------------- | -------------------------------------------------------------------------------------------------- |
| 注意力机制池化       | 通过加权平均让模型更多关注对说话人识别任务更重要的帧                                               |
| 自注意力池化（了解） | 找到一组权重、每帧对应一个权重并加权求和，类似 Transformer 中基于 {query, key, value} 的自注意力池 |

### 嵌入提取与说话人分类

| 项         | 内容                                                                                                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 嵌入表征   | 固定长度向量，捕捉说话人的**长期声纹特征**；聚合特征经若干全连接层处理，把**第一个线性层的输出**作为嵌入表征：$\phi=W^{\mathrm T}[\mu,\sigma]$                                              |
| 多类分类   | 输出层每个节点代表一个类（$y\in\{1,\dots,C\}$，$C$ 为训练集说话人数），用 **softmax** 激活：$l_j(x_i;W,b)=\dfrac{\exp(W_j^{\mathrm T}x_i+b_j)}{\sum_{c=1}^{C}\exp(W_c^{\mathrm T}x_i+b_c)}$ |
| 交叉熵损失 | $L=-\dfrac{1}{N}\sum_{i=1}^{N}\sum_{j=1}^{C}1\{y_i=j\}\log l_j(x_i;W,b)=-\dfrac{1}{N}\sum_{i=1}^{N}\log l_{y_i}(x_i;W,b)$                                                                   |

其中 $x_i$ 是第 $i$ 个训练样本的深度特征，$W_j$ 是输出前馈层权重矩阵的第 $j$ 列，$y_i$ 是类标签，$C$ 是类数，$N$ 是批量大小，$1\{y_i=j\}$ 是指示函数。

改进的 softmax（了解）：传统 softmax 输出层学习的嵌入**只针对类间分离**优化，未考虑**类内紧凑性**。可修改 softmax 促进类内紧凑，例如 **angular softmax**、**additive-margin softmax**：令偏置 $b_j=0$、权重归一化 $\lVert w_j\rVert=1$、特征归一化 $\lVert x_i\rVert=s$，交叉熵损失变为

$$L=-\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp\left(s\cdot\cos\theta_{y_i}\right)}{\sum_{c=1}^{C}\exp\left(s\cdot\cos\theta_{y_c}\right)}$$

数据增广（了解）：① 添加噪声和混响（使用增广数据集如 **MUSAN** 与房间脉冲响应；MUSAN 含 12 种语言的噪声、音乐、语音）；② 语音编码；③ 说话人增强——**音频速度扰动**，用速度因子 $\alpha$ 做时间扭曲 $x(\alpha^t)$。

# 6.4 声纹识别技术的展望（了解）

## 端到端声纹识别

把语音输入模型，**直接得到声纹识别结果**。

**Generalized End-to-End（GE2E）**：分别提取不同说话人的多条语音的嵌入向量；计算不同嵌入向量间的相似度并做线性变换，构造**相似度矩阵**；在相似度矩阵中，**同说话人**语音嵌入间的相似度要尽可能**大**，**不同说话人**语音嵌入间的相似度要尽可能**小**，据此设计损失函数优化模型参数。

## 四类挑战

| 挑战               | 内容                                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| **跨信道**         | 会严重降低声纹识别性能；信道变量类型包括**采录设备、传输信道、采录位置**（不同设备录同一段原始语音，语谱图差异明显） |
| **复杂声学场景**   | 加性噪声（音乐、杂音、白噪声）与混响；例如信噪比 6 dB 的仿真加性噪声就会显著改变语谱图                               |
| **时变及说话风格** | 相同说话人、相同内容，由于说话风格、健康状况、发声器官等变化可能产生高度不同的声学特征                               |
| **声纹欺诈攻击**   | 语音合成、语音转换、**录音重放**（replay device → device under attack）                                              |

## 前沿研究方向（了解）

2023 年声纹识别研究与应用学术研讨会的主要议题方向：说话人语音特征的编解码与识别、视觉讲话人检测与唇语识别、时变与非言语语音声纹识别、稳定学习与可解释声纹识别、**基于一致性的伪造语音检测**、目标语音提取（归结于说话人还是内容）、多设备多场景远场**说话人日志**、噪声与对抗环境下的鲁棒声纹识别、**对抗攻击与说话人匿名化**、基于图结构建模的说话人日志、物理攻击模拟、面向跨域数据的生成语音检测。
