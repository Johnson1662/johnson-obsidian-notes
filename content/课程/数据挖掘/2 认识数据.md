# 2 认识数据

总纲一句话：**数据是什么 → 怎么描述它 → 怎么比较两个它。**

## 总览（思维导图）

$$
\text{2 认识数据}
\begin{cases}
\text{是什么}
\begin{cases}
\text{数据对象}=\text{行},\ \text{属性}=\text{列},\ \text{数据集}=n\times p\\[2pt]
\text{属性类型}
\begin{cases}
\text{标称}\ (=,\ \neq)\\
\text{二元}
\begin{cases}
\text{对称}\Rightarrow \frac{r+s}{q+r+s+t}\\
\text{非对称}\Rightarrow \text{Jaccard}=\frac{q}{q+r+s}
\end{cases}\\
\text{序数}:<,>\quad z=\frac{r-1}{M-1}\\
\text{数值}
\begin{cases}
\text{区间}:+,-\\
\text{比率}:\times,\div
\end{cases}
\end{cases}
\end{cases}\\[4pt]
\text{怎么描述}
\begin{cases}
\text{中心}:\bar x,\ \text{中位数},\ \text{众数},\ \text{截尾均值}\\
\text{离散}:\text{Range},\ \text{IQR},\ \sigma^2\\
\text{形状}:\text{偏斜}\Rightarrow \text{均值被尾巴拉走}
\end{cases}\\[4pt]
\text{怎么比较}
\begin{cases}
\text{标称}:\frac{p-m}{p}\qquad \text{序数}:z\to L_2\\
\text{二元}:\text{Jaccard}\qquad \text{数值}:L_1,\ L_2,\ L_h\\
\text{方向}:\cos=\frac{v_1\cdot v_2}{\lVert v_1\rVert\lVert v_2\rVert}
\end{cases}
\end{cases}
$$

## 考点权重

| 模块             | 要会什么                          | 考试风险 |
| ---------------- | --------------------------------- | -------: |
| 数据是什么       | 数据对象、属性类型判断            | **很高** |
| 怎么描述数据     | 均值、中位数、四分位数、IQR、方差 | **很高** |
| 怎么比较两个数据 | 各种距离、相似度                  | **最高** |
| 可视化           | 盒图、直方图、散点图              |     中高 |

# 一、数据对象与属性

| 术语     | 别称               | 表里对应 | 例子                   |
| -------- | ------------------ | -------- | ---------------------- |
| 数据对象 | 样本 / 记录 / 点   | 一行     | 一个学生、商品、交易   |
| 属性     | 维度 / 特征 / 变量 | 一列     | 学号、性别、年龄、成绩 |

$$
\text{数据集}=n\ \text{个对象}\times p\ \text{个属性}
$$

后面所有内容都建立在这两个维度上。

# 二、属性类型（第二章最核心的判断题）

## 总表

| 类型 | 状态数 | 允许运算           | 例子                           | 关键陷阱                       |
| ---- | ------ | ------------------ | ------------------------------ | ------------------------------ |
| 标称 | 任意   | $=,\neq$           | 眼睛颜色、邮编、学号           | **用数字表示 ≠ 数值属性**      |
| 二元 | 2      | $=,\neq$           | 男/女、有/无、阳/阴            | 对称与非对称决定用哪个距离公式 |
| 序数 | 有序多 | 再加 $<,>$         | 差<中<良<优、满意度 1~5        | 相邻等级**间距未知**，不能相减 |
| 区间 | 连续   | 再加 $+,-$         | 摄氏温度                       | 无绝对零点                     |
| 比率 | 连续   | 再加 $\times,\div$ | 年龄、长度、质量、金额、K 温度 | 有真零点，比例才有意义         |

能力逐级递增（课件第 22 页）：

$$
\text{Distinctness}\ \to\ \text{Order}\ \to\ \text{Addition}\ \to\ \text{Multiplication}
$$

## 逐类要点

| 类型 | 要点                                                                                                                        |
| ---- | --------------------------------------------------------------------------------------------------------------------------- |
| 标称 | 只表示不同类别，不能比大小；学号 $20240001,20240002$ 相减得 $1$ 无意义 ⇒ 仍是标称                                           |
| 序数 | $\text{优}>\text{良}>\text{中}>\text{差}$，但相邻等级差未知，不能相减                                                       |
| 区间 | $10^\circ C-5^\circ C=5^\circ C$ 有意义；$0^\circ C$ 不代表“没有温度”，故无绝对零点，$10^\circ C$ 不是 $5^\circ C$ 的两倍热 |
| 比率 | $10\,\text{kg}=2\times 5\,\text{kg}$ 有意义（真零点）                                                                       |

## 二元属性：对称 vs 非对称

| 类型       | 状态关系           | 例子     | 都为 0 是否有信息 | 后果                  |
| ---------- | ------------------ | -------- | ----------------- | --------------------- |
| 对称二元   | 两个状态地位相同   | 性别     | 有                | 用普通二元距离        |
| 非对称二元 | 一个状态明显更重要 | 疾病检测 | **没有**          | 必须用 Jaccard 类公式 |

非对称例子：$1=$ 患病、$0=$ 未患病；“两个都没病”不能说明两人相似，所以计算时丢掉 $t$。

# 三、离散 vs 连续

| 类型 | 判定                        | 例子                    |
| ---- | --------------------------- | ----------------------- |
| 离散 | 有限 / 可数，能一个一个数出 | 人数、孩子数量          |
| 连续 | 区间内任意实数，不可数      | 身高 $175.238\ldots$ cm |

细节：课件把标称、二元、序数主要归为“离散”，数值属性归为“连续”；但**数值属性不一定连续**（孩子数量是比率属性却离散）。考试碰到具体例子，一律按“可数 → 离散，不可数 → 连续”判断。

# 四、描述统计：中心在哪里

| 统计量   | 公式 / 定义                            | 抗异常值 | 说明                               |
| -------- | -------------------------------------- | -------- | ---------------------------------- |
| 均值     | $\bar{x}=\frac{1}{N}\sum_{i=1}^{N}x_i$ | 差       | 所有数据参与，易被极端值拉走       |
| 加权均值 | $\bar{x}=\frac{\sum w_ix_i}{\sum w_i}$ | —        | 各数据权重不同                     |
| 截尾均值 | 去掉两端极端值后再求均值               | 好       | 专门为降低极端值影响               |
| 中位数   | 排序后取中间；偶数个取中间两个平均     | **好**   | 对异常值稳健                       |
| 中列数   | $\text{Midrange}=\frac{\max+\min}{2}$  | 极差     | 只用最大值和最小值                 |
| 众数     | 出现次数最多的值                       | —        | 可有多个或没有；**标称数据也能算** |

中位数例：$23,29,20,32,23,21,33,25$ 排序后为 $20,21,23,23,25,29,32,33$，故 $\text{Median}=\frac{23+25}{2}=24$。

# 五、不同属性能算什么

| 属性 | 合理统计量                 |
| ---- | -------------------------- |
| 标称 | 众数                       |
| 序数 | 众数、中位数               |
| 区间 | 众数、中位数、均值、标准差 |
| 比率 | 以上全部                   |

“颜色 = 红/蓝/绿”只能看哪个最多，**不能求平均颜色**。

# 六、分布偏斜

| 分布      | 关系                                    | 直觉             |
| --------- | --------------------------------------- | ---------------- |
| 对称单峰  | $\text{均值}=\text{中位数}=\text{众数}$ | —                |
| 正偏/右偏 | $\text{众数}<\text{中位数}<\text{均值}$ | 右侧长尾拉高均值 |
| 负偏/左偏 | $\text{均值}<\text{中位数}<\text{众数}$ | 左侧长尾拉低均值 |

一句话：**均值最容易被尾巴拉过去。**

# 七、数据有多“散”

## 极差与四分位数

| 量    | 定义              |
| ----- | ----------------- |
| 极差  | $Range=\max-\min$ |
| $Q_1$ | $25\%$ 分位数     |
| $Q_2$ | $50\%=$ 中位数    |
| $Q_3$ | $75\%$ 分位数     |

## 本课程的四分位数算法（务必按课件）

$$
(n+1)f=j+q
$$

| 情形     | 取法                                  |
| -------- | ------------------------------------- |
| $q=0$    | $Q=x_j$                               |
| $q\neq0$ | $Q=\frac{x_j+x_{j+1}}{2}$（直接平均） |

例：数据 $2,3,4,5,6,7$，$n=6$。

| 分位  | 计算                    | 结果  |
| ----- | ----------------------- | ----- |
| $Q_1$ | $(6+1)\times 0.25=1.75$ | $2.5$ |
| $Q_2$ | $(6+1)\times 0.5=3.5$   | $4.5$ |
| $Q_3$ | $(6+1)\times 0.75=5.25$ | $6.5$ |

现实中软件与教材有多种四分位数定义，**考试以课件算法为准**。

## IQR、离群点、五数概括

| 量       | 公式 / 判定                                                       |
| -------- | ----------------------------------------------------------------- |
| $IQR$    | $IQR=Q_3-Q_1$                                                     |
| 下界     | $Q_1-1.5\,IQR$，$x$ 小于它即可疑离群点                            |
| 上界     | $Q_3+1.5\,IQR$，$x$ 大于它即可疑离群点                            |
| 五数概括 | $\text{min},\ Q_1,\ \text{median},\ Q_3,\ \text{max}$（盒图基础） |

## 方差与标准差

$$
\sigma^2=\frac{1}{N}\sum_{i=1}^{N}(x_i-\mu)^2,\qquad \sigma=\sqrt{\sigma^2}
$$

课件用总体形式。值越大 → 越分散；越小 → 越集中、越稳定。

# 九、相似度与距离（最可能出计算大题）

## 基本区分

| 概念              | 越相似时           | 取值范围 / 约定   |
| ----------------- | ------------------ | ----------------- |
| 相似性 $sim$      | $sim(i,j)\uparrow$ | 课件一般 $0\sim1$ |
| 相异性 / 距离 $d$ | $d(i,j)\downarrow$ | 完全相同 $d=0$    |

## 数据矩阵与相异性矩阵

| 矩阵       | 维度        | 含义                                                                |
| ---------- | ----------- | ------------------------------------------------------------------- |
| 数据矩阵   | $n\times p$ | 行是对象，列是属性                                                  |
| 相异性矩阵 | $n\times n$ | $d_{ij}$ 为对象 $i,j$ 的距离；$d_{ii}=0$、$d_{ij}=d_{ji}$，**对称** |

## 按属性类型的计算公式

| 属性类型   | 距离 / 相似度                                                                           | 例子                                                                                                    |
| ---------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 标称       | $d=\frac{p-m}{p}$，$sim=\frac{m}{p}$（$p$ 属性总数，$m$ 相同属性数）                    | $(red,China,smoker)$ 与 $(black,China,non\text{-}smoker)$：$m=1,p=3\Rightarrow sim=\frac13,\ d=\frac23$ |
| 对称二元   | $d=\frac{r+s}{q+r+s+t}$（不同个数 / 总个数）                                            | 性别                                                                                                    |
| 非对称二元 | $d=\frac{r+s}{q+r+s}$，$sim_{Jaccard}=\frac{q}{q+r+s}$（**忽略 $t$，只关心 1**）        | 疾病检测                                                                                                |
| 序数       | 先排名 $r_{if}$，再标准化 $z_{if}=\frac{r_{if}-1}{M_f-1}\in[0,1]$，最后当数值属性算距离 | $Fair<Good<Excellent$                                                                                   |
| 数值       | 见下表三大距离                                                                          | —                                                                                                       |

二元属性计数表（$q$ 都为 1，$t$ 都为 0，$r,s$ 不同）：

|         | 对象2=1 | 对象2=0 |
| ------- | ------: | ------: |
| 对象1=1 |     $q$ |     $r$ |
| 对象1=0 |     $s$ |     $t$ |

## 数值属性三大距离

| 名称           | 公式                                                                     | 别名 / 参数    | 直觉                                                               |
| -------------- | ------------------------------------------------------------------------ | -------------- | ------------------------------------------------------------------ |
| 曼哈顿距离     | $d(i,j)=\sum_{k=1}^{p}\lvert x_{ik}-x_{jk}\rvert$                        | $L_1$，$h=1$   | 城市街区横走 + 竖走                                                |
| 欧氏距离       | $d(i,j)=\sqrt{\sum_{k=1}^{p}(x_{ik}-x_{jk})^2}$                          | $L_2$，$h=2$   | 两点直线距离                                                       |
| 闵可夫斯基距离 | $d(i,j)=\left(\sum_{k=1}^{p}\lvert x_{ik}-x_{jk}\rvert^{h}\right)^{1/h}$ | 统一 $L_1,L_2$ | $h\to\infty$ 时为 $\max_k\lvert x_{ik}-x_{jk}\rvert$（上确界距离） |

## 什么才算“真正的距离”

$$
\left.
\begin{array}{ll}
\text{非负性} & d(i,j)\geq 0\\
\text{同一性} & d(i,i)=0\\
\text{对称性} & d(i,j)=d(j,i)\\
\text{三角不等式} & d(i,j)\leq d(i,k)+d(k,j)
\end{array}
\right\}
\quad\text{四条常考选择/判断}
$$

## 余弦相似度

$$
sim(v_1,v_2)=\frac{v_1\cdot v_2}{\lVert v_1\rVert\lVert v_2\rVert}
$$

比较的是**方向**而非绝对长度，所以特别适合文本：两篇文章词频比例相近、长度差一倍，向量方向仍接近，余弦相似度依然很高。这也是嵌入检索大量使用它的原因。

## 距离 / 相似度选择（思维导图）

$$
\text{给两个对象选度量}
\begin{cases}
\text{属性是类别}\Rightarrow \text{简单匹配}\ \frac{p-m}{p}\\
\text{属性是 0/1}
\begin{cases}
\text{对称}\Rightarrow \frac{r+s}{q+r+s+t}\\
\text{非对称}\Rightarrow \text{Jaccard}\ \frac{q}{q+r+s}
\end{cases}\\
\text{属性是等级}\Rightarrow \text{排名}\to z\in[0,1]\to \text{按数值算}\\
\text{属性是数值}
\begin{cases}
\text{绝对差}\Rightarrow L_1,\ L_2,\ L_h\\
\text{只看方向}\Rightarrow \cos
\end{cases}
\end{cases}
$$
