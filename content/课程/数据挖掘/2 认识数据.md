# 2.1 数据对象与属性类型

## 2.1.1 数据对象

| 要点           | 内容                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------- |
| 定义           | 数据集由**数据对象**组成，一个数据对象代表一个实体                                              |
| 举例           | 销售：顾客、商品、销售记录；医疗：患者、药品；大学：学生、老师、课程                            |
| 别称           | 记录、数据点、实体、样本、实例、对象；存放在数据库中即为**数据元组**                            |
| 与被描述       | 数据对象用**属性**来描述                                                                        |
| 行列对应       | **行 → 数据对象，列 → 属性**                                                                    |
| 数据的其他形态 | 文本、图像；网络（Web、社交网络、分子结构）；时序数据（视频序列、时间序列、事务序列、DNA 序列） |

$$
\text{数据集}=n\ \text{个对象}\times p\ \text{个属性}
$$

## 2.1.2 数据属性

| 术语              | 说明                                                                                                        |
| ----------------- | ----------------------------------------------------------------------------------------------------------- |
| 属性（attribute） | 一个**域**，表示一个数据对象的一个特征，如顾客 ID、姓名、地址                                               |
| 同义词            | 属性、维度、特征、变量语义可交换：数据仓库用“维度”，机器学习用“特征”，统计用“变量”，数据挖掘/数据库用“属性” |
| 观察 / 属性向量   | 给定属性的可观察值称**观察**；刻画一个对象的属性集合称**属性向量**（特征向量）                              |

四类属性：**标称、二元、序数、数值**；数值再分**区间标度**与**比率标度**。

| 类型 | 定义                           | 状态数 | 允许运算           | 例子                                                        | 关键陷阱                            |
| ---- | ------------------------------ | ------ | ------------------ | ----------------------------------------------------------- | ----------------------------------- |
| 标称 | 事物的标号或名称（枚举型）     | 任意   | $=,\neq$           | 头发颜色、职业、婚姻状况、邮政编码、学号                    | **用数字表示 ≠ 数值属性**           |
| 二元 | 只有两个状态 $0/1$（布尔属性） | 2      | $=,\neq$           | 吸烟与否、化验结果、性别                                    | 是标称属性的**特例**；分对称/非对称 |
| 序数 | 值之间有有意义的序或秩评定     | 有序多 | 再加 $<,>$         | $\text{size}=\{small,medium,large\}$、满意度 $0\sim4$、等级 | 相继值之间的**差未知**              |
| 区间 | 定量、用相等单位尺度度量       | 连续   | 再加 $+,-$         | 摄氏温度、华氏温度、日历日期                                | **无真正零值**                      |
| 比率 | 具有固定零点                   | 连续   | 再加 $\times,\div$ | 开氏温标、字数、货币、工作年限、年龄、质量                  | 有真零点，比例才有意义              |

数据属性最基本的定义：**数据**是对客观事件进行记录并可以鉴别的符号；类型分连续型（数值）与离散型（标称、二元、序数）；主要问题是**不一致、错误、缺失**。

## 逐类要点

| 类型 | 要点                                                                                                       |
| ---- | ---------------------------------------------------------------------------------------------------------- |
| 标称 | 每个值表示类别、编码或状态，**无次序**；给颜色编号 $black{=}1,\ldots,white{=}6$ 后做算术无意义             |
| 二元 | $0$ 表示属性不出现、$1$ 表示出现；**约定把更重要的结果标为 1**（如 HIV positive）                          |
| 序数 | 可以用来记录不能客观度量的主观质量评估，调查中常用于排序                                                   |
| 区间 | $10^\circ C$ 比 $5^\circ C$ 高 $5^\circ C$，但**不能说 10℃ 比 5℃ 温暖 2 倍**（$0^\circ C$ 不代表没有温度） |
| 比率 | $10K$ 是 $5K$ 的两倍、100 元比 1 元富有 100 倍，都成立                                                     |

定性属性总结：标称、二元、序数都是**定性的**，描述对象特征而不给出实际大小或数量，通常是代表类别的词；**若使用整数，那只是类别的编码，而不是测量的量**。

## 二元属性的对称与非对称

| 类型       | 定义                       | 例子                          | 都为 0 是否有信息 | 后果                  |
| ---------- | -------------------------- | ----------------------------- | ----------------- | --------------------- |
| 对称二元   | 两种状态具有同等价值与权重 | 性别                          | 有                | 用普通二元相异性      |
| 非对称二元 | 两状态结果不同等重要       | 疾病化验（positive/negative） | **没有**          | 必须用 Jaccard 类公式 |

## 离散 vs 连续属性

| 类型     | 定义                                               | 例子                                                 | 对应属性类                 |
| -------- | -------------------------------------------------- | ---------------------------------------------------- | -------------------------- |
| 离散属性 | 具有有限或无限**可数**个值（可用或不用整数表示）   | 发色、是否吸烟、医学检查结果、饮料尺寸、邮编、电话号 | 定性的：标称、二元、序数   |
| 连续属性 | 连续值是实数，用有限位数字表示，一般用浮点变量表示 | 温度、高度、宽度                                     | 定量的：数值（区间、比率） |

细节：数值属性与连续属性在含义上通常一样，但**数值属性不一定连续**（孩子数量是比率属性却离散）。考试遇到具体例子就按“可数 → 离散，不可数连续区间 → 连续”判断。

## 属性的四大特性（决定类型）

$$
\text{Distinctness}\ (=\ \neq)\ \to\ \text{Order}\ (<>)\ \to\ \text{Addition}\ (+-)\ \to\ \text{Multiplication}\ (*/)
$$

| 属性     | 拥有的特性           |
| -------- | -------------------- |
| 标称     | distinctness         |
| 序数     | distinctness & order |
| 区间标度 | 再加 addition        |
| 比率标度 | 四条全有             |

## 各属性可用的统计量（课件对照表）

| 属性类型 | 允许运算      | 可算的统计量                         | 例子                             |
| -------- | ------------- | ------------------------------------ | -------------------------------- |
| 标称     | $=,\neq$      | 众数                                 | 邮编、员工 ID、眼睛颜色          |
| 序数     | $<,>$         | 众数、中位数                         | 矿物硬度、good/better/best、等级 |
| 区间     | $+,-$         | 众数、中位数、均值、标准差           | 摄氏/华氏温度、日历日期          |
| 比率     | $\times,\div$ | 众数、中位数、均值、标准差、**比率** | 开氏温度、货币、计数、年龄、质量 |

# 2.2 数据的基本统计描述

统计描述的目标是**更好地理解数据**：2.2.1 中心趋势（度量数据分布的中部或中心位置）+ 2.2.2 数据散布（数据如何分散）。

## 2.2.1 中心趋势度量

| 统计量   | 公式 / 定义                                                                  | 特点                                                         |
| -------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 均值     | $\bar{x}=\frac{1}{N}\sum_{i=1}^{N}x_i$（代数度量）                           | 全部数据参与，**会因每一个数据的变化而变化**，易受极端值影响 |
| 加权均值 | $\bar{x}=\frac{\sum w_ix_i}{\sum w_i}$，权重 $w$ 代表重要性、发生频率等      | 各数据权重不同                                               |
| 截尾均值 | 丢弃高低极端值后的均值                                                       | 专门为降低极端值影响                                         |
| 中位数   | 排序后居于中间位置的数，把集合划分为相等的上下两部分；偶数个取中间两个的平均 | 部分数据变动对它无影响，**不受最大最小极端值影响**           |
| 中列数   | $\text{Midrange}=\frac{\max+\min}{2}$                                        | 只使用最大值和最小值，可评估数值型数据的中心趋势             |
| 众数     | 集合中出现最频繁的值                                                         | 可有单峰/双峰/三峰；若每个值只出现一次则**没有众数**         |

中位数例：$23,29,20,32,23,21,33,25$ 排序后为 $20,21,23,23,25,29,32,33$，故 $\text{Median}=\frac{23+25}{2}=24$。

观测数量很大时中位数计算开销大，对数值属性可用**插值**求近似：

$$
\text{Median}=L_1+\frac{N/2-(\sum freq)_l}{freq_{\text{median}}}\times width
$$

$L_1$ 是中值区间最低值，$N$ 是数据值个数，$(\sum freq)_l$ 是所有低于中值区间的区间频率之和，$freq_{\text{median}}$ 是中值区间的频率，$width$ 是中值区间的宽度。

### 均值、中位数、众数的区别

| 统计量 | 依据         | 是否受极端值影响 | 适用场景                               |
| ------ | ------------ | ---------------- | -------------------------------------- |
| 均值   | 全部数据计算 | 会               | 数据较对称时最能代表整体水平           |
| 中位数 | 排序后位置   | 不会             | 个别数据变动大时描述集中趋势           |
| 众数   | 出现频率     | 不会             | “最佳”“最受欢迎”“最满意”等最普遍的倾向 |

对比 $0,1,5,5,6,8,100$ 与 $0,1,5,5,6,8,10$：后者把极端值换成 $10$ 后均值大变、中位数与众数不变。

### 哪些值能算（判断高频）

对下列属性问“众数/中位数/均值/差值/比率能否计算”：

| 属性                    | 众数 | 中位数 | 均值 | 差值 | 比率 |
| ----------------------- | ---- | ------ | ---- | ---- | ---- |
| 标称（颜色、邮编）      | 可   | 不可   | 不可 | 不可 | 不可 |
| 序数（满意度 $0\sim4$） | 可   | 可     | 不可 | 不可 | 不可 |
| 区间（摄氏温度）        | 可   | 可     | 可   | 可   | 不可 |
| 比率（分数、年龄）      | 可   | 可     | 可   | 可   | 可   |

### 偏斜

| 分布      | 关系                                                                | 直觉             |
| --------- | ------------------------------------------------------------------- | ---------------- |
| 对称单峰  | $\text{均值}=\text{中位数}=\text{众数}$                             | 三者重合于中心值 |
| 正偏/右偏 | 众数出现在小于中位数的值上，$\text{众数}<\text{中位数}<\text{均值}$ | 右侧长尾拉高均值 |
| 负偏/左偏 | 众数出现在大于中位数的值上，$\text{均值}<\text{中位数}<\text{众数}$ | 左侧长尾拉低均值 |

一句话：**均值最容易被尾巴拉过去。**

## 2.2.2 度量数据散布

考察对象：极差、分位数、四分位数、四分位数极差、五数概括、方差、标准差。

| 概念             | 定义                                                                 |
| ---------------- | -------------------------------------------------------------------- |
| 极差 Range       | $\max-\min$                                                          |
| 分位数 quantile  | 取自数据分布的每隔一定间隔上的点，把数据划分成基本大小相等的连贯集合 |
| 四分位数         | $Q_1$（第 25 百分位数）、$Q_3$（第 75 百分位数）；$Q_2=50\%=$ 中位数 |
| 四分位数极差 IQR | $IQR=Q_3-Q_1$                                                        |

### 四分位数怎么算（课件算法）

1. 对所有数据排序；
2. 计算 $(n+1)f\%=j+q$（$n$ 是数据个数，$f$ 是分位数，$j$ 是整数）；
3. $q=0$ 时 $x_{(j)}$ 就是 $f\%$ 的分位数；$q\neq0$ 时取 $0.5\,x_{(j)}+0.5\,x_{(j+1)}$。

| 例                       | 排序结果        | $(n+1)f\%$         | 结果            |
| ------------------------ | --------------- | ------------------ | --------------- |
| $3,5,7,6,4,8,9$（$n=7$） | $3,4,5,6,7,8,9$ | $8\times25\%=2$    | $Q_1=x_{(2)}=4$ |
|                          |                 | $8\times50\%=4$    | $Q_2=x_{(4)}=6$ |
|                          |                 | $8\times75\%=6$    | $Q_3=x_{(6)}=8$ |
| $2,6,5,3,4,7$（$n=6$）   | $2,3,4,5,6,7$   | $7\times25\%=1.75$ | $Q_1=2.5$       |
|                          |                 | $7\times50\%=3.5$  | $Q_2=4.5$       |
|                          |                 | $7\times75\%=5.25$ | $Q_3=6.5$       |

现实中软件与教材有多种四分位数定义，**考试以课件算法为准**。

### 五数概括与离群点

$$
\left.
\begin{array}{ll}
\text{五数概括} & \text{min},\ Q_1,\ \text{median},\ Q_3,\ \text{max}\\[2pt]
\text{可疑离群点} & x>Q_3+1.5\,IQR\ \ \text{或}\ \ x<Q_1-1.5\,IQR
\end{array}
\right\}
\ \text{盒图的基础}
$$

### 方差与标准差

$$
\sigma^2=\frac{1}{N}\sum_{i=1}^{N}(x_i-\mu)^2,\qquad \sigma=\sqrt{\sigma^2}
$$

课件用总体形式（代数度量、可分步计算）。意义：**方差和标准差 → 散布程度，均值 → 中心；$\sigma=0$ 即无散布，方差越小数据稳定性越强。**

# 2.3 数据可视化

## 2.3.1 概述

定义：将大型数据集中的数据以图形图像形式表示，并利用数据分析和开发工具发现其中未知信息；本质是把数据各属性值以**多维数据**形式表示，从不同维度观察数据。

| 作用           | 说明                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------ |
| 观测、跟踪数据 | 实时监控数据状态                                                                                 |
| 分析数据       | 例：**霍乱地图**分析患者分布与水井分布的关系，发现某口井供水范围内患者明显偏多，据此找到污染水泵 |
| 辅助理解数据   | 降低理解成本                                                                                     |
| 增强数据吸引力 | 图表新闻、顶刊插图（Nature/NMI 等）也靠可视化传达结论                                            |

## 2.3.2 常用图表

| 图表   | 维度       | 应用场景                                                 |
| ------ | ---------- | -------------------------------------------------------- |
| 柱状图 | 二维       | 指定一个分析轴进行数据大小的比较                         |
| 折线图 | 二维       | 按时间序列分析数据的变化趋势，适用于较大的数据集         |
| 饼图   | 二维       | 指定一个分析轴进行所占比例的比较，只适用于反映部分与整体 |
| 散点图 | 二维或三维 | 有两个维度需要比较                                       |
| 气泡图 | 三维或四维 | 其中只有两维能够精确辨识                                 |
| 雷达图 | 四维以上   | 数据点不超过 6 个                                        |

### 2.3.2.1 盒图 Boxplot

| 要素     | 规则                                                                                                |
| -------- | --------------------------------------------------------------------------------------------------- |
| 盒的端点 | 一般在四分位数上；箱子长度 $=IQR$                                                                   |
| 中位数   | 箱子中间的线                                                                                        |
| 须       | 若最大值 $<Q_3+1.5IQR$ 则须延伸到最大值；若最小值 $>Q_1-1.5IQR$ 则须延伸到最小值                    |
| 超出时   | 须只延伸到 $Q_3+1.5IQR$ 或 $Q_1-1.5IQR$，超出部分为离群点；正常范围就是 $[Q_1-1.5IQR,\ Q_3+1.5IQR]$ |

易考：给一幅盒图判断哪个数据更分散、哪个中位数更大、有无离群点。

### 2.3.2.2 直方图

| 变量类型 | 图形              | 规则                                                                                         |
| -------- | ----------------- | -------------------------------------------------------------------------------------------- |
| 标称 $X$ | 条形图            | 对 $X$ 的每一个已知值画一个柱/竖直条，条高表示该值出现的频率                                 |
| 数值 $X$ | 直方图/频率直方图 | 值域划分为不相交的连续子域，子域叫**桶（bucket）/箱（bin）**，桶的范围叫**宽度**，通常桶等宽 |

横轴表示值，纵轴表示频次。

### 2.3.2.3 散点图

每个值对视为一个代数坐标对，作为一个点画在平面上：用于观察**双变量数据**、点簇与离群点，以及变量间的关系与趋势。

| 相关方向 | 图形特征                         |
| -------- | -------------------------------- |
| 正相关   | 左下到右上，一个增大另一个也增大 |
| 负相关   | 左上到右下，一个增大另一个减小   |
| 不相关   | 两属性间不存在相关关系           |

$k$ 维数据可画**散点图矩阵**，共 $\frac{k(k-1)}{2}$ 张。

| 其他图表 | 要点                                         |
| -------- | -------------------------------------------- |
| 平行坐标 | 高维数据：每个属性一根竖轴，一个对象一条折线 |
| 思维导图 | 展现概念层次与关系                           |
| 标签云   | 用字号体现词频                               |

# 2.4 度量数据的相似性和相异性

很多算法越来越依赖于输入空间给定的好度量：K-means、K 近邻、SVM、深度学习等都需要能反映数据间重要关系的度量。

| 概念                 | 含义                               | 取值范围             |
| -------------------- | ---------------------------------- | -------------------- |
| 相似性 similarity    | 描述两对象相似程度，越像值**越高** | 通常 $[0,1]$         |
| 相异性 e.g. distance | 描述两对象差异程度，越像值**越低** | 最小相异度通常为 $0$ |

两者统称**邻近性**。

## 2.4.1 数据矩阵与相异性矩阵

| 矩阵       | 维度        | 类型     | 含义                                                        |
| ---------- | ----------- | -------- | ----------------------------------------------------------- |
| 数据矩阵   | $n\times p$ | 二模矩阵 | 行和列代表不同个体：行是对象、列是属性                      |
| 相异性矩阵 | $n\times n$ | 单模矩阵 | 只包含一类实体；$d_{ii}=0$、$d_{ij}=d_{ji}$，下三角即可存完 |

## 2.4.2 标称属性的邻近性度量

设 $p$ 为属性总数，$m$ 为取值相同的属性数。

**方法 1：简单匹配**

$$
d(i,j)=\frac{p-m}{p},\qquad sim(i,j)=\frac{m}{p}
$$

例：$d_1=\{red,China,smoker\}$，$d_2=\{black,China,non\text{-}smoker\}$，只有 country 相同 ⇒ $m=1,\ p=3$，则 $sim=\frac13,\ d=\frac23$。

**方法 2：one-hot 编码**——采用 $0$-$1$ 值代表 $M$ 个状态，例：

| 对象  | 取值                                   | one-hot         |
| ----- | -------------------------------------- | --------------- |
| $d_1$ | $\{red, not\ China, smoker\}$          | $\{001,01,01\}$ |
| $d_2$ | $\{black, China, non\text{-}smoker\}$  | $\{010,10,10\}$ |
| $d_3$ | $\{yellow, China, non\text{-}smoker\}$ | $\{100,10,10\}$ |

## 2.4.3 二元属性的邻近性度量

|         | 对象2=1 | 对象2=0 |
| ------- | ------: | ------: |
| 对象1=1 |     $q$ |     $r$ |
| 对象1=0 |     $s$ |     $t$ |

$q$：两者都取 1；$r,s$：两者取值不同；$t$：两者都取 0。

| 情形             | 公式                                                |
| ---------------- | --------------------------------------------------- |
| 对称二元相异性   | $d(i,j)=\frac{r+s}{q+r+s+t}$（不同的个数 / 总个数） |
| 非对称二元相异性 | $d(i,j)=\frac{r+s}{q+r+s}$（**忽略 $t$**）          |
| 非对称二元相似性 | $sim_{Jaccard}(i,j)=\frac{q}{q+r+s}$                |

课件例（Jack/Mary/Jim）：只按**非对称属性** $Test$-$1\sim Test$-$4$ 计算，对称属性（Gender/Fever/Cough）不参与。

> 理解比死背重要：**非对称二元只关心 1。**

## 2.4.4 序数属性的距离

序数属性的值之间有有意义的序或排位，但相继值之间的量值未知；而数值属性的值域可以映射到具有 $M_f$ 个状态的序数属性 $f$。

| 步  | 操作                                                               |
| --- | ------------------------------------------------------------------ |
| 1   | 第 $i$ 个对象的 $f$ 值为 $x_{if}$，用对应**排位** $r_{if}$ 取代它  |
| 2   | 映射到 $[0,1]$ 使每个属性权重相同：$z_{if}=\frac{r_{if}-1}{M_f-1}$ |
| 3   | 采用任意一种**数值属性**的距离度量（如欧氏距离）计算               |

这是标准考试流程题。

## 2.4.5 数值属性的距离

| 名称           | 公式                                                                     | 别名 / 参数                | 直觉                                                                         |
| -------------- | ------------------------------------------------------------------------ | -------------------------- | ---------------------------------------------------------------------------- |
| 欧几里得距离   | $d(i,j)=\sqrt{\sum_{k=1}^{p}(x_{ik}-x_{jk})^2}$                          | $L_2$，$h=2$               | 两点间直线距离（勾股定理）                                                   |
| 曼哈顿距离     | $d(i,j)=\sum_{k=1}^{p}\lvert x_{ik}-x_{jk}\rvert$                        | 城市街区距离，$L_1$，$h=1$ | 标准坐标系上的绝对轴距总和（横走 + 竖走）                                    |
| 闵可夫斯基距离 | $d(i,j)=\left(\sum_{k=1}^{p}\lvert x_{ik}-x_{jk}\rvert^{h}\right)^{1/h}$ | $L_h$ 范数                 | $h\to\infty$ 时为 $\max_k\lvert x_{ik}-x_{jk}\rvert$（上确界距离 $L_{max}$） |

注意：**两个点的范围差别较大时需要标准化**。

| 闵氏距离的特例 | 说明                                                                                 |
| -------------- | ------------------------------------------------------------------------------------ |
| $h=1$          | 曼哈顿距离（城市块距离、$L_1$）；当向量是二进制时即 **Hamming 距离**（不同位的个数） |
| $h=2$          | 欧几里得距离（$L_2$）                                                                |
| $h\to\infty$   | 上确界距离（$L_{max}$）：各分量（属性）差的最大值                                    |

### 什么才叫“距离”（四性质）

$$
\left.
\begin{array}{ll}
\text{非负性} & d(i,j)>0\ \ \text{当}\ \ i\neq j\\[2pt]
\text{同一性} & d(i,i)=0\\[2pt]
\text{对称性} & d(i,j)=d(j,i)\\[2pt]
\text{三角不等式} & d(i,j)\leq d(i,k)+d(k,j)
\end{array}
\right\}
\ \text{满足这些条件的测度称为度量}
$$

## 2.4.6 余弦相似性

$$
sim(v_1,v_2)=\frac{v_1\cdot v_2}{\lVert v_1\rVert\lVert v_2\rVert}
$$

常用于文本挖掘：向量第 $j$ 个数值是该文档中第 $j$ 个项的量度（词频）。

| 课件例（$\{v_i\}$ 共 25 维，前 11 维为第 1 类词、后 5 维为第 2 类词） | 计算                                  |
| --------------------------------------------------------------------- | ------------------------------------- |
| $sim(v_1,v_2)$                                                        | $\frac{0}{11\times5}=0$（完全无交集） |
| $sim(v_2,v_3)$                                                        | $\frac{0}{5\times8}=0$                |
| $sim(v_1,v_3)$                                                        | $\frac{7}{11\times8}\approx0.75$      |

它比较的是**方向**而非绝对长度，所以词频比例相近、长度差一倍的两篇文章仍可能很相似；这也是现代嵌入检索大量使用余弦相似度的原因。

## 2.4.7 度量学习

不是人工固定 $d(x_i,x_j)$，而是从数据学一个更合理的距离。

| 方法                                  | 核心思想                                                                                                                                  |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Isomap 等度量映射                     | 流形在局部区域与欧氏空间同胚，可用欧氏距离计算；**引入测地线距离**：先基于欧氏距离找近邻建近邻图，两点间测地距离 = 近邻图上两点间最短路径 |
| LMNN（Large Margin Nearest Neighbor） | 为 KNN 分类学一个大间隔距离度量                                                                                                           |
| 深度度量学习                          | 用神经网络学嵌入，损失包括：对比损失、三元组损失、四元组损失、难样本采样三元组（TriHard）、边界挖掘损失（MSML）                           |

三元组目标：$d(A,P)<d(A,N)$（锤点更近，异类更远）。

## 2.4.8 多模态对齐中的相似度

目标：让配对的图像与文本在共享空间中更接近，不配对的更远。

$$
z_i^I=\frac{f^I(x_i)}{\lVert f^I(x_i)\rVert_2},\quad z_j^T=\frac{f^T(t_j)}{\lVert f^T(t_j)\rVert_2},\quad s_{ij}=\tau\langle z_i^I,z_j^T\rangle+b
$$

$$
\mathcal{L}=\frac{1}{B^2}\sum_i\sum_j\log\left[1+\exp(-y_{ij}s_{ij})\right],\quad y_{ij}=+1\ \text{匹配},\ -1\ \text{不匹配}
$$

| SigLIP 2（2025）的改进 | 要点                                                                 |
| ---------------------- | -------------------------------------------------------------------- |
| 成对二分类             | 用 Sigmoid 损失独立判断每个图文对，避免 CLIP 对全批次 Softmax 的依赖 |
| 局部语义增强           | 加入图像描述、局部定位、自蒸馏与掩码预测，使图像块特征也具有语义     |
| 应用                   | 跨语言图文检索、零样本分类、开放词汇检测、视觉语言模型的视觉编码     |

## 2.4.9 大模型嵌入与 RAG 检索

大模型既要内部计算“注意力相似度”，也要在外部检索中计算“语义距离”；从单一余弦相似度走向**混合相关度**：

$$
s_{rank}=w_1s_{dense}+w_2s_{lex}+w_3s_{mul}
$$

| 成分         | 含义                                                     |
| ------------ | -------------------------------------------------------- |
| Dense        | 归一化句向量的内积，适合语义近似但措辞不同的文本         |
| Lexical      | 根据共同词项及其学习权重计算稀疏匹配，保留关键词精确匹配 |
| Multi-vector | 保留词元级向量并采用晚交互，捕捉查询与长文档的细粒度关系 |

代表工作：NV-Embed（LLM + 潜在注意力池化 + 两阶段对比指令微调），M3-Embedding（统一 dense、sparse、multi-vector，支持 100 余种语言、最长 8192 词元）。

## 2.4.10 视觉文档 RAG 的细粒度相关度

ColPali：**查询按词元表示，文档页按图像块表示**，再用 MaxSim 完成**晚交互**。

| 要点     | 内容                                                                  |
| -------- | --------------------------------------------------------------------- |
| MaxSim   | 每个查询词元选择最相似的页面图像块，再把各词元的最大相似度求和        |
| 优点     | 比单向量更能保留局部语义，可直接检索含表格、图形和复杂版式的 PDF 页面 |
| RAG 作用 | 先找到与问题最相关的页面，再把页面内容交给多模态大模型生成答案        |
