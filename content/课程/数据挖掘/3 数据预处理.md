# 3 数据预处理

一句话：整章 = **清洗 → 集成 → 归约 → 变换** 四条主线，最易真正出题的是缺失值/噪声、特征选择与相关系数/信息增益、PCA、规范化与离散化。

## 总览（思维导图）

$$
\begin{array}{c}
\text{脏、乱、大、高维的原始数据}\\[2pt]
\downarrow\\[2pt]
\begin{cases}

\text{集成}:\ \text{多源合并、冗余、冲突}\\
\text{归约}

\end{array}
$$

# 一、为什么需要预处理

现实数据四类问题：**有缺失、有噪声、不一致、高维/数量大。**

| 数据质量维度 | 含义                   |
| ------------ | ---------------------- |
| 完整性       | 数据有没有缺           |
| 有噪声       | 有没有错误、异常       |
| 一致性       | 不同字段之间有没有矛盾 |
| 准确性       | 数据本身对不对         |
| 时效性       | 是不是及时更新         |
| 可信性       | 是否值得相信           |
| 可解释性     | 是否容易理解           |

两个典型判断题：

| 现象                      | 属于       |
| ------------------------- | ---------- |
| $Age=42$，$Birthday=2010$ | 一致性问题 |
| $Salary=-100$             | 错误/噪声  |

# 二、预处理四大任务（必背）

| 操作 | 解决什么            |
| ---- | ------------------- |
| 清洗 | 缺失、噪声、错误    |
| 集成 | 多个来源合并        |
| 归约 | 数据太多、维度太高  |
| 变换 | 格式/尺度不适合算法 |

最终产出：**高质量、统一、低维、规范化的数据。**

# 三、数据清洗①：缺失值

例：A$(20,5000)$、B$(21,\text{空})$、C$(22,6000)$ —— B 的收入就是缺失值。

产生原因：设备异常、人工失误、没有录入、数据本身不适用（N/A）。

## 六种处理方法（简答题高频）

| 方法         | 做法                                   | 问题 / 说明                    |
| ------------ | -------------------------------------- | ------------------------------ |
| 忽略样本     | 直接删掉整行，如 $(21,?,\text{天津})$  | 缺失多时损失大量数据           |
| 人工填写     | 重新采集或用领域知识                   | 可能准确，但工作量大、可行性差 |
| 全局常量填充 | 填 `unknown` 或特殊值                  | 大量 `unknown` 人为制造新类别  |
| 属性均值填充 | $4000,5000,?,6000$ ⇒ 均值 $5000$       | **降低方差，把数据拉向平均值** |
| 同类样本均值 | 用“所有学生”的平均收入而非全体         | 通常比全局均值更合理           |
| 建模预测     | 贝叶斯、决策树、回归、矩阵补全、插值法 | $10,?,14\Rightarrow12$         |

考法：**“下面哪些方法可以处理缺失值？”** 或 **“简述缺失值处理方法及优缺点。”** 记：**删、人工填、常量填、均值填、同类均值填、模型预测。**

# 四、数据清洗②：噪声与分箱

噪声 = 测量变量中的**随机错误或偏差**；来源：仪器、输入、传输、技术限制。

最值得掌握的处理方法是**分箱（Binning）**：① 数据排序 ② 分入若干箱 ③ 每箱平滑。

课件数据 $4,8,15,21,21,24,25,28,34$，每三个一组：

$$
B_1=(4,8,15),\quad B_2=(21,21,24),\quad B_3=(25,28,34)
$$

| 平滑方式     | 规则                                    | 本例结果                                         |
| ------------ | --------------------------------------- | ------------------------------------------------ |
| 箱均值平滑   | 全箱替换为均值                          | $B_1:\frac{4+8+15}{3}=9$；$B_2\to22$；$B_3\to29$ |
| 箱中位数平滑 | 全箱替换为中位数                        | $B_1$ 中位数 $8\Rightarrow(8,8,8)$               |
| 箱边界平滑   | 只留最小/最大值，中间值替换为最近的边界 | $(4,8,15)\to(4,4,15)$，$8$ 离 $4$ 更近           |

边界平滑是很典型的计算题。

# 五、离群点 ≠ 异常点

| 概念   | 定义                               |
| ------ | ---------------------------------- |
| 离群点 | 从数据分布看，与大多数对象差异很大 |
| 异常   | 是否“异常”还跟具体任务语义有关     |

例：身高 $210$ cm 统计上可能是离群点，但完全可能是真实数据而非错误。

检测方法：聚类、回归、盒图、计算机检测 + 人工判断。

盒图判定（接第二章）：$x<Q_1-1.5IQR$ 或 $x>Q_3+1.5IQR$ 即可疑离群点。

# 六、数据集成

定义：把多个数据源的数据合并到统一的数据存储中。目的：减少**冗余、不一致**，提高**挖掘准确性、挖掘速度**。

四大问题：**实体识别、属性冗余、样本重复、数据值冲突。**

| 问题       | 例子 / 说明                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| 实体识别   | `Bill Clinton` 与 `William Clinton` 是否同一人；`customer_id` 与 `cust_number` 是否同一属性（实体/模式匹配） |
| 属性冗余   | 出生年份与年龄表达相同信息 ⇒ 引出**相关性**研究                                                              |
| 样本重复   | 两个库都有同一个人的记录，合并后不能留两份                                                                   |
| 数据值冲突 | $70$ kg vs $154$ lb；元 vs 千元；A+~F vs 1~10；公制 vs 英制 ⇒ 格式、单位、尺度、编码都要统一                 |

# 七、数据归约：属性 vs 数量

定义：数据变少，但尽量保留原数据的信息。目的三条：**减少存储量、减少计算量、缓解维数灾难。**

以 $1000000$ 个学生 $\times 100$ 个属性为例：

| 类型     | 做法                                         | 一句话                          |
| -------- | -------------------------------------------- | ------------------------------- |
| 属性归约 | $100$ 个属性 $\to10$ 个，对象仍是 $100$ 万人 | **减少列**                      |
| 数量归约 | $100$ 万人 $\to10$ 万人，属性可能仍 $100$ 个 | **减少行/数据量，或用模型概括** |

属性归约再分两种：

| 方式     | 做法                           | 例                               |
| -------- | ------------------------------ | -------------------------------- |
| 属性选择 | 从原属性里挑一部分，原属性还在 | $x_1,x_2,x_3,x_4\to x_1,x_3$     |
| 属性重构 | 制造新属性（线性组合）         | PCA：$x_1,\ldots,x_4\to z_1,z_2$ |

> **特征选择是挑原属性；PCA 是造新属性。**

## 归约体系（思维导图）

$$
\text{数据归约}
\begin{cases}
\text{属性归约}
\begin{cases}
\text{属性选择}:\ \text{Filter / Wrapper / Embedded}\\
\text{属性重构}:\ \text{PCA、NMF、t-SNE}
\end{cases}\\
\text{数量归约}
\begin{cases}
\text{参数化}:\ \text{回归（只存参数）}\\
\text{非参数化}:\ \text{直方图 / 聚类 / 抽样}
\end{cases}
\end{cases}
$$

# 八、特征选择三大类（必会比较）

| 方法            | 思路                                           | 评价指标 / 例子                                                                        | 特点                           |
| --------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------ |
| 过滤式 Filter   | 数据 → 特征选择 → 训练模型，**与最终模型无关** | 协方差、相关系数、卡方检验、Relief                                                     | 快、计算量小                   |
| 包裹式 Wrapper  | 直接用**最终模型性能**评价特征好坏             | $x_1,x_3,x_5\to95\%$，换成 $x_1,x_2,x_5\to97\%$ ⇒ 第二组更好；LVW、RFE（递归特征消除） | 更贴合模型，但反复训练、开销大 |
| 嵌入式 Embedded | 特征选择**包含在模型训练过程中**               | 决策树的信息增益、正则化                                                               | 训练同时完成选择               |

| 方法     | 什么时候选择特征   |
| -------- | ------------------ |
| Filter   | 训练模型之前       |
| Wrapper  | 反复训练模型来评价 |
| Embedded | 训练模型过程中     |

# 九、协方差与相关系数

$$
Cov(A,B)=\frac{1}{n}\sum_{i=1}^{n}(a_i-\bar A)(b_i-\bar B)
$$

| 取值    | 含义                                |
| ------- | ----------------------------------- |
| $Cov>0$ | $A$ 大时 $B$ 往往也大（正相关趋势） |
| $Cov<0$ | 一个增加时另一个往往减少            |
| $Cov=0$ | 没有线性协同变化                    |

注意：协方差数值**受数据单位和尺度影响** ⇒ 因此引入相关系数。

$$
r_{A,B}=\frac{Cov(A,B)}{\sigma_A\sigma_B},\qquad -1\leq r\leq1
$$

| 取值   | 含义               |
| ------ | ------------------ |
| $r>0$  | 正相关             |
| $r<0$  | 负相关             |
| $r=1$  | 完全正线性相关     |
| $r=-1$ | 完全负线性相关     |
| $r=0$  | **无线性**相关关系 |

陷阱：$r=0$ **不代表两变量完全没关系**，只是没有线性关系（如 $y=x^2$）。相关系数本质是**标准化后的协方差**，因此不像协方差那样受单位影响。

# 十、熵与信息增益

熵衡量不确定性（课件把它放在嵌入式特征选择里）：

$$
H(S)=-\sum_i p_i\log_2 p_i
$$

| 情形                 | $H(S)$              |
| -------------------- | ------------------- |
| $50\%$ 男、$50\%$ 女 | $1$（不确定性较大） |
| $100\%$ 男性         | $0$（完全确定）     |

增加属性 $X$ 后仍剩的不确定性为 $H(S\mid X)$，则

$$
Gain(S,X)=H(S)-H(S\mid X)
$$

**信息增益越大，该属性越有用**（不确定性下降越多）。课件例：

$$
H(S)=1,\quad H(S\mid X)=0.5477\ \Rightarrow\ Gain=1-0.5477=0.4523
$$

# 十一、PCA

主成分分析（Principal Component Analysis）解决：多个属性高度相关，能不能用少量**新属性**表达绝大部分信息？

例：语文+历史+政治+地理 ⇒ “文科综合能力”；身高+袖长+肩宽 ⇒ “长度指标”。

$$
\boxed{\text{不是删属性，而是把原属性线性组合成少量新主成分}}
$$

| 要点           | 内容                                                                                                                   |
| -------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 在寻找什么     | 在 $d$ 维中找 $k$ 个最能代表数据的**正交方向**（$k\leq d$），把 $d$ 维投影到 $k$ 维                                    |
| 关键原则       | $\boxed{\text{选择投影后方差最大的方向}}$（方差大 ⇒ 数据变化大 ⇒ 信息更多）                                            |
| 主成分顺序     | 第一主成分 = 最大方差方向；第二主成分 = 与第一主成分正交的剩余最大方差方向；依次类推                                   |
| 为什么能去相关 | 数据原本沿一个斜方向变化，PCA 旋转坐标系后主成分互相正交（不相关）；变换后的协方差矩阵希望成为对角阵，非对角元素为 $0$ |

$$
S(Y)=
\begin{bmatrix}
\lambda_1&0&0\\
0&\lambda_2&0\\
0&0&\lambda_3
\end{bmatrix}
\quad\Longleftrightarrow\quad
\text{不同主成分间协方差为 }0
$$

## 完整步骤（写流程题用）

| 步  | 操作                      |
| --- | ------------------------- |
| 1   | 数据中心化                |
| 2   | 计算协方差矩阵            |
| 3   | 对协方差矩阵做特征分解    |
| 4   | 特征值由大到小排序        |
| 5   | 选前 $k$ 个特征向量       |
| 6   | 把数据投影到这 $k$ 个方向 |

核心关系：**特征值越大 → 对应方向方差越大 → 越重要。** 课件没有大量 PCA 手算例题，所以「思想 + 流程 + 与其他方法的区别」优先级高于完整矩阵手算。

# 十二、PCA vs LDA，以及两个 LDA

| 维度         | PCA            | 线性判别分析 LDA       |
| ------------ | -------------- | ---------------------- |
| 是否需要标签 | 不需要         | 需要                   |
| 类型         | 无监督         | 有监督                 |
| 目标         | 投影后方差最大 | 类内尽量紧、类间尽量远 |
| 都能做什么   | 降维           | 降维                   |

> PCA 关心“数据本身怎么展开”；LDA 关心“怎样最利于分类”。

| 缩写 | 全称                         | 用途         |
| ---- | ---------------------------- | ------------ |
| LDA① | Linear Discriminant Analysis | 有监督降维   |
| LDA② | Latent Dirichlet Allocation  | 文档主题模型 |

两者只是缩写相同，完全不是一个算法。

| 其他降维方法     | 要点                                                          |
| ---------------- | ------------------------------------------------------------- |
| NMF 非负矩阵分解 | $X\approx WH$ 且 $W\geq0,\ H\geq0$；用于降维、文本聚类        |
| t-SNE            | 降维并尽量保持**局部邻域结构**；常用于高维数据二维/三维可视化 |

两者知道思想即可。

# 十三、数量归约

| 类别     | 方法   | 为什么能“压缩数据”                                                                  |
| -------- | ------ | ----------------------------------------------------------------------------------- |
| 参数化   | 回归   | 数据大致满足 $y=2x+1$ 时，只需保存参数 $a=2,b=1$（模型 $y=ax+b$），不必存一百万个点 |
| 非参数化 | 直方图 | 只保存每个区间的频数，不再保存每个具体值                                            |
| 非参数化 | 聚类   | $100$ 万样本 $\to100$ 个簇，只存簇中心、代表对象等                                  |
| 非参数化 | 抽样   | 取更小但具有代表性的子集                                                            |

回归流程：假定模型 → 估计参数 → 保存参数 → 原始数据可不必全部保存（**参数化数据归约**）。

| 抽样方式     | 做法                         |
| ------------ | ---------------------------- |
| 简单随机抽样 | 每个样本都有机会被随机抽到   |
| 簇抽样       | 先把数据分成若干簇，再抽取簇 |
| 分层抽样     | 先按类别等分层，再从每层抽   |

不均衡数据例：$90\%$ 正常用户 + $10\%$ 欺诈用户时，纯随机抽样可能抽不到足够欺诈样本，**分层抽样能保证各类都得到代表**。

# 十四、数据变换①：One-hot 编码

标称属性不能直接编号，否则暗示了并不存在的顺序：

$$
\text{红}=1,\ \text{绿}=2,\ \text{蓝}=3\ \Rightarrow\ \text{暗示 }\text{蓝}>\text{绿}>\text{红}\ (\text{错})
$$

$$
\text{红}=(1,0,0),\quad \text{绿}=(0,1,0),\quad \text{蓝}=(0,0,1)
$$

本质：**一个类别对应一个二元维度。**

# 十五、数据变换②：规范化

身高 $1.5\sim2$、收入 $1000\sim100000$，直接算 $d=\sqrt{(\Delta_{\text{身高}})^2+(\Delta_{\text{收入}})^2}$ 时，**收入尺度会完全支配结果** ⇒ 必须把不同属性放到可比较的尺度。三种方法必须会：

| 方法     | 公式                                                                                                          | 核心                       | 例                                                        |
| -------- | ------------------------------------------------------------------------------------------------------------- | -------------------------- | --------------------------------------------------------- |
| Min-Max  | $v'=\frac{v-\min_A}{\max_A-\min_A}(newMax_A-newMin_A)+newMin_A$，映射 $[0,1]$ 时为 $\frac{v-\min}{\max-\min}$ | 根据最大最小值压到固定区间 | $0\sim100$ 中的 $75\to0.75$                               |
| Z-score  | $v'=\frac{v-\bar A}{\sigma_A}$                                                                                | 减均值、除标准差           | 均分 $80$、标准差 $10$、成绩 $90\to z=1$（高 1 个标准差） |
| 小数定标 | $v'=\frac{v}{10^j}$，$j$ 是满足 $\max(\lvert v'\rvert)<1$ 的最小整数                                          | 移动小数点                 | $987\to0.987$（$j=3$）                                    |

课件笔误提醒：课件给工资范围 $700\sim12000$、工资 $7830$、结果标 `0.7430`；但按课件自己的公式 $\frac{7830-700}{12000-700}=\frac{7130}{11300}\approx0.631$。**记公式，不要把 `0.7430` 当结论背。**

# 十六、数据变换③：离散化

定义：把连续数值划分为若干区间，用区间标签代替具体数值。

例：年龄 $0\sim100$ ⇒ $0\sim18$ 未成年、$18\sim60$ 成年人、$60+$ 老年；此时 $23$ 不再表示 $23$，而表示“成年人”。

作用：减少取值数量、更容易形成高级概念、某些模型需要离散属性。

课件数据 $4,8,9,15,21,21,24,25,26,28,29,33$：

| 方式     | 要求                   | 本例结果                                                                                 |
| -------- | ---------------------- | ---------------------------------------------------------------------------------------- |
| 等频分箱 | **每箱样本数基本相同** | 每箱 4 个：$(4,8,9,15)$、$(21,21,24,25)$、$(26,28,29,33)$                                |
| 等宽分箱 | **数值区间宽度相同**   | 宽度约 $10$：$[4,14)\to(4,8,9)$；$[14,24)\to(15,21,21)$；$[24,34]\to(24,25,26,28,29,33)$ |

| 对比         | 等宽   | 等频       |
| ------------ | ------ | ---------- |
| 每箱宽度     | 相同   | 不一定     |
| 每箱样本数   | 不一定 | 基本相同   |
| 受离群点影响 | 是     | 相对小一些 |

聚类也可用于离散化（如 K-means 根据数据分布自动划分）。

# 十七、数据脱敏：背分类

目标：在保持数据可用性的同时保护敏感隐私（身份证号、手机号、银行卡号）。

| 类别 | 包括                     | 例                          |
| ---- | ------------------------ | --------------------------- |
| 替换 | 通用化、随机化           | —                           |
| 删除 | 删除整行、删除整列       | —                           |
| 掩盖 | 部分字符隐去、日期模糊化 | $13812345678\to138****5678$ |
| 加密 | 对称加密、非对称加密     | —                           |
| 哈希 | 单向哈希、加盐哈希       | —                           |

口诀：**替、删、掩、密、哈。** 大概率只是识记/简答，不像规范化那样要算。

# 十八、最容易混的概念

| 对比                   | 区别                                                                                         |
| ---------------------- | -------------------------------------------------------------------------------------------- |
| 数据清洗 vs 数据变换   | 清洗是修复有问题的数据；变换是数据本身没错，只是不适合算法                                   |
| 特征选择 vs PCA        | 特征选择留下部分原特征；PCA 组合出新特征                                                     |
| 属性归约 vs 数量归约   | 减少列 vs 减少数据量/对象表示                                                                |
| 分箱平滑 vs 分箱离散化 | 同一个工具不同目的：前者用箱均值/中位数/边界替换原值以平滑，后者把连续值映射为区间以减少取值 |
| PCA vs LDA             | 无监督、最大化方差 vs 有监督、类内近类间远                                                   |
| 两个 LDA               | 线性判别分析（降维） vs 隐狄利克雷分配（主题模型）                                           |

# 十九、计算题优先押这六种

| 优先级 | 题型               |
| ------ | ------------------ |
| 1      | 分箱平滑           |
| 2      | 协方差 / 相关系数  |
| 3      | 熵 / 信息增益      |
| 4      | Min-Max 规范化     |
| 5      | Z-score / 小数定标 |
| 6      | 等宽 / 等频离散化  |

PCA 更应把**思想、流程、PCA/LDA 区别**掌握牢：课件没像规范化那样给大量手算训练。

# 二十、考前必背公式

$$
\left.
\begin{array}{ll}
\text{协方差} & Cov(A,B)=\frac{1}{n}\sum_i(a_i-\bar A)(b_i-\bar B)\\[2pt]
\text{相关系数} & r_{A,B}=\frac{Cov(A,B)}{\sigma_A\sigma_B}\\[2pt]
\text{熵} & H(S)=-\sum_i p_i\log_2 p_i\\[2pt]
\text{信息增益} & Gain(S,X)=H(S)-H(S\mid X)\\[2pt]
\text{Min-Max} & v'=\frac{v-\min}{\max-\min}\\[2pt]
\text{Z-score} & v'=\frac{v-\bar A}{\sigma_A}\\[2pt]
\text{小数定标} & v'=\frac{v}{10^j}
\end{array}
\right\}
$$
