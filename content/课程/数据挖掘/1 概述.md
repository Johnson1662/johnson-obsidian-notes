# 二、第一章：数据挖掘到底是什么

## 1. 数据 → 信息 → 知识 → 智慧

这是最基础的一条链。

**数据（Data）**：原始记录，本身未必有明确意义。

例如：

> 35，38，40，39

只是一串数据。

**信息（Information）**：数据经过加工，有了含义。

> 某人过去四天体温分别为 35、38、40、39 ℃。

**知识（Knowledge）**：从信息中总结出的关系、模式、规律。

> 体温持续升高可能意味着身体状态异常。

**智慧（Wisdom）**：利用已有知识分析具体情况并作出决策。

课件第33页给出的逻辑就是：

**数据经过处理 → 信息；信息建立联系 → 知识；利用知识发现新关系并解决问题 → 智慧。**

考试如果问四者区别，抓住：

> **数据是原料，信息是有意义的数据，知识是规律，智慧是利用规律解决问题的能力。**

# 三、数据挖掘定义：第一章最应该背的一句话

课件第34页定义：

> 数据挖掘是从大量的、不完全的、有噪声的、模糊的、随机的实际应用数据中，提取隐含的、人们事先不知道的、但又潜在有用的信息和知识的过程。

不建议一字不差死背，至少记住六个关键词：

**大量、实际数据 → 有噪声/不完整 → 隐含 → 未知 → 有用 → 知识。**

老师如果让你解释“为什么数据库查询不算数据挖掘”，核心就在这里。

例如：

> `SELECT * FROM student WHERE score > 90`

你已经明确知道自己要找“90分以上学生”。

这是**查询**。

数据挖掘则更像：

> 我没有预先知道规律，让算法从数据中发现“什么因素和成绩相关”。

所以：

**数据库：回答你已经知道怎么问的问题。**

**数据挖掘：发现你原本不知道的模式。**

## 4. 为什么传统统计/数据库还不够？

课件专门列了数据挖掘面对的数据特点：

|特点|含义|
|---|---|
|海量|可能到 TB、PB|
|高维|属性可能成千上万|
|复杂、非结构化|文本、图像、视频、Web|
|特殊结构|时间序列、图、社会网络|
|异构|来源和格式不同|
|有噪声|错误、异常、缺失|

所以数据挖掘不是简单算个平均数，而是要能处理**大、杂、脏、复杂的数据**。

# 五、数据挖掘到底在“挖”什么？

这是第一章第二个核心。

课件首先从宏观分成：

### 预测性方法

已知一些变量：

XX

预测未知目标：

YY

即：

> **解释变量 → 目标变量**

典型：

分类、回归。

### 描述性方法

不是预测某个答案，而是：

> **发现人可以理解的数据规律。**

例如聚类、关联规则。

---

## 六、四种主要任务必须分清

### 1. 关联分析

发现：

> 哪些东西经常一起出现。

形式：

X⇒YX\Rightarrow Y

例如：

> 买尿布的人往往也买啤酒。

典型应用：推荐系统。

现在不用学支持度、置信度，那是后面章节。

---

### 2. 分类

核心：

> **类别是离散的，而且训练数据已有标签。**

例如根据：

年龄、收入、信用记录

预测：

> 是否违约：是 / 否。

因此：

**有标签 + 预测类别 = 分类。**

---

### 3. 聚类

核心：

> **事先没有标签，让算法自己把相似对象分组。**

例如给一万个用户，没有“高价值用户”“普通用户”的标签。

算法自动分成几组。

所以考试最喜欢问：

|分类|聚类|
|---|---|
|有标签|无标签|
|监督|无监督|
|预测已有类别|自动发现群体|

一句话：

> **分类是“类别已知，学怎么分”；聚类是“类别未知，自己找类别”。**

---

### 4. 回归

与分类非常像，但：

> **预测的是连续数值。**

例如：

房价 = 235 万。

不是：

房价高 / 中 / 低。

因此最基本判断口诀：

> 类别 → 分类  
> 数值 → 回归  
> 没标签分组 → 聚类  
> 找共同出现 → 关联分析

这四个一定要做到看到题目 3 秒判断。

# 十一、全章最重要：属性类型

这里非常容易考判断题。

课件分：

**标称、二元、序数、数值。**

数值再分：

**区间属性、比率属性。**

---

## 1. 标称属性

只表示：

> **不同类别。**

不能比较大小和顺序。

例如：

眼睛颜色：

> 黑、蓝、棕。

或者：

邮政编码、学号。

这里有一个考试陷阱：

> **数字不代表它一定是数值属性。**

例如学号：

20240001、20240002。

虽然用数字表示，但：

20240002−20240001=120240002-20240001=1

完全没有实际意义。

所以它是**标称属性**。

标称属性允许的本质操作只有：

=,≠=,\neq

---

## 2. 二元属性

只有两个状态：

0, 10,\ 1

例如：

男 / 女

有 / 无

阳性 / 阴性。

二元属性又分：

### 对称二元

两个状态地位一样。

例如：

性别。

### 非对称二元

其中一个状态明显更重要。

例如疾病检测：

1=患病1=\text{患病} 0=未患病0=\text{未患病}

这里“两个都没病”通常没那么有信息量。

这个区别会直接影响后面 **Jaccard 相似度**。

---

## 3. 序数属性

不仅能判断不同，还存在：

> **顺序。**

例如：

差<中<良<优差 < 中 < 良 < 优

或者：

小<中<大小 < 中 < 大

但是：

> 相邻等级之间的距离不知道。

因此：

“优”比“良”高。

但不能说：

> 优 - 良 = 良 - 中。

---

## 4. 区间属性

已经是数值了。

特点：

> **差值有意义，但没有真正的绝对零点。**

经典例子：

摄氏温度。

10∘C−5∘C=5∘C10^\circ C-5^\circ C=5^\circ C

有意义。

但：

> 10℃不是5℃的“两倍热”。

因为 0℃ 并不代表“没有温度”。

---

## 5. 比率属性

最高级的一种。

特点：

> 有真正零点，所以比例也有意义。

例如：

年龄、长度、质量、金额、开尔文温度。

例如：

10kg=2×5kg10kg=2\times5kg

有意义。

# 十三、离散和连续

### 离散

值可以一个一个数出来：

0,1,2,3,…0,1,2,3,\ldots

比如人数。

### 连续

理论上可以取一个区间中的任意实数。

例如：

身高 175.238…… cm。

有个细节：

课件有一页把标称、二元、序数主要放在“离散”，数值属性放在“连续”。

但严格来说：

> **数值属性不一定连续。**

例如“孩子数量”是数值、比率属性，但显然是离散的。

考试遇到具体例子，优先根据：

> **有限/可数 → 离散；不可数连续区间 → 连续**

来判断。

# 十四、统计描述：中心在哪里？

第二章第二个大块。

## 均值

xˉ=1N∑i=1Nxi\bar{x}=\frac{1}{N}\sum_{i=1}^{N}x_i

所有数据都参与。

因此：

> **容易受极端值影响。**

---

## 加权均值

xˉ=∑wixi∑wi\bar{x} = \frac{\sum w_ix_i}{\sum w_i}

某些数据权重更大。

---

## 截尾均值

先去掉两端极端的一部分数据，再算均值。

目的：

> 降低极端值影响。

---

## 中位数

把数据从小到大排序。

奇数个：

> 最中间一个。

偶数个：

> 中间两个平均。

例如：

23,29,20,32,23,21,33,2523,29,20,32,23,21,33,25

排序：

20,21,23,23,25,29,32,3320,21,23,23,25,29,32,33

因此：

Median=23+252=24Median=\frac{23+25}{2}=24

相比均值：

> **中位数对异常值更稳健。**

---

## 中列数

这个比较容易被忽略：

Midrange=max⁡+min⁡2\text{Midrange} = \frac{\max+\min}{2}

只使用最大值和最小值。

---

## 众数

出现次数最多的值。

可能：

一个众数、多个众数、没有明显众数。

而且：

> **标称数据也可以算众数。**

# 十九、方差和标准差

方差衡量数据离均值有多远。

课件使用总体形式：

σ2=1N∑i=1N(xi−μ)2\sigma^2 = \frac1N \sum_{i=1}^{N}(x_i-\mu)^2

标准差：

σ=σ2\sigma=\sqrt{\sigma^2}

意义：

> 方差/标准差越大 → 数据越分散。

> 越小 → 数据越集中、稳定。

|对象1=0|ss|tt|

也就是：

qq：两者都是1

r,sr,s：两者不同

tt：两者都是0

---

## 对称二元

0 和 1 同等重要。

因此：

d(i,j)=r+sq+r+s+t\boxed{ d(i,j)=\frac{r+s}{q+r+s+t} }

就是：

> 不同的个数 / 总个数。

---

## 非对称二元

例如疾病。

两个人：

> 都没患病

并不能说明他们很“相似”。

所以把：

tt

即“都为0”忽略。

距离：

d(i,j)=r+sq+r+s\boxed{ d(i,j)=\frac{r+s}{q+r+s} }

Jaccard 相似度：

simJaccard(i,j)=qq+r+s\boxed{ sim_{Jaccard}(i,j) = \frac{q}{q+r+s} }

理解比死背重要：

> **非对称二元只关心 1。**

# 二十五、序数属性怎么计算距离？

比如：

Fair<Good<ExcellentFair<Good<Excellent

rifr_{if}

MfM_f

第二步标准化：

zif=rif−1Mf−1\boxed{ z_{if} = \frac{r_{if}-1}{M_f-1} }

这是标准考试流程题。

# 二十六、数值属性三大距离

## 曼哈顿距离

d(i,j)=∑k=1p∣xik−xjk∣\boxed{ d(i,j) = \sum_{k=1}^{p}|x_{ik}-x_{jk}| }

直觉：

> 走城市街区，横着走 + 竖着走。

也叫：

L1L_1

---

## 欧氏距离

d(i,j)=∑k=1p(xik−xjk)2\boxed{ d(i,j) = \sqrt{ \sum_{k=1}^{p} (x_{ik}-x_{jk})^2 } }

直觉：

> 两点直线距离。

也叫：

L2L_2

---

## 闵可夫斯基距离

把两者统一：

d(i,j)=(∑k=1p∣xik−xjk∣h)1/h\boxed{ d(i,j) = \left( \sum_{k=1}^{p} |x_{ik}-x_{jk}|^h \right)^{1/h} }

当：

h=1h=1

就是曼哈顿距离。

当：

h=2h=2

就是欧氏距离。

当：

h→∞h\rightarrow\infty

变成：

max⁡k∣xik−xjk∣\boxed{ \max_k|x_{ik}-x_{jk}| }

即上确界距离。

# 二十七、什么才叫真正的“距离”？

课件要求满足四个性质：

非负性：

d(i,j)≥0d(i,j)\geq0

同一性：

d(i,i)=0d(i,i)=0

对称性：

d(i,j)=d(j,i)d(i,j)=d(j,i)

三角不等式：

d(i,j)≤d(i,k)+d(k,j)d(i,j)\leq d(i,k)+d(k,j)

这四条很适合选择/判断题。

# 二十八、余弦相似度：必须会公式

sim(v1,v2)=v1⋅v2∥v1∥∥v2∥\boxed{ sim(v_1,v_2) = \frac{v_1\cdot v_2} {\|v_1\|\|v_2\|} }

它比较的不是绝对长度，而主要是：

> **两个向量的方向。**

所以特别适合文本。

例如：

一篇文章出现：

机器学习 100 次、数据 50 次；

另一篇规模只有一半，但词语比例差不多。

两个向量长度差很多，但方向可能接近。

余弦相似度仍然很高。

这也是现代嵌入检索会大量使用余弦相似度的原因。

让：
