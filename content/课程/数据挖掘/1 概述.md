# 1 概述

一句话：数据挖掘 = 从**大量、不完全、有噪声、模糊、随机**的实际数据中，提取**隐含的、事先不知道的、潜在有用**的知识。

## 总览（思维导图）

$$
\text{1 概述}
\begin{cases}
\text{概念链}
\begin{cases}
\text{数据}\to\text{信息}\to\text{知识}\to\text{智慧}\\
\text{挖掘}\neq\text{查询}:\ \text{查询问已知，挖掘找未知}
\end{cases}\\[4pt]
\text{数据特点}
\begin{cases}
\text{海量、高维、异构}\\
\text{非结构化（文本/图像/视频）、特殊结构（时间序列/图）}\\
\text{有噪声}
\end{cases}\\[4pt]
\text{KDD 七步}
\begin{cases}
\text{清}\to\text{集}\to\text{选}\to\text{变}\to\text{挖}\to\text{评}\to\text{表}\\
\text{前四步}=\text{预处理（清理约占 60\% 工作量）}\\
\text{可迭代回退，不是只运行一次}
\end{cases}\\[4pt]
\text{任务}
\begin{cases}
\text{预测性}
\begin{cases}
\text{分类}:\ \text{离散标签}\\
\text{回归}:\ \text{连续值}
\end{cases}\\
\text{描述性}
\begin{cases}
\text{聚类}:\ \text{无标签}\\
\text{关联}:\ X\Rightarrow Y\\
\text{离群点}:\ \text{有时就是目标}
\end{cases}
\end{cases}
\end{cases}
$$

## 考点权重

| 模块                     | 要会什么                 | 考试风险 |
| ------------------------ | ------------------------ | -------- |
| 什么是数据挖掘           | 定义、KDD 流程、主要任务 | 高       |
| 历史、AutoML、Agent、RAG | 知道是什么               | 低~中    |

# 一、数据 → 信息 → 知识 → 智慧

| 层次 | 含义                     | 例子                               |
| ---- | ------------------------ | ---------------------------------- |
| 数据 | 原始记录，未必有明确意义 | $35,38,40,39$                      |
| 信息 | 数据经加工，有了含义     | 某人过去四天体温 $35,38,40,39$ ℃   |
| 知识 | 从信息中总结的规律       | 体温持续升高可能意味着身体状态异常 |
| 智慧 | 用知识分析具体情况并决策 | 据此判断是否就医                   |

$$
\text{数据处理}\to\text{信息},\quad \text{信息建立联系}\to\text{知识},\quad \text{用知识解决新问题}\to\text{智慧}
$$

一句话：**数据是原料，信息是有意义的数据，知识是规律，智慧是用规律解决问题的能力。**

# 二、数据挖掘定义

定义拆成两半背：

| 数据的一侧                                             | 知识的一侧                                     |
| ------------------------------------------------------ | ---------------------------------------------- |
| 大量的、不完全的、有噪声的、模糊的、随机的实际应用数据 | 隐含的、事先不知道的、潜在有用的**信息与知识** |

记忆链：**大量实际数据 →（有噪声/不完整）→ 隐含 → 未知 → 有用 → 知识。**

## 为什么数据库查询不算数据挖掘

| 对比   | 数据库查询                               | 数据挖掘                       |
| ------ | ---------------------------------------- | ------------------------------ |
| 前提   | 你已经知道要问什么                       | 事先不知道规律                 |
| 例     | `SELECT * FROM student WHERE score > 90` | 让算法发现“什么因素和成绩相关” |
| 一句话 | 回答你已经知道怎么问的问题               | 发现你原本不知道的模式         |

# 三、数据挖掘面对的数据特点

| 特点           | 含义                   |
| -------------- | ---------------------- |
| 海量           | 可能到 TB、PB          |
| 高维           | 属性可能成千上万       |
| 复杂、非结构化 | 文本、图像、视频、Web  |
| 特殊结构       | 时间序列、图、社会网络 |
| 异构           | 来源和格式不同         |
| 有噪声         | 错误、异常、缺失       |

结论：不是简单算个平均数，而要处理**大、杂、脏、复杂**的数据。这也是传统统计与数据库不够用的原因。

# 四、挖掘过程 KDD：七步必背

| 顺序 | 步骤         | 干什么                     |
| ---- | ------------ | -------------------------- |
| 1    | 数据清理     | 去噪声、纠正不一致         |
| 2    | 数据集成     | 合并多个数据源             |
| 3    | 数据选择     | 选与任务有关的数据         |
| 4    | 数据变换     | 转成适合挖掘的形式         |
| 5    | 挖掘算法设计 | 分类、聚类、关联规则、回归 |
| 6    | 性能评估     | 判断模式是否真正有用       |
| 7    | 知识表示     | 把结果展示给用户           |

口诀：**清集选变，挖评表。**

| 要点       | 内容                                                   |
| ---------- | ------------------------------------------------------ |
| 预处理范围 | 前四步属于数据预处理                                   |
| 工作量     | 数据清理可能占全过程约 **60%**                         |
| 过程性质   | 不是严格只运行一次；结果不好可回到清理、选特征、调算法 |

# 五、主要任务

## 宏观分类

| 类型   | 思路                                 | 典型任务       |
| ------ | ------------------------------------ | -------------- |
| 预测性 | 已知解释变量 $X_v$，预测未知目标 $Y$ | 分类、回归     |
| 描述性 | 不预测某个答案，发现人可理解的规律   | 聚类、关联规则 |

## 四种主要任务 + 时间序列

| 任务     | 核心                                                      | 例子                             |
| -------- | --------------------------------------------------------- | -------------------------------- |
| 关联分析 | 哪些东西经常一起出现，形式 $X\Rightarrow Y$               | 买尿布的人往往也买啤酒；推荐系统 |
| 分类     | **类别离散 + 训练数据已有标签**                           | 由年龄/收入/信用记录预测是否违约 |
| 聚类     | **事先无标签**，算法自己把相似对象分组                    | 一万个用户自动分组               |
| 回归     | 预测的是**连续数值**                                      | 房价 $=235$ 万                   |
| 时间序列 | 数据带时间顺序 $x_1,x_2,\ldots,x_t$，研究趋势、周期并预测 | 销量预测                         |

分类 vs 聚类（考试最爱）：

| 维度     | 分类               | 聚类                 |
| -------- | ------------------ | -------------------- |
| 标签     | 有标签             | 无标签               |
| 学习方式 | 监督               | 无监督               |
| 目标     | 预测已有类别       | 自动发现群体         |
| 一句话   | 类别已知，学怎么分 | 类别未知，自己找类别 |

离群点：与大部分数据行为明显不同的对象。

| 说法                 | 判断   |
| -------------------- | ------ |
| 多数情况下可能是噪声 | 对     |
| “离群点都是无用噪声” | **错** |

诈骗、异常交易、医疗异常等任务里，离群点恰恰是最想找的东西。

判断口诀：**类别 → 分类，数值 → 回归，没标签分组 → 聚类，找共同出现 → 关联分析。**

# 六、与其他学科的关系

| 学科            | 负责什么                           |
| --------------- | ---------------------------------- |
| 数据库技术      | 管理数据                           |
| 机器学习/统计学 | 分析数据                           |
| 数据挖掘        | 把二者结合，解决大规模真实数据问题 |

即：数据挖掘可认为是**数据库技术 + 机器学习**的交叉；其比较独特的一类任务是**关联分析**。
