## 程序17-1：货箱装船问题的FIFO分枝定界算法

### 问题描述
给定n个集装箱，每个集装箱重量为w[i]，以及一艘载重量为c的船，求在不超过载重量的前提下，第一艘船的最大装载重量。

### 问题分析
使用FIFO（先进先出）分枝定界算法搜索子集空间树。活节点以队列形式组织，按宽度优先顺序扩展。当展开一个E-节点时，生成其左孩子（x[i]=1，装入集装箱i）和右孩子（x[i]=0，不装），可行的孩子加入活节点队列。使用-1作为层尾标记。算法遍历所有可行节点，记录遇到的可行叶节点的最大重量。

**时间复杂度**：O(2^n)（最坏情况下遍历所有子集树节点）
**空间复杂度**：O(2^n)（活节点队列大小）

### 伪代码
```cpp
template<class T>
void AddLiveNode(LinkedQueue<T> &Q, T wt, T& bestw, int i, int n)
{
    // 如果不是叶节点，则将节点权值 wt 加入队列 Q
    if (i == n) {           // 到达叶节点
        if (wt > bestw) bestw = wt;  // 更新最优值
    } else {
        Q.Add(wt);          // 非叶节点加入活节点队列
    }
}

template<class T>
T MaxLoading(T w[], T c, int n)
{
    // 返回最优装载值，使用FIFO分枝定界算法
    LinkedQueue<T> Q;       // 活节点队列
    Q.Add(-1);              // 标记第一层的尾部
    int i = 1;              // E-节点的层
    T Ew = 0;               // E-节点的权值
    T bestw = 0;            // 目前的最优值

    // 搜索子集空间树
    while (true) {
        // 检查E-节点的左孩子（x[i] = 1）
        if (Ew + w[i] <= c) {                           // 左孩子可行
            AddLiveNode(Q, Ew + w[i], bestw, i, n);     // 将左孩子加入队列
        }
        // 右孩子总是可行的（x[i] = 0）
        AddLiveNode(Q, Ew, bestw, i, n);

        Q.Delete(Ew);                                   // 取下一个E-节点
        if (Ew == -1) {                                 // 到达层的尾部
            if (Q.IsEmpty()) return bestw;
            Q.Add(-1);                                  // 添加下一层的尾部标记
            Q.Delete(Ew);                               // 取下一个E-节点
            i++;                                        // E-节点层数加1
        }
    }
}
```

## 程序17-2：对程序17-1改进之后

### 问题描述
改进FIFO分枝定界算法，使用剩余重量进行剪枝，提前更新bestw以增强右孩子的剪枝效果。

### 问题分析
在程序17-1中，bestw在到达叶节点之前一直为0，导致右孩子测试始终通过。改进方法：每次向左孩子移动（即装入集装箱）时立即更新bestw；同时记录剩余集装箱总重量r，只有当"当前重量+剩余重量>bestw"时，右孩子才有可能产生更优解。这样可减少不必要的节点展开。

**时间复杂度**：O(2^n)，但实际展开节点数比程序17-1少
**空间复杂度**：O(2^n)

### 伪代码
```cpp
template<class T>
T MaxLoading(T w[], T c, int n)
{
    // 返回最优装载值，使用改进FIFO分枝定界算法
    LinkedQueue<T> Q;       // 活节点队列
    Q.Add(-1);              // 标记本层的尾部
    int i = 1;              // E-节点的层
    T Ew = 0;               // E-节点的重量
    T bestw = 0;            // 目前的最优值
    T r = 0;                // E-节点中余下的重量
    for (int j = 2; j <= n; j++)
        r += w[j];

    // 搜索子集空间树
    while (true) {
        // 检查E-节点的左孩子
        T wt = Ew + w[i];                       // 左孩子的权值
        if (wt <= c) {                          // 可行的左孩子
            if (wt > bestw) bestw = wt;         // 提前更新最优值
            if (i < n) Q.Add(wt);               // 非叶节点加入队列
        }
        // 检查右孩子：仅当有可能找到更优解时才加入
        if (Ew + r > bestw && i < n)
            Q.Add(Ew);

        Q.Delete(Ew);                           // 取下一个E-节点
        if (Ew == -1) {                         // 到达层的尾部
            if (Q.IsEmpty()) return bestw;
            Q.Add(-1);                          // 添加下一层尾部标记
            Q.Delete(Ew);                       // 取下一个E-节点
            i++;                                // E-节点层数加1
            r -= w[i];                          // 更新剩余重量
        }
    }
}
```

## 程序17-3：类QNode

### 问题描述
定义记录路径的节点类，用于在找到最优装载后回溯构造最优子集。

### 问题分析
QNode类包含三个成员：parent（父节点指针）、LChild（该节点是否为父节点的左孩子）、weight（节点对应的部分解重量）。当找到最优装载对应的叶节点后，沿parent指针回溯即可构造出最优子集x[]。

### 伪代码
```cpp
template<class T>
class QNode {
private:
    QNode *parent;      // 父节点指针
    bool LChild;        // 当且仅当是父节点的左孩子时，取值为true
    T weight;           // 由到达本节点的路径所定义的部分解的值
};
```

## 程序17-4：计算最优子集的分枝定界算法

### 问题描述
在求出最大装载重量的同时，记录最优子集（即哪些集装箱应装入第一艘船）。

### 问题分析
本算法扩展了程序17-2的功能。AddLiveNode在叶节点处记录最优路径（通过bestE和bestx[n]）。搜索结束后，沿bestE回溯构造x[]：若节点是父节点的左孩子，则x[j]=1；否则x[j]=0。算法同时使用了剩余重量r进行右孩子剪枝。

**时间复杂度**：O(2^n)
**空间复杂度**：O(2^n)

### 伪代码
```cpp
template<class T>
void AddLiveNode(LinkedQueue<QNode<T>*>& Q, T wt, int i, int n,
                 T bestw, QNode<T>* E, QNode<T>*& bestE, int bestx[], bool ch)
{
    // 向队列 Q 中添加一个 i 层、重量为 wt 的活节点
    // 新节点是 E 的一个孩子，当且仅当新节点是左孩子时，ch 为true
    if (i == n) {                   // 到达叶节点
        if (wt == bestw) {          // 属于最优解
            bestE = E;              // 记录最优解的父节点
            bestx[n] = ch;          // 设置x[n]
        }
        return;
    }
    // 非叶节点，添加到队列中
    QNode<T> *b = new QNode<T>;
    b->weight = wt;
    b->parent = E;
    b->LChild = ch;
    Q.Add(b);
}

template<class T>
T MaxLoading(T w[], T c, int n, int bestx[])
{
    // 返回最优装载值，并在 bestx 中返回最优装载方案
    // 使用FIFO分枝定界算法
    LinkedQueue<QNode<T>*> Q;   // 活节点队列，存储QNode指针
    Q.Add(0);                    // 0代表本层的尾部
    int i = 1;                   // E-节点的层
    T Ew = 0;                    // E-节点的重量
    T bestw = 0;                 // 迄今得到的最优值
    T r = 0;                     // E-节点中余下的重量
    for (int j = 2; j <= n; j++)
        r += w[j];

    QNode<T> *E = 0;             // 当前的E-节点
    QNode<T> *bestE;             // 目前最优的E-节点

    // 搜索子集空间树
    while (true) {
        // 检查E-节点的左孩子
        T wt = Ew + w[i];
        if (wt <= c) {                              // 可行的左孩子
            if (wt > bestw) bestw = wt;
            AddLiveNode(Q, wt, i, n, bestw, E, bestE, bestx, true);
        }
        // 检查右孩子
        if (Ew + r > bestw)
            AddLiveNode(Q, Ew, i, n, bestw, E, bestE, bestx, false);

        Q.Delete(E);                                // 下一个E-节点
        if (!E) {                                   // 到达层的尾部
            if (Q.IsEmpty()) break;
            Q.Add(0);                               // 层尾指针
            Q.Delete(E);                            // 下一个E-节点
            i++;                                    // E-节点的层次
            r -= w[i];                              // 更新剩余重量
        }
        Ew = E->weight;                             // 新的E-节点的重量
    }

    // 沿着从bestE到根的路径构造x[]
    for (int j = n - 1; j > 0; j--) {
        bestx[j] = bestE->LChild;   // 从bool转换为int
        bestE = bestE->parent;
    }
    return bestw;
}
```

## 程序17-5：bbnode和HeapNode类

### 问题描述
定义用于最大收益分枝定界的数据结构：bbnode表示子集树中的节点，HeapNode表示最大堆中的活节点。

### 问题分析
bbnode包含parent指针和LChild标志，用于构造部分解空间树。HeapNode包含ptr（指向bbnode的指针）、uweight（重量上限）和level（层数），按uweight降序从最大堆中取出。HeapNode重载了类型转换运算符T()，返回uweight，使最大堆能按uweight排序。

### 伪代码
```cpp
// 子集树中的节点类
class bbnode {
private:
    bbnode *parent;     // 父节点指针
    bool LChild;        // 当且仅当是父节点的左孩子时，取值为true
};

// 最大堆中的活节点类
template<class T>
class HeapNode {
public:
    operator T () const { return uweight; }  // 返回重量上限，用于堆排序
private:
    bbnode *ptr;         // 活节点在子集树中的位置指针
    T uweight;           // 活节点的重量上限
    int level;           // 活节点所在层
};
```

## 程序17-6：AddLiveNode（最大收益分枝定界的AddLiveNode和MaxLoading）

### 问题描述
实现货箱装船问题的最大收益分枝定界算法，使用最大堆存储活节点，按重量上限降序扩展。

### 问题分析
本算法维护一个部分解空间树（由bbnode组成）和一个最大堆。每个活节点包含重量上限uweight，即当前重量+剩余所有集装箱重量。算法总是从最大堆中取出uweight最大的节点作为下一个E-节点。当展开到叶节点时，沿parent指针回溯得到最优装载方案。使用剩余重量数组r[]加速定界计算。

**时间复杂度**：O(2^n)
**空间复杂度**：O(2^n)

### 伪代码
```cpp
template<class T>
void AddLiveNode(MaxHeap<HeapNode<T>>& H, bbnode* E, T wt, bool ch, int lev)
{
    // 向最大堆H中增添一个层为lev、上限重量为wt的活节点
    // 新节点是E的一个孩子，当且仅当新节点是左孩子时ch为true
    bbnode *b = new bbnode;
    b->parent = E;
    b->LChild = ch;
    HeapNode<T> N;
    N.uweight = wt;     // 重量上限 = 当前重量 + 剩余重量
    N.level = lev;      // 节点层数
    N.ptr = b;          // 指向子集树中的节点
    H.Insert(N);        // 插入最大堆
}

template<class T>
T MaxLoading(T w[], T c, int n, int bestx[])
{
    // 返回最优装载值，最优装载方案保存于 bestx
    // 使用最大收益分枝定界算法

    // 定义一个最多有1000个活节点的最大堆
    MaxHeap<HeapNode<T>> H(1000);

    // 计算剩余重量数组 r[j] = w[j+1:n] 的重量之和
    T *r = new T[n + 1];
    r[n] = 0;
    for (int j = n - 1; j > 0; j--)
        r[j] = r[j + 1] + w[j + 1];

    // 初始化层1
    int i = 1;              // E-节点的层
    bbnode *E = 0;          // 当前E-节点（根节点）
    T Ew = 0;               // E-节点的重量

    // 搜索子集空间树
    while (i != n + 1) {    // 未到达叶节点
        // 检查E-节点的左孩子
        if (Ew + w[i] <= c) {   // 可行的左孩子
            AddLiveNode(H, E, Ew + w[i] + r[i], true, i + 1);
        }
        // 右孩子
        AddLiveNode(H, E, Ew + r[i], false, i + 1);

        // 取下一个E-节点（重量上限最大的节点）
        HeapNode<T> N;
        H.DeleteMax(N);
        i = N.level;            // 更新层数
        E = N.ptr;              // 更新节点指针
        Ew = N.uweight - r[i - 1];  // 计算实际重量
    }

    // 沿着从E-节点E到根的路径构造bestx[]
    for (int j = n; j > 0; j--) {
        bestx[j] = E->LChild;   // 从bool转换为int
        E = E->parent;          // 回溯到父节点
    }
    return Ew;                  // 返回最优装载值
}
```

## 程序17-7：0/1背包问题的最大收益分枝定界算法

### 问题描述
给定n个物品，每个物品有重量w[i]和收益p[i]，背包容量为c，求在不超过背包容量的前提下，使总收益最大的物品子集。

### 问题分析
本算法使用最大收益分枝定界搜索子集空间树。每个活节点包含收益上限uprofit，按uprofit降序从最大堆中取出。使用Bound函数计算收益上限。当展开到叶节点时，该叶节点即为最优解。左孩子可行时（重量不超）加入堆，右孩子仅当收益上限>=当前最优收益时加入堆。

**时间复杂度**：O(2^n)
**空间复杂度**：O(2^n)（受限于最大堆大小1000）

### 伪代码
```cpp
template<class Tw, class Tp>
Tp Knap<Tw, Tp>::MaxProfitKnapsack()
{
    // 返回背包最优装载的收益，bestx[i]=1当且仅当物品i属于最优装载
    // 使用最大收益分枝定界算法

    // 定义一个最多可容纳1000个活节点的最大堆
    H = new MaxHeap<HeapNode<Tp, Tw>>(1000);
    bestx = new int[n + 1];     // 为最优解分配空间

    // 初始化层1
    int i = 1;                  // E-节点的层
    E = 0;                      // 当前E-节点（根）
    cw = 0;                     // 当前重量
    cp = 0;                     // 当前收益
    Tp bestp = 0;               // 目前的最优收益
    Tp up = Bound(1);           // 根节点子树的最大可能收益上限

    // 搜索子集空间树
    while (i != n + 1) {        // 不是叶节点
        // 检查左孩子（x[i] = 1）
        Tw wt = cw + w[i];
        if (wt <= c) {                              // 可行的左孩子
            if (cp + p[i] > bestp) bestp = cp + p[i];
            AddLiveNode(up, cp + p[i], cw + w[i], true, i + 1);
        }
        up = Bound(i + 1);                          // 计算右孩子的收益上限

        // 检查右孩子（x[i] = 0）
        if (up >= bestp)                            // 右孩子有可能找到更优解
            AddLiveNode(up, cp, cw, false, i + 1);

        // 取下一个E-节点（收益上限最大的节点）
        HeapNode<Tp, Tw> N;
        H->DeleteMax(N);
        E = N.ptr;              // 更新节点指针
        cw = N.weight;          // 更新当前重量
        cp = N.profit;          // 更新当前收益
        up = N.uprofit;         // 更新收益上限
        i = N.level;            // 更新层数
    }

    // 沿着从E-节点E到根的路径构造bestx[]
    for (int j = n; j > 0; j--) {
        bestx[j] = E->LChild;
        E = E->parent;
    }
    return cp;                  // 返回最优收益
}
```

## 程序17-8：最大完备子图问题的分枝定界算法

### 问题描述
给定一个无向图，求包含顶点数最多的完全子图（最大完备子图/最大团）。

### 问题分析
本算法使用最大收益分枝定界搜索子集空间树。每个CliqueNode包含cn（当前完备子图大小）、un（子树中可能的最大完备子图尺寸=cn+n-level+1）、level（层数）、ptr（指向bbnode的指针）。按un值降序从最大堆中取出节点。左孩子可行条件：顶点i与当前E-节点中所有顶点都有边相连。只有当右孩子的un>=bestn时才加入堆。

**时间复杂度**：O(2^n)
**空间复杂度**：O(2^n)

### 伪代码
```cpp
int AdjacencyGraph::BBMaxClique(int bestx[])
{
    // 寻找一个最大完备子图的最大收益分枝定界程序
    // 定义一个最多可容纳1000个活节点的最大堆
    MaxHeap<CliqueNode> H(1000);

    // 初始化层1
    bbnode *E = 0;              // 当前的E-节点为根
    int i = 1;                  // E-节点的层
    int cn = 0;                 // 完备子图的大小
    int bestn = 0;              // 目前最大完备子图的大小

    // 搜索子集空间树
    while (i != n + 1) {        // 不是叶节点
        // 检查顶点i是否与当前完备子图中的所有顶点相连
        bool OK = true;
        bbnode *B = E;
        for (int j = i - 1; j > 0; B = B->parent, j--) {
            if (B->LChild && a[i][j] == NoEdge) {
                OK = false;     // 顶点i与当前子图中的某个顶点无边相连
                break;
            }
        }
        if (OK) {               // 左孩子可行，将i加入完备子图
            if (cn + 1 > bestn) bestn = cn + 1;
            AddCliqueNode(H, cn + 1, cn + n - i + 1, i + 1, E, true);
        }
        // 右孩子：当un >= bestn时可能找到更大的完备子图
        if (cn + n - i >= bestn)
            AddCliqueNode(H, cn, cn + n - i, i + 1, E, false);

        // 取下一个E-节点（un值最大的节点）
        CliqueNode N;
        H.DeleteMax(N);
        E = N.ptr;              // 更新节点指针
        cn = N.cn;              // 更新完备子图大小
        i = N.level;            // 更新层数
    }

    // 沿着从E到根的路径构造bestx[]
    for (int j = n; j > 0; j--) {
        bestx[j] = E->LChild;
        E = E->parent;
    }
    return bestn;               // 返回最大完备子图的大小
}
```

## 程序17-9：旅行商问题的最小耗费分枝定界算法

### 问题描述
给定一个有向图（n个顶点，边上有耗费），求从顶点1出发，经过每个顶点恰好一次再回到顶点1的最短路径（即最小耗费的哈密顿回路）。

### 问题分析
本算法使用最小耗费分枝定界搜索排列树。每个MinHeapNode包含：x（当前顶点排列）、s（已确定的路径长度）、cc（当前路径耗费）、lcost（子树中任意叶节点的最小耗费下限）、rcost（剩余顶点出边最小耗费之和）。按下限lcost升序从最小堆中取出节点。当下限lcost>=bestc时剪枝。

**时间复杂度**：O(n!)
**空间复杂度**：O(n!)（受限于最小堆大小1000）

### 伪代码
```cpp
template<class T>
T AdjacencyWDigraph<T>::BBTSP(int v[])
{
    // 旅行商问题的最小耗费分枝定界算法
    // 定义一个最多可容纳1000个活节点的最小堆
    MinHeap<MinHeapNode<T>> H(1000);

    // 计算MinOut[i] = 离开顶点i的最小耗费边的耗费
    T *MinOut = new T[n + 1];
    T MinSum = 0;
    for (int i = 1; i <= n; i++) {
        T Min = NoEdge;
        for (int j = 1; j <= n; j++) {
            if (a[i][j] != NoEdge && (a[i][j] < Min || Min == NoEdge))
                Min = a[i][j];
        }
        if (Min == NoEdge) return NoEdge;   // 没有出边，无旅行路径
        MinOut[i] = Min;
        MinSum += Min;                      // 所有顶点最小出边耗费之和
    }

    // 把E-节点初始化为树根
    MinHeapNode<T> E;
    E.x = new int[n];
    for (i = 0; i < n; i++)
        E.x[i] = i + 1;                     // 初始排列为1,2,...,n
    E.s = 0;                                // 局部旅行路径为x[1:0]
    E.cc = 0;                               // 当前耗费为0
    E.rcost = MinSum;                       // 剩余顶点最小出边耗费之和
    T bestc = NoEdge;                       // 目前没有找到旅行路径

    // 搜索排列树
    while (E.s < n - 1) {                   // 不是叶节点
        if (E.s == n - 2) {                 // 叶子的父节点
            // 通过添加两条边来完成旅行
            if (a[E.x[n-2]][E.x[n-1]] != NoEdge &&
                a[E.x[n-1]][1] != NoEdge &&
                (E.cc + a[E.x[n-2]][E.x[n-1]] + a[E.x[n-1]][1] < bestc ||
                 bestc == NoEdge)) {
                // 找到更优的旅行路径
                bestc = E.cc + a[E.x[n-2]][E.x[n-1]] + a[E.x[n-1]][1];
                E.cc = bestc;
                E.lcost = bestc;
                E.s++;
                H.Insert(E);
            } else {
                delete[] E.x;
            }
        } else {                            // 产生孩子
            for (int i = E.s + 1; i < n; i++) {
                if (a[E.x[E.s]][E.x[i]] != NoEdge) {
                    // 可行的孩子，计算路径耗费下限
                    T cc = E.cc + a[E.x[E.s]][E.x[i]];
                    T rcost = E.rcost - MinOut[E.x[E.s]];
                    T b = cc + rcost;       // 耗费下限
                    if (b < bestc || bestc == NoEdge) {
                        // 子树可能有更好的叶子，加入最小堆
                        MinHeapNode<T> N;
                        N.x = new int[n];
                        for (int j = 0; j < n; j++)
                            N.x[j] = E.x[j];
                        // 交换，将x[i]放在路径的下一位置
                        N.x[E.s + 1] = E.x[i];
                        N.x[i] = E.x[E.s + 1];
                        N.cc = cc;
                        N.s = E.s + 1;
                        N.lcost = b;
                        N.rcost = rcost;
                        H.Insert(N);
                    }
                }
            }
            delete[] E.x;                   // 当前E-节点处理完毕
        }

        // 取下一个E-节点（lcost值最小的节点）
        try {
            H.DeleteMin(E);
        } catch (OutOfBounds) {
            break;                          // 没有未处理的节点
        }
    }

    if (bestc == NoEdge) return NoEdge;     // 没有旅行路径

    // 将最优路径复制到v[1:n]中
    for (i = 0; i < n; i++)
        v[i + 1] = E.x[i];

    // 释放最小堆中的所有节点
    while (true) {
        delete[] E.x;
        try {
            H.DeleteMin(E);
        } catch (OutOfBounds) {
            break;
        }
    }
    return bestc;                           // 返回最优耗费
}
```

## 程序17-10：电路板排列问题的最小耗费分枝定界算法

### 问题描述
给定n块电路板和m个插槽，每块电路板包含若干插槽（由矩阵B[i][j]表示，B[i][j]=1表示电路板i包含插槽j），求一种电路板排列，使得最小化最大连线密度（即任意位置左侧已放置电路板中，包含某插槽但该插槽的电路板尚未全部放置完毕的插槽数量）。

### 问题分析
本算法使用最小耗费分枝定界搜索排列树。每个BoardNode包含：x（电路板排列）、s（已放置的电路板数）、cd（当前密度）、now（当前已包含各插槽的电路板数）。按下限cd升序从最小堆中取出节点。当当前密度>=当前最优密度时剪枝。使用total数组记录包含各插槽的电路板总数，用于判断是否还有未处理的电路板。

**时间复杂度**：O(n!)（最坏情况）
**空间复杂度**：O(n!)（受限于最小堆大小1000）

### 伪代码
```cpp
int BBArrangeBoards(int **B, int n, int m, int* &bestx)
{
    // 最小耗费分枝定界算法，m个插槽，n块板
    MinHeap<BoardNode> H(1000);         // 容纳活节点的最小堆

    // 初始化第一个E-节点、total和bestd
    BoardNode E;
    E.x = new int[n + 1];
    E.s = 0;                            // 局部排列为E.x[1:s]
    E.cd = 0;                           // E.x[1:s]的密度
    E.now = new int[m + 1];
    int *total = new int[m + 1];
    // now[i] = x[1:s]中含插槽i的板的数目
    // total[i] = 含插槽i的板的总数目
    for (int i = 1; i <= m; i++) {
        total[i] = 0;
        E.now[i] = 0;
    }
    for (i = 1; i <= n; i++) {
        E.x[i] = i;                     // 初始排列为1,2,3,...,n
        for (int j = 1; j <= m; j++)
            total[j] += B[i][j];        // 统计包含插槽j的电路板总数
    }
    int bestd = m + 1;                  // 目前的最优密度（初始化为最大值）
    bestx = 0;                          // 空指针

    // 扩展E-节点
    do {
        if (E.s == n - 1) {             // 仅有一个孩子（最后一块板）
            int ld = 0;                 // 最后一块板的局部密度
            for (int j = 1; j <= m; j++)
                ld += B[E.x[n]][j];     // 最后一块板包含的插槽数即为局部密度
            if (ld < bestd) {           // 找到更优的排列
                delete[] bestx;
                bestx = E.x;
                bestd = max(ld, E.cd);  // 更新最优密度
            } else {
                delete[] E.x;
            }
            delete[] E.now;
        } else {                        // 生成E-节点的孩子
            for (int i = E.s + 1; i <= n; i++) {
                BoardNode N;
                N.now = new int[m + 1];
                for (int j = 1; j <= m; j++)
                    // 在新板中对插槽计数
                    N.now[j] = E.now[j] + B[E.x[i]][j];

                int ld = 0;             // 新板的局部密度
                for (j = 1; j <= m; j++) {
                    // 插槽j有电路板但尚未全部到齐，则密度加1
                    if (N.now[j] > 0 && total[j] != N.now[j])
                        ld++;
                }
                N.cd = max(ld, E.cd);   // 新的密度取局部密度和原密度的较大值
                if (N.cd < bestd) {     // 可能会引向更好的叶子
                    N.x = new int[n + 1];
                    N.s = E.s + 1;
                    for (int j = 1; j <= n; j++)
                        N.x[j] = E.x[j];
                    // 交换，将E.x[i]放在排列的下一位置
                    N.x[N.s] = E.x[i];
                    N.x[i] = E.x[N.s];
                    H.Insert(N);
                } else {
                    delete[] N.now;
                }
            }
            delete[] E.x;               // 处理完当前E-节点
        }
        // 取下一个E-节点（cd值最小的节点）
        try {
            H.DeleteMin(E);
        } catch (OutOfBounds) {
            return bestd;               // 没有E-节点，返回最优密度
        }
    } while (E.cd < bestd);             // 当前节点密度>=bestd时终止

    // 释放最小堆中的所有节点
    do {
        delete[] E.x;
        delete[] E.now;
        try {
            H.DeleteMin(E);
        } catch (...) {
            break;
        }
    } while (true);

    return bestd;                       // 返回最优密度
}
```
