# 第14章 分而治之算法

## 程序14-1：找出最小值和最大值的非递归程序

### 问题描述
给定一个数组 `w[0:n-1]`，找出其中的最小值和最大值，返回其下标。

### 问题分析
该程序基于分而治之思想，采用非递归方式实现。将元素两两配对进行比较，每对中较小的与当前最小值比较，较大的与当前最大值比较。当 n 为偶数时比较总次数为 3n/2-2，当 n 为奇数时比较总次数也为 ⌈3n/2⌉-2。该算法在比较次数上是最优的，因为最小最大问题的比较次数下限为 ⌈3n/2⌉-2。

### 伪代码
```cpp
template<class T>
bool MinMax(T w[], int n, T& Min, T& Max)
{// 寻找 w[0:n-1] 中的最小和最大值
 // 如果少于一个元素，则返回 false
    // 特殊情形：n <= 1
    if (n < 1) return false;
    if (n == 1) {
        Min = Max = 0;
        return true;
    }
    // 对 Min 和 Max 进行初始化
    int s;  // 循环起点
    if (n % 2) {  // n 为奇数，以第一个元素作为初始候选
        Min = Max = 0;
        s = 1;
    } else {  // n 为偶数，先比较第一对
        if (w[0] > w[1]) {
            Min = 1;
            Max = 0;
        } else {
            Min = 0;
            Max = 1;
        }
        s = 2;
    }
    // 比较余下的数对
    for (int i = s; i < n; i += 2) {
        // 寻找 w[i] 和 w[i+1] 中的较大者
        // 然后将较大者与 w[Max] 进行比较
        // 将较小者与 w[Min] 进行比较
        if (w[i] > w[i+1]) {
            if (w[i] > w[Max]) Max = i;
            if (w[i+1] < w[Min]) Min = i + 1;
        } else {
            if (w[i+1] > w[Max]) Max = i + 1;
            if (w[i] < w[Min]) Min = i;
        }
    }
    return true;
}
```

## 程序14-2：覆盖残缺棋盘

### 问题描述
残缺棋盘是一个 $2^k \times 2^k$ 的棋盘，恰有一个方格残缺。需要用三格板（trominoes）覆盖所有非残缺方格，要求三格板之间不重叠，且不覆盖残缺方格。所需三格板总数为 $(2^{2k}-1)/3$。

### 问题分析
采用分而治之策略：将 $2^k \times 2^k$ 棋盘划分为 4 个 $2^{k-1} \times 2^{k-1}$ 的小棋盘。其中一个小棋盘包含残缺方格，其余三个小棋盘通过在它们的交界处置放一块三格板来"人为制造"残缺方格，从而将问题转化为 4 个相同规模的子问题。递归进行直到棋盘大小为 1×1（仅有残缺方格，无需覆盖）。算法时间复杂度为 $\Theta(4^k)$。

### 伪代码
```cpp
// 全局变量：Board 为二维数组表示棋盘，tile 为当前使用的三格板编号
// 参数：tr, tc 为当前棋盘左上角行列号
//       dr, dc 为残缺方格位置
//       size 为棋盘大小

void TileBoard(int tr, int tc, int dr, int dc, int size)
{// 覆盖残缺棋盘
    if (size == 1) return;
    int t = tile++;   // 当前所使用的三格板编号
    int s = size / 2; // 子棋盘大小

    // 覆盖左上象限
    if (dr < tr + s && dc < tc + s)
        // 残缺方格位于本象限，递归覆盖
        TileBoard(tr, tc, dr, dc, s);
    else {
        // 本象限中没有残缺方格，将三格板 t 放在右下角
        Board[tr + s - 1][tc + s - 1] = t;
        // 覆盖其余部分
        TileBoard(tr, tc, tr + s - 1, tc + s - 1, s);
    }

    // 覆盖右上象限
    if (dr < tr + s && dc >= tc + s)
        // 残缺方格位于本象限
        TileBoard(tr, tc + s, dr, dc, s);
    else {
        // 本象限中没有残缺方格，将三格板 t 放在左下角
        Board[tr + s - 1][tc + s] = t;
        TileBoard(tr, tc + s, tr + s - 1, tc + s, s);
    }

    // 覆盖左下象限
    if (dr >= tr + s && dc < tc + s)
        // 残缺方格位于本象限
        TileBoard(tr + s, tc, dr, dc, s);
    else {
        // 本象限中没有残缺方格，将三格板 t 放在右上角
        Board[tr + s][tc + s - 1] = t;
        TileBoard(tr + s, tc, tr + s, tc + s - 1, s);
    }

    // 覆盖右下象限
    if (dr >= tr + s && dc >= tc + s)
        // 残缺方格位于本象限
        TileBoard(tr + s, tc + s, dr, dc, s);
    else {
        // 本象限中没有残缺方格，将三格板 t 放在左上角
        Board[tr + s][tc + s] = t;
        TileBoard(tr + s, tc + s, tr + s, tc + s, s);
    }
}
```

## 程序14-3：二路归并排序

### 问题描述
对数组 `a[0:n-1]` 中的元素进行非递减排序。

### 问题分析
采用非递归的二路归并排序算法。初始时每个元素视为大小为 1 的有序段，然后反复将相邻的有序段两两归并，每趟归并后段的大小翻倍，直到整个数组有序。通过轮流将元素从 a 归并到 b 再从 b 归并到 a，可以消除复制过程。时间复杂度为 $\Theta(n \log n)$。

### 伪代码
```cpp
template<class T>
void MergeSort(T a[], int n)
{// 使用归并排序算法对 a[0:n-1] 进行排序
    T *b = new T[n];
    int s = 1;  // 段的大小
    while (s < n) {
        MergePass(a, b, s, n);  // 从 a 归并到 b
        s += s;
        MergePass(b, a, s, n);  // 从 b 归并到 a
        s += s;
    }
}
```

## 程序14-4：MergePass函数

### 问题描述
对数组中大小为 s 的相邻有序段进行归并。

### 问题分析
遍历整个数组，每两个大小为 s 的相邻段调用 Merge 函数进行归并。如果最后剩余一个完整段和半个段，则对它们进行归并；如果只剩下一个完整段（不足两个段），则直接复制到目标数组。

### 伪代码
```cpp
template<class T>
void MergePass(T x[], T y[], int s, int n)
{// 归并大小为 s 的相邻段
    int i = 0;
    while (i <= n - 2 * s) {
        // 归并两个大小为 s 的相邻段
        Merge(x, y, i, i + s - 1, i + 2 * s - 1);
        i = i + 2 * s;
    }
    // 剩下不足 2 个段
    if (i + s < n)
        Merge(x, y, i, i + s - 1, n - 1);
    else
        for (int j = i; j <= n - 1; j++)
            // 把最后一段复制到 y
            y[j] = x[j];
}
```

## 程序14-5：Merge函数

### 问题描述
将两个相邻的有序子数组 `c[l:m]` 和 `c[m+1:r]` 归并到 `d[l:r]`。

### 问题分析
使用三个游标分别指向第一段、第二段和结果数组的当前位置。比较两段当前元素，将较小的放入结果数组，然后移动相应游标。当一个段处理完毕后，将另一个段的剩余元素直接复制到结果数组。

### 伪代码
```cpp
template<class T>
void Merge(T c[], T d[], int l, int m, int r)
{// 把 c[l:m] 和 c[m+1:r] 归并到 d[l:r]
    int i = l,    // 第一段的游标
        j = m + 1,// 第二段的游标
        k = l;    // 结果数组的游标

    // 只要在两段中都存在元素，则不断进行归并
    while ((i <= m) && (j <= r))
        if (c[i] <= c[j])
            d[k++] = c[i++];
        else
            d[k++] = c[j++];

    // 处理余下的部分
    if (i > m)  // 第一段已处理完，复制第二段剩余元素
        for (int q = j; q <= r; q++)
            d[k++] = c[q];
    else  // 第二段已处理完，复制第一段剩余元素
        for (int q = i; q <= m; q++)
            d[k++] = c[q];
}
```

## 图14-6：分而治之排序算法的伪代码

### 问题描述
对 n 个元素进行排序的通用分而治之算法框架。

### 问题分析
将元素集合分成两个子集 A 和 B，分别递归排序后再归并。参数 k 控制子集划分的比例，其中 A 包含前 n/k 个元素，B 包含其余 n-n/k 个元素。当子集大小小于 k 时直接使用插入排序。当 k=2 时即为标准的二路归并排序，具有最佳性能。

### 伪代码
```cpp
template<class T>
void sort(T E[], int n)
{// 对 E 中的 n 个元素进行排序，k 为全局变量
    if (n >= k) {
        i = n / k;
        j = n - i;
        // 令 A 包含 E 中的前 i 个元素
        // 令 B 包含 E 中余下的 j 个元素
        sort(A, i);
        sort(B, j);
        merge(A, B, E, i, j);  // 把 A 和 B 合并到 E
    } else {
        // 使用插入排序算法对 E 进行排序
    }
}
```

## 图14-7：分而治之排序算法的改进

### 问题描述
对图14-6通用分而治之排序算法的改进版本，使用数组下标来表示子集边界，避免元素的物理复制。

### 问题分析
当 k=2 时即为归并排序。改进之处在于：不再将元素复制到新数组 A 和 B，而是用 left 和 right 下标在原数组上划分子集。归并时先将结果归并到辅助数组 b，再复制回原数组 a。时间复杂度为 $\Theta(n \log n)$。

### 伪代码
```cpp
template<class T>
void MergeSort(T a[], int left, int right)
{// 对 a[left:right] 中的元素进行排序
    if (left < right) {  // 至少有两个元素
        int i = (left + right) / 2;  // 中心位置
        MergeSort(a, left, i);
        MergeSort(a, i + 1, right);
        Merge(a, b, left, i, right);  // 从 a 合并到 b
        Copy(b, a, left, right);      // 结果放回 a
    }
}
```

## 程序14-6：快速排序

### 问题描述
对数组 `a[0:n-1]` 进行快速排序。

### 问题分析
选择一个元素作为支点（pivot），将数组分为三段：左段（元素 ≤ 支点）、中段（支点元素）、右段（元素 ≥ 支点）。递归地对左段和右段排序。最坏情况下时间复杂度为 $\Theta(n^2)$，平均时间复杂度为 $\Theta(n \log n)$。

### 伪代码
```cpp
template<class T>
void QuickSort(T* a, int n)
{// 对 a[0:n-1] 进行快速排序，要求 a[n] 有最大关键值
    quickSort(a, 0, n-1);
}

template<class T>
void quickSort(T a[], int l, int r)
{// 排序 a[l:r]，a[r+1] 有最大值
    if (l >= r) return;
    int i = l,     // 从左至右的游标
        j = r + 1; // 从右到左的游标
    T pivot = a[l];

    // 把左侧 >= pivot 的元素与右侧 <= pivot 的元素进行交换
    while (true) {
        do {  // 在左侧寻找 >= pivot 的元素
            i = i + 1;
        } while (a[i] < pivot);
        do {  // 在右侧寻找 <= pivot 的元素
            j = j - 1;
        } while (a[j] > pivot);
        if (i >= j) break;  // 未发现交换对象
        Swap(a[i], a[j]);
    }

    // 设置 pivot
    a[l] = a[j];
    a[j] = pivot;

    quickSort(a, l, j-1);  // 对左段排序
    quickSort(a, j+1, r);  // 对右段排序
}
```

## 程序14-7：寻找第k个元素

### 问题描述
在数组 `a[0:n-1]` 中找出第 k 小的元素。

### 问题分析
基于快速排序的划分思想。选取支点后将数组分为左右两段，根据支点在第几小决定递归方向：若支点正好是第 k 个元素则返回，否则只在包含第 k 个小元素的那一侧递归（另一侧被舍弃）。因此只需 0 次或 1 次递归调用。平均时间复杂度为 $\Theta(n)$。

### 伪代码
```cpp
template<class T>
T Select(T a[], int n, int k)
{// 返回 a[0:n-1] 中第 k 小的元素
 // 假定 a[n] 是一个伪最大元素
    if (k < 1 || k > n) throw OutOfBounds();
    return select(a, 0, n-1, k);
}

template<class T>
T select(T a[], int l, int r, int k)
{// 在 a[l:r] 中选择第 k 小的元素
    if (l >= r) return a[l];
    int i = l,     // 从左至右的游标
        j = r + 1; // 从右到左的游标
    T pivot = a[l];

    // 把左侧 >= pivot 的元素与右侧 <= pivot 的元素进行交换
    while (true) {
        do {  // 在左侧寻找 >= pivot 的元素
            i = i + 1;
        } while (a[i] < pivot);
        do {  // 在右侧寻找 <= pivot 的元素
            j = j - 1;
        } while (a[j] > pivot);
        if (i >= j) break;  // 未发现交换对象
        Swap(a[i], a[j]);
    }

    if (j - l + 1 == k) return pivot;

    // 设置 pivot
    a[l] = a[j];
    a[j] = pivot;

    // 只对包含第 k 小元素的一段进行递归
    if (j - l + 1 < k)
        // 第 k 小元素在右段
        return select(a, j + 1, r, k - j + l - 1);
    else
        // 第 k 小元素在左段
        return select(a, l, j - 1, k);
}
```

## 程序14-8：点类

### 问题描述
定义用于最近点对问题的点类 Point1 和 Point2。

### 问题分析
Point1 用于按 x 坐标排序，包含点的编号 ID、x 坐标和 y 坐标。Point2 用于按 y 坐标排序，除了 x、y 坐标外还包含指向 Point1 数组中对应点的索引 p。两个类均重载了 `<=` 操作符以支持排序。

### 伪代码
```cpp
class Point1 {
    friend float dist(const Point1&, const Point1&);
    friend void close(Point1*, Point2*, Point2*, int, int, Point1&, Point1&, float&);
    friend bool closest(Point1*, int, Point1&, Point1&, float&);
    friend void main();
public:
    int operator<=(Point1 a) const
    {
        return (x <= a.x);
    }
private:
    int ID;     // 点的编号
    float x, y; // 点坐标
};

class Point2 {
    friend float dist(const Point2&, const Point2&);
    friend void close(Point1*, Point2*, Point2*, int, int, Point1&, Point1&, float&);
    friend bool closest(Point1*, int, Point1&, Point1&, float&);
    friend void main();
public:
    int operator<=(Point2 a) const
    {
        return (y <= a.y);
    }
private:
    int p;      // 数组 X 中相同点的索引
    float x, y; // 点坐标
};
```

## 程序14-9：计算两点距离

### 问题描述
计算点 u 和点 v 之间的欧氏距离。

### 问题分析
直接利用两点间距离公式计算并返回欧氏距离。类型 T 可以是 Point1 或 Point2。

### 伪代码
```cpp
template<class T>
inline float dist(const T& u, const T& v)
{// 计算点 u 和 v 之间的距离
    float dx = u.x - v.x;
    float dy = u.y - v.y;
    return sqrt(dx * dx + dy * dy);
}
```

## 程序14-10：预处理及调用close

### 问题描述
最近点对问题的入口函数，负责预处理并调用 close 函数求解。

### 问题分析
首先验证至少存在两个点，然后按 x 坐标对点进行归并排序，再将点复制到数组 Y 中并按 y 坐标排序，最后调用 close 函数递归求解。时间复杂度为 $\Theta(n \log n)$。

### 伪代码
```cpp
// 在 n >= 2 个点中寻找最近点对
// 如果少于 2 个点，则返回 false
// 否则，在 a 和 b 中返回距离最近的两个点

if (n < 2) return false;

// 按 x 坐标排序
MergeSort(X, n);

// 创建按 y 坐标排序的点数组
Point2* Y = new Point2[n];
for (int i = 0; i < n; i++) {
    // 将点 i 从 X 复制到 Y
    Y[i].p = i;
    Y[i].x = X[i].x;
    Y[i].y = X[i].y;
}
MergeSort(Y, n);  // 按 y 坐标排序

// 创建临时数组
Point2* Z = new Point2[n];

// 寻找最近点对
close(X, Y, Z, 0, n-1, a, b, d);

// 删除数组并返回
delete [] Y;
delete [] Z;
return true;
```

## 程序14-11：close函数

### 问题描述
递归求解最近点对问题的核心函数，在按 x 坐标排序的点集 X[l:r] 中寻找距离最近的两个点。

### 问题分析
采用分而治之策略：
1. 小问题（2 或 3 个点）：直接计算所有点对距离取最小值。
2. 大问题：按 x 坐标中点划分为左右两部分 A 和 B，递归求解各自最近点对距离 δ。
3. 合并：只需考虑距分割线距离小于 δ 的点，将这些点按 y 坐标排序后，每个点最多只需与其后 7 个点比较。
总体时间复杂度为 $\Theta(n \log n)$。

### 伪代码
```cpp
void close(Point1 X[], Point2 Y[], Point2 Z[], int l, int r,
           Point1& a, Point1& b, float& d)
{// X[l:r] 按 x 坐标排序，Y[l:r] 按 y 坐标排序
    if (r - l == 1) {  // 两个点
        a = X[l];
        b = X[r];
        d = dist(X[l], X[r]);
        return;
    }
    if (r - l == 2) {  // 三个点，计算所有点对之间的距离
        float d1 = dist(X[l], X[l+1]);
        float d2 = dist(X[l+1], X[r]);
        float d3 = dist(X[l], X[r]);
        // 寻找最近点对
        if (d1 <= d2 && d1 <= d3) {
            a = X[l];
            b = X[l+1];
            d = d1;
            return;
        }
        if (d2 <= d3) {
            a = X[l+1];
            b = X[r];
            d = d2;
        } else {
            a = X[l];
            b = X[r];
            d = d3;
        }
        return;
    }

    // 多于三个点，划分为两部分
    int m = (l + r) / 2;  // X[l:m] 在 A 中，余下的在 B 中

    // 在 Z[l:m] 和 Z[m+1:r] 中创建按 y 排序的表
    int f = l,       // Z[l:m] 的游标
        g = m + 1;   // Z[m+1:r] 的游标
    for (int i = l; i <= r; i++)
        if (Y[i].p > m)
            Z[g++] = Y[i];
        else
            Z[f++] = Y[i];

    // 对以上两个部分递归求解
    close(X, Z, Y, l, m, a, b, d);
    float dr;
    Point1 ar, br;
    close(X, Z, Y, m+1, r, ar, br, dr);

    // (a, b) 是两者中较近的点对
    if (dr < d) {
        a = ar;
        b = br;
        d = dr;
    }

    Merge(Z, Y, l, m, r);  // 重构 Y

    // 距离小于 d 的点放入 Z
    int k = l;  // Z 的游标
    for (int i = l; i <= r; i++)
        if (fabs(Y[m].x - Y[i].x) < d)
            Z[k++] = Y[i];

    // 通过检查 Z[l:k-1] 中的所有点对，寻找较近的点对
    for (int i = l; i < k; i++) {
        for (int j = i + 1; j < k && Z[j].y - Z[i].y < d; j++) {
            float dp = dist(Z[i], Z[j]);
            if (dp < d) {  // 找到更近的点对
                d = dp;
                a = X[Z[i].p];
                b = X[Z[j].p];
            }
        }
    }
}
```
