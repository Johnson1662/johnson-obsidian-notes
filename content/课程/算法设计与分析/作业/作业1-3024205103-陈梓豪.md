## 15
试确定函数Mult共执行了多少次乘法，该函数实现两个n×n矩阵的乘法

```C++
template<class T>
void Mult(T **a, T **b, T **c, int n)
{// 两个n x n 矩阵a 和b 相乘得到c .
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) {
            T sum = 0;
            for (int k = 0; k < n; k++)
                sum += a[i][k] * b[k][j];
            c[i][j] = sum;
        }
}
```

解：即计算`sum += a[i][k] * b[k][j];`的执行次数，不难发现Mult函数是一个三层嵌套循环，其中最内层循环执行n次，中层循环执行n次，外层循环执行n次，而该语句位于最内层循环，因此总执行次数为n^3次，即执行了n^3次乘法。

## 18
函数MinMax(见程序2-26)用来查找数组a[0:n-1] 中的最大元素和最小元素。令n为实例特征。试问a中元素之间的比较次数是多少？程序2-27中给出了另一个查找最大和最小元素的函数。在最好和最坏情况下a中元素之间比较次数分别是多少？试分析两个函数之间的相对性能。

程序2-26 查找最大和最小元素：

```C++
template<class T>
bool MinMax(T a[], int n, int& Min, int& Max)
{// 寻找a [ 0 : n - 1 ]中的最小元素和最大元素
// 如果数组中的元素数目小于1，则返回false
    if (n < 1) return false;
    Min = Max = 0; // 初始化
    for (int i = 1; i < n; i++) {
        if (a[Min] > a[i]) Min = i;
        if (a[Max] < a[i]) Max = i;
    }
    return true;
}
```

程序2-27 另一个查找最大和最小元素的函数：

```C++
template<class T>
bool MinMax(T a[], int n, int& Min, int& Max)
{// 寻找a [ 0 : n - 1 ]中的最小元素和最大元素
// 如果数组中的元素数目小于1，则返回false
    if (n < 1) return false;
    Min = Max = 0; // 初始化
    for (int i = 1; i < n; i++) {
        if (a[Min] > a[i]) Min = i;
        else if (a[Max] < a[i]) Max = i;
    }
    return true;
}
```

解：
（1）程序2-26中，当n<1时，执行0次；当n>=1时，for循环i从1到n-1，每次循环a中元素都要做2次比较，所以总共进行了2*(n-1)次比较。
（2）程序2-27中，当n<1时，执行0次；当n>=1时，for循环i从1到n-1，每次循环最多进行2次比较，但如果a[Min] > a[i]为真，则不会执行else if语句，因此在最好情况下每次循环只进行1次比较，总共进行了n-1次比较；在最坏情况下每次循环都要进行2次比较，总共进行了2*(n-1)次比较。
（3）相对性能分析：程序2-27在最好情况下的比较次数比程序2-26少了n-1次比较，因此在数据分布较为均匀的情况下，程序2-27的性能更好；而在最坏情况下，两者的比较次数相同，因此性能相当。总体来说，程序2-27在平均情况下的性能更好，因为它减少了不必要的比较。

## 20
程序2-28给出了另外一个迭代式顺序搜索函数。在最坏情况下x与a中元素之间执行了多少次比较？把这个比较次数与程序2-1中相应的比较次数进行比较，哪一个函数将运行得更快？为什么？

```C++
// 程序2-1 顺序搜索
template<class T>
int SequentialSearch(T a[], const T& x, int n)
{// 在未排序的数组a [ 0 : n-1 ]中搜索x
// 如果找到，则返回所在位置，否则返回- 1
    int i;
    for (i = 0; i < n && a[i] != x; i++);
        if (i == n) return -1 ;
    return i;
}

// 程序2-28 另一个顺序搜索函数
template<class T>
int SequentialSearch(T a[ ], const T& x, int n)
{// 在未排序的数组a [ 0 : n-1 ]中查找x
// 如果找到，则返回相应位置，否则返回- 1
    a[n] = x; // 假定该位置有效
    int i;
    for (i = 0; a[i] != x; i++);
        if (i == n) return -1 ;
    return i;
}
```

解：
（1）最坏情况下，程序2-28的i要从0->n，故要x要与a中元素比较n+1次，而程序2-1的比较次数为n次,因此此时程序2-1运行的更快。
（2）但在一般情况下，由于程序2-28相比程序2-1减少了i与n的比较，因此程序2-28运行的会更快。

24. 计算如下函数的平均执行步数：
1) SequentialSearch(见程序2-2)
```C++
template <class T>
int SequentialSearch(T a[], const T& x, int n)
{ //在未排序的数组a [ 0 : n-1 ]中查找x
//如果找到则返回所在位置，否则返回- 1
    if (n < 1) return -1 ;
    if (a[n-1] == x) return n-1;
    return SequentialSearch(a,x,n-1);
}
```

n < 1时，步数step(n) = 1
n >= 1时，步数step(n) = 1 + step(n-1) = 1 + 1 + step(n-2) = ... = n

2) SequentialSearch(见程序2-28)
```C++
template<class T>
int SequentialSearch(T a[ ], const T& x, int n)
{// 在未排序的数组a [ 0 : n-1 ]中查找x
// 如果找到，则返回相应位置，否则返回- 1
    a[n] = x; // 假定该位置有效
    int i;
    for (i = 0; a[i] != x; i++);
        if (i == n) return -1 ;
    return i;
}
```

step = 4 + O(n)

3) Insert(见程序2-10)
```C++
template<class T>
void Insert(T a[], int& n, const T& x)
{// 向有序数组a [ 0 : n-1 ]中插入元素x
// 假定a 的大小超过n
    int i;
    for (i = n-1; i >= 0 && x < a[i]; i--)
        a[i+1] = a[i];
    a[i+1] = x;
    n++; // 添加了一个元素
}
```
step = 3 + O(n)
