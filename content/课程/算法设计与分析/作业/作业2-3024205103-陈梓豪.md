## 1. 用归纳法（代入法）证明
   $$T(n) \le \begin{cases} 0 & \text{if } n = 1 \\ T\lfloor n/2 \rfloor + T\lceil n/2 \rceil + cn & \text{if } n > 1 \end{cases}\quad \le cn \lceil \log_2 n \rceil$$

①$n=1$时，$T(1)\le0\le c·1·0$，不等式成立
②假设对于$1<k<n$时，$T(k)\le ck \lceil \log_2 k \rceil$成立。

$$
\begin{aligned}
T(n) &\leq T(\lfloor n/2 \rfloor) + T(\lceil n/2 \rceil) + cn \\
&\leq c \lfloor n/2 \rfloor \lceil \log_2 \lfloor n/2 \rfloor \rceil + c \lceil n/2 \rceil \lceil \log_2 \lceil n/2 \rceil \rceil + cn \\
&\leq c \lfloor n/2 \rfloor (\lceil \log_2 n \rceil - 1) + c \lceil n/2 \rceil (\lceil \log_2 n \rceil - 1) + cn \\
&= c (\lfloor n/2 \rfloor + \lceil n/2 \rceil) (\lceil \log_2 n \rceil - 1) + cn \\
&= cn (\lceil \log_2 n \rceil - 1) + cn \\
&= cn \lceil \log_2 n \rceil - cn + cn \\
&= cn \lceil \log_2 n \rceil
\end{aligned}
$$

## 2. 应用主定理 (Master Method) 求解
   $$T(n) = 2T(n/2) + \Theta(n^{1/2})$$

$$
\begin{aligned}
&a = 2, \quad b = 2, \quad f(n) = \Theta(n^{1/2}) \\
&n^{\log_b a} = n^{\log_2 2} = n^1 = n \\
&比较 f(n) 和 n^{\log_b a} 可知 : \\
&f(n) = \Theta(n^{1/2}) = O(n^{1-\epsilon}) \quad (\epsilon = 0.5) \\
&\text{根据主定理 Case 1:} \quad T(n) = \Theta(n)
\end{aligned}
$$

## 3. 展开递归树： $T(n) = T(2) + T(n-2) + cn$，并做渐近分析。

```
                 T(n)
                 /   \
               T(2)  T(n-2)         cn
                     /    \
                  T(2)   T(n-4)     c(n-2)
                           \
               ...          ...
                           T(4)       c(4)
                           /   \
                        T(2)   T(2)    c(2)
```

$$\begin{aligned}
T(n) &= cn + c(n-2) + c(n-4) + \dots + c(4) + \frac{n}{2} \cdot T(2) \\
&= \sum_{i=0}^{\frac{n}{2}-2} c(n-2i) + \frac{n}{2} \cdot T(2) \\
&= c \left[ n + (n-2) + \dots + 4 \right] + \frac{n}{2} T(2) \\
&= c \cdot \frac{(\frac{n - 2}{2})(n + 4)}{2} + \frac{n}{2} T(2) \\
&= \frac{c}{4}(n^2 + 2n - 8) + \frac{n}{2} T(2)
\end{aligned}$$

渐近分析:通过上面的展开式可以清晰地看到：式子中最高次项是 $\frac{c}{4}n^2$。其余的$\frac{cn}{2}$ 和 $\frac{n}{2}T(2)$ 都是线性项 $O(n)$。因此，该递归式的渐近复杂度为：$T(n) = \Theta(n^2)$
## 4. 展开 $T(n) = T(0.2n) + T(0.8n) + \Theta(n)$ 的递归树并计算递归树的深度和 $T(n)$ 的渐近值。
（1）展开递归树
```
          cn                   <-- 第 0 层:  cn
        /    \
    0.2cn    0.8cn             <-- 第 1 层:  0.2cn + 0.8cn = cn
    /   \    /   \
0.04cn 0.16cn 0.16cn 0.64cn    <-- 第 2 层:  (0.04+0.16+0.16+0.64)cn = cn
 / \    / \    / \    / \
... ... ... ... ... ... ...    
```
（2）递归树的深度：取决于从根到叶子的最长和最短路径：
最短路径：始终选择 $0.2n$ 的分支。$$n \cdot (0.2)^k = 1 \Rightarrow k = \log_{5} n$$最长路径（树的深度）：始终选择 $0.8n$ 的分支。$$n \cdot (0.8)^h = 1 \Rightarrow n \cdot (4/5)^h = 1 \Rightarrow h = \log_{5/4} n $$因此，递归树的深度为 $O(\log n)$。
（3）$T(n)$ 的渐近值
$$T(n) \le cn \cdot \log_{5/4} n = O(n \log n) \\ T(n) \ge cn \cdot \log_{5} n = \Omega(n \log n) \\ T(n) = \Theta(n \log n)$$


## 5. 计算算法 A 的时间复杂度，算法满足递归关系式：
   $$\begin{cases} f(n) = 2f(n-1) + 1 \\ f(0) = 1 \end{cases}$$
   
   $$\begin{aligned}
   f(n) &= 2f(n-1) + 1 \\ 
   &= 2(2f(n-2) + 1) + 1  \\
   &= 2^2 f(n-2) + 2 + 1 \\ 
   &= 2^2(2f(n-3) + 1) + 2 + 1 \\ 
   &= 2^3 f(n-3) + 2^2 + 2 + 1 \\
   &= \dots = 2^{n} f(0) + \sum_{i=0}^{n-1} 2^i \\
   &= 2^{n} \cdot 1 + \frac{2^n - 1}{2 - 1} \\
   &= 2^{n} + 2^n - 1 \\
   &= 2 \cdot 2^n - 1 \\
   &= 2^{n+1} - 1
   \end{aligned}$$
因此，算法 A 的时间复杂度为 $O(2^n)$。
