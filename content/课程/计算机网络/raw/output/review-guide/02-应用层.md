## 考点 1：HTTP 协议工作机制与对象获取 RTT 时延模型

### 考点讲解
- **核心定义**：
  - **RTT（Round-Trip Time）**：一个短分组从客户端发送到服务器并返回的总时间。
  - **非持久 HTTP（Non-persistent）**：每个 TCP 连接只传输一个请求/响应对象，完成后连接关闭。
  - **持久 HTTP（Persistent）**：同一个 TCP 连接保持打开，可连续服务该页面的多个对象。
  - **流水线持久 HTTP（Pipelining）**：客户端收到前一个对象的响应前即可紧接着发送后续请求。
- **标准公式**：
  获取内嵌 $N$ 个引用对象的网页总时延：
  - 非持久串行：$T = RTT_{DNS} + 2RTT + N \times 2RTT = (2N + 2)RTT + RTT_{DNS}$
  - 非持久并行（$M$ 条连接）：$T = RTT_{DNS} + 2RTT + \lceil N/M \rceil \times 2RTT$
  - 持久非流水线：$T = RTT_{DNS} + 2RTT + N \times 1RTT = (N + 2)RTT + RTT_{DNS}$
  - 流水线持久：$T = RTT_{DNS} + 1RTT (建连) + 1RTT (HTML) + 1RTT (全部对象并发) = 3RTT + RTT_{DNS}$
- **初学易错点**：
  - ⚠️ 记住建立一个 TCP 连接必须花费 **1 个 RTT**（SYN $\to$ SYN-ACK）；请求并收到响应花费 **1 个 RTT**（ACK+GET $\to$ Data）。因此新建连接取首个对象必须是 **2 个 RTT**！

### 例题
<!-- Q0014 -->
**例题 1（2021年期末真题）**

**题目**：某 HTML 引用同一服务器上 8 个极小对象（传输时延忽略不计）。建立 TCP 需 1 RTT，请求响应 1 RTT，DNS 解析耗时 $RTT_{DNS}$。计算总时间：
(a) 非持久 HTTP 串行；(b) 非持久 HTTP 开启 6 条并行；(c) 流水线持久 HTTP；(d) 串行持久 HTTP。

**解答**：
(a) 非持久串行：HTML 占 $2RTT$，8 个对象每个需 $2RTT$。总计 $= 18 RTT + RTT_{DNS}$。
(b) 非持久并行（6条）：HTML 占 $2RTT$；8 个对象分 2 批并行（第一批 6 个耗 $2RTT$，第二批 2 个耗 $2RTT$）。总计 $= 6 RTT + RTT_{DNS}$。
(c) 流水线持久：TCP 握手 $1RTT$ + 请求 HTML $1RTT$ + 流水线并发出 8 个请求并集中返回 $1RTT$。总计 $= 3 RTT + RTT_{DNS}$。
(d) 串行持久：建连加 HTML 占 $2RTT$ + 8 个对象串行复用连接耗 $8 \times 1RTT = 8RTT$。总计 $= 10 RTT + RTT_{DNS}$。
