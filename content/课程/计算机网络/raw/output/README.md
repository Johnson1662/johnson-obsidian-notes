# 计算机网络历年真题提取与题库工作流说明

本目录由试卷提取工作流自动生成，输入源为 `课程/计算机网络/raw/exam/` 下的历年试卷原件（PDF 与 DOCX）。

## 目录结构说明

```text
课程/计算机网络/raw/output/
├── extracted/                # MinerU 原始 OCR 与文本提取 Markdown（未经格式化）
│   ├── 21_计网_翻译版.md
│   ├── 22_计网_电子.md
│   ├── 24252_计网.md
│   ├── 25262_计网.md
│   └── 25262计网期末回忆版.md
│
├── questions/                # 结构化原子题库（每题一个独立卡片，共 33 道真题）
│   ├── 2021-选择-*.md
│   ├── 2021-大题-*.md
│   ├── 2022-选择-*.md
│   ├── 2022-大题-*.md
│   ├── 2024-大题-*.md
│   └── 2025-大题-*.md
│
├── 题库汇总.md                # 全量真题按章节分类的一体化手册（折叠答案自测）
└── 题库看板.base              # Obsidian 原生 Bases 动态看板（按掌握度、章节、题型筛选）
```

## 核心设计规范

1. **题目卡片标准**：每道题均配置 YAML Frontmatter，包括 `qid`、`year`、`chapter`、`type`、`tags`、`concept`（双链反向引用课程笔记）、`status`（未做/已掌握/错题）以及 `difficulty`。
2. **遮挡自测交互**：正文使用 `> [!question]` 放置题目，答案与解析统一收纳在 `> [!check]-` 折叠块中，默认折叠，做题时不会剧透。
3. **多维看板视图**：`题库看板.base` 免代码提供三种预设视图：
   - **全部真题一览**：按年份与题型排序。
   - **高危错题集**：只过滤 `status == "错题"` 的题目，方便考前突击。
   - **高频核心大题**：聚焦历年必考的算法与计算大题。
