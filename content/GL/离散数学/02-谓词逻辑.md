# 02-谓词逻辑：从"点"到"面"的逻辑升维

在上一章的结尾，我们留下了一个悬念：为什么 "x > 5" 不是命题？

原因很简单：命题必须有**确定的真值**。但在 "x > 5" 中，x 是个"变量"，它就像一个空位，在没填入具体的数字之前，我们既不能说它对，也不能说它错。

如果说**命题逻辑**是处理"完整的句子"，那么本章要讲的**谓词逻辑（Predicate Logic）**就是拆解句子的内部结构，深入到"个体"与"性质"的微观世界。这不仅是数学证明的基石，更是理解数据库查询（SQL）和人工智能推理的钥匙。

---

## 1. 谓词逻辑的三大基石

为了表达更复杂的逻辑，我们需要三样新武器：**个体**、**谓词**和**量词**。

### 1.1 个体 (Individual)

个体就是我们讨论的对象。它可以是一个具体的人（苏格拉底）、一个具体的数（5）、或者一个具体的物体（我的电脑）。

- **个体常量**：具体的对象，通常用小写字母 $a, b, c$ 表示。
- **个体变量**：代表不确定的对象，用 $x, y, z$ 表示。

### 1.2 谓词 (Predicate)

谓词用来描述个体的性质或个体之间的关系。

- **一元谓词**：描述一个性质。如 $P(x)$ 表示 "$x$ 是程序员"。
- **多元谓词**：描述多个个体之间的关系。如 $L(x, y)$ 表示 "$x$ 喜欢 $y$"。

> [!tip] 编程视角
> 谓词就像是返回布尔值的**函数**：
>
> ```python
> def is_programmer(x): # P(x)
>     return x.job == "Programmer"
>
> def loves(x, y): # L(x, y)
>     return x.likes(y)
> ```

### 1.3 个体域 (Domain of Discourse)

这是初学者最容易忽略的一点：**你在讨论哪里的东西？**
如果你说"所有人都是凡人"，个体域就是"全人类"。如果你说"所有数都是偶数"，个体域可能是"自然数集"，也可能是"全体整数"。在谓词逻辑中，同一个公式在不同的个体域下，真值可能完全不同。

## 2. 量词：逻辑的"放大镜"

量词（Quantifier）让我们可以讨论"范围"。

### 2.1 全称量词 (Universal Quantifier, ∀)

**符号**：`∀x P(x)`
**读作**：对于所有的 $x$，$P(x)$ 为真。
**直观理解**：它相当于一个巨大的 `AND` 连接。如果个体域是 $\{a_1, a_2, ..., a_n\}$，那么 `∀x P(x)` 等价于 $P(a_1) ∧ P(a_2) ∧ ... ∧ P(a_n)$。

### 2.2 存在量词 (Existential Quantifier, ∃)

**符号**：`∃x P(x)`
**读作**：存在一个 $x$，使得 $P(x)$ 为真。
**直观理解**：它相当于一个巨大的 `OR` 连接。等价于 $P(a_1) ∨ P(a_2) ∨ ... ∨ P(a_n)$。

## 3. 翻译的艺术：避开最深的坑

这是离散数学考试中最容易丢分的地方。请务必记住这两条"黄金法则"：

### 规则一：全称量词通常搭配"蕴含 (→)"

**例子**：翻译"所有的程序员都熬夜"。

- **定义**：$P(x): x$ 是程序员；$S(x): x$ 熬夜。
- **❌ 错误写法**：`∀x (P(x) ∧ S(x))`
  - **人话翻译**：世界上所有的东西都是程序员，且都在熬夜。这显然不对（猫猫狗狗也是东西，但它们不是程序员）。
- **✅ 正确写法**：`∀x (P(x) → S(x))`
  - **人话翻译**：对于世界上的任何对象 $x$，**如果** $x$ 是程序员，**那么** $x$ 就熬夜。

### 规则二：存在量词通常搭配"合取 (∧)"

**例子**：翻译"有些程序员不熬夜"。

- **❌ 错误写法**：`∃x (P(x) → ¬S(x))`
  - **为什么错？** 还记得上一章的蕴含真值表吗？当前提为假，蕴含就是真。这意味着，只要世界上存在一个"不是程序员"的东西（比如一棵树），这个公式就是真的。但这并不能证明"存在不熬夜的程序员"。
- **✅ 正确写法**：`∃x (P(x) ∧ ¬S(x))`
  - **人话翻译**：存在一个对象 $x$，$x$ 既是程序员，又不熬夜。

## 4. 变元的约束：变量的作用域

在编程中，我们有局部变量和全局变量。在谓词逻辑中，我们有**约束变元**和**自由变元**。

```python
# ∀x (P(x) ∧ Q(x, y))
#    └──┬──┘     │
#      x 被 ∀ 约束了 (约束变元)
#                y 是自由的 (自由变元)
```

- **约束变元**：被量词管辖的变量。
- **自由变元**：没被量词管辖的变量。
- **辖域 (Scope)**：量词的作用范围。

> [!warning] 常见陷阱
> 同一个字母可以在不同地方既是自由的又是约束的，但这会导致逻辑混乱。在转换公式时，我们通常会进行**换名**或**代换**。

## 5. 等值演算与量词否定

量词和否定（¬）在一起时，会发生奇妙的化学反应。这本质上是命题逻辑中**德·摩根定律**的无限推广。

### 核心公式（量词转换律）：

1. `¬∀x P(x) ≡ ∃x ¬P(x)`
   - **直觉**："并非所有人都及格" ≡ "存在有人不及格"。
2. `¬∃x P(x) ≡ ∀x ¬P(x)`
   - **直觉**："不存在长生不老的人" ≡ "所有人都不长生不老"。

**记忆技巧**：否定符号往里跳，量词符号翻个个儿（∀变∃，∃变∀）。

---

## 6. 前束范式：逻辑的"归一化"

为了方便计算机处理和推理证明，我们希望所有的量词都待在公式的最前面。这种形式叫**前束范式 (Prenex Normal Form, PNF)**。

### 转换四部曲：

1. **消去联结词 `→` 和 `↔`**：利用 `p→q ≡ ¬p∨q`。
2. **否定内移**：利用双重否定律和量词转换律，把 `¬` 移到谓词符号紧邻的位置。
3. **变量换名**：确保每个量词约束的变量名都是唯一的，不要和自由变量冲突。
4. **量词外提**：把所有量词按照原有顺序提取到最前面。

### 实战演练：

将公式 $F = ∀x P(x) → ∃x Q(x)$ 转化为前束范式。

1. **消去蕴含**：`¬(∀x P(x)) ∨ ∃x Q(x)`
2. **否定内移**：`(∃x ¬P(x)) ∨ ∃x Q(x)`
3. **变量换名**（因为有两个 $x$，为了区分，把第二个改为 $y$）：`(∃x ¬P(x)) ∨ ∃y Q(y)`
4. **量词外提**：`∃x ∃y (¬P(x) ∨ Q(y))`
   **搞定！**

## 7. 谓词逻辑的推理规则

除了命题逻辑的规则，谓词逻辑多了四个关于量词的"开箱/封箱"操作：

- **全称指定 (US)**: 如果对所有人都成立，那么对张三一定成立。
  `∀x P(x) ⊢ P(c)`
- **全称推广 (UG)**: 如果你能证明一个性质对任意的、不加限制的对象都成立，那么它对所有人都成立。
- **存在指定 (ES)**: 如果知道存在某人满足 $P$，我们可以给这个人起个临时的代号 $c$，研究他的性质。
- **存在推广 (EG)**: 如果张三满足 $P$，那么一定存在某人满足 $P$。
  `P(c) ⊢ ∃x P(x)`

## 8. 应用：谓词逻辑与现代科技

你可能觉得这些符号离你很远，但其实它们就在你身边：

### 8.1 SQL 数据库查询

当你写下：

```sql
SELECT name FROM employees
WHERE salary > 5000 AND dept = 'Sales';
```

这本质上是在寻找满足谓词 $S(x) ∧ D(x)$ 的所有个体 $x$。数据库引擎的优化器，其实就是在后台做**谓词下推**等逻辑等值演化。

### 8.2 正则表达式与搜索

搜索"包含数字但不包含空格的字符串"，其实就是在做：
`∃s (HasDigit(s) ∧ ¬HasSpace(s))`。

## 本篇小结

- **谓词逻辑** = 个体 + 谓词 + 量词。
- **翻译陷阱**：∀ 配 →，∃ 配 ∧。
- **变量身份**：约束变元看量词，自由变元看外界。
- **量词否定**：搬家变号，∀ ↔ ∃。
- **前束范式**：把所有量词赶到公式开头。
