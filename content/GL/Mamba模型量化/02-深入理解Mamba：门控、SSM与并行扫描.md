# 02-深入理解Mamba：门控、SSM与并行扫描

上一章我们说得比较粗糙，这一章我们来细细拆解Mamba的核心机制。有反馈说概念跳跃太大，这章咱们就踏踏实实把每个部件都搞清楚。

## 线性层：神经网络的基本单元

在说门控和投影之前，先回顾一下神经网络里最基础的东西——**线性层**（Linear Layer），也叫全连接层。

它的公式很简单：

$$y = Wx + b$$

- $x$ 是输入向量
- $W$ 是权重矩阵
- $b$ 是偏置向量
- $y$ 是输出向量

你可以把$W$想象成一个"变换矩阵"——它把输入空间转换到输出空间。每个神经元就是$W$的一行，它和输入做点积，得到输出的一个维度。

在Mamba的架构图里，你会看到各种"投影"——Gate Projection、Input Projection、Output Projection——本质上都是线性层，只是它们各自负责不同的功能。

## 门控机制：Gating到底是什么

"门控"这个词听起来高大上，但其实它的概念非常直观。

### 从生活中的门控说起

想象你家里有一个**可控阀门**：

- 水流进来的时候，阀门可以开大也可以开小
- 阀门开得大 → 更多水通过
- 阀门开得小 → 更少水通过

这个阀门就是一个"门"——它控制信息流动的多少。

在神经网络里，**门控机制**做的事情一模一样：**决定多少信息可以通过**。

### 具体的门控实现

最经典的门控是LSTM里的"门"，它用一个额外的神经网络来**动态决定开合程度**。

具体实现通常是下面这个流程：

```
门控值 = sigmoid(W·x + b)
输出 = 门控值 ⊙ 原始输出
```

这里有两个关键点：

1. **sigmoid函数**：把任意数值映射到0~1之间。想象成"百分比"
2. **⊙符号**：逐元素乘法（element-wise product）

举个例子：

- 假设某个神经元的门控值是0.8，原始输出是10
- 最终输出 = 0.8 × 10 = 8
- 意思是有80%的信息通过了"门"

### Mamba里的门控投影

论文里提到的"Gate Projection"（门控投影），就是这样一个线性层，它的输出会被用来做门控。

在Mamba中，公式是：

$$z = \sigma(W_{gate} \cdot x)$$

- $W_{gate}$是Gate Projection的权重矩阵
- $\sigma$是SiLU激活函数（一种非线性的sigmoid变体）
- $z$就是门控向量，后续会用来"过滤"SSM的输出

你可以把Gate Projection理解成：**"决定哪些保留、哪些该丢弃信息该"**的决策器。

## 状态空间模型：Mamba的"心脏"

现在来说Mamba最核心的部分——**状态空间模型（State Space Model，简称SSM）**。

### 什么是"状态"

在讲SSM之前，先搞清楚什么是"状态"。

想象你在看一部电视剧：

- 某一集的场景，就是当前的"状态"
- 每一集之间是有关联的——你得知道上一集讲了什么，才能理解这一集
- 演员的表情、台词、剧情发展，都是在传递"状态信息"

在数学里，**状态**就是一个**包含历史信息的向量**。它不是只看当前输入，而是把过去的所有信息"压缩"进一个向量里。

### SSM的工作方式

SSM的核心思想可以用下面这张图来理解：

```
输入序列: x(0), x(1), x(2), x(3), ...
           ↓
    ┌─────────────────────┐
    │   状态更新方程       │
    │   h(t) = A·h(t-1) + B·x(t)   │
    └─────────────────────┘
           ↓
    状态序列: h(0), h(1), h(2), h(3), ...
           ↓
    ┌─────────────────────┐
    │   输出方程           │
    │   y(t) = C·h(t)     │
    └─────────────────────┘
           ↓
输出序列: y(0), y(1), y(2), y(3), ...
```

这里有三个核心矩阵：

- **A**：状态转移矩阵，控制历史状态如何传递到下一个时刻
- **B**：输入矩阵，控制当前输入如何影响状态
- **C**：输出矩阵，决定如何从状态生成输出

### 直观理解SSM

SSM的工作方式可以类比成**累加器**：

- 每一个新的输入进来，都会更新状态
- 状态里"沉淀"了之前所有输入的信息
- 输出时，从状态里"抽取"需要的信息

这和Transformer的Self-Attention形成了鲜明对比：

|       | SSM (Mamba) | Self-Attention (Transformer) |
| ----- | ----------- | ---------------------------- |
| 捕获长依赖 | 通过状态传递      | 通过注意力机制                      |
| 计算复杂度 | O(N) 线性     | O(N²) 平方                     |
| 显存占用  | 较小          | 较大                           |

## 并行扫描：Mamba的加速秘籍

说完SSM，你可能会有个疑问：**按顺序一个一个计算状态，速度会不会很慢？**

确实，如果按照上面的递推公式一步步算，时间复杂度是O(N)，但这是串行的——必须等前一个算完才能算后一个。

**并行扫描（Parallel Scan，简称PScan）**就是来解决这个问题的。

### 并行扫描的核心思想

其实这个思想在计算机里很常见——**分治法**。

想象你要计算：1 + 2 + 3 + 4 + 5 + 6 + 7 + 8

**串行方式**（一步步加）：

```
1+2=3
3+3=6
6+4=10
10+5=15
15+6=21
21+7=28
28+8=36
```

需要7步。

**并行方式**（两两相加）：

```
第1轮: 1+2=3, 3+4=7, 5+6=11, 7+8=15
第2轮: 3+7=10, 11+15=26
第3轮: 10+26=36
```

只需要3步！

这就是并行扫描的原理：**把原本串行的计算过程，通过巧妙的数学变换，改成可以并行执行的多个子任务**。

### 为什么PScan会放大异常值

论文特别提到PScan会放大异常值，这是为什么？

还是用累加的例子：

- 假设正常值是：1, 2, 3, 4 → 累加后是：1, 3, 6, 10
- 假设有一个异常值：1, 2, 100, 4 → 累加后是：1, 3, 103, 107

看到了吗？那个100的异常值不仅自己很大，还会**传递下去**，后续的值都被它"污染"了。

在Mamba的PScan里，情况类似：每一轮的状态传递都涉及矩阵乘法，数值越大的通道在每一轮都会被放大，最终导致**分布极度不均匀**。

## Mamba的整体数据流

现在我们可以把整个流程串起来了。下图是Mamba一个处理步骤的完整流程：

```
输入 x
  │
  ├──────────────────┬──────────────────┐
  ↓                  ↓                  ↓
Input Projection  Conv1D投影      Gate Projection
  ↓                  ↓                  ↓
x'               x_conv              z (门控)
  └──────────────────┬──────────────────┘
                     ↓
            ┌───────────────┐
            │   SSM (PScan) │
            │  h(t) = A·h   │
            │   + B·x'(t)   │
            └───────────────┘
                     ↓
                  y'_ssm
                     ↓
              ┌─────────────┐
              │  门控过滤   │
              │ y = y'_ssm ⊙ z
              └─────────────┘
                     ↓
                  输出 y
```

简单来说：

1. **输入投影**：把原始输入转换成SSM可处理的格式
2. **卷积**：捕捉局部模式
3. **门控**：学习哪些信息该保留
4. **SSM + PScan**：处理序列依赖
5. **门控过滤**：用门控值对SSM输出做"筛选"

## 为什么要特别关注Gate Projection

回到论文里提到的"门控投影层异常值"问题——现在你应该理解为什么这个层特别了。

Gate Projection的输出直接决定了**多少信息能通过**。如果这个门的数值分布不均匀——有些维度特别大、有些特别小——那量化的时候就很难处理：

- 按照大值设定量化范围 → 小值精度丢失
- 按照小值设定量化范围 → 大值溢出

这就是为什么论文把Gate Projection的异常值作为核心挑战之一。

- **线性层/投影**：神经网络的基本变换
- **门控机制**：动态控制信息流动的"阀门"
- **状态空间模型**：用状态传递来捕获序列依赖
- **并行扫描**：让SSM计算可以并行加速
- **异常值放大**：PScan的副作用
