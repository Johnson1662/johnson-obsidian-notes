## 什么是神经网络

先别被"神经网络"这个名字吓到，它的本质其实很简单：**一个超级复杂的函数**。

你中学学过函数吧？比如 $y = 2x + 1$，输入一个x，输出一个y。

神经网络也是一样的东西，只是：

- 输入不是一个数，而是一堆数（比如一张图片的所有像素）
- 输出也不是一个数，而是一堆数（比如"这是猫"的概率）
- 中间的计算过程超级复杂，有亿万个参数

就这么简单。**神经网络 = 一个超级复杂的函数**。

## 神经网络的基本单元：神经元

神经网络由很多"神经元"组成。一个神经元做的事情非常简单：

$$y = \sigma(w \cdot x + b)$$

别慌，我来拆解：

- **x**：输入（一个数字）
- **w**：权重（weight），就是一个数字，决定输入有多重要
- **b**：偏置（bias），也是一个数字，相当于"基础分"
- **σ**：激活函数，后面会讲
- **y**：输出

用大白话说：**把输入乘以权重，加上偏置，再过一遍激活函数，就是输出**。

举个例子：

假设你在决定要不要出门：

- x = 天气好不好（0~10分）
- w = 你有多在意天气（比如w=0.8）
- b = 你本来就想出门的倾向（比如b=2）

计算：$y = 0.8 \times x + 2$

- 如果天气很好(x=10)：$y = 0.8 \times 10 + 2 = 10$，出门！
- 如果天气很差(x=2)：$y = 0.8 \times 2 + 2 = 3.6$，不太想出门

这就是一个神经元做的事情——**加权求和**。

## 什么是权重和激活值

这两个词在论文里反复出现，必须搞清楚。

### 权重（Weight）

权重就是神经网络的"参数"，是模型学到的"知识"。

- 训练前：权重是随机数
- 训练后：权重是"学"出来的，能完成任务

你可以把权重想象成**每个输入的"重要程度"**。权重越大，这个输入对结果影响越大。

### 激活值（Activation）

激活值就是神经网络中间层的"输出"。

```
输入 → [第一层] → 激活值1 → [第二层] → 激活值2 → ... → 输出
```

每一层处理完后产生的中间结果，就叫"激活值"。

**为什么叫"激活"？** 因为它经过了激活函数的处理（下面讲）。

## 什么是激活函数

激活函数的作用是给神经网络加入"非线性"。

如果没有激活函数，神经网络就是一堆线性变换的叠加，最后还是一个线性函数——那它就学不会复杂的东西了。

常见的激活函数：

### 1. ReLU（最常用）

$$ReLU(x) = max(0, x)$$

超级简单：负数变0，正数不变。

- 输入-5 → 输出0
- 输入3 → 输出3

### 2. Sigmoid

$$\sigma(x) = \frac{1}{1+e^{-x}}$$

把任意数字压缩到0~1之间。

- 输入很大 → 输出接近1
- 输入很小 → 输出接近0
- 输入0 → 输出0.5

这个函数在Mamba的门控机制里用到，因为它能输出"百分比"。

### 3. SiLU（Mamba用的）

$$SiLU(x) = x \cdot \sigma(x)$$

就是输入乘以sigmoid，比ReLU更平滑。

## 什么是矩阵乘法

神经网络的核心计算就是矩阵乘法。别怕，其实就是"批量做乘法"。

### 从一个例子开始

假设你有3个学生，每个学生有2科成绩：

```
学生1: 语文80, 数学90
学生2: 语文70, 数学85
学生3: 语文90, 数学80
```

用矩阵表示：

$$X = \begin{bmatrix} 80 & 90 \\ 70 & 85 \\ 90 & 80 \end{bmatrix}$$

现在你想计算"加权总分"，权重是：语文0.4，数学0.6。

$$W = \begin{bmatrix} 0.4 \\ 0.6 \end{bmatrix}$$

矩阵乘法：

$$Y = X \times W = \begin{bmatrix} 80 \times 0.4 + 90 \times 0.6 \\ 70 \times 0.4 + 85 \times 0.6 \\ 90 \times 0.4 + 80 \times 0.6 \end{bmatrix} = \begin{bmatrix} 86 \\ 79 \\ 84 \end{bmatrix}$$

看到了吗？**矩阵乘法 = 批量做"加权求和"**。

### 在神经网络里

- **X**：输入矩阵（比如batch_size × 输入维度）
- **W**：权重矩阵（输入维度 × 输出维度）
- **Y**：输出矩阵（batch_size × 输出维度）

每一层就是一个矩阵乘法：$Y = XW + b$

## 什么是"层"和"投影"

### 层（Layer）

神经网络由很多"层"堆叠而成：

```
输入 → [线性层1] → [激活函数] → [线性层2] → [激活函数] → ... → 输出
```

每一层做的事情：

1. 线性变换（矩阵乘法）
2. 非线性变换（激活函数）

### 投影（Projection）

"投影"就是线性层的另一种叫法。

为什么叫"投影"？因为它把数据从一个空间"投射"到另一个空间。

比如：

- 输入维度是512
- 输出维度是256
- 这个线性层就把512维空间"投影"到256维空间

在Mamba论文里，你会看到：

- **Input Projection**：输入投影
- **Gate Projection**：门控投影
- **Output Projection**：输出投影

它们本质上都是线性层，只是用途不同。

## 什么是"维度"和"通道"

这两个概念容易混淆。

### 维度（Dimension）

维度就是"一个向量有多少个数"。

- 一个512维的向量 = 一个有512个数的数组
- 一个矩阵的维度 = (行数, 列数)

### 通道（Channel）

通道通常指"特征的数量"。

比如一张RGB图片：

- 3个通道：红、绿、蓝
- 每个通道是一个矩阵

在神经网络里：

- 输入64维 → 64个通道
- 权重矩阵的列数 = 输出通道数

论文里说的"通道方差不一致"，意思是：**不同特征维度上的数值分布差异很大**。

## 小结

这一章补了最基础的概念：

| 概念      | 一句话解释                     |
| --------- | ------------------------------ |
| 神经网络  | 一个超级复杂的函数             |
| 神经元    | 加权求和 + 激活函数            |
| 权重      | 模型学到的参数，决定输入重要性 |
| 激活值    | 中间层的输出                   |
| 激活函数  | 引入非线性，让网络能学复杂东西 |
| 矩阵乘法  | 批量做加权求和                 |
| 层/投影   | 线性变换 + 非线性变换          |
| 维度/通道 | 向量/特征的数量                |
