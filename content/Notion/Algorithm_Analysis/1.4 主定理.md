### 一句话总结主定理：$log_ab$和$O(f(n))$的非log次谁快就是谁，如果一样快就再乘个$logn$

### **主定理的表述**

对于递归方程$T(n) = aT(n/b) + f(n)$，其中$a \geq 1$，$b > 1$，$f(n) > 0$：

设$\log_b a$为临界指数，根据$f(n)$相对于$n^{\log_b a}$的渐近性质，分三种情况：

**情况1**：$f(n) = O(n^{\log_b a - \epsilon})$，其中$\epsilon > 0$为某一常数

$f(n)$的增长渐近地慢于$n^{\log_b a}$

**解**：$T(n) = \Theta(n^{\log_b a})$

**情况2**：$f(n) = \Theta(n^{\log_b a} \log^k n)$，其中$k \geq 0$为某一常数

$f(n)$和$n^{\log_b a}$几乎有相同的渐近增长率

**解**：$T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$

**情况3**：$f(n) = \Omega(n^{\log_b a + \epsilon})$，其中$\epsilon > 0$为一常数

$f(n)$多项式地快于$n^{\log_b a}$，且$f(n)$满足规则性条件：$af(n/b) \leq cf(n)$，$0 < c < 1$为常数

**解**：$T(n) = \Theta(f(n))$

**主定理的核心思想**

主定理的本质是比较递归树中两个主要成分的渐近增长率：

- 叶节点总数：$n^{\log_b a}$
- 非叶节点总代价：$\sum_{i=0}^{\log_b n - 1} a^i f(n/b^i)$

两者中阶较高的决定最终的时间复杂度。

### **实例分析**

**案例1：二分查找**

- 递归方程：$T(n) = T(n/2) + O(1)$
- 参数：$a = 1$，$b = 2$，$f(n) = O(1)$
- $n^{\log_b a} = n^{\log_2 1} = n^0 = 1$
- 情况2：$f(n) = \Theta(1) = \Theta(n^0 \log^0 n)$
- **解**：$T(n) = \Theta(\log n)$

**案例2：归并排序**

- 递归方程：$T(n) = 2T(n/2) + O(n)$
- 参数：$a = 2$，$b = 2$，$f(n) = O(n)$
- $n^{\log_b a} = n^{\log_2 2} = n^1 = n$
- 情况2：$f(n) = \Theta(n) = \Theta(n^1 \log^0 n)$
- **解**：$T(n) = \Theta(n \log n)$

**案例3：Strassen矩阵乘法**

- 递归方程：$T(n) = 7T(n/2) + O(n^2)$
- 参数：$a = 7$，$b = 2$，$f(n) = O(n^2)$
- $n^{\log_b a} = n^{\log_2 7} \approx n^{2.807}$
- 情况1：$f(n) = O(n^2) = O(n^{\log_2 7 - \epsilon})$，其中$\epsilon \approx 0.807$
- **解**：$T(n) = \Theta(n^{\log_2 7})$

**案例4：斐波那契数列的递归分析**

朴素递归算法：

```c++
int fibonacci(int n) {
    if (n <= 1) return n;
    return fibonacci(n-1) + fibonacci(n-2);
}
```

设$T(n)$为计算第n个斐波那契数的加法次数：

- $T(0) = T(1) = 0$
- $T(n) = T(n-1) + T(n-2) + 1$，$n \geq 2$

**分析**：

- 由于$T(n-1) > T(n-2)$，有$T(n) < 2T(n-1) + 1$
- 用归纳法可证：$T(n) \leq 2^n$
- 又有$T(n) > 2T(n-2) > \cdots > 2^{k-1}T(2) = 2^{k-1}$（当$n = 2k$时）
- 因此$T(n) = \Omega(2^{n/2})$

**结论**：朴素递归算法具有指数时间复杂度，这是因递归引起的大量重复计算所致。可设计线性时间复杂度的迭代算法。

**案例5：快速排序的平均情况分析**

快速排序的平均情况递归方程：
$T(n) = \frac{1}{n}\sum_{i=0}^{n-1}[T(i) + T(n-1-i)] + \Theta(n)$

倘若理想的快排可以平均划分：
$T(n) = \frac{2}{n}\sum_{i=0}^{n-1}T(i) + \Theta(n)$

通过数学技巧可以证明：$T(n) = \Theta(n \log n)$

### **小结**

1. **递归分析的核心**：建立递归方程，选择合适的求解方法
2. **主定理的应用**：快速判断标准形式递归方程的解
3. **方法选择**：
    - 递归树：直观，适合理解算法结构
    - 替代法：通用，但需要正确的猜测
    - 主定理：高效，但仅适用于特定形式。
