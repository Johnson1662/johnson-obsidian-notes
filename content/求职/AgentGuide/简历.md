## 项目经历

**Paper Agent：论文研读与综述助手**

- 基于 LangGraph + FastAPI + Milvus + BGE 构建论文研读 Agent，接入 arXiv、Semantic Scholar 与 PDF 解析工具，覆盖检索、精读、证据抽取与带引用的综述生成。
- 设计分层 context builder 管理 query、候选论文、证据片段与草稿；为每条结论保留 paper/page/section 引用，控制幻觉。
- 构建【20】条 eval case，引入 query decomposition + rerank，将正确引用率从【72%】提升至【88%】，幻觉率降至【X%】。
- 完成 BM25 / Dense / GraphRAG 三组 baseline 对比与消融，沉淀可 clone 运行的 Demo 与项目讲解稿。

**Agent 自动化评估 Harness**

- 设计面向工具调用 Agent 的离线评估流水线，支持测试集管理、LLM-as-Judge、规则评分与回归对比，作为各项目的通用评测底座。
- 将任务完成率、工具调用正确率、平均成本与 P95 延迟纳入统一报告，接入 CI 做 PR 前质量门禁。
- 对比 Promptfoo、DeepEval 后自研轻量脚本适配课程项目；通过持续评估定位工具参数错误、上下文污染、拒答边界不稳三类高频失败。
- 端到端通过率从【68%】提升至【82%】，沉淀失败 trace、配置诊断与回归用例。

**长期记忆 Agent（基于 Mem0 二开）**

- 基于 Mem0 构建跨会话长期记忆 Agent，实现记忆抽取、去重、衰减与图 + 向量混合召回。
- 构建【20】条多轮对话 eval case，以关闭记忆作为 baseline，评估记忆召回对多轮任务的影响。
- 将用户偏好类任务成功率从【61%】提升至【84%】，token 消耗降低【30%】。
- 完成"全量存储 / 摘要压缩 / 选择性遗忘"三组策略消融，沉淀记忆架构对比与成本分析。
