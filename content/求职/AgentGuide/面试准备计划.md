# 面试准备计划（Agent 开发 / AI 应用实习）

目标：Agent 开发、AI 应用岗实习。打法：用已有项目证据拿深挖分，用高频题库保底，不按算法岗标准铺开。

路线定位：走仓库「开发岗路线」（docs/05-roadmaps/learning-roadmap-development.md），算法岗路线（docs/05-roadmaps/learning-roadmap-algorithm.md）只看与模型原理相关的章节。

## 优先级 P0：先刷（高频 × 强匹配，必做）

### 1. Agent Harness / 记忆系统 / 上下文工程 —— 你的主战场
路径：
- docs/04-interview/18-agent-interview-playbooks/agent-harness-playbook.md
- docs/04-interview/18-agent-interview-playbooks/agent-memory-playbook.md
- docs/02-tech-stack/15-agent-memory.md
- docs/02-tech-stack/14-context-engineering.md（4 种失效 + 6 大修复技巧）
- docs/02-tech-stack/27-agent-harness-engineering.md（七层模型 + 可靠性六件套）

怎么准备：准备项目说辞为主，背概念为辅。把 OMP / DSH / Herdr 里实际做的事映射到 Harness 七层、记忆三层、上下文失效模式；每层能说清「我怎么做的、为什么、指标怎么量、失败样本是什么」。Harness playbook 里的六层机制阶梯要能背出来。

### 2. 项目讲述 + 项目深挖 —— 决定面试上限
路径：
- docs/04-interview/18-agent-interview-playbooks/star-storytelling-playbook.md
- docs/04-interview/23-frontier-interview-guides/project-deep-dive.md（BFS 主线 L0-L10 + DFS 六个追问算子）
- docs/04-interview/21-storytelling.md

怎么准备：纯准备项目说辞。选 1 个主项目 + 1 个备项目，各写 30 秒 / 2 分钟 / 15 分钟三版；按 DFS 六个算子（WHY-NOT、SOURCE、BOUNDARY 等）给自己造 20 个追问，每个都要有证据或明确「我不知道」。

### 3. Agent 系统题 + 开发岗专项（系统设计）
路径：
- docs/04-interview/03-agent-questions.md（重点：第二部分 Memory、第三部分 Tool Use、第六部分挑战与优化、第七部分系统设计）
- docs/04-interview/06-development-specialized.md（第一部分系统设计题、第二部分工程实践题、第三部分框架选型）

怎么准备：背概念 + 准备项目说辞。ReAct / Tool Calling / Multi-Agent / 容错机制背到能画架构图；系统设计题用你做过的 Agent 系统当素材答，别空谈。

### 4. RAG 全流程 + Agentic RAG
路径：
- docs/04-interview/02-rag-questions.md（核心原理、检索优化、工程实践）
- docs/02-tech-stack/20-rag-full-pipeline.md
- docs/04-interview/18-agent-interview-playbooks/agentic-rag-deep-research-playbook.md

怎么准备：背概念 + 手撕。混合检索、Rerank、分块、评估指标（Faithfulness / Answer Relevancy）要能讲清选型；从自己做过的记忆/检索模块里找一段能讲深的说辞。

### 5. 推理优化 / AI Infra（RoPE / KV Cache / MoE / vLLM）—— 你的差异化加分
路径：
- docs/04-interview/23-frontier-interview-guides/ai-infra.md（prefill/decode 拆分、显存估算模板）
- docs/04-interview/16-llm-fundamentals.md 第五部分推理优化、第八部分位置编码与长度外推
- docs/04-interview/01-theory-questions.md Q3（RoPE）、Q4（MHA/MQA/GQA）、Q13（MoE）
- docs/04-interview/04-coding-questions.md 第四部分模型优化与推理、第七部分 Transformer 手撕

怎么准备：背概念 + 手撕。RoPE 相对位置推导、KV Cache 显存计算、MoE 路由、vLLM PagedAttention 四个必须能白板讲；PyTorch 手撕 Multi-Head Attention 和 RoPE。

## 两周安排（每天 1.5-2 小时，周末可加倍）

第 1 周：搭骨架
- D1：P0-1 Harness playbook + 15-agent-memory.md，把 OMP / DSH / Herdr 列成项目映射表。
- D2：P0-1 14-context-engineering.md + 27-agent-harness-engineering.md，整理 4 失效 / 6 技巧对照表。
- D3：P0-2 STAR playbook + 21-storytelling.md，写出主项目 30 秒 / 2 分钟两版。
- D4：P0-2 project-deep-dive.md，给主项目造 20 个 DFS 追问并写答案。
- D5：P0-3 Agent 系统题（Memory / Tool Use / 系统设计），画 1 张系统架构图。
- D6：P0-3 开发岗专项系统设计题 3 道，手写架构 + 指标 + 失败分支。
- D7：复盘；整理「含糊点 / 无证据数字 / 不会题」三张表。

第 2 周：补深度 + 模拟
- D8：P0-4 RAG 题库 + 全流程文档，做一张检索优化选型表。
- D9：P0-4 Agentic RAG playbook，把 RAG 和你的记忆系统串成一条叙事。
- D10：P0-5 AI Infra + 16-llm-fundamentals.md 推理优化 / 位置编码，手推 RoPE、算 KV Cache 显存。
- D11：P0-5 04-coding-questions.md 第四、七部分，手撕 Attention / RoPE / KV Cache 各 1 遍。
- D12：P1 手撕题库 2 道 + 评测手册速读；补 D7 三张表里的薄弱项。
- D13：第一次模拟面试（找人对练或录音），只讲项目 + 系统设计，复盘卡壳点。
- D14：三档表达（30 秒 / 2 分钟 / 15 分钟）过一遍，一页速查表收尾，不扩题。

## 每天固定动作（30 分钟）

- 手撕 1 道代码题（04-coding-questions.md 或 22-algorithm-ai-coding-question-bank.md）。
- 复述 1 个项目故事并录音，压到 2 分钟。
- 更新三张表：含糊点、无证据数字、不会题。
