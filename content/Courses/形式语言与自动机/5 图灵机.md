# 5.1 图灵机

## 5.1.1 模型与形式定义

图灵机由 Alan Turing 于 1936 年提出。它用**无限纸带**提供不受限的存储空间；读写头可以读出当前格符号、改写该符号，并向左或向右移动。输入开始时写在纸带上，其余位置为空白；机器可把中间信息写回纸带，之后移动读头重新读取。进入接受态或拒绝态立即停机；若两者均未进入，计算可能继续无限久。

| 与有限自动机的差异 | 图灵机的能力 |
| --- | --- |
| 读写 | 既能读取纸带符号，也能改写符号 |
| 读头移动 | 可向左或向右移动 |
| 存储 | 纸带无限，且可用来保存计算中的信息 |
| 停机输出 | 进入指定的接受态或拒绝态即停机 |

图灵机 $M$ 是七元组：

$$
M=(Q,\Sigma,\Gamma,\delta,q_0,q_{\mathrm{accept}},q_{\mathrm{reject}})
$$

| 分量 | 含义与约束 |
| --- | --- |
| $Q$ | 有限状态集合 |
| $\Sigma$ | 输入字母表，不含空白符 $\sqcup$ |
| $\Gamma$ | 纸带字母表；$\Sigma\subseteq\Gamma$ 且 $\sqcup\in\Gamma$ |
| $\delta$ | 转移函数：$\delta:Q\times\Gamma\to Q\times\Gamma\times\{L,R\}$ |
| $q_0$ | 初始状态，$q_0\in Q$ |
| $q_{\mathrm{accept}}$ | 接受态，$q_{\mathrm{accept}}\in Q$ |
| $q_{\mathrm{reject}}$ | 拒绝态，$q_{\mathrm{reject}}\in Q$ 且 $q_{\mathrm{accept}}\ne q_{\mathrm{reject}}$ |

读到状态 $q$ 和当前符号 $b$ 时，若 $\delta(q,b)=(q',c,R)$，机器把 $b$ 改写为 $c$、转到 $q'$，再向右移动；方向为 $L$ 时则向左移动。接受态和拒绝态是停机状态，不再产生后继格局。等价地，可把转移函数定义在 $Q'=Q-\{q_{\mathrm{accept}},q_{\mathrm{reject}}\}$ 上，避免为两个停机态指定转移。

## 5.1.2 格局与计算

**格局 configuration**记录某一时刻的当前状态、纸带内容和读头位置。记作 $u q v$：状态为 $q$，当前纸带的有限非空白部分为 $uv$，读头正对 $v$ 的第一个符号；最后一个已写符号之后均为 $\sqcup$。例如 $1011q01111$ 表示当前状态为 $q$，读头读到右侧串的第一个 $0$。

若转移函数满足相应条件，一步产出关系 $C_1\vdash C_2$ 如下：

$$
\begin{aligned}
\delta(q_i,b)=(q_j,c,L)&\quad\Longrightarrow\quad uaq_ibv\vdash uq_jacv,\\
\delta(q_i,b)=(q_j,c,R)&\quad\Longrightarrow\quad uaq_ibv\vdash uacq_jv.
\end{aligned}
$$

在所写格局的最左端没有显式前缀 $a$ 时，课件的边界约定为：左移时 $q_i b v\vdash q_j c v$，右移时 $q_i b v\vdash c q_j v$。到纸带右侧已写内容末端时，可把格局 $u a q_i$ 看作 $u a q_i\sqcup$，即读头仍可读取后续空白格。

在输入 $w$ 上的初始格局是 $q_0w$。若存在有限格局序列 $C_1,C_2,\ldots,C_k$，满足 $C_1$ 为初始格局、每个 $C_i\vdash C_{i+1}$，且 $C_k$ 为接受格局，则 $M$ 接受 $w$。$M$ 接受的所有串组成其语言：

$$
L(M)=\{w\in\Sigma^*\mid M\text{ accepts }w\}.
$$

接受格局与拒绝格局分别含 $q_{\mathrm{accept}}$ 和 $q_{\mathrm{reject}}$；二者均为停机格局。

## 5.1.3 设计例：比较两份相同的串

令

$$
B=\{w\#w\mid w\in\{0,1\}^*\}.
$$

机器 $M_1$ 判定输入是否属于 $B$：从左边取最左侧尚未核对的 $0$ 或 $1$，把它改写为 $x$ 并记住其值；越过分隔符 $\#$ 后，找到右侧最左的未核对符号并比较。相同则也改写为 $x$，随后返回左端开始下一轮。若找不到分隔符、符号不相同或右侧长度不匹配，则拒绝；左侧处理完后，只有右侧也全被标记并到达空白格才接受。空串对应输入 `#`，检查右侧为空后接受。

| 状态 | 扫描阶段 | 关键动作 |
| --- | --- | --- |
| $q_1$ | 选取左侧最左未标记符号 | 读到 $0$ 或 $1$ 时写 $x$，分别转入记住该值的分支；读到 $\#$ 时开始检查右侧剩余内容 |
| $q_2,q_3$ | 向右扫描左半部，直到 $\#$ | 越过左半部字符；按刚才记住的值选择右半部匹配分支 |
| $q_4,q_5$ | 在右半部跳过已标记的 $x$ | 必须找到与左半部相同的 $0$ 或 $1$，将其写为 $x$ 后向左返回 |
| $q_6,q_7$ | 返回左半部并定位下一轮起点 | 越过分隔符和已处理内容，回到左半部最左侧未处理位置 |
| $q_8$ | 左半部已处理完，检查右半部 | 只越过 $x$；到达空白格则接受，尚有未匹配的 $0$ 或 $1$ 则不能接受 |

以课件中的输入 `011000#011000` 为例，以下各行表示**每轮匹配结束后的带内容**，省略了轮内逐格扫描的中间格局：

```text
开始：    q1 011000#011000
第 1 轮： x11000#x11000    配对左侧 0 与右侧 0
第 2 轮： xx1000#xx1000    配对左侧 1 与右侧 1
第 3 轮： xxx000#xxx000    配对左侧 1 与右侧 1
第 4 轮： xxxx00#xxxx00    配对左侧 0 与右侧 0
第 5 轮： xxxxx0#xxxxx0    配对左侧 0 与右侧 0
第 6 轮： xxxxxx#xxxxxx    配对左侧 0 与右侧 0
结束：    q1 读到 #，q8 越过右侧全部 x 到达空白格，接受
```

其中 $x$ 是“已核对”的记号，而不是输入符号；输入字母表为 $\{0,1,\#\}$，纸带字母表还需包含 $x$ 和空白符。课件状态图用不同状态记住待比较的符号，并以“标记—右移匹配—返回”的循环实现上述过程。

## 5.1.4 图灵可识别与图灵可判定

| 概念 | 机器要求 | 输入不属于语言时的可能结果 |
| --- | --- | --- |
| 图灵可识别 Turing-recognizable（递归可枚举） | 存在图灵机在语言中的每个输入上接受 | 拒绝，或一直运行而不停机 |
| 图灵可判定 Turing-decidable（可判定、递归） | 存在图灵机在每个输入上都停机；属于语言则接受，不属于则拒绝 | 必定停机并拒绝 |

图灵机启动后有三种结果：接受、拒绝或循环（不停止）。识别器无法接受某个输入，既可能是已拒绝，也可能只是运行很久或永不停机；因此“尚未接受”本身不能说明它最终会拒绝。若机器对所有输入都停机，称为**判定器 decider**。每个可判定语言都可识别。

课件给出的语言类包含关系为：

$$
\text{正则语言}\subseteq\text{上下文无关语言}\subseteq\text{可判定语言}\subseteq\text{图灵可识别语言}.
$$

特别地，**每个上下文无关语言都是可判定的**。图灵可识别类还包含可判定类；反之并未由上述定理保证。

# 5.2 图灵机的变形

多带图灵机、非确定型图灵机和枚举器可以换一种方式表达计算。课件列出的等价结论表明，前两种变形不改变图灵机可识别的语言范围；枚举器则刻画可识别语言。

| 模型 | 运行方式 | 课件给出的结论 |
| --- | --- | --- |
| 多带图灵机 Multitape TM | 多条纸带各有读写头；一步依据各带当前符号执行转移 | 每台多带图灵机都有等价的单带图灵机 |
| 非确定型图灵机 NTM | 同一状态和带符号可对应多个后继动作；转移为 $\delta:Q\times\Gamma\to\mathcal{P}(Q\times\Gamma\times\{L,R\})$ | 每台非确定型图灵机都有等价的确定型图灵机 |
| 枚举器 Enumerator | 逐个输出字符串，以输出过的串构成其枚举语言 | 语言图灵可识别，当且仅当存在枚举它的枚举器 |

“等价”指计算能力相同，即识别同一语言；机器结构和执行路径可以不同。课件还把“与其他模型的等价性”列入本节提纲，具体给出的结论包括多带机与单带机、非确定机与确定机，以及识别器与枚举器之间的对应关系。

# 5.3 算法的定义：邱奇-图灵论题

课件在这一部分列出 **Hilbert’s Problems** 作为背景主题，随后用下式概括邱奇-图灵论题：

$$
\text{算法的直观概念}\quad=\quad\text{图灵机算法}.
$$

论题主张：凡是直观上能按明确、机械步骤完成的算法计算，都可由图灵机表达；反过来，图灵机也是这种算法过程的形式模型。它把非形式化的“什么算算法”与精确定义的图灵机计算联系起来。这里是关于算法含义的基本论题，不是由七元组定义直接推出的定理。

# 5.5 考前速查表

| 题目出现 | 立刻想到 |
| --- | --- |
| 给出七元组或问空白符 | $\Sigma$ 不含 $\sqcup$；$\Gamma$ 含 $\Sigma$ 与 $\sqcup$；$\delta$ 同时确定新状态、写入符号和移动方向 |
| 要写格局或一步计算 | $u q v$ 中读头位于 $v$ 首符号；左移/右移时状态符号的位置随读头改变 |
| 机器在输入外循环 | 可能是识别器：非成员允许不停机；若要求判定，必须保证每个输入停机 |

| 比较可识别与可判定 | 可判定 $\Rightarrow$ 可识别；识别器在非成员上可能循环 |
| 多带或非确定机 | 与单带确定型图灵机识别能力等价 |
| 枚举器与语言识别 | 可识别 $\Longleftrightarrow$ 可由枚举器枚举 |
| 问“什么是算法” | 邱奇-图灵论题：直观算法的计算范围等于图灵机算法的计算范围 |
