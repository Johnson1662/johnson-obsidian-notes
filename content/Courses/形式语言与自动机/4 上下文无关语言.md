# 4 上下文无关语言

一句话：正则语言记不住 $0^n1^n$ 这种“配对计数”，给机器加一个**栈**就成了**下推自动机（PDA）**；**上下文无关文法（CFG，生成视角）与 PDA（识别视角）能力完全等价**，配套工具是二义性分析与乔姆斯基范式，天花板由 **CFL 泵引理（五段分解）** 划定。

## 总览（思维导图）

$$
\text{4 上下文无关语言}
\begin{cases}
\text{CFG}
\begin{cases}
G=(V,\Sigma,R,S)\\
\Rightarrow\ \text{直接推导},\ \Rightarrow^{*}\ \text{推导}\\
\text{设计四套路},\ \text{二义性}\\
\text{乔姆斯基范式}
\end{cases}\\[4pt]
\text{PDA}
\begin{cases}
6\text{ 元组}+\text{栈}\ (\text{LIFO})\\
\delta:Q\times\Sigma_\varepsilon\times\Gamma_\varepsilon\to\mathcal{P}(Q\times\Gamma_\varepsilon)\\
\text{CFG}\equiv\text{PDA}
\end{cases}\\[4pt]
\text{限制}
\begin{cases}
\text{CFL 泵引理：}s=uvxyz\\
\text{非 CFL 的判定素材}
\end{cases}
\end{cases}
$$

# 4.1 上下文无关文法（Part 1 · 1 Context-Free Grammars）

## 4.1.1 从正则到上下文无关

|          | 正则语言              | 上下文无关语言                                          |
| -------- | --------------------- | ------------------------------------------------------- |
| 识别器   | DFA / NFA；正则表达式 | 下推自动机 PDA                                          |
| 起源     | —                     | 最早用于人类语言研究                                    |
| 应用     | 词法                  | **编程语言的规范与编译**（parser：从 CFG 造语法分析器） |
| 典型反例 | $0^n1^n$ 不是正则     | $0^n1^n$ 是上下文无关的                                 |

## 4.1.2 CFG 的形式定义与推导

**CFG 是 4 元组** $(V,\Sigma,R,S)$：

| 成分     | 含义                                                    |
| -------- | ------------------------------------------------------- |
| $V$      | 有限的变元集                                            |
| $\Sigma$ | 有限的终结符集，与 $V$ 不相交                           |
| $R$      | 有限的规则（产生式）集：每条 = 一个变元 + 变元/终结符串 |
| $S\in V$ | 起始变元                                                |

| 记号                 | 含义                                                                                                |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| $uAv\Rightarrow uwv$ | **直接推导**（yields）：用了规则 $A\to w$                                                           |
| $u\Rightarrow^{*}v$  | **推导**（derives）：$u=v$ 或存在链 $u\Rightarrow u_1\Rightarrow\cdots\Rightarrow u_k\Rightarrow v$ |
| $L(G)$               | $\{w\in\Sigma^{*}\mid S\Rightarrow^{*}w\}$（文法的语言）                                            |

**例 $G_1$**：$V=\{A,B\}$，$\Sigma=\{0,1,\#\}$，$S=A$，$R$：$A\to0A1\mid B$，$B\to\#$。

```text
推导：A ⇒ 0A1 ⇒ 00A11 ⇒ 000A111 ⇒ 000B111 ⇒ 000#111
L(G1) = { 0ⁿ # 1ⁿ | n ≥ 0 }
```

多条右部可简写：$A\to0A1$ 与 $A\to B$ 合并成 $A\to0A1\mid B$。

## 4.1.3 例子集

| 语法                | 规则                                                                                                         | 说明                                                                    |
| ------------------- | ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| $G_2$（英语句型）   | 见下代码块                                                                                                   | 能生成 `the boy sees a flower`、`a girl with a flower likes the boy`    |
| $G_3$               | $S\to aSb\mid SS\mid\varepsilon$                                                                             | $\{a^nb^n\}$ 及其“拼接变体”                                             |
| $G_4$（算术表达式） | $<EXPR>\to<EXPR>+<TERM>\mid<TERM>$；$<TERM>\to<TERM>\times<FACTOR>\mid<FACTOR>$；$<FACTOR>\to(<EXPR>)\mid a$ | 生成 $a+a\times a$、$(a+a)\times a$；**无二义**（优先级被文法结构固定） |

```text
<SENTENCE>    ::= <NOUN-PHRASE><VERB-PHRASE>
<NOUN-PHRASE> ::= <CMPLX-NOUN> | <CMPLX-NOUN><PREP-PHRASE>
<VERB-PHRASE> ::= <CMPLX-VERB> | <CMPLX-VERB><PREP-PHRASE>
<PREP-PHRASE> ::= <PREP><CMPLX-NOUN>
<CMPLX-NOUN>  ::= <ARTICLE><NOUN>
<CMPLX-VERB>  ::= <VERB> | <VERB><NOUN-PHRASE>
<ARTICLE>     ::= a | the
<NOUN>        ::= boy | girl | flower
<VERB>        ::= touches | likes | sees
<PREP>        ::= with
```

## 4.1.4 设计 CFG 的四种套路

| 套路                 | 做法                            | 例                                                                                                                    |
| -------------------- | ------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| (1) 并集             | 若干简单 CFL 用新起始变元并起来 | $0^n1^n\cup1^n0^n$：$S\to S_1\mid S_2$，$S_1\to0S_11\mid\varepsilon$，$S_2\to1S_20\mid\varepsilon$                    |
| (2) 语言本身是正则的 | 把 DFA 直接翻译成 CFG           | 每个状态 $q_i$ 造变元 $R_i$；$\delta(q_i,a)=q_j\Rightarrow R_i\to aR_j$；接受态 $R_i\to\varepsilon$；$R_0$ 当起始变元 |
| (3) 两段式夹心       | 语言串里有两块要配对的子串      | 用 $R\to uRv$：一边加 $u$ 一边加 $v$                                                                                  |
| (4) 递归结构         | 结构自己套自己                  | 算术表达式（$G_4$ 的分层）                                                                                            |

## 4.1.5 二义性（Ambiguity）

| 概念         | 定义                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| 最左推导     | 每一步都替换**最左边**的剩余变元                                               |
| 串二义       | 同一串有 **2 条以上不同的最左推导**                                            |
| 文法二义     | 该文法至少能二义地生成某个串                                                   |
| 固有二义语言 | **只能**用二义文法生成的语言，如 $\{a^{i}b^{j}c^{k}\mid i=j\ \text{或}\ j=k\}$ |

典型对比：

|               | $G_5$（单层表达式文法）                                          | $G_4$（分层表达式文法） |
| ------------- | ---------------------------------------------------------------- | ----------------------- |
| 规则          | $<EXPR>\to<EXPR>+<EXPR>\mid<EXPR>\times<EXPR>\mid(<EXPR>)\mid a$ | 见 4.1.3                |
| $a+a\times a$ | **两棵**语法树（先加还是先乘不定）                               | 一棵                    |
| 结论          | 二义（不体现优先级）                                             | 无二义                  |

$G_2$ 也二义：`the girl touches the boy with the flower`（`with the flower` 修饰动词还是名词？）。

## 4.1.6 乔姆斯基范式（CNF）

**定义**：每条规则形如 $A\to BC$ 或 $B\to a$（$a$ 为终结符，$A,B,C$ 为变元，**$B,C$ 不能是起始变元**）；另外允许 $S\to\varepsilon$。

**定理**：任何上下文无关语言都存在一个处于乔姆斯基范式的 CFG 产生它。

**转换四步**（把违规规则换成等价的合格规则）：

| 步骤                    | 动作                                                                                                                                                                                                             |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 加新起始变元          | 加 $S_0\to S$，保证起始变元不出现在任何右部                                                                                                                                                                      |
| 2 消 $\varepsilon$ 规则 | 去掉 $A\to\varepsilon$（$A$ 非起始）：对右部每个 $A$ 的出现位置删掉它再写一条 $R\to uAv\Rightarrow R\to uv$；若原有 $R\to A$ 则补 $R\to\varepsilon$（先前已删的除外）；循环到除起始变元外没有 $\varepsilon$ 规则 |
| 3 消单位规则            | 去掉 $A\to B$：凡出现 $B\to u$ 就补 $A\to u$（先前已删的除外）；循环到没有单位规则                                                                                                                               |
| 4 拉直成长规则          | $A\to u_1u_2\cdots u_k$（$k\geqslant3$）拆成 $A\to u_1A_1,\ A_1\to u_2A_2,\ \dots,\ A_{k-2}\to u_{k-1}u_k$（$A_i$ 全新变元）；再把其中的终结符 $u_i$ 换成新变元 $U_i$ 并加 $U_i\to u_i$                          |

**例**：$G_6$：$S\to ASA\mid aB$，$A\to B\mid S\mid\varepsilon$，$B\to b\mid\varepsilon$。

```text
1 加 S0 → S
2 消 ε 规则：S → ASA | aB | a；A → B | S | ε（A→ε 再消，派生 SA/AS/S 等）
3 消单位规则：S0 → S | ASA | aB | a | SA | AS；
   A → S | b | ASA | aB | a | SA | AS …
4 拉直 + 终结符变量化，得等价 CNF：
   S0 → A A1 | U B | a | S A | A S
   S  → A A1 | U B | a | S A | A S
   A  → b | A A1 | U B | a | S A | A S
   A1 → S A        U → a        B → b
```

# 4.2 下推自动机（Part 1 · 2 / Part 2 · 2 Pushdown Automata）

## 4.2.1 栈带来的新能力

| 要点               | 内容                                                                                                                             |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| 结构               | 像 NFA，但多一个**栈**组件；栈提供控制部分之外的**无限**记忆                                                                     |
| 栈操作             | 只能动栈顶：**push**（压入）、**pop**（弹出）；后进先出                                                                          |
| 能力               | 能识别 $\{0^n1^n\mid n\geqslant0\}$ 这类非正则语言                                                                               |
| 与 CFG 关系        | **PDA 与 CFG 能力等价**；证“某语言上下文无关”二选一：给一个 CFG（生成器）或给一个 PDA（识别器）                                  |
| 确定性 vs 非确定性 | **与 DFA/NFA 不同**：确定型 PDA 与非确定型 PDA **不等价**（NPDA 能认一些 DPDA 认不了的语言）；课件聚焦 NPDA，因为它才与 CFG 等价 |

## 4.2.2 PDA 的形式定义

**PDA 是 6 元组** $(Q,\Sigma,\Gamma,\delta,q_0,F)$：

| 成分                                                                                                | 含义                                       |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| $Q$                                                                                                 | 有限状态集                                 |
| $\Sigma$                                                                                            | 输入字母表                                 |
| $\Gamma$                                                                                            | 栈字母表                                   |
| $\delta:Q\times\Sigma_\varepsilon\times\Gamma_\varepsilon\to\mathcal{P}(Q\times\Gamma_\varepsilon)$ | 转移函数（输入、栈顶均可取 $\varepsilon$） |
| $q_0\in Q$                                                                                          | 起始状态                                   |
| $F\subseteq Q$                                                                                      | 接受状态集                                 |

**接受计算的三条件**（$w=a_1\cdots a_m$，$a_i\in\Sigma_\varepsilon$；存在状态列 $r_0,\dots,r_m$ 与栈内容列 $s_0,\dots,s_m\in\Gamma^{*}$）：

1. $r_0=q_0$ 且 $s_0=\varepsilon$（栈起始为空）；
2. 对 $i=0,\dots,m-1$：$(r_{i+1},b)\in\delta(r_i,a_{i+1},a)$，其中 $s_i=at$、$s_{i+1}=bt$（某 $a,b\in\Gamma_\varepsilon$、$t\in\Gamma^{*}$——即只动栈顶）；
3. $r_m\in F$。

## 4.2.3 例：识别 $0^n1^n$ 的 $M_1$

$$M_1=(\{q_1,q_2,q_3,q_4\},\{0,1\},\{0,\$\},\delta,q_1,\{q_1,q_4\})$$

状态图（输入, 弹出 → 压入）：

```text
q1 (接受态) -- ε, ε→$ --> q2        开始：压入底标记 $
q2 -- 0, ε→0 --> q2                 读 0：压一个 0（自环）
q2 -- 1, 0→ε --> q3                 读第一个 1：弹一个 0
q3 -- 1, 0→ε --> q3                 继续读 1：逐个弹 0（自环）
q3 -- ε, $→ε --> q4 (接受态)        弹掉底标记，确认 0、1 配平
```

对应的 $\delta$ 表（空白 = $\varnothing$，`$` 表示栈底标记）：

| 状态 | 输入 0           | 输入 1           | 输入 $\varepsilon$   |
| ---- | ---------------- | ---------------- | -------------------- |
| q1   |                  |                  | `{(q2, $)}` 压入栈底 |
| q2   | `{(q2, 0)}` 压 0 | `{(q3, ε)}` 弹 0 |                      |
| q3   |                  | `{(q3, ε)}` 弹 0 | `{(q4, ε)}` 弹出栈底 |
| q4   |                  |                  |                      |

| 例    | 识别的语言                                                                | 要点                                     |
| ----- | ------------------------------------------------------------------------- | ---------------------------------------- |
| $M_1$ | $\{0^n1^n\mid n\geqslant0\}$                                              | 压 0 配 1，$n=0$ 由 $q_1$ 直接接受       |
| $M_2$ | $\{a^{i}b^{j}c^{k}\mid i,j,k\geqslant0\ \text{且}\ i=j\ \text{或}\ i=k\}$ | 非确定性地“选一边”配平（$i=j$ 或 $i=k$） |
| $M_3$ | $\{ww^{R}\mid w\in\{0,1\}^{*}\}$                                          | 前半压栈、后半弹栈匹配回文               |

## 4.2.4 与 CFG 的等价

| 结论     | 内容                                              |
| -------- | ------------------------------------------------- |
| 引理 1   | 语言上下文无关 $\Rightarrow$ 某 PDA 识别它        |
| 引理 2   | 某 PDA 识别它 $\Rightarrow$ 语言上下文无关        |
| **定理** | 语言上下文无关 $\iff$ 某 PDA 识别它（两引理合并） |
| 推论     | **每个正则语言都是上下文无关语言**                |

# 4.3 非上下文无关语言（Part 2 · 3 Non-Context-Free Languages）

**CFL 泵引理**：若 $A$ 是上下文无关语言，则存在泵长度 $p$：任何 $s\in A$、$\lvert s\rvert\geqslant p$，都能分成**五段** $s=uvxyz$，满足：

1. 对每个 $i\geqslant0$，$uv^{i}xy^{i}z\in A$；
2. $\lvert vy\rvert>0$；
3. $\lvert vxy\rvert\leqslant p$。

> 与正则泵引理对照：三段 $xyz$ 变五段，$v$、$y$ **两处同时泵**（对应 CFG 推导树的两层对称扩张），$\varepsilon$ 限制从 $\lvert xy\rvert$ 变 $\lvert vxy\rvert$。用法同样是“反设正则/上下文无关 → 选串 → 穷举分段 → 矛盾”。

# 4.4 本章小结

$$
\left.
\begin{array}{ll}
\text{CFG} & G=(V,\Sigma,R,S);\ uAv\Rightarrow uwv;\ L(G)=\{w\mid S\Rightarrow^{*}w\}\\[2pt]
\text{设计} & \text{并集、DFA}\to\text{CFG、}uRv\text{ 夹心、递归结构}\\[2pt]
\text{二义性} & \text{两条最左推导}=\text{二义};\ \text{固有二义如}\ a^ib^jc^k\ (i=j\ \text{或}\ j=k)\\[2pt]
\text{CNF} & A\to BC\ /\ B\to a\ /\ \text{允许}\ S\to\varepsilon;\ \text{四步：新起始、消}\varepsilon\\[2pt]
 & \text{消单位、拉直+终结符变量化}\\[2pt]
\text{PDA} & 6\text{ 元组};\ \delta:Q\times\Sigma_\varepsilon\times\Gamma_\varepsilon\to\mathcal{P}(Q\times\Gamma_\varepsilon)\\[2pt]
\text{等价} & \text{CFG}\iff\text{PDA};\ \text{正则}\subset\text{CFL};\ \text{DPDA}\neq\text{NPDA}\\[2pt]
\text{CFL 泵引理} & s=uvxyz:\ uv^ixy^iz\in A,\ \lvert vy\rvert>0,\ \lvert vxy\rvert\leqslant p
\end{array}
\right\}
$$
