# 3 正则语言

一句话：正则语言有四种等价说法——**DFA 识别、NFA 识别、正则表达式描述、正则文法生成**；DFA/NFA 的能力通过**子集构造**划等号，三个正则运算下**封闭**，而**泵引理**给出它的天花板：$0^n1^n$ 这类“要无限计数”的语言不是正则的。

## 总览（思维导图）

$$
\text{3 正则语言}
\begin{cases}
\text{有限自动机}
\begin{cases}
\text{DFA：}\delta:Q\times\Sigma\to Q\\
\text{NFA：}\delta:Q\times\Sigma_\varepsilon\to\mathcal{P}(Q)\\
\text{子集构造：}\text{NFA}\equiv\text{DFA}
\end{cases}\\[4pt]
\text{封闭性}
\begin{cases}
\cup,\ \circ,\ *\ \text{都封闭}\\
\text{乘积构造 / 并联 / 新起点}
\end{cases}\\[4pt]
\text{正则表达式}
\begin{cases}
\text{6 种构造}\\
\text{RE}\leftrightarrow\text{FA（GNFA 拆状态）}
\end{cases}\\[4pt]
\text{限制}
\begin{cases}
\text{泵引理：}s=xyz\ \text{可泵}\\
\text{反证法：}0^n1^n\ \text{非正则}
\end{cases}\\[4pt]
\text{RG}\equiv\text{FA（补充）}
\end{cases}
$$

| 泵引理             | 三条件、证明思想（鸽笼）、四步用法、五个例题选串                     | **最高** |
| 正则运算封闭性     | 并（乘积）、连接（$\varepsilon$ 跳转）、星（新起点回环）的构造       | 高       |

# 3.1 有限自动机（Part 1 · 1 Finite Automata）

## 3.1.1 DFA 的形式定义

**确定型有穷自动机（DFA）是 5 元组** $(Q,\Sigma,\delta,q_0,F)$：

| 成分                        | 含义                                           |
| --------------------------- | ---------------------------------------------- |
| $Q$                         | 有限的状态集                                   |
| $\Sigma$                    | 有限的字母表                                   |
| $\delta:Q\times\Sigma\to Q$ | 转移函数（**每个状态、每个符号恰有一条出边**） |
| $q_0\in Q$                  | 起始状态                                       |
| $F\subseteq Q$              | 接受状态集                                     |

## 3.1.2 例：$M_1$ 与它的语言

$M_1=(\{q_1,q_2,q_3\},\{0,1\},\delta,q_1,\{q_2\})$，转移表：

| $\delta$ | 0     | 1     |
| -------- | ----- | ----- |
| $q_1$    | $q_1$ | $q_2$ |
| $q_2$    | $q_3$ | $q_2$ |
| $q_3$    | $q_2$ | $q_2$ |

喂入 $1101$ 的走带过程：

```text
1 起点 q1
2 读 1：q1 → q2
3 读 1：q2 → q2
4 读 0：q2 → q3
5 读 1：q3 → q2
6 输入结束停在接受态 q2 → 接受
```

$L(M_1)=\{w\mid w$ 至少含一个 1，且最后一个 1 后面有偶数个 $0\}$。

**机器的语言**：$M$ 接受的全体串 $A$ 记作 $L(M)=A$，称 $M$ **识别** $A$；一台机器可以接受很多串，但只识别一个语言；一个串都不接受的语言（空语言）也合法。

其余小例：

| 机器           | 定义要点                                                                     | $L(M)$                                              |
| -------------- | ---------------------------------------------------------------------------- | --------------------------------------------------- |
| $M_2$          | $\{q_1,q_2\}$，$\delta$：两状态读 0 都回 $q_1$、读 1 都去 $q_2$，$F=\{q_2\}$ | 以 1 结尾的串                                       |
| $M_3$          | 与 $M_2$ 同 $\delta$，$F=\{q_1\}$                                            | 课件设问（按表推得）：“以 0 结尾，含 $\varepsilon$” |
| $B_i$（$M_5$） | $Q_i=\{q_0,\dots,q_{i-1\}}$，数字和模 $i$ 计数，$<RESET>$ 归零               | 和 $\equiv0\ (\mathrm{mod}\ i)$，遇 $<RESET>$ 清零  |

$M_5$（课件该例标 $i=3$；$\Sigma=\{<RESET>,0,1,2\}$）算 $w=10<RESET>22<RESET>012$（课件讲义直接给出该 10 符号的状态序列）：

```text
状态序列：q0,q1,q1,q0,q2,q1,q0,q0,q1,q0  → 末态 q0 ∈ F，接受
δi(qj,0)=qj；δi(qj,1)=q(j+1 mod i)；δi(qj,2)=q(j+2 mod i)；δi(qj,<RESET>)=q0
```

## 3.1.3 计算的三条件与正则语言定义

设 $M=(Q,\Sigma,\delta,q_0,F)$ 是 DFA，$w=a_1a_2\cdots a_n$。**$M$ 接受 $w$** 当且仅当存在状态序列 $r_0,r_1,\dots,r_n$：

1. $r_0=q_0$；
2. $\delta(r_i,a_{i+1})=r_{i+1}$，$i=0,\dots,n-1$；
3. $r_n\in F$。

**定义（正则语言）**：某个 DFA 识别的语言叫正则语言。

> “reader as automaton”：设计时把自己当成机器，看自己怎么读串。

## 3.1.4 设计自动机

| 语言                    | 状态怎么设                                                                           |
| ----------------------- | ------------------------------------------------------------------------------------ |
| 1 的个数为奇数（$E_1$） | $q_{even}$（目前偶数个 1）、$q_{odd}$（目前奇数个 1）                                |
| 含子串 $001$（$E_2$）   | $q$（尚未匹配任何符号）、$q_0$（刚见 0）、$q_{00}$（刚见 00）、$q_{001}$（整串已见） |
| 数字和模 $i$（$B_i$）   | 每个状态代表“当前和 $\bmod i$”的余数                                                 |

# 3.2 非确定性与封闭性（Part 1 · 2 Nondeterminism）

## 3.2.1 确定性 vs 非确定性

|                  | DFA       | NFA                                  |
| ---------------- | --------- | ------------------------------------ |
| 每个符号的出边   | 恰好 1 条 | 0 条、1 条或多条                     |
| $\varepsilon$ 边 | 不允许    | 允许（不读符号换状态）               |
| 下一步           | 唯一确定  | 多个选择“同时”尝试，任一路接受即接受 |

非确定性是确定性的推广：**每个 DFA 本身就是一台 NFA**。NFA 好处：描述某个语言常常比 DFA 容易得多。

## 3.2.2 NFA 的形式定义与例子

NFA 也是 5 元组 $(Q,\Sigma,\delta,q_0,F)$，区别只在：

$$
\delta:Q\times\Sigma_\varepsilon\to\mathcal{P}(Q),\qquad \Sigma_\varepsilon=\Sigma\cup\{\varepsilon\}
$$

$\mathcal{P}(Q)$ 是 $Q$ 的幂集。**接受**：可把 $w$ 写成 $a_1\cdots a_n$（$a_i\in\Sigma_\varepsilon$，$\varepsilon$ 可凭空混入）且存在 $r_0,\dots,r_n$ 满足 $r_0=q_0$、$r_{i+1}\in\delta(r_i,a_{i+1})$、$r_n\in F$。

| 例    | 语言                                                  | 要点                                                  |
| ----- | ----------------------------------------------------- | ----------------------------------------------------- |
| $N_1$ | 含子串 $101$ 或 $11$                                  | $Q=\{q_1,q_2,q_3,q_4\}$，$F=\{q_4\}$；$\delta$ 表见下 |
| $N_2$ | 倒数第 3 位是 1 的串（$000100\in A$，$0011\notin A$） | NFA 可“猜”哪一段是结尾                                |
| $N_3$ | $0^k$，$k$ 是 2 或 3 的倍数                           | $\varepsilon$ 边的便利：分支跳两条计数链              |

$N_1$ 的转移表（$\varepsilon$ 列即免费跳转）：

| $\delta$ | 0             | 1             | $\varepsilon$ |
| -------- | ------------- | ------------- | ------------- |
| $q_1$    | $\{q_1\}$     | $\{q_1,q_2\}$ | $\varnothing$ |
| $q_2$    | $\{q_3\}$     | $\varnothing$ | $\{q_3\}$     |
| $q_3$    | $\varnothing$ | $\{q_4\}$     | $\varnothing$ |
| $q_4$    | $\{q_4\}$     | $\{q_4\}$     | $\varnothing$ |

## 3.2.3 子集构造：NFA ≡ DFA（核心定理）

**定理**：每台 NFA 都有等价的 DFA。
**推论**：语言正则 $\iff$ 某台 NFA 识别它。

构造（先设无 $\varepsilon$ 边，再补 $\varepsilon$）：

| 要素           | 无 $\varepsilon$ 边           | 含 $\varepsilon$ 边                                |
| -------------- | ----------------------------- | -------------------------------------------------- |
| $Q'$           | $\mathcal{P}(Q)$              | $\mathcal{P}(Q)$                                   |
| $\delta'(R,a)$ | $\bigcup_{r\in R}\delta(r,a)$ | $\{q\in Q\mid q\in E(\delta(r,a))$ 对某 $r\in R\}$ |
| $q_0'$         | $\{q_0\}$                     | $E(\{q_0\})$                                       |
| $F'$           | 含 NFA 接受态的集合 $R$       | 同左                                               |

其中 $E(R)=\{q\mid q$ 可从 $R$ 出发沿 0 条或多条 $\varepsilon$ 边到达$\}$（含 $R$ 自身）。

例：$N_4$（$Q=\{1,2,3\}$，$q_0=1$，$F=\{1\}$，$\Sigma=\{a,b\}$）→ DFA $D$：

```text
Q' = {∅,{1},{2},{3},{1,2},{1,3},{2,3},{1,2,3}}
q0' = E({1}) = {1,3}
F'  = {{1},{1,2},{1,3},{1,2,3}}
无箭头指向的状态 {1}、{1,2} 可删（不影响行为）
```

## 3.2.4 正则运算与封闭性

**三个正则运算**（$A,B$ 为语言）：

| 运算            | 定义                                                           | 例（$\Sigma=\{a,\dots,z\}$，$A=\{$good, bad$\}$，$B=\{$boy, girl$\}$） |
| --------------- | -------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 并 $A\cup B$    | $\{x\mid x\in A$ 或 $x\in B\}$                                 | $\{$good, bad, boy, girl$\}$                                           |
| 连接 $A\circ B$ | $\{xy\mid x\in A,\ y\in B\}$                                   | $\{$goodboy, goodgirl, badboy, badgirl$\}$                             |
| 星 $A^*$        | $\{x_1x_2\cdots x_k\mid k\geqslant0,\ \text{每个}\ x_i\in A\}$ | $\{\varepsilon$, good, bad, goodgood, goodbad, …$\}$                   |

**三条封闭性定理与构造**：

| 封闭性         | 构造 $N$                                               | 关键规则                                                                                                                                                                                                                                         |
| -------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| $A_1\cup A_2$  | $Q=Q_1\times Q_2$（配对状态）                          | $\delta((r_1,r_2),a)=(\delta_1(r_1,a),\delta_2(r_2,a))$；$q_0=(q_1,q_2)$；$F=\{(r_1,r_2)\mid r_1\in F_1\ \text{或}\ r_2\in F_2\}$                                                                                                                |
| $A_1\circ A_2$ | $Q=Q_1\cup Q_2$，起点用 $q_1$，接受态用 $F_2$          | $q\in Q_1\setminus F_1\Rightarrow\delta_1$；$q\in F_1,a\neq\varepsilon\Rightarrow\delta_1$；$q\in F_1,a=\varepsilon\Rightarrow\delta_1(q,a)\cup\{q_2\}$；$q\in Q_2\Rightarrow\delta_2$                                                           |
| $A_1^*$        | $Q=\{q_0\}\cup Q_1$，新起点 $q_0$，$F=\{q_0\}\cup F_1$ | $q\in Q_1\setminus F_1\Rightarrow\delta_1$；$q\in F_1,a\neq\varepsilon\Rightarrow\delta_1$；$q\in F_1,a=\varepsilon\Rightarrow\delta_1(q,a)\cup\{q_1\}$；$q=q_0,a=\varepsilon\Rightarrow\{q_1\}$；$q=q_0,a\neq\varepsilon\Rightarrow\varnothing$ |

> 连接的难点：“$M$ 不知道该在哪儿把输入切开”——所以用 $\varepsilon$ 边在 $F_1$ 上**猜**切点；星用新起点 $q_0$ 与 $\varepsilon$ 回边实现“重复 0 次或多次”。

# 3.3 正则表达式（Part 2 · 1 Regular Expressions）

## 3.3.1 直观与例子

算术表达式算出一个**值**，正则表达式算出一个**语言**：$0\to\{0\}$、$(0\cup1)\to\{0,1\}$、$0^*\to\{0\}^*$、$(0\cup1)0^*=(0\cup1)\circ0^*$。$\Sigma=(0\cup1)$ 是字母表的简写，$\Sigma^*$ = 全体串。

课件例（$\Sigma=\{0,1\}$）：

| 正则表达式                             | 描述的语言               |
| -------------------------------------- | ------------------------ |
| $0^*10^*$                              | 恰含一个 1               |
| $\Sigma^*1\Sigma^*$                    | 至少含一个 1             |
| $\Sigma^*001\Sigma^*$                  | 含子串 $001$             |
| $1^*(01^+)^*$                          | 每个 0 后面至少跟一个 1  |
| $(\Sigma\Sigma)^*$                     | 长度为偶数               |
| $(\Sigma\Sigma\Sigma)^*$               | 长度是 3 的倍数          |
| $01\cup10$                             | $\{01,10\}$              |
| $0\Sigma^*0\cup1\Sigma^*1\cup0\cup1$   | 首尾符号相同             |
| $(0\cup\varepsilon)1^*$                | $01^*\cup1^*$            |
| $(0\cup\varepsilon)(1\cup\varepsilon)$ | $\{\varepsilon,0,1,01\}$ |
| $1^*\varnothing$                       | $\varnothing$            |
| $\varnothing^*$                        | $\{\varepsilon\}$        |

**优先级**：星 $>$ 连接 $>$ 并；括号可改序。

## 3.3.2 形式定义与恒等式

$R$ 是正则表达式，当且仅当它是以下之一（归纳定义，6 种情况）：

1. $a$（$a\in\Sigma$）；2. $\varepsilon$；3. $\varnothing$；
2. $(R_1\cup R_2)$；5. $(R_1\circ R_2)$；6. $(R_1^*)$。

记号：$L(R)$ 是 $R$ 描述的语言；$R^+$（$RR^*$）；$R^k$（连抄 $k$ 次）；$R^+\cup\varepsilon=R^*$。

| 恒等式                | 反例（为什么不能把 $\varepsilon$、$\varnothing$ 互换）                                         |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| $R\cup\varnothing=R$  | $R\cup\varepsilon$ 未必等于 $R$：$R=0$ 时 $L=\{0\}$ 但 $L(R\cup\varepsilon)=\{0,\varepsilon\}$ |
| $R\circ\varepsilon=R$ | $R\circ\varnothing$ 未必等于 $R$：$R=0$ 时变 $\varnothing$                                     |

**应用**：编译器词法分析（token 描述）；数值常量正则例

$$
(+\cup-\cup\varepsilon)(D^+\cup D^+.D^*\cup D^*.D^+),\quad D=\{0,\dots,9\}
$$

## 3.3.3 与有限自动机等价

**定理**：语言正则 $\iff$ 某个正则表达式描述它。两个方向拆成两条引理。

**方向一（RE→NFA）**：按正则表达式的 6 种情况归纳构造 NFA——$R=a$（两状态一条边）、$R=\varepsilon$（单状态自接受）、$R=\varnothing$（无接受态）、$R_1\cup R_2 / R_1\circ R_2 / R_1^*$ 直接复用 3.2.4 的三条封闭性构造；由“NFA 识别 $\Rightarrow$ 正则”收尾。

**方向二（DFA→RE）**：引入 GNFA。

| GNFA（广义 NFA） | 定义                                                                                                                                                                                                           |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 5 元组           | $(Q,\Sigma,\delta,q_{start},q_{accept})$，**只有一个接受态**                                                                                                                                                   |
| $\delta$         | $(Q-\{q_{accept}\})\times(Q-\{q_{start}\})\to\mathcal{R}$（$\mathcal{R}$ = 全体正则表达式）                                                                                                                    |
| 接受             | $w=w_1\cdots w_k$ 且存在状态链 $q_0=q_{start},\dots,q_k=q_{accept}$，每段 $w_i\in L(\delta(q_{i-1},q_i))$（从 $q_{start}$ 出发的边允许在它加完之后保留；课件定义只禁止进入 $q_{start}$、从 $q_{accept}$ 出来） |

```text
DFA → GNFA（四步）
1 加新起点，ε 箭头指向原起点
2 加新接受态，原各接受态 ε 箭头指向它
3 同向多条箭头合并为一条，标签取并
4 没有箭头的状态对补一条 ∅ 箭头
```

GNFA → 正则表达式（**拆状态**）：若状态数 $k\geqslant2$，去掉一个非起止状态 $q_{rip}$，把经过它的路都并进直连边——对每对 $q_i,q_j$：

$$
\delta'(q_i,q_j)=R_1R_2^*R_3\cup R_4
$$

其中 $R_1=\delta(q_i,q_{rip})$，$R_2=\delta(q_{rip},q_{rip})$，$R_3=\delta(q_{rip},q_j)$，$R_4=\delta(q_i,q_j)$。反复拆到只剩 2 个状态，起点到终点那条边的标签即所求正则表达式。

**CONVERT(G)** 的正确性对状态数 $k$ 归纳：基础 $k=2$ 显然；归纳步说明 $G$ 与 $G'$ 互相接受（$q_{rip}$ 的连续段被新表达式吸收/还原），递归结果同时等价于两者。

# 3.4 非正则语言与泵引理（Part 2 · 2 Nonregular Languages）

## 3.4.1 为什么需要证明

| 语言                                           | 直觉                                  | 真相                                             |
| ---------------------------------------------- | ------------------------------------- | ------------------------------------------------ |
| $B=\{0^n1^n\mid n\geqslant0\}$                 | 要记无穷多个 0 的个数，有限状态记不住 | 非正则（课件直觉）                               |
| $C=\{w\mid w$ 中 0、1 个数相等$\}$             | 同上                                  | 非正则                                           |
| $D=\{w\mid w$ 中 $01$ 与 $10$ 出现次数相等$\}$ | 看起来也难                            | **居然是正则的**——所以必须用数学证明，直觉不算数 |

## 3.4.2 泵引理（定理）

**若 $A$ 正则，则存在泵长度 $p$**：任何 $s\in A$ 且 $\lvert s\rvert\geqslant p$，都可分成三段 $s=xyz$，满足：

1. 对每个 $i\geqslant0$，$xy^iz\in A$；
2. $\lvert y\rvert>0$；
3. $\lvert xy\rvert\leqslant p$。

若 $A$ 中没有长度 $\geqslant p$ 的串，定理平凡成立（空洞真）。

**证明思想**：取 DFA 状态数为 $p$；$\lvert s\rvert=n\geqslant p$ 时走过的状态序列长 $n+1>p$，由**鸽笼原理**必有重复状态；第一个出现位置之前为 $x$、两次之间为 $y$、之后为 $z$——$y$ 让机器回到原状态，故可任意次“泵”。$x$ 把机器从 $r_1$ 送到 $r_j$，$y$ 在 $r_j$ 打转，$z$ 送到接受态。

## 3.4.3 用泵引理证“非正则”的四步

```text
1 反设 B 正则，得到泵长度 p
2 在 B 中挑一个长度 ≥ p、且“泵不动”的串 s
3 列出 s = xyz 的所有分法（用 |xy| ≤ p 锁定 y 的位置）
   对每种分法找一个 i，使 xy^i z ∉ B
4 矛盾 → B 非正则
```

## 3.4.4 例题集（选串是关键）

| 语言                         | 选串 $s$     | 矛盾点                                                                                                                             |
| ---------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| $B=\{0^n1^n\}$               | $0^p1^p$     | 三情形：$y$ 全 0（0 多了）、$y$ 全 1（1 多了）、$y$ 含 0 和 1（顺序乱）；课件注：用条件 3 可消去情形 2、3，只留情形 1              |
| $C=\{w\mid\#0=\#1\}$         | $0^p1^p$     | 条件 3 迫使 $y$ 只含 0，$xyyz$ 中 0 多于 1；注意选 $(01)^p$ 会被泵掉（$x=\varepsilon,y=01$ 永远等量）——**选串失败就换一个**        |
| $F=\{ww\mid w\in\{0,1\}^*\}$ | $0^p10^p1$   | 条件 3 下 $y$ 只含 0，$xyyz$ 不再“前后两半相同”；$0^p0^p$ 虽属 $F$ 但泵不坏，不能用                                                |
| $D=\{1^{n^2}\}$              | $1^{p^2}$    | $\lvert xy\rvert\leqslant p\Rightarrow\lvert y\rvert\leqslant p$，故 $p^2<\lvert xy^2z\rvert\leqslant p^2+p<(p+1)^2$，不是完全平方 |
| $E=\{0^i1^j\mid i>j\}$       | $0^{p+1}1^p$ | 泵 $i=0$：$xz$ 中 $\lvert y\rvert>0$ 只削 0，使 0 不再多于 1，$\Rightarrow xz\notin E$                                             |

> $D$ 的两个方向别记反：课件这里证的是 $\{1^{n^2}\}$ 非正则（$\{1^{n^2}\}$ 即 $D$ 在该页的定义）。

# 3.5 正则文法与有限自动机的等价（Part 3 补充）

**两个定理（证明课件板书）**：

| 定理   | 方向                                                    | 结论                                    |
| ------ | ------------------------------------------------------- | --------------------------------------- |
| 定理 1 | $L$ 被正则文法 $G$ 产生 $\Rightarrow$ $L$ 被某 NFA 接受 | $G\to$ NFA（按产生式造状态与转移）      |
| 定理 2 | $L$ 被 DFA $M$ 接受 $\Rightarrow$ $L$ 被某正则文法产生  | DFA $\to$ G（状态当变元、转移当产生式） |

课件例：

```text
G1：S → 0B        按定理 1 构造对应的 FA（板书）
    B → 0B | 1S | 0

G2：S → 0A        同上，B → 0 | ε 说明接受态要能“掉空串”
    A → 1A | B
    B → 0 | ε

DFA → RG：给出 DFA，按定理 2 的构造写产生式（板书）
```

**正则语言的三种表达形式**：

| 形式          | 动词        | 说明     |
| ------------- | ----------- | -------- |
| 有限自动机 FA | 接受 / 识别 | 机器视角 |
| 正则表达式 RE | 描述 / 代表 | 公式视角 |
| 正则文法 RG   | 生成 / 产生 | 文法视角 |

三种视角等价，**按需要选顺手的那一种**（FA↔RE 见 3.3.3，RG↔FA 见本节两定理）。

# 3.6 本章小结

$$
\left.
\begin{array}{ll}
\text{DFA} & \delta:Q\times\Sigma\to Q;\ \text{接受三条件：起点、递推、末态}\in F\\[2pt]
\text{NFA} & \delta:Q\times\Sigma_\varepsilon\to\mathcal{P}(Q);\ \text{子集构造}\Rightarrow\text{NFA}\equiv\text{DFA}\\[2pt]
\text{封闭} & \cup\ (\text{乘积}),\ \circ\ (\varepsilon\text{ 猜切点}),\ *\ (\text{新起点}+\varepsilon\text{ 回边})\\[2pt]
\text{RE} & \text{6 种形式；RE}\to\text{NFA（归纳）},\ \text{DFA}\to\text{GNFA}\to\text{RE（拆状态）}\\[2pt]
\text{泵引理} & s=xyz:\ xy^iz\in A,\ \lvert y\rvert>0,\ \lvert xy\rvert\leqslant p;\ \text{鸽笼}+\text{反证}\\[2pt]
\text{RG} & G\to\text{NFA},\ \text{DFA}\to G;\ \text{FA/RE/RG 三视角等价}
\end{array}
\right\}
$$

# 3.7 考前速查表

| 题目出现                            | 立刻想到                                                                         |
| ----------------------------------- | -------------------------------------------------------------------------------- |
| DFA 的 5 元组                       | $Q,\Sigma,\delta,q_0,F$；$\delta:Q\times\Sigma\to Q$                             |
| NFA 的差别                          | $\delta:Q\times\Sigma_\varepsilon\to\mathcal{P}(Q)$，可 $\varepsilon$ 跳、可分叉 |
| “NFA 比 DFA 强吗”                   | 不强：子集构造，$\text{NFA}\equiv\text{DFA}$                                     |
| $\varepsilon$ 边怎么消              | $E(R)$：沿 0+ 条 $\varepsilon$ 边可达集；$q_0'=E(\{q_0\})$                       |
| 删不掉的伪状态                      | 子集构造后无箭头指向的伪状态可删（课件的 $N_4$ 例删掉 $\{1\}$、$\{1,2\}$）       |
| 并封闭的构造                        | 状态取配对 $(r_1,r_2)$，接受“或”                                                 |
| 连接封闭的构造                      | $F_1$ 上用 $\varepsilon$ 边猜切点，接受态用 $F_2$                                |
| 星封闭的构造                        | 新起点 $q_0$，$F=\{q_0\}\cup F_1$，$F_1\xrightarrow{\varepsilon}q_1$ 回环        |
| $\varepsilon$ 与 $\varnothing$ 混淆 | $R\cup\varepsilon\neq R$（多出 $\varepsilon$）；$R\circ\varnothing=\varnothing$  |
| 正则表达式优先级                    | 星 $>$ 连接 $>$ 并                                                               |
| 语言正则的判据                      | 有 DFA / 有 NFA / 有 RE / 有 RG（四者等价）                                      |
| DFA 怎么改写成 RE                   | 加起止态 → 合并箭头 → 补 $\varnothing$ → 循环拆 $q_{rip}$：$R_1R_2^*R_3\cup R_4$ |
| 泵引理三条件                        | 能泵、$\lvert y\rvert>0$、$\lvert xy\rvert\leqslant p$（第 3 条最常用）          |
| 泵引理证非正则                      | 反设 → 选串 → 穷举分段找 $i$ → 矛盾                                              |
| 选串原则                            | 暴露“本质”：$F=\{ww\}$ 用 $0^p10^p1$ 而非 $0^p0^p$；失败就换串                   |

| $0^i1^j,\ i>j$ 怎么矛盾             | 取 $i=0$（泵 $0$ 次）：$xz$ 的 0 不够多                                          |
| 正则文法定理方向                    | $G\to$NFA；DFA$\to G$（别记反）                                                  |
