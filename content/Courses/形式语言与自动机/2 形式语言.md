# 2 形式语言

一句话：这章把“语法规则”从 BNF 升级成可证明的数学对象——**文法 $G=(V,T,P,S)$ 靠推导产生语言 $L(G)$**，再按产生式形状把文法切成 **0/1/2/3 四型（乔姆斯基谱系）**，后面三章就是逐型研究对应的自动机。

$$
\text{2 形式语言}
\begin{cases}
\text{问题提出}
\begin{cases}
\text{BNF：}\langle X\rangle::=\ \text{、}\ |\\
\text{语言的递归定义}
\end{cases}\\[4pt]
\text{形式文法}
\begin{cases}
G=(V,T,P,S)\\

3\text{型}\to\text{正则 RL}
\end{cases}
\end{cases}
$$

# 2.1 问题的提出

## 2.1.1 BNF：巴科斯-瑙尔范式

| 记号               | 读法     | 含义                       |
| ------------------ | -------- | -------------------------- |
| $\langle X\rangle$ | 非终结符 | 一种**需要定义**的语法成分 |
| `::=`              | “就是”   | 左边由右边定义             |
| `\|`               | “或者”   | 多个候选                   |

类 Pascal 语句的 BNF（课件节选）：

```text
<语句>     ::= <条件语句> | <当语句> | <复合语句> | <赋值语句>
<当语句>   ::= while <布尔表达式> do <语句>
<复合语句> ::= begin <语句表> end
<语句表>   ::= <语句> | <语句> ; <语句表>
<赋值语句> ::= <变量> := <算术表达式>
<算术表达式> ::= <常量> | <变量> | ( <算术表达式> <算术运算符> <算术表达式> )
```

简单英语句子的语法规则：

```text
<Sentence>    ::= <Noun phrase><Verb phrase>
<Noun phrase> ::= <Article><Noun>
<Article>     ::= the | a
<Noun>        ::= apple | cat | man
<Verb phrase> ::= <Verb><Noun phrase> | <Verb>
<Verb>        ::= eats | sings | runs
```

## 2.1.2 递归定义

例：`<语句表>` 的递归定义有三部分：

| 部分 | 内容                                         |
| ---- | -------------------------------------------- |
| 基础 | `<语句>` 是 `<语句表>`                       |
| 归纳 | 在 `<语句表>` 前加 `<语句>;` 仍是 `<语句表>` |
| 排他 | 除此之外 `<语句表>` 不再包含其他形式         |

例串：`while x<=5 do x:=(x+2)`。

# 2.2 形式文法与形式语言

## 2.2.1 文法的定义

**一个文法 $G$ 是四元组**

$$
G=(V,T,P,S)
$$

| 成分     | 含义                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------- |
| $V$      | 变元（非终结符）的有限集                                                                                             |
| $T$      | 终结符的有限集                                                                                                       |
| $P$      | 产生式的有限集；每条 $\alpha\to\beta$，$\alpha\in(V\cup T)^{+}$ 且**至少含一个 $V$ 中符号**，$\beta\in(V\cup T)^{*}$ |
| $S\in V$ | 开始符号                                                                                                             |

产生式中 $\alpha$ 叫**左部**、$\beta$ 叫**右部**。多条右部简写：

$$
\alpha\to\beta_1\mid\beta_2\mid\cdots\mid\beta_n
$$

**记号约定**（课件）：

| 类别               | 用什么字母                               |
| ------------------ | ---------------------------------------- |
| 变元               | 大写拉丁 $A,B,C,D,E,S$（$S$ 为开始符号） |
| 终结符             | 小写拉丁 $a,b,c,d,e$、数字               |
| 终结符串           | 小写 $u,v,w,x,y,z$                       |
| 变元与终结符混合串 | 小写希腊 $\alpha,\beta,\gamma$           |

例子：$S\to0A1\mid10,\quad 0A\to00A1,\quad A\to\varepsilon$。**写一个文法时只写出产生式集合即可。**

## 2.2.2 推导与归约

| 概念                   | 定义                                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 直接推导 $\Rightarrow$ | $\alpha=\alpha_1\alpha_2\alpha_3,\ \gamma=\alpha_1\beta\alpha_3$，且 $\alpha_2\to\beta\in P$，则 $\alpha\Rightarrow\gamma$ |
| 推导 $\Rightarrow^{*}$ | $\Rightarrow$ 在 $(V\cup T)^{*}$ 上的自反传递闭包，$\alpha\Rightarrow^{*}\gamma$ 称由 $\alpha$ 推导出 $\gamma$             |
| 句型                   | 若 $S\Rightarrow^{*}\gamma$，则 $\gamma$ 是句型                                                                            |
| 句子                   | 句型中 $\gamma\in T^{*}$ 的特例                                                                                            |
| 归约                   | $\alpha\Rightarrow\gamma$ 的逆向，记 $\gamma\Leftarrow\alpha$                                                              |

例（课件）：$S\to0A1\mid10,\ 0A\to00A1,\ A\to\varepsilon$，

```text
S ⇒ 0A1 ⇒ 00A11 ⇒ 000A111 ⇒ 000111        （S ⇒* 000111）
```

其中推导链上的每一串都是句型（含 $S$ 自身）；只有 $10$、$000111$ 这类纯终结符串才是**句子**（推导得到的完整终结串）。

## 2.2.3 文法产生的语言

$$
L(G)=\{w\mid S\Rightarrow^{*}w\ \land\ w\in T^{*}\}
$$

即从 $S$ 推导出的**全体句子的集合**。

例：$S\to aSb,\ S\to ab$，则 $L(G)=\{a^{n}b^{n}\mid n\geqslant1\}$。

## 2.2.4 由文法到语言（含归纳证明）

**例 1**：$S\to aB\mid bA,\quad A\to a\mid bAA\mid aS,\quad B\to b\mid aBB\mid bS$，

结论：$L(G)$ = 由**个数相等的 $a$ 和 $b$**（次序不限）组成的所有串。

证明要同时证三个联动命题（对 $\lvert w\rvert$ 归纳）：

| 命题 | 内容                                             |
| ---- | ------------------------------------------------ |
| (1)  | $S\Rightarrow^{*}w\iff$ $w$ 中 $a$、$b$ 个数相等 |
| (2)  | $A\Rightarrow^{*}w\iff$ $w$ 中 $a$ 比 $b$ 多 1   |
| (3)  | $B\Rightarrow^{*}w\iff$ $w$ 中 $b$ 比 $a$ 多 1   |

```text
归纳基础 |w|=1：
  (1) 产生式不可能使 S ⇒* 单符号串，且单符号串 a、b 个数必不等 → 两边同假，成立
  (2)(3) 只能 A ⇒ a、B ⇒ b（其它产生式都产出长度 >1 的串）→ 成立

归纳步骤：设 |w| ≤ k-1 时 (1)(2)(3) 成立，证 |w|=k
  (1) 首符号分两种：w = a w1 ⇒ w1 中 b 比 a 多 1 ⇒ (3) B ⇒* w1 ⇒ S ⇒ aB ⇒* w；
      w = b w1 同理用 (2)
  (2) 由 A 出发首步必为 A ⇒ aS 或 A ⇒ bAA：
      A ⇒ aS 时 w = a w1，w1 满足 (1)；A ⇒ bAA 时 w = b w1 w2，
      w1、w2 都满足 (2)，拆分后 |w1|、|w2| < k-1 可用归纳假设
  (3) 与 (2) 对称，课件留做作业
```

**例 2**：由语言构造文法，从简到难：

| 目标语言                                | 文法（产生式集）                 | 关键动作             |
| --------------------------------------- | -------------------------------- | -------------------- |
| $L=\{a^{n}\mid n\geqslant1\}$           | $S\to a\mid aS$                  | 一个递归产生式       |
| $L=\{ww^{R}\mid w\in\{a,b\}^{+}\}$      | $S\to aa\mid bb\mid aSa\mid bSb$ | 两端对称夹心         |
| $L=\{a^{n}b^{n}c^{n}\mid n\geqslant1\}$ | 见下                             | 引入“搬运工”变元 $B$ |

$ww^R$ 的推导示例：$S\Rightarrow aSa\Rightarrow aaaa,\ abba;\ S\Rightarrow bSb\Rightarrow baab,\ bbbb$。

$a^nb^nc^n$ 的构造过程（课件重点）：

```text
错误尝试：S → abc | S → aSbc        只能得到 aⁿ(bc)ⁿ，b、c 次序锁死
          cb → bc 不合法（产生式左部须含变元）
思路：引变元 B，用 cB → Bc 把 B 从 c 右边搬到 c 左边
  (1) S → aBc      (2) S → aSBc      (3) cB → Bc
  用 (1)(2) 得 S ⇒* aⁿ(Bc)ⁿ；用 (3) 反复搬运得 aⁿBⁿcⁿ
为何不能直接加 B → b？（否）
  推导无法限制何时用 B → b；过早替换会产出 c 仍在 b 前的串
  反例：S ⇒ aSBc ⇒ aaBcBc ⇒ aabcbc
解法：只有 B 前面是 a / b 时才替换
  (4) aB → ab      (5) bB → bb
完整文法 G：L(G) = {aⁿbⁿcⁿ | n ≥ 1}（证明板书）
```

## 2.2.5 文法等价

**定义**：$L(G_1)=L(G_2)$，则 $G_1$ 与 $G_2$ **等价**（等价只看产生的语言，不看产生式长相）。

例：构造产生全部十进制整数（前面可有若干个 $0$）的文法——课件给两种写法（$G_1$ 的 $DN$ 加在右侧、$G_2$ 的 $0N$ 也加在右侧，前导 $0$ 排在后面——课件原文如此，$G_1$、$G_2$ 由“$L(G_1)=L(G_2)$ 即等价”判定等价）：

| 文法  | 产生式                                                                |
| ----- | --------------------------------------------------------------------- |
| $G_1$ | $N\to D\mid DN$；$D\to0\mid1\mid2\mid3\mid4\mid5\mid6\mid7\mid8\mid9$ |
| $G_2$ | $N\to0\mid1\mid\cdots\mid9$；$N\to0N\mid1N\mid\cdots\mid9N$           |

# 2.3 乔姆斯基分类

## 2.3.1 四类文法（Chomsky hierarchy）

对 $G=(V,T,P,S)$，按产生式形状分四类：

| 型   | 名称 / 简记    | 产生式形状                          | 约束                                                                                                                    |
| ---- | -------------- | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 0 型 | 无限制文法 UG  | $\alpha\to\beta$                    | $\alpha\in(V\cup T)^{+}$ 至少含一个变元；$\beta\in(V\cup T)^{*}$                                                        |
| 1 型 | 上下文有关 CSG | $\alpha A\beta\to\alpha\gamma\beta$ | $A\in V$，$\alpha,\beta\in(V\cup T)^{*}$，$\gamma\in(V\cup T)^{+}$；允许 $S\to\varepsilon$（只要 $S$ 不出现在任何右部） |
| 2 型 | 上下文无关 CFG | $A\to\beta$                         | $A\in V$，$\beta\in(V\cup T)^{*}$                                                                                       |
| 3 型 | 正则文法 RG    | $A\to a$ 或 $A\to aB$               | $a\in T\cup\{\varepsilon\}$，$A,B\in V$                                                                                 |

## 2.3.2 语言分类

| 由什么文法产生 | 语言类         | 简记 |
| -------------- | -------------- | ---- |
| 无限制文法     | 递归可枚举语言 | REL  |
| 上下文有关文法 | 上下文有关语言 | CSL  |
| 上下文无关文法 | 上下文无关语言 | CFL  |
| 正则文法       | 正则语言       | RL   |

## 2.3.3 0 型文法的例子（课件：“迄今最复杂的例子”）

要产生 $L(G)=\{a^{2^{k}}\mid k\geqslant1\}=\{aa,aaaa,aaaaaa,\dots\}$（串长是 $2$ 的幂，需要“计数”）：

```text
(1) S → ACaB     A 左边界，B 右边界，C 相当于“光标”
(2) Ca → aaC     光标 C 从左到右越过一个 a 就把它变成两个 → 走一趟 a 个数翻倍
(3) CB → DB      到右边界后把 C 换成 D，D 由右向左走
(4) CB → E       或者把 CB 换成 E，表示推导即将结束
(5) aD → Da      D 向左走时遇 a 就交换位置
(6) AD → AC      D 走到左边界 A 再变回 C → 构成一次循环（继续翻倍）
(7) aE → Ea      E 向右走（善后）
(8) AE → ε       E 回到左边界后与 A 一起消去
```

- 光标 $C$ 走到右边界时，两边界间 $a$ 的个数一定是 $2^{k}$；**选择一**就此结束（(4)(7)(8)），**选择二**继续翻倍（(3)(5)(6)）。
- 结束时形如 $S\Rightarrow^{*}Aa\cdots aE$（$a$ 为 $2^{k}$ 个）。
- $L(G)$ **不是 CFL**（上下文无关文法产生不了，课件：“以后讲”）；1 型文法虽能产生，但比这个 0 型例子还复杂。

## 2.3.4 1 型文法的例子

产生同一语言 $\{a^{2^{k}}\mid k\geqslant1\}$ 的一个上下文有关文法（方括号是界符）：

```text
(1) S → [ACaB]
(2) [ACaB] → [Aa][aCB]      [Ca]a → aa[Ca]      [Ca][aB] → aa[CaB]
    [ACa]a → [Aa]a[Ca]      [ACa][aB] → [Aa]a[CaB]   [CaB] → a[aCB]
(3) [aCB] → [aDB]
(4) [aCB] → [aE]
(5) a[Da] → [Da]a           [aDB] → [DaDB]
    [Aa][Da] → [ADa]a       a[aDB] → [Da][aB]    [Aa][aDB] → [ADa][aB]
(6) [ADa] → [ACa]
(7) [aE] → [Ea]             a[Ea] → [Ea]a
(8) [Aa][Ea] → aa
```

## 2.3.5 为什么叫“上下文有关 / 无关”

对比两个文法（课件）：

|            | 文法 $G$                                                                         | 文法 $G'$                               |
| ---------- | -------------------------------------------------------------------------------- | --------------------------------------- |
| 产生式     | $S\to0A1\mid1A0$；$0A1\to0a1$；$1A0\to1b0$                                       | $S\to0A1\mid1A0$；$A\to a$；$A\to b$    |
| 类型       | 1 型（上下文有关）                                                               | 2 型（上下文无关）                      |
| 语言       | $L(G)=\{0a1,\ 1b0\}$                                                             | $L(G')=\{0a1,\ 0b1,\ 1a0,\ 1b0\}$       |
| $A$ 的替换 | $A$ 只有**左邻 $0$、右邻 $1$** 时才能换成 $a$；左邻 $1$、右邻 $0$ 时才能换成 $b$ | $A$ 无论出现在哪都可独立换成 $a$ 或 $b$ |

在 $\alpha_1A\alpha_2\to\alpha_1\beta\alpha_2$ 中，$\alpha_1,\alpha_2$ 就是变元 $A$ 的**上下文**；1 型文法的变元必须“看环境行事”，2 型文法没有环境限制——这就是“上下文无关”。

# 2.4 本章小结

$$
\left.
\begin{array}{ll}
\text{BNF} & \langle X\rangle::=\ \text{与}\ |\ \text{；递归定义 = 基础 + 归纳 + 排他}\\[2pt]
\text{文法} & G=(V,T,P,S);\ \alpha\to\beta,\ \alpha\ \text{至少含一个变元}\\[2pt]
\text{推导} & \Rightarrow\ \text{直接推导},\ \Rightarrow^{*}\ \text{闭包};\ \text{句型 / 句子 / 归约}\\[2pt]
\text{语言} & L(G)=\{w\mid S\Rightarrow^{*}w,\ w\in T^{*}\};\ L(G_1)=L(G_2)\ \text{即等价}\\[2pt]
\text{乔姆斯基} & 0\text{型 UG} \supset 1\text{型 CSG} \supset 2\text{型 CFG} \supset 3\text{型 RG}
\end{array}
\right\}
$$
