# 6 声纹识别

一句话：声纹识别是**根据声音特性判断说话人身份**。传统路线是 **GMM-UBM（Gaussian Mixture Model - Universal Background Model，高斯混合模型—通用背景模型）+ MAP（Maximum A Posteriori，最大后验概率）自适应 + 似然比打分**，深度学习路线是 **x-vector 说话人嵌入 + 后端打分**。

# 6.1 声纹识别概述

## 6.1.1 基本概念

### 定义

> **人话**：用声音认人：输入一段语音，输出这是谁。

声纹识别（说话人识别）是**生物识别**（指纹、掌纹、人脸、虹膜等）的一种，根据说话人的**声音特性**进行身份辨识。

- 输入：语音
- 输出：说话人身份

### 与其他语音任务的区别

> **人话**：同一段语音，不同任务读的是不同信息：文字、情绪、语种、身份。

| 任务     | 输出                         |
| -------- | ---------------------------- |
| 语音识别 | 语音携带的**文本信息**       |
| 情感识别 | 语音携带的**情感信息**       |
| 语种识别 | 语音所属的**语种**           |
| 语音合成 | 由文本输出语音               |
| 声纹识别 | 语音携带的**说话人身份信息** |

### 说话人身份相关的语音属性

> **人话**：音色来自生理（声带、声道），口音和习惯来自行为。

| 层级     | 与什么相关             | 具体表现                   |
| -------- | ---------------------- | -------------------------- |
| 低级属性 | 发声器官的**生理**方面 | 声道频谱、共振峰轨迹       |
| 高级属性 | 说话方式的**行为**差异 | 韵律、口音、话语中词的选择 |

### 两种分类方式

> **人话**：一个问「说的是什么内容」，一个问「是不是他」；再分「N 选 1」和「二选一」。

**按输入模式（文本相关 / 无关）**

| 类型     | 特点                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 文本相关 | 注册与测试话语共享（至少部分）相同内容；分析给定语音语境下的说话人特征；**性能更高** |
| 文本无关 | 注册与测试可用任意文本（甚至不同语言）；不用口语内容的先验信息；**便利性更高**       |

**按输出模式（辨认 / 确认）**

| 类型                      | 判定什么                                   | 对比形式    |
| ------------------------- | ------------------------------------------ | ----------- |
| 说话人辨认 Identification | 待识别说话人来自注册集中的**哪一个**       | 1:N         |
| 说话人确认 Verification   | 待识别语音是否来自注册集中的**某个**说话人 | 1:1（成对） |

### 评价指标

> **人话**：该放行的被拦下叫 FRR（False Rejection Rate，误拒绝率），该拦的被放行叫 FAR（False Acceptance Rate，误接受率）；两者相等时的错误率叫 EER（Equal Error Rate，等错误率）。

- **误拒绝率 FRR**：被错误拒绝的有效身份声明的比例（本该匹配成功却判失败）。
- **误接受率 FAR**：错误接受冒名顶替者声明的比例（本该失败却判成功）。
- **等错误率 EER**：调整阈值使 **FAR = FRR**，此时的错误率。EER 越小越好；阈值变化时两者的权衡画成 **DET（Detection Error Tradeoff，检测错误权衡）曲线**（检测—错误—均衡曲线）。

# 6.2 传统声纹识别算法（GMM-UBM）

## 特征提取

> **人话**：只保留与「谁」有关的部分，把内容和噪声尽量丢掉。

- 目的：**保留说话人信息**，**去除噪声和其他干扰信息**。
- 声学特征：梅尔频率倒谱系数（MFCC，Mel-Frequency Cepstral Coefficients）、线性预测倒谱系数（LPCC，Linear Predictive Cepstral Coefficients）。
- 完整前端还包括：**语音活动检测**（丢弃非语音帧）与**后处理**（如倒谱均值归一化 CMN（Cepstral Mean Normalization））。

## 基于 GMM 的说话人建模

> **人话**：用一坨概率分布描述「这个人的声音长什么样」。

**注册**：说话人模型由该说话人的注册语音构建。注册语音经前端得到一串特征向量，用 $K$ 个高斯分量的 GMM（Gaussian Mixture Model，高斯混合模型）描述它们的分布。

每个高斯分量有三组参数：**权重** $w_k$（这个分量占多大比重，所有分量加起来为 1）、**均值** $\mu_k$（分量中心落在特征空间的哪里）、**协方差** $\Sigma_k$（分量朝哪摊开、摊多宽）。

**问题**：实际场景中每个说话人的语音很少，训练不出可靠的高斯混合模型。

## GMM-UBM

> **人话**：每个人语音太少，先用大众模型打底，再小幅微调成个人模型。

![PPT 第19页：MAP 自适应（说话人相关 GMM 与 UBM 的关系）](assets/ch6-p19.webp)

**UBM（Universal Background Model，通用背景模型）**：用大量说话人无关的数据，通过 EM（Expectation-Maximization，期望最大化）算法训练一个**说话人无关**的 GMM，作为先验。

**MAP 自适应**：以 UBM 为初始模型，用最大后验概率（MAP）自适应得到目标说话人模型，可**大幅减少注册所需语音时长**。适应时权重、均值向量和协方差矩阵都可调整：均值适应使高斯分量**偏移**，协方差适应改变分量的**大小（不确定性）**。

好处：说话人相关的 GMM 与 UBM 模型复杂度相同，便于计算更可靠的对数似然分数。

## 打分：似然比测试（掌握）

> **人话**：比起「大众平均」，这段话更像「他」多少——超过阈值就认。

![PPT 第40页：GMM-UBM 的似然比测试](assets/ch6-p40.webp)

说话人确认可化为两个假设的检验：

- $H_0$：测试段 $Y$ 来自假设说话人；
- $H_1$：测试段 $Y$ 不是来自假设说话人。

**相似度怎么算**：把测试段的每一帧都丢进模型，算出该帧在这个模型下的概率，取对数后再对所有帧**求平均**，就得到「这段语音与该模型的平均对数似然」——分数越高，说明模型越能解释这段话。

**判决怎么做**：同一个测试段算两次——一次用**这个人的模型**，一次用**UBM**，两者相减得到**对数似然比**。这个差值的含义是「比起大众平均水平，这段话更像这个人多少」。超过阈值 $\eta$ 就接受（判为本人），否则拒绝。

## GMM 超向量（GMM supervector）

> **人话**：只调均值，把各分量的均值串成一条很长的向量当身份证。

GMM 由三组参数组成：权重（每个分量有多重要）、均值（分量中心在哪）、协方差（分量的形状）。

为简化计算、减少数据需求，**假设说话人与 UBM 的权重和协方差相同，只调整均值向量**；把所有高斯分量的均值向量按固定顺序首尾相连，就得到一条**超长的向量**，称为 **GMM 超向量**——它可作为说话人的定长表征。

# 6.3 基于深度学习的声纹识别

## 现代系统三段

现代声纹识别系统主要基于**说话人嵌入**：**特征提取 → 说话人嵌入 → 打分**。

## x-vector（掌握）

> **人话**：让网络自己学出一条定长向量来代表说话人。

![PPT 第45页：x-vector 的四个函数块](assets/ch6-p45.webp)

**x-vector 是一个包含四个函数块的深度神经网络**：

| 函数块        | 内容                                                                                    |
| ------------- | --------------------------------------------------------------------------------------- |
| 1. 帧处理器   | 多层神经网络提取深度特征（如延时神经网络 TDNN）；输入是 MFCC 或对数 mel-filterbank 系数 |
| 2. 池化层     | 把变长的特征向量序列压成**一个固定维向量**；最常用**时间池化**（取均值和标准差）        |
| 3. 嵌入提取   | 若干相连网络层，其中一层设计为**瓶颈层**；**瓶颈层（非线性层之前）的输出就是 x-vector** |
| 4. 说话人分类 | 用判别性损失按说话人标签做分类（softmax + 交叉熵）                                      |

### 各块的细节

![PPT 第53页：嵌入提取的网络层结构（512 维嵌入）](assets/ch6-p53.webp)

**TDNN（Time-Delay Neural Network，时延神经网络）与时间上下文**：TDNN 提取上下文的能力取决于**感受野**宽度（影响某个单元的输入空间区域）。想扩大视野可以用**空洞卷积**（按步长跳过输入值），或**堆叠更多空洞一维卷积层**。

**池化层**：说话人嵌入通过池化形成固定长度表征，时间池化即对每维特征求均值与标准差。

**嵌入提取**：聚合后的特征经过若干全连接层，把**第一个线性层的输出**作为嵌入表征；该嵌入是固定长度向量，捕捉说话人的**长期声纹特征**。

**分类与损失**：输出层每个节点代表一个说话人，用 **softmax** 归一化，用**交叉熵**衡量输出与标签的差异。
