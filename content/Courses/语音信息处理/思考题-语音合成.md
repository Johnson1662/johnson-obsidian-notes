# 思考题：语音合成的两条技术路线与大模型

## 4.1 传统神经网络语音合成与端到端语音合成

### 4.1.1 传统神经网络语音合成（多阶段、参数化）

传统神经网络合成把文本到波形拆成前后相接的四段，每一段单独建模、单独训练，链路依次是文本、语言学特征、声学参数、波形。

前端做文本分析：先做文本规整，把数字、缩写、符号转成可读形式，再分词、标词性，经字音转换（G2P）得到音素序列，最后结合上下文做上下文相关标注，把三音素、词内位置、词性、韵律层级写成问题集特征。时长模型吃的是音素级特征，输出每个音素及其状态的时长。声学参数生成模型按预测出的时长把音素展开成帧级序列，由 DNN 逐帧回归倒谱或 MCC、基频、清浊、能量、非周期成分等参数，训练时常以最小生成误差为目标，以缓解帧级独立回归带来的过平滑。

后端由声码器基于源—滤波器模型，把声学参数还原成激励与声道滤波并合成波形，早期用 STRAIGHT、WORLD 这类参数合成器，后来换成神经声码器，合成音质在很大程度上取决于这一步。由于各模块目标独立，时长、谱参数与声码器分别最优，训练时依赖 HMM 或强制对齐提供帧与音素的对应关系。

### 4.1.2 端到端语音合成

端到端路线不再把中间环节逐个建模，而是用整句目标优化整个系统。常规做法是从文本（音素）到梅尔谱、再由声码器出波形；VITS 一类模型则把声学模型与声码器合到一起，文本直接出波形。

前端仍然保留，但只做规整与字音转换，输出音素或字符序列，一般不再需要精细的上下文标注和独立的时长模块。声学模型用序列到序列结构：Tacotron 2 由编码器、位置敏感注意力与自回归解码器组成，逐帧预测梅尔谱并输出结束标记；FastSpeech 改为非自回归，用时长预测器加长度规整，利用文本与语音之间的单调对齐并行生成，正是为了绕开自回归慢、跳词重复、不可控这三个毛病。

声码器一侧用 WaveNet、WaveGlow、HiFi-GAN 等神经声码器把梅尔谱转成波形。VITS 进一步用后验编码器（输入线性谱）、先验编码器、Flow 与对抗训练把前后两段合成一个网络，省掉共用梅尔谱带来的信息瓶颈。训练以整句似然或对抗损失端到端进行，对齐由注意力或单调对齐搜索自动学出来，属弱监督。

### 4.1.3 优缺点对比

| 维度     | 传统神经网络合成（多阶段）                   | 端到端合成                                  |
| -------- | -------------------------------------------- | ------------------------------------------- |
| 中间表示 | 显式声学参数（谱 + $F_0$ + 时长）            | 隐式梅尔谱（VITS 进一步去掉）               |
| 对齐来源 | 依赖强制对齐 / HMM 状态对齐                  | 注意力或单调对齐自动学习                    |
| 优化目标 | 各模块分别最优，误差逐级累积                 | 整句目标，全局最优，减少人工假设            |
| 可控性   | 强：时长、韵律、$F_0$ 可显式干预             | 弱；FastSpeech 靠时长预测器部分找回         |
| 可解释性 | 强，错误可定位到某一模块                     | 弱，黑盒，端到端调优                        |
| 数据需求 | 小，几小时单说话人语料即可                   | 较大；但省去精细标注                        |
| 自然度   | 受参数化与声码器限制，易过平滑、发闷、机械感 | 显著更高，接近真人；VITS 尤佳               |
| 鲁棒性   | 稳定、不幻觉；前端错误可局部修正             | 自回归易跳词/重复/不收敛；FastSpeech 缓解   |
| 速度部署 | 链路长、模块多；声码器是瓶颈                 | Tacotron 2 自回归慢；FastSpeech/VITS 可实时 |

拆开建模让传统路线可控、可调试、也不幻觉，误差却会逐级累积，谱参数化又带来过平滑；端到端把整句当成一个优化目标，自然度上去了，代价是黑盒难调、可控性弱，自回归还容易跳词。

## 4.2 语音合成大模型

### 4.2.1 为什么效果更好

大模型把语音合成从回归连续信号改成续写离散 token，这是效果提升的起点。做法是用 EnCodec、SoundStream 这类神经编解码器把语音压成多码本（RVQ）的离散 token，合成于是变成给定文本 token 与几秒语音提示、预测后续语音 token 的条件语言模型任务，与 LLM 共享 next-token 预测的范式、架构与训练技巧，可以直接随参数、数据与算力规模化。规模之外还有数据面的优势：在海量多说话人、多语种、多风格、多信道语料上预训练，覆盖的音色、口音、情感与录音环境分布远宽于单说话人系统，泛化能力来自数据而不是人工规则。

上下文学习能力带来零样本克隆。VALL-E 一类模型只给 3 秒语音提示，就能合成未见说话人的语音，并延续提示里的音色、韵律、情感甚至声学环境，不必为目标说话人重新训练，这是传统系统与常规端到端系统做不到的。表征上，离散 codec token 保留了梅尔谱丢掉的部分细节；第一码本用自回归保证全局一致，其余码本用非自回归并行补齐，质量与效率兼顾；文本理解与语音生成还能共享语义空间，对多语种、语码混用与指令控制都有利。

框架上也更统一：同一个模型可覆盖合成、语音翻译、语音编辑与对话，用自然语言指令或提示就能控制情感、语速与风格，长上下文建模还改善了篇章级的韵律一致性。对齐与标注的负担同时下降，不再依赖强制对齐和复杂前端标注，对多语种与生僻组合更友好。

### 4.2.2 还存在哪些不足

最直接的问题是保真与稳定。自回归逐 token 生成会累积误差，出现漏字、重复、乱读、跨语种串音，长文本尤其明显；缺少逐字读对的硬约束，数字、专名与多音字仍要靠文本前端兜底。可控性与可解释性也弱于参数化系统，很难像后者那样精确约束时长、停顿与音高曲线，出错后难以定位，播报、配音这类要求严格的场景不好用。

工程侧的代价是效率与部署：参数量大、自回归解码慢、显存占用高，端侧与低延迟流式场景受限，往往要做蒸馏、量化或非自回归改造。落地还要面对数据合规与安全，包括训练语料版权、音色克隆被用于诈骗与伪造、说话人隐私与人格权，需要授权机制、水印与鉴伪技术配套。评测同样不好办，目前仍以主观 MOS 为主，成本高、方差大，缺少统一的客观指标与跨域基准，对表现力与长文本稳定性的评测不足。

资源与成本上，低资源语言、方言与情感语音数据稀缺，效果明显落后，训练与推理开销也高。表现力仍有上限，歌唱、细腻的情感变化、多人对话中的轮次衔接与重叠语音都有差距，长时合成还会出现音色漂移。

四代技术连起来看：波形拼接、统计参数（HMM/DNN，显式可控但过平滑）、端到端（整体优化、自然度高）、大模型（条件语言模型加离散 token，零样本泛化），每一步都在减少人工分解、扩大数据与模型规模。也因此，现在更难的部分在稳定性、可控性与合规，而不在像不像。
