# 4 语音合成

一句话：语音合成（TTS）是**由文本生成语音**，本质是把语言信息重新调制到声学信号上。工程上分**前端（文本 → 语言学特征）** 与 **后端（语言学特征 → 声学参数 → 波形）**，传统主流是 **HMM 统计参数合成 + 声码器**。

# 4.1 语音合成概述

## 4.1.1 基本概念

**定义**：语音合成是通过机械的、电子的方法产生人造语音的技术；**TTS** 指自动把文本转换为声音。

**两个目标**：

| 目标   | 含义                 |
| ------ | -------------------- |
| 可懂度 | 听者能听懂           |
| 自然度 | 听起来像不像真人说的 |

广义的语音合成还包括**语音转换**（说话人转换、语音到歌唱转换、情感转换、口音转换）、**歌唱合成**、**可视语音合成**。

TTS 流程涵盖了人的朗读过程的主要要素，但**没有考虑两个最重要的要素：上下文理解和意图表达**。

### 评价指标

**主观指标**

| 指标 | 形式                                                                       |
| ---- | -------------------------------------------------------------------------- |
| MOS  | 绝对评分（平均意见分）                                                     |
| CMOS | 相对评分，范围 $[-3,3]$，间隔为 1；3 表示远优于、$-3$ 远差于、0 表示无差别 |
| ABX  | A、B 两段对比，选 A 或 B 更好，或认为 X 无差别                             |

**客观指标**：与真实音频的距离度量，常用**梅尔倒谱失真 MCD**（Mel-Cepstral Distortion）。

## 4.1.2 方法回顾

| 方法         | 做法                                                                       | 问题/优点                            |
| ------------ | -------------------------------------------------------------------------- | ------------------------------------ |
| 波形拼接     | 从自然语音中抽取语音基元组成语料库，合成时按文本查找基元、拼接并做韵律修饰 | 依赖语料覆盖，拼接处不自然           |
| 统计参数合成 | 对语音做参数化表征，用统计模型建模声学参数，再由模型生成                   | 参数化后可灵活调整，音质受声码器限制 |

# 4.2 语音合成的整体框架

## 4.2.1 主要流程

语音是“通过语言调制、由人类发声器官产生的声学信号”；因此语音合成的原理就是**把语言信息调制到声学信号上**。

| 环节             | 内容                                             |
| ---------------- | ------------------------------------------------ |
| 语言处理（前端） | 句词切分（分词）、文本归一化、字音转换、韵律预测 |
| 声音处理（后端） | 韵律参数预测 + 声音波形生成（声学模型 + 声码器） |

有的研究把文本分析与韵律预测合并称为**语言分析**。

统计参数语音合成的两条线：

- **前端处理**：从原始文本提取可被声学模型识别的**语言学特征**，即音标与韵律信息的符号化表征。
- **后端处理**：把语言学特征转换成**声学特征**，再转换成语音波形。

## 4.2.2 文本分析

| 步骤           | 作用                                                                     |
| -------------- | ------------------------------------------------------------------------ |
| 分词与词性标注 | 标注词语边界与词性                                                       |
| 文本归一化     | 把非标准词转换为发音明确的口语词（如“前方 120M”→“前方一百二十米”）       |
| 字音转换       | 给出每个字符对应的发音，并处理协同发音、**多音字消歧**、儿化音标注、变调 |

## 4.2.3 韵律分析

**韵律的三级结构**：韵律词 → 中间短语（韵律短语）→ 语调短语。

韵律包含**语调、声调、重音**等成分。它的几个观察角度：

- 从语音信号看，韵律是**超音段**的声音物理属性信息；
- 从语用功能看，韵律编码了语音意图（信息焦点、对话连贯性、言语行为类型、说话人态度与情感）；
- 韵律是**句法与发音的接口**，受语气类型、词汇语义/句法关联、节奏、篇章连贯性影响；
- 在**感知**中，韵律反映节奏、强调、语速；在**生成**中，通过**音高（$F_0$）、时长、能量**的变化实现。

基频、时长、能量的生成方法有两类：**基于规则**、**基于数据**（传统统计模型、深度神经网络等）。语调调型隐含在基频模型中，句子的基频曲线由当前音节的拼音、声调与上下文，从语料库的基频统计模型得到。

# 4.3 基于 HMM 的语音合成

## 4.3.1 为什么用 HMM

HMM 在语音识别中成功，是因为它**适合为时序信号建模**：语音产生本身是**双重随机过程**——气流经由的过程无法观测，发出的语音可观测；HMM 同样是双重随机过程——隐马尔可夫链输出的状态序列不可观测，随机过程输出的观察序列可观测。

## 识别与合成是一对反向问题

| 环节 | 语音识别                                                   | 语音合成                                                       |
| ---- | ---------------------------------------------------------- | -------------------------------------------------------------- |
| 训练 | 估计 $\hat\Lambda=\arg\max P(L\mid O,\Lambda)$             | 估计 $\hat\Lambda=\arg\max P(O\mid L,\Lambda)$                 |
| 解码 | $\hat L=\arg\max_L P(O=o\mid L,\Lambda)$（识别、生成文本） | $\hat O=\arg\max_O P(O\mid L=l,\Lambda)$（合成、生成声学参数） |

其中 $O$ 是声学特征，$L$ 是文本（语言学）特征，$\Lambda$ 是 HMM 参数。**训练算法相同，都是 Baum-Welch（EM 的快速实现）；解码算法相同，都是基于动态规划的 Viterbi。**

## 基于 HMM 语音合成系统的框架

**训练流程**

1. 数据处理，提取**文本特征**与**声学参数**；
2. 模型训练（<文本特征, 声学参数> 作为训练数据）：方差下限估计 → 单音素 HMM 训练 → 上下文相关 HMM 训练 → 基于决策树的 HMM 聚类 → 聚类后 HMM 训练；
3. 分别得到**时长、基频、谱参数**三套模型（训练算法一致）。

**合成流程**

1. 文本处理，得到输入文本特征；
2. 基于**似然最大化准则**，用 HMM 生成声学参数；
3. 用**声码器**把声学参数转换为最终语音。

## HMM 合成的缺陷：过平滑

HMM 合成的声音平淡、音质不好，原因是**过平滑**：

- HMM 基于建模，假设各状态之间独立，状态参数分布是统计平均的结果；
- 决策树是浅层线性模型，无法建模复杂映射关系，对输入特征与数据空间的线性分割会降低模型泛化能力。

## 声码器

声码器基于**源—滤波器模型**：把声学参数（谱参数、基频、非周期成分等）还原为激励与声道滤波，再合成波形。声码器的好坏直接决定最终音质。

# 4.4 本章小结

- 合成 = 把语言信息调制到声学信号上；目标可懂度 + 自然度。
- 主观评价 MOS/CMOS/ABX，客观评价 MCD。
- 前端做文本分析与韵律预测，后端做声学模型与声码器。
- 韵律三级结构：韵律词、韵律短语、语调短语；由 $F_0$、时长、能量实现。
- HMM 合成与识别是反向问题，训练都用 Baum-Welch、解码都用 Viterbi。
- HMM 合成的核心缺陷是过平滑。
