## 考点 1：跨网络通信中 IP 与 MAC 地址的动态转换定律（铁律！）

### 考点讲解
- **端到端转发铁律**：
  - **网络层 IP 头部**：源 IP 地址与目的 IP 地址在整个传输路径中**始终保持不变**（除非经过 NAT 重写）。
  - **链路层 帧头部**：源 MAC 地址与目的 MAC 地址**每经过一跳路由器都必须重新封装，替换为当前局部物理链路的发送方与接收方硬件地址**！

## 考点 2：WiFi（802.11）与以太网 MAC 协议核心对比

### 考点讲解
- **为什么 WiFi 绝不能直接用有线以太网的 CSMA/CD？**
  1. **硬件无法实现碰撞检测**：天线发射功率极大，微弱接收信号会被自身发射彻底掩盖；
  2. **存在隐藏站（Hidden Terminal）问题**：两端节点互相侦听不到，但向中间节点同时发送会在接收端造成严重碰撞。
- **WiFi 解决方案（CSMA/CA）**：
  - 帧间隔 IFS 优先级调度；
  - 侦听信道忙时随机退避；
  - 每帧强制链路层 ACK 确认；
  - RTS/CTS 握手预约信道（解决隐藏站）。

## 考点 3：期末 45 分级终极压轴综合架构大题

### 例题
<!-- Q0032 -->
**例题 1（2025-2026期末压轴大题 · 45分）**

**核心采分点总结**：
1. **入网配置与 DHCP**：
   - 手工 4 大参数：IP、掩码、网关、DNS。
   - DHCP 4 步广播 Request 告知全网挑中了哪家，使未中选服务器及时回收预留 IP。
2. **木桶瓶颈吞吐量**：端到端瓶颈为链路最小带宽 $\min(500\text{M}, 80\text{M}, 1000\text{M}) = 80\,\mathrm{Mbps}$。
3. **缓存代理**：部署在客户端侧（靠近 R3），完全命中时免除跨越 80Mbps 瓶颈链路，直接享受 500Mbps 局域网全速。
4. **交换机自学习**：收到帧记录 `(源MAC, 入端口)`，目的未知则泛洪，已知则单播过滤。
5. **无线 RDT 设计**：高丢包链路选流水线；端到端论点（End-to-End Argument）决定链路层不追求 100% 可靠，将最终可靠性交由传输层 TCP 保证。
