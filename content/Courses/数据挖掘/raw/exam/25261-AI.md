### ① 非对称二元相异性与相异性矩阵

某电商记录 5 位用户对 6 个商品的购买情况，1 表示购买过，0 表示未购买过。

| 用户 | 面包 | 牛奶 | 尿布 | 啤酒 | 鸡蛋 | 可乐 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| U1   | 1    | 1    | 0    | 0    | 1    | 0    |
| U2   | 1    | 0    | 1    | 0    | 0    | 1    |
| U3   | 0    | 1    | 0    | 1    | 1    | 0    |
| U4   | 1    | 1    | 0    | 0    | 1    | 1    |
| U5   | 0    | 0    | 1    | 1    | 0    | 1    |

要求：

1. 说明为什么商品购买记录应当用非对称二元属性处理，两种取值各代表什么。
2. 写出非对称二元相异性（Jaccard 距离）的公式，并说明 0-0 匹配为什么不参与计算。
3. 对每一对用户统计 a、b、c 三个量，计算相异性 d(Ui, Uj)。
4. 写出 5×5 的相异性矩阵，对角线取 0。
5. 指出相异性最小与最大的一对用户（有并列时一并写出），并说明这两个数值在实际业务里意味着什么。

### ② 曼哈顿距离

4 位顾客在三个维度上的记录如下，三个维度分别是月消费额（百元）、到店次数（次）、平均停留时间（十分钟）。

| 顾客 | 月消费额 | 到店次数 | 平均停留 |
| ---- | -------- | -------- | -------- |
| P1   | 2        | 5        | 8        |
| P2   | 5        | 3        | 6        |
| P3   | 8        | 4        | 9        |
| P4   | 1        | 8        | 2        |

要求：

1. 写出曼哈顿距离（L1 范数）的公式，并与欧氏距离对比说明它衡量的是什么。
2. 计算 d(P1, P2)、d(P2, P3)、d(P3, P4)、d(P1, P4)。
3. 计算 P1 到其余三点的距离，指出与 P1 最相似的顾客。
4. 选做：先对每一维做 min-max 归一化到 [0, 1]，再算 d(P1, P4)，说明结果与未归一化时差异的来源。

四分位数按位置法计算：第 k 百分位数的位置为 (n+1)·k/100，位置非整数时取相邻两个值的线性插值。

要求：

2. 计算 Q1 与 Q3，写出位置与插值过程。

### ④ Apriori 算法关联规则挖掘

某超市 10 笔交易记录如下。

| 交易 | 商品                   |
| ---- | ---------------------- |
| T1   | 面包, 牛奶             |

| T3   | 牛奶, 尿布, 啤酒, 可乐 |
| T4   | 面包, 牛奶, 尿布, 啤酒 |
| T5   | 面包, 牛奶, 尿布, 可乐 |
