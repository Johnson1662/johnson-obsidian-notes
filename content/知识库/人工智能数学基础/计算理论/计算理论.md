## 1. 计算理论的研究目的与研究内容

**研究目的：** 回答计算机科学中最基础的问题——**"计算机的基本能力和局限性是什么？"**

**研究内容（三个支柱）：**

| 领域          | 核心问题      | 关键概念                                             |
| :---------- | :-------- | :----------------------------------------------- |
| **自动机理论**   | 计算的数学模型   | 有穷自动机(正则文法)<br>下推自动机(上下文无关文法)<br>图灵机（现代计算机的数学模型） |
| **可计算性理论**  | 问题能否被计算解决 | 可判定/不可判定、递归可枚举语言、递归语言                                 |
| **计算复杂性理论** | 问题算得快不快   | P、NP、NPC、NP-hard                                 |

## 2. 可计算性理论与计算复杂性理论

### 可计算性理论
- 目标：把问题分成可解的（可判定）和不可解的（不可判定）
### 计算复杂性理论
- 核心问题：是什么使得某些问题很难计算，而又使另一些问题容易计算?
- 目标：把问题分成容易计算的和难计算的

## 3. 有穷自动机的定义、状态转移图、接受语言

### 形式化定义（五元组）

一个有穷自动机（Finite Automaton,FA）是一个五元组 $M = (Q, \Sigma, \delta, q_0, F)$：

| 符号 | 含义 |
|:---|:---|
| $Q$ | 有穷状态集 |
| $\Sigma$ | 有穷输入字母表 |
| $\delta: Q \times \Sigma \to Q$ | 转移函数 |
| $q_0 \in Q$ | 初始状态 |
| $F \subseteq Q$ | 接受状态集 |

### 状态转移图

- **节点** → 状态集 $Q$ 中的各个状态
- **有向边** → 转移函数 $\delta$，边上标有输入字符
- **开始箭头** → 指向 $q_0$ 的无来源箭头
- **双圈** → 标识接受状态

### 接受语言的定义

扩充转移函数 $\hat{\delta}$：
- $\hat{\delta}(q, \varepsilon) = q$
- $\hat{\delta}(q, aw) = \hat{\delta}(\delta(q, a), w)$

FA $M$ 接受的语言：
$$L(M) = \{ x \mid \hat{\delta}(q_0, x) \in F \}$$

## 4. 图灵机的定义、状态转移图、与有穷自动机的关系

### 形式化定义（七元组）

图灵机（TM）是一个七元组 $M = (Q, \Sigma, \Gamma, \delta, q_0, q_{accept}, q_{reject})$：

| 符号                                                            | 含义                                                  |
| :------------------------------------------------------------ | :-------------------------------------------------- |
| $Q$                                                           | 有穷状态集                                               |
| $\Sigma$                                                      | 输入字母表（不含空白符 $\sqcup$）                               |
| $\Gamma$                                                      | 纸带字母表（$\sqcup \in \Gamma, \Sigma \subseteq \Gamma$） |
| $\delta: Q \times \Gamma \to Q \times \Gamma \times \{L, R\}$ | 转移函数                                                |
| $q_0$                                                         | 起始状态                                                |
| $q_{accept}$                                                  | 接受状态                                                |
| $q_{reject}$                                                  | 拒绝状态（$q_{accept} \neq q_{reject}$）                  |

### δ 的直观理解

$$\delta(q_i, X_j) = (q_k, X_l, D_m)$$

> **“状态 $q_i$ 读到 $X_j$ → 改写成 $X_l$，往 $D_m$ 移一格，进入 $q_k$”**

与 FA 的核心区别：TM **能读能写、能左能右、纸带无限**，FA 只能读且单向。

### 与有穷自动机的关系

| 特性 | FA | TM |
|:---|:---|:---|
| 读写能力 | 只读 | 读 + 写 |
| 移动方向 | 单向（通常向右） | 双向（左/右） |
| 存储 | 仅有穷状态 | 无限长纸带 |
| 结果 | 处理完字符串后判定 | 停机时判定，可能死循环 |

### TM 接受的语言

$M$ **接受**输入 $w$，当存在格局序列 $C_1, C_2, \dots, C_k$ 满足：
- $C_1$ 是 $M$ 在 $w$ 上的起始格局
- 每个 $C_i$ **产生**（一步转移得到）$C_{i+1}$
- $C_k$ 是接受格局

$M$ 识别的语言：$L(M) = \{ w \mid M \text{ 接受 } w \}$

### 三种运行结果

在输入 $w$ 上运行 TM，可能出现三种结果：

| 结果 | 含义 |
|:---|:----|
| **接受** | 停机在 $q_{accept}$，$w \in L(M)$ |
| **拒绝** | 停机在 $q_{reject}$，$w \notin L(M)$ |
| **循环** | 永不停机（死循环） |

> **关键问题**：循环和"跑很久很久"在外部无法区分。你永远不知道机器是死循环了，只是还没算完。

### 判定器（decider）

因为循环无法区分，人们更偏好**对所有输入都停机**的 TM——它们永不循环。

> 这种 TM 被称为**判定器**（decider），也叫**总停机的图灵机**，也叫**算法**。

- 判定器总能决定接受还是拒绝
- 能识别某语言的判定器，称它**判定**（decide）该语言

### 图灵可识别（递归可枚举语言）

> 若存在 TM $M$ 使 $L(M) = A$，则称 $A$ 是**图灵可识别的**（Turing-recognizable），也称**递归可枚举语言**。

对 $A$ 中的串，$M$ 一定接受；对不在 $A$ 中的串，$M$ 可能拒绝也可能**循环**。

### 图灵可判定（递归语言）

> 若存在**判定器** $M$ 使 $L(M) = A$，则称 $A$ 是**图灵可判定的**（Turing-decidable），也称**递归语言**（recursive）。

### 两者的关系

- 每个可判定语言都是可识别的（判定器本身就是一种特殊的 TM）
- 存在可识别但不可判定的语言（如 $L_u$、$L_h$）

**计算层次：** 正则语言 ⊂ 上下文无关语言 ⊂ **可判定语言（递归）** ⊂ **图灵可识别语言（递归可枚举语言）**

## 5. 多带图灵机的定义、与单带图灵机的等价性

### 定义

多带图灵机拥有 $k$ 条独立纸带，每条纸带有一个独立读写头。

转移函数：
$$\delta : Q \times \Gamma^k \to Q \times \Gamma^k \times \{L, R, S\}^k$$

### 与单带 TM 的对比

| | 单带 TM | 多带 TM |
|:---|:--------|:--------|
| 纸带数 | 1 条 | $k$ 条 |
| 读写头 | 1 个 | $k$ 个（每条带独立） |
| δ 读入 | 1 个符号 | $k$ 个符号（每条带各读一个） |
| δ 写入 | 1 个符号 | $k$ 个符号（每条带各写一个） |
| 移动选项 | $\{L,R\}$ | $\{L,R,S\}$（S=原地不动） |

> **多带 TM = 单带 TM × k**：本质完全一样，只是从“一个头做一件事”变成“$k$ 个头同时做 $k$ 件事”。

### 为什么单带没有 S，多带需要 S？

- **单带**：只有一个头，想“原地不动”可以通过 L→R 两步模拟，所以定义上没必要引入 S
- **多带**：$k$ 个头的移动必须**独立控制**。某条带这步不需要移，直接设 S 即可，不需要绕弯子

> S 不是“读到空集才不动”——它是 $\delta$ 里写死的移动方向选项，跟 L、R 平起平坐。

### 等价性证明

**定理：** 每个 $k$ 带图灵机 $M$ 等价于某个单带图灵机 $S$。
![](assets/计算理论/file-20260708112107527.png)
**证明：** 对 $M$ 的输入 $w = w_1 \cdots w_n$，$S$ 在其纸带上写入 $k$ 个区间（用 $k+1$ 个 `#` 分隔），格式为：

$$\# \dot w_1 w_2 \cdots w_n \# \dot \sqcup \# \dot \sqcup \# \cdots \#$$

第一个 `#` 为左端点，第 $k+1$ 个 `#` 为右端点。每个区间对应 $M$ 的一条纸带，**带点符号**（$\dot a$）标记该区间内虚拟读写头位置。（初始时第 1 个区间放输入，其余为空白。）

为模拟 $M$ 的一步，$S$ 执行**两趟扫描**：

1. **第一趟**（左→右）：找出各区间的带点符号，记下 $k$ 个符号 $(s_1,\dots,s_k)$（$k$ 固定，$S$ 用有限状态即可记住）
2. **第二趟**（左→右）：根据 $\delta(q_i,s_1,\dots,s_k) = (q_j,t_1,\dots,t_k,D_1,\dots,D_k)$，将各虚拟头位置改写为 $t_j$，标记点向 $D_j$ 移一格

**边界处理**：

- **右移遇到 `#`**：说明 $M$ 移入了空白区域。$S$ 把此 `#` 及右边的所有内容**整体右移一格**，在空位写 $\sqcup$，标记点放到 $\sqcup$ 上。

- **左移遇到 `#`**：说明 $M$ 在纸带最左端试图左移。$S$ 把标记点再右移一格（跳过 `#`），回到当前区间第一个符号上。

**正确性**：$S$ 精确复现 $M$ 的每一步格局变化，故 $M$ 接受 $w$ 当且仅当 $S$ 接受 $w$。

**复杂度**：$t(n)$ 步的多带机 → $O(t^2(n))$ 步的单带机（多项式等价）。

## 6. 非确定型图灵机的定义、与确定型图灵机的等价性

### 定义

NTM 的转移函数：
$$\delta : Q \times \Gamma \to \mathcal{P}(Q \times \Gamma \times \{L, R\})$$

> **对比单带 DTM**：$\delta : Q \times \Gamma \to Q \times \Gamma \times \{L, R\}$
> 区别只有一处——箭头右边从单个三元组变成了**集合 $\mathcal{P}(\dots)$**。

### 关键理解

- **计算树**：每步有多个分支，所有可能走法构成一棵树
- **接受条件**：**只要存在一条路径走到接受状态**，就认为 NTM 接受该输入
- **直观类比**：NTM 像一台有**无限个并行线程**的机器，每条分支一个线程，任一成功即整体成功

> NTM 不是现实中能造出来的机器——它是**思想实验**，用来精确刻画 **NP** 类问题（多项式时间可验证）。

### 等价性证明

**定理：** 每个 NTM 等价于某个确定型图灵机（DTM）。
![](assets/计算理论/file-20260708111858576.png)
**证明：** 构造 3 带确定型图灵机 $D$ 模拟 $N$ 如下。

| 纸带    | 用途                    |
| :---- | :-------------------- |
| 第 1 带 | 保存原始输入 $w$（只读）        |
| 第 2 带 | 模拟 $N$ 的**当前分支**的计算过程 |
| 第 3 带 | **地址带**——记录当前在计算树中的位置 |

地址带上的数字串决定 $N$ 每一步的走向：若 $\delta_N(q,a)$ 有 $m$ 种选择，则数字 $d$ 表示选第 $d$ 种。

$D$ 的算法流程：

> ① **初始设置**：第 1 带放输入 $w$，第 2、3 带均为空白
> ② **初始化当前分支**：将第 1 带内容复制到第 2 带，第 3 带写 $\varepsilon$（空串）
> ③ **模拟一个分支**：在第 2 带上运行 $N$，每步查询第 3 带的下一个数字 $d$，按第 $d$ 种选择执行
>    - 若地址串用完或选择无效 → 放弃此分支，转 ④
>    - 若遇到拒绝格局 → 放弃此分支，转 ④
>    - 若遇到接受格局 → **$D$ 接受，停机**
> ④ **换下一个分支**：$D$ 在第 3 带上把当前地址串**自增 1**（按字典序计算下一个串，如 $\varepsilon\!\to\!1\!\to\!11\!\to\!12\!\to\!\cdots\!\to\!2\!\to\!21\!\to\!\cdots$），转 ②

> **地址串怎么来的？** $D$ 自己算的——把第 3 带当作一个**计数器**，每次执行 ④ 就加 1。
> 例如最大分支数 $m=3$ 时，$D$ 的计数序列为 $\varepsilon \to 1 \to 2 \to 3 \to 11 \to 12 \to \cdots$（类似 $m$ 进制加法，满 $m$ 进一）。

**正确性**：$D$ 按字典序穷举 $N$ 的所有计算分支。存在接受分支当且仅当 $D$ 最终能遇到它，故 $N$ 接受 $w$ 当且仅当 $D$ 接受 $w$。

**复杂性差异**：$t(n)$ 时间的 NTM → $2^{O(t(n))}$ 时间的 DTM（**指数级爆炸**）。

## 9. 问题、语言、计算模型三者之间的关系

三者互为双向关系，构成一个**三角循环**：

$$\text{问题 (Problem)} \xleftrightarrow[\text{问题定义}]{\text{编码}} \text{语言 (Language)} \xleftrightarrow[\text{判定}]{\text{识别}} \text{计算模型 (TM)} \xleftrightarrow[\text{解决}]{\text{构造}} \text{问题 (Problem)}$$

| 关系 | 方向 | 含义 |
|:---|:----|:-----|
| **问题 ↔ 语言** | 问题 → 语言 | 将问题答案为"是"的实例编码为字符串集合 |
| | 语言 → 问题 | 每个语言对应一个判定问题："某串是否属于该语言？" |
| **语言 ↔ 计算模型** | 语言 → 模型 | 设计 TM 识别/判定该语言 |
| | 模型 → 语言 | TM 接受的所有字符串构成语言 $L(M)$ |
| **计算模型 ↔ 问题** | 模型 → 问题 | 每台 TM 定义了一个判定问题（它接受什么） |
| | 问题 → 模型 | 要解决问题，构造 TM 判定其对应语言 |

## 10. 受限制的图灵机与图灵机的编码

### 图灵机的编码

每条转移规则 $\delta(q_i, X_j) = (q_k, X_l, D_m)$ 编码为：
$$0^i 1 0^j 1 0^k 1 0^l 1 0^m$$

整个 TM 的编码 = 所有规则编码串用 `11` 分隔连接。

#### 编码的意义

- **可数性**：TM 数量可数 → 语言数量不可数 → 必然存在无法识别的语言
- 为对角化语言 $L_d$ 和通用语言 $L_u$ 的构造提供基础
#### 例题

$M = (\{q_1,q_2,q_3\}, \{0,1\}, \{0,1,\sqcup\}, \delta, q_1, q_2)$，其中 $\delta$ 包含 4 条规则：

| 规则                             | 编码                                                                                                               |
| :----------------------------- | :--------------------------------------------------------------------------------------------------------------- |
| $\delta(q_1,1)=(q_3,0,R)$      | $0^11\textcolor{gray}{0^2}1\textcolor{gray}{0^3}1\textcolor{gray}{0^1}1\textcolor{gray}{0^2} = 0100100010100$    |
| $\delta(q_3,0)=(q_1,1,R)$      | $0^31\textcolor{gray}{0^1}1\textcolor{gray}{0^1}1\textcolor{gray}{0^2}1\textcolor{gray}{0^2} = 0001010100100$    |
| $\delta(q_3,1)=(q_2,0,R)$      | $0^31\textcolor{gray}{0^2}1\textcolor{gray}{0^2}1\textcolor{gray}{0^1}1\textcolor{gray}{0^2} = 00010010010100$   |
| $\delta(q_3,\sqcup)=(q_3,1,L)$ | $0^31\textcolor{gray}{0^3}1\textcolor{gray}{0^3}1\textcolor{gray}{0^2}1\textcolor{gray}{0^1} = 0001000100010010$ |

整机编码（规则按任意顺序，用 `11` 分隔）：

$$0100100010100\,11\,0001010100100\,11\,00010010010100\,11\,0001000100010010$$

> 4 条规则共有 $4! = 24$ 种可能的整机编码（规则的排列顺序不同）。

### 受限制的图灵机

简化版 TM，用于理论分析：
- 状态集 $Q = \{q_1, q_2, \dots, q_n\}$
- 输入字母表 $\Sigma = \{0, 1\}$
- 纸带字母表 $\Gamma = \{0, 1, \sqcup\}$
- $q_1$ 为起始状态，$q_2$ 为接受状态

**等价性：** 与标准 TM 计算能力完全等价。

### 图灵机序列的枚举

每个受限制的图灵机都可以按前述规则编码为二进制串。约定：

- 若 $w_i$ 是某 TM 的合法编码 → 记为 $M_i$
- 若 $w_i$ 不是合法编码 → 仍视为 TM $M_i$ 的编码，且 $L(M_i) = \varnothing$

于是得到图灵机序列 $M_1, M_2, M_3, \dots$，每台 TM 与一个二进制串一一对应。

> **推论**：$\{0,1\}^*$ 可数 → **递归可枚举语言有可数个**。

> 这说明不可判定问题比可判定问题要多得多。

**为什么？**

1. **TM 可数**：每台 TM 对应一个二进制编码，所以 TM 台数 ≤ 二进制串总数
2. **递归可枚举语言可数**：每台 TM 识别一种递归可枚举语言，故递归可枚举语言个数 ≤ TM 台数
3. **所有语言不可数**：语言是 $\{0,1\}^*$ 的子集，其**幂集不可数（康托对角线法）**
4. **结论**：递归可枚举语言（可数）只是所有语言（不可数）中极小的一部分——**绝大多数语言没有图灵机能识别**，**一定能找到一个非递归可枚举语言**

## 11. 递归可枚举语言与递归语言的关系

### 定义

| 语言类型        | 别名    | TM 行为            | 直观理解           |
| :---------- | :---- | :--------------- | :------------- |
| **递归可枚举语言** | 图灵可识别 | 属于则停机接受，不属于可能死循环 | "对的肯定能算出来"     |
| **递归语言**    | 图灵可判定 | 总是停机（接受或拒绝）      | "总能在有限时间内给出答案" |

### 关系
1. **递归语言 ⊂ 递归可枚举语言**（每个可判定语言都是可识别的）
2. **互补性定理**：$L$ 是递归语言 ⟺ $L$ 和 $\bar{L}$ 都是递归可枚举语言
### 递归语言的性质

这两定理是后面证明 $L_u$、$L_h$ 不可判定的工具，卷面常作为引理或选项。
#### 定理 1：递归语言对补封闭

若 $L$ 是**递归**的，则 $\overline{L}$ 也是递归的。（又因为递归语言属于递归可枚举语言，所以 $L$ 和 $\bar{L}$ 都是递归可枚举语言）
#### 定理 2：$L$ 与 $\overline{L}$ 都是递归可枚举语言 $\Rightarrow$ $L$ 递归

## 12. 0 号问题 & 对角化语言 $L_d$

### 背景：所有图灵机可枚举

将所有二进制串 $w_1, w_2, w_3, \dots$ 按字典序排列。若 $w_i$ 是某 TM 的合法编码，记该 TM 为 $M_i$；若不是，约定 $w_i$ 也对应一台 TM $M_i$ 且 $L(M_i) = \varnothing$。

于是得到图灵机序列 $M_1, M_2, M_3, \dots$，将每台 TM 与一个二进制串一一对应。

### 对角化方法的思想

构建一张二维表，**行** = 图灵机，**列** = 输入串：

$$\begin{array}{c|ccccc}
& w_1 & w_2 & w_3 & w_4 & \cdots \\ \hline
M_1 & \checkmark & & \checkmark & \checkmark & \\
M_2 & & \checkmark & & & \\
M_3 & \checkmark & \checkmark & & & \\
M_4 & & \checkmark & & \checkmark & \\
\vdots & & & & & \ddots
\end{array}$$

- 第 $i$ 行 = 图灵机 $M_i$ 接受的所有字符串
- 第 $j$ 列 = 所有图灵机对 $w_j$ 的接受情况
- $\checkmark$ 在 $(i,j)$ = $M_i$ 接受 $w_j$

**看对角线**——$(1,1), (2,2), (3,3), \dots$ 上的每个 $\checkmark$ 或空白，表示 $M_i$ 是否接受自己的编码 $w_i$。

现在问：**能否构造一台图灵机，接受所有对角线上为空白（不接受自己）的那些 $w_i$？**

$L_d$ 就是干这件事的：它对每个 $i$ 取对角线位置的**反面**：

- 若 $M_i$ 接受 $w_i$（对角线上 $\checkmark$）→ $L_d$ **不**收 $w_i$
- 若 $M_i$ 不接受 $w_i$（对角线上空白）→ $L_d$ **收** $w_i$

**矛盾在哪？** 假设有一台 $M_j$ 能识别 $L_d$，那么在 $(j,j)$ 处：

- 若 $M_j$ 接受 $w_j$ → $w_j$ 应在 $L_d$ 中 → 但 $L_d$ 只收对角线上为**空白**的 $w_j$ ✗
- 若 $M_j$ 不接受 $w_j$ → $w_j$ 不在 $L_d$ 中 → 但 $L_d$ 要求接受对角线上为**空白**的 $w_j$ ✗

**无论怎样都自相矛盾**，所以这样的 $M_j$ 不存在。$L_d$ 就是靠这个"对角线取反"的设计，保证没有任何图灵机能识别它。


$L_d$ 就是这样一个具体的例子。

### 定义

$$L_d = \{ w_i \mid w_i \in \{0,1\}^*,\; w_i \notin L(M_i) \}$$

即：**第 $i$ 个字符串不在第 $i$ 台图灵机接受的语言中**。

### 证明： $L_d$ 不是递归可枚举语言

**证明（反证法 + 对角化）：**

1. **假设** $L_d$ 是递归可枚举语言 → 存在某台图灵机 $M$ 使得 $L(M) = L_d$
2. $L_d$ 是 $\{0,1\}^*$ 上的语言 → 这台 $M$ 一定有某个编码编号 $j$，即 $M = M_j$
3. 现在问：**$w_j$（第 $j$ 个字符串）是否被 $M_j$ 接受？**

看对角化表格的第 $j$ 行第 $j$ 列，只有两种可能：

$$\begin{array}{c|cccccc}
& \cdots & w_j & \cdots \\ \hline
\vdots & & \vdots & \\
M_j & \cdots & \text{？} & \cdots \\
\vdots & & \vdots & 
\end{array}$$

**情况 ①**：若 $M_j$ **接受** $w_j$（即 $w_j \in L(M_j)$）
   - 因为 $L(M_j) = L_d$ → $w_j \in L_d$
   - 但 $L_d$ 的定义是 "$L_d = \{ w_i \mid w_i \notin L(M_i) \}$"
   - 所以 $w_j \in L_d$ 要求 $w_j \notin L(M_j)$ —— 这与 $w_j \in L(M_j)$ 矛盾 ✗

**情况 ②**：若 $M_j$ **不接受** $w_j$（即 $w_j \notin L(M_j)$）
   - 由 $L_d$ 的定义，$L_d$ 恰好收集那些**不被**自己的 $M_i$ 接受的 $w_i$
   - 所以 $w_j \notin L(M_j)$ 意味着 $w_j \in L_d$
   - 但 $L(M_j) = L_d$ → $w_j \in L(M_j)$ —— 这与 $w_j \notin L(M_j)$ 矛盾 ✗

因此**假设不成立** → **$L_d$ 不是递归可枚举语言**。

## 13. 1 号问题 & 通用语言 $L_u$

### 定义
图灵机 $M$ 是否接受一个字符串 $w$。其对应语言为 $L_u$，即
$$L_u = \{ \langle M, w \rangle \mid w \in \{0,1\}^*,\; M \text{ 是一个图灵机且接受 } w \}$$
语言 $L_u$ 称为通用语言。如果存在一台图灵机 $M_u$，使得 $L(M_u) = L_u$，则称 $M_u$ 为通用图灵机。
### 证明： $L_u$ 是递归可枚举语言，即通用图灵机 $M_u$ 是存在的。

构造 $M_u$ 为一台 3 带图灵机：

| 纸带 | 用途 |
|:---|:----|
| 第 1 带 | 存放 $\langle M, w \rangle$ 的编码，即 $M$ 的规则串 $111$ $w$ |
| 第 2 带 | 模拟 $M$ 在 $w$ 上的运算 |
| 第 3 带 | 存放 $M$ 的当前状态 $q_i$（用 $0^i$ 表示） |

$M_u$ 的工作过程：

1. **检查输入**是否正确

2. **初始化**：
   - 将第 1 带上的 $w$ 复制到第 2 带
   - 第 2 带读写头指向 $w$ 的第一个符号
   - 在第 3 带上打印 $0$（即$0^1$,表示初始状态 $q_1$）

3. **模拟 $M$ 的一步**：
   - 设当前状态 $q_i$（第 3 带上为 $0^i$），第 2 带读写头读入 $X_j$
   - 若 $\delta(q_i, X_j) = (q_k, X_l, D_m)$ 有定义 → 在第 1 带上找编码 $0^i 1 0^j 1 0^k 1 0^l 1 0^m$
   - 然后执行：
     1. 抹去第 3 带的 $0^i$，打印 $0^k$（更新为 $q_k$）
     2. 在第 2 带当前格写入 $X_l$
     3. 第 2 带头根据 $m=1$ 左移或 $m=2$ 右移

4. 若 $\delta$ 无定义（第 1 带上找不到对应编码），$M_u$ 停机

$M_u$ 能模拟任意 $M$ 的行为 → 若 $M$ 接受则 $M_u$ 接受 → **$L_u$ 是递归可枚举语言**。

> **通用图灵机的意义**：
> 1. 现代电子计算机的抽象数学模型，证明了计算机是可以制造出来的
> 2. 不同硬件设计在计算能力上等价
> 3. 为高级语言的解释器奠定基础

### 证明 $L_u$ 不是递归语言（不可判定）

**思路**：递归语言对补运算封闭，若 $L_u$ 递归则 $\overline{L_u}$ 递归，故证 $\overline{L_u}$ 非递归即可得 $L_u$ 非递归。

**反证法 + 归约到 $L_d$：**

1. **假设** $\overline{L_u}$ 是递归的 → 存在总停机的图灵机 $M$，$L(M) = \overline{L_u}$。
   - $M$ 接受 $\langle M', w \rangle$ ⇔ $\langle M', w \rangle \in \overline{L_u}$ ⇔ $M'$ **不接受** $w$

2. **用 $M$ 构造 $M'$ 识别 $L_d$**：
   - $M'$ 输入 $w$，先检查是否含 $111$（含则直接拒绝）
   - $M'$ 把输入改成 $w111w$（即 $\langle M_w, w \rangle$，$M_w$ 是以 $w$ 为编码的图灵机）
   - $M'$ 直接模拟 $M$ 对 $\langle M_w, w \rangle$ 的判定，$M$ 的输出就是 $M'$ 的输出

3. **推理**：
   - $M$ 看到输入 $\langle M_w, w \rangle$，判定它是否属于 $\overline{L_u}$
   - 根据 $\overline{L_u}$ 的定义：$\langle M_w, w \rangle \in \overline{L_u}$ ⇔ $M_w$ **不接受** $w$
   - 所以 $M$ 接受 ⇔ $M_w$ 不接受 $w$ ⇔ $w \in L_d$
   - $M$ 拒绝 ⇔ $M_w$ 接受 $w$ ⇔ $w \notin L_d$
   - 故 $M'$（直接传 $M$ 的输出）接受 $w$ ⇔ $w \in L_d$，即 $M'$ 识别 $L_d$

4. **矛盾**：$L_d$ 是非递归可枚举语言（§12），不存在能识别它的图灵机

**结论**：$\overline{L_u}$ 非递归 → $L_u$ 非递归，即 $L_u$ 不可判定。

## 14. 图灵停机问题 & 语言 $L_h$

### 定义

$$L_h = \{ \langle M, w \rangle \mid w \in \{0,1\}^*,\; M \text{ 是一个图灵机且对输入 } w \text{ 停机} \}$$

### 证明 $L_h$ 是非递归语言

**反证法 + 归约到 $L_d$（构造方法与 $L_u$ 证明类似）：**

1. 假设 $L_h$ 是递归的 → 存在总停机的判定器 $M_{halt}$
2. 将 $M_{halt}$ 改造成 $M'$，使 $M'$ 接受 $L_d$：
   - 给定串 $w$ 作为输入，先检查 $w$ 中不含连续三个 $1$（若含 $111$ 则直接拒绝）
   - $M'$ 把输入改成 $w111w$（即 $\langle M_w, w \rangle$）
   - 先问 $M_{halt}$："$M_w$ 在 $w$ 上停机吗？"
     - 若不停机 → $M_w$ 不接受 $w$ → $w \in L_d$ → $M'$ **接受**
     - 若停机 → 模拟 $M_w$ 在 $w$ 上的运行
       - $M_w$ 接受 $w$ → $w \notin L_d$ → $M'$ **拒绝**
       - $M_w$ 拒绝 $w$ → $w \in L_d$ → $M'$ **接受**
3. $M'$ 接受 $w$ 当且仅当 $w \in L_d$ → $M'$ 识别 $L_d$
4. 但 $L_d$ 是非递归可枚举语言，不存在任何图灵机能识别它 → 矛盾

**结论**：$L_h$ 不是递归语言。

## 15. 莱斯定理的内容与应用

### 定理内容

> **递归可枚举语言的每一个非平凡性质都是不可判定的。**

**定义（递归可枚举语言的性质）：**

- 递归可枚举语言的任一集合 $P$ 就称为递归可枚举语言的一个**性质**
- 若 $P$ 非空，且 $P$ 不是所有递归可枚举语言，则 $P$ 称为**非平凡性质**
- 性质 $P$ 对应的语言：$L_P = \{\langle M \rangle \mid L(M) \in P\}$

> 莱斯定理没有蕴含与一台图灵机有关的每个问题都是不可判定的，只有**涉及语言特征**的问题才适用。

### 应用

以下问题均为不可判定（只需判断是否涉及"图灵机接受的语言"且非平凡）：

| 问题 | 判定内容 |
|:---|:---|
| 空语言判定 | $L(M) = \emptyset$ |
| 有穷性判定 | $L(M)$ 仅有穷个串 |
| 正则性判定 | $L(M)$ 是正则语言 |
| 上下文无关性判定 | $L(M)$ 是上下文无关语言 |
| 非空性判定 | $L(M) \neq \emptyset$ |

### 不适用的情况

- 不涉及语言特征的问题（如"图灵机的状态数是否超过10"）→ 可判定

## 16. 什么是规约

### 定义

将问题 $A$ 的实例转化为问题 $B$ 的具有相同答案的实例。

**形式化**（映射可规约 $A \le_m B$）：
存在可计算函数 $f$ 使得 $w \in A \iff f(w) \in B$

### 核心意义

> 若 $A$ 可规约到 $B$，则问题 $B$ **至少**与问题 $A$ 一样难。

### 归约定理

若存在从 $P_1$ 到 $P_2$ 的规约，则：

1. 若 $P_1$ 是不可判定的，则 $P_2$ 也是不可判定的
2. 若 $P_1$ 是非递归可枚举的，则 $P_2$ 也是非递归可枚举的

**证明：**

1. 若可以判定 $P_2$，则把从 $P_1$ 到 $P_2$ 的规约与判定 $P_2$ 的算法组合起来，构造一个判定 $P_1$ 的算法：给定 $P_1$ 的实例 $x$，对 $x$ 使用规约算法转化为 $P_2$ 的实例 $y$，再用判定 $P_2$ 的算法判定 $y$，结果即为 $x$ 的答案 → 与 $P_1$ 不可判定矛盾

2. 若 $P_2$ 是递归可枚举的（存在图灵机识别 $P_2$），则从 $P_1$ 的实例 $x$ 开始，归约为 $P_2$ 的实例 $y$：若 $x \in P_1$ 则 $y \in P_2$（图灵机接受），否则不接受 → 构造出识别 $P_1$ 的图灵机 → 与 $P_1$ 非递归可枚举矛盾

### 两种规约

| 类型 | 函数要求 | 用途 |
|:---|:---|:---|
| **一般规约** | 可计算 | 证明不可判定性 |
| **多项式时间规约** $\le_P$ | 多项式时间可计算 | 证明 NP-hard/NPC |

### 应用

- 可计算性：$A$ 不可判定 ∧ $A \le_m B$ ⇒ $B$ 不可判定
- 复杂性：$B \in$ P ∧ $A \le_P B$ ⇒ $A \in$ P

## 17. 单带、多带、NTM 之间的计算复杂性关系

### 复杂度对比

| 转换 | 时间消耗 | 对比类型 |
|:---|:---|:----|
| 多带 TM → 单带 TM（§5） | $O(t^2(n))$ | **多项式增长** |
| NTM → 单带 DTM（§6） | $2^{O(t(n))}$ | **指数级增长** |

### 为什么多带到单带只需平方？

§5 的模拟中，单带机用 $k$ 个"活动段"保存 $k$ 条带的内容，每模拟多带机的一步，单带机需要扫描整条记录带找到所有头的位置并更新 → 每步最多 $O(t(n))$ 时间 → 总共 $t(n)$ 步 → $O(t^2(n))$。

> **多项式等价**：所有确定型图灵机（单带、多带等）之间互相模拟的代价都是多项式级的。

### 为什么 NTM 到 DTM 是指数？

$t(n)$ 时间的 NTM 可能产生 $b^{t(n)}$ 条计算路径（$b$ 为最大分支数）。§6 中 DTM 按字典序**逐一穷举**所有可能路径，$b$ 种选择 × $t(n)$ 深度 → $b^{t(n)} = 2^{O(t(n))}$ 条路径。

> **指数爆炸**：非确定型 → 确定型存在根本性的效率差距。

### 核心结论

- **可计算性等价**：三种模型能解决的问题范围完全一致（丘奇-图灵论题）
- **多项式等价**：所有确定型模型（单带、多带等）在多项式意义下等价
- **指数鸿沟**：NTM 模拟 DTM 需要指数时间 → **P ≠ NP 猜想**的核心根源
  - P：DTM 多项式时间可判定的问题
  - NP：NTM 多项式时间可判定（= DTM 多项式时间可验证）的问题
  - 若 P = NP，则所有 NTM 的多项式算法都能被 DTM 多项式模拟——但 §6 的模拟表明这需要指数时间，因此 P ≠ NP 更可信

## 18. P、NP、NPC、NP-hard 的定义与关系

### 时间复杂性类

**定义（时间复杂度）：** 设 $M$ 是总停机的 DTM。$M$ 的运行时间是函数 $f: \mathbb{N} \to \mathbb{N}$，其中 $f(n)$ 是 $M$ 在所有长度为 $n$ 的输入上运行的最大步数。

**定义（复杂性类）：**
- $TIME(t(n)) = \{L \mid L$ 被 $O(t(n))$ 时间的 DTM 判定$\}$
- $NTIME(t(n)) = \{L \mid L$ 被 $O(t(n))$ 时间的 NTM 判定$\}$

### 直观定义

| 类 | 定义 | 时间复杂度 |
|:---|:-----|:----------|
| **P（多项式时间可解）** | 多项式时间内能**解**的问题 | $O(n),\; O(\log n),\; O(n^c)$ |
| **NP（非确定多项式时间）** | 多项式时间内能**验证一个解**的问题 | $O(2^n),\; O(n!)$ 等非多项式时间可能不可解，但解可快速验证 |

> 所有 NP 问题都是**判定问题**（回答 yes 或 no）。

**例（SAT 可满足性）：** 给定公式 $(x_1 \lor \bar{x}_2 \lor x_3) \land (\bar{x}_1 \lor x_2 \lor x_3) \land (x_1 \lor x_2 \lor \bar{x}_3)$，取赋值 $x_1=0,\; x_2=1,\; x_3=0$：
$$c_1 \land c_2 \land c_3 = (0 \lor 0 \lor 0) \land (1 \lor 1 \lor 0) \land (0 \lor 1 \lor 1) = 0 \land 1 \land 1 = 0$$
不可满足。换一组赋值直到找到令结果为 $1$ 的赋值 → 这就是 SAT 问题。

### 四大类定义

| 类           | 形式化定义                                       | 直观理解                            |
| :---------- | :------------------------------------------ | :------------------------------ |
| **P**       | $\displaystyle P = \bigcup_k TIME(n^k)$     | DTM 多项式时间可判定 → **实际可解**         |
| **NP**      | $\displaystyle NP = \bigcup_k NTIME(n^k)$   | NTM 多项式时间可判定 ⇔ DTM 多项式时间**可验证** |
| **NPC**     | ① $\in NP$ ② $\forall A \in NP, A \leq_P$ 它 | **NP 中最难**的问题                   |
| **NP-hard** | 满足条件②（不一定满足①）                               | **至少和 NPC 一样难**                 |

### NP 的两种等价定义

> **定理：** $L \in NP$ 当且仅当 $L$ 能被某个多项式时间的 NTM 判定。

**验证机定义：** 语言 $A$ 的验证机 $V$ 满足 $A = \{w \mid \exists c,\; V$ 接受 $\langle w, c \rangle\}$，其中 $c$ 是证据（certificate）。$V$ 在 $|w|$ 的多项式时间内运行 → 称 $A$ 有多项式时间验证机。

> $NP$ = 有多项式时间验证机的语言类。

### NP 中的经典问题

| 问题 | 判定内容 | 证据 | 验证时间 |
|:---|:---|:---|:----|
| **团问题** | 图 $G$ 有 $k$ 团吗？ | $k$ 个顶点 | $O(k^2)$ 查边 |
| **哈密顿路径** | 图 $G$ 有从 $s$ 到 $t$ 的哈密顿路径吗？ | 顶点排列 | $O(n)$ 查边 |
| **子集和** | 集合中有子集和等于 $t$ 吗？ | 子集 | $O(n)$ 求和 |
| **可满足性（SAT）** | 布尔公式可满足吗？ | 赋值 | $O(n)$ 求值 |

### P 中的问题举例

- **路径问题：** 有向图 $G$ 中 $s$ 到 $t$ 有路径吗？→ 标记算法 $O(n^2)$
- **互素判定：** $x$ 与 $y$ 互素吗？→ 辗转相除法
- **每个上下文无关语言都属于 P**。

### 关系图

```
        NP-hard
    ┌──────┴──────┐
    │    NPC      │ (NP ∩ NP-hard)
    │  ┌─────┐    │
    │  │  P  │    │
    │  └─────┘    │
    └─────────────┘
```

### 引入 NP 完全性的意义

- 若某个 NPC 问题多项式时间可解 → 所有 NP 问题均可多项式时间求解 → **$P = NP$**
- 若能证明某个 NP 问题不存在多项式时间算法（即 $P \neq NP$）→ 所有 NPC 问题都不存在多项式时间算法 → **$NPC \cap P = \varnothing$**
- ∴ **NPC 问题是 NP 问题中"最难的"**

> $P \neq NP$ 否还不知道，现在普遍认为 $P \neq NP$。

## 19. 多项式时间归约与 NPC 证明方法

### 多项式时间归约

**定义（多项式时间可计算函数）：** 若存在多项式时间图灵机 $M$，在任何输入 $w$ 上停机时带子上恰为 $f(w)$，则 $f: \Sigma^* \to \Sigma^*$ 是多项式时间可计算函数。

**定义（多项式时间归约 $\leq_P$）：** 语言 $A$ 可多项式时间归约到 $B$，记为 $A \leq_P B$，若存在多项式时间可计算函数 $f$，使得 $w \in A \iff f(w) \in B$。

**定理：** 若 $A \leq_P B$ 且 $B \in P$，则 $A \in P$。

> **证明：** 用 $f$ 将 $A$ 的实例 $w$ 映射为 $B$ 的实例 $f(w)$，再用 $B$ 的多项式算法判定。两步骤均在多项式时间内，故 $A \in P$。

### NPC 问题的正式定义

语言 $B$ 称为 **NP 完全的**（NP-complete），若：
1. $B \in NP$
2. $\forall A \in NP,\; A \leq_P B$（$B$ 是 NP-hard）

**核心定理：**
- 若 $B$ 是 NPC 且 $B \in P$，则 $P = NP$
- 若 $B$ 是 NPC 且 $B \leq_P C,\; C \in NP$，则 $C$ 是 NPC

### Cook 定理（第一个 NPC 问题）

> **定理：** 可满足问题（CNF-SAT）是 NP 完全的。

其证明用到非确定图灵机理论：将 NTM 的计算过程编码为布尔公式，使得公式可满足 ⟺ NTM 有接受路径。

### 证明 NPC 的两步法

| 步骤 | 要证 | 做法 |
|:---|:---|:-----|
| **① $A \in NP$** | 多项式时间可验证 | 给出证据（如顶点集、排列），说明 $O(n^k)$ 内可验证 |
| **② $A$ 是 NP-hard** | $A' \leq_P A$（$A'$ 是已知 NPC） | 构造 $f$ 将 $A'$ 实例映射到 $A$ 实例，证 $A'$ 有解 $\iff$ $A$ 有解 |

> 证明 **NP-hard** 只需做第②步。

### 经典归约链（从 Cook 定理出发）

```
Cook: CNF-SAT 是第一个 NPC
           ↓
      3CNF-SAT (子句长度限制为3)
       /     |      \
      ↓      ↓       ↓
   团问题  顶点覆盖  哈密顿路径
     ↓       ↓
   独立集   三维匹配
  (补图)     ↓
          划分问题 ← 子集和
```

## 20. 经典 NPC 问题与规约构造

### 预备知识：布尔公式

| 术语       | 含义                      | 示例                                                                  |
| :------- | :---------------------- | :------------------------------------------------------------------ |
| **文字**   | 布尔变量 $x$ 或其否定 $\bar{x}$ | $x_1,\; \bar{x}_2$                                                  |
| **子句**   | 文字用 $\lor$ 连接           | $(x_1 \lor \bar{x}_2 \lor x_3)$                                     |
| **CNF**  | 子句用 $\land$ 连接（合取范式）    | $(x_1 \lor x_2) \land (\bar{x}_1 \lor x_3)$                         |
| **3CNF** | 每个子句恰好 3 个文字的 CNF       | $(x_1 \lor x_2 \lor x_3) \land (\bar{x}_1 \lor x_2 \lor \bar{x}_3)$ |

---

### 3CNF-SAT 是 NP 完全的

**问题描述：** 给定 $n$ 个布尔变元 $x_1,\dots,x_n$ 和 $m$ 个子句，每个子句是 3 个文字的析取（$\lor$），例如：

$$(\bar{x}_1 \lor x_2 \lor x_3) \land (x_7 \lor x_9 \lor \bar{x}_{10}) \land \cdots \land (x_5 \lor \bar{x}_6 \lor x_4)$$

问：是否存在一组 $0/1$ 赋值使整个合取范式结果为真？

**前提**：已知 CNF-SAT 是 NPC（Cook 定理）。现证 3CNF-SAT 也是 NPC。

**① $\in$ NP：** 给定一组赋值，代入公式求值 → $O(|w|)$。

**② 定义归约函数 $f$（CNF-SAT $\leq_P$ 3CNF-SAT）：**

按多项式时间规约的定义 $w \in \text{CNF-SAT} \iff f(w) \in \text{3CNF-SAT}$，

$f$：输入 CNF 公式 $w$，输出 3CNF 公式 $f(w)$。对 $w$ 的每个子句按文字个数处理：

| 原子句长度                                            | 转化方式                                                                                                                                             |
| :----------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| $\vert C_i\vert =1$：$(l_1)$                      | 加 $y,z$，变 4 子句：$(l_1 \lor y \lor z) \land (l_1 \lor y \lor \bar{z}) \land (l_1 \lor \bar{y} \lor z) \land (l_1 \lor \bar{y} \lor \bar{z})$       |
| $\vert C_i\vert =2$：$(l_1 \lor l_2)$             | 加 $y$，变 2 子句：$(l_1 \lor l_2 \lor y) \land (l_1 \lor l_2 \lor \bar{y})$                                                                           |
| $\vert C_i\vert =3$：$(l_1 \lor l_2 \lor l_3)$    | 保持不变                                                                                                                                             |
| $\vert C_i\vert >3$：$(l_1 \lor \cdots \lor l_k)$ | 加 $y_1,\dots,y_{k-3}$，变成链：$(l_1 \lor l_2 \lor y_1) \land (\bar{y}_1 \lor l_3 \lor y_2) \land \cdots \land (\bar{y}_{k-3} \lor l_{k-1} \lor l_k)$ |

其中 $y, z, y_i$ 是新引入的辅助变量，$f(w)$ 的每个子句恰好 3 个文字。

**③ 证 $w$ 可满足 $\iff$ $f(w)$ 可满足（即 $w \in \text{CNF-SAT} \iff f(w) \in \text{3CNF-SAT}$）：**

**必要性（$\Rightarrow$）：** 设 $w$ 可满足（$w \in \text{CNF-SAT}$）→ 每个原 $C_i$ 至少一个文字为真 → 取相同赋值，按情况设辅助变量：
- $|C_i|=1$：$x=1$ → 4 子句全含 $x$ → 全为 $1$
- $|C_i|=2$：$x_1 \lor x_2 = 1$ → 两子句都含 $x_1 \lor x_2$ → 全为 $1$
- $|C_i|=3$：直接成立
- $|C_i|>3$：链中至少一个文字为真（设为 $x_p$）。从左往右看：**碰见 $x_p$ 之前**的子句，若无文字为真就把对应 $y$ 设 **1** 把"需求"往后传；**碰见 $x_p$ 之后**的子句，设 $y$ 全 **0**（$\bar{y}=1$ 自动满足）→ 链中每子句均真

→ $f(w)$ 可满足（即 $f(w) \in \text{3CNF-SAT}$）。

**充分性（$\Leftarrow$）：** 设 $f(w)$ 可满足（$f(w) \in \text{3CNF-SAT}$）→ 忽略辅助变量，只看原变量：
- $|C_i|=1$：若 $x=0$，4 子句覆盖了 $y,z$ 全部组合 → 必有 1 子句爲假 → 故 $x$ 必须为 $1$
- $|C_i|=2$：若 $x_1=x_2=0$，一子句要 $y=1$ 另一要 $y=0$ → 矛盾 → 故 $x_1 \lor x_2 = 1$
- $|C_i|=3$：直接成立
- $|C_i|>3$：反证法——若所有文字全 $0$，则第 $1$ 子句强制 $y_1=1$，第 $2$ 子句强制 $y_2=1$，… 链会强制所有 $y$ 为 $1$，最后子句变为 $0 \lor 0 \lor 0 = 0$，矛盾 → 至少有一个文字为真

→ $w$ 可满足（即 $w \in \text{CNF-SAT}$）。

> 两个方向均成立 → $w \in \text{CNF-SAT} \iff f(w) \in \text{3CNF-SAT}$ → $f$ 是正确规约 → **3CNF-SAT 是 NPC**

### $k$团问题

**问题描述：** 图 $G$ 有 $k$ 个顶点且两两之间有边的子图（$k$ 团）吗？

**前提：** 已知 3CNF-SAT 是 NPC，现证团问题也是 NPC。

**① $\in$ NP：** 给定 $k$ 个顶点，$O(k^2)$ 时间查所有顶点对之间是否有边。

**② 定义归约函数 $f$（3CNF-SAT $\leq_P$ 团问题）：**

按多项式时间规约的定义 $w \in \text{3CNF-SAT} \iff f(w) \in \text{团问题}$，

$f$：输入 3CNF 公式 $w$（$m$ 个子句），输出无向图 $f(w) = (V,E)$：
- $V$ = $w$ 中出现的每个文字（共 $3m$ 个，每个子句 3 个）
- $E$：两顶点之间有边 ⟺ **同时满足**以下两条：
  1. 两个文字**不属于同一子句**
  2. 两个文字**不是互补的**（即不是 $x$ 和 $\bar{x}$）
- 令 $k = m$

**③ 证 $w \in \text{3CNF-SAT} \iff f(w) \in \text{团问题}$：**

**必要性（$\Rightarrow$）：** 设 $w$ 可满足（$w \in \text{3CNF-SAT}$）→ 每个子句 $c_j$ 至少有一个文字为 $1$ → 从每个子句中任选一个真文字，得 $m$ 个顶点 → 这些顶点来自不同子句、文字不互补 → 两两有边 → 构成 $m$ 团 → $f(w)$ 有 $m$ 团

**充分性（$\Leftarrow$）：** 设 $f(w)$ 有 $m$ 团（$f(w) \in \text{团问题}$）→ 同子句内无边，故 $m$ 个顶点必来自 $m$ 个**不同子句**。按以下规则赋值：
  - 若顶点文字是 $x_i$，令 $x_i = 1$
  - 若顶点文字是 $\bar{x}_i$，令 $x_i = 0$（即该文字 $\bar{x}_i = 1$）
由于 $x_i$ 与 $\bar{x}_i$ 之间无边，**$m$ 团中不会同时出现 $x_i$ 和 $\bar{x}_i$**，赋值不会矛盾。每个子句恰好对应一个被选为 $1$ 的文字 → 每个子句为真 → $w$ 可满足

> 两个方向均成立 → $w \in \text{3CNF-SAT} \iff f(w) \in \text{团问题}$ → $f$ 是正确规约 → **团问题是 NPC**

### 顶点覆盖问题

**问题描述：** 图 $G$ 有 $k$ 个顶点的子集 $C$，使得每条边至少有一端在 $C$ 中吗？

**前提：** 已知 3CNF-SAT 是 NPC，现证顶点覆盖问题也是 NPC。

**① $\in$ NP：** 给定 $k$ 个顶点，检查每条边是否至少有一端在其中 → $O(|E|)$。

**② 定义归约函数 $f$（3CNF-SAT $\leq_P$ 顶点覆盖）：**

按多项式时间规约的定义 $w \in \text{3CNF-SAT} \iff f(w) \in \text{顶点覆盖}$，

$f$：输入 3CNF 公式 $w$（$n$ 个变量 $x_1,\dots,x_n$，$m$ 个子句 $c_1,\dots,c_m$），输出图 $f(w) = (V,E)$：
- **变量组件：** 每个变量 $x_i$ → 一条边 $(x_i, \bar{x}_i)$（2 个顶点）
- **子句组件：** 每个子句 $c_j$ → 一个三角形（3 个顶点，记为 $c_j^1, c_j^2, c_j^3$，两两连边）
- **连接边：** 三角形顶点 $c_j^t$ 与变量顶点相连（若该顶点文字是 $x_i$ 则连 $x_i$，若为 $\bar{x}_i$ 则连 $\bar{x}_i$）
- 令 $k = n + 2m$

**③ 证 $w \in \text{3CNF-SAT} \iff f(w) \in \text{顶点覆盖}$：**

**必要性（$\Rightarrow$）：** 设 $w$ 可满足（$w \in \text{3CNF-SAT}$）→ 构造覆盖集合：
  - **变量边：** 若 $x_i=1$ 则选 $x_i$，若 $x_i=0$ 则选 $\bar{x}_i$ → $n$ 条变量边各被选中的端点覆盖 
  - **三角形 + 连接边：** 每个子句 $c_j$ 至少有一个真文字，设为 $l$。该文字对应的三角形顶点与变量顶点之间的**连接边已被变量顶点覆盖**（因为变量顶点已选），故三角形中只需再选剩下 2 个顶点 → $2m$ 个 
  - 共 $n + 2m$ 个顶点 → $f(w)$ 有 $k$ 覆盖

**充分性（$\Leftarrow$）：** 设 $f(w)$ 有 $k$ 覆盖（$f(w) \in \text{顶点覆盖}$）：
  - **变量边约束：** 每条变量边 $(x_i, \bar{x}_i)$ 需选至少 $1$ 个端点 → 至少 $n$ 个顶点
  - **三角形约束：** 每个三角形需选至少 $2$ 个顶点（3 条边每边都要被覆盖，仅选 1 个顶点最多覆盖 2 条边）→ 至少 $2m$ 个顶点
  - 总数恰好 $k = n+2m$ → **必然**：变量边**恰好每边选 $1$ 个**，三角形**恰好每 clause 选 $2$ 个**
  - **三角形中剩哪个不选？** → 剩的那个必是它和变量顶点之间的**连接边已被变量顶点覆盖**的那个
  - **如何赋值？** 若选中的变量顶点是 $x_i$ 则令 $x_i=1$；若选中的是 $\bar{x}_i$ 则令 $x_i=0$
  - 每个三角形未选的那个顶点对应一个文字 $l$，其连接边的另一端的变量顶点已选 → 该文字为 $1$ → 每个子句均为真 → $w$ 可满足

> 两个方向均成立 → $w \in \text{3CNF-SAT} \iff f(w) \in \text{顶点覆盖}$ → $f$ 是正确规约 → **顶点覆盖问题是 NPC**

### 子集和问题

**问题描述：** 给定正整数集合 $A$ 和目标值 $B$，存在子集 $A' \subseteq A$ 使 $\sum A' = B$ 吗？

**前提：** 已知 3CNF-SAT 是 NPC，现证子集和问题也是 NPC。

**① $\in$ NP：** 给定 $A'$，求和并与 $B$ 比较 → $O(n)$。

**② 定义归约函数 $f$（3CNF-SAT $\leq_P$ 子集和）：**

按多项式时间规约的定义 $w \in \text{3CNF-SAT} \iff f(w) \in \text{子集和}$，

$f$：输入 3CNF 公式 $w$（$n$ 个变量 $x_1,\dots,x_n$，$m$ 个子句 $c_1,\dots,c_m$），输出数集 $A$ 和目标值 $B$，记为 $f(w) = (A,B)$。构造 $2(n+m)+1$ 个 $n+m$ 位十进制数（每位 $0\!\sim\!3$，进制足够大保证无进位）：

- **变量对应的 $2n$ 个数**：每个变量 $x_i$ 对应两个十进制数 $x_i$ 和 $\bar{x}_i$
  - $x_i$：第 $i$ 位（变量位）= $1$；若 $x_i$ 出现在子句 $c_j$ 中，第 $n+j$ 位（子句位）= $1$，其他位 = $0$
  - $\bar{x}_i$：第 $i$ 位（变量位）= $1$；若 $\bar{x}_i$ 出现在子句 $c_j$ 中，第 $n+j$ 位（子句位）= $1$，其他位 = $0$
- **子句对应的 $2m$ 个调节数**：每个子句 $c_j$ 对应两个数 $g_j, h_j$，第 $n+j$ 位（子句位）= $1$，其他位 = $0$
- **目标值 $B$**：$n$ 个 $1$ + $m$ 个 $3$，即 $\underbrace{1\cdots 1}_{n}\underbrace{3\cdots 3}_{m}$

**③ 证 $w \in \text{3CNF-SAT} \iff f(w) \in \text{子集和}$：**

**必要性（$\Rightarrow$）：** 设 $w$ 可满足（$w \in \text{3CNF-SAT}$）→ 构造子集：
  - **变量选择：** 若 $x_i=1$ 选数 $x_i$，若 $x_i=0$ 选数 $\bar{x}_i$ → 前 $n$ 位（变量位）每位恰好和为 $1$
  - **子句位凑 $3$：** 对每个子句 $c_j$，已选的 $x_i/\bar{x}_i$ 在子句位 $n+j$ 上的和可能是 $1,2,3$：
    - 和为 $1$（仅一个真文字）→ 把 $g_j, h_j$ 都加入子集（$+2$ → 得 $3$）
    - 和为 $2$（两个真文字）→ 把 $g_j, h_j$ 任一个加入子集（$+1$ → 得 $3$）
    - 和为 $3$（三个真文字）→ $g_j, h_j$ 都不加
  - 此时各位和均达到目标值 $B$，且每位和 $\le 5$ 无进位 → 所选数之和 $=B$ → $f(w)$ 有解

**充分性（$\Leftarrow$）：** 设 $f(w)$ 有解（$f(w) \in \text{子集和}$），即若干个数之和 $= B = \underbrace{1\cdots 1}_{n}\underbrace{3\cdots 3}_{m}$。每位和 $\le 5$，**不会产生进位**：
  - **变量位分析：** 前 $n$ 位每位和为 $1$ → 每位只能从 $\{x_i, \bar{x}_i\}$ 中**恰好选一个**。赋值规则：若 $x_i$ 在子集中则 $x_i=1$，若 $\bar{x}_i$ 在子集中则 $x_i=0$
  - **子句位分析：** 后 $m$ 位每位和为 $3$。即使 $g_j, h_j$ 全选，子句位也最多贡献 $2$ → **必须至少有一个 $x_i/\bar{x}_i$ 在该位为 $1$** → 每个子句 $c_j$ 至少有一个文字为真 → $w$ 可满足

> 两个方向均成立 → $w \in \text{3CNF-SAT} \iff f(w) \in \text{子集和}$ → $f$ 是正确规约 → **子集和问题是 NPC**

---

### 证明核心要诀

```
已知 NPC  →  构造 f  →  目标问题
   A'           ⟺         A
  有解                   有解
```

- **NPC 证明 = ① 属于 NP + ② NP-hard 归约**
- **NP-hard 证明 = 只需②**
- 归约本质：将已知 NPC 问题的实例**转化为**目标问题的实例，保持解一一对应
