## 2. 计算理论概述

> [!tip] **复习重点**
> 计算理论的研究目的与研究内容、可计算性理论与计算复杂性理论的区别，以及问题—语言—计算模型的关系，是期末常考点。

### 2.1 研究目的：计算机的基本能力和局限性是什么？

20 世纪 30 年代，数理逻辑学家开始追问：**什么叫“计算”？**  
计算理论不是要教你怎么写 Python，而是要回答：

- 哪些问题**原则上**可以用算法解决？  
- 哪些**永远**解决不了？  
- 能解决的里面，哪些**快**、哪些**慢**？

一句话：**给“计算”下精确的数学定义，并划出能力与边界。**

### 2.2 三大分支

| 分支 | 英文 | 研究什么 |
|------|------|----------|
| **自动机理论** | Automata | 计算的**数学模型**（有穷自动机、下推自动机、图灵机等）及其性质 |
| **可计算性理论** | Computability | 哪些问题**可被计算解决**，哪些**不可解** |
| **计算复杂性理论** | Complexity | 可解问题里，哪些**容易**、哪些**困难**，以及“难”的根源 |

生活类比：

- **自动机**：规定“机器长什么样、怎么转状态”（像先定比赛规则和场地）。  
- **可计算性**：这道题**有没有标准答案、能不能判对错**（像“是否存在判定程序”）。  
- **复杂性**：有答案时，**要花多少时间/空间**（像“1 秒出结果还是宇宙年龄都不够”）。

### 2.3 可计算性 vs 计算复杂性

两者目标不同，但紧密相关：

| | **可计算性理论** | **计算复杂性理论** |
|---|------------------|---------------------|
| **核心问题** | 问题**可解还是不可解**？ | 可解问题**多难算**？ |
| **典型结论** | 停机问题不可判定；某些数学命题无法算法判定真假 | P、NP 等分类；近似算法、随机算法等应对“难解” |
| **比喻** | 这座山**能不能爬上去** | 爬上去要**几天还是几年** |

课件中的对照：

- 可计算性：把问题分成**可解的**和**不可解的**。  
- 复杂性：把问题分成**容易计算的**和**难计算的**。

历史上与此相关的名字（了解即可）：哥德尔、**图灵**（图灵机）、丘奇（$\lambda$ 演算）——他们为“什么是可计算”提供了等价的不同模型。

### 2.4 自动机理论在整体中的角色

可计算性和复杂性都需要**精确的“计算机”数学定义**。自动机理论提供一族模型：

- **有穷自动机**（对应正则语言）— 状态有限，无无限记忆  
- **下推自动机**（对应上下文无关语言）— 带栈  
- **图灵机** — 现代计算机的抽象模型，无限纸带

后面章节会逐个展开；本章只需建立地图。

### 2.5 问题、语言与计算模型（预习）

> [!tip] **复习重点**
> 问题、语言、计算模型三者之间的关系（本章先建立直觉，ch03 会系统讲）。

在计算理论里，习惯这样统一语言：

1. **问题（Problem）**  
   例如：“给定一个数，判断它是否为素数？”“给定程序 $M$ 和输入 $w$，$M$ 在 $w$ 上会不会停机？”

2. **语言（Language）**  
   把问题的**是/否实例**编码成字符串；**语言**就是“所有应回答‘是’的编码串”组成的集合。  
   例：字母表 $\Sigma = \{0,1\}$，语言 $L$ 可能是“所有代表素数的二进制串”的集合。

3. **计算模型（Computation Model）**  
   如图灵机、有穷自动机：规定**怎样读串、怎样转移、何时接受**。  
   模型 $M$ **识别/判定**语言 $L$，即：对输入串，正确区分是否属于 $L$。

关系链（背下来）：

$$\text{实际问题} \;\Rightarrow\; \text{形式化问题} \;\Rightarrow\; \text{语言 } L \subseteq \Sigma^* \;\Rightarrow\; \text{用模型 } M \text{ 去识别/判定 } L$$

- **可计算性**常问：是否存在图灵机判定 $L$？  
- **复杂性**常问：判定 $L$ 需要多少时间/空间？

## 3. 数学基础

后续证明都建立在下面概念上；零基础可按“定义 + 小例子”记忆。

### 3.1 集合

**集合**：把一些对象看成整体。

$$S = \{7, 21, 25\}$$

| 概念 | 符号/说法 |
|------|-----------|
| 元素、成员 | $7 \in S$，$8 \notin S$ |
| 子集 | $A \subseteq B$（$A$ 每个元素都在 $B$ 里） |
| 真子集 | $A \subsetneq B$（子集且不相等） |
| 自然数集 / 整数集 | $\mathbb{N}$ / $\mathbb{Z}$ |
| 空集 | $\varnothing$（不含任何元素） |
| 并集 | $A \cup B$ |
| 交集 | $A \cap B$ |
| 补集 | $\overline{A}$（相对某个全集） |
| 幂集 | $\mathcal{P}(A)$ = $A$ 的所有子集构成的集合 |

**幂集例子**：$A = \{0, 1\}$，则

$$\mathcal{P}(A) = \{\varnothing, \{0\}, \{1\}, \{0,1\}\}$$

共 $2^{|A|} = 4$ 个子集。

**构造写法**：$\{n \mid n = m^2,\, m \in \mathbb{N}\}$ 表示“所有完全平方数”组成的集合。

### 3.2 序列和元组

**序列**：元素按**顺序**排列的列表；**顺序和重复**都重要。

$$(7, 21, 57)$$

| 概念 | 说明 |
|------|------|
| $k$-元组 | 长度为 $k$ 的序列 |
| 有序对 | $2$-元组，常写 $(a,b)$ |
| 笛卡尔积 | $A \times B = \{(a,b) \mid a \in A,\, b \in B\}$ |

例：$A = \{0,1\}$，$B = \{x,y\}$，则 $A \times B$ 有 4 个有序对：$(0,x),(0,y),(1,x),(1,y)$。

### 3.3 函数与关系

#### 函数

**函数** $f$：每个输入对应**唯一**输出（同样输入永远同样输出），也叫**映射**。

$$f: D \to R$$

- **定义域** $D$：允许的输入集合  
- **值域** $R$：输出可能取到的集合（有时写 codomain）

**映上（满射, onto / surjective）**：值域里每个元素都至少被某个输入命中。

**例（模 4 加法）**：$g: \mathbb{Z}_4 \times \mathbb{Z}_4 \to \mathbb{Z}_4$，其中 $\mathbb{Z}_4 = \{0,1,2,3\}$，$g(a,b) = (a+b) \bmod 4$。

| 概念 | 说明 |
|------|------|
| 一元函数 | 一个自变量 |
| 二元函数 | 两个自变量 |
| **谓词** | 值域为 $\{\mathsf{TRUE}, \mathsf{FALSE}\}$ 的函数，表示“性质” |

#### 关系

定义在 $A \times \cdots \times A$ 上的谓词叫 **$k$ 元关系**。二元关系 $R$：写 $a R b$ 表示 $(a,b)$ 满足关系。

**等价关系**需同时满足三条：

1. **自反**：$\forall x,\; x R x$  
2. **对称**：$x R y \Rightarrow y R x$  
3. **传递**：$x R y$ 且 $y R z \Rightarrow x R z$

例：“同余 mod $n$”是等价关系；把整数分成等价类，是后面证明里常见结构。

### 3.4 字符串与语言

#### 字母表与字符串

- **字母表** $\Sigma$：非空**有限**符号集合。  
- **字符串**：$\Sigma$ 上符号的**有限序列**。  
- **长度** $|w|$：符号个数。  
- **空串** $\varepsilon$：长度 0。  
- **反转** $w^{\mathcal{R}}$：符号顺序颠倒。  
- **子串**：在 $w$ 中**连续**出现的一段。  
- **连接** $xy$：先写 $x$ 再写 $y$；$x^k$ 表示 $x$ 连接 $k$ 次。

例：$\Sigma = \{0,1\}$，$w = 01001$，$|w| = 5$。

#### 语言

**语言** $L$：**字符串的集合**（通常是 $\Sigma^*$ 的子集）。

- **前缀**：存在 $z$ 使 $xz = y$，则 $x$ 是 $y$ 的前缀。  
- **无前缀语言**：语言中任意两个串，彼此都不是对方的真前缀（编码理论里会碰到）。

#### 语言运算

**连接**：

$$L_1 L_2 = \{xy \mid x \in L_1,\, y \in L_2\}$$

**Kleene 闭包** $L^*$：

- $L^0 = \{\varepsilon\}$  
- $L^n = L L^{n-1}$（$n \ge 1$）  
- $L^* = \bigcup_{n \ge 0} L^n$（零次或多次拼起来）  

**正闭包** $L^+ = \bigcup_{n \ge 1} L^n$（至少连接一次；不包含“0 次连接”的那一项，因此通常 $L^+$ 与 $L^*$ 差在是否显式包含仅由 0 次连接得到的 $\varepsilon$，当 $L$ 非空时 $L^+ \subseteq L^*$）。

**全体串**：

- $\Sigma^+$：由 $\Sigma$ 中符号拼成的**非空**串（若允许空串则看定义；课件中 $\Sigma^+ = \Sigma^* \setminus \{\varepsilon\}$ 的用法与 $\Sigma^* = \Sigma^+ \cup \{\varepsilon\}$）  
- $\Sigma^*$：**所有**有限长串，**包括** $\varepsilon$

**小例子**：$\Sigma = \{0,1\}$，$L = \{10, 01\}$。

- $L^2 = \{1010, 1001, 0110, 0101\}$  
- $L^*$ 包含 $\varepsilon$、$10$、$01$、以及任意有限次用 $10,01$ 拼出来的串

## 4. 证明方法

计算理论课大量定理靠证明；三种方法务必会认、会套简单题。

### 4.1 基本术语

- **定义**：概念精确定义  
- **定理 / 引理 / 推论**：真命题；引理是辅助，推论由定理直接推出  
- **证明**：无漏洞的逻辑推导  

复合命题习惯：

- $P \iff Q$：$P$ 当且仅当 $Q$  
- $P \Rightarrow Q$：$P$ 仅当 $Q$（$P$ 真则 $Q$ 真）  
- 证 $A = B$：常证 $A \subseteq B$ 且 $B \subseteq A$

### 4.2 构造性证明

**思路**：定理说“存在某个对象”，你就**真的造出来**，并验证满足条件。

**例（3-正则图）**：对每个大于 2 的偶数 $n$，存在 $n$ 个顶点的 3-正则图（每点度数 3）。

**构造**：顶点 $V = \{0,1,\ldots,n-1\}$，边包括：

- 环：$(i, i+1)$（$0 \le i \le n-2$）加 $(n-1, 0)$  
- 再连 $(i, i + n/2)$（$0 \le i \le n/2 - 1$）

画几个小 $n$（如 $n=4,6$）可直观看到每点恰好 3 条边——这就是构造性证明。

### 4.3 反证法

**思路**：假设结论**不成立**，推出**矛盾**，则原结论必真。

**定理**：$\sqrt{2}$ 是无理数（不能写成两个整数之比）。

**证明梗概**：

1. 设 $\sqrt{2} = m/n$，$m,n$ 互素（最简分数）。  
2. 平方得 $2n^2 = m^2$，故 $m^2$ 偶 $\Rightarrow$ $m$ 偶，写 $m = 2k$。  
3. 代入得 $n^2 = 2k^2$，故 $n$ 也偶。  
4. $m,n$ 都偶与互素矛盾 $\Rightarrow$ 假设错，$\sqrt{2}$ 无理。

反证法在**不可判定性**证明里极其常见（后面停机问题等）。

### 4.4 归纳法

对**全体自然数**或**按结构递归定义的对象**证明性质。

**数学归纳法**：

1. **基础**：证 $P(1)$（或 $P(0)$，看题设）  
2. **归纳步**：假设 $P(i)$（归纳假设），推出 $P(i+1)$  

**强归纳**：假设对所有 $j \le i$，$P(j)$ 成立，再证 $P(i+1)$。

**结构归纳法**：对象由**递归规则**生成（如“表达式的定义”），则：

- 对**基础情况**（规则 (1)）验证性质；  
- 对**构造情况**（规则 (2)）：假设子结构已有性质，证新构造仍满足。

**例（括号匹配）**：表达式由  
(1) 数字/字母是表达式；  
(2) 若 $E,F$ 是表达式，则 $E+F$、$E*F$、$(E)$ 也是；  
(3) 仅限于此。  

**命题**：每个表达式左括号数 = 右括号数。

- **基础**：单个符号，括号数 0。  
- **归纳**：对 $E+F$、$E*F$，括号数相加不变；对 $(E)$，左右各加 1。

## 练习

**练习 1（来自：ch00）**

**题目**：简述计算理论的**三大分支**及其各自的研究目标（各用一两句话）。

> [!question]- 点击查看完整解答
> **解答**：
>
> 设三大分支为自动机理论、可计算性理论、计算复杂性理论。
>
> 1. **自动机理论（Automata）**  
>    - **目标**：定义并研究各类**计算的数学模型**（如有穷自动机、下推自动机、图灵机），弄清它们能识别/生成哪类语言、有哪些性质。  
>    - **作用**：为“什么是计算机器”提供严格定义，是可计算性与复杂性的共同语言基础。
>
> 2. **可计算性理论（Computability）**  
>    - **目标**：把问题分为**可解**与**不可解**——是否存在算法（在图灵机等标准模型上）对一切输入给出正确答案。  
>    - **典型问题**：停机问题、判定某数学命题真假是否可算法化。
>
> 3. **计算复杂性理论（Complexity）**  
>    - **目标**：在**可解**的前提下，按时间/空间等资源把问题分为**易算**与**难算**，并分析“难”的原因与应对（近似、随机、平均情况等）。  
>    - **典型框架**：P、NP 等复杂度类（见 ch04）。
>
> 三者关系：自动机提供**模型**；可计算性划**能不能算**；复杂性划**算起来贵不贵**。

**练习 2（来自：ch00）**

**题目**：用自己的话说明**可计算性理论**与**计算复杂性理论**的区别，并各举一个课件中的“典型关切”。

> [!question]- 点击查看完整解答
> **解答**：
>
> **符号化**：
> - 可计算性：关心是否存在图灵机 $M$，对语言 $L$ 对应的判定问题**对所有输入**停机且回答正确。  
> - 复杂性：设问题可解，关心 $M$ 的运行时间 $T(n)$、空间 $S(n)$ 等是否多项式、是否指数级等。
>
> **通俗对比**：
> - 可计算性像问：“有没有改卷标准答案的**自动批改程序**？”——没有就是**不可解**。  
> - 复杂性像问：“批改一份卷子要 **1 秒还是 1 万年**？”——能批改但太慢，属于**难解但可解**。
>
> **课件典型关切**：
> 1. **可计算性**：有些看似简单的问题**不能用计算机解决**（例：判定任意数学命题真假）；要把问题分成可解/不可解；历史上有图灵、哥德尔、丘奇等。  
> 2. **复杂性**：在可解问题中，排序相对容易，时间表安排等问题往往困难；研究“什么使问题难算”、能否改模型（如随机计算）、能否求近似解等。
>
> **关系**：先过可计算性门槛（可解），再在可解集合里谈复杂性（易/难）。不可解问题不再讨论“多项式时间”意义上的高效算法。
