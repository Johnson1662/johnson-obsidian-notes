### 二、理论定律类（简答题）

**核心理论：**

#### 1. 加速比定律（三种经典定律）

| 定律名称 | 公式 | 核心思想 |
|----------|------|----------|
| **Amdahl定律** | $S = \frac{1}{(1-P) + P/N}$ | 固定问题规模，强调串行部分限制 |
| **Gustafson定律** | $S = N - (1-P)(N-1)$ | 固定执行时间，问题规模可扩展 |
| **Sun-Ni定律** | $S = \frac{N}{1+(N-1)W_1/W_G}$ | 内存受限的加速比模型 |

其中：P为可并行比例，N为处理器数量

#### 2. 并行算法设计策略

- **域分解（Domain Decomposition）**：将数据划分为多个子域，每个处理器处理一个子域
- **功能分解（Functional Decomposition）**：将任务按功能划分为多个子任务
- **区别**：域分解关注数据划分，功能分解关注任务划分

#### 3. PCAM设计方法学

- **P（Partitioning）划分**：将问题分解为小任务
- **C（Communication）通信**：确定任务间的数据交换
- **A（Agglomeration）聚合**：合并小任务以提高性能
- **M（Mapping）映射**：将任务分配到处理器

### 三、计算题型

**典型计算场景：**

#### 场景1：给定并行化比例求加速比

```
例：串行程序94%时间在可并行化函数中
   - 20个处理器的加速比 = ?
   - 最大加速比 = ?

解：S = 1 / ((1-0.94) + 0.94/20) = 1 / (0.06 + 0.047) ≈ 9.35
   理论最大加速比 = 1 / 0.06 ≈ 16.67
```

#### 场景2：给定目标加速比求处理器数

```
例：8%时间在I/O函数中，求加速比10需要多少处理器
   - 使用Amdahl定律反推
```

**考察要点：**
- Amdahl定律的灵活应用
- 理解串行部分对加速比的瓶颈作用
- I/O等不可并行化部分的处理

### 四、编程实现类

**MPI编程考点：**

#### 1. MPI组通信接口

| 函数 | 功能 | 应用场景 |
|------|------|----------|
| `MPI_Bcast` | 广播 | 一对多数据分发 |
| `MPI_Reduce` | 归约 | 多对一数据聚合 |
| `MPI_Scatter` | 散射 | 数据分发到各进程 |
| `MPI_Gather` | 收集 | 数据汇总到根进程 |
| `MPI_Allgather` | 全收集 | 所有进程收集全部数据 |
| `MPI_Allreduce` | 全归约 | 所有进程获得归约结果 |

#### 2. 经典并行算法

- 理解树形归约过程

**MPI求立方和：**
```
f(n) = 1³ + 2³ + ... + n³
```
- 使用MPI并行计算
- 进程间数据分配与结果汇总

**Inverted Index算法：**

### 易错点提醒

⚠️ **计算题：**
- 注意区分"可并行化比例"和"串行比例"
- Amdahl定律中分母是 `(1-P) + P/N`，不要写反
- 最大加速比是 `1/(1-P)`，不是无穷大

⚠️ **编程题：**
- MPI函数参数顺序容易混淆
- 前缀和算法的边界条件处理
- MapReduce的中间结果处理

⚠️ **概念题：**
- NUMA和UMA的本质区别（访问延迟是否均匀）
- 共享内存vs分布式内存的编程模型差异
- OpenMP是共享内存，MPI是消息传递
