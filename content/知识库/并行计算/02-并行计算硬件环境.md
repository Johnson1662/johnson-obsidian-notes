## PRAM模型

### 什么是PRAM
**PRAM（Parallel Random Access Machine）**：并行随机访问机器，是并行计算的理论模型。

### PRAM工作流程
1. **读取阶段（Read phase）**：每个处理器同时从共享内存读取数据到本地寄存器
2. **计算阶段（Compute phase）**：每个处理器执行计算，数据存储在本地寄存器
3. **写入阶段（Write phase）**：每个处理器同时将数据写入共享内存（可能有冲突）

![PRAM模型](/mnt/d/学习/专业课/并行计算/PPT/md/images/69fca21494edd396e7be52326f5be700658c19467d8ce6e0c881bd38eb73621c.jpg)

### PRAM衍生模型
根据读写权限不同，PRAM分为四种模型：

| 模型 | 读权限 | 写权限 | 说明 |
|------|--------|--------|------|
| **EREW** | 排他读 | 排他写 | 最严格，不能并发读写 |
| **CREW** | 并发读 | 排他写 | 可以并发读，但不能并发写 |
| **ERCW** | 排他读 | 并发写 | 不能并发读，但可以并发写 |
| **CRCW** | 并发读 | 并发写 | 最宽松，可以并发读写 |

**实际应用**：CRCW模型更实际，但需要处理并发写冲突。

### 基于PRAM的算法设计

#### 1. 前缀求和
**问题**：计算数组的前缀和
```c
for (i = 1; i < n; i++)
    A[i] = A[i] + A[i-1];
```

**并行算法**：
- 外循环：log(n)次（向上取整）
- 内循环：从第2ⁱ个数开始，每个数加上前面距离为2ⁱ的数

![前缀求和算法](/mnt/d/学习/专业课/并行计算/PPT/md/images/5299d01d619d4a6a097e6226e556deb25a3be87a788f741b8e5c8789e81d2a64.jpg)

#### 2. 数组压缩
**问题**：从数组中提取满足条件的元素
**方法**：
1. 使用前缀和确定每个元素在新数组中的位置
2. 根据位置信息将元素复制到新数组

![数组压缩算法](/mnt/d/学习/专业课/并行计算/PPT/md/images/1f2c0861a0d1fe74c5780be849c1a7c1c3076a6bbf34209c93757d3a5f7de020.jpg)

## 处理器类型

### Flynn分类法
根据指令流和数据流的不同，计算机系统分为四类：

| 类型 | 指令流 | 数据流 | 说明 | 例子 |
|------|--------|--------|------|------|
| **SISD** | 单 | 单 | 传统单处理器 | 早期计算机 |
| **SIMD** | 单 | 多 | 单指令多数据 | GPU、向量处理器 |
| **MISD** | 多 | 单 | 多指令单数据 | 容错系统（少见） |
| **MIMD** | 多 | 多 | 多指令多数据 | 多核处理器、集群 |

![Flynn分类法](/mnt/d/学习/专业课/并行计算/PPT/md/images/6ea939752b5123875fd4a53585a60268c0b4118c05ef24fba2aa21b2058157a6.jpg)

### SIMD指令集

#### X86 SSE/AVX指令集
- **SSE**：128位向量寄存器，可同时处理4个单精度浮点数
- **AVX**：256位向量寄存器，可同时处理8个单精度浮点数
- **AVX-512**：512位向量寄存器，可同时处理16个单精度浮点数

**示例代码**：
```c
// AVX2示例
__m256 a, b, c; // 声明AVX寄存器
c = _mm256_add_ps(a, b); // c[0:8] = a[0:8] + b[0:8]
```

#### 向量内积计算
**常规实现**：
```c
float vectorDOT(uint32_t len, const float* a, const float* b) {
    double sum = 0;
    for (uint32_t i = 0; i < len; i++)
        sum += a[i] * b[i];
    return (float)sum;
}
```

**SSE实现**：
```c
// 使用_mm_dp_ps指令计算点乘
__m128 A = _mm_load_ps(a + i);
__m128 B = _mm_load_ps(b + i);
__m128 C = _mm_dp_ps(A, B, 0xf1);
sum += C[0];
```

### AoS与SoA数据布局

#### AoS（Array of Structure）
```c
// 结构体数组
struct Point { float x, y, z; };
Point points[n];
```

#### SoA（Structure of Array）
```c
// 数组结构体
struct Points {
    float x[n];
    float y[n];
    float z[n];
};
```

**SIMD优化**：SoA更适合SIMD处理，因为相同属性的数据连续存储。

### 多核处理器

#### 摩尔定律的挑战
- **功率墙（Power Wall）**：功耗增长过快，散热困难
- **内存墙（Memory Wall）**：内存速度跟不上处理器速度
- **隐式指令级并行**：流水线技术

#### 多核时代
- 多个处理核并行工作
- CPU时钟频率基本不变
- 计算机硬件不会更快，但会更"宽"

**双核技术 vs 超线程**：
- **双核**：真正双处理器，不发生资源冲突
- **超线程**：逻辑上双处理器，共享执行资源

![多核处理器](/mnt/d/学习/专业课/并行计算/PPT/md/images/5c650d5745607f9dab9f62bd940358f9241f429c0d42127f01e59da9df537884.jpg)

### GPU（图形处理器）

#### GPU设计哲学
- 将更多元件用于数据处理，而非控制和存储
- 适合大规模数据并行处理

![GPU与CPU对比](/mnt/d/学习/专业课/并行计算/PPT/md/images/6a2e06ba7a777729094c1710df9a0485c3eebeadf97b21cc3240c5f0c44b6949.jpg)

#### GPU编程模型
- **SPMD**（单程序多数据）模式
- 数据并行处理

#### NVIDIA CUDA
- 统一计算设备架构
- CPU + GPU协同编程

### 其他处理器类型

#### APU（加速处理器）
- 集成CPU和GPU核心
- 高性能串行和并行处理

#### MIC（Intel Phi）
- 57个核心
- 28.5MB缓存
- 1.1GHz主频
- 8GB内存

## 互连网络

### 静态互连网络
处理单元间有固定连接，程序执行期间连接保持不变。

#### 1. 一维线性阵列
- 最简单、最基本的互连方式
- 每个节点只与左、右近邻相连
- 内节点度为2，直径为N-1

#### 2. 二维网孔（2-D Mesh）
- 每个节点与上、下、左、右近邻相连
- 边界节点除外

![二维网孔](/mnt/d/学习/专业课/并行计算/PPT/md/images/9cf91bc79f8e2156845b0d7d1f92b8d5676c783637d8d9fbada3ba7570b46bc8.jpg)

#### 3. 二叉树
- 除根、叶节点外，每个内节点与父节点和两个子节点相连
- 胖树：节点间通路自叶向根逐渐变宽

#### 4. 超立方
- 高维立方体结构
- 节点度与维度相关

### 动态互连网络
用交换开关构成，可动态改变连接组态。

#### 1. 总线
- 所有设备共享同一通信线路
- 简单但易成为瓶颈

#### 2. 交叉开关（Crossbar）
- 非阻塞网络
- 任意输入输出可建立连接

![交叉开关](/mnt/d/学习/专业课/并行计算/PPT/md/images/2550a3de39447bf18bf91fa38a1b09e5978b2c9f283634790b3dbc5009513e83.jpg)

#### 3. 多级互连网络
- 单级交叉开关级联
- Omega网络等

## 内存访问模式

### 共享存储访问
#### UMA（均匀存储访问）
- 每个处理器等同地访问统一存储空间
- 访问时间相同

#### NUMA（非均匀存储访问）
- 存储全局统一编址
- 访问本地存储比远程存储快

![NUMA架构](/mnt/d/学习/专业课/并行计算/PPT/md/images/5396119b48c102a7b8d67dd6e7c7b678acf6a39a9ef629a8dfc8befb1f16a2a1.jpg)

### 分布式存储访问
- 每个物理节点有私有存储空间
- 通过高速网络连接
- 数据交换通过消息传递实现

![分布式存储](/mnt/d/学习/专业课/并行计算/PPT/md/images/9547034f86fa5c4170bb1c8eff4fd66776ce80638057a5c5bbd55a549ee57b38.jpg)

## 并行计算系统体系结构

### PVP（并行向量处理器）
- 功能强大的定制向量处理器
- 定制高带宽交叉开关
- 通常不使用高速缓存
- 例：银河I、NEC地球模拟器、GPU

### SMP（对称多处理器）
- 多个处理器通过总线或交叉开关连接到共享存储器
- 每个处理器等同地访问共享存储器、I/O设备
- 扩展性有限
- 例：胖节点服务器、多核CPU

### MPP（大规模并行处理器）
- 处理节点采用商品微处理器
- 物理上分布式存储器
- 高通信带宽和低延迟的互连网络
- 能扩展至成千上万处理器
- 例：天河、K-Computer、Cray XT5、BlueGene

![天河二号](/mnt/d/学习/专业课/并行计算/PPT/md/images/55f77315d067d01bf1a7c15f85ae90e4d7bf0751b76716bd02fb653f422d64c8.jpg)

### 集群（Cluster）
- 高速网络连接的高性能工作站或PC机
- 像统一整合资源一样工作
- **优点**：
  - 投资风险小
  - 系统结构灵活
  - 性能/价格比高
  - 可扩展性好
- **问题**：
  - 通信性能
  - 并行编程环境

![集群架构](/mnt/d/学习/专业课/并行计算/PPT/md/images/200034d7d703b9034a377b9f764fdf3a77945c1e1a7cd17bbb01682a52aa729f.jpg)

## 重要概念总结

### 1. PRAM模型
- **理论模型**，帮助理解并行算法
- **读写冲突**是关键问题
- **EREW、CREW、CRCW**是不同变种

### 2. SIMD vs MIMD
- **SIMD**：适合数据并行，如图像处理
- **MIMD**：适合任务并行，如多线程程序

### 3. 互连网络
- **静态**：固定连接，适合特定算法
- **动态**：可重构，灵活性高

### 4. 内存架构
- **共享内存**：编程简单，但扩展性有限
- **分布式内存**：扩展性好，但编程复杂

### 5. 系统结构选择
- **SMP**：适合中小规模并行
- **MPP/Cluster**：适合大规模并行
- **GPU**：适合数据密集型并行

## 实际应用建议

1. **理解硬件特性**：不同硬件适合不同并行模式
2. **选择合适的互连**：根据通信需求选择网络拓扑
3. **优化内存访问**：减少缓存失效，提高局部性
4. **考虑扩展性**：为未来需求预留扩展空间
