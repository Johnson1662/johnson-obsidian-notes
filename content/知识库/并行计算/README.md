## 📖 推荐复习顺序

### 第一轮：概念理解（2小时）
1. 阅读 `01-基础`，理解基本概念
2. 阅读 `03-OpenMP`，理解共享内存编程
3. 阅读 `04-MPI`，理解消息传递编程

### 第二轮：重点突破（2小时）
1. **精读** `02-性能`，掌握Amdahl定律计算
2. **精读** `04-MPI`，掌握组通信函数
3. **精读** `05-算法`，掌握PCAM和MapReduce

### 第三轮：真题演练（1小时）
1. 阅读 `试题考点分析报告.md`
2. 对照真题查漏补缺
3. 准备论述题素材

## 📊 分值预估

| 题型 | 预估分值 | 得分策略 |
|------|----------|----------|
| 名词解释 | 15-20分 | 背诵关键词，不丢分 |
| 简答题 | 20-25分 | 理解要点，分点作答 |
| 计算题 | 20-25分 | **必拿分**，公式要熟 |
| 编程题 | 15-20分 | MPI/MapReduce必须掌握 |
| 论述题 | 10-15分 | 有案例、有数据、有层次 |

**预估总分：100分**

---

## 💡 考试技巧

1. **名词解释**：先写定义，再写特点或例子
2. **简答题**：分点作答，每点一行
3. **计算题**：写出公式，代入数值，步骤清晰
4. **编程题**：写出框架，注释关键步骤
5. **论述题**：200字以上，有具体案例，有数据支撑
