# 并行计算硬件环境

## PRAM模型

### Parallel Random Access Machine

PRAM（并行随机存取机器）是理论并行计算模型：
- **Read phase**：每个处理器同时从共享内存读取数据到寄存器
- **Compute phase**：每个处理器执行计算，结果存本地寄存器
- **Write phase**：每个处理器同时写数据回共享内存（潜在写冲突）

### PRAM衍生模型

| 组合 | 说明 |
|------|------|
| EREW | 互斥读、互斥写（最严格） |
| CREW | 并发读、互斥写 |
| CRCW | 并发读、并发写（最实际，但需处理写冲突） |

> 并发写策略：任意写、优先级写、归约写（如求和时所有处理器写入同一位置，自动求和）

### 基于PRAM的并行算法设计

#### 前缀求和（Prefix Sum）
```
for (i = 1; i < n; i++)
    A[i] = A[i] + A[i-1]
```
- 使用 `do_in_parallel` 并行化：每个 `i` 由不同处理器执行
- 需 $\lceil \log n \rceil$ 轮，每轮间隔加倍

#### 数组压缩
1. 标记需要保留的元素（如非零元素）
2. 并行前缀求和得到压缩后位置
3. 按新位置搬移元素

## 处理器架构

### Flynn分类

| 类型 | 说明 |
|------|------|
| SISD | 单指令流、单数据流（传统串行） |
| SIMD | 单指令流、多数据流（向量机、GPU） |
| MISD | 多指令流、单数据流（极少使用） |
| MIMD | 多指令流、多数据流（多核CPU、集群） |

### SIMD指令集

Intel对X86体系的SIMD扩展：

| 指令集 | 年份 | 寄存器宽度 | 说明 |
|---------|------|------------|------|
| SSE | 1999 | 128-bit (XMM) | 支持4个单精度浮点 |
| AVX | 2011 | 256-bit (YMM) | 支持8个单精度或4个双精度 |
| AVX2 | 2013 | 256-bit (YMM) | 增加整数SIMD支持 |
| AVX-512 | 2016 | 512-bit (ZMM) | 支持16个单精度浮点 |

#### 示例：向量内积（AVX）
```c
#include <x86intrin.h>
float vector_dot(uint32_t len, const float* a, const float* b) {
    double sum = 0;
    uint32_t i = 0;
    uint32_t end = len & (~7);  // 8的倍数
    for (; i < end; i += 8) {
        __m256 tmp = _mm256_dp_ps(_mm256_load_ps(a+i), _mm256_load_ps(b+i), 0xf1);
        sum += tmp[0] + tmp[4];
    }
    // 处理尾部
    end = len & (~3);
    for (; i < end; i += 4) {
        __m128 c = _mm_dp_ps(_mm_load_ps(a+i), _mm_load_ps(b+i), 0xf1);
        sum += c[0];
    }
    for (; i < len; i++) sum += a[i] * b[i];
    return (float)sum;
}
```

### AoS vs SoA

| 结构 | 说明 | SIMD适用 |
|--------|------|---------|
| AoS（Array of Structures） | `float x[3*n], y[3*n], z[3*n]` | 不友好，数据不连续 |
| SoA（Structure of Arrays） | `struct { float x[n], y[n], z[n]; }` | 友好，向量化方便 |

### 摩尔定律的终结

- **Power Wall**：主频提升遇瓶颈，CPU主频基本停滞（Pentium 4达3.8GHz后不再大幅提升）
- **Memory Wall**：缓存占芯片面积>70%，内存带宽提升远落后于处理器
- **多核时代**：不再追求更高主频，转向更多核心（"更宽"而非"更快"）

### 多核 vs 超线程

| 技术 | 说明 | 性能提升 |
|------|------|---------|
| 双核 | 两个独立物理核心，无资源冲突 | 约等于2倍单核（浮点任务） |
| 超线程（HT） | 单个核心模拟两个逻辑线程，共享FPU等 | 约1/3额外提升 |

## GPU: Graphics Processing Unit

### GPU设计哲学
- 将更多晶体管用于数据处理，而非控制和存储
- 适合大规模数据并行（SIMT: Single Instruction, Multiple Threads）

| 对比项 | CPU | GPU |
|--------|-----|-----|
| 设计目标 | 低延迟、复杂逻辑 | 高吞吐、简单计算 |
| 缓存 | 大（MB级） | 小（KB级） |
| 控制逻辑 | 复杂（分支预测、乱序执行） | 简单（大量重复线程） |
| 计算单元 | 少（几到几十） | 多（数千个） |

### GPU编程：CUDA
- NVIDIA于2006年推出CUDA
- 编程模型：SPMD（单程序多数据）
- 支持C/C++/Fortran，编译器：`nvcc`

### 其他加速处理器

| 类型 | 代表产品 | 特点 |
|------|---------|------|
| APU | AMD APU | CPU+GPU集成，每瓦性能优化 |
| MIC | Intel Xeon Phi | 57核、1.1GHz、8GB内存、12通道 |
| FPGA | Xilinx/Altera | 半定制，可重构逻辑，能效比高 |
| ASIC | DianNao（神经网络芯片） | 全定制，最优能效，但不可更改 |
| NPU | Google TPU | 神经网络专用，非冯·诺伊曼结构 |

#### CPU/GPU/FPGA/ASIC 对比

| 平台 | 架构特点 | 最高性能 | 功耗 | 能效比 |
|------|---------|---------|------|---------|
| CPU | 70%晶体管用于缓存，适合通用计算 | 1.33 TFLOPS | 145W | 9 GFLOPS/W |
| GPU | 大部分晶体管用于计算单元 | 8.74 TFLOPS | 300W | 29 GFLOPS/W |
| FPGA | 可编程逻辑，接近底层IO | 1.8 TFLOPS | 30W | 60 GFLOPS/W |
| ASIC | 按算法全定制，无冗余 | 452 GOPS | 485mW | 932 GFLOPS/W |

## 互连网络

### 静态互连网络

| 类型 | 说明 | 直径 | 对剖宽度 |
|------|------|------|---------|
| 一维线性阵列 | 每节点连左右近邻，首尾可连成环 | N-1 | 1 |
| 二维网孔（2-D Mesh） | 每节点连上下左右近邻（边界除外） | $2\sqrt{N}$ | $\sqrt{N}$ |
| 二叉树 | 每节点连父节点+两个子节点 | $2\log N$ | 1（根瓶颈） |
| 胖树（Fat Tree） | 通路自叶向根逐渐变宽 | $\log N$ | 高 |
| 超立方 | $d$维，每节点 $d$个近邻 | $d=\log N$ | $N/2$ |

### 动态互连网络

| 类型 | 说明 |
|------|------|
| 总线 | 所有节点共享一条总线，可扩展差 |
| 交叉开关（Crossbar） | 任意输入输出全连接，无阻塞，但成本高 |
| 多级互连网络 | 单级交叉开关级联，如Omega网络 |

## 内存访问模式

| 模型            | 说明                     |
| ------------- | ---------------------- |
| UMA（均匀存储访问）   | 所有处理器等同访问统一地址空间，速度相同   |
| NUMA（非均匀存储访问） | 全局统一编址，本地存储访问快于远程访问    |
| 分布式存储         | 每个节点有私有存储空间，通过消息传递交换数据 |

## 并行计算系统体系结构

| 类型 | 说明 | 示例 |
|------|------|------|
| PVP（并行向量处理机） | 少量强大向量处理器，使用向量寄存器和指令缓存 | 银河I、GPU |
| SMP（对称多处理机） | 多处理器通过总线/交换开关连共享存储器，扩展性有限 | 胖节点服务器、多核CPU |
| MPP（大规模并行处理机） | 商品微处理器+分布式存储+定制高速网络，可扩展至数万处理器 | 天河、K-Computer、BlueGene |
| 集群（Cluster） | 工作站/PC通过商用网络连接，性价比高 | 天河1A、天河2号 |

### 天河2号逻辑结构
- 16000个运算节点
- 每节点：2× Xeon E5 12核CPU + 3× Xeon Phi协处理器
- 共312万计算核心

### 多层次混合架构
- 节点内：OpenMP或多线程 + （可选）GPU加速
- 节点间：MPI消息传递
- 物理节点私有内存，跨节点通过互联网络通信
