# 多线程并行程序设计

## 线程与进程的区别

| 对比项 | 进程（Process） | 线程（Thread） |
|--------|---------------|---------------|
| 定义 | 资源分配的实体 | 被调度执行的基本单元 |
| 调度 | 进程是资源拥有者，线程是调度单位 | 线程切换不涉及资源切换 |
| 并发性 | 进程间可并发 | 进程内多线程也可并发 |
| 拥有资源 | 拥有系统资源（内存、文件等） | 仅拥有栈、寄存器等必要资源 |
| 系统开销 | 创建/撤销/切换开销大 | 开销小，可高效并发 |

> 例：未引入线程时，文件服务进程被封锁则无法服务；引入线程后，一个线程等待时其他线程可继续服务，显著提高吞吐量。

### 线程层次

- **用户级线程**：通过线程库在用户层实现，不依赖系统调用
- **核心级线程**：由操作系统直接支持，线程创建/撤销/切换由内核实现
- **硬件线程**：线程在硬件执行资源上的表现形式
- 单个线程通常包含三个层次：用户级 → 核心级 → 硬件线程

### 线程生命周期

```
New → Ready ⇄ Running → Terminated
                ↓
              Blocked (等待I/O/锁等）
```

### 线程池

- 维护多个线程，等待调度器分配可并发执行的任务
- 避免频繁创建/销毁线程的开销
- 线程数应取决于可用处理器、内存、网络sockets等数量

## PThread 多线程

### POSIX Thread API

PThread（Portable Operating System Interface Threads）是基于UNIX的标准线程API，提供跨平台可移植性。

#### 主要操作函数

| POSIX函数          | 描述             |
| ---------------- | -------------- |
| `pthread_create` | 创建一个线程         |
| `pthread_join`   | 等待一个线程结束       |
| `pthread_self`   | 获取自己的线程ID      |
| `pthread_equal`  | 测试两个线程ID是否相等   |
| `pthread_exit`   | 退出线程（不退出进程）    |
| `pthread_cancel` | 终止另一个线程        |
| `pthread_detach` | 分离线程，退出时资源自动回收 |

#### 创建线程：`pthread_create`

```c
int pthread_create(
    pthread_t *tid,        // 返回的线程ID
    const pthread_attr_t *attr, // 线程属性（NULL为默认）
    void *(*start_routine)(void *), // 线程执行函数
    void *arg              // 传递给函数的参数
);
```
- 返回0表示成功，否则返回错误码
- 可通过结构体传递多个参数给start_routine

#### 等待线程：`pthread_join`

```c
int pthread_join(
    pthread_t tid,    // 要等待的线程ID
    void **status     // 线程退出状态
);
```
- 成功返回0，否则返回错误码
- 被join的线程不再存在，其ID无效

#### 线程退出：`pthread_exit`

```c
void pthread_exit(void *status);  // 线程退出状态
```
- 线程通过return或pthread_exit退出
- 返回的状态可被其他线程通过pthread_join获取

#### 取消线程：`pthread_cancel`

```c
int pthread_cancel(pthread_t thread);  // 要取消的目标线程ID
```
- 目标线程的取消状态决定响应方式：
  - `PTHREAD_CANCEL_ENABLE`：接受取消请求（默认）
  - `PTHREAD_CANCEL_DISABLE`：取消请求被挂起

#### 分离线程：`pthread_detach`

```c
int pthread_detach(pthread_t thread);
```
- 分离后线程退出时资源自动回收
- 错误码：`EINVALID`（非可分离线程）、`ESRCH`（线程不存在）

### PThread 示例：积分法求π

#### 串行代码
```c
double factor = 1.0, sum = 0.0;
for (int i = 0; i < n; i++, factor = -factor) {
    sum += factor / (2*i + 1);
}
pi = 4.0 * sum;
```

#### 并行版本（多线程）
```c
#include <pthread.h>

void* Thread_sum(void* rank) {
    long my_rank = (long) rank;
    double factor, my_sum = 0.0;
    long long i;
    long long my_n = n / thread_count;
    long long my_first_i = my_n * my_rank;
    long long my_last_i = my_first_i + my_n;

    if (my_first_i % 2 == 0) factor = 1.0;
    else factor = -1.0;

    for (i = my_first_i; i < my_last_i; i++, factor = -factor) {
        my_sum += factor / (2*i + 1);
    }

    // 使用互斥锁保护共享变量sum
    pthread_mutex_lock(&mutex);
    sum += my_sum;
    pthread_mutex_unlock(&mutex);
    return NULL;
}
```

## 缓存一致性与竞态条件

### 缓存一致性（Cache Coherence）
在层次存储系统中，保证高速缓存与主存中数据相同的机制。
- 多核/多处理器共享数据时，各缓存可能持有不同版本
- 硬件通过缓存一致性协议（如MESI）自动维护

### 竞态条件（Race Condition）
当多个线程同时访问共享内存，且最终结果取决于线程执行顺序时，称为竞态条件。

#### 示例：银行账户
```c
shared double balance;

// 存款线程
balance = balance + amount;

// 取款线程
balance = balance - amount;
```
汇编层面：load → add/sub → store，若两个线程交错执行，可能导致结果错误。

### 临界区（Critical Section）
- 访问共享数据的代码段，任意时刻至多一个线程可执行
- 若线程A在临界区内，线程B必须等待
- 进入区 → 临界区 → 退出区

### 互斥锁（Mutex）
互斥锁（Mutual EXclusion）是实现线程同步的基本方法：
- 线程访问共享资源前必须先获得锁
- 锁未被任何线程持有时才能被获取
- 持有锁的线程退出临界区时释放锁

#### 不加锁的问题
```c
// 两个线程可能同时进入临界区，导致输出交错
print("A Hello one");
print("A Hello two");
```

#### 加锁后的正确行为
```c
void someMethod() {
    mutex.lock();
    print("Thread: Hello one");
    print("Thread: Hello two");
    mutex.unlock();
}
// 输出：要么A完整输出，要么B完整输出
```

#### 多个锁与死锁
```c
// 线程1
get(lock1);          // 获得锁1
<critical section 1>;
get(lock2);          // 等待锁2（被线程2持有）
<critical section 2>;
release(lock2);
release(lock1);

// 线程2
get(lock2);          // 获得锁2
<critical section 2>;
get(lock1);          // 等待锁1（被线程1持有）→ 死锁！
<critical section 1>;
release(lock1);
release(lock2);
```
> 避免死锁：按相同顺序获取锁，或使用`pthread_mutex_trylock()`。

## 条件变量（Condition Variable）

条件变量用于线程间通知共享数据状态的变化。

### 主要操作

| 函数 | 说明 |
|------|------|
| `pthread_cond_signal` | 唤醒一个在该条件变量上等待的线程 |
| `pthread_cond_broadcast` | 唤醒所有在该条件变量上等待的线程 |
| `pthread_cond_wait` | 释放互斥锁并等待条件变量触发 |

### `pthread_cond_wait` 行为
1. 自动释放互斥锁（如同执行了`pthread_mutex_unlock`）
2. 线程挂起，不占用CPU，直到条件变量被触发
3. 返回前自动重新获得互斥锁（如同执行了`pthread_mutex_lock`）

### 示例
```c
#include <pthread.h>

pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;
pthread_cond_t cond = PTHREAD_COND_INITIALIZER;
int i = 1;

// 线程1：生产数据
void* thread1(void* junk) {
    for (i = 1; i <= 9; i++) {
        pthread_mutex_lock(&mutex);
        if (i % 3 == 0)
            pthread_cond_signal(&cond);  // 通知线程2
        else
            printf("thread1: %d\n", i);
        pthread_mutex_unlock(&mutex);
    }
    return NULL;
}

// 线程2：消费数据
void* thread2(void* junk) {
    while (i < 9) {
        pthread_mutex_lock(&mutex);
        if (i % 3 != 0)
            pthread_cond_wait(&cond, &mutex);  // 等待通知
        printf("thread2: %d\n", i);
        pthread_mutex_unlock(&mutex);
    }
    return NULL;
}
```
输出：`thread1:1,2` → `thread2:3` → `thread1:4,5` → `thread2:6` ...

## Java 多线程

### 创建多线程的方法

#### 方法1：继承Thread类
```java
class UserThread extends Thread {
    int sleepTime;
    public UserThread(String id) { super(id); }
    public void run() {
        sleepTime = (int)(Math.random() * 1000);
        System.out.println("线程名: " + getName() + ", 睡眠: " + sleepTime + "毫秒");
    }
}

// 使用
UserThread t1 = new UserThread("NO1");
UserThread t2 = new UserThread("NO2");
t1.start(); t2.start();
```

#### 方法2：实现Runnable接口（推荐）
```java
class UserMultThread implements Runnable {
    int num;
    UserMultThread(int n) { num = n; }
    public void run() {
        for (int i = 0; i < 3; i++)
            System.out.println("运行线程：" + num);
    }
}

// 使用
Thread mt1 = new Thread(new UserMultThread(1));
Thread mt2 = new Thread(new UserMultThread(2));
mt1.start(); mt2.start();
mt1.join(); mt2.join();  // 等待线程结束
```

### Java线程调度
- 调度程序选择就绪状态中优先级最高的线程
- 多个线程优先级相同时，轮流调度

### 同步方法

Java通过`sychronized`关键字实现同步：

#### 锁定对象
```java
sychronized (objRef) {
    // 需要同步执行的语句体
}
```

#### 锁定方法
```java
sychronized void play(int n) {
    // 方法体
}
```
> 注意：`run()`方法不能加锁，否则无法避免冲突。

## 并行算法实例：统计数字3的个数

### 问题分析
- 数组规模50M，随机分布30%的数值3
- 线程数4，每个线程处理12.5M个元素

### 算法1：直接共享变量（错误）
```c
int count = 0;  // 共享变量，无保护
void count3s_thread(int id) {
    for (i = start; i < start + len_per_thread; i++)
        if (array[i] == 3) count++;  // 竞态条件！
}
```
> 多个线程同时写`count`，结果不正确。

### 算法2：加互斥锁（正确但慢）
```c
mutex m;
void count3s_thread(int id) {
    for (i = start; i < start + len_per_thread; i++) {
        if (array[i] == 3) {
            mutex_lock(m);
            count++;
            mutex_unlock(m);
        }
    }
}
```
> 每次比较都要加锁，锁竞争严重，性能差。

### 算法3：私有计数+归约（改进）
```c
int private_count[MaxThreads];  // 每线程私有计数
mutex m;
void count3s_thread(int id) {
    for (i = start; i < start + len_per_thread; i++)
        if (array[i] == 3) private_count[id]++;
    // 所有线程计算完后，再归约到共享变量
    mutex_lock(m);
    count += private_count[id];
    mutex_unlock(m);
}
```
> 大幅减少锁竞争，性能显著提升。

### 算法4：避免伪共享（False Sharing）
```c
struct padded_int {
    int value;
    char padding[60];  // 填充使每个元素独占一个cache行（64B）
} private_count[MaxThreads];

void count3s_thread(int id) {
    for (i = start; i < start + len_per_thread; i++)
        if (array[i] == 3) private_count[id].value++;
    mutex_lock(m);
    count += private_count[id].value;
    mutex_unlock(m);
}
```
> Cache行大小为64B，通过填充确保每个线程的私有计数在不同cache行，避免伪共享导致的性能下降。

### 性能对比

| 线程数 | Busy-Waiting | Mutex |
|---------|--------------|-------|
| 1 | 2.90s | 2.90s |
| 2 | 1.45s | 1.45s |
| 4 | 0.73s | 0.73s |
| 8 | 0.38s | 0.38s |
| 16 | 0.50s | 0.38s |
| 32 | 0.80s | 0.40s |
| 64 | 3.56s | 0.38s |

> Busy-waiting在低线程数时尚可，高线程数时因自旋等待导致性能急剧下降；Mutex则保持稳定。

## 计算π：Busy-Waiting vs Mutex

### Busy-Waiting方法
```c
void* Thread_sum(void* rank) {
    long my_rank = (long) rank;
    double factor, my_sum = 0.0;
    // ... 计算每个线程的部分和存入my_sum
    while (flag != my_rank);  // 自旋等待
    sum += my_sum;
    flag = (flag + 1) % thread_count;
    return NULL;
}
```
> 自旋等待浪费CPU周期，线程数多时严重影响性能。

### Mutex方法
```c
void* Thread_sum(void* rank) {
    long my_rank = (long) rank;
    double factor, my_sum = 0.0;
    // ... 计算每个线程的部分和存入my_sum
    pthread_mutex_lock(&mutex);
    sum += my_sum;
    pthread_mutex_unlock(&mutex);
    return NULL;
}
```
> Mutex让等待线程休眠，不浪费CPU，性能稳定。
