实验二：多线程求解稀疏线性方程组
气象预报、石油勘探、核子物理等现代科学技术大多依赖计算机的计算模拟，模拟计算的
核心是求解大规模线性系统。另一方面，在人工智能领域，许多机器学习算法也需要求解线性
方程组。优化稀疏线性方程组的求解性能可以显著提升科学计算和AI 应用的效率。本实验以
共轭梯度法（Conjugate Gradient，CG）为例，研究如何使用多线程并行加速稀疏线性方程组

阵向量乘（SpMV）、向量点积和向量更新。

// 输入：n(矩阵维度), values(非零元素), row_ptr(行偏移), col_idx(列索引), b(右端向量),
max_iter(最大迭代次数), tol(收敛精度)
// 输出：x(解向量，函数内会覆盖初始值)
void cg_serial(int n, const double* values, const int* row_ptr, const int* col_idx,
const double* b, double* x, int max_iter, double tol) {
// 1. 内存分配并检查是否成功
double *r = (double*)malloc(n * sizeof(double));
double *p = (double*)malloc(n * sizeof(double));
double *Ap = (double*)malloc(n * sizeof(double));
if (r == NULL || p == NULL || Ap == NULL) {
// 内存分配失败，直接返回
return;
}
// 2. 初始化：x=0, r=b-Ax=b, p=r
for (int i = 0; i < n; i++) {
x[i] = 0.0;
r[i] = b[i];
p[i] = r[i];
}
// 3. 计算初始残差内积rho0 = r₀·r₀
double rho0 = 0.0;
for (int i = 0; i < n; i++) {
rho0 += r[i] * r[i];
}
// 初始残差范数已满足精度，直接返回
if (sqrt(rho0) < tol) {
free(r); free(p); free(Ap);
return;
}
// 4. 迭代核心逻辑
for (int iter = 0; iter < max_iter; iter++) {
// 4.1 计算Ap = A*p
spmv_csr(n, values, row_ptr, col_idx, p, Ap);
// 4.2 计算p·Ap，避免除以0
double pAp = 0.0;
for (int i = 0; i < n; i++) {
pAp += p[i] * Ap[i];
}
if (fabs(pAp) < 1e-15) {
// 分母接近0，停止迭代
break;
}
// 4.3 计算步长alpha = rho0 / (p·Ap)
double alpha = rho0 / pAp;
// 4.4 更新解x 和残差r：x = x + alpha*p; r = r - alpha*Ap
for (int i = 0; i < n; i++) {
x[i] += alpha * p[i];
r[i] -= alpha * Ap[i];
}

double rho_new = 0.0;
for (int i = 0; i < n; i++) {
rho_new += r[i] * r[i];

// 残差L2 范数

}

free(p);
free(Ap);

// 输入：n(矩阵维度), values(非零元素值), row_ptr(行偏移), col_idx(列索引), x(输入向量)
// 输出：y(输出向量，y = A*x)
void spmv_csr(int n, const double* values, const int* row_ptr, const int* col_idx,
const double* x, double* y) {
// 初始化输出向量为0
for (int i = 0; i < n; i++) {
y[i] = 0.0;
}
// CSR 格式矩阵乘向量核心逻辑
for (int i = 0; i < n; i++) {
// 遍历第i 行的所有非零元素
for (int j = row_ptr[i]; j < row_ptr[i+1]; j++) {
y[i] += values[j] * x[col_idx[j]];
}
}
}

实验三：MPI 多进程求解稀疏线性方程组
本实验针对实验二问题，采用MPI 编程模型实现CG 法的并行计算。要求将矩阵按行分
块，每个进程存储连续的行块，并实现分布式向量和全局点积的通信。

并行算法设计思路（供参考）
使用行分块：将矩阵A 的n 行均匀划分给p 个进程，每个进程存储本地的行块（CSR 格
式）、对应的右端项片段b_local 和未知数片段x_local。
向量p 和r 也采用分布式存储，每个进程只存储自己对应的片段。
稀疏矩阵向量乘Ap = A * p 需要从所有进程收集完整的p 向量？若采用分布式存储，则
Ap 的计算需要进程间的通信。简化方案：所有进程保持完整的向量p 和r（冗余存储），
这样spmv 只需本地计算（因为矩阵行分块，但列索引需要全局p 值）。这种方法通信少，
但内存浪费。本实验采用冗余向量方式，每个进程存储完整p 和r，只对矩阵分块。这样
每次迭代开始前，所有进程的p 保持一致（可通过广播实现，但初始时已一致，迭代中更
新时需保证同步）。

实验四：异构并行计算求解稀疏线性方程组
本实验针对实验二问题，采用CPU+GPU 异构并行方式加速CG 法。要求将最耗时的稀
疏矩阵向量乘（SpMV）移植到GPU 上执行。建议使用HIP 编程模型。

异构策略（供参考）
CPU 负责控制流、点积计算、向量更新等；GPU 负责SpMV。
数据在主机和设备之间传输：矩阵（values, row_ptr, col_idx）和向量p, Ap 需在设备端
分配内存，每次迭代前将p 从主机拷贝到设备，启动SpMV kernel，然后将Ap 从设备拷
贝回主机。
为了减少传输开销，可考虑将p 和Ap 始终留在设备端，但点积需要主机端访问，因此仍
需传输。优化方案：将点积也移至GPU，但本实验为简化，仅将SpMV 卸载到GPU。
