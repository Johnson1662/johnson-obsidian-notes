# 共轭梯度法（CG）数学原理详解

## 一、问题背景

### 1.1 我们要解决什么问题？

求解**线性方程组**：

$$\mathbf{A}\mathbf{x} = \mathbf{b}$$

其中：
- $\mathbf{A}$ 是 $n \times n$ 的**对称正定矩阵**（稀疏矩阵）
- $\mathbf{x}$ 是 $n$ 维未知向量（我们要求的）
- $\mathbf{b}$ 是 $n$ 维已知向量

**例子**：
```
3x₁ + 2x₂ = 8
2x₁ + 6x₂ = 10

矩阵形式：
[3  2] [x₁]   [8 ]
[2  6] [x₂] = [10]
```

### 1.2 为什么不用高斯消元法？

对于**大规模稀疏矩阵**（如 100000×100000，但大部分元素是0）：

| 方法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| 高斯消元 | $O(n^3)$ | $O(n^2)$ | 小规模稠密矩阵 |
| 共轭梯度法 | $O(kn)$ | $O(n)$ | 大规模稀疏矩阵 |

其中 $k$ 是迭代次数，通常 $k \ll n$

---

## 二、从优化问题到迭代算法

### 2.1 等价的优化问题

求解 $\mathbf{A}\mathbf{x} = \mathbf{b}$ 等价于最小化二次函数：

$$f(\mathbf{x}) = \frac{1}{2}\mathbf{x}^T\mathbf{A}\mathbf{x} - \mathbf{b}^T\mathbf{x}$$

**为什么等价？**

对 $f(\mathbf{x})$ 求导并令其为零：

$$\nabla f(\mathbf{x}) = \mathbf{A}\mathbf{x} - \mathbf{b} = 0$$

这正是原方程！

**几何意义**（2维情况）：

```
f(x₁, x₂) 是一个碗状曲面
      
      ^
      |     
      |    ╱╲
      |   ╱  ╲
      |  ╱ ★  ╲  ← 最低点就是解
      | ╱      ╲
      |╱________╲
      +----------->
      
从任意点出发，沿着下降方向走，最终到达最低点
```

---

### 2.2 梯度下降法（最简单的想法）

**思路**：沿着梯度的反方向走

```
1. 从初始点 x₀ 开始
2. 计算梯度 g = ∇f(x) = Ax - b
3. 沿着 -g 方向更新：x_{k+1} = x_k - α·g
4. 重复直到收敛
```

**问题**：收敛很慢！

```
梯度下降的路径（之字形）：
      
      起点
       ↓
       ●→
         ↘
          ●→
            ↘
             ●→
               ↘
                ● ← 目标点
                
走了很多步才到达
```

---

### 2.3 共轭梯度法（聪明的改进）

**核心思想**：不沿着梯度方向，而是沿着**共轭方向**

```
共轭梯度的路径（直达）：
      
      起点
       ↓
       ●────→ ● ← 目标点
       
只需要几步就到达！
```

**什么是共轭方向？**

两个向量 $\mathbf{p}_i$ 和 $\mathbf{p}_j$ 关于矩阵 $\mathbf{A}$ 共轭，如果：

$$\mathbf{p}_i^T \mathbf{A} \mathbf{p}_j = 0 \quad (i \neq j)$$

**性质**：沿着 $n$ 个共轭方向，最多 $n$ 步就能找到精确解！

---

## 三、共轭梯度法算法推导

### 3.1 核心思想

在每一步：
1. 选择一个搜索方向 $\mathbf{p}_k$
2. 沿着这个方向走到最优点
3. 下一个方向与之前所有方向共轭

### 3.2 算法步骤

**初始化**：
```
x₀ = 0                    （初始猜测）
r₀ = b - Ax₀ = b          （初始残差）
p₀ = r₀                   （初始搜索方向）
```

**迭代**（第 $k$ 步）：

**步骤1**：计算步长 $\alpha_k$

沿着 $\mathbf{p}_k$ 方向走多远？

$$\alpha_k = \frac{\mathbf{r}_k^T \mathbf{r}_k}{\mathbf{p}_k^T \mathbf{A} \mathbf{p}_k}$$

**推导**：
- 目标：最小化 $f(\mathbf{x}_k + \alpha \mathbf{p}_k)$
- 对 $\alpha$ 求导并令其为零
- 得到上式

**步骤2**：更新解和残差

$$\mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k \mathbf{p}_k$$

$$\mathbf{r}_{k+1} = \mathbf{r}_k - \alpha_k \mathbf{A} \mathbf{p}_k$$

**步骤3**：检查收敛

如果 $\|\mathbf{r}_{k+1}\| < \epsilon$，停止

**步骤4**：计算新的搜索方向

$$\beta_k = \frac{\mathbf{r}_{k+1}^T \mathbf{r}_{k+1}}{\mathbf{r}_k^T \mathbf{r}_k}$$

$$\mathbf{p}_{k+1} = \mathbf{r}_{k+1} + \beta_k \mathbf{p}_k$$

**推导**：
- 要求 $\mathbf{p}_{k+1}$ 与所有之前的方向共轭
- 利用残差的正交性
- 得到上式（神奇的是只需要前一个方向！）

---

### 3.3 完整算法

```
输入：A, b, ε（收敛精度）
输出：x（方程的解）

1. x = 0
2. r = b
3. p = r
4. ρ_old = r^T · r

5. for k = 0, 1, 2, ... do
6.     Ap = A · p                    ← 矩阵向量乘（最耗时）
7.     α = ρ_old / (p^T · Ap)        ← 计算步长
8.     x = x + α·p                   ← 更新解
9.     r = r - α·Ap                  ← 更新残差
10.    ρ_new = r^T · r               ← 计算残差范数
11.    if √ρ_new < ε then            ← 检查收敛
12.        break
13.    β = ρ_new / ρ_old             ← 计算方向系数
14.    p = r + β·p                   ← 更新搜索方向
15.    ρ_old = ρ_new
16. end for

17. return x
```

## 四、关键性质和定理

### 4.1 残差的正交性

**定理1**：残差向量相互正交

$$\mathbf{r}_i^T \mathbf{r}_j = 0 \quad (i \neq j)$$

**意义**：每次迭代都在一个新的方向上减小误差

### 4.2 搜索方向的共轭性

**定理2**：搜索方向关于 $\mathbf{A}$ 共轭

$$\mathbf{p}_i^T \mathbf{A} \mathbf{p}_j = 0 \quad (i \neq j)$$

**意义**：保证不会破坏之前的优化结果

### 4.3 收敛性

**定理3**：对于 $n$ 维问题，CG算法最多 $n$ 步收敛到精确解

**实际情况**：
- 对于良态矩阵，通常 $k \ll n$ 步就足够
- 收敛速度取决于矩阵的条件数

**条件数**：

$$\kappa(\mathbf{A}) = \frac{\lambda_{max}}{\lambda_{min}}$$

- $\kappa$ 越小，收敛越快
- $\kappa = 1$（单位矩阵）：1步收敛
- $\kappa$ 很大：收敛慢

## 五、为什么CG算法高效？

### 5.1 计算复杂度分析

**每次迭代的操作**：

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| $\mathbf{Ap}$ | $O(nnz)$ | 稀疏矩阵向量乘，nnz是非零元素数 |
| $\mathbf{p}^T\mathbf{Ap}$ | $O(n)$ | 向量点积 |
| $\mathbf{x} + \alpha\mathbf{p}$ | $O(n)$ | 向量加法 |
| $\mathbf{r}^T\mathbf{r}$ | $O(n)$ | 向量点积 |

**总复杂度**：$O(nnz + n) \approx O(nnz)$

对于稀疏矩阵，$nnz \ll n^2$，所以非常高效！

### 5.2 内存需求

只需要存储：
- 矩阵 $\mathbf{A}$（稀疏格式）：$O(nnz)$
- 向量 $\mathbf{x}, \mathbf{r}, \mathbf{p}, \mathbf{Ap}$：$O(n)$

**总内存**：$O(nnz + n)$

相比高斯消元的 $O(n^2)$，节省巨大！

## 六、稀疏矩阵存储（CSR格式）

### 6.1 为什么需要特殊存储？

**稠密存储**：
```
矩阵 A (5×5):
[1  0  0  2  0]
[0  3  0  0  0]
[4  0  5  0  6]
[0  0  0  7  0]
[0  8  0  0  9]

存储：25个元素（包括很多0）
```

**稀疏存储（CSR）**：
```
只存储非零元素：
values  = [1, 2, 3, 4, 5, 6, 7, 8, 9]  （9个元素）
col_idx = [0, 3, 1, 0, 2, 4, 3, 1, 4]  （列索引）
row_ptr = [0, 2, 3, 6, 7, 9]           （行起始位置）

节省空间：9 vs 25
```

### 6.2 CSR格式详解

**三个数组**：

1. **values**：所有非零元素的值
2. **col_idx**：每个非零元素的列号
3. **row_ptr**：每行的起始位置

**例子**：
```
矩阵第2行（索引从0开始）：
[4  0  5  0  6]

在CSR中：
- row_ptr[2] = 3  （第2行从values[3]开始）
- row_ptr[3] = 6  （第3行从values[6]开始）
- 所以第2行有 6-3=3 个非零元素

values[3:6]  = [4, 5, 6]
col_idx[3:6] = [0, 2, 4]

表示：A[2,0]=4, A[2,2]=5, A[2,4]=6
```

### 6.3 CSR格式的SpMV

```cpp
// y = A * x
for (int i = 0; i < n; i++) {
    double sum = 0.0;
    for (int j = row_ptr[i]; j < row_ptr[i+1]; j++) {
        sum += values[j] * x[col_idx[j]];
    }
    y[i] = sum;
}
```

**效率**：只遍历非零元素，$O(nnz)$

## 七、数值稳定性和预条件

### 7.1 数值稳定性

**问题**：浮点运算有误差

**解决**：
- 使用双精度（double）
- 设置合理的收敛精度（如 $10^{-10}$）
- 检查残差范数而不是解的变化

### 7.2 预条件技术

**问题**：条件数大时收敛慢

**解决**：预条件矩阵 $\mathbf{M}$

求解：$\mathbf{M}^{-1}\mathbf{A}\mathbf{x} = \mathbf{M}^{-1}\mathbf{b}$

**常用预条件**：
- 对角预条件：$\mathbf{M} = \text{diag}(\mathbf{A})$
- 不完全Cholesky分解
- 多重网格方法

**效果**：大幅减少迭代次数

## 八、CG算法的几何解释

### 8.1 二维情况的可视化

```
目标函数的等高线（椭圆）：

        x₂
         ^
         |
         |    ╱─╲
         |   ╱   ╲
         |  │  ★  │  ← 最优点
         |   ╲   ╱
         |    ╲─╱
         +-----------> x₁

梯度下降：之字形路径
共轭梯度：直线路径（2步到达）
```

### 8.2 Krylov子空间

CG算法在**Krylov子空间**中寻找最优解：

$$\mathcal{K}_k = \text{span}\{\mathbf{r}_0, \mathbf{A}\mathbf{r}_0, \mathbf{A}^2\mathbf{r}_0, ..., \mathbf{A}^{k-1}\mathbf{r}_0\}$$

**意义**：
- 第 $k$ 步的解 $\mathbf{x}_k$ 在 $\mathcal{K}_k$ 中
- 维度逐步增加：$\mathcal{K}_1 \subset \mathcal{K}_2 \subset ... \subset \mathcal{K}_n = \mathbb{R}^n$
- 最多 $n$ 步覆盖整个空间

## 九、实际应用中的考虑

### 9.1 收敛判据

**绝对残差**：
$$\|\mathbf{r}_k\| < \epsilon$$

**相对残差**：
$$\frac{\|\mathbf{r}_k\|}{\|\mathbf{b}\|} < \epsilon$$

**推荐**：使用相对残差（与问题规模无关）

### 9.2 最大迭代次数

设置上限防止无限循环：
```
max_iter = min(n, 10000)
```

### 9.3 初始猜测

- 通常用 $\mathbf{x}_0 = \mathbf{0}$
- 如果有更好的初始猜测，可以加速收敛

---

## 十、总结

### 10.1 CG算法的优势

✅ **高效**：$O(k \cdot nnz)$，$k \ll n$
✅ **省内存**：$O(nnz + n)$
✅ **简单**：易于实现和并行化
✅ **理论保证**：最多 $n$ 步精确收敛

### 10.2 CG算法的限制

❌ **要求对称正定**：不适用于一般矩阵
❌ **条件数敏感**：病态矩阵收敛慢
❌ **数值误差**：实际可能需要重启

### 10.3 变种算法

- **BiCG**：双共轭梯度（非对称矩阵）
- **GMRES**：广义最小残差（一般矩阵）
- **PCG**：预条件共轭梯度（加速收敛）
