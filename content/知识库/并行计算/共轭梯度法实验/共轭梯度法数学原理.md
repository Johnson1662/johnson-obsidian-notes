# 共轭梯度法（CG）数学原理

## 一、问题定义

求解线性方程组：

$$\mathbf{A}\mathbf{x} = \mathbf{b}$$

其中：

- $\mathbf{A}$ 是 $n \times n$ **对称正定矩阵**（稀疏）
- $\mathbf{x}$ 是 $n$ 维未知向量
- $\mathbf{b}$ 是 $n$ 维已知向量

**对称正定的含义**：

- 对称：$\mathbf{A}^T = \mathbf{A}$，即 $A_{ij} = A_{ji}$
- 正定：对任意非零向量 $\mathbf{v}$，有 $\mathbf{v}^T\mathbf{A}\mathbf{v} > 0$

**稀疏矩阵**：大部分元素为0。例如 $100000 \times 100000$ 的矩阵只有几百万个非零元素。

---

## 二、等价优化问题

求解 $\mathbf{A}\mathbf{x} = \mathbf{b}$ 等价于最小化二次函数：

$$f(\mathbf{x}) = \frac{1}{2}\mathbf{x}^T\mathbf{A}\mathbf{x} - \mathbf{b}^T\mathbf{x}$$

**证明等价性**：

对 $f(\mathbf{x})$ 求梯度：

$$\nabla f(\mathbf{x}) = \frac{\partial f}{\partial \mathbf{x}} = \mathbf{A}\mathbf{x} - \mathbf{b}$$

令梯度为零得到最优解：

$$\nabla f(\mathbf{x}^*) = \mathbf{A}\mathbf{x}^* - \mathbf{b} = 0 \implies \mathbf{A}\mathbf{x}^* = \mathbf{b}$$

**几何意义**：$f(\mathbf{x})$ 是一个碗状曲面，最低点就是方程的解。

---

## 三、残差向量

**定义**：残差向量 $\mathbf{r}_k$ 表示当前解 $\mathbf{x}_k$ 与真实解的差距：

$$\mathbf{r}_k = \mathbf{b} - \mathbf{A}\mathbf{x}_k$$

**性质**：

- $\mathbf{r}_k = -\nabla f(\mathbf{x}_k)$（残差是负梯度）
- 当 $\mathbf{r}_k = \mathbf{0}$ 时，$\mathbf{x}_k$ 就是精确解
- $\|\mathbf{r}_k\|$ 越小，解越接近真实值

---

## 四、共轭方向

**定义**：两个向量 $\mathbf{p}_i$ 和 $\mathbf{p}_j$ 关于矩阵 $\mathbf{A}$ **共轭**，如果：

$$\mathbf{p}_i^T \mathbf{A} \mathbf{p}_j = 0 \quad (i \neq j)$$

**理解**：

- 类似于正交（垂直），但是在 $\mathbf{A}$ 定义的内积下
- 普通正交：$\mathbf{p}_i^T \mathbf{p}_j = 0$
- $\mathbf{A}$-共轭：$\mathbf{p}_i^T \mathbf{A} \mathbf{p}_j = 0$

**核心性质**：如果有 $n$ 个 $\mathbf{A}$-共轭的方向 $\{\mathbf{p}_0, \mathbf{p}_1, ..., \mathbf{p}_{n-1}\}$，沿着这些方向依次搜索，**最多 $n$ 步就能找到精确解**。

---

## 五、算法推导

### 5.1 初始化

从零向量开始：

$$\mathbf{x}_0 = \mathbf{0}$$

$$\mathbf{r}_0 = \mathbf{b} - \mathbf{A}\mathbf{x}_0 = \mathbf{b}$$

$$\mathbf{p}_0 = \mathbf{r}_0$$

第一个搜索方向就是初始残差（负梯度方向）。

---

### 5.2 步长计算

在第 $k$ 步，沿着方向 $\mathbf{p}_k$ 搜索，需要确定步长 $\alpha_k$：

$$\mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k \mathbf{p}_k$$

**目标**：选择 $\alpha_k$ 使得 $f(\mathbf{x}_{k+1})$ 最小。

将 $\mathbf{x}_{k+1}$ 代入 $f$：

$$f(\mathbf{x}_k + \alpha \mathbf{p}_k) = \frac{1}{2}(\mathbf{x}_k + \alpha \mathbf{p}_k)^T\mathbf{A}(\mathbf{x}_k + \alpha \mathbf{p}_k) - \mathbf{b}^T(\mathbf{x}_k + \alpha \mathbf{p}_k)$$

对 $\alpha$ 求导并令其为零：

$$\frac{df}{d\alpha} = \mathbf{p}_k^T\mathbf{A}(\mathbf{x}_k + \alpha \mathbf{p}_k) - \mathbf{b}^T\mathbf{p}_k = 0$$

$$\mathbf{p}_k^T\mathbf{A}\mathbf{x}_k + \alpha \mathbf{p}_k^T\mathbf{A}\mathbf{p}_k = \mathbf{b}^T\mathbf{p}_k$$

$$\alpha = \frac{\mathbf{b}^T\mathbf{p}_k - \mathbf{p}_k^T\mathbf{A}\mathbf{x}_k}{\mathbf{p}_k^T\mathbf{A}\mathbf{p}_k}$$

注意到 $\mathbf{r}_k = \mathbf{b} - \mathbf{A}\mathbf{x}_k$，所以：

$$\mathbf{b}^T\mathbf{p}_k - \mathbf{p}_k^T\mathbf{A}\mathbf{x}_k = (\mathbf{b} - \mathbf{A}\mathbf{x}_k)^T\mathbf{p}_k = \mathbf{r}_k^T\mathbf{p}_k$$

因此：

$$\alpha_k = \frac{\mathbf{r}_k^T\mathbf{p}_k}{\mathbf{p}_k^T\mathbf{A}\mathbf{p}_k}$$

**简化**：利用残差正交性（后面证明），可以证明 $\mathbf{r}_k^T\mathbf{p}_k = \mathbf{r}_k^T\mathbf{r}_k$，所以：

$$\alpha_k = \frac{\mathbf{r}_k^T\mathbf{r}_k}{\mathbf{p}_k^T\mathbf{A}\mathbf{p}_k}$$

---

### 5.3 残差更新

更新解后，残差变为：

$$\mathbf{r}_{k+1} = \mathbf{b} - \mathbf{A}\mathbf{x}_{k+1}$$

$$= \mathbf{b} - \mathbf{A}(\mathbf{x}_k + \alpha_k \mathbf{p}_k)$$

$$= \mathbf{b} - \mathbf{A}\mathbf{x}_k - \alpha_k \mathbf{A}\mathbf{p}_k$$

$$= \mathbf{r}_k - \alpha_k \mathbf{A}\mathbf{p}_k$$

**关键**：不需要重新计算 $\mathbf{A}\mathbf{x}_{k+1}$，只需要用之前计算的 $\mathbf{A}\mathbf{p}_k$。

---

### 5.4 新搜索方向

下一个搜索方向 $\mathbf{p}_{k+1}$ 需要满足：

1. 与所有之前的方向 $\mathbf{A}$-共轭
2. 包含新的残差信息

构造方式：

$$\mathbf{p}_{k+1} = \mathbf{r}_{k+1} + \beta_k \mathbf{p}_k$$

其中 $\beta_k$ 需要保证 $\mathbf{p}_{k+1}^T \mathbf{A} \mathbf{p}_k = 0$：

$$(\mathbf{r}_{k+1} + \beta_k \mathbf{p}_k)^T \mathbf{A} \mathbf{p}_k = 0$$

$$\mathbf{r}_{k+1}^T \mathbf{A} \mathbf{p}_k + \beta_k \mathbf{p}_k^T \mathbf{A} \mathbf{p}_k = 0$$

$$\beta_k = -\frac{\mathbf{r}_{k+1}^T \mathbf{A} \mathbf{p}_k}{\mathbf{p}_k^T \mathbf{A} \mathbf{p}_k}$$

**简化**：利用 $\mathbf{r}_{k+1} = \mathbf{r}_k - \alpha_k \mathbf{A}\mathbf{p}_k$：

$$\mathbf{r}_{k+1}^T \mathbf{A} \mathbf{p}_k = (\mathbf{r}_k - \alpha_k \mathbf{A}\mathbf{p}_k)^T \mathbf{A} \mathbf{p}_k$$

$$= \mathbf{r}_k^T \mathbf{A} \mathbf{p}_k - \alpha_k (\mathbf{A}\mathbf{p}_k)^T \mathbf{A} \mathbf{p}_k$$

利用残差正交性，$\mathbf{r}_k^T \mathbf{A} \mathbf{p}_k = \alpha_k^{-1} \mathbf{r}_k^T \mathbf{r}_k$，以及 $\alpha_k = \frac{\mathbf{r}_k^T\mathbf{r}_k}{\mathbf{p}_k^T\mathbf{A}\mathbf{p}_k}$：

$$\mathbf{r}_{k+1}^T \mathbf{A} \mathbf{p}_k = \frac{\mathbf{r}_k^T\mathbf{r}_k}{\alpha_k} - \alpha_k \mathbf{p}_k^T \mathbf{A} \mathbf{p}_k$$

$$= \mathbf{p}_k^T \mathbf{A} \mathbf{p}_k - \alpha_k \mathbf{p}_k^T \mathbf{A} \mathbf{p}_k = (1-\alpha_k) \mathbf{p}_k^T \mathbf{A} \mathbf{p}_k$$

这个推导比较复杂。实际上，通过残差正交性可以直接得到：

$$\beta_k = \frac{\mathbf{r}_{k+1}^T\mathbf{r}_{k+1}}{\mathbf{r}_k^T\mathbf{r}_k}$$

---

### 5.5 完整算法

```
输入：A（对称正定矩阵），b（右端向量），ε（收敛精度）
输出：x（方程的解）

1.  x = 0                           // 初始解
2.  r = b                           // 初始残差
3.  p = r                           // 初始搜索方向
4.  ρ_old = r^T · r                 // 残差范数平方

5.  for k = 0, 1, 2, ... do
6.      Ap = A · p                  // 矩阵向量乘（最耗时的操作）
7.      α = ρ_old / (p^T · Ap)     // 计算步长
8.      x = x + α · p               // 更新解
9.      r = r - α · Ap              // 更新残差
10.     ρ_new = r^T · r             // 新残差范数平方
11.     if √ρ_new < ε then          // 检查收敛
12.         break
13.     end if
14.     β = ρ_new / ρ_old           // 计算方向系数
15.     p = r + β · p               // 更新搜索方向
16.     ρ_old = ρ_new               // 保存当前残差范数
17. end for

18. return x
```

## 六、关键性质

### 6.1 残差正交性

**定理**：CG算法产生的残差向量两两正交：

$$\mathbf{r}_i^T \mathbf{r}_j = 0 \quad \text{for } i \neq j$$

**意义**：每次迭代在一个新的独立方向上减小误差，不会重复之前的工作。

---

### 6.2 搜索方向共轭性

**定理**：CG算法产生的搜索方向关于 $\mathbf{A}$ 共轭：

$$\mathbf{p}_i^T \mathbf{A} \mathbf{p}_j = 0 \quad \text{for } i \neq j$$

**意义**：保证沿着 $\mathbf{p}_{k+1}$ 搜索时，不会破坏之前在 $\mathbf{p}_0, ..., \mathbf{p}_k$ 方向上的优化结果。

---

### 6.3 收敛性

**定理**：对于 $n$ 维问题，CG算法在精确算术下最多 $n$ 步收敛到精确解。

**实际情况**：

- 浮点运算有误差，可能需要更多步
- 对于良态矩阵（条件数小），通常 $k \ll n$ 步就足够

**条件数**：

$$\kappa(\mathbf{A}) = \frac{\lambda_{\max}(\mathbf{A})}{\lambda_{\min}(\mathbf{A})}$$

其中 $\lambda_{\max}$ 和 $\lambda_{\min}$ 是 $\mathbf{A}$ 的最大和最小特征值。

- $\kappa$ 接近1：收敛很快
- $\kappa$ 很大：收敛慢

---

## 七、稀疏矩阵存储（CSR格式）

### 7.1 为什么需要特殊存储

**问题**：对于 $n \times n$ 的稀疏矩阵，如果用二维数组存储，需要 $O(n^2)$ 空间，但大部分是0。

**解决**：只存储非零元素。

---

### 7.2 CSR（Compressed Sparse Row）格式

**三个数组**：

1. **values**：所有非零元素的值（长度 $nnz$）
2. **col_idx**：每个非零元素的列索引（长度 $nnz$）
3. **row_ptr**：每行的起始位置（长度 $n+1$）

**规则**：

- 第 $i$ 行的非零元素在 `values[row_ptr[i] : row_ptr[i+1]]`
- 对应的列索引在 `col_idx[row_ptr[i] : row_ptr[i+1]]`

**例子**：

矩阵：

```
[1  0  2]
[0  3  0]
[4  0  5]
```

CSR表示：

```
values  = [1, 2, 3, 4, 5]
col_idx = [0, 2, 1, 0, 2]
row_ptr = [0, 2, 3, 5]
```

解释：

- 第0行：`values[0:2] = [1, 2]`，列索引 `[0, 2]`，即 $A_{0,0}=1, A_{0,2}=2$
- 第1行：`values[2:3] = [3]`，列索引 `[1]`，即 $A_{1,1}=3$
- 第2行：`values[3:5] = [4, 5]`，列索引 `[0, 2]`，即 $A_{2,0}=4, A_{2,2}=5$

---

### 7.3 稀疏矩阵向量乘（SpMV）

计算 $\mathbf{y} = \mathbf{A}\mathbf{x}$：

```cpp
for (int i = 0; i < n; i++) {
    double sum = 0.0;
    for (int j = row_ptr[i]; j < row_ptr[i+1]; j++) {
        sum += values[j] * x[col_idx[j]];
    }
    y[i] = sum;
}
```

**复杂度**：$O(nnz)$，只遍历非零元素。

---

## 八、计算复杂度分析

### 8.1 每次迭代的操作

| 操作                             | 复杂度   | 说明           |
| -------------------------------- | -------- | -------------- |
| $\mathbf{Ap}$                    | $O(nnz)$ | 稀疏矩阵向量乘 |
| $\mathbf{p}^T\mathbf{Ap}$        | $O(n)$   | 向量点积       |
| $\mathbf{x} + \alpha\mathbf{p}$  | $O(n)$   | 向量加法       |
| $\mathbf{r} - \alpha\mathbf{Ap}$ | $O(n)$   | 向量减法       |
| $\mathbf{r}^T\mathbf{r}$         | $O(n)$   | 向量点积       |
| $\mathbf{r} + \beta\mathbf{p}$   | $O(n)$   | 向量加法       |

**总复杂度**：$O(nnz + n) \approx O(nnz)$（因为 $nnz \gg n$）

---

### 8.2 总体复杂度

假设迭代 $k$ 次收敛：

$$\text{总复杂度} = O(k \cdot nnz)$$

对于良态矩阵，$k \ll n$，所以远优于高斯消元的 $O(n^3)$。

---

### 8.3 空间复杂度

需要存储：

- 矩阵 $\mathbf{A}$（CSR格式）：$O(nnz)$
- 向量 $\mathbf{x}, \mathbf{r}, \mathbf{p}, \mathbf{Ap}$：$4 \times O(n)$

**总空间**：$O(nnz + n)$

---

## 九、数值稳定性

### 9.1 浮点误差

**问题**：浮点运算不精确，导致：

- 残差不完全正交
- 搜索方向不完全共轭
- 可能需要超过 $n$ 步才能收敛

**解决**：

- 使用双精度（`double`）
- 设置合理的收敛精度（如 $\epsilon = 10^{-10}$）
- 使用相对残差判断收敛：$\frac{\|\mathbf{r}_k\|}{\|\mathbf{b}\|} < \epsilon$

---

### 9.2 预条件技术

**问题**：条件数大时收敛慢。

**解决**：引入预条件矩阵 $\mathbf{M}$，求解等价问题：

$$\mathbf{M}^{-1}\mathbf{A}\mathbf{x} = \mathbf{M}^{-1}\mathbf{b}$$

**要求**：

- $\mathbf{M}$ 容易求逆
- $\mathbf{M}^{-1}\mathbf{A}$ 的条件数小于 $\mathbf{A}$

**常用预条件**：

- **对角预条件**：$\mathbf{M} = \text{diag}(\mathbf{A})$
- **不完全Cholesky分解**：$\mathbf{M} \approx \mathbf{L}\mathbf{L}^T$

**效果**：大幅减少迭代次数。

---

## 十、算法总结

### 10.1 核心思想

1. 将线性方程组转化为优化问题
2. 沿着共轭方向迭代搜索
3. 每步在当前方向上走到最优点
4. 利用残差正交性简化计算

---

### 10.2 关键公式

**步长**：
$$\alpha_k = \frac{\mathbf{r}_k^T\mathbf{r}_k}{\mathbf{p}_k^T\mathbf{A}\mathbf{p}_k}$$

**残差更新**：
$$\mathbf{r}_{k+1} = \mathbf{r}_k - \alpha_k \mathbf{A}\mathbf{p}_k$$

**方向系数**：
$$\beta_k = \frac{\mathbf{r}_{k+1}^T\mathbf{r}_{k+1}}{\mathbf{r}_k^T\mathbf{r}_k}$$

**新方向**：
$$\mathbf{p}_{k+1} = \mathbf{r}_{k+1} + \beta_k \mathbf{p}_k$$

---

### 10.3 优势

- **高效**：$O(k \cdot nnz)$，$k \ll n$
- **省内存**：$O(nnz + n)$
- **易并行**：SpMV、点积、向量加法都易并行

---

### 10.4 限制

- **要求对称正定**：不适用于一般矩阵
- **条件数敏感**：病态矩阵收敛慢
- **数值误差**：浮点运算影响收敛

---
