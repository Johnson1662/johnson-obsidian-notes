## 一、并行计算基本概念

### 1.1 什么是并行计算？

**定义**：并行计算（Parallel Computing）是指同时使用多种计算资源来解决计算问题的过程。

**核心思想**：
- 将一个大问题分解为多个小问题
- 使用多个处理器同时处理这些小问题
- 最终合并结果得到完整解答

**为什么需要并行计算？**

| 原因 | 说明 |
|------|------|
| 单处理器性能受限 | 2002年后性能提升从50%/年降至20%/年 |
| 计算需求爆炸增长 | 天气预报、人工智能、大数据等 |
| 硬件发展推动 | 多核处理器成为主流，集群广泛应用 |
| 存储/IO瓶颈 | 数据访问速度远落后于处理器速度 |

### 1.2 性能度量

**FLOPS（Floating-point Operations Per Second）**：每秒浮点运算次数

| 单位 | 数值 |
|------|------|
| K | 10³ (千) |
| M | 10⁶ (百万) |
| G | 10⁹ (十亿) |
| T | 10¹² (万亿) |
| P | 10¹⁵ (千万亿) |

**示例**：
- ENIAC (1946): 300 FLOPS
- 现代GPU: 100+ TFLOPS
- 超级计算机: PFLOPS级别

## 二、并行计算硬件架构

### 2.1 Flynn分类法

| 类型 | 指令流 | 数据流 | 示例 |
|------|--------|--------|------|
| **SISD** | 单指令 | 单数据 | 传统单核CPU |
| **SIMD** | 单指令 | 多数据 | GPU、向量处理器 |
| **MISD** | 多指令 | 单数据 | 容错系统（少见） |
| **MIMD** | 多指令 | 多数据 | 多核CPU、集群 |

> 📖 **重点**：SIMD和MIMD是最常见的并行架构

### 2.2 PRAM模型（并行随机访问机）

**PRAM（Parallel Random Access Machine）**：理想的并行计算模型

**三个阶段**：
1. **Read phase**：每个处理器同时从共享内存读取数据到本地寄存器
2. **Compute phase**：每个处理器独立执行计算
3. **Write phase**：每个处理器同时将结果写入共享内存

**PRAM衍生模型**：

| 模型 | 全称 | 读写规则 |
|------|------|----------|
| **EREW** | Exclusive Read Exclusive Write | 不能并发读，不能并发写 |
| **CREW** | Concurrent Read Exclusive Write | 可以并发读，不能并发写 |
| **CRCW** | Concurrent Read Concurrent Write | 可以并发读，可以并发写 |

> ⚠️ **考试重点**：理解三种PRAM模型的区别，CRCW最灵活但需要处理写冲突

### 2.3 SIMD指令集

**SSE（Streaming SIMD Extensions）**：
- 128位寄存器（XMM）
- 同时处理4个单精度浮点数

**AVX/AVX2/AVX512**：

| 版本 | 寄存器宽度 | 说明 |
|------|------------|------|
| AVX | 256位（YMM） | 2011年，支持浮点 |
| AVX2 | 256位 | 2013年，支持整数 |
| AVX512 | 512位（ZMM） | 2016年，性能更强 |

**AoS vs SoA数据布局**：

```c
// AoS: Array of Structure（结构体数组）
struct Point { float x, y, z; };
Point points[N];  // 不利于SIMD

// SoA: Structure of Array（数组结构体）
struct Points { float x[N], y[N], z[N]; };  // 利于SIMD
```

> 📖 **记忆技巧**：SIMD需要连续相同类型数据，SoA更符合这个特点

## 三、内存架构与访问模式

### 3.1 UMA与NUMA

**UMA（Uniform Memory Access，统一内存访问）**：
- 所有处理器访问内存的时间相同
- 适用于对称多处理器（SMP）
- 扩展性有限

**NUMA（Non-Uniform Memory Access，非统一内存访问）**：
- 处理器访问本地内存快，访问远程内存慢
- 每个处理器有本地内存，形成节点
- 扩展性好，但编程复杂

```
UMA架构：                    NUMA架构：
┌─────────────────┐         ┌────────┐  ┌────────┐
│   CPU1    CPU2  │         │CPU  MEM│  │CPU  MEM│
│      \  /      │         │  \    /│  │  \    /│
│    共享内存     │         │  本地   │──│  本地   │
│      /  \      │         │  可访问远│  │  可访问远│
│   CPU3    CPU4  │         └────────┘  └────────┘
└─────────────────┘
```

> 🎯 **必考概念**：NUMA和UMA的区别，访问延迟是否均匀

### 3.2 存储器层次结构

```
        ┌─────────┐
        │ 寄存器  │  ← 最快，容量最小
        ├─────────┤
        │ L1 Cache│  ← 延迟~1ns
        ├─────────┤
        │ L2 Cache│  ← 延迟~10ns
        ├─────────┤
        │ L3 Cache│  ← 延迟~40ns
        ├─────────┤
        │  主存   │  ← 延迟~100ns
        ├─────────┤
        │  磁盘   │  ← 最慢，容量最大
        └─────────┘
```

### 3.3 缓存优化原则

**时间局部性（Temporal Locality）**：
- 最近访问的数据很可能再次被访问
- 循环变量、频繁使用的变量应保持在缓存中

**空间局部性（Spatial Locality）**：
- 访问某数据后，很可能访问其相邻数据
- 数组按行访问（C语言）比按列访问更高效

**矩阵乘法优化示例**：

```c
// 差：按列访问，缓存命中率低
for (j=0; j<n; j++)
    for (i=0; i<n; i++)
        C[i][j] += A[i][k] * B[k][j];

// 好：按行访问，缓存命中率高
for (i=0; i<n; i++)
    for (j=0; j<n; j++)
        C[i][j] += A[i][k] * B[k][j];
```

## 四、集群系统

### 4.1 集群分类

| 类型 | 特点 | 优化目标 |
|------|------|----------|
| **高性能计算集群** | 科学计算、并行计算 | 计算性能 |
| **大数据集群** | 分布式数据处理 | IO与存储性能 |
| **高可用服务集群** | 在线服务、负载均衡 | 可靠性、低延迟 |

### 4.2 集群管理系统

**PBS（Portable Batch System）**：
- 历史悠久，功能齐全
- 包含：openPBS、PBS Pro、Torque

**Slurm（Simple Linux Utility for Resource Management）**：
- TOP500超算中约60%使用
- 支持大规模集群，容错性好

## 五、名词解释汇总

| 术语 | 英文 | 定义 |
|------|------|------|
| **并行计算** | Parallel Computing | 同时使用多个计算资源解决问题 |
| **UMA** | Uniform Memory Access | 统一内存访问，所有处理器访问时间相同 |
| **NUMA** | Non-Uniform Memory Access | 非统一内存访问，本地/远程访问时间不同 |
| **SIMD** | Single Instruction Multiple Data | 单指令多数据，一条指令处理多个数据 |
| **MIMD** | Multiple Instruction Multiple Data | 多指令多数据，多处理器独立执行 |
| **PRAM** | Parallel Random Access Machine | 并行随机访问机，理想并行模型 |
| **集群** | Cluster | 多台计算机通过网络连接组成的并行系统 |
| **FLOPS** | Floating-point Operations Per Second | 每秒浮点运算次数 |
| **缓存** | Cache | 处理器与主存之间的高速存储器 |
| **局部性** | Locality | 程序访问内存的规律性（时间/空间） |
