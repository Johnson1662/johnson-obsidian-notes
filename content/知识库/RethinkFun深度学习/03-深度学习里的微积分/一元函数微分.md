# 一元函数微分

## 3.5 一元函数微分

### 3.5.1 微分的由来

首先我们看函数：$y=f(x)=2x$y=f(x)=2x，在$x_0$x0​处有：

$\triangle y =f(x_0+\triangle x)-f(x_0)=2(x_0+\triangle x) - 2x_0 = 2 \triangle x$△y=f(x0​+△x)−f(x0​)=2(x0​+△x)−2x0​=2△x

可以看到在$x_0$x0​处，y的增量等于x的增量的2倍。

接着看函数：$y=x^2$y=x2, 在$x_0$x0​处有：

$\triangle y = (x_0+\triangle x)^2-{x_0}^2=2x_0\triangle x+(\triangle x)^2$△y=(x0​+△x)2−x0​2=2x0​△x+(△x)2

$\lim_{\triangle x \to 0}\frac{\triangle y}{\triangle x}=\lim_{\triangle x \to 0}\frac{2x_0\triangle x+(\triangle x)^2}{\triangle x}$lim△x→0​△x△y​=lim△x→0​△x2x0​△x+(△x)2​

$\lim_{\triangle x \to 0}\frac{\triangle y}{\triangle x}=2x_0$lim△x→0​△x△y​=2x0​

可以看到在$x_0$x0​处，y的增量由两部分构成，第一部分可以看做一个常数$2x_0$2x0​与x的增量$\triangle x$△x的乘积，这部分$\triangle x$△x和$\triangle y$△y满足线性关系。第二部分，当$\triangle x$△x趋于0时，$(\triangle x)^2$(△x)2可以看做是$\triangle x$△x的高阶无穷小。所以当$\triangle x$△x趋于0时，可以忽略高阶无穷小部分。原本x和y不是线性关系，但是x和y的增量部分，$\triangle y$△y就可以用$\triangle x$△x线性表示。所以当$\triangle x$△x变化很小时，就可以用简单的线性估算出$\triangle y$△y。

最后我们再看一个函数：$y=x^3$y=x3, 在$x_0$x0​处有：

$\triangle y = (x_0+\triangle x)^3-{x_0}^3=3{x_0}^2\triangle x +3x_0(\triangle x)^2 +(\triangle x)^3$△y=(x0​+△x)3−x0​3=3x0​2△x+3x0​(△x)2+(△x)3

$\lim_{\triangle x \to 0}\frac{\triangle y}{\triangle x}=\lim_{\triangle x \to 0}\frac{3{x_0}^2\triangle x +3x_0(\triangle x)^2 +(\triangle x)^3}{\triangle x}$lim△x→0​△x△y​=lim△x→0​△x3x0​2△x+3x0​(△x)2+(△x)3​

$\lim_{\triangle x \to 0}\frac{\triangle y}{\triangle x}=\lim_{\triangle x \to 0}\frac{3{x_0}^2\triangle x +O(\triangle x)}{\triangle x}$lim△x→0​△x△y​=lim△x→0​△x3x0​2△x+O(△x)​

$\lim_{\triangle x \to 0}\frac{\triangle y}{\triangle x}=3{x_0}^2$lim△x→0​△x△y​=3x0​2

当$\triangle x$△x趋于0时，$\triangle y$△y也可以由$\triangle x$△x的线性部分$3{x_0}^2\triangle x$3x0​2△x和$\triangle x$△x的高阶无穷小部分$3x_0(\triangle x)^2 +(\triangle x)^3$3x0​(△x)2+(△x)3构成。所以当$\triangle x$△x趋于0时，$\triangle y$△y和$\triangle x$△x之间也满足线性关系。进而当$\triangle x$△x很小时，我们根据x的变化量也可以通过线性关系估算y的变化量。当x变化越小这个估算越准。

### 3.5.2 微分的定义

通过上边3个函数我们发现，当$\triangle x$△x趋于0时，$\triangle y$△y可以表示为一个常数A与$\triangle x$△x的乘积加上一个$\triangle x$△x的高阶无穷小。

$\triangle y = A \triangle x + O(\triangle x);(\triangle x \to 0)$△y=A△x+O(△x);(△x→0)

则称$y=f(x)$y=f(x)在$x_0$x0​处可微。$A \triangle x$A△x为线性主部（线性关系的主要部分）。记作：

$\mathrm{d}y = A \mathrm{d}x$dy=Adx

$\mathrm{d}x$dx和$\mathrm{d}y$dy分别是x和y的微分。

可微描述的是$\triangle x$△x和$\triangle y$△y之间的类线性关系。

### 3.5.3微分和导数的关系

$\mathrm{d}y = A \mathrm{d}x$dy=Adx 中的A等于$f'(x_0)$f′(x0​)。

通过3.5.1节的几个例子，你可以发现：

对于$y=2x$y=2x，A等于2。

对于$y=x^2$y=x2，A等于$2x_0$2x0​。

对于$y=x^3$y=x3，A等于$3(x_0)^2$3(x0​)2。

A都等于在$x_0$x0​处的导数。

下边给出证明：

根据微分定义

$\triangle y = A \triangle x + O(\triangle x);(\triangle x \to 0)$△y=A△x+O(△x);(△x→0)

则有：

$\lim_{\triangle x \to 0} \frac{\triangle y}{\triangle x}=\lim_{\triangle x \to 0}(A+\frac{O( \triangle x)}{\triangle x})=A$lim△x→0​△x△y​=lim△x→0​(A+△xO(△x)​)=A

$\lim_{\triangle x \to 0} \frac{f(x_0+\triangle x)-f(x_0)}{\triangle x}=A$lim△x→0​△xf(x0​+△x)−f(x0​)​=A

所以$f'(x_0)=A$f′(x0​)=A

在一元函数里，可微和可导是等价的。可微必可导，可导必可微。

### 3.5.4微分的几何意义

微分的几何意义就是以直代曲。用直线代替曲线。比如函数$y=x^2$y=x2，它的导数$\frac{\mathrm{d}y}{\mathrm{d}x}=2x$dxdy​=2x。

在x等于1附近，x发生微小变化时，y的变化可以用$\mathrm{d}y = 2 \mathrm{d}x$dy=2dx这个线性变化来近似。
