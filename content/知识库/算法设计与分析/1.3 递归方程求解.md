### **1. 递归算法简介**

**递归的基本概念**

递归是一种重要的算法设计技术，其核心思想是将原问题分解为规模更小的同类子问题，通过解决子问题来解决原问题。

**递归算法的设计要素**

1. **基础情况（Base Case）**：递归的终止条件，通常是规模最小的子问题
2. **递归情况（Recursive Case）**：将原问题分解为更小规模的子问题
3. **递归调用**：在递归情况中调用自身来解决子问题

**递归算法示例**

<!-- Column 1 -->

```c++
// 计算阶乘
int factorial(int n) {
    if (n <= 1) return 1;        // 基础情况
    return n * factorial(n-1);   // 递归情况
}

// 斐波那契数列
int fibonacci(int n) {
    if (n <= 1) return n;        // 基础情况
    return fibonacci(n-1) + fibonacci(n-2);  // 递归情况
}
```

<!-- Column 2 -->

$$\boxed{
\begin{aligned}
&\text{\textbf{Algorithm Factorial}(n)} \\
&\quad \text{\textbf{Input}: } \text{非负整数}n \\
&\quad \text{\textbf{Output}: } n! \\
&\quad \text{\textbf{Procedure}:} \\
&\quad 1.\ \mathbf{if}\ n \leq 1\ \mathbf{return}\ 1 \quad \textcolor{gray}{// 基础情况} \\
&\quad 2.\ \mathbf{return}\ n \times \text{Factorial}(n-1) \quad \textcolor{gray}{// 递归调用} \\
&\quad \mathbf{end\ procedure}
\end{aligned}
}$$

### **2. 递归方程的建立**

**从递归算法到递归方程**

递归算法的时间复杂度通常可以用递归方程（递推关系）来表示。递归方程描述了问题规模为n时的计算时间与更小规模子问题计算时间之间的关系。

**递归方程的标准形式**

$T(n) = aT(n/b) + f(n)$
其中：

- $a \geq 1$：子问题的个数
- $b > 1$：子问题规模缩减的倍数
- $f(n)$：分解问题和合并结果所需的时间

**常见递归方程示例**

1. **二分查找**：$T(n) = T(n/2) + O(1)$
2. **归并排序**：$T(n) = 2T(n/2) + O(n)$
3. **快速排序（平均情况）**：$T(n) = 2T(n/2) + O(n)$
4. **矩阵乘法（传统方法）**：$T(n) = 8T(n/2) + O(n^2)$

### **3. 递归方程求解方法**

**方法一：递归树方法**

递归树是一种图解方法，通过画出递归调用的树形结构来分析算法的时间复杂度。

**递归树构造步骤**：

1. 根节点表示原问题$T(n)$
2. 每个内部节点表示一个递归调用
3. 叶节点表示基础情况
4. 计算每层的总代价
5. 求和得到总时间复杂度

**示例：归并排序的递归树分析**

递归方程：$T(n) = 2T(n/2) + cn$

<!-- Column 1 -->

$$\boxed{
\begin{aligned}
&\text{Level 0: } cn \\
&\text{Level 1: } cn/2 \qquad cn/2 \\
&\text{Level 2: } cn/4 \quad cn/4 \quad cn/4 \quad cn/4 \\
&\vdots \\
&\text{Level } \log_2 n: \underbrace{c \quad \cdots \quad c}_{n\text{个}}
\end{aligned}
}$$

<!-- Column 2 -->

```
		cn
	   /  \
	cn/2  cn/2
	/  \   /  \
cn/4 cn/4 cn/4 cn/4
...
```

- 每层的总代价：$cn$
- 树的深度：$\log_2 n$
- 总时间复杂度：$T(n) = cn \cdot \log_2 n = O(n \log n)$

**方法二：替代法（数学归纳法）**

替代法是解递归方程最一般的方法：

1. **猜测**解的形式
2. **用数学归纳法验证**猜测
3. **求解常数**

**示例：证明**$T(n) = 2T(n/2) + n$**的解为**$T(n) = O(n \log n)$

1. **猜测**：$T(n) \leq cn \log n$
2. **归纳假设**：对于$k < n$，有$T(k) \leq ck \log k$
3. **归纳证明**：
$$T(n) = 2T(n/2) + n \leq 2c(n/2)\log(n/2) + n \\
= cn\log(n/2) + n \\ 
= cn\log n - cn\log 2 + n \\ 
= cn\log n - cn + n \leq cn\log n$$
当$c \geq 1$时不等式成立。
