### **3.1 使用主定理**

- 归并排序：$T(n) = 2T(n/2) + \Theta(n) → Case 2 → \Theta(n \log n)$.
- Strassen：$T(n) = 7T(n/2) + \Theta(n^2) → Case 1 → \Theta(n^{\log_2 7})$.

### **3.2 替换法（Substitution Method）**

- **步骤**：猜测解 → 数学归纳法验证。
- **示例**：金块问题 $c(n) = 2c(n/2) + 2$，解为 $c(n) = \frac{3n}{2} - 2$.

### **3.3 复杂性下限证明**

1. **最大最小值问题**
    - **状态空间法**：定义算法状态 (a, b, c, d)：
        - a: 未比较元素数。
        - b: 只胜未败元素数。
        - c: 只败未胜元素数。
        - d: 已淘汰元素数。
    - **初始状态**：(n, 0, 0, 0)，**结束状态**：(0, 1, 1, n-2)。
    - **结论**：任何算法至少需 $\lceil 3n/2 \rceil - 2$次比较（分治法最优）。
2. **排序问题**
    - **决策树模型**：
        - 叶节点数 = $n!$（所有可能排序）。
        - 树高 $≥ \log_2(n → \Omega(n \log n)$.
    - **结论**：比较排序算法下界为 $\Omega(n \log n)$（堆排、归排、快排均最优）。
