# 一 算法分析
## 1 渐进分析法

### **大$O$记号（Big O Notation）**

$f(n) = O(g(n))$ 当且仅当存在常数c和$n_0$使得对所有$n > n_0$有$f(n) \leq cg(n)$成立。

等价定义：$\lim_{n \to \infty} |f(n)/g(n)| = c$，$0 \leq c < \infty$，则$f(n) = O(g(n))$。

称g(n)为f(n)的**渐近上界（Asymptotic Upper Bound）**。

**示例**：

- $10n^2 + 3n + 100 = O(n^2)$，$\lim = 10$
- $1000n^2 = O(n^{2.1})$，$\lim = 0$

### **大$\Omega$记号（Big Omega Notation）**

$f(n) = \Omega(g(n))$ 当且仅当存在常数c和$n_0$使得对所有$n > n_0$有$f(n) \geq cg(n)$成立。

等价定义：$\lim_{n \to \infty} |f(n)/g(n)| = c$，$0 < c \leq \infty$，则$f(n) = \Omega(g(n))$。

称$g(n)$为$f(n)$的**渐近下界**。

### **大$\Theta$记号（Big Theta Notation）**

如果$f(n) = O(g(n))$同时$f(n) = \Omega(g(n))$则$f(n) = \Theta(g(n))$，并称f(n)与g(n)同阶。

等价定义：$\lim_{n \to \infty} f(n)/g(n) = c$，$0 < c < \infty$，则$f(n) = \Theta(g(n))$。

当$f(n)$为算法的时间复杂度函数时，称$g(n)$为该算法的复杂度的阶。
