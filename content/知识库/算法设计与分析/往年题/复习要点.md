# 一 算法分析
## 1 渐进分析法




### **大$O$记号（Big O Notation）**

$f(n) = O(g(n))$ 当且仅当存在常数c和$n_0$使得对所有$n > n_0$有$f(n) \leq cg(n)$成立。

等价定义：$\lim_{n \to \infty} |f(n)/g(n)| = c$，$0 \leq c < \infty$，则$f(n) = O(g(n))$。

称g(n)为f(n)的**渐近上界（Asymptotic Upper Bound）**。

**示例**：

- $10n^2 + 3n + 100 = O(n^2)$，$\lim = 10$
- $1000n^2 = O(n^{2.1})$，$\lim = 0$

### **大$\Omega$记号（Big Omega Notation）**

$f(n) = \Omega(g(n))$ 当且仅当存在常数c和$n_0$使得对所有$n > n_0$有$f(n) \geq cg(n)$成立。

等价定义：$\lim_{n \to \infty} |f(n)/g(n)| = c$，$0 < c \leq \infty$，则$f(n) = \Omega(g(n))$。

称$g(n)$为$f(n)$的**渐近下界**。

### **大$\Theta$记号（Big Theta Notation）**

如果$f(n) = O(g(n))$同时$f(n) = \Omega(g(n))$则$f(n) = \Theta(g(n))$，并称f(n)与g(n)同阶。

等价定义：$\lim_{n \to \infty} f(n)/g(n) = c$，$0 < c < \infty$，则$f(n) = \Theta(g(n))$。

当$f(n)$为算法的时间复杂度函数时，称$g(n)$为该算法的复杂度的阶。
# 二 递归
## 1 主定理

对于递归方程$T(n) = aT(n/b) + f(n)$，其中$a \geq 1$，$b > 1$，$f(n) > 0$：

设$\log_b a$为临界指数，根据$f(n)$相对于$n^{\log_b a}$的渐近性质，分三种情况：

**情况1**：$f(n) = O(n^{\log_b a - \epsilon})$，其中$\epsilon > 0$为某一常数

$f(n)$的增长渐近地慢于$n^{\log_b a}$

**解**：$T(n) = \Theta(n^{\log_b a})$

**情况2**：$f(n) = \Theta(n^{\log_b a} \log^k n)$，其中$k \geq 0$为某一常数

$f(n)$和$n^{\log_b a}$几乎有相同的渐近增长率

**解**：$T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$

**情况3**：$f(n) = \Omega(n^{\log_b a + \epsilon})$，其中$\epsilon > 0$为一常数

$f(n)$多项式地快于$n^{\log_b a}$，且$f(n)$满足规则性条件：$af(n/b) \leq cf(n)$，$0 < c < 1$为常数

**解**：$T(n) = \Theta(f(n))$

**主定理的核心思想**

主定理的本质是比较递归树中两个主要成分的渐近增长率：

- 叶节点总数：$n^{\log_b a}$
- 非叶节点总代价：$\sum_{i=0}^{\log_b n - 1} a^i f(n/b^i)$

两者中阶较高的决定最终的时间复杂度。
