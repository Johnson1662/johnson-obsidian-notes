### **1. 明确问题输入与目标**

- **输入**：矩阵链 $( A_1, A_2, \dots, A_n )$，维度数组 $( p = [p_0, p_1, \dots, p_n] )$。
  $(A_i)$ 的维度为 $(p_{i-1} \times p_i)$
- **目标**：找到最小标量乘法次数的加括号方式。

---

### **2. 初始化动态规划表**

- 定义二维表 m[i][j]：存储子链 ( $A_iA_{i+1}\dots A_j$ ) 的最小乘法次数。
- 定义分割点表 s[i][j]：记录分割位置 ( k )。
- **边界条件**：对角线 m[i][i] = 0（单个矩阵无需乘法）。

---

### **3. 递推填充动态规划表**

- **按子链长度 ( l ) 递增**（从 ( l=2 ) 到 ( l=n )）:
  依次计算所有长度为 ( l ) 的子链。
- **遍历起点 ( i )**：
  对每个起点 ( i )，终点 ( j = i + l - 1 )（不超过 ( n )）。
- **遍历分割点 ( k )**（从 ( i ) 到 ( j-1 )）:
  计算 m[i][j] = min(m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j])
  并记录最小值的分割点 s[i][j] = k。

---

### **4. 构造最优解（括号化方式）**

- **递归分解**：从根节点 s[1][n] 开始，递归分割左右子链。
- **输出格式**：
  - 若子链长度为 1：直接写矩阵名（如 ($A_i$)）。
  - 若子链长度 >1：递归左右子树，用括号包裹合并结果。**示例**：( $(A_1A_2)(A_3A_4)$ )。

---

### **5. 复杂度与注意事项**

- **时间复杂度：( **$O(n^3)$** )（三重循环）。**
- **空间复杂度**：( $O(n^2)$ )（二维表）。
- **关键点**：
  - 必须按子链长度从小到大的顺序填表。
  - 分割点 ( k ) 的范围是 ($i \leq k < j$ )。

---

### **6. 快速验证（可选）**

- **计算总乘法次数**：
  将分解后的每一步乘法次数累加，检查是否等于 m[1][n]。
- **示例验证**：
  - ( ($A_1A_2)$ )：计算次数为 ($p_0 \times p_1 \times p_2$)。
  - 合并后的次数：根据分割点计算合并代价。

---

### **7.考场速记模板**

```plain text
输入：维度数组 p = [p0, p1, ..., pn]
目标：最小乘法次数

初始化 m[i][j] 表：
  对角线 m[i][i] = 0

递推填表（按链长 l 递增）：
  for l = 2 to n:
    for i = 1 to n - l + 1:
      j = i + l - 1
      m[i][j] = ∞
      for k = i to j-1:
        cost = m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j]
        if cost < m[i][j]:
          m[i][j] = cost
          s[i][j] = k

构造最优解：
  递归分割点 s[i][j]，生成括号表达式

输出：m[1][n] 和括号化方式
```

### **附：证明动态规划表中总引用次数为 **$(\frac{n^3 - n}{3})$

---

**1. 动态规划填表过程分析**

矩阵链乘法问题的动态规划算法中，二维表 m[i][j] 表示计算子链 ( $A_iA_{i+1}\dots A_j$) 的最小乘法次数。填表过程按子链长度 ( l ) 递增进行：

- 对每个长度 ($l \in [2, n]$)，
- 对每个起点 ( $i \in [1, n-l+1]$ )，终点 ( j = i + l - 1 ),
- 遍历分割点 ( $k \in [i, j-1]$)，计算：
  $m[i][j] = \min_{k} \left( m[i][k] + m[k+1][j] + p[i-1] \cdot p[k] \cdot p[j] \right)$
  其中每次计算需访问两个子问题 m[i][k] 和 m[k+1][j]。

---

**2. 总引用次数的计算**

**引用次数定义**：每次计算 m[i][j] 时，对子问题 m[i][k] 和 m[k+1][j] 各产生 **1次引用**。

**总引用次数公式**：
$\text{总引用次数} = 2 \cdot \sum_{l=2}^n \sum_{i=1}^{n-l+1} \sum_{k=i}^{j-1} 1$
其中 $j = i + l - 1$

---

**3. 求和化简**

3. **固定长度 ( l )**：
   - 每个 ( l ) 对应的起点 ( i ) 有 ( n - l + 1 ) 个。
   - 每个 ( i ) 对应的分割点 ( k ) 有 ( l - 1 ) 个。
   - 总操作数为：

$\sum_{l=2}^n (n - l + 1)(l - 1)$

4. **变量替换 ( m = l - 1 )**：
   当$l \in [2, n]$ 时，$m \in [1, n-1]$，求和变为：
   $\sum_{m=1}^{n-1} (n - m) \cdot m$
5. **拆分求和项**：
   $\sum_{m=1}^{n-1} (n \cdot m - m^2) = n \sum_{m=1}^{n-1} m - \sum_{m=1}^{n-1} m^2$
6. **已知求和公式**：

$\sum_{m=1}^{k} m = \frac{k(k+1)}{2}$

$\sum_{m=1}^{k} m^2 = \frac{k(k+1)(2k+1)}{6}$ 7. **代入公式**：
$n \cdot \frac{(n-1)n}{2} - \frac{(n-1)n(2n-1)}{6} = \frac{n^3 - n}{3}$

---

**4. 最终结果**

总引用次数为：
$2 \cdot \frac{n^3 - n}{6} = \boxed{\frac{n^3 - n}{3}}$
