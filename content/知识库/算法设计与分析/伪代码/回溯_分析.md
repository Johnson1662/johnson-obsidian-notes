# 第16章 回溯算法分析

## 程序16-1：第一种回溯算法

### 问题描述
该算法解决两艘货箱装船问题中的核心子问题：尽可能将第一艘船装满（使装入第一艘船的货箱总重量不超过其容量c且最大化）。给定n个货箱的重量数组w[1..n]和第一艘船的容量c，返回不超过c的最大重量子集之和。

### 问题分析
将解空间组织成子集树（二叉树），每个节点表示对前i个货箱的决策状态。从根节点开始深度优先搜索，按如下规则移动：
- 左孩子（x[i]=1）：当`cw + w[i] ≤ c`时可行，更新当前重量cw并递归搜索。
- 右孩子（x[i]=0）：无需可行性检查，直接递归搜索。
到达叶节点时，若当前重量cw大于最优重量bestw则更新。算法遍历所有可行节点，复杂度为O(2^n)，递归栈空间O(n)。

### 伪代码
```cpp
// 类Loading：存储装载问题搜索状态
template<class T>
class Loading {
    friend MaxLoading(T [], T, int);
    private:
    void maxLoading(int i);
    int n;    // 货箱数目
    T *w,     // 货箱重量数组
      c,      // 第一艘船的容量
      cw,     // 当前装载的重量
      bestw;  // 目前最优装载的重量
};

// 递归搜索第i层节点
template<class T>
void Loading<T>::maxLoading(int i)
{
    if (i > n) {         // 到达叶节点
        if (cw > bestw) bestw = cw;  // 更新最优解
        return;
    }
    // 尝试x[i] = 1（搜索左子树）
    if (cw + w[i] <= c) {
        cw += w[i];
        maxLoading(i+1);
        cw -= w[i];      // 回溯，恢复状态
    }
    // 尝试x[i] = 0（搜索右子树）
    maxLoading(i+1);
}

// 驱动程序：初始化并返回最优装载重量
template<class T>
T MaxLoading(T w[], T c, int n)
{
    Loading<T> X;
    X.w = w;
    X.c = c;
    X.n = n;
    X.bestw = 0;
    X.cw = 0;
    X.maxLoading(1);     // 从第1层开始搜索
    return X.bestw;
}
```

## 程序16-2：程序16-1的优化

### 问题描述
在程序16-1的基础上，引入加强的限界函数来减少搜索节点数。当右子树不可能产生比当前最优解更好的解时，跳过该右子树的搜索。

### 问题分析
为类Loading增加私有成员r（当前节点之后所有未考虑货箱的重量之和）。在节点Z（第i层），以Z为根的子树中任何叶节点的重量都不可能超过`cw + r`。若`cw + r ≤ bestw`，则右子树中不可能有更优解，直接剪枝。该优化不改变最坏情况复杂度O(2^n)，但实际搜索的节点数显著减少。

### 伪代码
```cpp
// 加强限界函数的装载回溯算法
template<class T>
void Loading<T>::maxLoading(int i)
{
    if (i > n) {         // 到达叶节点
        bestw = cw;      // 叶节点必定比当前最优解好
        return;
    }
    r -= w[i];           // 更新剩余重量

    // 尝试x[i] = 1（搜索左子树）
    if (cw + w[i] <= c) {
        cw += w[i];
        maxLoading(i+1);
        cw -= w[i];      // 回溯
    }
    // 尝试x[i] = 0，仅当右子树可能产生更优解
    if (cw + r > bestw) {
        maxLoading(i+1);
    }
    r += w[i];           // 恢复剩余重量
}

// 驱动程序
template<class T>
T MaxLoading(T w[], T c, int n)
{
    Loading<T> X;
    X.w = w;
    X.c = c;
    X.n = n;
    X.bestw = 0;
    X.cw = 0;
    // r初始值为所有重量之和
    X.r = 0;
    for (int i = 1; i <= n; i++)
        X.r += w[i];
    X.maxLoading(1);
    return X.bestw;
}
```

## 程序16-3：给出最优装载的代码

### 问题描述
在程序16-2的基础上增加记录最优子集的功能。不仅返回最大装载重量，还通过数组bestx[1..n]记录哪些货箱被装入第一艘船（bestx[i]=1表示货箱i在最优子集中）。

### 问题分析
增加两个私有成员：x[1..n]（记录从根到当前节点的路径，即x[i]=1或0）和bestx[1..n]（记录当前最优解）。每次到达叶节点时，将x复制到bestx。由于bestx可能被更新O(2^n)次，每次复制O(n)，故复杂度为O(n·2^n)。可采用两种方法降回O(2^n)：（1）先运行程序16-2获得最优重量，再运行修改版在第一次到达叶节点时终止；（2）在回溯过程中逐步更新bestx。

### 伪代码
```cpp
// 带最优子集记录的装载回溯
template<class T>
void Loading<T>::maxLoading(int i)
{
    if (i > n) {         // 到达叶节点
        for (int j = 1; j <= n; j++)
            bestx[j] = x[j];  // 记录当前最优路径
        bestw = cw;
        return;
    }
    r -= w[i];

    // 尝试x[i] = 1
    if (cw + w[i] <= c) {
        x[i] = 1;
        cw += w[i];
        maxLoading(i+1);
        cw -= w[i];
    }
    // 尝试x[i] = 0，仅当右子树可能更优
    if (cw + r > bestw) {
        x[i] = 0;
        maxLoading(i+1);
    }
    r += w[i];
}

// 驱动程序：返回最优装载重量，bestx记录最优子集
template<class T>
T MaxLoading(T w[], T c, int n, int bestx[])
{
    Loading<T> X;
    X.x = new int [n+1];
    X.w = w;
    X.c = c;
    X.n = n;
    X.bestx = bestx;
    X.bestw = 0;
    X.cw = 0;
    X.r = 0;
    for (int i = 1; i <= n; i++)
        X.r += w[i];
    X.maxLoading(1);
    delete [] X.x;
    return X.bestw;
}
```

## 程序16-4：迭代代码

### 问题描述
将程序16-3的递归回溯算法改写为迭代（循环）版本，消除大小为O(n)的递归栈空间，使空间需求降至O(1)（不计数组x本身）。

### 问题分析
迭代版本模拟深度优先搜索的栈操作：从根节点开始不断向左孩子移动直到不能移动为止；若到达叶节点则更新最优解；否则尝试右孩子；当发现当前子树不可能产生更优解时回溯到最近的x[i]=1的节点并尝试右移。该版本的时间复杂性与递归版本相同，但避免了递归调用开销和栈空间。

### 伪代码
```cpp
// 迭代回溯算法
template<class T>
T MaxLoading(T w[], T c, int n, int bestx[])
{
    // 初始化根节点
    int i = 1;         // 当前节点层次
    int *x = new int [n+1];
    T bestw = 0,       // 最优装载重量
      cw = 0,          // 当前装载重量
      r = 0;           // 剩余货箱总重量

    for (int j = 1; j <= n; j++)
        r += w[j];

    while (true) {
        // 尽可能向左移动
        while (i <= n && cw + w[i] <= c) {
            r -= w[i];
            cw += w[i];
            x[i] = 1;
            i++;
        }

        if (i > n) {   // 到达叶节点
            for (int j = 1; j <= n; j++)
                bestx[j] = x[j];
            bestw = cw;
        } else {       // 尝试右孩子
            r -= w[i];
            x[i] = 0;
            i++;
        }

        // 回溯：当当前子树无更好解时返回
        while (cw + r <= bestw) {
            i--;
            // 从右孩子回溯
            while (i > 0 && !x[i]) {
                r += w[i];
                i--;
            }
            if (i == 0) {   // 搜索完毕
                delete [] x;
                return bestw;
            }
            // 尝试右子树
            x[i] = 0;
            cw -= w[i];
            i++;
        }
    }
}
```

## 程序16-5：Knap类

### 问题描述
定义Knap类，用于封装0/1背包问题的回溯算法所需的所有数据和成员函数。该类作为背包问题求解的核心容器，减少了递归函数Knapsack和限界函数Bound的参数传递开销。

### 问题分析
Knap类包含模板参数Tw（重量类型）和Tp（收益类型）。私有成员包括背包容量c、对象数目n、重量数组w、收益数组p、当前重量cw、当前收益cp、当前最优收益bestp。成员函数Bound(int i)计算子树收益上界，Knapsack(int i)实现递归搜索。通过将状态封装在类中，递归调用不必传递大量参数，从而减少栈空间和执行时间。

### 伪代码
```cpp
// 背包问题回溯算法核心类
template<class Tw, class Tp>
class Knap {
    friend Tp Knapsack(Tp *, Tw *, Tw, int);
    private:
    Tp Bound(int i);          // 限界函数
    void Knapsack(int i);     // 递归搜索
    Tw c;                     // 背包容量
    int n;                    // 对象数目
    Tw *w;                    // 对象重量数组
    Tp *p;                    // 对象收益数组
    Tw cw;                    // 当前背包重量
    Tp cp;                    // 当前背包收益
    Tp bestp;                 // 迄今最大收益
};
```

## 程序16-6：限界函数

### 问题描述
实现0/1背包问题的限界函数Bound(i)，计算从第i层节点开始的子树中可能获得的最大收益上界。该上界用于决定是否剪枝——仅当上界大于当前最优收益时才搜索右子树。

### 问题分析
限界函数采用贪心策略：将剩余对象按收益密度（p[i]/w[i]）降序填充背包剩余容量。对于能完整放入的对象全部放入，遇到第一个不能完整放入的对象时取其一部分（允许分数），从而得到一个可能高于实际最优解的上界。该上界保证不小于子树中任何可行解的收益值，因此是安全的剪枝条件。

### 伪代码
```cpp
// 计算子树最优收益上界
template<class Tw, class Tp>
Tp Knap<Tw, Tp>::Bound(int i)
{
    Tw cleft = c - cw;   // 背包剩余容量
    Tp b = cp;           // 当前收益作为下界基础

    // 按照收益密度降序装填剩余容量
    while (i <= n && w[i] <= cleft) {
        cleft -= w[i];
        b += p[i];
        i++;
    }
    // 取下一个对象的一部分（分数背包）
    if (i <= n) b += p[i] / w[i] * cleft;
    return b;            // 返回收益上界
}
```

## 程序16-7：0/1背包问题的迭代函数

### 问题描述
实现递归函数Knapsack(i)，在子集树中搜索0/1背包问题的最优解。该函数与程序16-2的maxLoading结构相似，但使用限界函数Bound代替简单重量和来判断是否搜索右子树。

### 问题分析
从第i层节点开始搜索：若i > n则到达叶节点，更新最优收益；否则先尝试左孩子（x[i]=1，即装入对象i），若`cw + w[i] ≤ c`则可行并递归搜索；然后尝试右孩子（x[i]=0），仅当`Bound(i+1) > bestp`时递归搜索右子树。限界函数在每个右孩子处被计算，复杂度O(n)，总共O(2^n)个右孩子，故整体复杂度O(n·2^n)。

### 伪代码
```cpp
// 0/1背包问题的递归回溯算法
template<class Tw, class Tp>
void Knap<Tw, Tp>::Knapsack(int i)
{
    if (i > n) {             // 到达叶节点
        bestp = cp;          // 更新最优收益
        return;
    }
    // 尝试x[i] = 1（装入对象i）
    if (cw + w[i] <= c) {
        cw += w[i];
        cp += p[i];
        Knapsack(i+1);
        cw -= w[i];          // 回溯
        cp -= p[i];
    }
    // 尝试x[i] = 0，仅当可能产生更优解
    if (Bound(i+1) > bestp) {
        Knapsack(i+1);
    }
}
```

## 程序16-8：Object类

### 问题描述
定义Object类，用于在预处理阶段按收益密度（p[i]/w[i]）对对象进行降序排序。该类重载了<=运算符以便归并排序程序按密度递减顺序排列。

### 问题分析
Object类包含两个私有成员：ID（对象编号）和d（收益密度p[i]/w[i]）。重载operator<=使其按密度d降序比较（d >= a.d返回真），这样归并排序（程序14-3）可将对象按密度从高到低排列。排序后的顺序将作为Knap类中w和p数组的访问顺序。

### 伪代码
```cpp
// 按收益密度排序的对象类
class Object {
    friend int Knapsack(int *, int *, int, int);
    public:
    int operator<=(Object a) const
    {
        return (d >= a.d);  // 按密度降序排列
    }
    private:
    int ID;     // 对象编号
    float d;    // 收益密度 = p[i] / w[i]
};
```

## 程序16-9：程序16-7的预处理代码

### 问题描述
实现Knapsack函数，作为调用Knap::Knapsack前的预处理步骤。该函数验证总重量是否超过背包容量、按收益密度排序对象、初始化Knap对象各成员，然后递归搜索最优解。

### 问题分析
首先计算所有对象的总重量和总收益：若总重量不超过容量c，直接返回总收益（全部装入）；否则创建Object数组并计算各对象收益密度，用归并排序按密度降序排列；然后按排序后的顺序将重量和收益分别存入Knap对象的w和p数组；初始化Knap状态后调用Knapsack(1)开始搜索；最后释放动态分配的内存并返回最优收益。

### 伪代码
```cpp
// 0/1背包问题预处理及驱动函数
template<class Tw, class Tp>
Tp Knapsack(Tp p[], Tw w[], Tw c, int n)
{
    // 初始化：计算总重量和总收益
    Tw W = 0;
    Tp P = 0;
    Object *Q = new Object [n];

    for (int i = 1; i <= n; i++) {
        Q[i-1].ID = i;
        Q[i-1].d = 1.0 * p[i] / w[i];  // 计算收益密度
        P += p[i];
        W += w[i];
    }

    if (W <= c) return P;      // 所有对象可全部装入

    MergeSort(Q, n);           // 按密度降序排序

    // 创建Knap对象并初始化
    Knap<Tw, Tp> K;
    K.p = new Tp [n+1];
    K.w = new Tw [n+1];
    for (int i = 1; i <= n; i++) {
        K.p[i] = p[Q[i-1].ID];  // 按排序后顺序赋值
        K.w[i] = w[Q[i-1].ID];
    }
    K.cp = 0;
    K.cw = 0;
    K.c = c;
    K.n = n;
    K.bestp = 0;

    // 搜索最优解
    K.Knapsack(1);

    delete [] Q;
    delete [] K.w;
    delete [] K.p;
    return K.bestp;
}
```

## 程序16-10：最大完备子图

### 问题描述
给定无向图G（n个顶点，邻接矩阵a[1..n][1..n]），寻找G的一个最大完备子图（最大团）。当顶点i与当前已选子集中所有顶点之间都有边时，将i加入子集；在右子树中仅当可能找到更大的完备子图时才搜索。

### 问题分析
将解空间组织成子集树，从顶点1开始依次决定每个顶点是否加入当前完备子图。私有成员maxClique(i)递归搜索第i层节点：先检查顶点i与当前子集中所有已选顶点是否都有边（完全性检查），是则尝试x[i]=1并继续搜索；然后当`cn + n - i > bestn`（剩余顶点数加上当前子集大小仍可能超过最优解）时尝试x[i]=0。驱动函数MaxClique初始化后调用maxClique(1)并返回最大完备子图尺寸，bestx记录子集成员。复杂度O(n·2^n)。

### 伪代码
```cpp
// 最大完备子图（最大团）回溯算法

// 递归搜索第i层节点
void AdjacencyGraph::maxClique(int i)
{
    if (i > n) {                 // 到达叶节点
        // 找到更大的完备子图，更新
        for (int j = 1; j <= n; j++)
            bestx[j] = x[j];
        bestn = cn;
        return;
    }
    // 检查顶点i是否与当前子图中所有顶点相连
    int OK = 1;
    for (int j = 1; j < i; j++)
        if (x[j] && a[i][j] == NoEdge) {
            OK = 0;              // i与j不相邻
            break;
        }
    if (OK) {                    // 尝试x[i] = 1
        x[i] = 1;
        cn++;                    // 将i加入完备子图
        maxClique(i+1);
        x[i] = 0;
        cn--;
    }
    // 尝试x[i] = 0，仅当可能找到更大完备子图
    if (cn + n - i > bestn) {
        x[i] = 0;
        maxClique(i+1);
    }
}

// 驱动程序：返回最大完备子图大小，顶点放入v[1..n]
int AdjacencyGraph::MaxClique(int v[])
{
    x = new int [n+1];
    cn = 0;
    bestn = 0;
    bestx = v;

    maxClique(1);

    delete [] x;
    return bestn;
}
```

## 程序16-12：旅行商问题的迭代回溯算法

### 问题描述
给定n顶点有向带权图（邻接矩阵a[1..n][1..n]），寻找一条经过所有顶点恰好一次并回到起点的最小耗费环路（旅行）。使用排列树上的回溯算法搜索所有可能的顶点排列，找到最优旅行。

### 问题分析
解空间为排列树，从顶点1出发，搜索x[2..n]的所有排列。函数tSP(i)搜索第i层：当i=n时检查从x[n-1]到x[n]和从x[n]到x[1]是否有边，若有则构成一个完整旅行，优于当前最优解时更新；当i<n时，对每个j≥i，若从x[i-1]到x[j]有边且当前部分耗费cc加上该边耗费小于当前最优解bestc，则交换x[i]和x[j]后递归搜索。每次回溯时恢复状态。

### 伪代码
```cpp
// 旅行商问题的回溯算法（排列树搜索）
template<class T>
void AdjacencyWDigraph<T>::tSP(int i)
{
    if (i == n) {   // 位于叶节点的父节点
        // 检查能否通过两条边完成旅行
        if (a[x[n-1]][x[n]] != NoEdge &&
            a[x[n]][1] != NoEdge &&
            (cc + a[x[n-1]][x[n]] + a[x[n]][1] < bestc ||
             bestc == NoEdge)) {
            // 找到更优的旅行路径，更新最优解
            for (int j = 1; j <= n; j++)
                bestx[j] = x[j];
            bestc = cc + a[x[n-1]][x[n]] + a[x[n]][1];
        }
    } else {
        // 尝试每个可能的下一顶点
        for (int j = i; j <= n; j++) {
            // 检查能否移动到x[j]
            if (a[x[i-1]][x[j]] != NoEdge &&
                (cc + a[x[i-1]][x[j]] < bestc ||
                 bestc == NoEdge)) {
                // 搜索该子树
                Swap(x[i], x[j]);
                cc += a[x[i-1]][x[i]];
                tSP(i+1);
                cc -= a[x[i-1]][x[i]];
                Swap(x[i], x[j]);  // 回溯恢复
            }
        }
    }
}

// 驱动程序：初始化并返回最优旅行耗费
template<class T>
T AdjacencyWDigraph<T>::TSP(int v[])
{
    x = new int [n+1];
    for (int i = 1; i <= n; i++)
        x[i] = i;
    bestc = NoEdge;
    bestx = v;
    cc = 0;

    tSP(2);          // 从第2层开始搜索x[2..n]的排列

    delete [] x;
    return bestc;
}
```

## 程序16-13：Board的类定义

### 问题描述
定义Board类，用于封装电路板排列问题回溯算法所需的所有数据。该类管理电路板与网组的关系，记录搜索路径、当前最优排列以及部分排列中各网组的连接状态。

### 问题分析
Board类的私有成员包括：x（当前路径，即电路板排列）、bestx（最优排列）、total[j]（网组j包含的电路板总数）、now[j]（当前已放置电路板中属于网组j的数量）、bestd（最优排列的密度）、n（电路板数）、m（网组数）、B（n×m的二维数组，B[i][j]=1表示电路板i属于网组j）。函数BestOrder(i, cd)在排列树中搜索最优排列。通过now和total的差值可判断网组在当前插槽与下一个插槽之间是否有连线。

### 伪代码
```cpp
// 电路板排列问题的Board类定义
class Board {
    friend ArrangeBoards(int**, int, int, int[]);
    private:
    void BestOrder(int i, int cd);  // 递归搜索排列树
    int *x,        // 到达当前节点的路径（电路板排列）
        *bestx,    // 目前的最优排列
        *total,    // total[j] = 网组j中包含的电路板数
        *now,      // now[j] = 当前已放置电路中属于网组j的数量
        bestd,     // 最优排列的密度
        n,         // 电路板数目
        m,         // 网组数目
        **B;       // 电路板-网组关系矩阵
};
```

## 程序16-14：搜索排列树

### 问题描述
实现Board类的私有成员函数BestOrder(i, cd)，在排列树中搜索电路板排列问题的最优解。该函数与程序16-12的tSP结构相似，但使用局部密度作为限界条件。

### 问题分析
当i=n时所有电路板已放置，当前密度cd即为排列密度，更新最优解。当i<n时，对每个未放置的电路板x[j]尝试作为下一个放置的电路板：计算新密度ld（遍历所有网组k，若`0 < now[k] < total[k]`则网组k在当前插槽与下一插槽间有连线，计数加1；取cd和本次计算的较大值作为新密度）；仅当`ld < bestd`（可能优于当前最优）时递归搜索子树。每次尝试后恢复now数组状态。在排列树每个节点处计算密度需O(m)时间。

### 伪代码
```cpp
// 电路板排列的排列树搜索算法
void Board::BestOrder(int i, int cd)
{
    if (i == n) {                   // 所有电路板已放置
        for (int j = 1; j <= n; j++)
            bestx[j] = x[j];
        bestd = cd;                 // 更新最优密度
        return;
    }
    // 尝试每个未放置的电路板作为下一块
    for (int j = i; j <= n; j++) {
        // 计算将x[j]放入插槽i后的新密度
        int ld = 0;
        for (int k = 1; k <= m; k++) {
            now[k] += B[x[j]][k];
            // 若网组k部分放置（有连线穿过此插槽）
            if (now[k] > 0 && total[k] != now[k])
                ld++;
        }
        // 取局部排列的最大密度
        if (cd > ld) ld = cd;

        // 仅当子树可能包含更优排列时搜索
        if (ld < bestd) {
            Swap(x[i], x[j]);
            BestOrder(i+1, ld);
            Swap(x[i], x[j]);       // 回溯恢复
        }
        // 恢复now数组状态
        for (int k = 1; k <= m; k++)
            now[k] -= B[x[j]][k];
    }
}
```

## 程序16-15：BestOrder的预处理代码

### 问题描述
实现函数ArrangeBoards，作为调用Board::BestOrder前的预处理步骤。该函数创建Board对象、初始化total和now数组、填充初始排列x，然后调用BestOrder搜索最优排列，最后返回最优密度。

### 问题分析
首先创建Board对象X并分配x、total、now数组空间；初始化total和now为0；遍历所有电路板，填充x（初始顺序1..n）并计算每个网组包含的电路板总数total；设bestd初始值为m+1（密度的上界，因最大密度不可能超过网组数m）；然后调用`X.BestOrder(1, 0)`从空排列（密度0）开始搜索；最后释放动态内存并返回最优密度bestd。

### 伪代码
```cpp
// 电路板排列问题的预处理及驱动函数
int ArrangeBoards(int **B, int n, int m, int bestx[])
{
    // 返回最优排列的密度，最优排列存入bestx
    Board X;
    X.x = new int [n+1];
    X.total = new int [m+1];
    X.now = new int [m+1];
    X.B = B;
    X.n = n;
    X.m = m;
    X.bestx = bestx;
    X.bestd = m + 1;           // 初始化为最大可能密度+1

    // 初始化total和now
    for (int i = 1; i <= m; i++) {
        X.total[i] = 0;
        X.now[i] = 0;
    }

    // 初始化x并计算各网组的电路板总数
    for (int i = 1; i <= n; i++) {
        X.x[i] = i;
        for (int j = 1; j <= m; j++)
            X.total[j] += B[i][j];
    }

    // 从密度0开始搜索最优排列
    X.BestOrder(1, 0);

    delete [] X.x;
    delete [] X.total;
    delete [] X.now;
    return X.bestd;
}
```
