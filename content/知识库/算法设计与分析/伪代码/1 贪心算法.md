# 第13章 贪婪算法

## 程序13-1：货箱装船

### 问题描述
给定n个货箱，每个货箱i的重量为w[i]，货船的最大载重量为c。目标是在不超过载重量的前提下，在船上装入尽可能多的货箱（最大化装入的货箱数量）。

### 问题分析
采用贪婪算法，按货箱重量递增的顺序依次装载。每次从剩余货箱中选择重量最小的货箱装入，直到剩余容量无法容纳任何一个剩余货箱。该策略能保证装载的货箱数量最多。算法先对重量按间接寻址方式排序，需O(nlogn)时间，后续线性选择需O(n)时间，总复杂度为O(nlogn)。

### 伪代码
```cpp
template<class T>
void ContainerLoading(int x[], T w[], T c, int n)
{// 货箱装船问题的贪婪算法
 // x[i] = 1 当且仅当货箱 i 被装载，1 <= i <= n
 // c 是船的容量，w 是货箱的重量

    // 对重量按间接寻址方式排序
    // t 是间接寻址表
    int *t = new int [n+1];
    IndirectSort(w, t, n);
    // 此时，w[t[i]] <= w[t[i+1]], 1 <= i < n

    // 初始化 x
    for (int i = 1; i <= n; i++)
        x[i] = 0;

    // 按重量次序选择物品
    for (i = 1; i <= n && w[t[i]] <= c; i++) {
        x[t[i]] = 1;
        c -= w[t[i]];  // 剩余容量
    }

    delete [] t;
}
```

## 程序13-2：拓扑排序

### 问题描述
给定一个有向图，找出其顶点的一个线性排列（拓扑序列），使得对于每条有向边(i, j)，顶点i在序列中出现在顶点j之前。若不存在这样的序列（图中有环），则返回false。

### 问题分析
使用贪婪算法按从左到右的顺序构造拓扑序列。维护每个顶点的入度，将入度为0的顶点作为候选顶点存入栈中。每次从栈中取出一个顶点加入序列，并更新其邻接顶点的入度。若使用邻接矩阵，复杂度为Θ(n²)；若使用邻接链表，复杂度为Θ(n+e)。

### 伪代码
```cpp
bool Network::Topological(int v[])
{// 计算有向图中顶点的拓扑次序
 // 如果找到了一个拓扑次序，则返回 true，此时在 v[0:n-1] 中记录拓扑次序
 // 如果不存在拓扑次序，则返回 false

    int n = Vertices();

    // 计算入度
    int *InDegree = new int [n+1];
    InitializePos();  // 图遍历器数组
    for (int i = 1; i <= n; i++)  // 初始化
        InDegree[i] = 0;
    for (i = 1; i <= n; i++) {  // 从 i 出发的边
        int u = Begin(i);
        while (u) {
            InDegree[u]++;
            u = NextVertex(i);
        }
    }

    // 把入度为 0 的顶点压入堆栈
    LinkedStack<int> S;
    for (i = 1; i <= n; i++)
        if (!InDegree[i]) S.Add(i);

    // 产生拓扑次序
    i = 0;  // 数组 v 的游标
    while (!S.IsEmpty()) {  // 从堆栈中选择
        int w;  // 下一个顶点
        S.Delete(w);
        v[i++] = w;
        int u = Begin(w);
        while (u) {  // 修改入度
            InDegree[u]--;
            if (!InDegree[u]) S.Add(u);
            u = NextVertex(w);
        }
    }

    DeactivatePos();
    delete [] InDegree;
    return (i == n);
}
```

## 程序13-3：箱子函数的定义

### 问题描述
为实现二分覆盖算法中的"按New值选取顶点"操作，需要一种支持快速插入和移动的数据结构。双向链接箱子（bins）将具有相同New值的顶点组织成双向链表，支持在O(1)时间内将顶点从一个箱子移动到另一个箱子。

### 问题分析
CreateBins创建b个空箱子和n个节点；InsertBins将顶点v插入箱子b的双向链表头部；MoveBins将顶点v从其当前所在箱子移动到目标箱子。这些操作均需O(1)时间，为二分覆盖算法提供了高效的数据结构支持。

### 伪代码
```cpp
void Undirected::CreateBins(int b, int n)
{// 创建b个空箱子和n个节点
    node = new NodeType [n+1];
    bin = new int [b+1];
    // 将箱子置空
    for (int i = 1; i <= b; i++)
        bin[i] = 0;
}

void Undirected::InsertBins(int b, int v)
{// 若b不为0，则将v插入箱子b
    if (!b) return;  // b为0，不插入
    node[v].left = b;  // 添加在左端
    if (bin[b]) node[bin[b]].left = v;
    node[v].right = bin[b];
    bin[b] = v;
}

void Undirected::MoveBins(int bMax, int ToBin, int v)
{// 将顶点v从其当前所在箱子移动到ToBin
    // v的左、右节点
    int l = node[v].left;
    int r = node[v].right;

    // 从当前箱子中删除
    if (r) node[r].left = node[v].left;
    if (l > bMax || bin[l] != v)  // 不是最左节点
        node[l].right = r;
    else bin[l] = r;  // 箱子l的最左边

    // 添加到箱子ToBin
    InsertBins(ToBin, v);
}
```

## 程序13-4：构造贪婪覆盖

### 问题描述
给定一个二分图，顶点分为集合A和B，要求找出A的一个最小子集A'，使得B中每个顶点至少与A'中的一个顶点相邻（即A'覆盖B）。二分覆盖问题是NP-复杂问题，本算法采用贪婪启发式方法求解。

### 问题分析
算法逐步构造覆盖A'：每一步从A中选择能覆盖B中最多未被覆盖顶点的顶点加入A'，然后更新各顶点的New值。使用双向链接箱子维护各顶点的New值，可在O(1)时间内选出最大New值的顶点。算法总复杂度为O(n²)或O(n+e)（取决于图的描述方式）。

### 伪代码
```cpp
bool Undirected::BipartiteCover(int L[], int C[], int& m)
{// 寻找一个二分图覆盖
 // L 是输入顶点的标号，L[i] = 1 当且仅当 i 在 A 中
 // C 是一个记录覆盖的输出数组
 // 如果图中不存在覆盖，则返回 false
 // 如果图中有一个覆盖，则返回 true
 // 在 m 中返回覆盖的大小；在 C[0:m-1] 中返回覆盖

    int n = Vertices();

    // 插件结构
    int SizeOfA = 0;
    for (int i = 1; i <= n; i++)  // 确定集合 A 的大小
        if (L[i] == 1) SizeOfA++;
    int SizeOfB = n - SizeOfA;
    CreateBins(SizeOfB, n);
    int *New = new int [n+1];     // 顶点i覆盖了B中New[i]个未被覆盖的顶点
    bool *Change = new bool [n+1]; // Change[i]为true当且仅当New[i]已改变
    bool *Cov = new bool [n+1];    // Cov[i]为true当且仅当顶点i被覆盖
    InitializePos();
    LinkStack<int> S;

    // 初始化
    for (i = 1; i <= n; i++) {
        Cov[i] = Change[i] = false;
        if (L[i] == 1) {  // i 在 A 中
            New[i] = Degree(i);  // i 覆盖了这么多
            InsertBins(New[i], i);
        }
    }

    // 构造覆盖
    int covered = 0;       // 被覆盖的顶点数
    int MaxBin = SizeOfB;  // 可能非空的最大箱子
    m = 0;  // C 的游标
    while (MaxBin > 0) {  // 搜索所有箱子
        // 选择一个顶点
        if (bin[MaxBin]) {  // 箱子不空
            int v = bin[MaxBin];  // 第一个顶点
            C[m++] = v;  // 把 v 加入覆盖
            // 标记新覆盖的顶点
            int j = Begin(v), k;
            while (j) {
                if (!Cov[j]) {  // j 尚未被覆盖
                    Cov[j] = true;
                    covered++;
                    // 修改 New
                    k = Begin(j);
                    while (k) {
                        New[k]--;  // j 不计入在内
                        if (!Change[k]) {
                            S.Add(k);    // 仅入栈一次
                            Change[k] = true;
                        }
                        k = NextVertex(j);
                    }
                }
                j = NextVertex(v);
            }
            // 更新箱子
            while (!S.IsEmpty()) {
                S.Delete(k);
                Change[k] = false;
                MoveBins(SizeOfB, New[k], k);
            }
        }
        else MaxBin--;
    }

    DeactivatePos();
    DestroyBins();
    delete [] New;
    delete [] Change;
    delete [] Cov;
    return (covered == SizeOfB);
}
```

## 程序13-5：最短路径程序

### 问题描述
给定一个有向图G，每条边有一个非负长度a[i][j]，求从源顶点s到图中所有其他顶点的最短路径（Dijkstra算法）。

### 问题分析
算法按路径长度递增的顺序产生最短路径。维护数组d[i]表示当前从s到i的最短路径长度，p[i]记录路径中i的前驱顶点。每次从未到达的顶点中选择d值最小的顶点作为下一条最短路径的终点，然后更新其邻接顶点的d值。使用邻接矩阵时复杂度为O(n²)。

### 伪代码
```cpp
template<class T>
void AdjacencyWDigraph<T>::ShortestPaths(int s, T d[], int p[])
{// 寻找从顶点 s 出发的最短路径，在d中返回最短距离
 // 在p中返回前继顶点

    if (s < 1 || s > n) throw OutOfBounds();
    Chain<int> L;  // 路径可到达顶点的列表
    ChainIterator<int> l;

    // 初始化 d, p, L
    for (int i = 1; i <= n; i++) {
        d[i] = a[s][i];
        if (d[i] == NoEdge) p[i] = 0;
        else {
            p[i] = s;
            L.Insert(0, i);
        }
    }

    // 更新 d, p
    while (!L.IsEmpty()) {  // 寻找具有最小d的顶点v
        int *v = l.Initialize(L);
        int *w = l.Next();
        while (w) {
            if (d[*w] < d[*v]) v = w;
            w = l.Next();
        }

        // 从L中删除通向顶点v的下一最短路径并更新d
        int i = *v;
        L.Delete(*v);
        for (int j = 1; j <= n; j++) {
            if (a[i][j] != NoEdge && (!p[j] ||
                d[j] > d[i] + a[i][j])) {
                // 减小 d[j]
                d[j] = d[i] + a[i][j];
                // 将j加入L
                if (!p[j]) L.Insert(0, j);
                p[j] = i;
            }
        }
    }
}
```

## 程序13-6：Kruskal算法所需数据类型

### 问题描述
在Kruskal最小生成树算法中，需要按边的权值（耗费）从小到大依次选择边。EdgeNode类作为最小堆的元素和生成树数组的数据类型，封装了边的两个端点和权值。

### 问题分析
EdgeNode类重载了operator T()，使其可直接作为最小堆的元素类型，堆按照边的权值进行比较。成员u和v记录边的两个端点，weight记录边的权值。

### 伪代码
```cpp
template <class T>
class EdgeNode {
public:
    operator T() const {return weight;}
private:
    T weight;      // 边的权值
    int u, v;      // 边的端点
};
```

## 程序13-7：WNetwork类

### 问题描述
WNetwork是加权网络的虚基类，为有向加权图和无向加权图提供统一的遍历接口。在Kruskal算法中需要遍历边并获取权值，因此需要定义返回权值的遍历函数。

### 问题分析
WNetwork从Network虚基类派生，定义了纯虚函数First和Next，这两个函数不仅返回邻接顶点的编号，还返回到达该顶点的边的权值。具体实现由派生类AdjacencyWDigraph和LinkedWDigraph完成。

### 伪代码
```cpp
template<class T>
class WNetwork : virtual public Network
{
public:
    virtual void First(int i, int& j, T& c) = 0;
    virtual void Next(int i, int& j, T& c) = 0;
};
```

## 程序13-8：Kruskal算法的C++代码

### 问题描述
给定一个具有n个顶点的无向连通网络（加权图），求一棵最小耗费生成树（MST），即选择n-1条边使得所有顶点连通且边的总权值最小。

### 问题分析
Kruskal算法采用贪婪策略：按边的权值递增顺序考察每条边，若加入当前边不会形成环路，则将其选入生成树。使用最小堆选取最小耗费边（O(loge)），使用Union-Find结构（加权合并+路径压缩）检测环路。算法总复杂度为O(n + e loge)。

### 伪代码
```cpp
template<class T>
bool UNetwork<T>::Kruskal(EdgeNode<T> t[])
{// 使用Kruskal算法寻找最小耗费生成树
 // 如果不连通则返回false
 // 如果连通，则在t[0:n-2]中返回最小生成树

    int n = Vertices();
    int e = Edges();

    // 设置网络边的数组
    InitializePos();  // 图遍历器
    EdgeNode<T> *E = new EdgeNode<T>[e+1];
    int k = 0;  // E的游标
    for (int i = 1; i <= n; i++) {  // 使所有边附属于i
        int j;
        T c;
        First(i, j, c);
        while (j) {  // j 邻接自i
            if (i < j) {  // 添加到达E的边
                E[++k].weight = c;
                E[k].u = i;
                E[k].v = j;
            }
            Next(i, j, c);
        }
    }

    // 把边放入最小堆
    MinHeap<EdgeNode<T>> H(1);
    H.Initialize(E, e, e);

    UnionFind U(n);  // 合并/搜索结构

    // 根据耗费的次序来抽取边
    k = 0;  // 此时作为t的游标
    while (e && k < n - 1) {
        // 生成树未完成，尚有剩余边
        EdgeNode<T> x;
        H.DeleteMin(x);  // 最小耗费边
        e--;
        int a = U.Find(x.u);
        int b = U.Find(x.v);
        if (a != b) {  // 选择边
            t[k++] = x;
            U.Union(a, b);
        }
    }

    DeactivatePos();
    H.Deactivate();
    return (k == n - 1);
}
```
