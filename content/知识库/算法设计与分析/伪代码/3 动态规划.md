## 程序15-1：背包问题的递归函数

### 问题描述
求解0/1背包问题的动态规划递归函数。给定n个物品，每个物品i有重量w[i]和价值p[i]，背包容量为c，求装入背包的物品最大总价值。函数F(i, y)返回剩余容量为y、剩余物品为i, i+1, …, n时的最优解值f(i, y)。

### 问题分析
基于动态规划递归式(15-2)：当y ≥ w[i]时，f(i, y) = max{f(i+1, y), f(i+1, y-w[i]) + p[i]}；否则f(i, y) = f(i+1, y)。递归算法直接翻译该递推关系，但存在大量重复计算，时间复杂度为O(2ⁿ)。

### 伪代码
```cpp
int F(int i, int y)
{   // 返回 f(i, y)，即剩余容量y下物品i..n的最大价值
    if (i == n)                         // 最后一个物品
        return (y < w[n]) ? 0 : p[n];   // 容量不够则不能放入
    if (y < w[i])                       // 当前物品放不下
        return F(i + 1, y);             // 跳过当前物品
    // 取"不放"和"放"两种选择中的较大值
    return max(F(i + 1, y), F(i + 1, y - w[i]) + p[i]);
}
```

## 程序15-2：f和x的迭代计算

### 问题描述
当物品重量为整数时，用迭代方式计算0/1背包问题的所有f(i, y)值，并通过回溯确定每个物品是否装入背包。Knapsack函数计算二维数组f，Traceback函数根据f数组反推最优解x。

### 问题分析
采用自底向上的迭代方式，先初始化f[n][*]，再依次计算f[n-1][*]到f[2][*]，最后计算f[1][c]。每个f(i, y)只计算一次，避免了递归的重复计算。Knapsack时间复杂度为Θ(nc)，Traceback时间复杂度为Θ(n)。

### 伪代码
```cpp
template<class T>
void Knapsack(T p[], int w[], int c, int n, T** f)
{   // 对于所有i和y计算f[i][y]
    // 初始化 f[n][]
    for (int y = 0; y <= ymax; y++)
        f[n][y] = 0;
    for (int y = w[n]; y <= c; y++)
        f[n][y] = p[n];

    // 计算剩下的f
    for (int i = n - 1; i > 1; i--) {
        for (int y = 0; y <= ymax; y++)
            f[i][y] = f[i+1][y];          // 不放物品i
        for (int y = w[i]; y <= c; y++)
            f[i][y] = max(f[i+1][y], f[i+1][y-w[i]] + p[i]);  // 取最大值
    }
    // 计算f[1][c]
    f[1][c] = f[2][c];
    if (c >= w[1])
        f[1][c] = max(f[1][c], f[2][c-w[1]] + p[1]);
}

template<class T>
void Traceback(T **f, int w[], int c, int n, int x[])
{   // 根据f数组回溯计算最优解x
    for (int i = 1; i < n; i++)
        if (f[i][c] == f[i+1][c])
            x[i] = 0;                     // 物品i未装入
        else {
            x[i] = 1;                     // 物品i已装入
            c -= w[i];                    // 剩余容量减少
        }
    x[n] = (f[n][c]) ? 1 : 0;             // 最后一个物品
}
```

## 程序15-3：递归计算s、kay及最优合并

### 问题描述
在图像压缩问题中，将n个像素段合并为若干段，以最小化存储空间。每个段有段长l[i]和像素位数b[i]，每段标题需header位，段长不超过L（256）。递归函数S(i)返回前i段最优合并所需空间s[i]，并记录kay[i]为取得最小值时的合并段数。Traceback根据kay值输出合并方案。

### 问题分析
利用动态规划递归式(15-3)：s[i] = min{s[i-k] + lsum(i-k+1,i) * bmax(i-k+1,i)} + header，其中1≤k≤i且lsum≤L。递归求解时存在大量重复计算，时间复杂度为O(2ⁿ)。Traceback时间复杂度为Θ(n)。

### 伪代码
```cpp
int S(int i)
{   // 返回S(i)并计算kay[i]
    if (i == 0) return 0;
    // k=1时，根据公式(15-3)计算最小值
    int lsum = l[i], bmax = b[i];
    int s = S(i-1) + lsum * bmax;
    kay[i] = 1;
    // 对其余的k计算最小值并更新
    for (int k = 2; k <= i && lsum + l[i-k+1] <= L; k++) {
        lsum += l[i-k+1];
        if (bmax < b[i-k+1]) bmax = b[i-k+1];
        int t = S(i-k);
        if (s > t + lsum * bmax) {
            s = t + lsum * bmax;
            kay[i] = k;
        }
    }
    return s + header;
}

void Traceback(int kay[], int n)
{   // 输出最优合并的段划分
    if (n == 0) return;
    Traceback(kay, n - kay[n]);
    cout << "New segment begins at " << (n - kay[n] + 1) << endl;
}
```

## 程序15-4：避免重复计算的递归算法

### 问题描述
对程序15-3的改进，使用全局数组s保存已计算过的s[i]值，避免递归过程中的重复计算。同样计算图像压缩中的最优合并空间消耗s[i]和对应的kay[i]。

### 问题分析
在递归计算s[i]之前，先检查s[i]是否已计算（s[i] > 0），若已计算则直接返回，避免重复递归。通过分期分析方法可得时间复杂度为Θ(n)。

### 伪代码
```cpp
int S(int i)
{   // 计算S(i)和kay[i]，避免重复计算
    if (i == 0) return 0;
    if (s[i] > 0) return s[i];         // 已计算过，直接返回

    // 首先根据公式(15-3)计算k=1时最小值
    int lsum = l[i], bmax = b[i];
    s[i] = S(i-1) + lsum * bmax;
    kay[i] = 1;
    // 对其余的k计算最小值并更新
    for (int k = 2; k <= i && lsum + l[i-k+1] <= L; k++) {
        lsum += l[i-k+1];
        if (bmax < b[i-k+1]) bmax = b[i-k+1];
        int t = S(i-k);
        if (s[i] > t + lsum * bmax) {
            s[i] = t + lsum * bmax;
            kay[i] = k;
        }
    }
    s[i] += header;
    return s[i];
}
```

## 程序15-5：迭代计算s和kay

### 问题描述
用迭代方式计算图像压缩问题的最优合并空间s[i]和对应的kay[i]。按i=1到n的顺序依次计算，确保计算s[i]时所有s[j]（j<i）均已就绪。Traceback函数同程序15-3。

### 问题分析
迭代法依序计算s[1]到s[n]，每个s[i]的计算需要检查最多L种合并方式。由于L为常数256，每个s[i]的计算时间为O(1)，总时间复杂度为Θ(n)。迭代程序不需要递归栈空间，比递归方式更快。

### 伪代码
```cpp
void Vbits(int l[], int b[], int n, int s[], int kay[])
{   // 计算s[i]和kay[i]
    int L = 256, header = 11;
    s[0] = 0;
    // 根据式(15-3)依次计算s[i]
    for (int i = 1; i <= n; i++) {
        // k=1时，计算最小值
        int lsum = l[i], bmax = b[i];
        s[i] = s[i - 1] + lsum * bmax;
        kay[i] = 1;
        // 对其余的k计算最小值并更新
        for (int k = 2; k <= i && lsum + l[i - k + 1] <= L; k++) {
            lsum += l[i - k + 1];
            if (bmax < b[i - k + 1]) bmax = b[i - k + 1];
            if (s[i] > s[i-k] + lsum * bmax) {
                s[i] = s[i-k] + lsum * bmax;
                kay[i] = k;
            }
        }
        s[i] += header;
    }
}
```

## 程序15-6：递归计算c(i,j)和kay(i,j)

### 问题描述
在矩阵乘法链问题中，给定q个矩阵M₁×M₂×⋯×Mq，其中Mi的维度为r[i]×r[i+1]，求计算该乘积的最优乘法顺序（即加括号方式）。函数C(i,j)返回计算Mᵢⱼ的最小消耗c(i,j)，并记录kay[i][j]为最优划分点。Traceback根据kay值输出乘法顺序。

### 问题分析
动态规划递归式：c(i,i)=0；c(i,i+1)=r[i]*r[i+1]*r[i+2]；当s>1时，c(i,i+s)=min{c(i,k)+c(k+1,i+s)+r[i]*r[k+1]*r[i+s+1]}，其中i≤k<i+s。递归直接实现该递推关系，但存在大量重复计算，时间复杂度为O(2^q)。Traceback时间复杂度为Θ(q)。

### 伪代码
```cpp
int C(int i, int j)
{   // 返回c(i,j)并计算kay[i][j]
    if (i == j) return 0;                    // 单个矩阵，消耗为0
    if (i == j - 1) {                        // 两个矩阵，直接相乘
        kay[i][i + 1] = i;
        return r[i] * r[i + 1] * r[i + 2];
    }
    // 多于两个矩阵的情形
    // 设u为k=i时的最小值
    int u = C(i, i) + C(i + 1, j) + r[i] * r[i + 1] * r[j + 1];
    kay[i][j] = i;
    // 计算其余k值对应的消耗并更新最小值
    for (int k = i + 1; k < j; k++) {
        int t = C(i, k) + C(k + 1, j) + r[i] * r[k + 1] * r[j + 1];
        if (t < u) {                         // 找到更小的消耗
            u = t;
            kay[i][j] = k;
        }
    }
    return u;
}

void Traceback(int i, int j, int **kay)
{   // 输出计算Mij的最优乘法顺序
    if (i == j) return;
    Traceback(i, kay[i][j], kay);            // 递归输出左半部分
    Traceback(kay[i][j] + 1, j, kay);        // 递归输出右半部分
    cout << "Multiply M" << i << ", " << kay[i][j];
    cout << " and M" << (kay[i][j] + 1) << ", " << j << endl;
}
```

## 程序15-7：无重复计算的c(i,j)计算方法

### 问题描述
对程序15-6的改进，使用全局数组c[][]保存已计算过的c(i,j)值，避免递归过程中的重复计算。同样计算矩阵乘法链的最优消耗c(i,j)和划分点kay[i][j]。

### 问题分析
在递归计算c(i,j)之前，先检查c[i][j]是否已计算（c[i][j] > 0），若已计算则直接返回。通过分期分析方法，每个c(i,j)仅计算一次，而每个c(i,j)的计算需要O(s)时间（s=j-i），总时间复杂度为Θ(q³)。

### 伪代码
```cpp
int C(int i, int j)
{   // 返回c(i,j)并计算kay[i][j]，避免重复计算
    if (c[i][j] > 0) return c[i][j];        // 已计算过，直接返回

    if (i == j) return 0;                    // 单个矩阵
    if (i == j - 1) {                        // 两个矩阵
        kay[i][i + 1] = i;
        c[i][j] = r[i] * r[i + 1] * r[i + 2];
        return c[i][j];
    }
    // 多于两个矩阵的情形
    // 设u为k=i时的最小值
    int u = C(i, i) + C(i + 1, j) + r[i] * r[i + 1] * r[j + 1];
    kay[i][j] = i;
    // 计算其余k值对应的消耗并更新最小值
    for (int k = i + 1; k < j; k++) {
        int t = C(i, k) + C(k + 1, j) + r[i] * r[k + 1] * r[j + 1];
        if (t < u) {                         // 找到更小的消耗
            u = t;
            kay[i][j] = k;
        }
    }
    c[i][j] = u;
    return u;
}
```

## 程序15-8：c和kay的迭代计算

### 问题描述
用迭代方式计算矩阵乘法链问题中所有c(i,j)和kay(i,j)。按s=2,3,…,q-1的顺序依次计算c(i,i+s)，确保计算每个c(i,j)时其依赖的子问题均已就绪。

### 问题分析
先初始化c[i][i]=0和c[i][i+1]=r[i]*r[i+1]*r[i+2]及对应的kay值。然后按区间长度s从小到大依次计算。对每个c[i][i+s]，遍历所有可能的划分点k（i≤k<i+s）取最小值。三层循环总时间复杂度为Θ(q³)。

### 伪代码
```cpp
// 为所有的Mij计算耗费c和划分点kay
// 初始化c[i][i]、c[i][i+1]和kay[i][i+1]
for (int i = 1; i < q; i++) {
    c[i][i] = 0;
    c[i][i+1] = r[i] * r[i+1] * r[i+2];
    kay[i][i+1] = i;
}
c[q][q] = 0;

// 按区间长度从小到大计算余下的c和kay
for (int s = 2; s < q; s++)                         // 区间长度
    for (int i = 1; i <= q - s; i++) {               // 区间起点
        // k=i时的最小项
        c[i][i+s] = c[i][i] + c[i+1][i+s] + r[i] * r[i+1] * r[i+s+1];
        kay[i][i+s] = i;

        // 遍历其余可能的划分点k
        for (int k = i+1; k < i + s; k++) {
            int t = c[i][k] + c[k+1][i+s] + r[i] * r[k+1] * r[i+s+1];
            if (t < c[i][i+s]) {                     // 找到更小的消耗
                c[i][i+s] = t;
                kay[i][i+s] = k;
            }
        }
    }
```

## 程序15-9：c和kay的计算

### 问题描述
在有向图中寻找所有点对之间的最短路径（Floyd-Warshall算法）。给定n个顶点的有向图G，邻接矩阵为a，函数AllPairs计算所有顶点对(i,j)之间的最短路径长度c[i][j]和路径中最大中间顶点kay[i][j]。

### 问题分析
动态规划递归式：c(i,j,k)=min{c(i,j,k-1), c(i,k,k-1)+c(k,j,k-1)}，其中c(i,j,k)表示从i到j且中间顶点编号不超过k的最短路径长度。通过迭代方式依次增加k，最终c(i,j)=c(i,j,n)即为最短路径长度。时间复杂度为Θ(n³)。

### 伪代码
```cpp
template<class T>
void AdjacencyWDigraph<T>::AllPairs(T **c, int **kay)
{   // 所有点对的最短路径
    // 对于所有i和j，计算c[i][j]和kay[i][j]
    // 初始化c[i][j]=c(i,j,0)
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++) {
            c[i][j] = a[i][j];              // 初始化为直接边长度
            kay[i][j] = 0;                  // 无中间顶点
        }
    for (int i = 1; i <= n; i++)
        c[i][i] = 0;                        // 自身到自身距离为0

    // 依次考虑每个顶点k作为中间顶点
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++) {
                T t1 = c[i][k];
                T t2 = c[k][j];
                T t3 = c[i][j];
                // 若经过k的路径更短，则更新
                if (t1 != NoEdge && t2 != NoEdge &&
                    (t3 == NoEdge || t1 + t2 < t3)) {
                    c[i][j] = t1 + t2;
                    kay[i][j] = k;          // 记录中间顶点
                }
            }
}
```

## 程序15-10：输出最短路径

### 问题描述
根据程序15-9计算得到的kay数组，输出从顶点i到顶点j的最短路径所经过的顶点序列。

### 问题分析
利用kay[i][j]存储的中间顶点信息递归构造路径：若kay[i][j]==0，则i到j为直接边，输出j；否则递归输出i到kay[i][j]的路径和kay[i][j]到j的路径。输出一条最短路径的时间复杂度为O(n)。

### 伪代码
```cpp
void outputPath(int **kay, int i, int j)
{   // 输出从i到j的路径的实际代码
    if (i == j) return;
    if (kay[i][j] == 0)
        cout << j << ' ';                   // 直接相连，输出终点
    else {
        outputPath(kay, i, kay[i][j]);      // 递归输出前半段
        outputPath(kay, kay[i][j], j);      // 递归输出后半段
    }
}

template<class T>
void OutputPath(T **c, int **kay, T NoEdge, int i, int j)
{   // 输出从i到j的最短路径（带路径存在性检查）
    if (c[i][j] == NoEdge) {
        cout << "There is no path from " << i << " to " << j << endl;
        return;
    }
    cout << "The path is" << endl;
    cout << i << ' ';
    outputPath(kay, i, j);
    cout << endl;
}
```

## 程序15-11：寻找最大无交叉子集

### 问题描述
给定一个布线通道，顶部有n个针脚，底部有n个针脚，连接关系由排列C（C[i]为顶部针脚i连接的底部针脚编号）给出。求一个最大无交叉子集（MNS），使得该子集中任意两个网组(i,C[i])和(j,C[j])不相交，即可布设在同一层。

### 问题分析
动态规划递归式：size(1,j)=0（j<C[1]）或1（j≥C[1]）；对于i>1，若j<C[i]则size(i,j)=size(i-1,j)；否则size(i,j)=max{size(i-1,j), size(i-1,C[i]-1)+1}。函数MNS用二维数组size[][]迭代计算所有size(i,j)，时间复杂度为Θ(n²)。Traceback根据size数组回溯找出MNS中的网组，时间复杂度为Θ(n)。总时间复杂度为Θ(n²)。

### 伪代码
```cpp
void MNS(int C[], int n, int **size)
{   // 对于所有的i和j，计算size[i][j]
    // 初始化size[1][*]
    for (int j = 0; j < C[1]; j++)
        size[1][j] = 0;                     // 底部针脚小于C[1]，网组1不在MNS中
    for (int j = C[1]; j <= n; j++)
        size[1][j] = 1;                     // 底部针脚不小于C[1]，网组1在MNS中

    // 计算size[i][*], 1 < i < n
    for (int i = 2; i < n; i++) {
        for (int j = 0; j < C[i]; j++)
            size[i][j] = size[i-1][j];      // 网组i无法放入
        for (int j = C[i]; j <= n; j++)
            // 取"不选i"和"选i"中的较大值
            size[i][j] = max(size[i-1][j], size[i-1][C[i]-1] + 1);
    }
    // 处理最后一个网组
    size[n][n] = max(size[n-1][n], size[n-1][C[n]-1] + 1);
}

void Traceback(int C[], int **size, int n, int Net[], int &m)
{   // 在Net[0:m-1]中返回最大无交叉子集中的网组编号
    int j = n;    // 当前允许的最大底部针脚编号
    m = 0;        // 网组计数器
    for (int i = n; i > 1; i--)
        // 判断网组i是否在MNS中
        if (size[i][j] != size[i-1][j]) {   // 网组i属于MNS
            Net[m++] = i;
            j = C[i] - 1;                   // 更新底部针脚上限
        }
    // 判断网组1是否在MNS中
    if (j >= C[1])
        Net[m++] = 1;
}
```
