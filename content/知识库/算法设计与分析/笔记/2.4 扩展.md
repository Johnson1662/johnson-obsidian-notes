**分治效率关键**：子问题规模平衡（如 n/2）显著影响性能。

**矩阵乘法突破**：分治降低指数（O(n^3) \to O(n^{2.373})），但 O(n^2) 仍是开放问题。

**排序算法对比**：

| 算法     | 最坏复杂度    | 平均复杂度    | 是否稳定 |
| -------- | ------------- | ------------- | -------- |
| 归并排序 | $O(n \log n)$ | $O(n \log n)$ | 是       |
| 快速排序 | $O(n^2)$      | $O(n \log n)$ | 否       |
| 堆排序   | $O(n \log n)$ | $O(n \log n)$ | 否       |

**可以思考一下逆序对问题**：修改归并排序，合并时统计跨子数组逆序对，复杂度 $O(n \log n)$.
