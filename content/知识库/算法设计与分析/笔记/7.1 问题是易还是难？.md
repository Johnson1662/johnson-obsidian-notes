### 1. 易解问题 (Tractable Problems)

- **定义**：如果某问题存在一个多项式时间复杂度的求解算法，则称该问题为易解（计算）问题。
  - 求解算法的上界是多项式界，例如 log(n), n log(n), n² 等。
- **例子**：
  - 排序问题：$O(n log n)$
  - 查找图中任意两个节点的最短路径问题：$O(n³)$（flyod法）
  - 计算整数的完全平方根问题：$O(log n)$
- **注意**：
  - 这类问题复杂性的上界约束只适用于合理的输入实例尺寸。
  - 某些问题当前不是易解的问题，不排除将来可能会变为易解问题（例如，素数检验问题）。

### 什么是合理的输入实例尺寸？

问题的*“合理性”*取决于期望的输出与输入的关系。例如：

- 在《算法》教材里查找含有”NP问题”的段落 (易解)
- 在整个互联网里查找含有”NP问题”的网页 (可能难解，取决于规模)

### 2. 难解问题 (Intractable Problems)

- **定义**：指的是不存在多项式界求解算法的问题。即求解该问题算法的复杂性至少是指数级的。
- **典型的例子包括**：
  - **问题本身的输出是输入实例大小的超多项式函数**：
    - 组合问题：输出n个不同符号的所有组合 $O(2ⁿ)$
    - 排列问题：输出n个不同符号的所有排列 $O(n!)$
    - 汉诺塔问题：输出n个圆盘的移动步骤O$(2ⁿ - 1)$
  - **有些问题，尽管不需要超出多项式界的输出，但仍然无法找到求解的多项式界算法**：
    - 0/1背包问题
    - 旅行商问题 (TSP)
    - 查找完全子图问题 (Clique Problem)
- **素数检验问题**：
  - 穷举法具有伪多项式界的复杂性。
  - 2004年，AKS算法被提出，其复杂性是n的位数的多项式函数，证明了素数检验是P类问题。

### 3. 不可解问题 (Unsolvable Problems)

- **定义**：指的是不能被确定型图灵机求解的计算问题，即不存在任何算法能够求解的计算问题。
- **停机问题 (Halting Problem)**：判断任意一个程序P对于任意输入I是否能在有限的时间之内结束运行。
  - **判定问题描述**：是否存在一个程序H，对于任意输入的程序P和输入I，能够判断P(I)会在有限时间内结束或者死循环。
  - **证明思路**：艾伦·图灵在1936年用对角论证法证明了不存在解决停机问题的通用算法。
    - 假设存在 halt(P, I) 算法。
    - 构造程序 Z(P):

```plain text
Z(P) {
  if halt(P, P) then
    loop forever; // 死循环
  else
    halt; // 停机
}
```

        - 考虑 Z(Z) 是否停机：
            - 若 Z(Z) 停机，则 halt(Z, Z) 为真，根据 Z 的定义，Z(Z) 应进入死循环。矛盾。
            - 若 Z(Z) 死循环，则 halt(Z, Z) 为假，根据 Z 的定义，Z(Z) 应停机。矛盾。
        - 因此，halt(P, I) 不存在，停机问题是不可解的。

- **其他不可计算问题**：程序等价性问题、断言验证问题、定理识别问题。

---

### 小结：问题分类

- **观察视角**：计算复杂性。
- **判别原则**：
  - 难易：是否存在多项式界算法。
  - 不可解：可计算性理论证明。
- **判别方法**：
  - 存在性（易解）：举例构造多项式算法。
  - 不存在性（难解/不可解）：反证法，归约。
