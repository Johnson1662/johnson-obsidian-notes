# 第 2 章 递归法

---

## 1. 本章概述

递归法是一种通过将原问题逐步分解为规模更小、结构相同的子问题来求解的算法设计方法。本章主要学习如何建立递归方程（递归关系式），以及如何使用 **代入法、递归树法、Master 定理** 分析递归算法的时间复杂度，并通过 **Hanoi 塔问题** 等经典案例理解递归的执行过程。

| **适用问题** | 适用于那些可以被分解为**规模较小但类型相同**的子问题的情况，且存在明确的停止计算的边界条件，如阶乘计算、斐波那契数列和汉诺塔问题                    |
| -------- | ------------------------------------------------------------------------------------- |
| **核心思想** | 通过函数**直接或间接地调用自身**，将大问题转化为子问题求解。递归由**递归方程**（描述问题如何分解）和**边界条件**（定义非递归的初值，防止无限循环）两个要素组成 |

---

## 2. 知识点讲解

### 2.1 递归的基本概念

**通俗定义**：递归就是一个函数在它的定义中调用它自己。每一次调用处理一个更小（更简单）的版本，直到遇到最简单的情况（称为"递归基"或"基准情形"）为止。

**三个要素**：

1. **递归基（Base Case）**——最小规模的子问题，能够直接求解，不再递归调用。
2. **递归步骤（Recursive Step）**——将原问题分解为更小规模的同类子问题，并调用自身去求解。
3. **递推关系（Recurrence Relation）**——描述原问题规模 $n$ 的解与子问题规模解之间的数学关系。

**一般形式**：

$$
T(n) = a\,T\!\left(\frac{n}{b}\right) + f(n)
$$

其中：
- $n$ 是问题规模，
- $a$ 是子问题的个数（每次分解产生 $a$ 个子问题），
- $b$ 是每次分解后子问题的规模缩小倍数（每个子问题的规模约为 $n/b$），
- $f(n)$ 是分解与合并的开销。

**举例**：阶乘函数

$$
\text{fact}(n) = \begin{cases}
1, & n = 0 \quad (\text{递归基}) \\[4pt]
n \times \text{fact}(n-1), & n > 0 \quad (\text{递归步骤})
\end{cases}
$$

- 计算 $\text{fact}(3)$ 的执行过程：
  - $\text{fact}(3) = 3 \times \text{fact}(2)$
  - $\text{fact}(2) = 2 \times \text{fact}(1)$
  - $\text{fact}(1) = 1 \times \text{fact}(0)$
  - $\text{fact}(0) = 1$（递归基，开始返回）
  - 逐层回代：$\text{fact}(0)=1 \to \text{fact}(1)=1 \to \text{fact}(2)=2 \to \text{fact}(3)=6$

**初学易错点**：
- ❌ **缺少递归基**：函数会无限递归，最终栈溢出。
- ❌ **递归参数不收敛于基**：每次调用问题规模没有减小，导致死循环。
- ❌ **认为递归效率一定低**：递归是"设计思想"，效率取决于具体实现（如尾递归可优化为迭代）。

---

### 2.2 递归方程的建立

将递归算法的执行时间表达为递归方程（递推式），是分析递归复杂度的第一步。

**步骤**：

1. 确定递归基的时间复杂度（通常是常数 $O(1)$）。
2. 写出递归步骤的时间开销：分解开销 + 子问题求解时间 + 合并开销。
3. 将上述关系表示成数学方程。

**举例**：二分查找（Binary Search）

```
binarySearch(arr, left, right, target):
    if left > right:                    // 递归基
        return -1
    mid = (left + right) // 2           // 分解（O(1)）
    if arr[mid] == target:
        return mid
    elif target < arr[mid]:
        return binarySearch(arr, left, mid-1, target)  // 1个子问题，规模 n/2
    else:
        return binarySearch(arr, mid+1, right, target) // 1个子问题，规模 n/2
```

递归方程：

$$
T(n) = T\!\left(\frac{n}{2}\right) + O(1)
$$

其中 $O(1)$ 是计算 mid 和比较的开销。

**初学易错点**：
- ❌ **混淆 $a$ 和 $b$**：$a$ 是子问题个数，$b$ 是规模缩小倍数。例如二分查找 $a=1$（只查一边）、$b=2$（规模减半）。
- ❌ **忽略递归基**：$T(1)=O(1)$ 是分析的边界条件，不能省略。

---

### 2.3 Master 定理（主方法）

Master 定理用于求解形如 $T(n) = a\,T(n/b) + f(n)$ 的递归方程，其中 $a \ge 1$，$b > 1$，$f(n)$ 是渐近正函数。

**定理内容**：

比较 $f(n)$ 与 $n^{\log_b a}$ 的大小关系，可分为三种情况：

1. **情况一**：$f(n) = O\!\left(n^{\log_b a - \varepsilon}\right)$（$\varepsilon > 0$），即 $f(n)$ 的增长慢于 $n^{\log_b a}$
   $$
   T(n) = \Theta\!\left(n^{\log_b a}\right)
   $$

2. **情况二**：$f(n) = \Theta\!\left(n^{\log_b a}\right)$，即 $f(n)$ 与 $n^{\log_b a}$ 增长相同
   $$
   T(n) = \Theta\!\left(n^{\log_b a} \log n\right)
   $$

3. **情况三**：$f(n) = \Omega\!\left(n^{\log_b a + \varepsilon}\right)$（$\varepsilon > 0$）且满足**正则性条件** $a\,f(n/b) \le c\,f(n)$（$c<1$），即 $f(n)$ 的增长快于 $n^{\log_b a}$
   $$
   T(n) = \Theta\!\big(f(n)\big)
   $$

**直观理解**：比较 $f(n)$（分解合并开销）与 $n^{\log_b a}$（子问题的总工作量）的"增长速度"，哪个增长更快就由哪个主导复杂度。

**举例**：
- $T(n) = 4T(n/2) + n$：$\log_b a = \log_2 4 = 2$，$f(n)=n = O(n^{2-\varepsilon})$，情况一，$T(n)=\Theta(n^2)$。
- $T(n) = 4T(n/2) + n^2$：$\log_b a = 2$，$f(n)=n^2 = \Theta(n^2)$，情况二，$T(n)=\Theta(n^2 \log n)$。
- $T(n) = 4T(n/2) + n^3$：$\log_b a = 2$，$f(n)=n^3 = \Omega(n^{2+\varepsilon})$，情况三，$T(n)=\Theta(n^3)$。

**初学易错点**：
- ❌ **Master 定理不适用于所有递归方程**——当 $f(n)$ 不属于多项式可比时（如 $f(n) = n \log n$ 虽介于情况一与情况二之间但仍可用情况二的扩展），或 $a$、$b$ 不是常数时，不能直接套用。
- ❌ **忘记检查正则性条件**：情况三要求 $a\,f(n/b) \le c\,f(n)$，不满足时 Master 定理失效。
- ❌ **将 $\log_b a$ 中的 $b$ 与对数底数混淆**：$\log_b a$ 是数学表达式，底数为 $b$。

### 2.4 递归树法

**通俗定义**：将递归方程画成一棵树——每个节点代表一层递归调用的开销，各层开销之和就是总时间复杂度。

**步骤**：

1. 画出递归树：根节点为 $f(n)$，每个子节点为下一层递归的 $f(n/b)$。
2. 计算每一层的总开销。
3. 计算树的高度（递归深度）。
4. 将所有层的开销相加。

**举例**：$T(n) = 2T(n/2) + n$

- 第 0 层（根）：开销 $n$
- 第 1 层：2 个节点，每个开销 $n/2$，总开销 $n$
- 第 2 层：4 个节点，每个开销 $n/4$，总开销 $n$
- ...
- 第 $k$ 层：$2^k$ 个节点，每个开销 $n/2^k$，总开销 $n$
- 树的高度：$\log_2 n$ 层
- 总开销：$n \times (\log_2 n + 1) = \Theta(n \log n)$

**初学易错点**：
- ❌ **忽略叶子节点（递归基）的开销**：到了叶子层（规模为 1），每个叶子是 $O(1)$，叶子数量可能很多，不能忽略。
- ❌ **求和时忘记乘层数或节点数**：每层可能有多个节点，要乘以节点数。

---

### 2.5 代入法（Guess and Verify）

**通俗定义**：先猜测一个上界（或下界），然后用数学归纳法证明猜测正确。

**步骤**：

1. **猜测** $T(n)$ 的渐近形式（如 $O(n \log n)$）。
2. **假设** 对所有小于 $n$ 的规模猜测成立。
3. **代入** 递归方程，证明对规模 $n$ 也成立。
4. **确定常数** 使不等式成立。

**举例**：$T(n) = 2T(\lfloor n/2 \rfloor) + n$

- **猜测**：$T(n) = O(n \log n)$，即存在 $c>0$ 使 $T(n) \le c n \log n$。
- **归纳假设**：对 $\lfloor n/2 \rfloor$，有 $T(\lfloor n/2 \rfloor) \le c \lfloor n/2 \rfloor \log(\lfloor n/2 \rfloor)$。
- **代入**：
  $$
  \begin{aligned}
  T(n) &\le 2 \left(c \frac{n}{2} \log \frac{n}{2}\right) + n \\
       &= c n (\log n - \log 2) + n \\
       &= c n \log n - c n + n \\
       &= c n \log n - (c - 1)n
  \end{aligned}
  $$
- 取 $c \ge 1$，则 $-(c-1)n \le 0$，得 $T(n) \le c n \log n$，归纳成立。

**初学易错点**：
- ❌ **猜测方向错误**：证明上界用"$\le$"，证明下界用"$\ge$"，不要混淆。
- ❌ **忘记处理取整**：实际递归中 $n/2$ 有取整，代入法通常忽略取整，但要确认不影响渐近结果。
- ❌ **归纳步骤中常数选择不当**：需要保留足够的自由度来消去额外项。

### 2.6 Hanoi 塔问题

**问题描述**：有三根柱子 A、B、C。A 上有 $n$ 个大小不等的圆盘，按大小顺序叠放（大盘在下，小盘在上）。目标：将所有圆盘从 A 移到 C，每次只能移动一个盘，且任何时候大盘不能放在小盘上面。

**递归解法**：

```
Hanoi(A, C, n):
    if n == 1:
        move(A → C)
    else:
        Hanoi(A, B, n-1)   // 将 n-1 个盘从 A 移到 B（借助 C）
        move(A → C)          // 将最大的盘从 A 移到 C
        Hanoi(B, C, n-1)   // 将 n-1 个盘从 B 移到 C（借助 A）
```

**递归方程**：

$$
T(n) = 2\,T(n-1) + 1
$$

- $T(1) = 1$
- 求解：$T(n) = 2^n - 1$

**为什么是 $2^n - 1$？**
- 每次移动 $n$ 个盘子需要：先把 $n-1$ 个盘子移到辅助柱（$T(n-1)$ 步），再移动最大盘（1 步），最后把 $n-1$ 个盘子移到目标柱（$T(n-1)$ 步）。
- $T(n) = 2T(n-1) + 1$；迭代展开：
  $$
  \begin{aligned}
  T(n) &= 2T(n-1) + 1 \\
       &= 2(2T(n-2) + 1) + 1 = 4T(n-2) + 2 + 1 \\
       &= 2^k T(n-k) + (2^{k} - 1) \\
       &= 2^{n-1} T(1) + (2^{n-1} - 1) = 2^{n-1} + 2^{n-1} - 1 = 2^n - 1
  \end{aligned}
  $$

**初学易错点**：
- ❌ **混淆柱子角色**：每次递归调用中，源柱、目标柱、辅助柱的角色都会变化，不要死记柱子的物理编号，而要理解"从哪里搬到哪里、借助哪根"。
- ❌ **认为 $T(n)$ 的规模参数是减半**：Hanoi 问题的 $n$ 是逐次减 1（$n-1$），而不是除以常数 $b$，因此不能使用 Master 定理，而是用迭代法求解。

---

### 2.7 递归的时间复杂度总结

常见递归方程及其解（熟记）：

| 递归方程 | 复杂度 | 典型算法 |
|---|---|---|
| $T(n) = T(n-1) + O(1)$ | $\Theta(n)$ | 线性递归（如遍历链表） |
| $T(n) = T(n-1) + O(n)$ | $\Theta(n^2)$ | 选择排序 |
| $T(n) = 2T(n-1) + O(1)$ | $\Theta(2^n)$ | Hanoi 塔 |
| $T(n) = T(n/2) + O(1)$ | $\Theta(\log n)$ | 二分查找 |
| $T(n) = 2T(n/2) + O(1)$ | $\Theta(n)$ | 二叉树遍历 |
| $T(n) = 2T(n/2) + O(n)$ | $\Theta(n \log n)$ | 归并排序、快速排序（平均） |
| $T(n) = T(n/2) + O(n)$ | $\Theta(n)$ | 未优化的分治 |

### 例题 1（来源：[Q0044]）

**题目**：
应用 Master 方法解递归方程：
$$
T(n) = 5\,T\!\left(\frac{n}{5}\right) + n \log n
$$

**解答**：

**第一步**：写出标准形式 $T(n) = a\,T(n/b) + f(n)$，确定参数。

从方程可得：
- $a = 5$（每次分解产生 5 个子问题）
- $b = 5$（每个子问题规模缩小到原来的 $1/5$）
- $f(n) = n \log n$（分解和合并的开销）

**第二步**：计算 $\log_b a$。

$$
\log_b a = \log_5 5 = 1
$$

因此 $n^{\log_b a} = n^{1} = n$。

**第三步**：比较 $f(n)$ 与 $n^{\log_b a}$ 的增长速度。

$$
f(n) = n \log n, \quad n^{\log_b a} = n
$$

问题转化为：$n \log n$ 与 $n$ 相比，增长速度如何？

我们可以写成：
$$
f(n) = n \log n = n \cdot \log n = n^{\log_b a} \cdot \log n
$$

这属于**情况二的扩展**——当 $f(n) = \Theta(n^{\log_b a} \log^k n)$（$k \ge 0$）时，有：
$$
T(n) = \Theta(n^{\log_b a} \log^{k+1} n)
$$

这里 $f(n) = n \log n = n^{1} \log^{1} n$，对应 $k = 1$。

**第四步**：代入公式得到结果。

$$
T(n) = \Theta(n \log^2 n)
$$

**解析**：
- Master 定理的三种基本情况覆盖了 $f(n)$ 与 $n^{\log_b a}$ 的多项式比较（差一个 $n^\varepsilon$ 因子）。
- 当 $f(n) = n^{\log_b a} \log^k n$ 时，属于情况二的扩展形式。此时 $T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$。
- 本题中，$f(n) = n \log n$ 与 $n^{\log_b a} = n$ 的比值是 $\log n$，它增长慢于任何 $n^\varepsilon$（$\varepsilon > 0$），所以不属于情况一或情况三，而属于情况二的扩展。
- 另一种思路：用递归树。根节点开销 $n \log n$，下一层 5 个子节点每个开销 $(n/5) \log(n/5)$，总开销 $n \log(n/5)$。随层数增加，总开销逐层递减（因为 $\log(n/5) < \log n$），但层数为 $\log_5 n$。对各层求和后可得到 $\Theta(n \log^2 n)$。

### 例题 2（来源：[Q0047]）

**题目**：
分析求解 Hanoi 问题的算法的渐近复杂度：
```txt
void Hanoi(A, C, n) {
    if n == 1
        move(A, C);
    else {
        Hanoi(A, B, n - 1);
        move(A, C);
        Hanoi(B, C, n - 1);
    }
}
```

**解答**：

**第一步**：写出递归方程。

- 当 $n = 1$ 时，只需一次移动，$T(1) = 1$。
- 当 $n > 1$ 时：
  - 先将 $n-1$ 个盘子从 A 移到 B（借助 C）：需要 $T(n-1)$ 步。
  - 将最大的盘子从 A 直接移到 C：需要 1 步。
  - 再将 $n-1$ 个盘子从 B 移到 C（借助 A）：需要 $T(n-1)$ 步。

所以递归方程为：
$$
T(n) = \begin{cases}
1, & n = 1 \\[4pt]
2\,T(n-1) + 1, & n > 1
\end{cases}
$$

**第二步**：迭代展开求解。

$$
\begin{aligned}
T(n) &= 2\,T(n-1) + 1 \\
     &= 2\big(2\,T(n-2) + 1\big) + 1 \\
     &= 4\,T(n-2) + 2 + 1 \\
     &= 2^2\,T(n-2) + (2^2 - 1) \\
     &\quad \vdots \\
     &= 2^k\,T(n-k) + (2^k - 1)
\end{aligned}
$$

当 $n-k = 1$ 即 $k = n-1$ 时代入 $T(1) = 1$：

$$
\begin{aligned}
T(n) &= 2^{n-1} \cdot T(1) + (2^{n-1} - 1) \\
     &= 2^{n-1} + 2^{n-1} - 1 \\
     &= 2^n - 1
\end{aligned}
$$

**第三步**：得到渐近复杂度。

$$
T(n) = 2^n - 1 \quad \Rightarrow \quad T(n) = \Theta(2^n)
$$

Hanoi 问题的时间复杂度是指数级的 $\Theta(2^n)$。

**解析**：
- Hanoi 问题的递归方程 $T(n) = 2T(n-1) + 1$ 的规模参数是逐次减 1（$n-1$），而不是除以常数 $b$，因此**不能使用 Master 定理**。必须用迭代法（展开法）求解。
- 从代码结构上看，$n$ 个盘子的 Hanoi 问题需要 $2^n - 1$ 步。例如：
  - $n=1$：$2^1 - 1 = 1$ 步
  - $n=2$：$2^2 - 1 = 3$ 步
  - $n=3$：$2^3 - 1 = 7$ 步
  - $n=64$：$2^{64} - 1 \approx 1.84 \times 10^{19}$ 步（假设每秒移动一个盘，需要约 5849 亿年）
- 因此 Hanoi 问题在 $n$ 较大时是理论上不可解的（指数爆炸），体现递归算法不一定高效——指数级递归（每次只减少常数规模）会导致灾难性的复杂度。

### 例题 3（补充：归并排序的递归分析）

**题目**：
归并排序算法将长度为 $n$ 的数组分成两半，递归排序每一半，然后在线性时间内合并。请建立递归方程并用 Master 定理解出时间复杂度。

**解答**：

**第一步**：建立递归方程。

- 分割：将数组分为两半，开销 $O(1)$。
- 递归：对左右两半分别排序，每半规模 $n/2$，两个子问题，开销 $2\,T(n/2)$。
- 合并：将两个有序子数组合并为一个，需要 $\Theta(n)$。

综上：
$$
T(n) = 2\,T\!\left(\frac{n}{2}\right) + \Theta(n)
$$

递归基：$T(1) = \Theta(1)$。

**第二步**：套用 Master 定理。

- $a = 2$，$b = 2$
- $\log_b a = \log_2 2 = 1$，所以 $n^{\log_b a} = n$
- $f(n) = \Theta(n)$，与 $n^{\log_b a} = n$ 同阶

命中**情况二**（$f(n) = \Theta(n^{\log_b a})$）：

$$
T(n) = \Theta\left(n^{\log_b a} \log n\right) = \Theta(n \log n)
$$

**解析**：
- 归并排序是分治递归的经典代表。Master 定理的情况二告诉我们：当分解+合并的开销与子问题总个数所决定的基本工作量相当时，总复杂度是 $n^{\log_b a} \log n$。
- 也可以用递归树验证：每层总开销均为 $\Theta(n)$，共 $\log_2 n$ 层，总开销 $\Theta(n \log n)$。
- 对比：如果 $f(n) = \Theta(n^2)$（合并开销是平方级），将落入情况三，$T(n) = \Theta(n^2)$，归并排序也就不高效了——这体现了 $f(n)$ 的重要性。

### 例题 4（补充：二分查找的递归分析）

**题目**：
二分查找在有序数组中查找目标值，每次与中间元素比较后只在半边递归搜索。请建立递归方程并分析时间复杂度。

**解答**：

**第一步**：建立递归方程。

- 比较中间元素：$O(1)$
- 递归搜索左半边或右半边（只选一边）：1 个子问题，规模 $n/2$

$$
T(n) = T\!\left(\frac{n}{2}\right) + O(1)
$$

递归基：$T(1) = O(1)$（直接比较是否相等）。

**第二步**：套用 Master 定理。

- $a = 1$，$b = 2$
- $\log_b a = \log_2 1 = 0$，所以 $n^{\log_b a} = n^0 = 1$
- $f(n) = O(1) = \Theta(1) = \Theta(n^0)$

命中**情况二**：

$$
T(n) = \Theta(n^{\log_b a} \log n) = \Theta(1 \cdot \log n) = \Theta(\log n)
$$

**解析**：
- 二分查找每次将问题规模减半，但只处理一个子问题（$a=1$），因此 $n^{\log_b a}=n^0=1$，意味着子问题的工作量不随 $n$ 增长。
- 总复杂度由递归深度 $\log_2 n$ 决定，每一层 $O(1)$ 开销，所以是 $O(\log n)$。
- 这是"减治"（Decrease and Conquer）而非"分治"（Divide and Conquer）的典型——虽然也是递归，但只求解一个子问题而非多个。

### 例题 5（补充：斐波那契数列的朴素递归）

**题目**：
朴素递归求解斐波那契数列 $F(n) = F(n-1) + F(n-2)$，递归基 $F(1)=F(2)=1$。请写出递归方程并分析时间复杂度。

**解答**：

**第一步**：建立递归方程。

```txt
fib(n):
    if n == 1 or n == 2:
        return 1
    else:
        return fib(n-1) + fib(n-2)
```

每个 $n>2$ 的调用产生两个子问题，规模分别为 $n-1$ 和 $n-2$，合并开销 $O(1)$。

上界估计（用较大的子问题替代）：
$$
T(n) = T(n-1) + T(n-2) + O(1) \le 2\,T(n-1) + O(1)
$$

**第二步**：求解上界。

对不等式 $T(n) \le 2\,T(n-1) + O(1)$ 展开：

$$
\begin{aligned}
T(n) &\le 2\,T(n-1) + c \\
     &\le 2\,(2\,T(n-2) + c) + c = 4\,T(n-2) + 2c + c \\
     &\le 2^{k}\,T(n-k) + c(2^{k} - 1)
\end{aligned}
$$

当 $n-k=1$ 时 $k=n-1$，$T(1)=1$：

$$
T(n) \le 2^{n-1} + c(2^{n-1} - 1) = O(2^n)
$$

所以 $T(n) = O(2^n)$（指数级）。

**更精确的分析**：
实际上 $T(n)$ 与斐波那契数 $F(n)$ 同阶，而 $F(n) \approx \frac{1}{\sqrt{5}} \phi^n$（$\phi \approx 1.618$ 是黄金分割比），因此精确复杂度为 $\Theta(\phi^n)$，约 $\Theta(1.618^n)$。

**解析**：
- 朴素斐波那契递归之所以慢，是因为大量重复计算——$T(n)$ 的递归树包含 $2^n$ 量级的节点，但很多节点是重复的（如 $\text{fib}(3)$ 被多次计算）。
- 这是典型的"指数级递归"案例，也是动态规划要解决的问题——通过记忆化（Memoization）将复杂度降为 $O(n)$。
- 与 Hanoi 问题对比：Hanoi $T(n)=2T(n-1)+1$ 是严格的 $2^n$，而斐波那契是两个不同规模的子问题（$n-1$ 和 $n-2$），其递归树形态不完全平衡，略小于 $2^n$。

命中**情况二**。

**第三步**：代入公式。

T(n) = \Theta\left(n^{\log_b a} \log n\right) = \Theta(n^2 \log n)

### 自测题 4

**题目**：
用**递归树法**求解 $T(n) = T(n/3) + T(2n/3) + O(n)$ 的时间复杂度。

**提示**：
- 递归树不是完全平衡的。两条路径分别为 $n \to n/3 \to n/9 \to \cdots$ 和 $n \to 2n/3 \to 4n/9 \to \cdots$。
- 树的高度由最长路径决定。
- 每层总开销约 $O(n)$。
- 思考：树的高度是多少？最长分支每次缩减为原来的 $2/3$。

<details>
<summary><b>点击查看完整解答</b></summary>

**第一步**：分析树的结构。

- 根节点：开销 $n$，分出两个子节点 $n/3$ 和 $2n/3$。
- 第 1 层：两个节点，开销分别为 $n/3$ 和 $2n/3$，总开销 $n$。
- 第 2 层：四个节点（$n/9$、$2n/9$、$2n/9$、$4n/9$），总开销仍然是 $n$。
- 继续展开，每一层的总开销基本保持为 $n$（只要 $n/3 + 2n/3 = n$ 的和不变）。

**第二步**：确定树的高度。

树的高度由最长的路径决定（即每次都走 $2n/3$ 分支的那条路径）。

该路径上问题规模的变化：$n \to \frac{2}{3}n \to \left(\frac{2}{3}\right)^2 n \to \cdots \to \left(\frac{2}{3}\right)^h n = 1$。

所以：
$$
\left(\frac{2}{3}\right)^h n = 1 \quad \Rightarrow \quad h = \log_{3/2} n
$$

**第三步**：求和。

总复杂度：
$$
T(n) = \sum_{i=0}^{h} O(n) = O\big(n \cdot (\log_{3/2} n + 1)\big) = O(n \log n)
$$

因此 $T(n) = O(n \log n)$。

（注：实际上可以更精确地证明 $T(n) = \Theta(n \log n)$。）

</details>

### 自测题 5

**题目**：
使用**代入法**证明 $T(n) = 2\,T(n/2) + n$ 的解为 $T(n) = O(n \log n)$。

**提示**：
- 猜测 $T(n) \le c n \log n$（$c$ 为某正常数）。
- 假设 $T(n/2) \le c \cdot (n/2) \cdot \log(n/2)$。
- 代入方程展开，尝试消去多余项。

<details>
<summary><b>点击查看完整解答</b></summary>

**第一步**：猜测。

$T(n) \le c n \log n$，其中 $c > 0$ 是待定常数。

**第二步**：归纳假设。

对 $m < n$（特别是 $m = n/2$），有 $T(m) \le c m \log m$。

因此：
$$
T(n/2) \le c \cdot \frac{n}{2} \cdot \log \frac{n}{2}
$$

**第三步**：代入递归方程。

$$
\begin{aligned}
T(n) &= 2\,T(n/2) + n \\
     &\le 2 \cdot \left(c \cdot \frac{n}{2} \cdot \log \frac{n}{2}\right) + n \\
     &= c n \cdot (\log n - \log 2) + n \\
     &= c n \log n - c n + n \\
     &= c n \log n - (c - 1)n
\end{aligned}
$$

**第四步**：确定常数 $c$。

要使 $T(n) \le c n \log n$ 成立，需要：
$$
c n \log n - (c - 1)n \le c n \log n
$$
即：
$$
-(c - 1)n \le 0
$$
即：
$$
c \ge 1
$$

取 $c = 1$，则 $T(n) \le n \log n$ 对所有 $n \ge 2$ 成立（还需验证递归基 $T(1)$ 的情况，通常取足够大的 $c$ 使基成立即可）。

**第五步**：结论。

由数学归纳法，$T(n) = O(n \log n)$ 得证。

</details>

### 自测题 7

**题目**：
写出以下递归算法的时间复杂度递归方程，并用一种方法求解。

```txt
function fun(n):
    if n <= 1:
        return 1
    for i = 1 to n:
        print(i)
    return fun(n-1) + fun(n-1)
```

**提示**：
- 递归基 $T(1)=O(1)$。
- for 循环从 1 到 $n$，是 $O(n)$ 的操作。
- 递归调用产生了两个规模为 $n-1$ 的子问题。
- 得到的递归方程是 $T(n) = 2\,T(n-1) + O(n)$，比 Hanoi 问题多了一个 $O(n)$。

<details>
<summary><b>点击查看完整解答</b></summary>

**第一步**：建立递归方程。

- 递归基：$T(1) = O(1)$
- 循环：打印 1 到 $n$，$\Theta(n)$
- 两个递归调用：$T(n-1)$ 各一次

$$
T(n) = 2\,T(n-1) + \Theta(n)
$$

**第二步**：迭代展开求解。

$$
\begin{aligned}
T(n) &= 2\,T(n-1) + n \\
     &= 2\big(2\,T(n-2) + (n-1)\big) + n \\
     &= 4\,T(n-2) + 2(n-1) + n \\
     &= 8\,T(n-3) + 4(n-2) + 2(n-1) + n \\
     &\quad \vdots \\
     &= 2^{k}\,T(n-k) + \sum_{i=0}^{k-1} 2^{i} \cdot (n-i)
\end{aligned}
$$

当 $n-k=1$ 即 $k=n-1$ 时：

$$
\begin{aligned}
T(n) &= 2^{n-1} \cdot T(1) + \sum_{i=0}^{n-2} 2^{i} \cdot (n-i) \\
     &= O(2^{n-1}) + \sum_{i=0}^{n-2} 2^{i} \cdot (n-i)
\end{aligned}
$$

求和部分主导项为 $n \cdot 2^{n-1}$，所以：

$$
T(n) = O(n \cdot 2^n)
$$

比 Hanoi 问题（$2^n$）多了一个 $n$ 因子，因为每次递归调用前还有 $\Theta(n)$ 的循环开销。

</details>

## 5. 本章总结

| 概念 | 核心要点 |
|---|---|
| 递归三要素 | 递归基 + 递归步骤 + 递推关系 |
| Master 定理 | $T(n)=aT(n/b)+f(n)$，比较 $f(n)$ 与 $n^{\log_b a}$ |
| Master 适用条件 | $a\ge 1$，$b>1$，$f(n)$ 多项式可比 |
| 递归树法 | 每层开销求和，适合 $a$、$b$ 不规则的方程 |
| 代入法 | 猜 + 数学归纳法验证，适合任意形式 |
| Hanoi 塔 | $T(n)=2T(n-1)+1$，$\Theta(2^n)$，不能用 Master |
| 指数递归 | 问题规模每次只减常数（$n-1$），复杂度指数级 |
| 分治递归 | 问题规模每次除以常数（$n/b$），可用 Master |

**常见误区速查**：
1. ❌ 对 $T(n)=T(n-1)+...$ 的形式使用 Master 定理 → 应使用迭代法。
2. ❌ 将 $\log_b a$ 中的 $b$ 当作代码中的常数混淆。
3. ❌ 忘记检查情况三的正则性条件。
4. ❌ 忽略递归树的叶子节点开销。
5. ❌ 认为递归一定低效——分治递归（如归并排序）往往是最优解。
</details>
