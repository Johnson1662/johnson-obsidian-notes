# 第 6 章 回溯法与分支界限法

## 1. 本章概述

回溯法（Backtracking）和分支界限法（Branch and Bound）是两类**系统性搜索算法**，用于在解空间树中寻找问题的解（可行解或最优解）。回溯法采用**深度优先搜索**策略，配合限界函数剪去不含解的分支；分支界限法则采用**广度优先或优先队列（LC-检索）** 策略，每次选择最有希望的节点展开，以更快地逼近最优解。

---

## 2. 知识点讲解

### 2.1 解空间树（Solution Space Tree）

#### 通俗定义

许多算法问题可以转化为在一棵树上搜索答案。这棵树称为**解空间树**，树中的每一条从根到叶子的路径对应一个可能的解。根据问题类型，解空间树主要有两种形式：

- **子集树（Subset Tree）**：从 $n$ 个元素中选出若干元素构成子集，每个节点分支表示"选"或"不选"当前元素。子集树有 $2^n$ 个叶子节点。
- **排列树（Permutation Tree）**：确定 $n$ 个元素的一种排列顺序，每个节点分支表示选择哪个剩余元素作为当前位置。排列树有 $n!$ 个叶子节点。

#### 标准公式

$$
\text{子集树叶子数} = 2^n, \quad \text{排列树叶子数} = n!
$$

#### 举例

- **子集树**：0/1 背包问题（每个物品选或不选）、子集和数问题。
- **排列树**：TSP 问题（城市访问顺序）、N 皇后问题（棋子放置位置）。

#### 初学易错点

- 不要混淆子集树和排列树：如果问题关心的是"选了哪些元素"（无序），用子集树；如果关心的是"元素的排列顺序"（有序），用排列树。
- 子集树中每个节点有 2 个分支（选/不选），排列树中每个节点的分支数随深度递减。

---

### 2.2 回溯法（Backtracking）的基本思想

#### 通俗定义

回溯法像是一个**有条理的试错过程**：沿着一条路往前走，如果发现此路不通，就退回到上一个岔路口换一条路走，直到找到所有解或最优解。这个过程在解空间树上体现为**深度优先遍历**。

#### 标准流程

```
1. 从根节点开始，按深度优先方式搜索解空间树。
2. 每到达一个节点，用限界函数判断：
   - 如果该节点不可能包含解（或不可能得到更优解），则剪枝（即不再向下搜索）。
   - 否则继续向下一层搜索。
3. 到达叶子节点时，记录找到的解（或更新最优解）。
```

#### 初学易错点

- 回溯法不一定遍历整棵树——正是通过**剪枝**来减少搜索量，效率取决于限界函数的设计。
- 限界函数分为两类：**约束函数**（判断是否满足约束条件）和**限界函数**（判断是否可能优于当前最优解）。

---

### 2.3 回溯法的限界条件

#### 通俗定义

限界条件就是"提前判断此路不通"的规则，目的是在搜索过程中尽早放弃那些不可能产生解（或更优解）的分支。

#### 标准公式

对于**最大化问题**（如背包问题），设：

- 当前节点 $X = (x_1, x_2, \ldots, x_k)$ 表示已经决定了前 $k$ 个元素的选择
- $\text{cw}$ = 当前已选的总重量
- $\text{cp}$ = 当前已选的总价值
- $\text{bestp}$ = 迄今为止找到的最佳价值
- $r$ = 剩余物品的总价值

**左子节点（选择当前物品）的限界条件**：

$$
\text{cw} + w_{k+1} > c \quad \Rightarrow \quad \text{剪枝（不可行）}
$$

**右子节点（不选当前物品）的限界条件**：

$$
\text{cp} + \text{bound}(X) \leq \text{bestp} \quad \Rightarrow \quad \text{剪枝（不可能更优）}
$$

其中 $\text{bound}(X)$ 是对剩余物品能获得价值的**乐观估计**（上界），通常用**连续背包问题的贪心解**作为上界。

#### 举例

在 0/1 背包问题中，如果当前已选价值为 10，剩余物品的连续背包上界为 8，而当前最优解已经是 15，则 $10 + 8 = 18 > 15$，不能剪枝，还要继续搜索。如果当前最优解已经是 20，则 $10 + 8 = 18 < 20$，说明此分支不可能超过 20，可以剪枝。

#### 初学易错点

- 限界函数的计算必须**乐观**（使用连续背包放松），否则可能会剪掉最优解。
- 约束函数和限界函数要分开使用：左子节点用约束函数判断可行性，右子节点用限界函数判断优化可能性。

---

### 2.4 分支界限法（Branch and Bound）的基本思想

#### 通俗定义

分支界限法和回溯法类似，也是在解空间树上搜索，但它的搜索方式是**按"最有希望"的顺序展开**，而不是死板地一条路走到底。它会维护一个"待考察节点"的列表，每次都从列表中挑选**最有可能通向最优解**的节点来展开。

#### 标准流程

```
1. 将根节点加入活节点表（优先级队列或先进先出队列）。
2. 从活节点表中选择一个节点展开（生成其子节点）。
3. 对每个子节点：
   - 计算限界值；
   - 如果限界值优于当前最优解，则加入活节点表；
   - 否则丢弃（剪枝）。
4. 重复步骤 2-3，直到活节点表为空或找到最优解。
```

#### 初学易错点

- 分支界限法不一定要遍历到叶子节点才能确定最优解——当活节点表中所有节点的限界值都不优于当前最优解时，算法可以提前终止。
- 分支界限法需要额外的存储空间（队列或堆）来管理活节点，空间复杂度高于回溯法。

---

### 2.5 LC-检索（Least Cost Search）

#### 通俗定义

LC-检索（Least Cost Search）是分支界限法的一种实现方式。它给每个节点定义了一个**成本函数** $\hat{c}(X)$，用这个函数的值来衡量"从该节点出发找到最优解的难度"。每次从活节点表中选择成本最小（最有希望）的节点展开，通常使用**最小堆（优先队列）** 来实现。

#### 标准公式

对于最大化问题，节点的成本函数通常定义为负的限界值：

$$
\hat{c}(X) = -(\text{cp} + \text{bound}(X))
$$

或等价地，用限界值作为优先级（限界值越大，优先级越高）。

**限界函数的计算**（以 0/1 背包为例）：

$$
\text{bound}(X) = \text{cp} + \text{剩余容量的连续背包价值}
$$

其中连续背包价值是按价值密度 $p_i/w_i$ 从大到小依次取物品，最后一个物品可以取一部分。

#### 举例

在 0/1 背包问题中，如果根节点的限界值为 20，而另一个节点的限界值为 15，则 LC-检索会优先展开限界值为 20 的节点，因为它的上界更高，更可能找到最优解。

#### 初学易错点

- LC-检索中每个节点的**限界值一旦计算出就不会改变**，而回溯法中限界值是动态计算的（依赖于当前最优解的变化）。因此分支界限法需要更精确的初始上界。
- 成本函数的设计直接影响搜索效率：如果成本函数估计越准确，搜索的节点就越少。

---

### 2.6 回溯法与分支界限法的区别

| 比较维度 | 回溯法（Backtracking） | 分支界限法（Branch and Bound） |
|---------|----------------------|-------------------------------|
| 搜索策略 | 深度优先搜索 | 广度优先 / 最佳优先（LC-检索） |
| 节点选择 | 按深度顺序，一条路走到底再回溯 | 从活节点表中选择最优节点展开 |
| 数据结构 | 递归栈 | 队列 / 优先队列（堆） |
| 空间复杂度 | $O(\text{树的最大深度})$ | $O(\text{活节点数})$，通常更大 |
| 适用场景 | 寻找所有解或最优解 | 主要寻找最优解 |
| 剪枝依据 | 限界函数 + 当前最优解 | 限界值 + 全局最优解（可提前终止） |
| 是否依赖初始解 | 可在搜索过程中逐步更新 best | 需要一个较好的初始上界来提高剪枝效率 |

#### 初学易错点

- 回溯法和分支界限法**不是互斥的**，它们的核心区别在于节点展开的顺序。
- 回溯法不需要额外存储所有活节点，空间效率更高；分支界限法由于存储所有活节点，空间开销更大，但可能通过更精准的剪枝减少搜索的总节点数。

## 3. 典型例题

### 例题 1（来源：[Q0058]）

**题目**：

子集和数问题：已知 $n+1$ 个正数 $w_i\;(1 \leq i \leq n)$ 和 $M$。要求找 $\{w_i\}$ 的所有子集，使得子集内元素之和等于 $M$。用 $n$ 元组的方法表示解向量。要求：

（1）给出回溯方法求解该问题的两种限界方法。  
（2）给出利用上述限界条件的回溯法伪代码。

**解答**：

用定长元组的方法表示解向量，即 $(x_1, x_2, \ldots, x_n)$，其中 $x_i \in \{0, 1\}$。$x_i = 1$ 表示选择第 $i$ 个元素，$x_i = 0$ 表示不选。

**（1）两种限界条件**

设当前已搜索到第 $k$ 层（即已决定前 $k$ 个元素的选择），记：

- $s = \sum_{i=1}^{k-1} w_i \cdot x_i$：前 $k-1$ 个已选元素之和
- $r = \sum_{i=k}^{n} w_i$：从第 $k$ 到第 $n$ 个元素的总和

**第一种限界条件（上限剪枝）**：如果即使把剩下的所有元素都选上，总和仍然小于目标值，则此分支不可能产生可行解，应剪枝。

$$
s + r < M \quad \Rightarrow \quad \text{剪枝}
$$

**第二种限界条件（下限剪枝）**：如果当前已选元素之和加上下一个最小元素已经超过了目标值，则继续选下去不可能得到和为 $M$ 的解，应剪枝。这里假设 $w_i$ 已按**非递减顺序排序**。

$$
s + w_k > M \quad \Rightarrow \quad \text{剪枝}
$$

其中 $w_k$ 是当前正在考虑的元素（排序后最小的剩余元素之一），由于 $w_i$ 非递减，$w_k$ 是剩余元素中的最小值。

**（2）回溯法伪代码**

```
// 前提：w[1..n] 已按非递减顺序排序
// s = 当前已选元素之和
// r = 剩余元素的总和
// k = 当前正在考虑的元素下标

procedure SumOfSubset(s, k, r)
    // 生成左子节点（选择 w[k]）
    x[k] ← 1
    if s + w[k] = M then
        // 找到一个解，输出
        output x[1..k]
    else if s + w[k] + w[k+1] ≤ M then
        // 继续搜索左子树（选择 w[k] 后仍有可能继续添加）
        SumOfSubset(s + w[k], k+1, r - w[k])
    end if

    // 生成右子节点（不选 w[k]）
    if s + (r - w[k]) ≥ M and s + w[k+1] ≤ M then
        // 条件1: 即使不选 w[k]，剩余元素还有可能达到 M
        // 条件2: 不选 w[k] 后，下一个元素的值不超过剩余所需
        x[k] ← 0
        SumOfSubset(s, k+1, r - w[k])
    end if
end procedure

// 初始调用：SumOfSubset(0, 1, sum(w))
```

**解析**：

本题的核心是理解回溯法中**两种限界条件**的作用：

1. **上限条件** $s + r \geq M$ 确保剩余元素还有达到目标值的可能性——如果剩余全选都不够 M，此路不通。
2. **下限条件** $s + w_k \leq M$ 确保选当前元素后不会立即超过目标值——如果当前元素加上去就超了，不应该选它（但可以尝试不选的情况）。

注意右下角分支（不选 $w_k$）的条件中，要求 $s + (r - w_k) \geq M$，即不选当前元素后剩余的元素总和仍然可能达到 $M$，同时 $s + w_{k+1} \leq M$ 保证下一个最小元素不会直接超过目标值。这两个条件必须同时满足，否则右子树也不需要搜索了。

### 例题 2（来源：[Q0031]）

**题目**：

对以下 0/1 背包问题的实例：$n=5,\; c=10,\; w=[2,2,6,5,4],\; p=[6,3,5,4,6]$

用回溯法求解，写出限界条件，并画出展开的状态空间树，求出优化解和优化值。

**解答**：

**第一步：按价值密度排序**

为了提高剪枝效率，先将物品按价值密度 $p_i / w_i$ 从大到小排序。排序后的结果如下：

| 排序后编号 | 原物品编号 | 重量 $w_i$ | 价值 $p_i$ | $p_i/w_i$ |
|:----------:|:----------:|:----------:|:----------:|:---------:|
| 1 | 1 | 2 | 6 | 3 |
| 2 | 2 | 2 | 3 | 1.5 |
| 3 | 5 | 4 | 6 | 1.5 |
| 4 | 3 | 6 | 5 | 0.83 |
| 5 | 4 | 5 | 4 | 0.8 |

当 $p_i/w_i$ 相同时，优先处理重量较小的物品。

**第二步：定义限界条件**

设当前节点为 $X$，对应已考虑完前 $k-1$ 个物品，当前总重量为 $\text{cw}$，当前总价值为 $\text{cp}$，$\text{bestp}$ 为当前最优价值。

**左子节点（选择物品 $k$）的限界条件**：

$$
\text{cw} + w_k \leq c \quad \Rightarrow \quad \text{可展开}
$$

如果 $\text{cw} + w_k > c$，则左子节点不可行，剪枝。

**右子节点（不选物品 $k$）的限界条件**：

$$
\text{cp} + \text{bound}(k, \text{cw}) > \text{bestp} \quad \Rightarrow \quad \text{可展开}
$$

其中 $\text{bound}(k, \text{cw})$ 是取剩余物品的**连续背包问题（分数背包）** 的贪心值：

$$
\text{bound}(k, \text{cw}) = \text{cp} + \sum_{j=k+1}^{i-1} p_j + \left(c - \text{cw} - \sum_{j=k+1}^{i-1} w_j\right) \times \frac{p_i}{w_i}
$$

其中 $i$ 是第一个无法完整装入的物品下标。

如果 $\text{cp} + \text{bound}(k, \text{cw}) \leq \text{bestp}$，则此分支不可能优于当前最优解，剪枝。

**第三步：搜索过程**

初始化：$\text{bestp} = 0$，根节点 $\text{cw} = 0$，$\text{cp} = 0$。

**第 1 层（物品 1：$w=2, p=6$）**

- **左子节点（选）**：$\text{cw}=2 \leq 10$，$\text{cp}=6$。  
  计算 bound：剩余容量 $=8$，依次取物品 2($2,3$)、物品 3($4,6$)、物品 4 的部分 $2/6$：
  $6 + 3 + 6 + 5 \times \frac{2}{6} = 6 + 3 + 6 + 1.67 = 16.67 > \text{bestp}=0$ → **展开**。

- **右子节点（不选）**：$\text{cw}=0$，$\text{cp}=0$。  
  bound：剩余容量 $=10$，取物品 2($2,3$)、物品 3($4,6$)、物品 4 的部分 $4/6$：
  $0 + 3 + 6 + 5 \times \frac{4}{6} = 0 + 3 + 6 + 3.33 = 12.33 > 0$ → **展开**。

**第 2 层（在选物品 1 的分支中，考虑物品 2：$w=2, p=3$）**  
当前 $\text{cw}=2, \text{cp}=6$。

- **左子节点（选物品 2）**：$\text{cw}=4 \leq 10$，$\text{cp}=9$。  
  bound：剩余容量 $=6$，取物品 3($4,6$)、物品 4 的部分 $2/6$：
  $9 + 6 + 5 \times \frac{2}{6} = 9 + 6 + 1.67 = 16.67 > 0$ → **展开**。

- **右子节点（不选物品 2）**：$\text{cw}=2$，$\text{cp}=6$。  
  bound：剩余容量 $=8$，取物品 3($4,6$)、物品 4 的部分 $4/6$：
  $6 + 6 + 5 \times \frac{4}{6} = 6 + 6 + 3.33 = 15.33 > 0$ → **展开**。

**第 3 层（选物品 1 和 2 的分支，考虑物品 3：$w=4, p=6$）**  
当前 $\text{cw}=4, \text{cp}=9$。

- **左子节点（选物品 3）**：$\text{cw}=8 \leq 10$，$\text{cp}=15$。  
  更新 $\text{bestp} = \max(0, 15) = 15$。  
  bound：剩余容量 $=2$，取物品 4 的部分 $2/6$：
  $15 + 5 \times \frac{2}{6} = 15 + 1.67 = 16.67 > 15$ → **展开**。
  
- **右子节点（不选物品 3）**：$\text{cw}=4$，$\text{cp}=9$。  
  bound：剩余容量 $=6$，取物品 4($6,5$)、物品 5 无法装入：
  $9 + 5 = 14 < \text{bestp}=15$ → **剪枝！**

**第 4 层（选物品 1、2、3 的分支，考虑物品 4：$w=6, p=5$）**  
当前 $\text{cw}=8, \text{cp}=15$。

- **左子节点（选物品 4）**：$\text{cw}=14 > 10$ → **不可行，剪枝！**
- **右子节点（不选物品 4）**：$\text{cw}=8$，$\text{cp}=15$。  
  bound：剩余容量 $=2$，取物品 5($5,4$) 的部分 $2/5$：
  $15 + 4 \times \frac{2}{5} = 15 + 1.6 = 16.6 > 15$ → **展开**。

**第 5 层（选物品 1、2、3、不选物品 4 的分支，考虑物品 5：$w=5, p=4$）**  
当前 $\text{cw}=8, \text{cp}=15$。

- **左子节点（选物品 5）**：$\text{cw}=13 > 10$ → **不可行，剪枝！**
- **右子节点（不选物品 5）**：叶子节点，$\text{cp}=15$。不更新 bestp。

**回到第 3 层（选物品 1、不选物品 2 的分支，考虑物品 3：$w=4, p=6$）**  
当前 $\text{cw}=2$，$\text{cp}=6$。

- **左子节点（选物品 3）**：$\text{cw}=6 \leq 10$，$\text{cp}=12$。  
  bound：剩余容量 $=4$，取物品 4 的部分 $4/6$：
  $12 + 5 \times \frac{4}{6} = 12 + 3.33 = 15.33 > 15$ → **展开**。

  第 4 层（选物品 1、3，考虑物品 4：$w=6, p=5$）：
  - 左子节点（选物品 4）：$\text{cw}=12 > 10$ → **不可行，剪枝！**
  - 右子节点（不选物品 4）：$\text{cw}=6$，$\text{cp}=12$。  
    bound：剩余容量 $=4$，取物品 5 的部分 $4/5$：$12 + 4 \times \frac{4}{5} = 12 + 3.2 = 15.2 > 15$ → **展开**。

  第 5 层（考虑物品 5：$w=5, p=4$）：
  - 左子节点（选物品 5）：$\text{cw}=11 > 10$ → **不可行，剪枝！**
  - 右子节点（不选物品 5）：叶子节点，$\text{cp}=12$，不更新 bestp。

- **右子节点（不选物品 3）**：$\text{cw}=2$，$\text{cp}=6$。  
  bound：剩余容量 $=8$，取物品 4($6,5$)、物品 5($5,4$) 的部分 $2/5$：
  $6 + 5 + 4 \times \frac{2}{5} = 6 + 5 + 1.6 = 12.6 < \text{bestp}=15$ → **剪枝！**

**回到第 2 层（不选物品 1 的分支，考虑物品 2：$w=2, p=3$）**  
当前 $\text{cw}=0$，$\text{cp}=0$。

- **左子节点（选物品 2）**：$\text{cw}=2 \leq 10$，$\text{cp}=3$。  
  bound：剩余容量 $=8$，取物品 3($4,6$)、物品 4 的部分 $4/6$：
  $3 + 6 + 5 \times \frac{4}{6} = 3 + 6 + 3.33 = 12.33 < \text{bestp}=15$ → **剪枝！**

- **右子节点（不选物品 2）**：$\text{cw}=0$，$\text{cp}=0$。  
  bound：剩余容量 $=10$，取物品 3($4,6$)、物品 4($6,5$)、物品 5($5,4$) 的部分 $0/5$：
  $0 + 6 + 5 = 11 < \text{bestp}=15$ → **剪枝！**

**第四步：得出结果**

最优解：选择物品 1、物品 2、物品 5（排序后为物品 1、2、3）。  
总重量：$2 + 2 + 4 = 8 \leq 10$。  
总价值：$6 + 3 + 6 = 15$。

**状态空间树（简化示意）**：

```
                          根 (cw=0, cp=0)
                         /              \
            选物品1(w=2,p=6)         不选物品1
           /              \           /         \
    选物品2(w=2,p=3)  不选物品2  选物品2(cp=3) 不选物品2
     /       \         /     \     (bound=12.33  (bound=11
  选物品3   不选物品3 选物品3 不选物品3  <15剪枝)  <15剪枝)
(cp=15)   (bound=14  (cp=12) (bound=12.6
bestp=15   <15剪枝)            <15剪枝)
   |
   ...(继续搜索，未发现更优解)
```

**第五步：验证答案**

$\text{优化值}=15$，优化解为选择物品 $(1, 2, 5)$（即排序后的物品 1、2、3，对应原物品编号 1、2、5）。

**解析**：

本题的关键在于：

1. **限界条件的设计**：左子树用可行性判断（重量不超容量），右子树用优化判断（上界大于当前最优值）。
2. **bound 函数**使用的是**分数背包的贪心解**，因为它给出了整数背包问题的一个上界（分数背包允许分割物品，得到的价值一定不低于整数背包）。
3. **排序预处理**：按价值密度排序后，bound 函数可以按顺序取物品，计算更简洁，剪枝效率也更高。
4. 注意在搜索过程中，**bestp 是动态更新的**——一旦发现一个可行解的价值超过当前 bestp，就立即更新。后续的剪枝都基于最新的 bestp 进行判断。

### 例题 3（来源：[Q0032]）

**题目**：

对以下 0/1 背包问题的实例：$n=5,\; c=10,\; w=[2,2,6,5,4],\; p=[6,3,5,4,6]$

用 LC-检索的分支限界法求解，写出限界条件，画出以"下标增量"表示展开的状态空间树，求出优化解和优化值。

**解答**：

**第一步：排序与限界条件**

与回溯法相同，先将物品按 $p_i/w_i$ 从大到小排序（同例题 2 的排序表）。

**限界条件**（与回溯法使用相同的 bound 函数）：

对于节点 $X$，其限界值为：

$$
\text{bound}(X) = \text{cp} + \text{剩余容量的连续背包价值}
$$

节点 $X$ 的优先级 = $\text{bound}(X)$，值越大优先级越高。

**可行条件**（左子节点）：

$$
\text{cw} + w_k \leq c
$$

**剪枝条件**（右子节点）：

$$
\text{bound}(X) \leq \text{bestp} \quad \Rightarrow \quad \text{丢弃}
$$

**第二步：LC-检索过程**

用最大堆（优先队列）存储活节点，每个节点存储 $(\text{bound}, \text{level}, \text{cp}, \text{cw}, \text{选中的物品列表})$。堆顶是 bound 值最大的节点。

初始：$\text{bestp} = 0$。将根节点（level=0, cp=0, cw=0）加入堆。

**展开节点 1：根节点**（bound 值计算）  
剩余容量 $=10$，取物品 1($2,6$)、物品 2($2,3$)、物品 3($4,6$)、物品 4 的部分 $2/6$：
$\text{bound} = 0 + 6 + 3 + 6 + 5 \times \frac{2}{6} = 16.67$

生成两个子节点：
- **左子（选物品 1）**：$\text{cw}=2 \leq 10$，$\text{cp}=6$。bound 计算同回溯法 → 16.67。入堆。
- **右子（不选物品 1）**：$\text{cw}=0$，$\text{cp}=0$。bound = 12.33。入堆。

堆状态：[(16.67, 选1), (12.33, 不选1)]

**展开节点 2：左子（选物品 1）**，bound=16.67，level=1。

考虑物品 2：
- **左子（选 1, 选 2）**：$\text{cw}=4$，$\text{cp}=9$。bound = 16.67。入堆。
- **右子（选 1, 不选 2）**：$\text{cw}=2$，$\text{cp}=6$。bound = 15.33。入堆。

堆状态：[(16.67, 选1选2), (15.33, 选1不选2), (12.33, 不选1)]

**展开节点 3：（选 1, 选 2）**，bound=16.67，level=2。

考虑物品 3：
- **左子（选 1,2,3）**：$\text{cw}=8$，$\text{cp}=15$。bound = 16.67。入堆。更新 bestp = 15。
- **右子（选 1,2, 不选 3）**：$\text{cw}=4$，$\text{cp}=9$。bound = 14（${}< 15$）→ **剪枝！**

堆状态：[(16.67, 选1选2选3), (15.33, 选1不选2), (12.33, 不选1)]

**展开节点 4：（选 1,2,3）**，bound=16.67，level=3，已选 cw=8, cp=15。

考虑物品 4：
- **左子（选 4）**：$\text{cw}=14 > 10$ → **不可行，丢弃！**
- **右子（不选 4）**：$\text{cw}=8$，$\text{cp}=15$。bound = $15 + 4 \times \frac{2}{5} = 16.6$。入堆（bound 值 16.6）。

堆状态：[(16.6, 选1选2选3不选4), (15.33, 选1不选2), (12.33, 不选1)]

**展开节点 5：（选 1,2,3, 不选 4）**，bound=16.6，level=4。

考虑物品 5：
- **左子（选 5）**：$\text{cw}=13 > 10$ → **不可行，丢弃！**
- **右子（不选 5）**：叶子节点，$\text{cp}=15$。不更新 bestp。

堆状态：[(15.33, 选1不选2), (12.33, 不选1)]

**展开节点 6：（选 1, 不选 2）**，bound=15.33，level=2。

考虑物品 3：
- **左子（选 3）**：$\text{cw}=6$，$\text{cp}=12$。bound = 15.33。入堆。
- **右子（不选 3）**：$\text{cw}=2$，$\text{cp}=6$。bound = $6+5+4\times\frac{2}{5}=12.6 < 15$ → **剪枝！**

堆状态：[(15.33, 选1不2选3), (12.33, 不选1)]

**展开节点 7：（选 1, 不选 2, 选 3）**，bound=15.33，level=3。

考虑物品 4：
- **左子（选 4）**：$\text{cw}=12 > 10$ → **不可行，丢弃！**
- **右子（不选 4）**：$\text{cw}=6$，$\text{cp}=12$。bound = $12+4\times\frac{4}{5}=15.2$。入堆。

堆状态：[(15.2, 选1不2选3不选4), (12.33, 不选1)]

**展开节点 8：（选 1, 不选 2, 选 3, 不选 4）**，bound=15.2，level=4。

考虑物品 5：
- **左子（选 5）**：$\text{cw}=11 > 10$ → **不可行，丢弃！**
- **右子（不选 5）**：叶子节点，$\text{cp}=12 < 15$。不更新 bestp。

堆状态：[(12.33, 不选1)]

**展开节点 9：（不选 1）**，bound=12.33，level=1。

$\text{bound} = 12.33 < \text{bestp} = 15$ → **剪枝！** 此节点及其所有子节点都不可能超过当前最优解 15。

堆为空，算法结束。

**第三步：结果**

优化解：选择物品 1、2、5（排序后为物品 1、2、3，对应原物品编号 1、2、5）。  
优化值：15。

**展开的状态空间树（LC-检索顺序）**：

```
展开顺序: ①→②→③→④→⑤→⑥→⑦→⑧→⑨

①根(bound=16.67)
├─②左:选1(bound=16.67)
│ ├─③左:选2(bound=16.67)
│ │ ├─④左:选3(cp=15, bestp=15, bound=16.67)
│ │ │ └─⑤右:不选4(bound=16.6)
│ │ │   ├─左:选5(不可行)
│ │ │   └─右:不选5(叶子cp=15)
│ │ └─右:不选3(bound=14 <15 剪枝)
│ └─⑥右:不选2(bound=15.33)
│   ├─⑦左:选3(bound=15.33)
│   │ └─⑧右:不选4(bound=15.2)
│   │   ├─左:选5(不可行)
│   │   └─右:不选5(叶子cp=12)
│   └─右:不选3(bound=12.6 <15 剪枝)
└─⑨右:不选1(bound=12.33 <15 剪枝)
```

**解析**：

LC-检索与回溯法的核心区别在本题中清晰体现：

1. **节点展开顺序不同**：回溯法严格按照深度优先展开（一条路走到黑），而 LC-检索每次选择 bound 值最大的节点展开。
2. **LC-检索的优势**：由于每次选择最有希望的节点，LC-检索往往能更快地找到一个较好的可行解（bestp 更新更早），从而提升后续的剪枝效率。
3. **空间开销**：LC-检索需要维护一个优先队列（堆），存储所有活节点，空间开销大于回溯法。
4. **在这个实例中**，两种方法搜索的节点数相近，这是因为实例规模较小且 bound 函数准确。在更大规模的问题中，LC-检索通常能比回溯法剪掉更多的分支。

### 例题 4（来源：[Q0051]）

**题目**：

有以下 TSP 问题（距离矩阵，行表示出发城市，列表示到达城市）：

|       | 北京 | 上海 | 广州 | 南京 |
|:-----:|:----:|:----:|:----:|:----:|
| 北京  | 0    | 500  | 600  | 100  |
| 上海  | 100  | 0    | 800  | 500  |
| 广州  | 1000 | 200  | 0    | 2000 |
| 南京  | 400  | 400  | 100  | 0    |

分别使用回溯法和分支限界法，写出相应的限界条件，画出展开的状态空间树，求出问题的优化解和优化值。

**解答**：

设城市编号：1-北京，2-上海，3-广州，4-南京。出发城市为北京（城市 1），最终返回北京。

**一、回溯法求解**

**（1）限界条件**

设当前已访问的城市序列为 $(v_1=1, v_2, \ldots, v_k)$，当前路径总长度为 $\text{cl}$，当前最优路径长度为 $\text{bestl}$。

- **可行性条件**：下一个要访问的城市 $v_{k+1}$ 不能是已访问过的城市。
- **限界条件**：

$$
\text{cl} + \text{bound}(v_k) \geq \text{bestl} \quad \Rightarrow \quad \text{剪枝}
$$

其中 $\text{bound}(v_k)$ 是**从当前城市出发到剩余未访问城市以及返回起点的最小可能代价**的下界估计。一种简单有效的 bound 函数是：**从当前城市到所有未访问城市的最小距离** + **每个未访问城市到其他城市（未访问或起点）的最小距离之和** + **从未访问城市返回起点的最小距离**。

更精确地，对于当前最后一个城市 $v_k$，剩余未访问城市集合 $S = \{全部城市\} \setminus \{v_1, \ldots, v_k\}$，以及返回城市 $v_1=1$：

$$
\text{bound}(v_k) = \min_{j \in S} d(v_k, j) + \sum_{j \in S} \min\left(\min_{i \notin S \setminus\{j\}, i \neq j} d(j, i),\; d(j,1)\right)
$$

其中第一项是从当前城市进入未访问区域的最小代价，第二项是每个未访问城市**离开**的最小代价（可以选择去另一个未访问城市或直接回起点）。

在实际考试中，也可以使用更简化的 bound：

$$
\text{bound}(v_k) = \min_{j \in S} d(v_k, j) + \sum_{j \in S} \min_{i \neq j} d(j, i)
$$

即从当前城市出发连接最近未访问城市，然后每个未访问城市都选一条最短出边。

**（2）回溯搜索过程**

从北京（城市 1）出发，搜索所有排列。

**路径 1→2→3→4→1**：
1→2: 500, cl=500
2→3: 800, cl=1300
3→4: 2000, cl=3300
4→1: 400, cl=3700
$\text{bestl} = 3700$

**路径 1→2→4→3→1**：
1→2: 500, cl=500
2→4: 500, cl=1000
bound: 从 4 出发到未访问城市 {3} 的最小距离 = $d(4,3)=100$，未访问城市 3 返回或去他处的最小值 = $\min(d(3,1)=1000) = 1000$（只能返回北京）。$\text{cl} + \text{bound} = 1000 + 100 + 1000 = 2100 < 3700$ → 展开。
4→3: 100, cl=1100
3→1: 1000, cl=2100
$\text{bestl} = \min(3700, 2100) = 2100$

**路径 1→3→2→4→1**：
1→3: 600, cl=600
bound: 从 3 出发到未访问 {2,4} 的最小距离 = $\min(d(3,2)=200, d(3,4)=2000) = 200$。未访问城市 2 的最小出边 = $\min(d(2,1)=100, d(2,4)=500)=100$，城市 4 的最小出边 = $\min(d(4,1)=400, d(4,2)=400)=400$。$\text{cl} + \text{bound} = 600 + 200 + 100 + 400 = 1300 < 2100$ → 展开。
3→2: 200, cl=800
2→4: 500, cl=1300
4→1: 400, cl=1700
$\text{bestl} = \min(2100, 1700) = 1700$

**路径 1→3→4→2→1**：
1→3: 600, cl=600
3→4: 2000, cl=2600
此时已经超过 bestl=1700 → **剪枝！**

**路径 1→4→2→3→1**：
1→4: 100, cl=100
bound: 从 4 出发到未访问 {2,3} 的最小距离 = $\min(d(4,2)=400, d(4,3)=100)=100$。未访问城市 2 的最小出边 = $\min(d(2,1)=100, d(2,3)=800)=100$，城市 3 的最小出边 = $\min(d(3,1)=1000, d(3,2)=200)=200$。$\text{cl} + \text{bound} = 100 + 100 + 100 + 200 = 500 < 1700$ → 展开。
4→2: 400, cl=500
2→3: 800, cl=1300
3→1: 1000, cl=2300
$\text{bestl} = \min(1700, 2300) = 1700$（未更新）

**路径 1→4→3→2→1**：
1→4: 100, cl=100
4→3: 100, cl=200
bound: 从 3 出发到未访问 {2} 的最小距离 = $d(3,2)=200$。未访问城市 2 的最小出边 = $\min(d(2,1)=100, d(2,4)=500)=100$。$\text{cl} + \text{bound} = 200 + 200 + 100 = 500 < 1700$ → 展开。
3→2: 200, cl=400
2→1: 100, cl=500
$\text{bestl} = \min(1700, 500) = 500$ ← **最优解！**

**回溯法结果**：优化路径为 1→4→3→2→1（北京→南京→广州→上海→北京），优化值为 500。

**回溯法状态空间树**：

```
                             ①北京
              ┌───────────────┼───────────────┐
           ②上海           ③广州           ④南京
         ┌──┴──┐         ┌──┴──┐         ┌──┴──┐
       ③广州  ④南京   ②上海  ④南京   ②上海  ③广州
        │      │        │      │        │      │
       ④南京  ③广州  ④南京  ②上海  ③广州  ②上海
        │      │        │      │        │      │
       ①北京  ①北京  ①北京  ①北京  ①北京  ①北京
      cl=3700 cl=2100 cl=1700 剪枝   cl=2300 cl=500 ←最优
      bestp=3700 bestp=2100 bestp=1700      bestp=500
```

**二、分支限界法（LC-检索）求解**

**（1）限界条件**

与回溯法使用相同的 bound 函数。每个节点的优先级为 $\text{cl} + \text{bound}$，值越小优先级越高（因为是求最小路径）。

**（2）LC-检索过程**

使用最小堆，堆顶为 $\text{cl} + \text{bound}$ 最小的节点。

初始化：根节点（北京，路径=1, cl=0），bestl = ∞。

**展开 1：根节点**

计算 bound：从 1 出发到所有城市的最小出边和。
从 1 出发的最短出边 = $\min(500,600,100)=100$（去南京）。
从 2 出发的最短出边 = $\min(100,800,500)=100$（回北京）。
从 3 出发的最短出边 = $\min(1000,200,2000)=200$（去上海）。
从 4 出发的最短出边 = $\min(400,400,100)=100$（去广州）。
$\text{bound} = \frac{1}{2} \times (100 + 100 + 200 + 100) = 250$ （更精确的下界：每个城市一进一出，总和的一半）
或使用简化 bound：$100 + 100 + 200 + 100 = 500$。

边界值 = $0 + 500 = 500$。

生成子节点：1→2 (500), 1→3 (600), 1→4 (100)。

- 1→2: cl=500, bound: 从 2 出 min=100, 未访问{3,4}的 min 出边=200+100... 简化 bound=500+100+200+100=900。入堆。
- 1→3: cl=600, bound=600+200+... 简化 bound=600+200+100+100=1000。入堆。  
- 1→4: cl=100, bound=100+100+100+200=500。入堆。

堆状态：[(500, 1→4), (900, 1→2), (1000, 1→3)]

**展开 2：1→4** (cl=100, bound=500)

从南京(4)出发，未访问 {2,3}：
- 4→2: 400, cl=500. bound: 从 2 出 min=100, 未访问{3}出 min=200. → 500+100+200=800. 入堆。
- 4→3: 100, cl=200. bound: 从 3 出 min=200, 未访问{2}出 min=100. → 200+200+100=500. 入堆。

堆状态：[(500, 1→4→3), (800, 1→4→2), (900, 1→2), (1000, 1→3)]

**展开 3：1→4→3** (cl=200, bound=500)

从广州(3)出发，未访问 {2}：
- 3→2: 200, cl=400. 从 2 回 1: 100, cl=500. 完整路径！bestl=500.
- 入堆的是完整路径，不再展开。

堆状态：[(800, 1→4→2), (900, 1→2), (1000, 1→3)]

所有剩余节点的 bound 均 $\geq 500$，且我们已经找到了一个可行解 500，因此剪枝。

LC-检索结果：优化路径为 1→4→3→2→1（北京→南京→广州→上海→北京），优化值为 500。

**解析**：

1. TSP 问题的解空间是**排列树**，对于 $n$ 个城市，有 $(n-1)!$ 种可能的路径（固定起点）。
2. 回溯法在搜索过程中逐步更新 bestl，不断收紧剪枝条件。在本题中，回溯法探索了 6 条完整路径中的 5 条（剪掉了 1→3→4→2→1）。
3. LC-检索由于使用了 bound 值排序，优先展开了 bound 最小的 1→4→3 分支，很快找到了最优解 500，剩余分支全部剪掉，搜索节点少于回溯法。
4. 本题中距离矩阵是**不对称的**（例如北京→上海=500，上海→北京=100），在处理时要特别注意方向的区分。

### 例题 5（来源：[Q0076]）

**题目**：

（1）简述回溯法和分支限界法的区别。（4 分）

（2）设 $X = (x(1), \ldots, x(k))$ 为状态空间树的节点，bestp 是算法当前获得的最优效益值，$\text{cp} = x(1)p(1) + \cdots + x(k)p(k)$。令 $\text{bound}(X) = \text{cp} + \text{其余物品的连续背包问题的优化效益值}$（根据贪心法得到）。请分别给出用回溯法求解时，展开左子节点和右子节点的限界条件，并画出被限界后的状态空间树，给出优化解和优化值。（8 分）

（3）请给出 LC 分支限界法的限界条件，并画出被限界后的部分状态空间树，给出优化解和优化值。（8 分）

**注**：本题第（2）（3）问缺少具体实例，此处给出通用解答。

**解答**：

**（1）回溯法和分支限界法的区别**

| 方面 | 回溯法（Backtracking） | 分支限界法（Branch and Bound） |
|:----|:--------------------|:-----------------------------|
| 搜索方式 | 深度优先搜索 | 广度优先（FIFO分支限界）或最佳优先（LC-检索） |
| 节点选择 | 沿一条路径深入，遇到死路再回溯 | 从活节点表中选择最有希望的节点展开 |
| 数据结构 | 系统栈（递归调用栈） | 队列（FIFO）或优先队列（LC） |
| 空间复杂度 | $O(\text{树深度})$，空间小 | $O(2^{\text{树深度}})$ 最坏情况，空间需求大 |
| 目标 | 可以找所有解，也可以找最优解 | 通常用于找最优解 |
| 是否可提前终止 | 不能，必须遍历完所有未被剪枝的分支 | 可以，当活节点表中所有节点限界值都不优于当前最优解时可提前终止 |
| 剪枝依据 | 当前最优解 + 限界函数 | 全局限界值比较（可预先排序） |

**（2）回溯法的限界条件**

**展开左子节点（选择第 $k+1$ 个物品）的限界条件**：

左子节点表示将物品 $k+1$ 放入背包，首先必须满足**可行性条件**：

$$
\text{cw} + w_{k+1} \leq c
$$

如果不满足，左子节点不可行，直接剪枝。

如果满足可行性条件，则展开左子节点，继续搜索。

**展开右子节点（不选第 $k+1$ 个物品）的限界条件**：

右子节点表示不将物品 $k+1$ 放入背包。需要判断不选该物品后，是否还有希望得到更优解：

$$
\text{cp} + \text{bound}(X') > \text{bestp}
$$

其中 $X'$ 是右子节点对应的状态，$\text{bound}(X')$ 是对剩余物品（$k+2$ 到 $n$）用连续背包贪心法计算的上界。

如果 $\text{cp} + \text{bound}(X') \leq \text{bestp}$，则即使把剩余物品全部（允许分割）装入，也无法超过当前最优解，**剪枝**。

**（3）LC 分支限界法的限界条件**

与回溯法使用相同的 bound 函数：

$$
\text{bound}(X) = \text{cp} + \text{剩余物品的连续背包价值}
$$

**节点选择规则**：从优先队列中选择 $\text{bound}(X)$ 最大的节点展开（对于最大化问题）。

**剪枝条件**：

- 左子节点：$\text{cw} + w_{k+1} \leq c$ 则展开，否则丢弃。
- 右子节点：$\text{cp} + \text{bound}(X') > \text{bestp}$ 则入堆，否则丢弃。
- **额外终止条件**：如果堆顶节点的 $\text{bound} \leq \text{bestp}$，则算法可以提前终止，因为堆中所有节点的 bound 值都不大于堆顶，即都不优于当前最优解。

**解析**：

1. 回溯法和分支限界法可以共用**相同的 bound 函数**，区别仅在于节点的展开顺序和管理方式。
2. 回溯法在搜索过程中动态更新 bestp，每条分支展开时用最新的 bestp 进行判断。
3. LC 分支限界法在展开节点时也使用 bestp 进行剪枝，但与回溯法不同的是，LC 检索优先展开 bound 值大的节点，往往能更快地找到高质量的解，从而更早地收紧剪枝条件。
4. 当问题规模较大时，LC 检索通常比回溯法搜索更少的节点就能找到最优解，但代价是需要维护优先队列，空间开销更大。

货箱装船问题：

- 这是一个特殊的 0/1 背包问题（价值等于重量），目标为最大化装载重量。
- 分支限界法与前述 0/1 背包的 LC-检索类似，只需将 $p_i = w_i$ 代入即可。
- 按重量降序排序有助于提高 bound 函数的剪枝效率。

<details>
<summary><b>点击展开完整解答</b></summary>

**（1）分支限界法伪代码**

```
// 货箱装船问题 - 分支限界法
// w[1..n]: 货箱重量, c: 第一艘船载重量

function MaxLoading(w, c, n):
    // 按重量降序排序
    sort w in descending order
    
    // 初始化
    bestw = 0                     // 当前最优装载量
    E = new Node(level=0, cw=0)  // 根节点（扩展节点）
    
    // 计算所有货箱总重量
    total_w = sum(w)
    
    // LC-检索：使用最大堆（按 bound 排序）
    heap = new MaxHeap()
    
    while true:
        // 尝试左子节点（选择当前货箱）
        if E.cw + w[E.level] <= c:
            left_cw = E.cw + w[E.level]
            if left_cw > bestw:
                bestw = left_cw       // 更新最优解
            // 计算左子节点的 bound
            left_bound = left_cw + remaining_possible(E.level+1, w, c, left_cw)
            if left_bound > bestw:
                heap.insert(Node(level=E.level+1, cw=left_cw, bound=left_bound))
        
        // 尝试右子节点（不选当前货箱）
        right_bound = E.cw + remaining_possible(E.level+1, w, c, E.cw)
        if right_bound > bestw:
            heap.insert(Node(level=E.level+1, cw=E.cw, bound=right_bound))
        
        // 选择下一个扩展节点
        if heap.isEmpty():
            break
        E = heap.extractMax()
        
        // 提前终止判断
        if E.bound <= bestw:
            break
    
    return bestw

function remaining_possible(k, w, c, cw):
    // 从第 k 个货箱开始，在剩余容量 (c-cw) 中
    // 按贪心方式（重量降序）最多能装的重量
    // 由于是整数背包（价值=重量），直接使用贪心即可
   剩余容量 = c - cw
   总重 = 0
   for i from k to n:
       if w[i] <= 剩余容量:
           总重 += w[i]
           剩余容量 -= w[i]
       else:
           break  // 不能再装入（按重量降序排列后，后续更小）
   return 总重
```

**（2）状态空间树**

给定 $n=4,\; c_1=12,\; w=[8,6,2,3]$。按重量降序排列：$w=[8,6,3,2]$。

**根节点**：cw=0，剩余容量=12。
- 左（选 8）：cw=8，bestw=8
- 右（不选 8）：cw=0

**展开左分支（选 8）**：cw=8，剩余=4。
- 左（再选 6）：8+6=14>12，不可行
- 右（不选 6，考虑 3）：8+3=11≤12，bestw=11
  - 左（再选 3）：cw=11
  - 右（不选 3，考虑 2）：8+2=10
    - 左（选 2）：cw=10
    - 右（不选 2）：cw=8

继续展开右分支，最终最优解为 $\text{bestw}=11$（选重量 8 和 3 的货箱），剩余 1 的重量装不上第一艘船。

具体状态空间树在此从略，思路与 0/1 背包相同。

### 自测题 4（来源：[Q0042]）

令三元组 $(p_i, d_i, t_i)$ 表示一个作业的罚款额、截止期和执行时间。试用 LC-分支限界法求解以下最小罚款额调度问题的实例：4 个作业的罚款额、截止期和执行时间分别为 $(8,2,1)$，$(4,2,1)$，$(9,3,2)$，$(2,1,1)$。

写出所使用的限界函数。对于上述实例，画出分支限界过程中展开的部分状态空间树。

**提示**：

- 最小罚款额调度问题：安排作业的执行顺序，使**未按时完成**的作业的罚款总额最小。
- 定义调度为作业的一个排列。检查一个调度是否可行：按顺序执行，每个作业必须在截止期 $d_i$ 之前完成。
- 一种常用的 bound 函数：**当前已选作业的罚款** + **剩余作业的最小可能罚款**（将剩余作业按罚款额降序排列，都视为延期，取前几个的最大可能罚款）。
- 具体做法：使用 LC-检索，每个节点记录已安排的作业集合和累计罚款，bound 为当前罚款 + 剩余作业全部罚款（这是最坏情况的下界）。

<details>
<summary><b>点击展开完整解答</b></summary>

**1. 问题分析**

我们有 4 个作业，每个作业 $(p_i, d_i, t_i)$ 分别表示罚款额、截止期（从开始时间算起的时间点）、执行时间。

| 作业 | 罚款 $p_i$ | 截止期 $d_i$ | 执行时间 $t_i$ |
|:---:|:----------:|:------------:|:-------------:|
| J1 | 8 | 2 | 1 |
| J2 | 4 | 2 | 1 |
| J3 | 9 | 3 | 2 |
| J4 | 2 | 1 | 1 |

目标：找到一个调度（作业执行顺序），使得**延误作业的罚款总额最小**。

一个作业如果在它的截止期之后完成，就算延误，要交罚款；如果在截止期之前（含）完成，就算按时，不交罚款。

**2. 限界函数**

对于节点 $X$，设已安排了部分作业，当前总罚款为 $\text{cp}$，剩余未安排的作业集合为 $S$。

**下界函数**（因为是最小化问题，下界表示至少会产生的罚款）：

$$
\text{bound}(X) = \text{cp} + \sum_{j \in S} p_j
$$

这个 bound 的含义是：当前已产生的罚款 **加上** 剩余所有作业的罚款（即假设剩余作业全部延误，这是最坏情况，也是罚款的下界——实际罚款不可能少于 0，但这里用"当前已产生 + 剩余全罚"作为最坏估计）。

注意：对于最小化问题，我们使用**下界**（lower bound），即"至少会产生这么多罚款"。如果某节点的下界已经大于当前最优解（当前找到的最小罚款），则该节点不可能产生更优解，应剪枝。

更精确的 bound 可以考虑剩余作业中部分可能按时完成，从而只累加那些**一定无法按时完成**的作业的罚款。但上述简单 bound 已足够用于本题。

### 自测题 5（来源：[Q0065]）

**题目**：

试用回溯法解决下列整数变换问题：关于整数 $i$ 的变换 $f$ 和 $g$ 定义如下：
$$f(i) = 3i; \qquad g(i) = \lfloor i/2 \rfloor$$
对于给定的两个整数 $n$ 和 $m$，要求用最少的变换 $f$ 和 $g$ 变换次数将 $n$ 变为 $m$。

**提示**：

- 这是一个**深度受限的搜索**问题（迭代加深搜索），因为搜索深度未知。
- 从 $n$ 开始，每次可以应用 $f$（乘 3）或 $g$（除以 2 取整）。
- 由于 $f$ 使数字快速增长，$g$ 使数字减小，需要合理的深度上限。
- 参考给出的伪代码，理解 `search(dep, n)` 函数的递归逻辑：每次尝试两种变换，直到达到指定深度 $k$。如果 $k$ 深度内找不到解，则增加深度上限继续搜索。

<details>
<summary><b>点击展开完整解答</b></summary>

**完整解答思路**：

本题使用**迭代加深搜索**（Iterative Deepening Depth-First Search, IDDFS），这是回溯法的一种变体。

**核心思想**：由于我们不知道最少需要多少次变换，因此从深度 $k=1$ 开始尝试，如果在深度 $k$ 内搜索不到解，则将深度上限 $k$ 加 1，重新搜索。这样既保证了找到的解是变换次数最少的，又控制了搜索空间的大小。

**已给出的伪代码**：

```c
void compute()
{
    k = 1;
    while (!search(1, n)) {
        k++;
        if (k > maxdep) break;
        init();
    }
    if (found) output();
    else cout << "No Solution!" << endl;
}

bool search(int dep, int n)
{
    if (dep > k) return false;
    for (int i = 0; i < 2; i++) {
        int n1 = f(n, i);
        t[dep] = i;
        if (n1 == m || search(dep+1, n1)) {
            found = true;
            out();
            return true;
        }
    }
    return false;
}
```

**代码解释**：

1. `compute()` 是主函数，从 $k=1$ 开始逐步增加深度上限。
2. `search(dep, n)` 是在当前深度上限 $k$ 下搜索解：
   - 如果当前深度 `dep` 超过了上限 `k`，返回 false。
   - 依次尝试两种变换（$i=0$ 对应 $f$，$i=1$ 对应 $g$）。
   - 如果变换后的值等于目标值 $m$，或者在更深层找到了解，则记录并返回 true。
3. 当找到解时，`t[dep]` 数组中存储了每一步使用的变换方式。

**优缺点**：
- 优点：保证找到的解步数最少，空间复杂度仅为 $O(k)$（递归深度）。
- 缺点：会重复搜索浅层的状态（但时间开销可以接受，因为深层节点占绝大多数）。

</details>

### 自测题 6（来源：[Q0070]）

**题目**：

解空间的表示方法是（  ）

A. 优先级树  
B. 子集树  
C. 排列树  
D. 以上三个都包括

**提示**：

- 回顾知识点 2.1 中关于解空间树的介绍。
- 回溯法和分支限界法处理的问题，其解空间通常用哪种树来表示？
- 子集树和排列树分别对应哪两类问题？

<details>
<summary><b>点击展开完整解答</b></summary>

**答案：D**

**解析**：

解空间树的表示方法包括三种：

1. **子集树（Subset Tree）**：当问题是从 $n$ 个元素的集合中找出满足某些性质的子集时使用。例如：0/1 背包问题、子集和数问题。子集树有 $2^n$ 个叶子节点。

2. **排列树（Permutation Tree）**：当问题是确定 $n$ 个元素满足某种性质的排列时使用。例如：TSP 问题、N 皇后问题。排列树有 $n!$ 个叶子节点。

3. **优先级树**：在某些问题中，解空间也可以用基于优先级关系的树来表示。

因此，D 选项"以上三个都包括"是正确的。

**注意**：虽然子集树和排列树是最常见的两种解空间树，但题目选项 D 包含了所有选项，所以选择 D。

</details>

> **小结**：回溯法和分支限界法是解决组合优化问题的两大"系统搜索"利器。回溯法简洁、空间效率高，适合深而窄的解空间；分支限界法通过优先队列策略，适合宽而浅的解空间。在实际应用中，限界函数的设计质量直接影响两种方法的效率——一个紧致的 bound 函数往往能让搜索量指数级下降。建议读者在掌握基本框架的基础上，多动手画状态空间树，感受剪枝带来的效率提升。
