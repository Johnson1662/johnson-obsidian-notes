# 第一章 算法概述与分析

## 1. 本章概述

本章从零开始建立"算法"的基本概念，介绍算法的定义、特性，以及如何科学地衡量一个算法的效率——包括渐近记号（大 $O$、$\Omega$、$\Theta$）、步计数法、递归方程的求解（代入法、递归树法、Master 定理），最后延伸至计算理论的复杂性分类（$P$、$NP$、$NP\text{-}hard$、$NP\text{-}complete$）。掌握本章内容是后续学习排序、动态规划、贪心等算法策略的基础。

## 2. 知识点讲解

### 2.1 算法的定义与特性

**通俗定义**：算法就是**一步一步执行、在有限步内结束**的计算步骤序列。可以理解为"做一道菜的食谱"——每一步都必须清晰明确，并且最终一定能做完。

**标准定义**：算法是求解问题的一系列**明确**的计算步骤，它通过**有限的**步骤将输入转化为输出。

**算法的五个基本特征**：

| 特性 | 含义 | 反例 |
|------|------|------|
| **有穷性** | 算法必须在执行有限步后终止 | 死循环不是算法 |
| **确定性** | 每一步的含义必须明确，无歧义 | "把数变大一点" → 不确定 |
| **可行性** | 每一步都可以在有限时间内完成 | "瞬间算出第 100 位质数" → 不现实 |
| **输入** | 算法有零个或多个输入 | — |
| **输出** | 算法至少产生一个输出 | — |

**初学易错点**：
- 把"算法"和"程序"混为一谈。程序可以无限运行（如操作系统），而**算法必须有限步终止**。所以操作系统本身不是算法，但操作系统中实现某个具体功能的模块（如进程调度器）可能是一个算法。
- "算法总能在执行有限步后终止"是算法的基本要求（有穷性），但并不是所有写得像算法的代码都满足这一点——写循环时忘记终止条件就可能违反有穷性。

### 2.2 渐近记号（Asymptotic Notations）

为什么要用渐近记号？因为精确的运行时间依赖于机器、语言、编译器，而我们只关心**输入规模 $n$ 增大时，时间增长的趋势**。

#### 2.2.1 大 $O$ 记号（上界）

> **$O(g(n))$** 表示算法运行时间的**增长不超过** $g(n)$ 的常数倍。

**标准定义**：
$$
O(g(n)) = \{ f(n) \mid \text{存在正常数 } c \text{ 和 } n_0 \text{，使得对所有 } n \ge n_0 \text{，有 } 0 \le f(n) \le c g(n) \}
$$

**举例**：$T(n) = 3n^2 + 10n$ 的渐近上界是 $O(n^2)$，因为当 $n \ge 10$ 时，$3n^2 + 10n \le 4n^2$（取 $c=4$）。

**直观理解**：大 $O$ 说"不会比这个更差"。面试常问"算法的时间复杂度是多少"，通常回答的就是 $O$ 上界。

#### 2.2.2 大 $\Omega$ 记号（下界）

> **$\Omega(g(n))$** 表示算法运行时间的**增长不低于** $g(n)$ 的常数倍。

**标准定义**：
$$
\Omega(g(n)) = \{ f(n) \mid \text{存在正常数 } c \text{ 和 } n_0 \text{，使得对所有 } n \ge n_0 \text{，有 } 0 \le c g(n) \le f(n) \}
$$

**举例**：$T(n) = 3n^2 + 10n$ 的渐近下界是 $\Omega(n^2)$，因为当 $n \ge 1$ 时，$3n^2 + 10n \ge 3n^2$（取 $c=3$）。

**直观理解**：大 $\Omega$ 说"至少不会比这个好"。

#### 2.2.3 大 $\Theta$ 记号（紧确界）

> **$\Theta(g(n))$** 表示算法运行时间的增长**恰好与 $g(n)$ 同阶**。

**标准定义**：
$$
\Theta(g(n)) = \{ f(n) \mid \text{存在正常数 } c_1, c_2, n_0 \text{，使得对所有 } n \ge n_0 \text{，有 } 0 \le c_1 g(n) \le f(n) \le c_2 g(n) \}
$$

**举例**：$T(n) = 3n^2 + 10n = \Theta(n^2)$，因为可以找到 $c_1=3, c_2=4$，使得 $3n^2 \le 3n^2+10n \le 4n^2$（$n \ge 10$）。

**直觉判定**：只看**最高次项**，忽略系数和低次项。$3n^2+10n$ 的最高次项是 $n^2$，所以是 $\Theta(n^2)$。$21+1/n$ 的最高次项是常数 $21$，所以是 $\Theta(1)$。

**初学易错点**：
- **不能直接说 $O$ 就是"最坏时间复杂度"**。$O$ 只是一个上界，最坏情况也可以有下界。通常我们说"最坏情况时间复杂度是 $O(n^2)$"，意思是即使在最坏情况下，时间增长不超过 $n^2$ 级别。
- 大 $O$ 关系具有**传递性**：若 $f = O(g)$ 且 $g = O(h)$，则 $f = O(h)$。
- **渐近记号之间可以运算**：$O(f) + O(g) = O(f+g)$（加法），$O(f) \cdot O(g) = O(f \cdot g)$（乘法）。

#### 2.2.4 常见时间复杂度的比较

从小到大（n 足够大时）：

$$
O(1) < O(\log n) < O(\sqrt n) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)
$$

**记忆口诀**：常数、对数、根号、线性、线性对数、平方、立方、指数、阶乘。

### 2.3 步计数法（Step Count Method）

**通俗定义**：把每一条语句的执行时间视为一个"单位步"，数一数所有语句一共执行了多少次，然后合并成一个关于 $n$ 的函数。

**标准步骤**：
1. 为每条语句确定 $s/e$（每执行一次消耗的步数，通常为 1）。
2. 计算每条语句的**执行频率**（共执行了多少次）。
3. 计算**总步数** = $\sum (s/e \times \text{频率})$。
4. 用渐近记号表示结果。

**举例**：下面的算法求数组中的最小值和最大值。

```
MinMax(a[], n):
  if n < 1: return false      // 1次
  Min = Max = 0               // 1次
  for i = 1 to n-1:           // n-1次
    if a[Min] > a[i]: Min=i   // 最坏: n-1次
    else if a[Max] < a[i]: Max=i  // 最坏: n-1次
  return true                  // 1次
```

最坏情况总步数 $\approx 1 + 1 + (n-1) + (n-1) + (n-1) + 1 = 3n$，所以最坏时间复杂度为 $\Theta(n)$。

**初学易错点**：
- 循环头部的判断语句（如 `i < n`）也要算步数，通常比循环体多执行 1 次。
- 频率表要逐行列清楚，不要跳步。

### 2.4 递归方程与求解方法

很多算法（如归并排序）是递归定义的，其时间复杂度满足一个**递归方程**（递推关系式）。常用的求解方法有三种：

#### 2.4.1 代入法（替换法 / Substitution Method）

**通俗定义**：先猜一个上界形式（例如 $T(n) \le c n^2$），然后用数学归纳法证明这个猜想成立。

**举例**：$T(1) = c$，$T(n) = 4T(n/2) + n$。

**步骤**：
1. **猜想**：$T(n) \le c_1 n^2 - c_2 n$。
2. **归纳假设**：假设对小于 $n$ 的所有规模，$T(k) \le c_1 k^2 - c_2 k$ 成立。
3. **代入验证**：
   $$
   \begin{aligned}
   T(n) &= 4T(n/2) + n \\
   &\le 4\left[c_1 (n/2)^2 - c_2 (n/2)\right] + n \\
   &= 4\left[c_1 n^2/4 - c_2 n/2\right] + n \\
   &= c_1 n^2 - 2c_2 n + n \\
   &= c_1 n^2 - c_2 n - (c_2 n - n)
   \end{aligned}
   $$
   只要取 $c_2 > 1$，就有 $c_2 n - n > 0$，所以 $T(n) \le c_1 n^2 - c_2 n$。
4. **验证初始条件**：取 $c_1 > c + c_2$，使 $n=1$ 时 $T(1) = c \le c_1 - c_2$ 成立。

因此 $T(n) = O(n^2)$。

**初学易错点**：
- 代入时要把 $T(n/2)$ 的 $n$ 都替换成 $n/2$，**不能漏换**。
- 必须验证基本情形（$n=1$），否则归纳不完整。
- 有时需要减去一个低次项（如 $-c_2 n$）才能让归纳成立。

#### 2.4.2 递归树法（Recursion Tree Method）

**通俗定义**：把递归展开成一棵树，树的每一层对应一次递归调用，然后逐层求和。

**举例**：$T(n) = T(n-2) + T(2) + cn$。

```
                  T(n)
          ┌────────┴────────┐
        T(n-2)             T(2)
    ┌────┴────┐            │
 T(n-4)      T(2)         ...
   ...        ...
```

每次递归减少 2 的规模，T(2) 是常数时间。总共约 $n/2$ 层，每层求和约 $O(n)$，所以 $T(n) = O(n^2)$。

**更严谨**地分析 $T(n) = T(n-1) + cn$：

```
第 1 层: cn
第 2 层: c(n-1)
第 3 层: c(n-2)
...
第 n 层: c(1)
```

总和 = $c(1 + 2 + \dots + n) = c \cdot \frac{n(n+1)}{2} = \Theta(n^2)$。

**初学易错点**：
- 递归树的层数要数清楚。$T(n) = T(n-1) + cn$ 有 $n$ 层，而 $T(n) = 2T(n/2) + cn$ 只有 $\log_2 n$ 层。
- 不要忘了叶子节点的代价（基本情形的 $T(1)$ 或 $T(2)$）。

#### 2.4.3 Master 定理（主方法）

**通俗定义**：对于形如 $T(n) = aT(n/b) + f(n)$ 的递归方程（$a \ge 1, b > 1$），可以直接套用公式，无需推导。

**标准形式**：$T(n) = aT(n/b) + f(n)$，其中 $a \ge 1$，$b > 1$。

令 $\log_b a$（即 $\log$ 以 $b$ 为底 $a$ 的对数），比较 $f(n)$ 与 $n^{\log_b a}$ 的增长速度：

| 情形 | 条件 | 结论 |
|------|------|------|
| **情形 1** | $f(n) = O(n^{\log_b a - \varepsilon})$，即 $f(n)$ 增长**慢于** $n^{\log_b a}$ | $T(n) = \Theta(n^{\log_b a})$ |
| **情形 2** | $f(n) = \Theta(n^{\log_b a})$，即增长速度**相同** | $T(n) = \Theta(n^{\log_b a} \log n)$ |
| **情形 3** | $f(n) = \Omega(n^{\log_b a + \varepsilon})$，且满足正则条件 | $T(n) = \Theta(f(n))$ |

**举例 1**：$T(n) = 7T(n/2) + cn^2$
- $a = 7, b = 2$，$\log_2 7 \approx 2.81$
- $f(n) = cn^2 = O(n^{2.81 - 0.5})$（取 $\varepsilon = 0.5$）
- 属于**情形 1**，所以 $T(n) = \Theta(n^{\log_2 7}) \approx \Theta(n^{2.81})$

**举例 2**：$T(n) = 4T(n/2) + n^2$
- $a = 4, b = 2$，$\log_2 4 = 2$
- $f(n) = n^2 = \Theta(n^2)$
- 属于**情形 2**，所以 $T(n) = \Theta(n^2 \log n)$

**举例 3**：$T(n) = 9T(n/3) + 11n^2$
- $a = 9, b = 3$，$\log_3 9 = 2$
- $f(n) = 11n^2 = \Theta(n^2)$
- 属于**情形 2**，所以 $T(n) = \Theta(n^2 \log n)$

**初学易错点**：
- **$\log_b a$ 的计算方法**：$\log_b a = \frac{\ln a}{\ln b}$。例如 $\log_2 7$ 是"2 的多少次方等于 7"（约 2.81）。
- Master 定理**不能直接用于**不是 $T(n) = aT(n/b) + f(n)$ 形式的递归，例如 $T(n) = T(n-1) + cn$（$b$ 不是常数）或 $T(n) = T(\sqrt n) + O(1)$。
- 情形 3 的正则条件：存在 $c < 1$ 和 $n_0$，使得 $a f(n/b) \le c f(n)$ 对所有 $n \ge n_0$ 成立。这个条件通常会自动满足，但理论上需要验证。

### 2.5 插入排序的复杂度分析

**问题描述**：将元素 $x$ 插入到已排序数组 $a[0:n-1]$ 的合适位置。

**伪代码**：
```
for i = n-1 down to 0 and x < a[i]:
    a[i+1] = a[i]
a[i+1] = x
```

**最好情况**：$x \ge a[n-1]$（即 $x$ 比已排序的最后一个元素还大或相等），只需要比较 **1 次**，然后直接放到末尾。

**最坏情况**：$x < a[0]$（即 $x$ 比已排序的第一个元素还小），需要比较 **$n$ 次**，然后把 $x$ 放到开头。

**平均情况**：在随机排列中，$x$ 在 $n$ 个位置中的等概率插入，平均比较次数为 $n/2$，所以平均也为 $\Theta(n)$。

### 2.6 算法复杂度的分类（P、NP、NP-hard、NP-complete）

#### 2.6.1 类 P（Polynomial Time）

**通俗定义**：存在**确定性**算法能在**多项式时间**（如 $O(n^2)$、$O(n^3)$）内求解的问题。例如：排序、最短路径、最小生成树。

#### 2.6.2 类 NP（Nondeterministic Polynomial Time）

**通俗定义**：对于一个**候选解**，能在多项式时间内**验证**它是否正确的问题。注意：NP 不是"非多项式"，而是"非确定性多项式"。

**举例**：旅行商问题（TSP）——你给我一条路线，我可以在多项式时间内验证它的总长度是否小于某个值。但要在所有路线中找到最短的，目前没有多项式时间算法。

**关系**：显然 $P \subseteq NP$（能快速求解当然就能快速验证）。

#### 2.6.3 NP-hard（NP 难）

**通俗定义**：如果**所有 NP 问题**都能在多项式时间内**约化**（转化）到问题 $Q$，那么 $Q$ 就是 NP-难的。

**直观理解**：$Q$ 至少和任何 NP 问题一样难。NP-难问题不一定属于 NP 类（即不一定能快速验证解）。

#### 2.6.4 NP-complete（NP 完全）

**通俗定义**：既是 NP 又是 NP-hard 的问题。NP-complete 是 NP 类中"最难"的那一批问题。

**关系图示**：

```
     ┌──────────────────────┐
     │         NP           │
     │  ┌───────────────┐   │
     │  │      P        │   │
     │  └───────────────┘   │
     │  ┌───────────────┐   │
     │  │  NP-complete  │   │
     │  └───────────────┘   │
     └──────────────────────┘
          NP-hard (包含之外的部分)
```

**证明一个问题是 NPC（NP-完全）的步骤**：
1. 证明该问题属于 NP（即能在多项式时间内验证一个候选解）。
2. 选择一个已知的 NPC 问题 $P$。
3. 证明 $P$ 可以**多项式地约化**到目标问题 $Q$（即构造一个多项式时间的变换，使得 $P$ 的 yes 实例对应 $Q$ 的 yes 实例）。

**初学易错点**：
- **$P \neq NP$ 是一个猜想**，尚未被证明。目前 $P \subseteq NP$ 是已知的，但 $P = NP$ 是否成立是千禧年未解难题。
- "NP 难"并不要求问题本身属于 NP，但"NP 完全"要求既属于 NP 又属于 NP 难。
- 多项式约化（Polynomial Reduction）不是"等价"，而是单向的：如果 $P$ 可约化为 $Q$，且 $Q$ 可解，则 $P$ 可解；反之不一定成立。

## 3. 典型例题

### 例题 1（来源：[Q0067]）

**题目**：计算机算法必须具备的三个特性是（ ）

A. 可执行性、可移植性、可扩充性

B. 可执行性、确定性、有穷性

C. 确定性、有穷性、稳定性

D. 易读性、稳定性、安全性

**解答**：

算法的基本特征包括：有穷性（有限步后终止）、确定性（每一步含义明确）、可行性（可执行）。选项中，**可执行性**对应可行性，**确定性**对应每一步无歧义，**有穷性**对应有限步终止。因此，B 选项的"可执行性、确定性、有穷性"是最核心的三条。

A 错在"可移植性、可扩充性"是软件工程中的概念，不是算法的基本特征。C 和 D 中出现的"稳定性"是排序算法的性质，"易读性"和"安全性"也不是算法必须的特征。

**答案**：B

**解析**：这道题直接考查算法定义中的核心特性。注意题目问的是"必须具备的"特性，这意味着缺少任何一个就不成其为算法。"稳定性""可移植性"虽然在实际编程中很重要，但它们不是算法的"必须"特征。

### 例题 2（来源：[Q0060]）

**题目**：对于下列各组函数 $f(n)$ 和 $g(n)$，确定 $f(n) = O(g(n))$ 或 $f(n) = \Omega(g(n))$ 或 $f(n) = \Theta(g(n))$，并简述理由。

(1) $f(n) = \log n^2$； $g(n) = \log n + 5$

(2) $f(n) = \log n^2$； $g(n) = \sqrt n$

(3) $f(n) = n$； $g(n) = \log^2 n$

**解答**：

**(1)** $f(n) = \log n^2 = 2 \log n$，$g(n) = \log n + 5$。当 $n$ 很大时，$\log n$ 起主导作用。
- 取 $c_1 = 1$，$c_2 = 2$：$1 \cdot (\log n + 5) \le 2 \log n \le 2 \cdot (\log n + 5)$ 对足够大的 $n$ 成立。
- 所以 $f(n) = \Theta(g(n))$。

**(2)** $\log n^2 = 2 \log n$，而 $\sqrt n$ 的增长速度远快于 $\log n$（因为指数函数增长快于对数函数）。
- 当 $n$ 足够大时，$2 \log n \le n^{1/2}$。
- 所以 $f(n) = O(g(n))$（$f$ 增长不超过 $g$）。

**(3)** $n$ 的增长速度远快于 $\log^2 n$。
- 当 $n$ 足够大时，$n \ge c \cdot \log^2 n$（对任何常数 $c$ 都成立）。
- 所以 $f(n) = \Omega(g(n))$（$f$ 的增长不低于 $g$）。

**解析**：这类核心题型要求熟练掌握常见函数的增长速度排名。指数 $(2^n)$ > 多项式 $(n^k)$ > 根号 $(\sqrt n)$ > 对数 $(\log n)$。$n$ 虽是线性级别的，但 $\log^2 n$ 仍然是对数级别，所以 $n$ 快于 $\log^2 n$。如果要死记：**指数 > 多项式 > 对数**。

### 例题 3（来源：[Q0010]）

**题目**：使用步计数法分析下面算法在最好和最坏情形的渐近时间复杂度。

```
template <class T>
bool MinMax(T a[], int n, int & Min, int & Max)
{
    if (n < 1) return false;          // 语句 1
    Min = Max = 0;                    // 语句 2
    for (int i = 1; i < n; i++)      // 语句 3
        if (a[Min] > a[i]) Min = i;  // 语句 4
        else if (a[Max] < a[i]) Max = i;  // 语句 5
    return true;                      // 语句 6
}
```

**解答**：

**分步计数**（每行 $s/e = 1$）：

| 语句 | 最好情况频率 | 最坏情况频率 |
|------|-------------|-------------|
| 语句 1 (`if n < 1`) | 1 次 | 1 次 |
| 语句 2 (`Min = Max = 0`) | 1 次 | 1 次 |
| 语句 3 (for 循环，含 $n-1$ 次循环体 + 1 次退出判断) | $n$ 次 | $n$ 次 |
| 语句 4 (`if a[Min] > a[i]`) | $n-1$ 次（每次判断一次） | $n-1$ 次 |
| 语句 5 (`else if`) | 0 次（每次 if 都进入） | $n-1$ 次（每次 if 不成立，走 else if） |
| 语句 6 (`return true`) | 1 次 | 1 次 |

**最好情况**（数组已逆序，即 $a[0] > a[1] > \dots > a[n-1]$）：
- 每次 `if (a[Min] > a[i])` 成立，所以 `Min = i` 每次都执行，不进入 `else if`。
- 总步数 = $1 + 1 + n + (n-1) + 0 + 1 = 2n + 2 = \Theta(n)$。

**最坏情况**（数组已正序，即 $a[0] < a[1] < \dots < a[n-1]$）：
- 每次 `if (a[Min] > a[i])` 不成立（因为 $a[i]$ 更大），所以进入 `else if`。
- 总步数 = $1 + 1 + n + (n-1) + (n-1) + 1 = 3n + 1 = \Theta(n)$。

**答案**：最好情形 $\Theta(n)$，最坏情形 $\Theta(n)$。

**解析**：注意这道题的**最好和最坏都是 $\Theta(n)$**，因为无论如何外层循环必须遍历所有元素。区别仅在于语句 5 执行了 0 次还是 $n-1$ 次，这只是常数级别的差异，不影响渐近阶。这也说明：步计数法一定要算到最后用 $\Theta$ 表示，不要因常数不同就误以为阶数不同。

### 例题 4（来源：[Q0008]）

**题目**：应用 Master 方法求解以下递归方程

(1) $T(n) = 7T(n/2) + cn^2$

(2) $T(n) = 4T(n/2) + n^2$

**解答**：

**(1)** $T(n) = 7T(n/2) + cn^2$

- $a = 7$，$b = 2$，$\log_b a = \log_2 7 \approx 2.81$。
- $f(n) = cn^2 = O\left(n^{2.81 - \varepsilon}\right)$，取 $\varepsilon = 0.5$，则 $2.81 - 0.5 = 2.31$。$n^2$ 确实慢于 $n^{2.31}$。
- 属于 **Master 情形 1**：$f(n) = O\left(n^{\log_b a - \varepsilon}\right)$。
- 结论：$T(n) = \Theta\left(n^{\log_b a}\right) = \Theta\left(n^{\log_2 7}\right) \approx \Theta(n^{2.81})$。

**(2)** $T(n) = 4T(n/2) + n^2$

- $a = 4$，$b = 2$，$\log_b a = \log_2 4 = 2$。
- $f(n) = n^2 = \Theta\left(n^{\log_b a}\right) = \Theta(n^2)$。
- 属于 **Master 情形 2**：$f(n) = \Theta\left(n^{\log_b a}\right)$。
- 结论：$T(n) = \Theta\left(n^{\log_b a} \log n\right) = \Theta(n^2 \log n)$。

**解析**：Master 定理的三步法：
1. 从递归式中提取 $a$（子问题个数）、$b$（规模缩小的倍数）。
2. 计算 $\log_b a$，并将 $f(n)$ 与 $n^{\log_b a}$ 比较。
3. 根据比较结果（小/相等/大）套用对应情形。

注意 $(2)$ 中 $f(n) = n^2$ 恰好等于 $n^{\log_2 4}$，这时不能直接说答案是 $\Theta(n^2)$——情形 2 要求乘以 $\log n$。初学者最常犯的错误是忘记情形 2 多出的 $\log n$ 因子。

### 例题 5（来源：[Q0045]）

**题目**：什么是类 P、类 NP、NP 难、NP 完全问题？画图说明它们的关系。

**解答**：

**类 P**：在**多项式时间**内（由**确定性**算法）可以求解的问题集合。例如：求数组最大值（$O(n)$）、归并排序（$O(n\log n)$）、最短路径（Dijkstra 算法 $O(E\log V)$）。

**类 NP**：在多项式时间内可以**验证**一个候选解是否正确的问题集合。注意：这里的"NP"不是"非多项式"，而是"非确定性多项式"（Nondeterministic Polynomial）。例如：数独——如果有人给你一个填写好的数独盘面，你可以在多项式时间内验证它是否满足所有规则。

**NP 难（NP-hard）**：如果所有 NP 问题都能在多项式时间内**约化**到问题 $Q$，则 $Q$ 是 NP 难的。直观理解：$Q$ 至少和任何 NP 问题一样难。

**NP 完全（NP-complete）**：既是 NP 问题，又是 NP 难的问题。它是 NP 类中最难的问题。一旦一个 NPC 问题被证明有多项式时间算法，那么所有 NP 问题都有多项式时间算法（即 $P = NP$）。

**关系图**：

```
                 ┌────────────────────────┐
                 │          NP            │
                 │  ┌──────────────┐      │
                 │  │      P       │      │
                 │  │  (多项式可解) │      │
                 │  └──────────────┘      │
                 │  ┌──────────────┐      │
                 │  │ NP-complete  │      │
                 │  │  (NP完全问题) │      │
                 │  └──────────────┘      │
                 └────────────────────────┘
        ┌──────────────────────────────────────┐
        │          NP-hard (NP难问题)           │
        │  (包括 NP-complete 以及更难的)        │
        └──────────────────────────────────────┘
```

**解析**：考试中常出现的易错点：

- $P \subseteq NP$ 是确定的，但 $P = NP$ 还是 $P \subsetneq NP$ 尚未知。
- NP 难的问题**不一定属于 NP**（例如图灵停机问题是 NP 难的，但它不可判定，不属于 NP）。
- NP 完全问题是 NP 和 NP 难的**交集**。所以证明一个问题是 NPC 必须做两件事：（1）证明它在 NP 中；（2）证明它是 NP 难的。

### 自测题 14（来源：[Q0009]）

**题目**：假定 $T(n)$ 满足以下递归式

$$
T(1) = c,\quad T(n) = 4T(n/2) + n \quad (n > 1)
$$

式中 $c$ 为正的常数。用归纳法证明 $T(n) \le c_1 n^2 - c_2 n$，$c_1$ 和 $c_2$ 为待定常数。

**提示**：先假设结论对 $n/2$ 成立，代入递归式右侧的 $4T(n/2)$，然后整理出 $c_1 n^2 - c_2 n$ 的形式。注意要加上一项 $-(c_2 n - n)$。

<details>
<summary>查看答案</summary>

**答案**：**证明**：

假设当小于 $n$ 时归纳假设成立：
$$
T(n/2) \le c_1 (n/2)^2 - c_2 (n/2)
$$

代入递归式：
$$
\begin{aligned}
T(n) &= 4T(n/2) + n \\
&\le 4[c_1(n/2)^2 - c_2(n/2)] + n \\
&= 4[c_1 n^2/4 - c_2 n/2] + n \\
&= c_1 n^2 - 2c_2 n + n \\
&= c_1 n^2 - c_2 n - (c_2 n - n)
\end{aligned}
$$

取 $c_2 > 1$，则 $c_2 n - n > 0$，所以：
$$
T(n) \le c_1 n^2 - c_2 n
$$

再验证初始条件 $n = 1$ 时，需要 $T(1) = c \le c_1 - c_2$，取 $c_1 \ge c + c_2$ 即可。

因此，存在常数 $c_1, c_2$ 使得 $T(n) \le c_1 n^2 - c_2 n$ 对所有 $n \ge 1$ 成立，即 $T(n) = O(n^2)$。
</details>

### 自测题 15（来源：[Q0022]）

**题目**：应用 Master 方法求解以下递归方程：

(1) $T(n) = 4T(n/2) + n^{1.9}$

(2) $T(n) = 9T(n/2) + n^2 2^n$

(3) $T(n) = 9T(n/3) + 11n^2$

**提示**：提取 $a, b$，计算 $\log_b a$，与 $f(n)$ 比较。

<details>
<summary>查看答案</summary>

**答案**：

**(1)** $a=4, b=2, \log_2 4 = 2$。$f(n)=n^{1.9}=O(n^{2-0.1})$。属于**情形 1**。所以 $T(n)=\Theta(n^{\log_2 4})=\Theta(n^2)$。

**(2)** $a=9, b=2, \log_2 9 \approx 3.17$。$f(n)=n^2 2^n$。指数函数 $2^n$ 的增长速度远远快于任何 $n^{3.17}$，所以 $f(n)=\Omega(n^{\log_2 9+\varepsilon})$。检查正则条件：$a f(n/b) = 9 \cdot (n/2)^2 2^{n/2} = \frac{9}{4} n^2 2^{n/2}$，$c f(n) = c n^2 2^n$。对足够大的 $n$，$\frac{9}{4} 2^{n/2} \le c 2^n$ 成立（取 $c=1$，则 $\frac{9}{4} \le 2^{n/2}$ 对 $n \ge 4$ 成立）。属于**情形 3**。所以 $T(n)=\Theta(f(n))=\Theta(n^2 2^n)$。

**(3)** $a=9, b=3, \log_3 9 = 2$。$f(n)=11n^2=\Theta(n^2)$。属于**情形 2**。所以 $T(n)=\Theta(n^2 \log n)$。
</details>

### 自测题 16（来源：[Q0033]）

**题目**：应用 Master 方法求解以下递归方程：

(1) $T(n) = 27T(n/3) + 11n^3$

(2) $T(n) = 64T(n/4) + 10n^3 \log_2 n$

**提示**：分别计算 $a, b$，算出 $\log_b a$ 并与 $f(n)$ 比较。

<details>
<summary>查看答案</summary>

**答案**：

**(1)** $a=27, b=3$，$\log_3 27 = 3$。$f(n) = 11n^3 = \Theta(n^3)$。属于**情形 2**。所以 $T(n) = \Theta(n^3 \log n)$。

**(2)** $a=64, b=4$，$\log_4 64 = \log_4 (4^3) = 3$。$f(n) = 10n^3 \log_2 n$。由于 $\log_2 n$ 的增长速度慢于任何 $n^\varepsilon$，所以 $f(n)$ 的增长比 $n^3$ 快但比 $n^{3+\varepsilon}$ 慢。然而 Master 定理的情形划分要求 $f(n)$ 与 $n^{\log_b a} = n^3$ 比较——这里 $f(n) = n^3 \log n$，比 $n^3$ 多了一个 $\log n$ 因子，但并不符合情形 1（因为不是 $O(n^{3-\varepsilon})$），也不完全符合情形 2（因为 $n^3 \log n \neq \Theta(n^3)$），也不完全符合情形 3（因为不是 $\Omega(n^{3+\varepsilon})$）。这种情况更为精细，可以用扩展的 Master 定理：

对于 $f(n) = n^{\log_b a} (\log n)^k$，有 $T(n) = \Theta(n^{\log_b a} (\log n)^{k+1})$。

所以 $T(n) = \Theta(n^3 (\log n)^2)$。
</details>

### 自测题 17（来源：[Q0034]）

**题目**：展开递归式 $T(n) = T(n-1) + cn$，并对 $T(n)$ 做渐近分析。

**提示**：用递归树方法，逐层展开，看看第 1 层、第 2 层、……、第 $n$ 层的代价分别是多少。

<details>
<summary>查看答案</summary>

**答案**：$T(n) = \Theta(n^2)$

**展开**：
$$
\begin{aligned}
T(n) &= T(n-1) + cn \\
&= T(n-2) + c(n-1) + cn \\
&= T(n-3) + c(n-2) + c(n-1) + cn \\
&= \dots \\
&= T(1) + c[1 + 2 + \dots + n] \\
&= T(1) + c \cdot \frac{n(n+1)}{2} = \Theta(n^2)
\end{aligned}
$$

递归树有 $n$ 层，每层的代价分别是 $cn, c(n-1), \dots, c$，总和是一个等差数列，结果为 $\Theta(n^2)$。
</details>

### 自测题 18（来源：[Q0023]）

**题目**：展开递归式 $T(n) = T(n-2) + T(2) + cn$ 的递归树并作渐近分析。

**提示**：$T(2)$ 是常数。每次递归减少 2 的规模，大约有多少层？每层的总代价如何？

<details>
<summary>查看答案</summary>

**答案**：$T(n) = O(n^2)$

**递归树展开**：
```
                 T(n)
          ┌───────┴───────┐
        T(n-2)          T(2) + cn
    ┌─────┴─────┐
 T(n-4)      T(2) + c(n-2)
   ...       
```

递归深度约 $n/2$。每一层存在一个 $T(2)$ 分支（常数时间），和一个大小为 $cn, c(n-2), \dots$ 的线性项。将所有层相加：

$$
\sum_{k=0}^{n/2} \left[T(2) + c(n - 2k)\right] = \Theta(n) + c \cdot \Theta(n^2) = \Theta(n^2)
$$

所以 $T(n) = \Theta(n^2)$。
</details>

### 自测题 20（来源：[Q0043]）

**题目**：简述渐近记号 $O$、$\Omega$、$\Theta$ 的含义。

**提示**：分别从"上界""下界""紧确界"三个角度回答，可以举例说明。

<details>
<summary>查看答案</summary>

**答案**：

- **$O(g(n))$**：表示"不超过" $g(n)$ 的常数倍，即渐近上界。若 $f(n)=O(g(n))$，则存在 $c,n_0>0$，使 $0 \le f(n) \le c g(n)$ 对所有 $n \ge n_0$ 成立。
- **$\Omega(g(n))$**：表示"不低于" $g(n)$ 的常数倍，即渐近下界。若 $f(n)=\Omega(g(n))$，则存在 $c,n_0>0$，使 $0 \le c g(n) \le f(n)$ 对所有 $n \ge n_0$ 成立。
- **$\Theta(g(n))$**：表示"等于" $g(n)$ 的常数倍，即渐近紧确界。若 $f(n)=\Theta(g(n))$，则存在 $c_1,c_2,n_0>0$，使 $0 \le c_1 g(n) \le f(n) \le c_2 g(n)$ 对所有 $n \ge n_0$ 成立。

**举例**：$f(n)=3n^2+10n$，则 $f(n)=O(n^2)=\Omega(n^2)=\Theta(n^2)$。
</details>

### 自测题 21（来源：[Q0059]）

**题目**：

(1) 证明：$O(f) + O(g) = O(f+g)$

(2) 求下列函数的渐近表达式：
① $3n^2+10n$　　② $21 + 1/n$

**提示**：(1) 根据大 $O$ 定义，设 $F \in O(f)$, $G \in O(g)$，然后找 $n_0$ 和 $c$ 使 $F+G \le c(f+g)$。(2) 渐近表达式就是最高次项。

<details>
<summary>查看答案</summary>

**答案**：

**(1) 证明**：

由 $O$ 的定义：$F(n)=O(f(n))$ 意味着存在 $n_1, c_1$，使得对所有 $n \ge n_1$，$F(n) \le c_1 f(n)$。

同理，$G(n)=O(g(n))$ 意味着存在 $n_2, c_2$，使得对所有 $n \ge n_2$，$G(n) \le c_2 g(n)$。

取 $c_3 = \max\{c_1, c_2\}$，$n_3 = \max\{n_1, n_2\}$，则对所有 $n \ge n_3$：

$$
F(n) \le c_1 f(n) \le c_3 f(n),\quad G(n) \le c_2 g(n) \le c_3 g(n)
$$

所以：
$$
F(n) + G(n) \le c_3 f(n) + c_3 g(n) = c_3 [f(n) + g(n)]
$$

即 $F+G = O(f+g)$，也就是 $O(f) + O(g) = O(f+g)$。

**(2)**：
① $3n^2+10n$ 的渐近表达式是 $3n^2$（最高次项）。
② $21 + 1/n$ 的渐近表达式是 $21$（常数项）。
</details>

### 自测题 22（来源：[Q0001]）

**题目**：

1、简述 NP、NPH 问题和它们之间的关系。

2、证明 $\Theta(f(n)) + \Theta(g(n)) = \Theta(\min\{f(n), g(n)\})$。

3、动态规划适用于哪些问题？简述动态规划思想。

**提示**：第 2 题注意 $\Theta$ 定义的双侧有界性，以及 $\min$ 的含义。第 3 题与本章关系不大，可参考动态规划章节。

<details>
<summary>查看答案</summary>

**答案**：

**1. NP 与 NPH 的关系**：
- **NP（非确定性多项式）**：能在多项式时间内验证一个候选解的正确性的问题集合。
- **NPH（NP 难）**：所有 NP 问题都能在多项式时间内约化到它的问题。
- **关系**：NP 难问题至少和任何 NP 问题一样难。NP 完全问题是 NP 和 NP 难的**交集**。如果 $P \neq NP$，则 NPC 问题既不在 $P$ 中，也不可多项式的求解。

**2. 证明**：

设 $F(n) \in \Theta(f(n))$，则存在 $c_1, c_2, n_1$，使得 $c_1 f(n) \le F(n) \le c_2 f(n)$（$n \ge n_1$）。

设 $G(n) \in \Theta(g(n))$，则存在 $d_1, d_2, n_2$，使得 $d_1 g(n) \le G(n) \le d_2 g(n)$（$n \ge n_2$）。

令 $h(n) = \min\{f(n), g(n)\}$。

由于 $F(n) + G(n) \ge c_1 f(n) + d_1 g(n) \ge \min\{c_1, d_1\} \cdot (f(n) + g(n)) \ge \min\{c_1, d_1\} \cdot h(n)$。

同时 $F(n) + G(n) \le c_2 f(n) + d_2 g(n) \le \max\{c_2, d_2\} \cdot (f(n) + g(n))$。

而 $f(n) + g(n) \le 2 \max\{f(n), g(n)\}$，但本题要求 $\min$……实际上需更严谨分析。

更直接的思路：$f(n) + g(n) \le 2\max\{f,g\}$，且 $f(n) + g(n) \ge \max\{f,g\}$。而 $\max\{f,g\} \ge \min\{f,g\}$，且 $\max\{f,g\} \le \frac{f+g}{\min\{f,g\}} \cdot \min\{f,g\}$……实际上一个更稳妥的方式是利用 $\Theta$ 定义。但本题可能有歧义，通常结论是 $\Theta(f) + \Theta(g) = \Theta(\max\{f,g\})$（而不是 $\min$）。请以课堂讲授为准。

**3. 动态规划**：适用于具有**最优子结构**和**重叠子问题**特性的问题。思想是将大问题分解为小问题，先求解小问题并将结果存储（记忆化），避免重复计算，从而高效地得到最优解。
</details>

### 自测题 23（来源：[Q0052]）

**题目**：

(1) 简述算法复杂性分析的方法及用途。

(2) 算法 A 的计算时间 $f(n)$ 满足递归关系式 $f(n) = 2f(n-1) + 1$（$n > 0$，$f(0) = 1$）。算法 B 的计算时间 $g(n) = 2f(n/2) + \log n$。请使用渐进符号分别表示 $f(n)$ 和 $g(n)$。

(3) 简述多项式约化的含义，并简述证明一个问题是 NPC 问题的步骤。

**提示**：(2) 中 $f$ 和 $g$ 是独立的两个函数。$f(n) = 2f(n-1) + 1$ 是线性递推，可以展开为等比数列。$g(n)$ 中的 $f$ 已由前一步求出。

<details>
<summary>查看答案</summary>

**答案**：

**(1)** 方法：**解析法**（通过数学推导得到精确函数表达式或渐近阶）和**实验测量法**（实际运行程序，测量不同规模下的时间）。用途：选择适合的算法、评价算法效率、预测大规模输入时的表现。

**(2)** 展开 $f(n) = 2f(n-1) + 1$：
$$
\begin{aligned}
f(n) &= 2[2f(n-2) + 1] + 1 = 4f(n-2) + 2 + 1 \\
&= 2^k f(n-k) + (2^{k-1} + \dots + 2 + 1) \\
&= 2^n f(0) + (2^{n-1} + \dots + 1) \\
&= 2^n + (2^n - 1) = 2^{n+1} - 1
\end{aligned}
$$
所以 $f(n) = O(2^n)$。

$g(n) = 2f(n/2) + \log n = 2 \cdot (2^{n/2+1} - 1) + \log n = 2^{n/2+2} - 2 + \log n = O(2^{n/2})$。

**(3) 多项式约化**：问题 $P$ 可多项式地约化为问题 $Q$，如果存在一个多项式时间的确定性算法 $T$，使得对任意输入 $x$，$T$ 输出 $T(x)$，且 $x$ 是 $P$ 的 yes 实例当且仅当 $T(x)$ 是 $Q$ 的 yes 实例。

**证明问题是 NPC 的步骤**：
1. 选择一已知的 NP-完全问题 $P$。
2. 证明 $P$ 可多项式地约化为目标问题 $Q$。
3. （还需额外一步）证明 $Q$ 属于 NP 类。
</details>

### 自测题 24（来源：[Q0053]）

**题目**：分析下面用伪代码描述的算法的复杂性，写出分析过程。

```
for m = 2 to n do {
    for i = 0 to n - m do {
        j = i + m
        w(i, j) = w(i, j-1) + P(i) + Q(j)
        c(i, j) = min_{i < l ≤ j} { c(i, l-1) + c(l, j) } + w(i, j)
    }
}
```

$W(n,n)$，$P(n)$，$Q(n)$，$c(n,n)$ 为算法中使用的数组并已初始化。

**提示**：最内层的 $\min_{i < l \le j} \{ \dots \}$ 需要遍历 $j-i$ 个元素。分析 $\min$ 操作的执行时间，然后逐层累加。

<details>
<summary>查看答案</summary>

**答案**：$\Theta(n^3)$

**分析**：
1. 最内层的 $\min_{i < l \le j} \{ c(i, l-1) + c(l, j) \}$ 需要遍历 $j-i$ 个 $l$ 值，即执行 $m-1$ 次（因为 $j-i=m$），所以执行时间为 $\Theta(m)$。
2. 内层 `for i` 循环执行 $n-m+1$ 次，每次执行时间 $\Theta(m)$，故内层总时间 $\Theta(m(n-m+1)) = \Theta(m(n-m))$。
3. 外层 `for m` 循环从 $m=2$ 到 $n$，总时间：
   $$
   \sum_{m=2}^{n} m(n-m) = \sum_{m=1}^{n} m(n-m) = n \sum_{m=1}^{n} m - \sum_{m=1}^{n} m^2 = n \cdot \frac{n(n+1)}{2} - \frac{n(n+1)(2n+1)}{6} = \Theta(n^3)
   $$

所以算法的时间复杂度为 $\Theta(n^3)$。
</details>
