### 集装箱装船问题与0/1背包问题的回溯解题思路

### **一、问题共性**

二者均属于组合优化问题，需在满足约束条件下寻找最优解，具有以下共同特征：

- **解空间树结构**：决策过程可建模为状态空间树，每个节点代表部分解，分支对应二元选择（装入/不装入）。
- **深度优先搜索**：通过递归或迭代实现DFS遍历，优先探索深层节点。
- **剪枝策略**：结合约束条件与限界函数，动态剪除无效分支以提升效率。

---

### **二、解题思路对比**

| **问题**           | **集装箱装船问题**                           | **0/1背包问题**                             |
| ------------------ | -------------------------------------------- | ------------------------------------------- |
| **核心目标**       | 找到子集使其总重量尽可能接近第一艘船容量`c₁` | 在容量限制下选择物品使总价值最大            |
| **状态表示**       | 当前已选集装箱总重量`cw`，剩余总重量`r`      | 当前总重量`cw`，总价值`cp`，剩余价值上界`b` |
| **预处理**         | 集装箱按重量降序排列（尽早剪枝）             | 物品按单位价值`p/w`降序排列（优化限界计算） |
| **左子树剪枝条件** | `cw + w[i] > c₁`（超载）                     | `cw + w[i] > c`（超容）                     |
| **右子树剪枝条件** | `cw + r ≤ bestw`（剩余无法优化当前最优）     | `Bound(i+1) ≤ bestp`（限界不足）            |
| **最优解更新条件** | 到达叶节点且`cw > bestw`                     | 到达叶节点且`cp > bestp`                    |

---

### **三、剪枝策略详解**

1. **集装箱装船问题**：
   - **左子树剪枝**：若装入当前集装箱导致超载（cw + w[i] > c₁），**跳过该分支**。
   - **右子树剪枝**：若当前总重量与剩余所有集装箱重量之和无法超过已知最优解（cw + r ≤ bestw），**停止探索该分支**。
2. **0/1背包问题**：
   - **左子树剪枝**：装入当前物品导致超容时剪枝。
   - **右子树限界函数**：计算剩余物品在最优情况下的价值上界（允许部分装入），若此上界无法超过当前最优值则剪枝。

---

### **四、算法框架**

**回溯模板**：

<!-- Column 1 -->

```c++
template<class T>
class Loading {
private:
    T* w;          // 集装箱重量数组
    T c;           // 船的最大载重
    int n;         // 集装箱数量
    int* x;        // 当前解
    int* bestx;    // 最优解
    T bestw;       // 最优解的总重量
    T cw;          // 当前载重
    T r;           // 剩余集装箱总重量

public:
    void maxLoading(int i) {
        if (i > n) {  // 到达叶节点
            for (int j = 1; j <= n; j++) {
                bestx[j] = x[j];
            }
            bestw = cw;
            return;
        }

        r -= w[i];  // 剩余重减去集装箱重量
        // 尝试装入当前集装箱（x[i] = 1）
        if (cw + w[i] <= c) {
            x[i] = 1;
            cw += w[i];
            maxLoading(i + 1);
            cw -= w[i];  // 回溯
        }

        // 尝试不装入当前集装箱（x[i] = 0）
        if (cw + r > bestw) {  // 限界条件
            x[i] = 0;
            maxLoading(i + 1);
        }
        r += w[i];  // 恢复剩余重量
    }
};

template<class T>
T MaxLoading(T w[], T c, int n, int bestx[]) {
    Loading<T> X;
    X.x = new int[n + 1];
    X.w = w;
    X.c = c;
    X.n = n;
    X.bestx = bestx;
    X.bestw = 0;
    X.cw = 0;
    X.r = 0;

    for (int i = 1; i <= n; i++) {
        X.r += w[i];
    }

    X.maxLoading(1);
    delete[] X.x;
    return X.bestw;
}
```

$$\boxed{
\begin{aligned}
&\text{\textbf{Algorithm MaxLoading}(w, c, n, bestx)} \\
&\quad \text{\textbf{Input}: } \\
&\quad \quad \bullet\ \text{重量数组 } w[1..n] \\
&\quad \quad \bullet\ \text{船的最大载重 } c \\
&\quad \quad \bullet\ \text{集装箱数量 } n \\
&\quad \quad \bullet\ \text{最优解数组 } bestx[1..n] \\
&\quad \text{\textbf{Output}: } \text{最优装载重量 } bestw \\
&\quad \text{\textbf{Procedure}:} \\
&\quad 1.\ \text{初始化 } bestw \leftarrow 0,\ cw \leftarrow 0,\ r \leftarrow \sum_{i=1}^{n} w[i] \\
&\quad 2.\ \text{调用 } \text{maxLoading}(1) \\
&\quad 3.\ \mathbf{return}\ bestw \\
&\quad \mathbf{end\ procedure}
\end{aligned}
}$$

$$\boxed{
\begin{aligned}
&\text{\textbf{Algorithm maxLoading}(i)} \\
&\quad \text{\textbf{Input}: } \text{当前决策层 } i \\
&\quad \text{\textbf{Procedure}:} \\
&\quad 1.\ \mathbf{if}\ i > n: \quad \textcolor{gray}{// 到达叶节点} \\
&\quad \quad \quad bestx[1..n] \leftarrow x[1..n] \\
&\quad \quad \quad bestw \leftarrow cw \\
&\quad \quad \quad \mathbf{return} \\
&\quad 2.\ r \leftarrow r - w[i] \quad \textcolor{gray}{// 剩余重量更新} \\
&\quad 3.\ \mathbf{if}\ cw + w[i] \leq c: \quad \textcolor{gray}{// 尝试装入} \\
&\quad \quad \quad x[i] \leftarrow 1 \\
&\quad \quad \quad cw \leftarrow cw + w[i] \\
&\quad \quad \quad \text{maxLoading}(i + 1) \\
&\quad \quad \quad cw \leftarrow cw - w[i] \quad \textcolor{gray}{// 回溯} \\
&\quad 4.\ \mathbf{if}\ cw + r > bestw: \quad \textcolor{gray}{// 限界条件} \\
&\quad \quad \quad x[i] \leftarrow 0 \\
&\quad \quad \quad \text{maxLoading}(i + 1) \\
&\quad 5.\ r \leftarrow r + w[i] \quad \textcolor{gray}{// 恢复剩余重量} \\
&\quad \mathbf{end\ procedure}
\end{aligned}
}$$

### **五、关键优化点**

---

- **排序预处理**：通过降序排列加速剪枝，使无效分支尽早暴露。
- **动态更新剩余值**：维护剩余总重量（集装箱）或价值上界（背包），避免重复计算。
- **记忆化技术**：部分问题可通过缓存中间结果减少冗余搜索（如子集和问题的记忆化回溯）。

---

### **六、复杂度与适用性**

- **时间复杂度**：最坏情况仍为指数级$O(2ⁿ)$，但剪枝显著降低实际复杂度。
- **适用场景**：中等规模问题，或问题具有强约束条件使得剪枝高效。
