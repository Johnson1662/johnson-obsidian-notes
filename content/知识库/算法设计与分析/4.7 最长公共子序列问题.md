### 1. **问题定义**

给定两个序列：

- $X = \langle x_1, x_2, \dots, x_m \rangle$
- $Y = \langle y_1, y_2, \dots, y_n \rangle$

**子序列**：从原序列中删除零个或多个元素后得到的序列（保持剩余元素的相对顺序）。

**公共子序列**：既是X的子序列，又是 Y 的子序列。

**最长公共子序列（LCS）**：所有公共子序列中长度最长的子序列（可能不唯一）。

### 2. **动态规划解法**

- **状态定义**：
  $c[i][j]$ 表示 $X[1..i]$ 和 $Y[1..j]$ 的 LCS 长度。
- **初始条件**：
  $c[i][0] = 0$（$1 \leq i \leq m$），$c[0][j] = 0$（$1 \leq j \leq n$）。
- **递推关系**：
  $$c[i][j] = 
\begin{cases} 
c[i-1][j-1] + 1 & \text{if } x_i = y_j, \\ 
\max(c[i-1][j], c[i][j-1]) & \text{if } x_i \neq y_j. 
\end{cases}$$
- **目标**：
  $c[m][n]$ 即为 LCS 的长度。

### 3. **构造 LCS**

通过辅助方向矩阵 $b[i][j]$ 回溯：

- $b[i][j] = 1$（对角线）：$x_i = y_j$，属于 LCS。
- $b[i][j] = 2$（向上）：$c[i-1][j] \geq c[i][j-1]$。
- $b[i][j] = 3$（向左）：$c[i][j-1] > c[i-1][j]$。

### 4. **复杂度分析**

- **时间复杂度**：$O(mn)$（填表 + 回溯）。
- **空间复杂度**：$O(mn)$（可优化至 $O(\min(m, n))$）。

### 5.来个例题

### **给定序列**

- **X = A B C B D A B**（长度 m = 7）
- **Y = B D C A B A**（长度 n = 6）

### **1. 初始化 DP 表**

- 创建一个 `(m+1) × (n+1)` 的二维数组 `c[i][j]`，其中 `i` 对应 X 的字符，`j` 对应 Y 的字符。
- 初始化 `c[0][j] = 0`（第一行）和 `c[i][0] = 0`（第一列），表示空序列的 LCS 长度为 0。

### **2. 填表规则**

对于每个 `i`（1 ≤ i ≤ m）和 `j`（1 ≤ j ≤ n）：

- **如果 **`**X[i] == Y[j]**`：
  - `c[i][j] = c[i-1][j-1] + 1`（继承左上角的值 +1）。
- **如果 **`**X[i] != Y[j]**`：
  - `c[i][j] = max(c[i-1][j], c[i][j-1])`（取上方或左方的较大值）。

### **3. 逐步填表**

我们逐行计算 `c[i][j]`：

**第 1 行（X = A）**

- `X[1] = A`，与 Y 的每个字符比较：

  - `Y[2] = D` → `A != D` → `c[1][2] = max(0, 0) = 0`
  - `Y[3] = C` → `A != C` → `c[1][3] = max(0, 0) = 0`
  - `Y[4] = A` → `A == A` → `c[1][4] = c[0][3] + 1 = 0 + 1 = 1`
  - `Y[5] = B` → `A != B` → `c[1][5] = max(c[0][5], c[1][4]) = max(0, 1) = 1`
  - `Y[6] = A` → `A == A` → `c[1][6] = c[0][5] + 1 = 0 + 1 = 1`

### 6.解题思路

6. **初始化**：
   - 创建一个二维数组 c，大小为 (m+1) x (n+1)，其中 m 和 n 分别是 X 和 Y 的长度。
   - 初始化第一行和第一列为 0。
7. **填表**：
   - 遍历 X 的每个字符 X[i]，从第二行开始。
   - 遍历 Y 的每个字符 Y[j]，从第二列开始。
   - 根据 X[i] 和 Y[j] 是否相等，选择递推公式：
     - 如果 X[i] == Y[j]，则 c[i][j] = c[i-1][j-1] + 1。
     - 否则，c[i][j] = max(c[i-1][j], c[i][j-1])。
8. **回溯构造 LCS**：
   - 从 c[m][n] 开始，根据 X[i] 和 Y[j] 的关系选择路径：
     - 如果 X[i] == Y[j]，则将 X[i] 添加到 LCS 序列，并向左上方移动。
     - 否则，选择上方或左方较大的值，并相应地移动。
   - 终止条件是到达 c[0][0]。
9. **返回 LCS**：
   - 返回构造好的 LCS 序列。
