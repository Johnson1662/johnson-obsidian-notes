# 栈和队列

## Largest Rectangle in a Histogram（直方图中的最大矩形）

### 题目描述

直方图是由一系列在共同基线上对齐的矩形组成的多边形。这些矩形宽度相等，但高度可能不同。下图展示了一个由高度为 2, 1, 4, 5, 1, 3, 3（单位：矩形宽度）组成的直方图：

![](http://poj.org/images/2559_1.jpg)

直方图通常用于表示离散分布，例如文本中字符的频率。注意矩形的顺序（即高度）很重要。请计算直方图中与基线对齐的最大矩形的面积。右图展示了该直方图中的最大对齐矩形。

### 输入格式

输入包含多个测试用例。每个测试用例以整数 $n$ 开头，表示直方图中矩形的数量（$1 \le n \le 100\,000$）。接下来是 $n$ 个整数 $h_1, \dots, h_n$，其中 $0 \le h_i \le 10^9$，表示从左到右的矩形高度。每个矩形的宽度为 1。最后一个测试用例以 0 结束。

### 输出格式

对于每个测试用例，输出一行，包含该直方图中最大矩形的面积。

### 样例输入

```
7 2 1 4 5 1 3 3
4 1000 1000 1000 1000
0
```

### 样例输出

```
8
4000
```

### 问题分析

#### 第一步：理解我们要找什么

直方图由一系列宽度为 1、高度不同的矩形组成。我们要找的是直方图中面积最大的矩形（这个矩形必须与底部对齐）。

例如高度 [2,1,4,5,1,3,3] 中，最大矩形面积是 8（由高度 4 和 5 组成的 2×4 矩形）。

#### 第二步：暴力解法与单调栈的动机

最直接的想法：枚举每个矩形的高度 h[i]，向左向右扩展，找到能保持高度 ≥ h[i] 的最远范围。

对于每个 i，向左找到第一个高度 < h[i] 的位置 left，向右找到第一个高度 < h[i] 的位置 right，那么以 h[i] 为高的最大矩形面积 = h[i] × (right - left - 1)。

暴力做法：每遇到一个 i 就向左右各扫描一次，最坏 O(N²)，N=10⁵ 时不可行。

**单调栈**可以优化这个过程：我们只需要从左到右扫描一次，就能同时确定每个位置的右边界（和左边界）。

#### 第三步：单调栈如何工作

维护一个**单调递增栈**（栈中存储下标，对应的高度递增）：

- 当遇到一个新高度 h[i] 时：
  - 如果 h[i] > 栈顶高度：直接入栈（还没找到栈顶的右边界）
  - 如果 h[i] < 栈顶高度：**栈顶的右边界确定了**，弹出栈顶并计算面积

关键点：栈中每个元素的下一个元素就是它的左边界。因为栈是递增的，栈顶的下一个元素的高度一定 ≤ 栈顶的高度。

#### 第四步：模拟样例

h = [2, 1, 4, 5, 1, 3, 3]，末尾加一个 0（强制清空栈）：

| i | h[i] | 操作 | 栈状态 | 计算面积 |
|:-:|:---:|:---|:---:|:---|
| 1 | 2 | 入栈 | [1] | — |
| 2 | 1 | 1 < 栈顶 2，弹出 2：左边界=0，右=i=2，面积=2×(2-0-1)=2 | [] → [2] | max=2 |
| 3 | 4 | 4 > 1，入栈 | [2,3] | — |
| 4 | 5 | 5 > 4，入栈 | [2,3,4] | — |
| 5 | 1 | 1 < 5，弹出 5：左边界=3，右=i=5，面积=5×(5-3-1)=5 | [2,3] | max=5 |
|   |   | 1 < 4，弹出 4：左边界=2，右=i=5，面积=4×(5-2-1)=8 | [2] | max=8 |
|   |   | 1 = 1，停止弹出，入栈 5 | [2,5] | — |
| 6 | 3 | 3 > 1，入栈 | [2,5,6] | — |
| 7 | 3 | 3 = 3，入栈 | [2,5,6,7] | — |
| 8 | 0 | 0 < 3，弹出 7：左=6，右=8，面积=3×(8-6-1)=3 | [2,5,6] | max=8 |
|   |   | 0 < 3，弹出 6：左=5，右=8，面积=3×(8-5-1)=6 | [2,5] | max=8 |
|   |   | 0 < 1，弹出 5：左=2，右=8，面积=1×(8-2-1)=5 | [2] | max=8 |
|   |   | 0 < 1，弹出 2：左=0，右=8，面积=1×(8-0-1)=7 | [] | max=8 |

注意最后一步弹出的高度是 h[2]=1，面积 1×7=7，不影响最终答案。正确答案为 8 ✅

### 代码实现

```cpp
#include <iostream>
#include <stack>
#include <vector>
#include <algorithm>

using namespace std;

typedef long long ll;

int main() {
    int n;
    while (scanf("%d", &n) && n != 0) {
        vector<ll> h(n + 2, 0);
        for (int i = 1; i <= n; i++) {
            scanf("%lld", &h[i]);
        }

        // 在末尾加一个0，强制清空栈
        h[n + 1] = 0;

        stack<int> s;
        ll max_area = 0;

        for (int i = 1; i <= n + 1; i++) {
            // 如果当前高度小于栈顶高度，说明栈顶元素的右边界已找到
            while (!s.empty() && h[s.top()] > h[i]) {
                ll height = h[s.top()];
                s.pop();
                // 如果栈为空，说明该高度可以一直延伸到最左边
                int width = s.empty() ? i - 1 : i - s.top() - 1;
                max_area = max(max_area, height * width);
            }
            s.push(i);
        }
        printf("%lld\n", max_area);
    }
    return 0;
}
```

## NOIP201302 表达式求值

### 题目描述

给定一个只包含加法和乘法的算术表达式，请你编程计算表达式的值。

### 输入格式

仅有一行，为需要你计算的表达式。表达式中只包含数字、加法运算符 `"+"` 和乘法运算符 `"*"`，且没有括号。所有参与运算的数字均为 0 到 $2^{31}-1$ 之间的整数。输入数据保证这一行只有 0 到 9、`+`、`*` 这 12 种字符。

### 输出格式

输出只有一行，包含一个整数，表示这个表达式的值。注意：当答案长度多于 4 位时，请只输出最后 4 位，前导 0 不输出。

### 样例输入

```
1+1*3+4
```

### 样例输出

```
8
```

### 问题分析

#### 第一步：理解优先级

算术表达式中，乘法优先级高于加法。例如 `1+1*3+4`，先算 `1*3=3`，再算 `1+3+4=8`。

如果没有括号，可以通过栈来巧妙地处理优先级：
1. 遇到加法：数字先放一边（入栈），等后面处理
2. 遇到乘法：立即和栈顶的数字相乘，结果入栈
3. 最后栈中剩下的数字都是加法关系，全部相加即可

#### 第二步：模拟样例

表达式：`1+1*3+4`

| 步骤 | 读取 | 操作 | 栈内容 |
|:-:|:---:|---|---|
| 1 | 1 | 第一个数，入栈 | [1] |
| 2 | + | 读到加法，下一个数字暂不入栈 | [1] |
| 3 | 1 | 数字，入栈 | [1,1] |
| 4 | * | 读到乘法，说明后面数字要先和栈顶相乘 | [1,1] |
| 5 | 3 | 数字，弹出栈顶 1，计算 1×3=3，结果入栈 | [1,3] |
| 6 | + | 读到加法，数字暂不入栈 | [1,3] |
| 7 | 4 | 数字，入栈 | [1,3,4] |
| 8 | — | 结束，栈中所有数相加：1+3+4=8 ✅ | |

#### 第三步：取模处理

题目要求结果只输出最后 4 位，因此每次入栈时都对 10000 取模，累加时也取模。这样可以避免数字过大溢出。

### 代码实现

```cpp
#include <iostream>
#include <stack>
#include <cstdio>

using namespace std;

int main() {
    long long num;
    char op;
    stack<long long> s;

    // 读入第一个数
    if (scanf("%lld", &num) != EOF) {
        s.push(num % 10000);
    }

    // 循环读入 "运算符 数字"
    while (scanf("%c%lld", &op, &num) != EOF) {
        if (op == '*') {
            // 乘法优先级高，直接和栈顶元素计算
            long long top = s.top();
            s.pop();
            s.push((top * (num % 10000)) % 10000);
        } else if (op == '+') {
            // 加法先入栈，等乘法全部处理完再算
            s.push(num % 10000);
        }
    }

    // 将栈中剩余的数（都是加法关系）求和
    long long ans = 0;
    while (!s.empty()) {
        ans = (ans + s.top()) % 10000;
        s.pop();
    }

    printf("%lld\n", ans);

    return 0;
}
```
