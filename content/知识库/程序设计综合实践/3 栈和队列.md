# 栈和队列

## Largest Rectangle in a Histogram（直方图中的最大矩形）

**Contest Problem**

- **Time Limit**：C/C++ 1000MS，Other 2000MS
- **Memory Limit**：C/C++ 64MB，Other 128MB

### 题目描述

直方图是由一系列在共同基线上对齐的矩形组成的多边形。这些矩形宽度相等，但高度可能不同。下图展示了一个由高度为 2, 1, 4, 5, 1, 3, 3（单位：矩形宽度）组成的直方图：

![](http://poj.org/images/2559_1.jpg)

直方图通常用于表示离散分布，例如文本中字符的频率。注意矩形的顺序（即高度）很重要。请计算直方图中与基线对齐的最大矩形的面积。右图展示了该直方图中的最大对齐矩形。

### 输入格式

输入包含多个测试用例。每个测试用例以整数 *n* 开头，表示直方图中矩形的数量（1 ≤ n ≤ 100000）。接下来是 *n* 个整数 *h₁,…,hₙ*，其中 0 ≤ hᵢ ≤ 10⁹，表示从左到右的矩形高度。每个矩形的宽度为 1。最后一个测试用例以 0 结束。

### 输出格式

对于每个测试用例，输出一行，包含该直方图中最大矩形的面积。

### 样例输入

```
7 2 1 4 5 1 3 3
4 1000 1000 1000 1000
0
```

### 样例输出

```
8
4000
```

### 解题思路

使用单调栈（Monotonic Stack）求解。对于每个位置 i，我们需要找到以 h[i] 为高的最大矩形：
- 左边第一个小于 h[i] 的位置（左边界）
- 右边第一个小于 h[i] 的位置（右边界）

使用单调递增栈，当遇到比栈顶小的元素时，栈顶元素的右边界就确定了。

### 代码实现

```cpp
#include <iostream>
#include <stack>
#include <vector>
#include <algorithm>

using namespace std;

typedef long long ll;

void solve() {
    int n;
    while (scanf("%d", &n) && n != 0) {
        vector<ll> h(n + 2, 0);
        for (int i = 1; i <= n; i++) {
            scanf("%lld", &h[i]);
        }

        // 在末尾加一个0，强制清空栈
        h[n + 1] = 0;

        stack<int> s;
        ll max_area = 0;

        for (int i = 1; i <= n + 1; i++) {
            // 如果当前高度小于栈顶高度，说明栈顶元素的右边界已找到
            while (!s.empty() && h[s.top()] > h[i]) {
                ll height = h[s.top()];
                s.pop();
                // 如果栈为空，说明该高度可以一直延伸到最左边
                int width = s.empty() ? i - 1 : i - s.top() - 1;
                max_area = max(max_area, height * width);
            }
            s.push(i);
        }
        printf("%lld\n", max_area);
    }
}

int main() {
    solve();
    return 0;
}
```

## NOIP201302 表达式求值

**Contest Problem**

- **Time Limit**：C/C++ 1000MS，Other 2000MS
- **Memory Limit**：C/C++ 256MB，Other 512MB

### 题目描述

给定一个只包含加法和乘法的算术表达式，请你编程计算表达式的值。

### 输入格式

仅有一行，为需要你计算的表达式。表达式中只包含数字、加法运算符"+"和乘法运算符"*"，且没有括号。所有参与运算的数字均为 0 到 2³¹-1 之间的整数。输入数据保证这一行只有 0 到 9、+、* 这 12 种字符。

### 输出格式

输出只有一行，包含一个整数，表示这个表达式的值。注意：当答案长度多于 4 位时，请只输出最后 4 位，前导 0 不输出。

### 样例输入

```
1+1*3+4
```

### 样例输出

```
8
```

### 解题思路

由于乘法优先级高于加法，可以使用栈来处理：
1. 遇到数字先入栈
2. 遇到 '*' 时，弹出栈顶与下一个数字相乘，结果入栈
3. 遇到 '+' 时，数字直接入栈
4. 最后将栈中所有数相加（取模 10000）

### 代码实现

```cpp
#include <iostream>
#include <stack>
#include <cstdio>

using namespace std;

int main() {
    long long num;
    char op;
    stack<long long> s;

    // 读入第一个数
    if (scanf("%lld", &num) != EOF) {
        s.push(num % 10000);
    }

    // 循环读入 "运算符 数字"
    while (scanf("%c%lld", &op, &num) != EOF) {
        if (op == '*') {
            // 乘法优先级高，直接和栈顶元素计算
            long long top = s.top();
            s.pop();
            s.push((top * (num % 10000)) % 10000);
        } else if (op == '+') {
            // 加法先入栈，等乘法全部处理完再算
            s.push(num % 10000);
        }
    }

    // 将栈中剩余的数（都是加法关系）求和
    long long ans = 0;
    while (!s.empty()) {
        ans = (ans + s.top()) % 10000;
        s.pop();
    }

    printf("%lld\n", ans);

    return 0;
}
```
