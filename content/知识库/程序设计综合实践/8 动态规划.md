数字三角形

  

Contest Problem

Time Limit：C/C++ 1000MS，Other 2000MS  
Memory Limit：C/C++ 256MB，Other 512MB  

Description

给定一个如下图所示的数字三角形，从顶部出发，在每一结点可以选择移动至其左下方的结点或移动至其右下方的结点，一直走到底层，要求找出一条路径，使路径上的数字的和最大。  
7  
3 8  
8 1 0  
2 7 4 4  
4 5 2 6 5

Input

第一行包含整数 n，表示数字三角形的层数。

接下来 n 行，每行包含若干整数，其中第 i 行表示数字三角形第 i 层包含的整数。

Output

输出一个整数，表示最大的路径数字和。

Sample Input 1 

5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5

Sample Output 1 

30

Hint

1≤n≤500,−10000≤三角形中的整数≤10000

对于样例：

7->3->8->7->5 得到30


从 `DFS`（特别是加上了记忆化搜索的 `DFS`）转换成**动态规划（DP）**，本质上就是把“自上而下的递归”**变成**“自下而上的递推”。

在记忆化搜索中，我们是为了解决大问题，去递归地问小问题；而动态规划则是**先解决所有小问题，然后用小问题的答案直接拼凑出大问题的答案**。

下面为你拆解如何一步步转换，并给出最终的动态规划代码。

---

## 第一步：理解状态与转移（从 DFS 照搬）

我们在记忆化搜索中定义了：

- **状态**：`dfs(x, y)` 表示从坐标 $(x, y)$ 出发，到达底层的最大路径和。
    
- **转移方程**：`dfs(x, y) = arr[x][y] + max(dfs(x+1, y), dfs(x+1, y+1))`
    

在动态规划中，我们用一个二维数组 `dp[x][y]` 来代替 `dfs(x, y)` 函数：

- **状态定义**：`dp[x][y]` 表示从坐标 $(x, y)$ 出发，到达底层的最大路径和。
    
- **状态转移方程**：
    
    $$dp[x][y] = arr[x][y] + \max(dp[x+1][y], dp[x+1][y+1])$$
    

---

## 第二步：确定计算顺序（自下而上）

观察转移方程，想要算出 `dp[x][y]`，必须先知道它正下方 `dp[x+1][y]` 和右下方 `dp[x+1][y+1]` 的值。

也就是说，**下一行的结果是上一行的基础**。

因此，我们的循环顺序必须是**从倒数第二层开始，一行一行向上计算**，直到算到顶部 `dp[0][0]`。

---

## 第三步：边界条件（初始化）

最底层（第 $n-1$ 行）的结点下面没有其他数字了，所以它们到达底层的最大路径和，就是它们**自身的值**。

- 初始化：`dp[n-1][j] = arr[n-1][j]` （对于最底层的每一个 $j$）
    

---

## 第四步：编写动态规划代码

把上面的逻辑翻译成代码，你会发现它比 DFS 更简练，因为不需要递归函数了：

C++

```
#include <iostream>
#include <algorithm>

using namespace std;

int arr[500][500];
int dp[500][500]; // dp[i][j] 表示从 (i, j) 到底部的最大路径和
int n;

int main() {
    cin >> n;
    
    // 读入数字三角形
    for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++) {
            cin >> arr[i][j];
        }
    }
    
    // 1. 初始化最底层
    for (int j = 0; j < n; j++) {
        dp[n-1][j] = arr[n-1][j];
    }
    
    // 2. 自下而上递推：从倒数第二行 (n-2) 开始，一路向上走到第 0 行
    for (int i = n - 2; i >= 0; i--) {
        for (int j = 0; j <= i; j++) {
            // 当前位置的最大和 = 当前值 + max(左下方, 右下方)
            dp[i][j] = arr[i][j] + max(dp[i+1][j], dp[i+1][j+1]);
        }
    }
    
    // 3. 顶部的 dp[0][0] 就是我们要的最终答案
    cout << dp[0][0] << endl;
    
    return 0;
}
```

---

## 💡 终极优化：空间压缩（滚动数组）

如果你仔细观察上面的动态规划代码，会发现计算第 `i` 行的 `dp` 值时，**只需要用到第 `i+1` 行的 `dp` 值**，再往下的数据其实已经没用了。

所以，我们甚至不需要一个二维的 `dp[500][500]` 数组，只需要一个一维的 `dp[500]` 数组，每次直接在上面覆盖更新即可：

C++

```
// 优化后的核心递推部分
for (int j = 0; j < n; j++) {
    dp[j] = arr[n-1][j]; // 用最底层初始化一维数组
}

for (int i = n - 2; i >= 0; i--) {
    for (int j = 0; j <= i; j++) {
        // 直接在原有的一维数组上更新
        dp[j] = arr[i][j] + max(dp[j], dp[j+1]);
    }
}
cout << dp[0] << endl;
```

这样不仅时间复杂度是 $O(N^2)$，空间复杂度也从 $O(N^2)$ 降低到了 $O(N)$，在面临空间限制严格的题目时非常有用。


最长上升子序列

  

Contest Problem

Time Limit：C/C++ 1000MS，Other 2000MS  
Memory Limit：C/C++ 256MB，Other 512MB  

Description

一个数的序列b_i，当b_1<b_2<...<b_S的时候，我们称这个序列是上升的。对于给定的一个序列(a_1,a_2,...,a_N)，我们可以得到一些上升的子序列(a_i1,a_i2,...,a_iK)，这里$1≤i\_1

你的任务，就是对于给定的序列，求出最长上升子序列的长度。

Input

输入的第一行是序列的长度N(1≤N≤1000)。第二行给出序列中的N个整数，这些整数的取值范围都在0到10000。

Output

最长上升子序列的长度。

Sample Input 1 

7
1 7 3 5 9 4 8

Sample Output 1 

4


这道题是经典的最长上升子序列（Longest Increasing Subsequence，简称 LIS）问题。

既然你已经理解了数字三角形那道题的“自下而上”递推，那么面对这道题时，思考动态规划（DP）的核心就在于**如何定义一个能够记录“过去状态”的数组**。

我们可以通过经典的 **DP 四步思考法**来破解这道题：

---

## 1. 状态定义：每个位置的“身份”是什么？

数字三角形的每个状态天然地由坐标 $(x, y)$ 决定。而在这一题中，数据是一个一维序列，我们通常用一个一维数组 `dp[i]` 来代表某种状态。

- **错误定义尝试**：定义 `dp[i]` 为前 `i` 个数字中，最长上升子序列的长度。
    
    - _为什么不行？_ 因为当你要判断第 `i+1` 个数字能不能拼接到前面时，你不知道前面那个最长子序列是以哪个数字**结尾**的。如果新数字比前面的结尾数字小，就无法拼接。
        
- **正确定义**：**`dp[i]` 表示以第 `i` 个数字 `a[i]` 结尾的最长上升子序列的长度。**
    
    - _妙在哪里？_ 只要规定了“必须以 `a[i]` 结尾”，那么这个子序列的最后一项就确定是 `a[i]`。当我们要算后面的状态时，拿新数字和 `a[i]` 做大小对比即可。
        

---

## 2. 状态转移方程：新状态怎么从旧状态算出来？

假设我们现在要计算 `dp[i]`（即以 `a[i]` 结尾的最长长度）。

既然 `a[i]` 是这个子序列的**最后一个数**，那么它的**倒数第二个数**一定在它前面（假设下标为 `j`，其中 $0 \le j < i$）。

既然是上升序列，就必须满足：`a[j] < a[i]`。

因此，为了让整体序列最长，我们需要在前面所有满足 `a[j] < a[i]` 的数字中，挑一个 `dp[j]` 最大的那一个，然后把 `a[i]` 接在它后面（长度 $+1$）。

**状态转移方程：**

$$dp[i] = \max(dp[j]) + 1 \quad (\text{其中 } 0 \le j < i \text{ 且 } a[j] < a[i])$$

> 如果前面没有一个数字比 `a[i]` 小，那么 `a[i]` 只能自己独立成一个序列，长度为 1。

---

## 3. 边界与初始化

对于任何一个单独的数字，它本身都可以看作一个长度为 1 的上升子序列。

- **初始化**：把 `dp` 数组的每一项都初始化为 `1`。
    

---

## 4. 模拟走一遍示例

以题目给出的样例数据为例：`a = [1, 7, 3, 5, 9, 4, 8]`

|**i**|**a[i]**|**往前寻找满足 a[j] < a[i] 的最大 dp[j]**|**计算 dp[i]**|**说明**|
|---|---|---|---|---|
|0|**1**|没有比它小的|`1`|子序列 `[1]`|
|1|**7**|找到 `a[0]=1`，其 `dp[0]=1`|`1 + 1 = 2`|子序列 `[1, 7]`|
|2|**3**|找到 `a[0]=1`，其 `dp[0]=1`|`1 + 1 = 2`|子序列 `[1, 3]`|
|3|**5**|找到 `a[2]=3`（`dp[2]=2`）比 `a[0]` 的更大|`2 + 1 = 3`|子序列 `[1, 3, 5]`|
|4|**9**|找到 `a[3]=5`（`dp[3]=3`）最大|`3 + 1 = 4`|子序列 `[1, 3, 5, 9]`|
|5|**4**|找到 `a[2]=3`（`dp[2]=2`）最大|`2 + 1 = 3`|子序列 `[1, 3, 4]`|
|6|**8**|找到 `a[3]=5` 或 `a[5]=4`（`dp`均为3）最大|`3 + 1 = 4`|子序列 `[1, 3, 5, 8]`|

最后，**整个数组的最大值**就是我们要的答案。表中 `dp` 的最大值是 `4`。

## 代码实现

结合以上思考，写成 C++ 代码如下：

C++

```
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int n;
    if (!(cin >> n)) return 0;
    
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    // dp[i] 初始化为 1
    vector<int> dp(n, 1);
    int ans = 1; // 记录全局最大长度
    
    // 外层循环遍历每一个位置 i，计算 dp[i]
    for (int i = 0; i < n; i++) {
        // 内层循环在 i 前面寻找可以拼接的 j
        for (int j = 0; j < i; j++) {
            if (a[j] < a[i]) { // 只有严格小于时，才能构成上升序列
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        // 随时更新全局最大值
        ans = max(ans, dp[i]);
    }
    
    cout << ans << endl;
    
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：用了两层循环，每一层最多跑 $N$ 次，因此时间复杂度是 $O(N^2)$。题目给出的 $N \le 1000$，$N^2 = 1,000,000$（百万级别运算），计算机可以在几毫秒内轻松跑完，完全不会超时。
    
- **空间复杂度**：需要一个大小为 $N$ 的 `dp` 数组，空间复杂度为 $O(N)$。


最大子段和

  

Contest Problem

Time Limit：C/C++ 1000MS，Other 2000MS  
Memory Limit：C/C++ 256MB，Other 512MB  

Description

输入若干个整数，有正有负，要求用动态规划算法计算最大子段和，并输出这个和。注意子段为一段连续的数，同时规定全是负数的子段其和为 0。

Input

第一行为一个整数 M，代表有 M 组测试数据。  
随后每组测试数据的第一行为 N ，代表该组数据有 N 个数。  
接下来一行给出用空格隔开的这 N 个整数。

Output

每组测试数据输出一行，即最大子段和。

Sample Input 1 

1
8
-2 10 8 -4 7 5 -29 10

Sample Output 1 

26

Hint

1≤M≤106  
1≤∑N≤106


太棒了，我们马上学以致用！这道题是经典的最大子段和（Maximum Subarray Sum）问题，也叫 Kadane 算法。

既然你刚刚掌握了“一维 DP 状态定义黄金法则”，那我们直接套用法则一（以 `i` 结尾）来推导这道题，看看是不是能一眼看破。

---

## 1. 状态定义：用黄金法则生套

题目要求的是**一段连续的数**（子段），而且后面新加入的数字必须紧紧跟在前面数字的后面。

如果新数字想加入前一个子段，它必须知道前一个子段**是不是就在它左边紧挨着（即以 `i-1` 结尾）**。

因此，我们直接掏出法则一：

- **`dp[i]` 表示以第 `i` 个数字 `a[i]` 结尾的最大连续子段和。**
    

---

## 2. 状态转移方程：面临人生的抉择

现在假设我们要计算 `dp[i]`，也就是必须包含 `a[i]`。此时 `a[i]` 有两种选择：

1. **认祖归宗**：加入到以 `a[i-1]` 结尾的那个子段里去。这时候的和就是 `dp[i-1] + a[i]`。
    
2. **自立门户**：嫌弃前面的子段太小了（`dp[i-1] < 0`），带上它反而会拉低自己的值。于是 `a[i]` 决定自己作为新子段的开头。这时候的和就是 `a[i]` 自己。
    

为了让子段和最大，我们在这两种选择里挑一个最大的：

**状态转移方程：**

$$dp[i] = \max(dp[i-1] + a[i], a[i])$$

或者是更直观的写法：如果 `dp[i-1] > 0`，就加进来；如果 `dp[i-1] <= 0`，就直接等于 `a[i]`。

---

## 3. 边界、初始化与题目特殊要求

- **初始化**：`dp[0] = a[0]`（第一个数字前面没有数，只能自立门户）。
    
- **题目特判**：题目规定“全是负数的子段其和为 0”。这意味着如果整个过程中算出来的最大值连 `0` 都不如，我们就输出 `0`。
    

---

## 4. 模拟样例

样例数据：`[-2, 10, 8, -4, 7, 5, -29, 10]`

|**i**|**a[i]**|**抉择：dp[i-1] + a[i] 还是 a[i]？**|**dp[i]**|**说明**|
|---|---|---|---|---|
|0|**-2**|只能靠自己|`-2`|以 `-2` 结尾最大是 -2|
|1|**10**|$\max(-2 + 10, 10) \rightarrow 10$|`10`|前面是负贡献，不如自立门户|
|2|**8**|$\max(10 + 8, 8) \rightarrow 18$|`18`|前面有 10，认祖归宗|
|3|**-4**|$\max(18 + (-4), -4) \rightarrow 14$|`14`|前面底子厚，虽然自己是负数也认了|
|4|**7**|$\max(14 + 7, 7) \rightarrow 21$|`21`|继续认祖归宗|
|5|**5**|$\max(21 + 5, 5) \rightarrow 26$|`26`|此时达到全局最大|
|6|**-29**|$\max(26 + (-29), -29) \rightarrow -3$|`-3`|被暴击了，但跟着前面好歹比自己单干强|
|7|**10**|$\max(-3 + 10, 10) \rightarrow 10$|`10`|前面又是负的了，果断自立门户|

最后，**整个 `dp` 数组里的最大值是 `26`**（对应子段 `[10, 8, -4, 7, 5]`）。

## C++ 代码实现

注意题目说有 $M$ 组测试数据，且数据量 $\sum N \le 10^6$，所以我们要用快速一点的输入输出（`ios::sync_with_stdio(false)`），并且由于状态只和前一个有关，我们可以像数字三角形一样，**用一个变量优化掉 `dp` 数组**。

C++

```
#include <iostream>
#include <algorithm>

using namespace std;

void solve() {
    int n;
    cin >> n;
    
    long long max_so_far = 0; // 记录全局最大子段和（初始化为0以满足全负数输出0的要求）
    long long current_max = 0; // 相当于 dp[i]，表示以当前数字结尾的最大和
    
    for (int i = 0; i < n; i++) {
        long long a;
        cin >> a;
        
        if (i == 0) {
            current_max = a;
        } else {
            // 状态转移：接在后面还是自立门户
            current_max = max(current_max + a, a);
        }
        
        // 更新全局最大值
        max_so_far = max(max_so_far, current_max);
    }
    
    cout << max_so_far << "\n";
}

int main() {
    // 提高输入输出效率，防止 10^6 数据超时
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int m;
    if (cin >> m) {
        while (m--) {
            solve();
        }
    }
    return 0;
}
```

体验到“以 `i` 结尾”这个黄金法则的威力了吗？只要题目要求结果是**连续的**或者**极其看重末尾状态**，往这个方向想准没错！
