# 8 动态规划

## 1. 数字三角形

> [!abstract] Contest Problem
> **Time Limit**：C/C++ 1000MS，Other 2000MS  
> **Memory Limit**：C/C++ 256MB，Other 512MB  
> 
> **Description**
> 给定一个如下图所示的数字三角形，从顶部出发，在每一结点可以选择移动至其左下方的结点或移动至其右下方的结点，一直走到底层，要求找出一条路径，使路径上的数字的和最大。  
> ```text
>         7  
>       3   8  
>     8   1   0  
>   2   7   4   4  
> 4   5   2   6   5
> ```
> 
> **Input**
> 第一行包含整数 $n$，表示数字三角形的层数。
> 接下来 $n$ 行，每行包含若干整数，其中第 $i$ 行表示数字三角形第 $i$ 层包含的整数。
> 
> **Output**
> 输出一个整数，表示最大的路径数字和。
> 
> **Sample Input 1**
> ```text
> 5
> 7
> 3 8
> 8 1 0
> 2 7 4 4
> 4 5 2 6 5
> ```
> 
> **Sample Output 1**
> `30`
> 
> **Hint**
> $1 \le n \le 500, -10000 \le \text{三角形中的整数} \le 10000$
> 对于样例：`7->3->8->7->5` 得到 `30`

从 `DFS`（特别是加上了记忆化搜索的 `DFS`）转换成**动态规划（DP）**，本质上就是把“自上而下的递归”**变成**“自下而上的递推”。

在记忆化搜索中，我们是为了解决大问题，去递归地问小问题；而动态规划则是**先解决所有小问题，然后用小问题的答案直接拼凑出大问题的答案**。

下面为你拆解如何一步步转换，并给出最终的动态规划代码。

---

### 第一步：理解状态与转移（从 DFS 照搬）

我们在记忆化搜索中定义了：
- **状态**：`dfs(x, y)` 表示从坐标 $(x, y)$ 出发，到达底层的最大路径和。
- **转移方程**：`dfs(x, y) = arr[x][y] + max(dfs(x+1, y), dfs(x+1, y+1))`

在动态规划中，我们用一个二维数组 `dp[x][y]` 来代替 `dfs(x, y)` 函数：
- **状态定义**：`dp[x][y]` 表示从坐标 $(x, y)$ 出发，到达底层的最大路径和。
- **状态转移方程**：
  $$dp[x][y] = arr[x][y] + \max(dp[x+1][y], dp[x+1][y+1])$$

---

### 第二步：确定计算顺序（自下而上）

观察转移方程，想要算出 `dp[x][y]`，必须先知道它正下方 `dp[x+1][y]` 和右下方 `dp[x+1][y+1]` 的值。
也就是说，**下一行的结果是上一行的基础**。

因此，我们的循环顺序必须是**从倒数第二层开始，一行一行向上计算**，直到算到顶部 `dp[0][0]`。

---

### 第三步：边界条件（初始化）

最底层（第 $n-1$ 行）的结点下面没有其他数字了，所以它们到达底层的最大路径和，就是它们**自身的值**。
- **初始化**：`dp[n-1][j] = arr[n-1][j]` （对于最底层的每一个 $j$）

---

### 第四步：编写动态规划代码

把上面的逻辑翻译成代码，你会发现它比 DFS 更简练，因为不需要递归函数了：

```cpp
#include <iostream>
#include <algorithm>

using namespace std;

int arr[500][500];
int dp[500][500]; // dp[i][j] 表示从 (i, j) 到底部的最大路径和
int n;

int main() {
    cin >> n;
    
    // 读入数字三角形
    for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++) {
            cin >> arr[i][j];
        }
    }
    
    // 1. 初始化最底层
    for (int j = 0; j < n; j++) {
        dp[n-1][j] = arr[n-1][j];
    }
    
    // 2. 自下而上递推：从倒数第二行 (n-2) 开始，一路向上走到第 0 行
    for (int i = n - 2; i >= 0; i--) {
        for (int j = 0; j <= i; j++) {
            // 当前位置的最大和 = 当前值 + max(左下方, 右下方)
            dp[i][j] = arr[i][j] + max(dp[i+1][j], dp[i+1][j+1]);
        }
    }
    
    // 3. 顶部的 dp[0][0] 就是我们要的最终答案
    cout << dp[0][0] << endl;
    
    return 0;
}
```

---

### 💡 终极优化：空间压缩（滚动数组）

如果你仔细观察上面的动态规划代码，会发现计算第 `i` 行的 `dp` 值时，**只需要用到第 `i+1` 行的 `dp` 值**，再往下的数据其实已经没用了。

所以，我们甚至不需要一个二维的 `dp[500][500]` 数组，只需要一个一维的 `dp[500]` 数组，每次直接在上面覆盖更新即可：

```cpp
// 优化后的核心递推部分
for (int j = 0; j < n; j++) {
    dp[j] = arr[n-1][j]; // 用最底层初始化一维数组
}

for (int i = n - 2; i >= 0; i--) {
    for (int j = 0; j <= i; j++) {
        // 直接在原有的一维数组上更新
        dp[j] = arr[i][j] + max(dp[j], dp[j+1]);
    }
}
cout << dp[0] << endl;
```

这样不仅时间复杂度是 $O(N^2)$，空间复杂度也从 $O(N^2)$ 降低到了 $O(N)$，在面临空间限制严格的题目时非常有用。

## 2. 最长上升子序列

> [!abstract] Contest Problem
> **Time Limit**：C/C++ 1000MS，Other 2000MS  
> **Memory Limit**：C/C++ 256MB，Other 512MB  
> 
> **Description**
> 一个数的序列 $b_i$，当 $b_1 < b_2 < ... < b_S$ 的时候，我们称这个序列是上升的。对于给定的一个序列 $(a_1, a_2, ..., a_N)$，我们可以得到一些上升的子序列 $(a_{i1}, a_{i2}, ..., a_{iK})$，这里 $1 \le i_1 < i_2 < ... < i_K \le N$。
> 你的任务，就是对于给定的序列，求出最长上升子序列的长度。
> 
> **Input**
> 输入的第一行是序列的长度 $N (1 \le N \le 1000)$。第二行给出序列中的 $N$ 个整数，这些整数的取值范围都在 $0$ 到 $10000$。
> 
> **Output**
> 最长上升子序列的长度。
> 
> **Sample Input 1**
> ```text
> 7
> 1 7 3 5 9 4 8
> ```
> 
> **Sample Output 1**
> `4`

这道题是经典的最长上升子序列（Longest Increasing Subsequence，简称 LIS）问题。思考 DP 的核心就在于**如何定义一个能够记录“过去状态”的数组**。

我们可以通过经典的 **DP 四步思考法**来破解这道题：

### 1. 状态定义：每个位置的“身份”是什么？

数字三角形的状态天然由坐标决定，而一维序列通常用 `dp[i]` 代表某种状态。
- **错误尝试**：定义 `dp[i]` 为前 `i` 个数字中，最长上升子序列的长度。
    - *问题*：不知道子序列是以哪个数字**结尾**的，新数字比结尾小时无法拼接。
- **正确定义**：**`dp[i]` 表示以第 `i` 个数字 `a[i]` 结尾的最长上升子序列的长度。**
    - *优点*：确定了最后一项，后续状态只需对比大小即可。

### 2. 状态转移方程

假设计算 `dp[i]`，倒数第二个数下标为 `j` ($0 \le j < i$)，需满足 `a[j] < a[i]`。
**状态转移方程：**
$$dp[i] = \max(dp[j]) + 1 \quad (\text{其中 } 0 \le j < i \text{ 且 } a[j] < a[i])$$

> 如果前面没有一个数字比 `a[i]` 小，那么 `a[i]` 只能自己独立成一个序列，长度为 1。

---

### 3. 边界与初始化

- **初始化**：把 `dp` 数组的每一项都初始化为 `1`。

---

### 4. 模拟走一遍示例

`a = [1, 7, 3, 5, 9, 4, 8]`

| **i** | **a[i]** | **往前寻找满足 a[j] < a[i] 的最大 dp[j]** | **计算 dp[i]** | **说明** |
| :--- | :--- | :--- | :--- | :--- |
| 0 | **1** | 没有比它小的 | `1` | 子序列 `[1]` |
| 1 | **7** | 找到 `a[0]=1`，其 `dp[0]=1` | `1+1=2` | 子序列 `[1, 7]` |
| 2 | **3** | 找到 `a[0]=1`，其 `dp[0]=1` | `1+1=2` | 子序列 `[1, 3]` |
| 3 | **5** | 找到 `a[2]=3` (`dp[2]=2`) | `2+1=3` | 子序列 `[1, 3, 5]` |
| 4 | **9** | 找到 `a[3]=5` (`dp[3]=3`) | `3+1=4` | 子序列 `[1, 3, 5, 9]` |
| 5 | **4** | 找到 `a[2]=3` (`dp[2]=2`) | `2+1=3` | 子序列 `[1, 3, 4]` |
| 6 | **8** | 找到 `a[3]=5` 或 `a[5]=4` (`dp=3`) | `3+1=4` | 子序列 `[1, 3, 5, 8]` |

最后，**整个数组的最大值**就是答案。

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int n;
    if (!(cin >> n)) return 0;
    
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    vector<int> dp(n, 1);
    int ans = 1;
    
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (a[j] < a[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        ans = max(ans, dp[i]);
    }
    cout << ans << endl;
    return 0;
}
```

#### 复杂度分析
- **时间复杂度**：用了两层循环，每一层最多跑 $N$ 次，因此时间复杂度是 $O(N^2)$。题目给出的 $N \le 1000$，$N^2 = 1,000,000$（百万级别运算），计算机可以在几毫秒内轻松跑完，完全不会超时。
- **空间复杂度**：需要一个大小为 $N$ 的 `dp` 数组，空间复杂度为 $O(N)$。

## 3. 最大子段和

> [!abstract] Contest Problem
> **Time Limit**：C/C++ 1000MS，Other 2000MS  
> **Memory Limit**：C/C++ 256MB，Other 512MB  
> 
> **Description**
> 输入若干个整数，有正有负，要求用动态规划算法计算最大子段和，并输出这个和。注意子段为一段连续的数，同时规定全是负数的子段其和为 0。
> 
> **Input**
> 第一行为一个整数 $M$，代表有 $M$ 组测试数据。  
> 随后每组测试数据的第一行为 $N$ ，代表该组数据有 $N$ 个数。  
> 接下来一行给出用空格隔开的这 $N$ 个整数。
> 
> **Output**
> 每组测试数据输出一行，即最大子段和。
> 
> **Sample Input 1**
> ```text
> 1
> 8
> -2 10 8 -4 7 5 -29 10
> ```
> 
> **Sample Output 1**
> `26`
> 
> **Hint**
> $1 \le M \le 10^6, 1 \le \sum N \le 10^6$

这是经典的最大子段和（Kadane 算法）。

### 1. 状态定义
- **`dp[i]` 表示以第 `i` 个数字 `a[i]` 结尾的最大连续子段和。**

### 2. 状态转移方程
对于 `a[i]`，有两种选择：
1. **认祖归宗**：加入到以 `a[i-1]` 结尾的子段中。和为 `dp[i-1] + a[i]`。
2. **自立门户**：由于 `dp[i-1] < 0`，自己作为新开头。和为 `a[i]`。

**方程：**
$$dp[i] = \max(dp[i-1] + a[i], a[i])$$

---

### 3. 边界与特判
- **初始化**：`dp[0] = a[0]`。
- **题目特判**：若最大值为负，输出 `0`。

---

### 4. 模拟样例
`[-2, 10, 8, -4, 7, 5, -29, 10]`

| **i** | **a[i]** | **抉择：dp[i-1] + a[i] 还是 a[i]？** | **dp[i]** | **说明** |
| :--- | :--- | :--- | :--- | :--- |
| 0 | **-2** | 只能靠自己 | `-2` | 以 `-2` 结尾最大是 -2 |
| 1 | **10** | $\max(-2 + 10, 10) \rightarrow 10$ | `10` | 前面是负贡献，不如自立门户 |
| 2 | **8** | $\max(10 + 8, 8) \rightarrow 18$ | `18` | 前面有 10，认祖归宗 |
| 3 | **-4** | $\max(18 + (-4), -4) \rightarrow 14$ | `14` | 前面底子厚 |
| 4 | **7** | $\max(14 + 7, 7) \rightarrow 21$ | `21` | 继续认祖归宗 |
| 5 | **5** | $\max(21 + 5, 5) \rightarrow 26$ | `26` | 此时达到全局最大 |
| 6 | **-29** | $\max(26 + (-29), -29) \rightarrow -3$ | `-3` | 认祖归宗好过单干 |
| 7 | **10** | $\max(-3 + 10, 10) \rightarrow 10$ | `10` | 前面负值，果断单干 |

---

### C++ 代码实现（空间优化版）

```cpp
#include <iostream>
#include <algorithm>

using namespace std;

void solve() {
    int n;
    cin >> n;
    
    long long max_so_far = 0; // 记录全局最大子段和
    long long current_max = 0; // 相当于 dp[i]
    
    for (int i = 0; i < n; i++) {
        long long a;
        cin >> a;
        
        if (i == 0) {
            current_max = a;
        } else {
            // 状态转移：接在后面还是自立门户
            current_max = max(current_max + a, a);
        }
        
        // 更新全局最大值
        max_so_far = max(max_so_far, current_max);
    }
    
    cout << max_so_far << "\n";
}

int main() {
    // 提高输入输出效率
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int m;
    if (cin >> m) {
        while (m--) {
            solve();
        }
    }
    return 0;
}
```

## 4. 01背包问题

> [!abstract] Contest Problem
> **Description**
> 一个旅行者有一个最多能装 $M$ 公斤的背包，现在有 $n$ 件物品，它们的重量分别是 $W_1, W_2, ..., W_n$，价值分别为 $C_1, C_2, ..., C_n$，求能获得的最大总价值。
> 
> **Input**
> 第一行：两个整数，$M$（容量，$M \le 200$）和 $N$（数量，$N \le 30$）；
> 第 $2..N+1$ 行：每行二个整数 $W_i, C_i$。
> 
> **Output**
> 仅一行，一个数，表示最大总价值。
> 
> **Sample Input 1**
> ```text
> 10 4
> 2 1
> 3 3
> 4 5
> 7 9
> ```
> 
> **Sample Output 1**
> `12`

### 1. 尝试直觉定义（撞墙分析）

如果我们生套黄金法则二（前 $i$ 个）：
> 尝试定义：`dp[i]` 表示前 $i$ 件物品能获得的最大价值。

我们要决定拿还是不拿：
- 如果**不拿**：最大价值就是前 $i-1$ 件物品的结果，即 `dp[i-1]`。
- 如果**拿**：最大价值应该是（前 $i-1$ 件物品的结果） + 当前物品价值 $C_i$。

**问题来了：** 你拿了第 $i$ 件物品，背包就得消耗 $W_i$ 的重量。可是你的 `dp[i-1]` 根本**没有记录前 $i-1$ 件物品一共用掉了多少重量**！

---

### 2. 强行补齐信息：升级为“二维 DP”

既然缺少“背包容量”的信息，那我们就和前面一样——**缺什么，就把什么塞进状态定义里！**
- **状态定义：`dp[i][j]` 表示在前 `i` 件物品中进行选择，当背包容量恰好为 `j` 时，能获得的最大价值。**

---

### 3. 状态转移方程：拿还是不拿？

面对第 $i$ 件物品，我们只有两个选择：
1. **不拿第 $i$ 件物品**：$dp[i][j] = dp[i-1][j]$
2. **拿第 $i$ 件物品**：$dp[i][j] = dp[i-1][j - W_i] + C_i$

**方程：**
- 当 $j < W_i$：$dp[i][j] = dp[i-1][j]$
- 当 $j \ge W_i$：$dp[i][j] = \max(dp[i-1][j], dp[i-1][j - W_i] + C_i)$

---

### 4. 边界与初始化

- 如果不考虑任何物品（$i = 0$），或者背包容量为 0（$j = 0$），最大价值都是 `0`。
- 整个 `dp` 数组可以全部初始化为 `0`。

---

### 5. C++ 代码实现（二维直观版）

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int M, N;
    if (!(cin >> M >> N)) return 0; // M是容量，N是数量
    
    vector<int> W(N + 1);
    vector<int> C(N + 1);
    for (int i = 1; i <= N; i++) {
        cin >> W[i] >> C[i];
    }
    
    // dp[i][j] 默认初始化为 0
    vector<vector<int>> dp(N + 1, vector<int>(M + 1, 0));
    
    for (int i = 1; i <= N; i++) {
        for (int j = 0; j <= M; j++) {
            if (j < W[i]) {
                dp[i][j] = dp[i-1][j];
            } else {
                dp[i][j] = max(dp[i-1][j], dp[i-1][j - W[i]] + C[i]);
            }
        }
    }
    cout << dp[N][M] << endl;
    return 0;
}
```

---

### 💡 进阶思考：能像前几题一样压缩空间吗？

计算第 `i` 行只需要用到第 `i-1` 行的数据。我们可以把它压缩成一维数组 `dp[j]`。

但这里有一个极其经典的**大坑**：
如果 `j` 从小到大递增：
```cpp
for (int j = W[i]; j <= M; j++) {
    dp[j] = max(dp[j], dp[j - W[i]] + C[i]);
}
```
此时的 `dp[j - W[i]]` 可能已经在当前轮更新过了，导致物品被重复拿多次。

为了保证 `dp[j - W[i]]` 依然是上一轮的干净数据，需要**逆序遍历**：

```cpp
// 终极优化：一维 01 背包
vector<int> dp(M + 1, 0);

for (int i = 1; i <= N; i++) {
    // 必须逆序遍历容量！
    for (int j = M; j >= W[i]; j--) {
        dp[j] = max(dp[j], dp[j - W[i]] + C[i]);
    }
}
cout << dp[M] << endl;
```

## 5. 分组背包

> [!abstract] Contest Problem
> **Time Limit**：C/C++ 1000MS，Other 2000MS  
> **Memory Limit**：C/C++ 256MB，Other 512MB  
> 
> **Description**
> 一个旅行者有一个最多能装 $V$ 公斤的背包，现在有 $n$ 件物品，它们的重量分别是 $W_1, W_2, ..., W_n$，价值分别为 $C_1, C_2, ..., C_n$。物品被划分为了若干组，每组中的物品互相冲突，最多只能选一件。求解在不超过背包容量的情况下，价值总和最大。
> 
> **Input**
> 第一行：三个整数，$V$（容量，$V \le 200$），$N$（数量，$N \le 30$）和 $T$（最大组号，$T \le 10$）；
> 第 $2..N+1$ 行：三个整数 $W_i, C_i, P$。

### 1. 状态定义：以“组”为核心维度

我们需要把第一维升级为“第 $k$ 组物品”：
- **`dp[k][j]` 表示在前 $k$ 组物品中进行选择，容量为 $j$ 时，能获得的最大价值。**

---

### 2. 状态转移方程：抉择变多了

面对第 $k$ 组物品时，要在整组里做抉择：
1. **这组一个都不拿**：$dp[k][j] = dp[k-1][j]$
2. **拿这组里的第 $i$ 个物品**：$dp[k][j] = dp[k-1][j - W_i] + C_i$

**方程：**
$$dp[k][j] = \max \left( dp[k-1][j], \max_{i \in \text{Group } k} \{ dp[k-1][j - W_i] + C_i \} \right)$$

---

### 3. 一维空间优化的超级大坑：循环顺序

三层循环的嵌套顺序极其严格：
1. **先遍历组**
2. **再逆序遍历容量**
3. **最后遍历组内的每一个物品**

```cpp
for (int k = 1; k <= T; k++) {          // 1. 先遍历组
    for (int j = V; j >= 0; j--) {      // 2. 再逆序遍历容量
        for (auto& item : groups[k]) {  // 3. 最后遍历组内物品
            if (j >= item.w) {
                dp[j] = max(dp[j], dp[j - item.w] + item.c);
            }
        }
    }
}
```

> [!tip] 为什么要这样排序？
> 当我们在计算容量 `j` 时，最内层循环把该组所有物品试一遍，所有的尝试都是基于**上一组**留下的数据。它们互相竞争，只有最强的能更新 `dp[j]`，这就完美限制了“每组最多选一个”。

---

### 4. C++ 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

struct Item {
    int w, c;
};

int main() {
    int V, N, T;
    if (!(cin >> V >> N >> T)) return 0; // V:容量, N:数量, T:最大组号
    
    // 用一个二维 vector 把物品按组号归类
    vector<vector<Item>> groups(T + 1);
    
    for (int i = 0; i < N; i++) {
        int w, c, p;
        cin >> w >> c >> p;
        groups[p].push_back({w, c});
    }
    
    // 一维 dp 数组，初始化为 0
    vector<int> dp(V + 1, 0);
    
    // 1. 遍历每一个组
    for (int k = 1; k <= T; k++) {
        if (groups[k].empty()) continue;
        
        // 2. 逆序遍历背包容量
        for (int j = V; j >= 0; j--) {
            // 3. 遍历当前组内的每一个物品
            for (const auto& item : groups[k]) {
                if (j >= item.w) {
                    dp[j] = max(dp[j], dp[j - item.w] + item.c);
                }
            }
        }
    }
    
    cout << dp[V] << endl;
    return 0;
}
```
