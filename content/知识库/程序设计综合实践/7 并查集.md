## 1. 食物链

> [!abstract] Contest Problem
> **Time Limit**：C/C++ 1000MS，Other 2000MS  
> **Memory Limit**：C/C++ 64MB，Other 128MB  
> 
> **Description**
> 动物王国中有三类动物 A、B、C，这三类动物的食物链构成了有趣的环形。A 吃 B，B 吃 C，C 吃 A。
> 
> 现有 N 个动物，以 1 到 N 编号。每个动物都是 A、B、C 中的一种，但是我们并不知道它到底是哪一种。
> 
> 有人用两种说法对这 N 个动物所构成的食物链关系进行描述：
> 
> 1. 第一种说法是 "1 X Y"，表示 X 和 Y 是同类。
> 2. 第二种说法是 "2 X Y"，表示 X 吃 Y。
> 
> 此人对 N 个动物，用上述两种说法，一句接一句地说出 K 句话，这 K 句话有的是真的，有的是假的。当一句话满足下列三条之一时，这句话就是假话，否则就是真话：
> 
> 1. 当前的话与前面的某些真的话冲突，就是假话；
> 2. 当前的话中 X 或 Y 比 N 大，就是假话；
> 3. 当前的话表示 X 吃 X，就是假话。
> 
> 你的任务是根据给定的 N（1 ≤ N ≤ 50,000）和 K 句话（0 ≤ K ≤ 100,000），输出假话的总数。
> 
> **Input**
> 第一行包含两个整数 N 和 K，表示动物的数量和语句的数量。
> 接下来 K 行，每行包含三个整数 D、X、Y，表示一条语句。其中 D 表示语句类型（1 或 2），X 和 Y 表示涉及的动物编号。
> 
> **Output**
> 输出一个整数，表示假话的总数。
> 
> **Sample Input 1**
> ```text
> 100 7
> 1 101 1
> 2 1 2
> 2 2 3
> 2 3 3
> 1 1 3
> 2 3 1
> 1 5 5
> ```
> 
> **Sample Output 1**
> ```text
> 3
> ```

这是一个经典的并查集（Disjoint Set Union, DSU）题目，通常被称为"带权并查集"或"偏移量并查集"的模板题。

### 核心思路：带权并查集

在这个问题中，不仅需要维护动物是否在同一个集合（即是否有关系），还需要维护它们之间的**捕食关系**。

我们可以用 `dist[x]` 表示节点 `x` 与其父节点 `parent[x]` 的关系：

- **0**：`x` 与父节点是同类。
- **1**：`x` 吃父节点。
- **2**：`x` 被父节点吃。

在环形食物链中，这种关系可以通过**模 3 运算**（$\mod 3$）来简化。

---

### 关键操作

#### 1. 查找与路径压缩（`find`）

在执行 `find` 操作时，我们需要更新当前节点到根节点的距离：

$$
dist[x] = (dist[x] + dist[parent[x]]) \pmod 3
$$

#### 2. 判断真假

对于每一句话 $D, X, Y$：

- **越界或 X 吃 X**：如果 $X > N$ 或 $Y > N$ 或（$D=2$ 且 $X=Y$），直接判定为假话。
- **已有关系**：如果 $X$ 和 $Y$ 已经在同一个集合中（根节点相同）：
  - 若 $D=1$（同类）：必须满足 $(dist[X] - dist[Y]) \pmod 3 == 0$。
  - 若 $D=2$（$X$ 吃 $Y$）：必须满足 $(dist[X] - dist[Y]) \pmod 3 == 1$。
  - *注意：C++ 中取模负数需要写成 `(a % 3 + 3) % 3`。*

#### 3. 合并集合（`union`）

如果 $X$ 和 $Y$ 不在同一集合，则该话为真，执行合并：

- 找到 $X$ 的根 $rootX$ 和 $Y$ 的根 $rootY$。
- 令 `parent[rootX] = rootY`。
- 更新 $dist[rootX]$：
  - 若 $D=1$：$dist[rootX] = (dist[Y] - dist[X] + 3) \pmod 3$。
  - 若 $D=2$：$dist[rootX] = (dist[Y] - dist[X] + 1 + 3) \pmod 3$。

### 参考代码（C++）

```cpp
#include <iostream>
#include <vector>

using namespace std;

const int MAXN = 50005;
int p[MAXN], d[MAXN]; // p 为父节点，d 为到父节点的距离

int find(int x) {
    if (p[x] != x) {
        int root = find(p[x]);
        d[x] = (d[x] + d[p[x]]) % 3; // 路径压缩更新距离
        p[x] = root;
    }
    return p[x];
}

int main() {
    int n, k;
    scanf("%d %d", &n, &k);

    for (int i = 1; i <= n; i++) {
        p[i] = i;
        d[i] = 0;
    }

    int res = 0;
    while (k--) {
        int t, x, y;
        scanf("%d %d %d", &t, &x, &y);

        if (x > n || y > n) {
            res++;
            continue;
        }

        int px = find(x), py = find(y);

        if (t == 1) {
            if (px == py && (d[x] - d[y] % 3 + 3) % 3 != 0) {
                res++;
            } else if (px != py) {
                p[px] = py;
                d[px] = (d[y] - d[x] + 3) % 3;
            }
        } else {
            if (x == y) {
                res++;
                continue;
            }
            if (px == py && (d[x] - d[y] % 3 + 3) % 3 != 1) {
                res++;
            } else if (px != py) {
                p[px] = py;
                d[px] = (d[y] - d[x] + 1 + 3) % 3;
            }
        }
    }

    printf("%d\n", res);
    return 0;
}
```

### 复杂度分析

- **时间复杂度**：$O(K \cdot \alpha(N))$，其中 $\alpha$ 是阿克曼函数的反函数，接近常数。
- **空间复杂度**：$O(N)$，用于存储并查集数组。
