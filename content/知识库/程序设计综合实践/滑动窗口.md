# 滑动窗口
Boring count

  

No tag

Time Limit：C/C++ 1000MS，Other 2000MS  
Memory Limit：C/C++ 32MB，Other 64MB  
Level： Beginner  
Created By：  

Description

You are given a string S consisting of lowercase letters, and your task is counting the number of substring that the number of each lowercase letter in the substring is no more than K.

Input

In the first line there is an integer T , indicates the number of test cases.  
For each case, the first line contains a string which only consist of lowercase letters. The second line contains an integer K.  
  
[Technical Specification]  
1<=T<= 100  
1 <= the length of S <= 100000  
1 <= K <= 100000

Output

For each case, output a line contains the answer.

Sample Input 1 

3
abc
1
abcabc
1
abcabc
2

Sample Output 1 

6
15
21

```C++
#include <iostream>
#include <string>
#include <vector>

using namespace std;

typedef long long ll;

void solve() {
    string s;
    int k;
    if (!(cin >> s >> k)) return;

    int n = s.length();
    vector<int> count(26, 0); // 记录窗口内每个字母出现的次数
    ll totalSubstrings = 0;
    int left = 0;

    for (int right = 0; right < n; ++right) {
        int charIdx = s[right] - 'a';
        count[charIdx]++;

        // 如果当前字母超过了限制 K，缩小左边界
        while (count[charIdx] > k) {
            count[s[left] - 'a']--;
            left++;
        }

        // 窗口 [left, right] 及其内部所有以 right 结尾的子串都符合要求
        totalSubstrings += (right - left + 1);
    }

    cout << totalSubstrings << endl;
}

int main() {
    // 优化 IO
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    if (!(cin >> t)) return 0;
    while (t--) {
        solve();
    }
    return 0;
}
```

# 单调队列

## Sliding Window

**Contest Problem**

- **Time Limit**：C/C++ 12000MS，Other 24000MS
- **Memory Limit**：C/C++ 64MB，Other 128MB

### Description

An array of size *n* ≤ 10⁶ is given to you. There is a sliding window of size *k* which is moving from the very left of the array to the very right. You can only see the *k* numbers in the window. Each time the sliding window moves rightwards by one position.

Your task is to determine the maximum and minimum values in the sliding window at each position.

### Input

The input consists of two lines. The first line contains two integers *n* and *k* which are the lengths of the array and the sliding window. There are *n* integers in the second line.

### Output

There are two lines in the output. The first line gives the minimum values in the window at each position, from left to right, respectively. The second line gives the maximum values.

### Sample Input

```
8 3
1 3 -1 -3 5 3 6 7
```

### Sample Output

```
-1 -3 -3 -3 3 3
3 3 5 5 6 7
```

### Solution

```cpp
#include <deque>
#include <iostream>
#include <vector>

using namespace std;

void solve()
{
    int n, k;
    if (!(cin >> n >> k))
        return;

    vector<int> a(n);
    for (int i = 0; i < n; ++i)
        cin >> a[i];

    // 单调队列存索引
    deque<int> q;

    // 1. 求最小值
    for (int i = 0; i < n; ++i)
    {
        // 如果队头超出窗口范围，弹出
        while (!q.empty() && q.front() <= i - k)
            q.pop_front();
        // 如果新元素比队尾元素还小，队尾没用了
        while (!q.empty() && a[q.back()] >= a[i])
            q.pop_back();
        q.push_back(i);
        // 窗口形成后开始输出
        if (i >= k - 1)
            cout << a[q.front()] << (i == n - 1 ? "" : " ");
    }
    cout << endl;

    q.clear();

    // 2. 求最大值
    for (int i = 0; i < n; ++i)
    {
        while (!q.empty() && q.front() <= i - k)
            q.pop_front();
        // 如果新元素比队尾元素还大，队尾没用了
        while (!q.empty() && a[q.back()] <= a[i])
            q.pop_back();
        q.push_back(i);
        if (i >= k - 1)
            cout << a[q.front()] << (i == n - 1 ? "" : " ");
    }
    cout << endl;
}

int main()
{
    // 加速 I/O，在大数据量下非常重要
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
    return 0;
}
```
