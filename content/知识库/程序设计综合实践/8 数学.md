The Euler function

  

Contest Problem

Time Limit：C/C++ 1000MS，Other 2000MS  
Memory Limit：C/C++ 32MB，Other 64MB  

Description

The Euler function phi is an important kind of function in number theory, (n) represents the amount of the numbers which are smaller than n and coprime to n, and this function has a lot of beautiful characteristics. Here comes a very easy question: suppose you are given a, b, try to calculate (a)+ (a+1)+…+ (b)

Input

There are several test cases. Each line has two integers a, b (2<a<b<3000000).

Output

```
Output the result of  (a)+ (a+1)+....+ (b)
```

Sample Input 1 

3 100

Sample Output 1 

3042

这道题目要求计算给定区间 $[a, b]$ 内所有整数的欧拉函数（Euler's totient function）之和。

由于数据范围 $b$ 高达 $3,000,000$，且存在多组测试数据，如果对每个数单独计算 $\phi(n)$，复杂度会过高。最高效的方法是利用**埃拉托斯特尼筛法（Eratosthenes Sieve）**的思想，预处理出所有数的欧拉函数值，再通过**前缀和**实现 $O(1)$ 的区间查询。

---

### 核心算法：线性筛求欧拉函数

欧拉函数具有以下性质：

1. 若 $p$ 为质数，则 $\phi(p) = p - 1$。
2. 若 $p$ 为质数且 $p \mid n$：
* 如果 $p^2 \mid n$，则 $\phi(n) = \phi(n/p) \cdot p$。
* 如果 $p \nmid (n/p)$，则 $\phi(n) = \phi(n/p) \cdot (p - 1)$（根据积性函数性质）。



### 实现步骤

1. **预处理 $\phi(n)$**：使用类似线性筛的算法，在 $O(N)$ 时间内计算出 $1$ 到 $3,000,000$ 的所有 $\phi$ 值。
2. **计算前缀和**：令 $S[i] = \sum_{j=1}^{i} \phi(j)$。这样 $\sum_{i=a}^{b} \phi(i) = S[b] - S[a-1]$。
3. **处理多组输入**：直接输出计算结果。

> **注意**：结果可能超过 `int` 的范围（$3 \times 10^6$ 的平方量级），因此必须使用 `long long`。

---

### 参考代码 (C++)

```cpp
#include <iostream>

using namespace std;

const int MAXN = 3000005;
const int MAX_PRIME = 220000; // 3000000以内的质数只有216816个

long long sum[MAXN];          // 只保留这一个大数组，身兼两职
int primes[MAX_PRIME], cnt;
bool st[MAXN];

void get_phi(int n) {
    sum[1] = 1; // 暂存 phi[1]
    for (int i = 2; i <= n; i++) {
        if (!st[i]) {
            primes[cnt++] = i;
            sum[i] = i - 1; // 暂存 phi[i]
        }
        for (int j = 0; j < cnt && primes[j] <= n / i; j++) {
            st[i * primes[j]] = true;
            if (i % primes[j] == 0) {
                sum[i * primes[j]] = sum[i] * primes[j];
                break;
            }
            sum[i * primes[j]] = sum[i] * (primes[j] - 1);
        }
    }
    
    // 关键：就地转化为前缀和
    for (int i = 1; i <= n; i++) {
        sum[i] = sum[i - 1] + sum[i];
    }
}

int main() {
    // 预处理
    get_phi(3000000);
    
    int a, b;
    while (scanf("%d %d", &a, &b) != EOF) {
        printf("%lld\n", sum[b] - sum[a - 1]);
    }
    return 0;
}

```

### 复杂度分析

* **空间复杂度**：$O(N)$
	- **复用 `sum` 数组**：我们根本不需要同时保留 `phi` 数组和 `sum` 数组。在筛法的过程中，可以直接把 $\phi$ 值累加并存进同一个 `long long` 数组里。这样直接砍掉 **22.9 MB**。
	- **缩减 `primes` 数组**：在 $3 \times 10^6$ 以内，质数的个数其实只有 **216,816** 个。所以 `primes` 数组开到 `220000` 就足够了，不需要开到 $3 \times 10^6$。这样又能省下约 **10.5 MB**。
	- **使用 `std::bitset` 或更小的布尔标记**：`bool` 标记数组如果写成全局，差不多是 3MB，但如果用 `bitset` 还能再压小 8 倍。不过优化了前两项后，内存就已经完全安全了。
* **时间复杂度**：
* 预处理：$O(N)$。
* 查询：每组数据 $O(1)$。
* 在 $N=3 \times 10^6$ 的情况下，运行时间远低于 1000MS。
