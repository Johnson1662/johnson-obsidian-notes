# 滑动窗口

## Boring count（无聊的计数）

**Contest Problem**

- **Time Limit**：C/C++ 1000MS，Other 2000MS
- **Memory Limit**：C/C++ 32MB，Other 64MB
- **Level**：Beginner

### 题目描述

给定一个由小写字母组成的字符串 S，你的任务是统计满足条件的子串数量：子串中每个小写字母的出现次数不超过 K。

### 输入格式

第一行是一个整数 T，表示测试用例的数量。

每个测试用例包含两行：
- 第一行：一个只包含小写字母的字符串
- 第二行：一个整数 K

[技术规格]
- 1 ≤ T ≤ 100
- 1 ≤ 字符串长度 ≤ 100000
- 1 ≤ K ≤ 100000

### 输出格式

每个测试用例输出一行，包含答案（符合条件的子串数量）。

### 样例输入

```
3
abc
1
abcabc
1
abcabc
2
```

### 样例输出

```
6
15
21
```

### 算法分析

使用滑动窗口（双指针）方法。维护一个窗口 `[left, right]`，保证窗口内每个字母的出现次数都不超过 `K`。

对于每个右端点 `right`，不断移动左端点 `left` 直到窗口合法。此时以 `right` 结尾的合法子串数量为 `right - left + 1`。

### 代码实现

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

typedef long long ll;

void solve() {
    string s;
    int k;
    if (!(cin >> s >> k)) return;

    int n = s.length();
    vector<int> count(26, 0); // 记录窗口内每个字母出现的次数
    ll totalSubstrings = 0;
    int left = 0;

    for (int right = 0; right < n; ++right) {
        int charIdx = s[right] - 'a';
        count[charIdx]++;

        // 如果当前字母超过了限制 K，缩小左边界
        while (count[charIdx] > k) {
            count[s[left] - 'a']--;
            left++;
        }

        // 窗口 [left, right] 及其内部所有以 right 结尾的子串都符合要求
        totalSubstrings += (right - left + 1);
    }

    cout << totalSubstrings << endl;
}

int main() {
    // 优化 IO
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    if (!(cin >> t)) return 0;
    while (t--) {
        solve();
    }
    return 0;
}
```

## Sliding Window（滑动窗口 / 单调队列）

**Contest Problem**

- **Time Limit**：C/C++ 12000MS，Other 24000MS
- **Memory Limit**：C/C++ 64MB，Other 128MB
- **Level**：Beginner

### 题目描述

给定一个大小为 $n$（$n \le 10^6$）的数组。有一个大小为 $k$ 的滑动窗口从数组最左边移动到最右边。你只能看到窗口内的 $k$ 个数。窗口每次向右移动一个位置。

下表展示了窗口位置及对应的最小值和最大值：

| 窗口位置 | 最小值 | 最大值 |
|---|---|---|
| `[1  3  -1] -3  5  3  6  7` | -1 | 3 |
| `1 [3  -1  -3] 5  3  6  7` | -3 | 3 |
| `1  3 [-1  -3  5] 3  6  7` | -3 | 5 |
| `1  3  -1 [-3  5  3] 6  7` | -3 | 5 |
| `1  3  -1  -3 [5  3  6] 7` | 3 | 6 |
| `1  3  -1  -3  5 [3  6  7]` | 3 | 7 |

你的任务是确定每个窗口位置的最小值和最大值。

### 输入格式

输入包含两行：
- 第一行：两个整数 $n$ 和 $k$，分别表示数组长度和滑动窗口大小
- 第二行：$n$ 个整数

### 输出格式

输出包含两行：
- 第一行：从左到右每个窗口的最小值
- 第二行：从左到右每个窗口的最大值

### 样例输入

```
8 3
1 3 -1 -3 5 3 6 7
```

### 样例输出

```
-1 -3 -3 -3 3 3
3 3 5 5 6 7
```

### 算法分析

使用`单调队列（Monotonic Queue）`维护窗口内的最值：
- **最小值**：维护一个递增的`单调队列`，队头始终是当前窗口的最小值
- **最大值**：维护一个递减的`单调队列`，队头始终是当前窗口的最大值

`单调队列`中存储数组下标，方便判断元素是否还在窗口内。

### 代码实现

```cpp
#include <deque>
#include <iostream>
#include <vector>

using namespace std;

void solve()
{
    int n, k;
    if (!(cin >> n >> k))
        return;

    vector<int> a(n);
    for (int i = 0; i < n; ++i)
        cin >> a[i];

    // 单调队列存索引
    deque<int> q;

    // 1. 求最小值（递增队列）
    for (int i = 0; i < n; ++i)
    {
        // 如果队头超出窗口范围，弹出
        while (!q.empty() && q.front() <= i - k)
            q.pop_front();
        // 如果新元素比队尾元素还小，队尾没用了
        while (!q.empty() && a[q.back()] >= a[i])
            q.pop_back();
        q.push_back(i);
        // 窗口形成后开始输出
        if (i >= k - 1)
            cout << a[q.front()] << (i == n - 1 ? "" : " ");
    }
    cout << endl;

    q.clear();

    // 2. 求最大值（递减队列）
    for (int i = 0; i < n; ++i)
    {
        while (!q.empty() && q.front() <= i - k)
            q.pop_front();
        // 如果新元素比队尾元素还大，队尾没用了
        while (!q.empty() && a[q.back()] <= a[i])
            q.pop_back();
        q.push_back(i);
        if (i >= k - 1)
            cout << a[q.front()] << (i == n - 1 ? "" : " ");
    }
    cout << endl;
}

int main()
{
    // 加速 I/O，在大数据量下非常重要
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
    return 0;
}
```
