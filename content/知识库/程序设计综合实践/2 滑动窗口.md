# 滑动窗口

## Boring count（无聊的计数）

### 题目描述

给定一个由小写字母组成的字符串 S，你的任务是统计满足条件的子串数量：子串中每个小写字母的出现次数不超过 K。

### 输入格式

第一行是一个整数 T，表示测试用例的数量。

每个测试用例包含两行：
- 第一行：一个只包含小写字母的字符串
- 第二行：一个整数 K

[技术规格]
- 1 ≤ T ≤ 100
- 1 ≤ 字符串长度 ≤ 100000
- 1 ≤ K ≤ 100000

### 输出格式

每个测试用例输出一行，包含答案（符合条件的子串数量）。

### 样例输入

```
3
abc
1
abcabc
1
abcabc
2
```

### 样例输出

```
6
15
21
```

### 问题分析

#### 第一步：理解题意

给定一个字符串 S，求有多少个子串，使得子串中每个字母的出现次数都不超过 K。

子串的定义是原字符串中连续的一段。"abc" 的所有子串有："a", "b", "c", "ab", "bc", "abc"，共 6 个。

#### 第二步：滑动窗口的核心思想

暴力枚举所有子串需要 O(N²) 的时间，N=10 万时无法接受。

滑动窗口（双指针）的思想是：
- 维护一个窗口 `[left, right]`，保证窗口内的每个字母都不超过 K 次
- 对于每个右端点 right，找到最小的 left，使得 `[left, right]` 是合法的
- 此时所有以 right 结尾的合法子串数量 = right - left + 1

为什么是 right - left + 1？
> 窗口 `[left, right]` 中的任意后缀 `[i, right]`（其中 left ≤ i ≤ right）也都是合法子串（因为窗口内的字母都没超过 K，它的子集更不会超过）。这些后缀的数量正好是 right - left + 1 个。

#### 第三步：如何移动窗口？

右指针 right 每次都向右移动一位，加入一个新字符。

如果新字符导致某个字母超过 K 次，就不断移动左指针 left 向右，直到该字母的计数不再超标。

这个过程就像用一个可伸缩的框去扫描字符串——框太宽了就收紧左边界，保持框内始终合法。

#### 第四步：模拟样例

S="abc", K=1：

| right | S[right] | 加入后状态 | 需要左移？ | left | 合法子串（以 right 结尾） | 数量 |
|:---:|:---:|---|---|:---:|---|---|
| 0 | 'a' | a:1 | 否 | 0 | "a" | 1 |
| 1 | 'b' | a:1,b:1 | 否 | 0 | "ab", "b" | 2 |
| 2 | 'c' | a:1,b:1,c:1 | 否 | 0 | "abc", "bc", "c" | 3 |

总数 = 1+2+3 = 6 ✅

S="abcabc", K=1，当 right 到第二个 'a' 时：

| right | S[right] | 加入后 | 需要左移？ | left | 数量 |
|:---:|:---:|---|---|:---:|:---:|
| 0 | a | a:1 | 否 | 0 | 1 |
| 1 | b | a:1,b:1 | 否 | 0 | 2 |
| 2 | c | a:1,b:1,c:1 | 否 | 0 | 3 |
| 3 | a | a:2 > 1 | 左移 left=1, a-- → a:1 | 1 | 3-1+1=3 |
| 4 | b | b:2 > 1 | 左移 left=2, b-- → b:1 | 2 | 4-2+1=3 |
| 5 | c | c:2 > 1 | 左移 left=3, c-- → c:1 | 3 | 5-3+1=3 |

总数 = 1+2+3+3+3+3 = 15 ✅

### 代码实现

```cpp
#include <iostream>
#include <string>
#include <vector>

using namespace std;

typedef long long ll;

void solve() {
    string s;
    int k;
    if (!(cin >> s >> k)) return;

    int n = s.length();
    vector<int> count(26, 0); // 记录窗口内每个字母出现的次数
    ll totalSubstrings = 0;
    int left = 0;

    for (int right = 0; right < n; ++right) {
        int charIdx = s[right] - 'a';
        count[charIdx]++;

        // 如果当前字母超过了限制 K，缩小左边界
        while (count[charIdx] > k) {
            count[s[left] - 'a']--;
            left++;
        }

        // 窗口 [left, right] 及其内部所有以 right 结尾的子串都符合要求
        totalSubstrings += (right - left + 1);
    }

    cout << totalSubstrings << endl;
}

int main() {
    // 优化 IO
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    if (!(cin >> t)) return 0;
    while (t--) {
        solve();
    }
    return 0;
}
```

## Sliding Window（滑动窗口 / 单调队列）

### 题目描述

给定一个大小为 $n$（$n \le 10^6$）的数组。有一个大小为 $k$ 的滑动窗口从数组最左边移动到最右边。你只能看到窗口内的 $k$ 个数。窗口每次向右移动一个位置。

下表展示了窗口位置及对应的最小值和最大值：

| 窗口位置 | 最小值 | 最大值 |
|---|---|---|
| `[1  3  -1] -3  5  3  6  7` | -1 | 3 |
| `1 [3  -1  -3] 5  3  6  7` | -3 | 3 |
| `1  3 [-1  -3  5] 3  6  7` | -3 | 5 |
| `1  3  -1 [-3  5  3] 6  7` | -3 | 5 |
| `1  3  -1  -3 [5  3  6] 7` | 3 | 6 |
| `1  3  -1  -3  5 [3  6  7]` | 3 | 7 |

你的任务是确定每个窗口位置的最小值和最大值。

### 输入格式

输入包含两行：
- 第一行：两个整数 $n$ 和 $k$，分别表示数组长度和滑动窗口大小
- 第二行：$n$ 个整数

### 输出格式

输出包含两行：
- 第一行：从左到右每个窗口的最小值
- 第二行：从左到右每个窗口的最大值

### 样例输入

```
8 3
1 3 -1 -3 5 3 6 7
```

### 样例输出

```
-1 -3 -3 -3 3 3
3 3 5 5 6 7
```

### 问题分析

#### 第一步：理解题目

一个长度为 k 的窗口在数组上滑动，每次滑一个位置。我们需要输出每个窗口位置的最小值和最大值。

#### 第二步：暴力方法为什么慢？

最直接的做法：对于每个窗口位置，遍历窗口内的 k 个元素找最小值和最大值。
- 窗口数量 ≈ N，每个窗口遍历 k 个元素 → O(N·k)
- N=10⁶, k=10⁵ 时，10¹¹ 次运算，无法接受

#### 第三步：单调队列的核心思想

单调队列的核心思路是：**对于最小值问题，如果一个元素比它后面的元素还大，那么它永远不可能成为后续窗口的最小值。因为它不仅更大，而且更早出窗口。**

具体来说，我们维护一个双端队列（deque）存放数组下标，并保证：
- **最小值队列**：队列中的下标对应的值是递增的（队头最小）
- **最大值队列**：队列中的下标对应的值是递减的（队头最大）

主要操作：
1. **出队检查**：队头如果已经滑出当前窗口，弹出
2. **维护单调性**：新元素加入前，把破坏单调性的队尾元素全部弹出
3. **入队**：将新元素的下标加入队尾
4. **输出**：窗口形成后（i ≥ k-1），队头就是当前窗口的最值

#### 第四步：模拟样例

a = [1, 3, -1, -3, 5, 3, 6, 7]，k=3，求最小值：

| i | a[i] | 操作 | 队列（存储下标） | 窗口 | 最小值 |
|:-:|:---:|:---|:---:|:---:|:---:|
| 0 | 1 | 入队 | [0] | — | — |
| 1 | 3 | 3 > 队尾 1，直接入队 | [0,1] | — | — |
| 2 | -1 | -1 < 队尾 3，弹出 1；-1 < 队尾 1，弹出 0；入队 | [2] | [1,3,-1] | a[2]=-1 |
| 3 | -3 | -3 < 队尾 -1，弹出 2；入队 | [3] | [3,-1,-3] | a[3]=-3 |
| 4 | 5 | 5 > 队尾 -3，直接入队 | [3,4] | [-1,-3,5] | a[3]=-3 |
| 5 | 3 | 3 < 队尾 5，弹出 4；3 > 队尾 -3，入队 | [3,5] | [-3,5,3] | a[3]=-3 |
| 6 | 6 | 6 > 队尾 3，直接入队；队头 3 已出窗口？3 < 6-3=3 ✓ | [3,5,6] | [5,3,6] | a[3]=-3 |
| 7 | 7 | 7 > 队尾 6，直接入队；队头 3 已出窗口 3 ≤ 7-3=4，弹出 3 | [5,6,7] | [3,6,7] | a[5]=3 |

输出：-1 -3 -3 -3 3 3 ✅

### 代码实现

```cpp
#include <deque>
#include <iostream>
#include <vector>

using namespace std;

void solve()
{
    int n, k;
    if (!(cin >> n >> k))
        return;

    vector<int> a(n);
    for (int i = 0; i < n; ++i)
        cin >> a[i];

    // 单调队列存索引
    deque<int> q;

    // 1. 求最小值（递增队列）
    for (int i = 0; i < n; ++i)
    {
        // 如果队头超出窗口范围，弹出
        while (!q.empty() && q.front() <= i - k)
            q.pop_front();
        // 如果新元素比队尾元素还小，队尾没用了
        while (!q.empty() && a[q.back()] >= a[i])
            q.pop_back();
        q.push_back(i);
        // 窗口形成后开始输出
        if (i >= k - 1)
            cout << a[q.front()] << (i == n - 1 ? "" : " ");
    }
    cout << endl;

    q.clear();

    // 2. 求最大值（递减队列）
    for (int i = 0; i < n; ++i)
    {
        while (!q.empty() && q.front() <= i - k)
            q.pop_front();
        // 如果新元素比队尾元素还大，队尾没用了
        while (!q.empty() && a[q.back()] <= a[i])
            q.pop_back();
        q.push_back(i);
        if (i >= k - 1)
            cout << a[q.front()] << (i == n - 1 ? "" : " ");
    }
    cout << endl;
}

int main()
{
    // 加速 I/O，在大数据量下非常重要
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    solve();
    return 0;
}
```
