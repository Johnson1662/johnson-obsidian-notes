# 二分答案

## 序列变换

**Contest Problem**

- **Time Limit**：C/C++ 1000MS，Other 2000MS
- **Memory Limit**：C/C++ 64MB，Other 128MB

### 题目描述

给定序列 $A=\{A_1, A_2, \dots, A_n\}$，要求改变序列 $A$ 中的某些元素，形成一个**严格单调**的序列 $B$（即 $B_i < B_{i+1}, 1 \le i < N$）。

定义变换代价为 $\text{cost}(A, B) = \max(|A_i - B_i|)$。请求出满足条件的**最小代价**。

> [!important] 注意
> 每个元素在变换前后都必须是**整数**。

### 输入格式

- 第一行为测试组数 $T$（$1 \le T \le 10$）。
- 每组数据：
  - 第一行：序列长度 $N$（$1 \le N \le 10^5$）。
  - 第二行：$N$ 个正整数 $A_1, A_2, \dots, A_n$（$A_i \le 10^6$）。

### 输出格式

对于每个样例，输出两行：
1. `Case #i:`
2. 最小代价整数。

### 样例输入

```
2
2
1 10
3
2 5 4
```

### 样例输出

```
Case #1:
0
Case #2:
1
```

### 算法分析

1. 严格单调递增要求 `B[i] < B[i+1]`，且 `B` 为整数。等价于 `B[i] - i < B[i+1] - (i+1)`。
   令 `C[i] = A[i] - i`，问题转化为：寻找序列 `D`，使得 `D` 为非递减序列 (`D[i] <= D[i+1]`)，且最小化 $\max|C[i] - D[i]|$。

2. 最小化最大差值问题，可以考虑二分答案。
   假设代价为 `mid`，那么对于每个位置 `i`，`B[i]` 必须落在 `[A[i] - mid, A[i] + mid]` 范围内。
   同时要满足 `B[i] - i <= B[i+1] - (i+1)`。
   令 `C[i] = A[i] - i`，则 `D[i]` 必须落在 `[C[i] - mid, C[i] + mid]` 范围内，且 `D[i] <= D[i+1]`。

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

/**
 * 假设代价为 mid，检查是否可行
 * 每个位置 i 的值必须落在 [C[i] - mid, C[i] + mid] 范围内
 * 且序列必须非递减：D[i] <= D[i+1]
 */
bool check(int mid, int n, const vector<int> &C)
{
    // 设置第一个元素的最小可能值
    int current_min = C[0] - mid;

    for (int i = 1; i < n; ++i)
    {
        // 当前元素能达到的范围是 [C[i] - mid, C[i] + mid]
        // 且必须满足 D[i] >= D[i-1] (即 current_min)
        int lower = C[i] - mid;
        int upper = C[i] + mid;

        // 如果当前元素的上限都比前一个元素的最小值还要小，说明 mid 太小了
        if (upper < current_min)
            return false;

        // 为了给后面留出更多空间，我们让 D[i] 取尽可能小的值
        // 但不能小于前一个元素的值，也不能小于它的允许下限
        current_min = max(current_min, lower);
    }
    return true;
}

void solve(int caseNum)
{
    int n;
    cin >> n;
    vector<int> A(n);
    vector<int> C(n);
    for (int i = 0; i < n; ++i)
    {
        cin >> A[i];
        C[i] = A[i] - i;
    }

    // 二分搜索最小代价 mid
    int left = 0, right = 1000000;
    int ans = right;

    while (left <= right)
    {
        int mid = left + (right - left) / 2;
        if (check(mid, n, C))
        {
            ans = mid;
            right = mid - 1;
        }
        else
        {
            left = mid + 1;
        }
    }

    cout << "Case #" << caseNum << ":" << endl;
    cout << ans << endl;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    if (!(cin >> T))
        return 0;
    for (int i = 1; i <= T; ++i)
    {
        solve(i);
    }
    return 0;
}
```

## River Hopscotch（河跳石）

**Contest Problem**

- **Time Limit**：C/C++ 2000MS，Other 4000MS
- **Memory Limit**：C/C++ 64MB，Other 128MB

### 题目描述

每年奶牛们都会举办一场特殊的跳房子比赛，比赛在一条笔直的河流上进行。河流的起点和终点各有一块岩石，相距 $L$ 个单位（$1 \le L \le 1\,000\,000\,000$）。在起点和终点之间，还有 $N$（$0 \le N \le 50\,000$）块岩石，每块岩石距离起点 $D_i$（$0 < D_i < L$）。

农夫约翰计划移除一些岩石，以增加奶牛跳跃的最短距离。他不能移除起点和终点的岩石，但可以移除最多 $M$ 块岩石（$0 \le M \le N$）。

请帮助农夫约翰确定：在最优移除 $M$ 块岩石后，奶牛跳跃的最短距离的最大值是多少？

### 输入格式

第 1 行：三个空格分隔的整数 $L$、$N$ 和 $M$

第 2…$N$+1 行：每行一个整数，表示该岩石距离起点的距离。没有两块岩石在同一位置。

### 输出格式

第 1 行：一个整数，表示移除 $M$ 块岩石后，奶牛跳跃的最短距离的最大可能值。

### 样例输入

```
25 5 2
2
14
11
21
17
```

### 样例输出

```
4
```

### 提示

移除任何岩石之前，最短跳跃是从 0（起点）到 2，距离为 2。移除位置 2 和 14 的岩石后，最短跳跃距离为 4（从 17 到 21 或从 21 到 25）。

### 解题思路

二分答案：假设最短距离为 mid，检查移除不超过 M 块岩石后，是否能使所有相邻岩石（含起点和终点）的距离都不小于 mid。

检查方法：从左到右遍历岩石，如果当前岩石与上一个保留岩石的距离小于 mid，则移除当前岩石；否则保留当前岩石。最后还要检查终点与最后一个保留岩石的距离。

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

bool check(long long min_dist, int L, int N, int M, const vector<int> &rocks)
{
    int removed = 0;
    int last_pos = 0;

    for (int i = 0; i < N; ++i)
    {
        if (rocks[i] - last_pos < min_dist)
        {
            // 距离太短，移除这块岩石
            removed++;
        }
        else
        {
            // 保留这块岩石，跳到这里
            last_pos = rocks[i];
        }
    }

    // 检查最后一段跳到终点的距离
    if (L - last_pos < min_dist)
    {
        removed++;
    }

    return removed <= M;
}

int main()
{
    int L, N, M;
    if (!(cin >> L >> N >> M))
        return 0;

    vector<int> rocks(N);
    for (int i = 0; i < N; ++i)
    {
        cin >> rocks[i];
    }

    sort(rocks.begin(), rocks.end());

    long long left = 0, right = L;
    long long ans = 0;

    while (left <= right)
    {
        long long mid = left + (right - left) / 2;
        if (mid == 0)
        { // 避免 0 距离导致无限循环
            left = 1;
            continue;
        }
        if (check(mid, L, N, M, rocks))
        {
            ans = mid;
            left = mid + 1;
        }
        else
        {
            right = mid - 1;
        }
    }

    cout << ans << endl;

    return 0;
}
```

## Can you find it?（你能找到吗？）

**Contest Problem**

- **Time Limit**：C/C++ 3000MS，Other 6000MS
- **Memory Limit**：C/C++ 9MB，Other 18MB
- **Level**：Beginner

### 题目描述

给你三个数字序列 `A`、`B`、`C`，然后给你一个数字 `X`。现在你需要判断是否能找到三个数字 $A_i$、$B_j$、$C_k$，满足公式 $A_i + B_j + C_k = X$。

### 输入格式

输入包含多个测试用例。每个测试用例的格式如下：
- 第一行：三个整数 $L$、$N$、$M$
- 第二行：$L$ 个整数，表示序列 `A`
- 第三行：$N$ 个整数，表示序列 `B`
- 第四行：$M$ 个整数，表示序列 `C`
- 第五行：一个整数 $S$，表示有 $S$ 个 $X$ 需要计算

其中 $1 \le L, N, M \le 500$，$1 \le S \le 1000$。所有整数都是 32 位整数。

### 输出格式

对于每个测试用例，首先输出用例编号，格式为 "Case d:"，然后对于每个 $X$，输出 "YES" 或 "NO"。

### 样例输入

```
3 3 3
1 2 3
1 2 3
1 2 3
3
1
4
10
```

### 样例输出

```
Case 1:
NO
YES
NO
```

### 解题思路

直接三重循环会超时。优化方法：
1. 预处理 A+B 的所有组合，存入数组并排序去重
2. 对于每个 X 和每个 C[k]，检查 X - C[k] 是否在 A+B 的数组中（二分查找）

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

void solve(int L, int N, int M, int caseNum) {
    vector<int> A(L), B(N), C(M);
    for (int &x : A) cin >> x;
    for (int &x : B) cin >> x;
    for (int &x : C) cin >> x;

    // 1. 预处理 A+B 的所有组合
    vector<int> sumAB;
    sumAB.reserve(L * N);
    for (int i = 0; i < L; ++i) {
        for (int j = 0; j < N; ++j) {
            sumAB.push_back(A[i] + B[j]);
        }
    }

    // 2. 排序以便二分查找
    sort(sumAB.begin(), sumAB.end());
    sumAB.erase(unique(sumAB.begin(), sumAB.end()), sumAB.end());

    int S;
    cin >> S;
    cout << "Case " << caseNum << ":" << endl;

    while (S--) {
        int X;
        cin >> X;
        bool found = false;

        // 3. 遍历 C，二分找 X - C[k]
        for (int k = 0; k < M; ++k) {
            int target = X - C[k];
            if (binary_search(sumAB.begin(), sumAB.end(), target)) {
                found = true;
                break;
            }
        }

        if (found) cout << "YES" << endl;
        else cout << "NO" << endl;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int L, N, M, caseNum = 1;
    while (cin >> L >> N >> M) {
        solve(L, N, M, caseNum++);
    }
    return 0;
}
```

## Median（中位数）

**Contest Problem**

- **Time Limit**：C/C++ 1000MS，Other 2000MS
- **Memory Limit**：C/C++ 64MB，Other 128MB
- **Level**：Beginner

### 题目描述

给定 $N$ 个数字 $X_1, X_2, \dots, X_n$，计算每对数字的差值：$|X_i - X_j|$（$1 \le i < j \le N$）。我们可以得到 $C(N,2)$ 个差值。现在你的任务是以最快的速度找出这些差值的中位数！

注意：本题中，中位数定义为第 $m/2$ 小的数字（如果 $m$ 是偶数）。例如，当 $m = 6$ 时，你需要找第 3 小的差值。

### 输入格式

输入包含多个测试用例。每个测试用例的第一行是 $N$。接下来是 $N$ 个数字，表示 $X_1, X_2, \dots, X_n$（$X_i \le 1\,000\,000\,000$，$3 \le N \le 100\,000$）。

### 输出格式

对于每个测试用例，输出一行中位数。

### 样例输入

```
4
1 3 2 4
3
1 10 2
```

### 样例输出

```
1
8
```

### 解题思路

差值的中位数具有单调性：如果差值 ≤ mid 的对数 ≥ 目标排名，说明答案 ≤ mid。

使用二分答案，对于每个 mid，统计差值 ≤ mid 的对数（使用双指针技巧，先排序）。

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

typedef long long ll;

// 核心函数：统计数组中差值 <= mid 的对数
ll countPairs(const vector<int>& a, int n, int mid) {
    ll count = 0;
    // 使用双指针：对于每个 i，找到最大的 j 使得 a[j] - a[i] <= mid
    for (int i = 0, j = 0; i < n; ++i) {
        while (j < n && a[j] - a[i] <= mid) {
            j++;
        }
        // 此时 a[i+1...j-1] 与 a[i] 的差都 <= mid
        // 数量就是 j - i - 1
        count += (j - i - 1);
    }
    return count;
}

int main() {
    int n;
    while (cin >> n) {
        vector<int> a(n);
        for (int i = 0; i < n; ++i) cin >> a[i];

        sort(a.begin(), a.end()); // 排序是所有操作的基础

        ll m = (ll)n * (n - 1) / 2; // 总对数
        ll target = (m + 1) / 2;    // 题目要求的中位数排名（第几小）
        if (m % 2 == 0) target = m / 2; // 根据题目特殊定义：m为偶数取第m/2个

        // 在差值的可能范围 [0, 最大差值] 内进行二分
        int left = 0, right = a[n - 1] - a[0], ans = 0;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (countPairs(a, n, mid) >= target) {
                ans = mid;         // 这个差值够大，尝试更小的
                right = mid - 1;
            } else {
                left = mid + 1;    // 差值太小，对数不够
            }
        }
        cout << ans << endl;
    }
    return 0;
}
```
