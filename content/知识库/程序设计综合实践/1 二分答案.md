## 1. 序列变换

> [!abstract] Contest Problem
> **Description**
> 给定序列 $A=\{A_1, A_2, \dots, A_n\}$，要求改变序列 $A$ 中的某些元素，形成一个**严格单调**的序列 $B$（即 $B_i < B_{i+1}, 1 \le i < N$）。
> 
> 定义变换代价为 $\text{cost}(A, B) = \max(|A_i - B_i|)$。请求出满足条件的**最小代价**。
> 
> **注意：** 每个元素在变换前后都必须是**整数**。
> 
> **Input**
> 第一行为测试组数 $T$（$1 \le T \le 10$）。
> 每组数据：第一行为序列长度 $N$（$1 \le N \le 10^5$），第二行为 $N$ 个正整数 $A_1, A_2, \dots, A_n$（$A_i \le 10^6$）。
> 
> **Output**
> 对于每个样例，输出两行：第一行为 `Case #i:`，第二行为最小代价整数。
> 
> **Sample Input 1**
> ```text
> 2
> 2
> 1 10
> 3
> 2 5 4
> ```
> 
> **Sample Output 1**
> ```text
> Case #1:
> 0
> Case #2:
> 1
> ```

### 问题分析

#### 第一步：理解题目在做什么

题目给了我们序列 A，允许我们修改每个位置的值（保持整数），得到一个**严格单调递增**的序列 B。代价是每个位置上 |A[i] - B[i]| 的**最大值**。

通俗地理解：我们有一组数，允许把它们整体"拧一拧"让它们变成严格递增的。每拧一个数字都有一定的"幅度"，题目问的是：把整个序列拧成递增所需的最大幅度最小能是多少。

#### 第二步：简化约束——为什么令 `C[i] = A[i] - i`？

严格递增的条件 `B[i] < B[i+1]` 比较严格，但有一个技巧可以把它变成更宽松的"非递减"：

> 如果序列 B 严格递增，那么 B[i] - i 一定是非递减的。

验证一下：因为 `B[i] < B[i+1]` 且所有值均为整数，所以 `B[i] ≤ B[i+1] - 1`。两边同时减 `(i+1)` 得 `B[i] - (i+1) ≤ B[i+1] - 1 - (i+1)`，即 `B[i] - i ≤ B[i+1] - (i+1)`。

因此令 `C[i] = A[i] - i`，`D[i] = B[i] - i`，原问题转化为：
- 寻找非递减序列 D（`D[i] ≤ D[i+1]`）
- 最小化 `max|C[i] - D[i]|`

这样一来，"严格递增"变成了"非递减"，后续处理更容易。

#### 第三步：为什么用二分答案？

"最小化最大值"是二分答案的经典信号。假设我们猜代价为 mid，问题就变成了一个判定问题：
> 是否存在一个非递减序列 D，使得每个位置都满足 |C[i] - D[i]| ≤ mid？

这个判定问题具有**单调性**：如果 mid 可行，那么更大的 mid 也一定可行（范围放大了）；如果 mid 不可行，那么更小的 mid 也一定不可行。

这正是二分答案能够成立的前提条件。

#### 第四步：check(mid) 的贪心判定逻辑

给定 mid，每个位置 i 的 D[i] 允许的范围是 `[C[i] - mid, C[i] + mid]`。

我们从左到右构造 D，采用贪心策略：**让每个 D[i] 尽可能小**，这样能留给后面的位置更大的余地。

1. 第一个位置：取最小值 `D[0] = C[0] - mid`
2. 对于位置 i（从 1 开始）：
   - 当前范围是 `[C[i] - mid, C[i] + mid]`
   - 同时必须满足 `D[i] ≥ D[i-1]`（非递减）
   - 所以实际可取的最小值为 `max(C[i] - mid, D[i-1])`
   - 如果这个最小值超过了 `C[i] + mid`，说明即使取最大值也达不到前面的高度 → mid 太小，不可行

#### 第五步：模拟样例

`A = [2, 5, 4]`，计算 `C = [2-0, 5-1, 4-2] = [2, 4, 2]`

尝试 mid = 0：

| i | C[i] | 允许范围 | 与前一个比较 | 实际取值 |
|:-:|:-:|---|---|---|
| 0 | 2 | [2,2] | — | 取最小值 2 |
| 1 | 4 | [4,4] | 需要 ≥ 2 ✓ | 取最小值 4 |
| 2 | 2 | [2,2] | 需要 ≥ 4，但上限仅为 2 → **不可行** ❌ |

尝试 mid = 1：

| i | C[i] | 允许范围 | 与前一个比较 | 实际取值 |
|:-:|:-:|---|---|---|
| 0 | 2 | [1,3] | — | 取最小值 1 |
| 1 | 4 | [3,5] | 需要 ≥ 1 ✓ | 取 max(3,1)=3 ≤ 5 ✓ |
| 2 | 2 | [1,3] | 需要 ≥ 3，取 max(1,3)=3 ≤ 3 ✓ | 取 3 ✓ |

mid=1 可行，最小代价为 1，与题目输出一致。

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

/**
 * 假设代价为 mid，检查是否可行
 * 每个位置 i 的值必须落在 [C[i] - mid, C[i] + mid] 范围内
 * 且序列必须非递减：D[i] <= D[i+1]
 */
bool check(int mid, int n, const vector<int> &C)
{
    // 设置第一个元素的最小可能值
    int current_min = C[0] - mid;

    for (int i = 1; i < n; ++i)
    {
        // 当前元素能达到的范围是 [C[i] - mid, C[i] + mid]
        // 且必须满足 D[i] >= D[i-1] (即 current_min)
        int lower = C[i] - mid;
        int upper = C[i] + mid;

        // 如果当前元素的上限都比前一个元素的最小值还要小，说明 mid 太小了
        if (upper < current_min)
            return false;

        // 为了给后面留出更多空间，我们让 D[i] 取尽可能小的值
        // 但不能小于前一个元素的值，也不能小于它的允许下限
        current_min = max(current_min, lower);
    }
    return true;
}

void solve(int caseNum)
{
    int n;
    cin >> n;
    vector<int> A(n);
    vector<int> C(n);
    for (int i = 0; i < n; ++i)
    {
        cin >> A[i];
        C[i] = A[i] - i;
    }

    // 二分搜索最小代价 mid
    int left = 0, right = 1000000;
    int ans = right;

    while (left <= right)
    {
        int mid = left + (right - left) / 2;
        if (check(mid, n, C))
        {
            ans = mid;
            right = mid - 1;
        }
        else
        {
            left = mid + 1;
        }
    }

    cout << "Case #" << caseNum << ":" << endl;
    cout << ans << endl;
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    if (!(cin >> T))
        return 0;
    for (int i = 1; i <= T; ++i)
    {
        solve(i);
    }
    return 0;
}
```

## 2. 河跳石

> [!abstract] Contest Problem
> **Description**
> 每年奶牛们都会举办一场特殊的跳房子比赛，比赛在一条笔直的河流上进行。河流的起点和终点各有一块岩石，相距 $L$ 个单位（$1 \le L \le 1\,000\,000\,000$）。在起点和终点之间，还有 $N$（$0 \le N \le 50\,000$）块岩石，每块岩石距离起点 $D_i$（$0 < D_i < L$）。
> 
> 农夫约翰计划移除一些岩石，以增加奶牛跳跃的最短距离。他不能移除起点和终点的岩石，但可以移除最多 $M$ 块岩石（$0 \le M \le N$）。
> 
> 请帮助农夫约翰确定：在最优移除 $M$ 块岩石后，奶牛跳跃的最短距离的最大值是多少？
> 
> **Input**
> 第 1 行：三个空格分隔的整数 $L$、$N$ 和 $M$。
> 第 2…$N$+1 行：每行一个整数，表示该岩石距离起点的距离。没有两块岩石在同一位置。
> 
> **Output**
> 第 1 行：一个整数，表示移除 $M$ 块岩石后，奶牛跳跃的最短距离的最大可能值。
> 
> **Sample Input 1**
> ```text
> 25 5 2
> 2
> 14
> 11
> 21
> 17
> ```
> 
> **Sample Output 1**
> `4`
> 
> **Hint**
> 移除任何岩石之前，最短跳跃是从 0（起点）到 2，距离为 2。移除位置 2 和 14 的岩石后，最短跳跃距离为 4（从 17 到 21 或从 21 到 25）。

### 问题分析

#### 第一步：理解题目

河里有起点的岩石（位置 0）、终点的岩石（位置 L）和 N 块中间岩石。每次跳跃，奶牛必须从一块保留的岩石跳到下一块保留的岩石。

约翰可以移除最多 M 块中间岩石。移除后，奶牛跳跃的"最短距离"（即所有相邻保留岩石之间距离的最小值）会发生改变。

题目问：在最优移除方案下，这个"最短距离"最大能是多少？

#### 第二步：为什么用二分答案？

又是"最大化的最小值"问题——二分答案的典型特征。

假设我们猜测最短距离为 mid，判定问题变为：
> 移除不超过 M 块岩石后，能否让所有相邻保留岩石的距离都 ≥ mid？

单调性：如果 mid 可行（能保证每跳至少 mid 米），那么比 mid 更小的距离也一定可行；反之，如果 mid 不可行（保证不了这么长的跳跃），那么更大的距离更加不可能。

#### 第三步：check(mid) 的贪心判定

从左到右遍历中间岩石，贪心地保留尽可能多的岩石：

1. 从起点（位置 0）出发
2. 对于每一块中间岩石，检查它和上一块保留岩石的距离：
   - 如果距离 < mid：说明这块岩石离得太近，跳跃距离不够，**移除它**
   - 如果距离 ≥ mid：说明这块岩石足够远，**保留它**，并更新上一点位置
3. 最后检查终点：如果最后一段跳到终点的距离 < mid，也要移除最后这块保留的岩石（即上一步保留的岩石其实是多余的）
4. 如果总移除数量 ≤ M，说明 mid 可行

这种贪心策略是最优的——为了让留出的距离尽可能大，我们当然希望尽可能保留那些能保证距离 ≥ mid 的岩石。

#### 第四步：模拟样例

L=25，N=5，岩石位置：[2, 11, 14, 17, 21]，最多移除 M=2 块

尝试 mid = 4：

| 步骤 | 当前岩石 | 距离上一保留点 | 是否 ≥ 4 | 操作 |
|:-:|:-:|:-:|:-:|---|
| 起点 | 0 | — | — | 保留 |
| 1 | 2 | 2-0=2 | ❌ | 移除 |
| 2 | 11 | 11-0=11 | ✓ | 保留，last=11 |
| 3 | 14 | 14-11=3 | ❌ | 移除 |
| 4 | 17 | 17-11=6 | ✓ | 保留，last=17 |
| 5 | 21 | 21-17=4 | ✓ | 保留，last=21 |
| 终点 | 25 | 25-21=4 | ✓ | 通过 |

移除 2 块（位置 2 和 14），≤ M，可行。

尝试 mid = 5：

| 步骤 | 当前岩石 | 距离上一保留点 | 是否 ≥ 5 | 操作 |
|:-:|:-:|:-:|:-:|---|
| 起点 | 0 | — | — | 保留 |
| 1 | 2 | 2 | ❌ | 移除 |
| 2 | 11 | 11-0=11 | ✓ | 保留，last=11 |
| 3 | 14 | 3 | ❌ | 移除 |
| 4 | 17 | 6 | ✓ | 保留，last=17 |
| 5 | 21 | 4 | ❌ | 移除 |
| 终点 | 25 | 25-17=8 | ✓ | 通过 |

移除了 3 块 > M(2)，不可行。因此最大可行 mid 为 4。

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

bool check(long long min_dist, int L, int N, int M, const vector<int> &rocks)
{
    int removed = 0;
    int last_pos = 0;

    for (int i = 0; i < N; ++i)
    {
        if (rocks[i] - last_pos < min_dist)
        {
            // 距离太短，移除这块岩石
            removed++;
        }
        else
        {
            // 保留这块岩石，跳到这里
            last_pos = rocks[i];
        }
    }

    // 检查最后一段跳到终点的距离
    if (L - last_pos < min_dist)
    {
        removed++;
    }

    return removed <= M;
}

int main()
{
    int L, N, M;
    if (!(cin >> L >> N >> M))
        return 0;

    vector<int> rocks(N);
    for (int i = 0; i < N; ++i)
    {
        cin >> rocks[i];
    }

    sort(rocks.begin(), rocks.end());

    long long left = 0, right = L;
    long long ans = 0;

    while (left <= right)
    {
        long long mid = left + (right - left) / 2;
        if (mid == 0)
        { // 避免 0 距离导致无限循环
            left = 1;
            continue;
        }
        if (check(mid, L, N, M, rocks))
        {
            ans = mid;
            left = mid + 1;
        }
        else
        {
            right = mid - 1;
        }
    }

    cout << ans << endl;

    return 0;
}
```

## 3. 你能找到吗？

> [!abstract] Contest Problem
> **Description**
> 给你三个数字序列 `A`、`B`、`C`，然后给你一个数字 `X`。现在你需要判断是否能找到三个数字 $A_i$、$B_j$、$C_k$，满足公式 $A_i + B_j + C_k = X$。
> 
> **Input**
> 输入包含多个测试用例。每个测试用例的格式如下：
> 第一行：三个整数 $L$、$N$、$M$。
> 第二行：$L$ 个整数，表示序列 `A`。
> 第三行：$N$ 个整数，表示序列 `B`。
> 第四行：$M$ 个整数，表示序列 `C`。
> 第五行：一个整数 $S$，表示有 $S$ 个 $X$ 需要计算。
> 其中 $1 \le L, N, M \le 500$，$1 \le S \le 1000$。所有整数都是 32 位整数。
> 
> **Output**
> 对于每个测试用例，首先输出用例编号，格式为 "Case d:"，然后对于每个 $X$，输出 "YES" 或 "NO"。
> 
> **Sample Input 1**
> ```text
> 3 3 3
> 1 2 3
> 1 2 3
> 1 2 3
> 3
> 1
> 4
> 10
> ```
> 
> **Sample Output 1**
> ```text
> Case 1:
> NO
> YES
> NO
> ```

### 问题分析

#### 第一步：暴力做法为什么不行？

最直接的想法是三重循环：枚举 A[i]、B[j]、C[k]，检查 A[i] + B[j] + C[k] = X。

但 L, N, M 最大都是 500，三重循环就是 500 × 500 × 500 = 1.25 亿次。再加上 S 最多 1000 个查询，总运算量将达到天文数字。

#### 第二步：优化思路——"两数之和 + 二分"

我们可以换个思路：
1. 先计算 A 和 B 的所有两数之和，得到一个数组 sumAB
2. 对于每个 X 和每个 C[k]，检查是否存在 A+B 的组合等于 X - C[k]

这样就把三重循环拆分成了：
- 一次双层循环（L × N = 25 万）来预处理
- S 次单层循环（M = 500）来查询，每次查询用二分查找（log(25万) ≈ 18）

总运算量约 25 万 + 1000 × 500 × 18 ≈ 34 万，远低于 1.25 亿。

#### 第三步：具体步骤

1. 预处理：遍历所有 A[i] + B[j]，将结果加入 sumAB 数组
2. 排序并去重 sumAB（去重是可选的，但可以减少二分查找的范围）
3. 对于每个 X，遍历 C[k]：
   - 计算 target = X - C[k]
   - 在 sumAB 中二分查找 target
   - 如果找到，则输出 YES

#### 第四步：模拟样例

A=[1,2,3], B=[1,2,3], C=[1,2,3]

预处理 A+B：
1+1=2, 1+2=3, 1+3=4, 2+1=3, 2+2=4, 2+3=5, 3+1=4, 3+2=5, 3+3=6
sumAB = [2,3,3,4,4,4,5,5,6] → 排序去重后 [2,3,4,5,6]

查询 X=1：遍历 C
- C[0]=1, target=0, 不在 sumAB ❌
- C[1]=2, target=-1, 不在 ❌
- C[2]=3, target=-2, 不在 ❌
→ 输出 NO

查询 X=4：
- C[0]=1, target=3, 在 sumAB 中 ✓ → 输出 YES

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

void solve(int L, int N, int M, int caseNum) {
    vector<int> A(L), B(N), C(M);
    for (int &x : A) cin >> x;
    for (int &x : B) cin >> x;
    for (int &x : C) cin >> x;

    // 1. 预处理 A+B 的所有组合
    vector<int> sumAB;
    sumAB.reserve(L * N);
    for (int i = 0; i < L; ++i) {
        for (int j = 0; j < N; ++j) {
            sumAB.push_back(A[i] + B[j]);
        }
    }

    // 2. 排序以便二分查找
    sort(sumAB.begin(), sumAB.end());
    sumAB.erase(unique(sumAB.begin(), sumAB.end()), sumAB.end());

    int S;
    cin >> S;
    cout << "Case " << caseNum << ":" << endl;

    while (S--) {
        int X;
        cin >> X;
        bool found = false;

        // 3. 遍历 C，二分找 X - C[k]
        for (int k = 0; k < M; ++k) {
            int target = X - C[k];
            if (binary_search(sumAB.begin(), sumAB.end(), target)) {
                found = true;
                break;
            }
        }

        if (found) cout << "YES" << endl;
        else cout << "NO" << endl;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int L, N, M, caseNum = 1;
    while (cin >> L >> N >> M) {
        solve(L, N, M, caseNum++);
    }
    return 0;
}
```

## 4. 中位数

> [!abstract] Contest Problem
> **Description**
> 给定 $N$ 个数字 $X_1, X_2, \dots, X_n$，计算每对数字的差值：$|X_i - X_j|$（$1 \le i < j \le N$）。我们可以得到 $C(N,2)$ 个差值。现在你的任务是以最快的速度找出这些差值的中位数！
> 
> 注意：本题中，中位数定义为第 $m/2$ 小的数字（如果 $m$ 是偶数）。例如，当 $m = 6$ 时，你需要找第 3 小的差值。
> 
> **Input**
> 输入包含多个测试用例。每个测试用例的第一行是 $N$。接下来是 $N$ 个数字，表示 $X_1, X_2, \dots, X_n$（$X_i \le 1\,000\,000\,000$，$3 \le N \le 100\,000$）。
> 
> **Output**
> 对于每个测试用例，输出一行中位数。
> 
> **Sample Input 1**
> ```text
> 4
> 1 3 2 4
> 3
> 1 10 2
> ```
> 
> **Sample Output 1**
> ```text
> 1
> 8
> ```

### 问题分析

#### 第一步：理解问题

给定 N 个数，每两个数之间计算差值的绝对值，总共可以得到 C(N,2) 个差值。

题目定义中位数为第 m/2 小的数（m 为偶数时）。例如 N=4 时有 6 个差值，那么要找第 3 小的差值。

#### 第二步：为什么用二分答案？

差值的中位数具有**单调性**：
- 假设我们猜中位数为 mid
- 如果差值 ≤ mid 的对数 ≥ 目标排名（即第 m/2 个），说明 mid 够大了，可能中位数 ≤ mid
- 如果差值 ≤ mid 的对数 < 目标排名，说明 mid 太小了，中位数一定 > mid

这个单调性使我们可以通过二分搜索来逼近真实的中位数。

#### 第三步：如何统计差值 ≤ mid 的对数？

直接两两枚举差值是 O(N²)，N 最大 10 万，会超时。

技巧：先对数组排序。排序后，如果固定一个位置 i，我们可以用双指针找到最大的 j，使得 a[j] - a[i] ≤ mid。那么所有 a[i+1] 到 a[j-1] 与 a[i] 的差值都 ≤ mid，共 (j - i - 1) 对。

| i=0 | i=1 | i=2 | ... |
|:---:|:---:|:---:|:---:|
| a[i] 与 a[i+1..j-1] 的差值 ≤ mid | ... | ... | ... |

指针 j 只需要一直向右移动（因为数组已排序），所以总复杂度是 O(N) 而不是 O(N²)。

#### 第四步：模拟样例

`[1, 3, 2, 4]`，排序后为 `[1, 2, 3, 4]`。

总对数 m = C(4,2) = 6，目标排名 = 6/2 = 3（第 3 小的数）。

尝试 mid = 1：
| i | a[i] | j 的增长过程 | j 最终 | 对数 |
|:-:|:-:|---|---|:-:|
| 0 | 1 | a[0]=0≤1→j=1; a[1]=1≤1→j=2; a[2]=2>1 停 | 2 | 2-0-1=1 |
| 1 | 2 | a[2]=1≤1→j=3; a[3]=2>1 停 | 3 | 3-1-1=1 |
| 2 | 3 | a[3]=1≤1→j=4（越界） | 4 | 4-2-1=1 |
| 3 | 4 | — | 4 | 4-3-1=0 |

总对数 = 3，已达到目标排名 3，mid=1 可行。

尝试 mid = 0：
| i | a[i] | j 的增长过程 | j 最终 | 对数 |
|:-:|:-:|---|---|:-:|
| 0 | 1 | a[1]=1>0 停 | 1 | 1-0-1=0 |
| 1 | 2 | 同上 | — | 0 |
| 2 | 3 | — | — | 0 |

总对数 = 0 < 3，mid=0 不可行。因此答案是 1。✅

### 代码实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

typedef long long ll;

// 核心函数：统计数组中差值 <= mid 的对数
ll countPairs(const vector<int>& a, int n, int mid) {
    ll count = 0;
    // 使用双指针：对于每个 i，找到最大的 j 使得 a[j] - a[i] <= mid
    for (int i = 0, j = 0; i < n; ++i) {
        while (j < n && a[j] - a[i] <= mid) {
            j++;
        }
        // 此时 a[i+1...j-1] 与 a[i] 的差都 <= mid
        // 数量就是 j - i - 1
        count += (j - i - 1);
    }
    return count;
}

int main() {
    int n;
    while (cin >> n) {
        vector<int> a(n);
        for (int i = 0; i < n; ++i) cin >> a[i];

        sort(a.begin(), a.end()); // 排序是所有操作的基础

        ll m = (ll)n * (n - 1) / 2; // 总对数
        ll target = (m + 1) / 2;    // 题目要求的中位数排名（第几小）
        if (m % 2 == 0) target = m / 2; // 根据题目特殊定义：m为偶数取第m/2个

        // 在差值的可能范围 [0, 最大差值] 内进行二分
        int left = 0, right = a[n - 1] - a[0], ans = 0;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (countPairs(a, n, mid) >= target) {
                ans = mid;         // 这个差值够大，尝试更小的
                right = mid - 1;
            } else {
                left = mid + 1;    // 差值太小，对数不够
            }
        }
        cout << ans << endl;
    }
    return 0;
}
```
