# CS336 Lecture 14: 预训练数据清洗、质量过滤与 MinHash 去重

互联网原始爬虫数据中充满大量 SEO 垃圾站、机器翻译博彩、版权免责声明、重复模板与毒性内容。将原始 Common Crawl 清洗为可用于预训练的高质量语料，通常需要经过**百倍级别的体积缩减过滤 Pipeline**。

---

## 1. 工业级数据清洗流水线 (Data Pipeline)

```
[ Common Crawl 原始 WET 文本 (100%) ]
                 |
                 v
[ 步骤 1: 基础格式标准化与清洗 (Encoding / Normalization) ]
                 |
                 v
[ 步骤 2: 语种识别过滤 (Language ID / FastText) ] ---> 丢弃置信度 < 0.65 或非目标语种
                 |
                 v
[ 步骤 3: 启发式规则过滤 (Heuristic Quality Filters) ] ---> 剔除词长异常/标点过载/SEO垃圾
                 |
                 v
[ 步骤 4: 文本质量分类器 (ML Quality Classifier) ] ---> 基于 FastText / 小模型评分筛选
                 |
                 v
[ 步骤 5: 文档与段落级去重 (Deduplication) ]
  ├── 精确去重 (Exact Hash / 13-gram)
  └── 模糊去重 (MinHash + LSH, Jaccard >= 0.8)
                 |
                 v
[ 步骤 6: 领域数据配比与混合 (Data Mixing) ] ---> (最终产出 ~1% - 3% 黄金预训练语料)
```

## 2. 启发式质量过滤规则 (Heuristic Filters)

DeepMind (Gopher) 与 Google (C4) 总结了一套被全行业通用的经典启发式过滤指标：

### 2.1 统计学词频与长度规则
- **词数范围约束**：单篇文档词数必须在 **$50 \sim 100,000$ 词** 之间（过短多为导航栏，过长多为日志/字典）。
- **平均词长约束**：词语平均字符长度必须在 **$3 \sim 10$ 个字符** 之间（剔除 base64 乱码或无空格串）。
- **停用词过滤 (Stop Words)**：英文文档必须包含至少 **2 个高频常见停用词**（如 *the, and, that, with*），否则判定为关键词堆砌（SEO 假文本）。
- **符号与标点比例**：
  - 符号与词数比（Symbol-to-Word Ratio）$< 0.1$；
  - 省略号结尾行比例 $< 0.3$；
  - 大写字母比例 $< 0.4$（剔除全大写垃圾广告）。

### 2.2 毒性与模板剔除
- **敏感词黑名单 (Bad-word List)**：匹配过滤成人、色情、暴恐与黑灰产词汇；
- **通用模板去除**：剔除 Cookie 提示（"Accept all cookies"）、免责声明、页脚版权行。

## 3. 文本去重算法：精确去重与 MinHash LSH 模糊去重

如果语料中存在大量重复文本，模型会严重过拟合重复内容，且**重复数据浪费大量宝贵的训练 FLOPs**。

### 3.1 精确去重 (Exact Deduplication)
- 对每篇文档（或连续 13 个词的 $N$-gram）计算 64-bit 散列值（如 SHA-256 或 xxHash）；
- 利用 Bloom Filter 或 Hash Set 将全局重复出现的文档直接丢弃。

### 3.2 模糊去重：MinHash + 局部敏感哈希 (LSH)
两篇文档可能仅相差一两个标点或年份，无法被精确 Hash 识别。**MinHash LSH** 能够在 $O(N)$ 时间内识别海量文档对的 Jaccard 相似度。

#### 1. Jaccard 相似度与 $k$-Shingle
将文档 $A$ 拆解为 $k$ 连续词构成的集合（$k$-Shingles）：
$$
J(A, B) = \frac{|A \cap B|}{|A \cup B|}
$$

#### 2. MinHash 定理
设 $h$ 为均匀随机哈希函数，定义 $\min h(A) = \min_{s \in A} h(s)$：
$$
P(\min h(A) = \min h(B)) = J(A, B)
$$
使用 $m$ 个独立哈希函数（如 $m = 128$），计算出文档的签名向量 $V_A = [\min h_1(A), \dots, \min h_m(A)]$。

#### 3. 分桶检索 (Band Partitioning)
将 $m$ 个哈希值切分为 **$b$ 个波段（Bands）**，每个波段包含 **$r$ 个哈希值**（$m = b \times r$）：
- 只要两篇文档在**任意一个 Band 内的 $r$ 个哈希值完全相同**，该文档对即被送入候选池进行精确校验。
- 相似度为 $s = J(A, B)$ 的两篇文档成为候选对的概率为：
  $$
  P(\text{Candidate Pair}) = 1 - (1 - s^r)^b
  $$

```
成为候选对的概率 P ^
                   |                           /---------- (s > 0.8 时 P 接近 1.0)
                   |                          /
                   |                         /  S 曲线 (S-Curve)
                   |                        /
                   |           ------------/ (s < 0.5 时 P 接近 0.0)
                   +-------------------------------------------------------->
                   0                       0.8                             1.0
                                                Jaccard 相似度 s
```

- **参数选择 (如 $b = 16, r = 8$)**：形成极陡峭的 S 曲线，在 $s \ge 0.8$ 时候选检出率 $>99\%$，而在低相似度时极少触发比较，将 $O(N^2)$ 全局两两比对降低至接近线性复杂度。

## 4. 数据配比 (Data Mixing) 与高质量合成数据

### 4.1 数据配比技术 (Data Mixing)
不同来源数据（代码、百科、数学、通用网页）的混合比例极大影响最终模型能力：
- **DoReMi / RegMix**：使用小模型在少量目标高质量数据（如 GSM8K、HumanEval、MMLU）上做参考，通过梯度下降或回归模型反向搜索出**使基准 Loss 下降最快的最佳语料配比权重**。

### 4.2 高质量合成数据 (Synthetic Data)
前沿模型（Llama 3, Phi-4, Qwen 2.5）大量使用强模型合成的训练数据：
1. **网络弱文本重写 (Web Rewriting)**：将抓取的口语化网页由大模型重写为教科书风格（Textbook Quality）；
2. **多步骤推理构造**：生成成套的数学解题思路、代码单元测试与长思维链合成数据，显著提升模型的推理与泛化能力。
