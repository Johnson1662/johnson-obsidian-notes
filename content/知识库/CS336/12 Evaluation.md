# CS336 Lecture 12: 大模型评测体系、基准测试与数据污染检测

评测（Evaluation）是驱动大模型迭代的罗盘。评测分为两大维度：**内部评测（Internal Evaluation）** 用于指导训练收敛与 Scaling 规律；**外部评测（External Evaluation）** 用于度量真实下游应用能力。

---

## 1. 语言模型基础度量：困惑度 (Perplexity, PPL)

### 1.1 数学定义与物理含义
对于长度为 $T$ 的测试序列 $x_{1:T}$，自回归语言模型的困惑度定义为测试集交叉熵损失的指数形式：

$$
\text{PPL}(x_{1:T}) = \exp\left( -\frac{1}{T} \sum_{t=1}^T \log P(x_t \mid x_{<t}) \right) = \exp(\bar{L})
$$

- **直观理解**：在每个预测步骤，模型在几何平均意义上相当于在 $\text{PPL}$ 个等概率候选分支中做选择。$\text{PPL}$ 越低，模型预测越自信准确。

### 1.2 困惑度的分词器偏差陷阱与 BPB 归一化
如果两个模型采用了不同的分词器（Tokenizer），**直接对比 PPL 是完全错误且无效的**：
- 分词器 A（大词表）将一句英文切成 10 个 Token；分词器 B（小词表）切成 30 个 Token；
- 即使模型理解能力完全相同，分词器 A 的每个 Token 承载了更多信息量，其单 Token 交叉熵损失必然偏高，导致 PPL 虚高。

#### 解决方案：按字节归一化 (Bits Per Byte, BPB)
计算模型编码每个 UTF-8 原始字节平均所需的比特数（完全独立于分词器实现）：
$$
\text{BPB} = \frac{\text{Total Cross-Entropy Loss (in nats)} \times \frac{1}{\ln 2}}{\text{Total UTF-8 Bytes of Test Text}}
$$
- 只有基于 BPB 或在**完全相同的固定分词器**下，PPL 对比才具备严密科学性。

## 2. 核心 Benchmark 评测体系全景

现代大模型通过多维度的标准测试集进行综合能力画像：

| 能力维度 | 代表性 Benchmark | 评测形式 | 局限性与现状 |
|---|---|---|---|
| **综合学科知识** | **MMLU / MMLU-Pro** (57 个学科选择题) | 多选题 (0-shot / 5-shot) | 头部模型已超 $90\%$，选项易受选项顺序偏置影响 |
| **基础数学推理** | **GSM8K** (小学应用题) | 链式思考 (CoT) + 答案正则匹配 | 题目过于简单，已被前沿模型基本刷满 ($>95\%$) |
| **高阶数学与竞赛** | **MATH / AIME 2024 / OlympiadBench** | 复杂符号推导 + LaTeX 最终结果比对 | 考验长思维链推理 (RLVR / DeepSeek-R1 主战场) |
| **代码生成** | **HumanEval / MBPP** | Python 函数生成 + Unit Tests 自动判题 | 单元函数测试过于简单，存在严重测试集过拟合 |
| **真实软件工程** | **SWE-bench (Verified / Lite)** | 基于 GitHub 真实 Issue 的端到端代码修复与 Git Patch 验证 | 衡量 Agent 级代码调用与长流程调试的核心黄金标准 |
| **真实人类偏好** | **LMSYS Chatbot Arena** | 盲测众包对战，通过 Bradley-Terry 计算 Elo 动态天梯分 | 最贴近真实用户体感，但评测长文本推理与专业事实较吃力 |

## 3. 评测脆弱性与工程偏置 (Evaluation Fragility)

在实际评测中，评测结果往往对细微的格式变化极度敏感：
1. **Prompt 格式敏感性**：冒号后有无空格、Few-shot 示例的顺序与换行符变化，可能导致同一模型在 MMLU 上的分数波动高达 $5\% \sim 10\%$。
2. **多选题选项顺序偏置 (Choice Bias)**：大模型天然对选项位置存在偏好（如显著更倾向于选择选项 A 或 C）。
   - **防御手段**：必须采用**循环排列置换（Permutation Testing）**，将每个题目的选项顺时针旋转打分并取平均。

## 4. 数据污染检测 (Data Contamination Detection)

若预训练语料中无意（或有意）包含了测试集题目与答案，会导致基准测试虚高，严重误导研发判断。

```
[ 待测测试集样本 ]  ---+
                       |---> [ N-gram / MinHash 快速比对 ] ---> 筛出重合度 > 80% 的潜在污染样本
[ 预训练海量语料库 ] ---+                                              |
                                                                       v
                                                 [ 困惑度骤降突变检验 (PPL Divergence) ]
                                                 - 若测试集 PPL 显著反常低于同分布非公开数据
                                                 - 判定为已污染 (Contaminated)
```

### 4.1 $N$-gram 重合度过滤
提取测试集的连续 8-gram 或 13-gram 词组，在预训练语料的 Bloom Filter 或反向索引中检索匹配。若单篇文本匹配到的 $N$-gram 覆盖率超过阈值（如 $70\%$），标记为污染。

### 4.2 困惑度异常突变检验 (Perplexity Divergence Test)
对比模型在两组数据上的表现：
- 组 1：发布于预训练截止日期之前的公开展览测试题；
- 组 2：完全私密封闭、未公开上线的最新衍生同难度题目；
- 若模型在公开测试集上的 PPL 显著断崖式低于私密测试集（例如准确率差距 $>20\%$），可确定模型权重中记住了测试集原题。
