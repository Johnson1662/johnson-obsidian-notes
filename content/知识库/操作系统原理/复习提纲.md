### 第3章：进程管理（占50%权重，最大板块）

**一、进程基本概念（选择题）**
1. **进程的三个基本状态**：就绪（Ready）、运行（Running）、阻塞/等待（Blocked/Wait）。
2. **三个状态间的四个箭头转换关系**：
   - 就绪→运行（调度程序选中）
   - 运行→就绪（时间片到/被抢占）
   - 运行→等待（请求I/O或事件）
   - 等待→就绪（I/O完成或事件发生）
3. **为什么没有另外两个箭头**（如等待→运行、就绪→等待）。必须理解原因（例如：等待态进程缺少资源，即使CPU空闲也无法运行，必须等待资源就绪后转为就绪态，再由调度器分配CPU）。

**二、线程管理（选择题）**
1. **用户级线程 vs 内核级线程**的实现方式。
2. 两种方案的**优缺点**

**三、调度（Scheduling）——选择题+大题考点**
1. **三种调度类型**（长期/高级调度（作业调度）、中期/中级调度（内存交换调度）、短期/低级调度（进程/CPU调度））的区别与对象。
2. **计算大题①：作业/进程调度算法**（核心计算题）
   - 必记英文缩写：**FCFS**（先来先服务）、**SJF**（短作业优先）、**SRT**（最短剩余时间优先）、**HRRN**（最高响应比优先）。
   - 涉及概念：**周转时间、等待时间、执行时间、带权周转时间**等。
   - 考题形式：给出多个作业/进程，要求分别计算不同算法下的平均周转时间/等待时间。
   - **关键提醒**：大题必须写步骤（如计算响应比必须写出比值并比较），不写步骤会扣分。
3. **轮转法（RR）和多级反馈队列**作为了解（可能小题）。


### 第6章（按内容逻辑应为“同步与互斥”）（必有一道大题）

**一、基本概念（选择题）**
- **竞争条件（Race Condition）**、**临界资源**、**临界区（Critical Section）**。
- 临界区**本质是一段代码**（不是内存区/磁盘区），会以选择题考查定义。

**二、同步的硬件/软件解决方案（选择题）**
- 了解 `TestAndSet`（或 `Exchange` 指令）实现原子操作（自旋锁基础）。

**三、信号量（Semaphore）与PV操作（超级重点！选择+大题）**
1. **PV原语定义**：P（申请/等待）、V（释放/唤醒）。
2. **信号量分类**：
   - **记录型信号量**（默认！考试语境下默认此类型）：含整数值 + 等待队列。正数代表可用资源数，**负数代表有进程等待，其绝对值为等待进程个数**。
   - **计数型信号量**（忙等版）：仅有整数值，无等待队列。
3. **核心规则**：信号量除定义初始化外，**绝不可出现在PV操作之外**（不能写 `if(S)` 或 `S=S+1`）。
4. **计算小题示例**（信号量值含义）：如初值为3，现值为-5，问等待进程数 → 答案：**5个**（负数绝对值，不需加初值）。
5. **计算大题②：经典同步问题（必背！）**
   - **生产者-消费者问题**：**必须全文背诵**，所有PV题基础。
   - **读者-写者问题**：**必须背诵“读者优先”** 写法；“写者优先”和“公平竞争”可了解。
   - 复习资料：课件例题 + 作业题（全是变形）。


### 死锁（Deadlock）（选择+大题）

**一、死锁的四个必要条件（选择题）**
- **互斥使用**、**不可抢占**、**持有并等待**（部分拥有且期望更多）、**循环等待**。需能辨识哪个不是。

**二、银行家算法（Banker's Algorithm）（计算大题③）**
1. 核心数据结构：已分配矩阵、可用资源数、**仍需资源数（Max - Allocation）**。
2. **易错陷阱**：出题可能不给“仍需”而给“最大需求”，需用 **“最大需求 - 已分配”** 求仍需；不给“可用”而给“总数”，需用 **“总数 - 已分配总数”** 求可用。
3. 算法逻辑简单（10以内加减法），但数据多易写乱，需细心。


### 内存管理（Memory Management）（占1/4~1/3权重）

**一、基础概念（选择题）**
- **逻辑地址/物理地址**、**重定位**（地址转换）。
- **Cache** 基本不考（老师明确划掉）。

**二、分区管理（Partition）（选择题/小题计算）**
1. **固定分区** → 产生**内碎片**。
2. **可变分区** → 产生**外碎片**。
3. **分区分配算法**（首次适应、最佳适应、最坏适应、下次适应）的小型计算题。

**三、分页（Paging）（绝对核心！大题+小题）**
1. **逻辑地址转物理地址**：页号 = 地址 >> N，页内偏移 = 地址 & (2^N - 1)，查页表得页框号，拼接。
2. **页表大小计算**（极易出大题）：
   - 页表项个数 = 逻辑地址空间大小 / 页面大小。
   - 页表大小 = 页表项个数 × 每个页表项大小（如4字节）。
   - **进阶坑点**：**页表占几页？** = 页表大小 / 页面大小（页表也占用内存空间）。
3. **多级页表**：课件中的特定例题（如1KB页面大小的十六进制拆分）非常关键，必做。

**四、分段（Segmentation）（小题）**
- 给定段表，检查段号是否越界、段内偏移是否越界，计算物理地址 = 段基址 + 偏移。

**五、页面置换算法（Page Replacement）（计算大题④）**
- 核心算法：**OPT（最优）**、**FIFO（先进先出）**、**LRU（最近最久未使用）**。
- 必须会画置换图并计算缺页次数/缺页率。

**六、内存管理综合题（大计算⑤）**
- 结合快表（TLB）、页表、缺页中断处理时间等，给定虚地址序列求访问时间（课件中的典型期末考题，必做）。


### 文件系统（File System）

**一、基本概念（选择题）**
- **Inode（索引节点）**：一个文件对应一个Inode；但多个文件名（目录项）可指向同一个Inode（硬链接原理）。
- **软链接（符号链接）** vs **硬链接**的区别。

**二、多级索引（Mixed / Multi-level Indexing）（计算大题⑥）**
- **绝对必考**（因为与实验6对应、课件例题、作业均有）。
- 计算：直接块、一级间接块、二级间接块、三级间接块分别能支持的最大文件大小，或访问特定偏移所需读盘次数。


### 大容量存储（磁盘）与I/O系统

**一、磁盘调度（Disk Scheduling）（计算大题⑦）**
1. **磁盘读写时间三部分**：**寻道时间** + **旋转延迟时间** + **传输时间**。
2. **旋转延迟计算**：若转速 6000 r/min → 100 r/s → 一圈10ms → **半圈5ms**（固定）。
3. **调度算法**：FCFS、SSTF（最短寻道时间优先）、**SCAN（电梯算法）**、LOOK、C-SCAN、C-LOOK。
4. **特别规定（考试必看！）**：本次期末考试严格规定——
   - **SCAN = 两边都到头**（未优化）。
   - **LOOK = 两边不到头**（优化版）。
   - （注意：教材/考研有歧义，以此规定为准）

**二、I/O系统（选择题，非重点）**
- 中断、DMA（直接存储器访问）、单缓冲/双缓冲等概念，了解即可（无大题）。
