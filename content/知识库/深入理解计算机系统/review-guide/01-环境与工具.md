## 1. 本章概述

本章介绍计算机系统基础课程所需的开发环境和基本工具，重点包括 Linux 常用文件操作命令和 GCC 编译器的使用。掌握这些工具是后续学习程序的机器级表示、链接、存储器层次结构等章节的基础。

## 2. 知识点讲解

### 2.1 Linux 文件与目录操作命令

#### 2.1.1 mkdir — 创建目录

**通俗定义**：`mkdir` 命令用于创建一个新的目录（文件夹）。如果目标目录的上级目录不存在，默认会报错，需要加上 `-p` 参数才能自动创建完整的目录路径。

**标准格式**：

```bash
mkdir [-p] <目录路径>
```

- `-p`（parents）：递归创建目录，如果上级目录不存在则自动创建。

**举例**：

```bash
# 当前目录下创建 mylab 目录
mkdir mylab

# 创建多级目录（假设 dir1 不存在）
mkdir -p dir1/mylab
```

**初学易错点**：
- 忘记 `-p` 参数：如果要在不存在的父目录下创建子目录，不加 `-p` 会报错 `No such file or directory`。
- 目录名含有空格时未加引号：目录名中有空格应使用引号包裹或使用反斜杠转义。

#### 2.1.2 cp — 复制文件或目录

**通俗定义**：`cp` 命令用于将文件或目录从源位置复制到目标位置。复制目录时需要加 `-r`（recursive）参数。

**标准格式**：

```bash
cp [选项] <源路径> <目标路径>
```

- `-r`（recursive）：递归复制，复制目录时必选。
- `-i`（interactive）：覆盖前提示确认。

**举例**：

```bash
# 复制文件 main.c 到 mylab 目录下
cp main.c mylab/

# 复制整个目录 src 到 dst
cp -r src/ dst/
```

**初学易错点**：
- 复制目录时忘记加 `-r`，会报错 `omitting directory`。
- 目标路径写成了不存在的目录，会报错 `No such file or directory`（此时需要先 `mkdir`）。
- `cp` 默认会覆盖目标文件而不提示，加 `-i` 可启用确认。

#### 2.1.3 命令组合：先创建目录再复制文件

在实际操作中，如果目标目录不存在，需要先创建目录，再复制文件：

```bash
mkdir mylab        # 先创建目录
cp main.c mylab/   # 再复制文件
```

或者使用一步到位的方式（先 `mkdir` 再 `cp`）：

```bash
mkdir mylab && cp main.c mylab/
```

其中 `&&` 表示前一条命令执行成功后再执行后一条命令。

### 2.2 GCC 编译器

#### 2.2.1 GCC 概述

**通俗定义**：GCC（GNU Compiler Collection）是 GNU 项目开发的编译器套件，能将 C/C++ 等高级语言源代码转换为可执行程序。GCC 的编译过程分为四个阶段：**预处理 → 编译 → 汇编 → 链接**。

#### 2.2.2 GCC 编译流程四阶段

| 阶段 | 功能 | 对应命令选项 | 输出文件类型 |
|------|------|-------------|-------------|
| 预处理（Preprocessing） | 展开宏、处理头文件包含、删除注释 | `gcc -E` | `.i`（预处理后的源码） |
| 编译（Compilation） | 将 C 代码翻译为汇编代码 | `gcc -S` | `.s`（汇编代码） |
| 汇编（Assembly） | 将汇编代码翻译为机器指令（目标文件） | `gcc -c` | `.o`（可重定位目标文件） |
| 链接（Linking） | 将多个目标文件和库合并为可执行文件 | （无特别选项，直接 `gcc`） | 可执行文件（默认 `a.out`） |

**流程图**：

```
源代码 (.c)  ──[预处理 -E]──>  预处理后源码 (.i)
    ──[编译 -S]──>  汇编代码 (.s)
    ──[汇编 -c]──>  目标文件 (.o)
    ──[链接]──>  可执行文件
```

#### 2.2.3 常用选项速查

| 选项 | 作用 |
|------|------|
| `-E` | 只进行预处理，不编译 |
| `-S` | 编译到汇编代码，不汇编 |
| `-c` | 编译并汇编到目标文件，不链接 |
| `-o <文件>` | 指定输出文件名 |
| `-g` | 生成调试信息（供 GDB 使用） |
| `-O0/-O1/-O2/-O3` | 优化级别 |
| `-Wall` | 显示所有警告信息 |
| `-I<目录>` | 添加头文件搜索路径 |
| `-L<目录>` | 添加库文件搜索路径 |
| `-l<库名>` | 链接指定的库 |

#### 2.2.4 常见混淆点与易错点

1. **`-c` vs `-S` 的区别**：
   - `-c`：**编译并汇编**，生成 `.o` 目标文件（机器码，不可读）。
   - `-S`：**仅编译到汇编**，生成 `.s` 汇编代码文件（文本，可读）。
   - 初学者容易混淆，记住：**S 代表 assembly（汇编代码文本），c 代表 compile（生成目标文件）**。

2. **`-o` 指定输出文件名**：
   - `gcc -o sum.c sum` 这样的写法**错误**！`-o` 后面跟的是**输出文件名**，不是源文件。
   - 正确用法：`gcc sum.c -o sum` 或 `gcc -o sum sum.c`。

3. **选项大小写敏感**：
   - `-S`（大写）是生成汇编代码。
   - `-s`（小写）是 strip 符号表，功能完全不同。
   - `-E`（大写）是预处理，`-e`（小写）不存在。

4. **扩展名的重要性**：
   - GCC 根据文件扩展名判断语言类型：`.c` 为 C 语言，`.C`（大写）或 `.cpp` 为 C++ 语言。
   - 如果误将 `sum.c` 写成 `sum.C`（大写），GCC 会按 C++ 编译，可能导致链接错误。

## 3. 典型例题

### 例题 1（来源：[Q0004]）

**题目**：

现有 C 语言源代码文件 sum.c，下面哪一条命令可以将 sum.c 编译为**汇编代码**？

A. `gcc -c sum.c`

B. `gcc -o sum.c`

C. `gcc -S sum.c`

D. `gcc -E sum.C`

---

**解答**：

**第一步**：理解题目要求。题目要求将 C 源代码编译为**汇编代码**，也就是生成 `.s` 文件，而不是目标文件或可执行文件。

**第二步**：逐项分析各选项：

- **选项 A** `gcc -c sum.c`：`-c` 选项的作用是编译并汇编，生成目标文件（`.o`）。目标文件中已经是机器码（二进制），而不是可读的汇编代码。**不符合题目要求。**

- **选项 B** `gcc -o sum.c`：`-o` 用于指定输出文件名，但这里 `-o` 后面跟的 `sum.c` 会被当作输出文件名，而源文件呢？命令中缺少源文件参数（即使源文件名为 sum.c，这样写也会导致混淆甚至报错）。此外，这也不是生成汇编代码的选项。**错误选项。**

- **选项 C** `gcc -S sum.c`：`-S` 选项的作用是只进行编译（将 C 代码翻译为汇编代码），在汇编阶段之前停止，输出扩展名为 `.s` 的汇编代码文件。这正是题目要求的功能。**符合题意。**

- **选项 D** `gcc -E sum.C`：`-E` 只进行预处理，不编译。而且 `sum.C`（大写 C）表示 C++ 源文件，与题目中的 `sum.c`（小写 c）不同。**不符合要求。**

**第三步**：得出结论，正确答案为 **C**。

---

**解析**：

本题考察 GCC 编译流程中各个选项的含义。关键在于区分 GCC 四个阶段的对应选项：

- 预处理 → `-E`
- 编译到汇编 → **`-S`**
- 汇编到目标文件 → `-c`
- 链接 → 无特别选项

记忆技巧：**S 代表 "assembly"**（汇编代码的英文是 assembly，包含字母 S，`-S` 生成 `.s` 文件）。此外要留意选项 D 中的陷阱——`sum.C` 大写 C 表示 C++ 文件，与题目中的 `sum.c` 不同。

### 例题 2（来源：[Q0029]）

**题目**：

`/home/user` 目录下存在一个文件 main.c，需要将 main.c 文件复制到 `/home/user/mylab` 目录下（该目录当前不存在），应该执行哪些命令才能完成上述工作（当前工作目录为 `/home/user`）。

---

**解答**：

**第一步**：分析已知条件。
- 当前工作目录：`/home/user`
- 源文件位置：`/home/user/main.c`（在当前目录下，可直接用 `main.c` 引用）
- 目标目录：`/home/user/mylab`（**该目录当前不存在**）
- 操作目标：将文件复制到目标目录下

**第二步**：确定操作流程。由于目标目录 `mylab` 不存在，不能直接将文件复制进去。需要**先创建目录，再复制文件**。

**第三步**：执行创建目录命令。

```bash
mkdir /home/user/mylab
```

或者，由于当前目录已经是 `/home/user`，可以使用相对路径：

```bash
mkdir mylab
```

**第四步**：执行复制文件命令。

```bash
cp /home/user/main.c /home/user/mylab/
```

或者使用相对路径：

```bash
cp main.c mylab/
```

**最终答案**：

```bash
mkdir /home/user/mylab
cp /home/user/main.c /home/user/mylab/
```

或简写为：

```bash
mkdir mylab
cp main.c mylab/
```

---

**解析**：

本题的核心考点有两个：一是 `mkdir` 创建目录，二是 `cp` 复制文件。最容易出错的地方是**忘记目标目录尚不存在**，直接执行 `cp main.c mylab/` 会收到如下错误：

```
cp: cannot create regular file 'mylab/main.c': No such file or directory
```

因为 `cp` 命令不会自动创建目标目录，需要先用 `mkdir` 创建。另外注意，如果目标目录存在且末尾有 `/`，表示将文件复制到该目录下（保持原名）；如果没有 `/` 且目标目录存在，效果相同。但对于本题来说，由于目录不存在，必须先创建。

## 4. 自测题

### 自测题 1

**题目**：请简述 GCC 编译的四个阶段及其对应的命令行选项。

> [!question]- 点击查看完整解答
> GCC 编译分为四个阶段：
>
> 1. **预处理**（Preprocessing）：展开宏定义、处理 `#include` 头文件包含、删除注释等。选项：`gcc -E`，生成 `.i` 文件。
>
> 2. **编译**（Compilation）：将 C 代码翻译为汇编代码。选项：`gcc -S`，生成 `.s` 文件。
>
> 3. **汇编**（Assembly）：将汇编代码翻译为机器指令（目标文件）。选项：`gcc -c`，生成 `.o` 文件。
>
> 4. **链接**（Linking）：将多个目标文件和库合并为可执行文件。无需特别选项，直接 `gcc` 即可，默认生成 `a.out`（可用 `-o` 指定输出文件名）。
>
> **记忆口诀**：预处理展开宏，编译变汇编，汇编成目标，链接出可执行。

### 自测题 2

**题目**：以下命令中，哪些可以正确地将 `hello.c` 编译为名为 `hello` 的可执行文件？（多选）

A. `gcc hello.c -o hello`

B. `gcc -o hello hello.c`

C. `gcc hello.c`

D. `gcc -c hello.c -o hello`

> [!question]- 点击查看完整解答
> **分析**：
>
> - **选项 A** `gcc hello.c -o hello`：✅ 正确。将 `hello.c` 编译链接，输出可执行文件命名为 `hello`。
>
> - **选项 B** `gcc -o hello hello.c`：✅ 正确。与 A 等价，`-o` 选项可以放在源文件前面或后面。
>
> - **选项 C** `gcc hello.c`：✅ 正确。编译链接生成默认的可执行文件 `a.out`（在 Windows 上可能是 `a.exe`）。虽然没有指定 `-o`，但确实得到了可执行文件。
>
> - **选项 D** `gcc -c hello.c -o hello`：❌ 错误。`-c` 只编译到目标文件（`.o`），不会进行链接。虽然输出文件名被指定为 `hello`，但本质上它仍然是一个目标文件（缺少链接步骤），不能直接执行。
>
> **答案**：A、B、C
>
> **注意**：D 选项是常见陷阱——用了 `-c` 就只到汇编阶段生成 `.o` 文件，不会进行链接。即便用 `-o` 改了名字，它也只是一个重命名的目标文件，不是可执行文件。

### 自测题 3

**题目**：假设当前目录是 `/home/student`，该目录下有文件 `data.txt`。请写出将 `data.txt` 复制到 `/home/student/project/backup/` 目录下的命令（假设 `project`、`backup` 等目录都不存在）。

> [!question]- 点击查看完整解答
> **分析**：目标目录的完整路径为 `/home/student/project/backup/`，这是一个嵌套的多级目录结构，且各级目录都不存在。
>
> **方法一**（分步创建，逐级创建）：
>
> ```bash
> mkdir project
> mkdir project/backup
> cp data.txt project/backup/
> ```
>
> **方法二**（使用 `-p` 参数一步到位）：
>
> ```bash
> mkdir -p project/backup
> cp data.txt project/backup/
> ```
>
> 或者用 `&&` 连接：
>
> ```bash
> mkdir -p project/backup && cp data.txt project/backup/
> ```
>
> **关键点**：`mkdir -p` 可以递归创建所有不存在的父目录，避免逐层创建的繁琐。不加 `-p` 时，如果父目录不存在，`mkdir` 会报错。

### 自测题 4

**题目**：执行命令 `gcc -S sum.c -o sum.s` 后，会生成什么文件？该文件的内容是什么形式的？

> [!question]- 点击查看完整解答
> **解答**：
>
> - 生成的**文件名**：`sum.s`（由 `-o sum.s` 指定）
> - 文件的**内容形式**：**汇编代码**（assembly code），即 x86-64 汇编指令的文本形式
>
> **原理**：`-S` 选项让 GCC 在编译阶段完成后就停止，不进行汇编和链接。此时生成的 `.s` 文件包含与 C 源代码对应的汇编指令，是可读的文本文件。
>
> 可以用文本编辑器打开查看，内容类似：
>
> ```assembly
> 	.file	"sum.c"
> 	.text
> 	.globl	main
> 	.type	main, @function
> main:
> 	pushq	%rbp
> 	movq	%rsp, %rbp
> 	...
> ```
>
> 这是后续学习"程序的机器级表示"章节时，需要经常接触的内容形式。

### 自测题 5

**题目**：Linux 中 `cp` 命令和 `mv` 命令有何区别？如果要将一个文件从一个目录移动到另一个目录（目标目录不存在），需要执行哪些命令？

> [!question]- 点击查看完整解答
> **`cp` 与 `mv` 的区别**：
>
> | 命令 | 功能 | 源文件在操作后的状态 |
> |------|------|-------------------|
> | `cp` | 复制——在目标位置创建副本 | 源文件**仍然保留** |
> | `mv` | 移动——将文件从原位置移到目标位置 | 源文件**被删除** |
>
> **移动文件到不存在的目录**（与复制类似，需要先创建目标目录）：
>
> ```bash
> mkdir mylab          # 先创建目标目录
> mv main.c mylab/     # 再将文件移动到目标目录
> ```
>
> 或者一步完成：
>
> ```bash
> mkdir mylab && mv main.c mylab/
> ```
>
> **注意**：`mv` 也不会自动创建目标目录，所以在目标目录不存在时，必须先用 `mkdir` 创建。
