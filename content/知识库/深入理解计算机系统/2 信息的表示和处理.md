# 位运算

![](assets/2%20信息的表示和处理/file-20260507161320777.png)

```C
bool allNibblesGreaterThan9(uint32_t X) {
    // 1. 提取各个权重位
    uint32_t x3 = X & 0x88888888; // 8
    uint32_t x2 = X & 0x44444444; // 4
    uint32_t x1 = X & 0x22222222; // 2

    // 2. 运用公式: f = x3 & (x2 | x1)
    // 我们把所有位都对齐到 x1 的位置（即每个 4 位组的第 2 位）进行运算
    uint32_t match = (x3 >> 2) & ((x2 >> 1) | x1);

    // 3. 检查结果
    // 如果 8 个十六进制位都符合，那么 match 应该是 0x22222222
    return match == 0x22222222;
}
```

# 整数表示

## 补码表示法

在计算机底层，所有的整数（尤其是负数）都是以**补码**的形式存储的。

- **规则**：正数的补码与其原码相同；负数的补码等于其绝对值的原码**取反加 1**。
- **示例**：`char c = -2`。
  - 2 的 8 位原码：`0000 0010`
  - 取反：`1111 1101`
  - 加 1：`1111 1110` (即十六进制 `0xFE`)

## 符号扩展与零扩展

当将窄类型转换为宽类型时，需要填充高位。

- **有符号数（Signed）**：高位全部填充原始数值的**符号位**（即最高位）。
  - 示例：`char -2` (`1111 1110`) 扩展为 16 位 `short` → `1111 1111 1111 1110` (`0xFFFE`)
- **无符号数（Unsigned）**：高位一律补 0。

## 算术移位

- **算术左移**：右边补 0，符号位可能被改变（如 `1 << 31` 得到 `0x80000000`，即 `-2147483648`）。
- **算术右移**：左边空位补**符号位**，而非补 0。
  - 示例：`0x80000000 >> 31` → `0xFFFFFFFF` (即 `-1`)。

## 转换总结

| 转换类型              | 关键机制       | 结果变化         |
| :-------------------- | :------------- | :--------------- |
| **负数存储**          | 补码 (取反加1) | `0xFE`           |
| **窄变宽 (signed)**   | **符号扩展**   | 高位补符号位 (1) |
| **窄变宽 (unsigned)** | **零扩展**     | 高位一律补 0     |
| **左移**              | 低位补 0       | 符号位可能改变   |
| **算术右移**          | 高位补符号位   | `0x80000000` → `-1` |

# 浮点数表示

计算机遵循 **IEEE 754** 标准，类似二进制科学计数法。

## 存储结构（32位单精度）

一个 `float` 分为三部分：

1. **符号位 (S, 1位)**：0 为正，1 为负。
2. **阶码 (E, 8位)**：存储的是实际指数 + 127（Bias）。
3. **尾数 (M, 23位)**：决定精度。规格化数中，小数点前的 `1` 是隐含的（隐藏位），不占空间，故实际精度为 24 位。

## 核心公式

$$V = (-1)^S \times (1.M) \times 2^{E-Bias}$$

## 规格化数与非规格化数

- **规格化数**：阶码 $E$ 不全为 0 且不全为 1。形式为 $1.f \times 2^{E-127}$。
  - 最小正规格化数：$E=1, f=0$，即 $2^{-126}$。
- **非规格化数**：阶码 $E$ 全为 0。形式为 $0.f \times 2^{-126}$，用于平滑处理下溢。
- **特殊值**：阶码 $E$ 全为 1。尾数全 0 表示 $\infty$；尾数非 0 表示 **NaN**。

## 精度与类型转换

- `int` 转 `float` 可能丢精度：`float` 有效位仅 24 位，而 `int` 有效位可达 31 位（超过 $2^{24}$ 的整数无法精确表示）。
- `int` 转 `double` 不会丢精度：`double` 有效位为 53 位，足以容纳 `int` 的全部 31 位。

## 常见数值范围（单精度）

| 描述                  | 阶码 (E)  | 尾数 (f) | 对应数值                     |
| :-------------------- | :-------- | :------- | :--------------------------- |
| **0**                 | 0000 0000 | 全 0     | 0.0                          |
| **最小正规格化数**    | 0000 0001 | 全 0     | $1.0 \times 2^{-126}$        |
| **最大单精度数**      | 1111 1110 | 全 1     | $\approx 3.4 \times 10^{38}$ |
| **无穷大 ($\infty$)** | 1111 1111 | 全 0     | $\infty$                     |

## float 与 double 对比

| 类型       | 总位数 | 符号位 | 阶码位数 | 尾数位数 | 有效精度（含隐藏位） |
| :--------- | :----- | :----- | :------- | :------- | :--------------------- |
| **float**  | 32 位  | 1      | 8        | 23       | **24 位**              |
| **double** | 64 位  | 1      | 11       | 52       | **53 位**              |

## 十进制转 IEEE 754 流程

以 $5.0$ 为例：
1. 转二进制：$5 \rightarrow 101.0$
2. 规格化：$1.01 \times 2^2$
3. 计算存储阶码：$2 + 127 = 129 \rightarrow 10000001$
4. 拼接：`[S] + [E] + [f 补齐0]`

> **注意**：十进制 $0.1$ 无法被二进制精确表示，会成无限循环小数，因此浮点数中 `0.1` 是近似值。
