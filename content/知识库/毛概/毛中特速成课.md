## 一、总时间线与课程结构

### 1.1 中国近现代到新时代

| 时段 | 内容 |
|------|------|
| 1840—1919 | 旧的民主主义革命（戊戌变法、辛亥革命想建立资本主义社会，都失败） |
| 1919 五四运动 | 工人大规模罢工应援学生，**中国工人（无产阶级）登上历史舞台** → 变为**无产阶级领导的新民主主义革命** |
| 1919—1949 | **新民主主义革命** |
| 1949 | 新中国 = **新民主主义社会**（资本主义 + 社会主义成分并存） |
| 1949—1956（约七年） | **社会主义革命**（亦称**社会主义改造**）→ 过渡到社会主义社会 |
| 1956 至今 | **社会主义初级阶段** |
| 1956—1978 | 社会主义建设的**初步探索** |
| 1978 起 | **改革开放** |
| 1978—1989 | **邓小平理论**，提出建设**中国特色社会主义**重大命题 |
| 1989—2002 | **三个代表重要思想** |
| 2002—2012 | **科学发展观** |
| 2012 至今 | **中国特色社会主义进入新时代** → **习近平新时代中国特色社会主义思想**（内容多，单独成科） |

> [!note] 课程命名
> - **1919—1978**：**毛泽东思想**  
> - **1978 之后**：**中国特色社会主义理论体系**（毛中特 = 毛 + 中特，一脉相承又与时俱进）  
> - **2012 之后新思想**：单独学科，理论上仍属中特理论体系中的**新的飞跃**

### 1.2 毛中特八章对应

1. 毛泽东思想  
2. 新民主主义革命理论  
3. 社会主义革命理论（社会主义改造）  
4. 社会主义建设的初步探索理论  
5. 中国特色社会主义理论体系  
6. 邓小平理论  
7. 三个代表重要思想  
8. 科学发展观

## 二、导论：马克思主义中国化

- **命题提出**：毛泽东 **1938 年**党的**六届六中全会**（口诀：马克思主义 **666**）。
- **第一次结合**：马克思主义同**当时的中国革命**相结合 → 完成 → 成果 **毛泽东思想**。
- **第二次结合**：**1956 年**社会主义建设伊始提出，马克思主义同**社会主义建设**相结合 → **显然没有完成**（社会主义建设一直在进行）。

> [!warning] caution：两次结合 ≠ 两个结合
> - **两个结合**（马克思主义中国化时代化内涵）：马克思主义同**中国具体实际**相结合 + 同**中华优秀传统文化**相结合。  
> - **中国化**对应中国，**时代化**对应传统；**魂脉**、**根脉**（课上要求区分，以教材权威表述为准）。

| 对比 | 毛泽东思想 | 中特理论体系 |
|------|-----------|-------------|
| **实践基础** | **革命和建设** | **建设和改革**（**没有革命**） |
| **时代主题** | 革命与战争 / 帝国主义战争和无产阶级革命（表述以教材为准） | **和平与发展** |

## 三、第一章 毛泽东思想

### 3.1 时代主题与实践基础

- **时代主题**：帝国主义战争和无产阶级的革命（战争多）。  
- **实践基础**：**革命和建设**。

### 3.2 发展脉络与统一战线、革命对象（表格重要，课下念逐字稿、给自己讲一遍）

| 时期 | 阶段定位 | 代表著作/成果 | 统一战线 | 革命对象/任务 |
|------|---------|--------------|---------|--------------|
| **国民大革命**（第一次国共合作） | **萌芽** | 《中国社会各阶级的分析》《湖南农民运动考察报告》等；分析农民斗争特点；解决革命**中心问题**——无产阶级**领导权**；提出新民主主义革命**基本思想** | **国民革命联合战线** | **北洋军阀** |
| **1927—1937 土地革命**（十年内战，井冈山等） | **初步形成** | 《中国的红色政权为什么能够存在》《井冈山的斗争》《星星之火，可以燎原》《反对本本主义》等；**工农武装割据**；**农村包围城市、武装夺取政权**新道路 | **工农民主统一战线** | 封建压迫、**国民党新军阀** |
| **遵义会议后 + 1937 起全民族抗战** | **走向成熟** | 《实践论》《矛盾论》《〈共产党人〉发刊词》等；系统阐述**新民主主义革命理论** | **抗日民族统一战线**（第二次国共合作） | **日本** |
| **解放战争 + 新中国成立以后** | **继续发展** | 《论人民民主专政》《论十大关系》等；改造、建设理论（第三、四章） | **人民民主统一战线** | **国民党反动派** |

- **遵义会议**：党**生死攸关的转折点**，确立毛泽东领导地位；长征途中电台坏了联系不上，**开始独立自主**解决中国革命实际问题。  
- **活的灵魂**（口诀：**群**主）：**实事求是**、**群众路线**、**独立自主**。

#### 实事求是

- **精髓和基本点**；马克思主义**根本观点**；认识和改造世界的**根本要求**；**党的思想路线**。  
- **思想路线何时确立**：**延安整风**（反教条主义，要实事求是）。  
- **释义**：实事 = 客观事物；求 = 研究；是 = 客观事物内部的联系即**规律性** → 对客观事物研究其内部规律。  
- 比方：**有的放矢**——**矢** = 马克思主义之箭，**的** = 中国革命之靶。

#### 群众路线

- 党的**生命线**和**工作路线**（与**思想路线**区分）。

#### 独立自主

- **对外开放的立足点**；**中华民族精神之魂**。  
- 最初表述见《反对本本主义》：中国革命胜利要靠中国同志了解中国情况。

## 四、第二章 新民主主义革命理论

### 4.1 国情、矛盾、任务

- **最基本国情**：**半殖民地半封建社会**（两半社会）。  
- **主要矛盾两对**：中华民族 vs 帝国主义；人民大众 vs 封建主义。**最主要**：前者。  
- **革命总路线**：**无产阶级领导的，人民大众的，反三座大山的革命**。  
- **总路线完整表述**：**1948 年**《在晋绥干部会议上的讲话》（对象中当时**增加了官僚资本主义**）。  
- **根本任务**：反三座大山（**帝国主义、封建主义、官僚资本主义**）。  
- **革命性质**：资产阶级民主革命（新民主主义革命）；**根本问题**：**国家政权**。

### 4.2 人民大众、领导权、问题层级

| 角色 | 定位 |
|------|------|
| **工人** | 领导阶级；**最基本的动力** |
| **农民** | **主力军**（人多） |
| **小资产阶级、民族资产阶级** | 动力（国旗四星对应工、农、小资产、民资；中间星为党） |

| 问题类型 | 内容 |
|---------|------|
| **首要问题** | **分清敌友** |
| **基本问题** | **农民问题** |
| **中心问题 / 核心问题** | **无产阶级领导权** |

**实现无产阶级领导权**：关键 = **统一战线**；策略 = **独立自主**；坚强支柱 = **武装力量**；根本保证 = **党**；基础 = **对农民的领导**。

### 4.3 三大法宝（《〈共产党人〉发刊词》）

**统一战线、武装斗争、党的建设**（战斗舰）。

**统一战线两个联盟**：

1. 工人、农民、知识分子和其他劳动者的联盟——**主要是工农联盟**（党徽锤镰；**统一战线的基础**）。  
2. 工人和民族资产阶级、非劳动人民的联盟——**又联合又斗争**。

**武装斗争**：新型人民军队**根本原则**——坚持党对军队的**绝对领导**；**宗旨**——**为人民服务**（口诀：**人民宗旨**）。  
军队政治工作四原则：**官兵一致、军民一致、瓦解敌军、优待俘虏**（16 字）。

**党的建设**：此时**思想建设首位**；主要矛盾——无产阶级思想与非无产阶级思想之间的矛盾。  
**新时代**：**政治建设**第一位。  
**根本组织原则**：**民主集中制**（少数服从多数，服从组织）。  
**三大作风**：理论联系实际、密切联系群众、批评与自我批评（与史纲表述“理论与实际相结合”等略有差异，记三关键词：**理论、群众、批评**）。

### 4.4 三大纲领

**经济**：

1. 没收封建地主阶级的土地归农民所有（**主要内容**）  
2. 没收官僚资产阶级的垄断资本归国家所有  
3. **保护民族工商业**（**极具特色**；**没有没收外国资本**）

**政治**：推翻帝国主义和封建主义（反帝反封）；建立**无产阶级领导的、以工农联盟为基础的、各革命阶级联合专政**的新民主主义共和国。  
- 建国初**国体**：**各革命阶级联合专政**；现今**人民民主专政**。  
- **政体**：**人民代表大会制度**（国体 = 谁说了算；政体 = 管理国家的形式）。

**文化**：**民族的、科学的、大众的**文化。  
- 民族：反对帝国压迫，主张中华民族尊严和独立。  
- 科学：反封建（与反帝反封对应）。  
- 大众。

### 4.5 道路：农村包围城市，武装夺取政权

- **内容**：土地革命、武装斗争、农村革命根据地建设**有机统一**（工农武装割据）。  
- **工农**→土地革命；**武装**→武装斗争；**割据**→根据地建设。  
- 良性循环：土地革命 → 根据地 → 武装斗争 → 再土地革命。  
- **土地革命** = **基本内容**；**武装斗争** = **主要形式**；**根据地建设** = **依托**。

## 五、第三章 社会主义革命理论（社会主义改造）

- 新中国初：**新民主主义社会**；**主要矛盾**：**工人阶级和资产阶级**之间的矛盾。  
- **五种经济成分**：社会主义性质**国营经济**；**合作社**；非社非资的**个体经济**；资本主义性质**私人资本主义**；**国家资本主义**（实质三种：社会主义、个体、资本主义）。  
- **国营经济居于领导地位**；建立国营经济主要手段：**没收官僚资本**（与纲领一致）。  
- **个体** → 半社会主义性质**合作社** → 完全社会主义性质**集体经济**。  
- **私人资本主义（工商业）** → **国家资本主义** → **国营经济**。  
- **合作社、国家资本主义**均为**过渡**形式。

### 5.1 总路线：一化三改

- **一化**：社会主义工业化 = **主体**  
- **三改**：农业、手工业、工商业改造 = **两翼**

### 5.2 改造步骤（与五种经济成分逻辑对应）

**农业**：互助组 → 初级农业生产合作社 → 高级合作社；原则：**自愿互利、典型示范、国家帮助**（**没有**统筹兼顾）。

**手工业**：供销小组 → 供销合作社 → 生产合作社；**积极领导，稳步前进**。

**工商业（国家资本主义）**：

1. **初级形式**国家资本主义——与资本家**企业外部**合作（委托加工、订货、代销等；课上强调尚未统购包销表述以教材为准）→ 有社会主义**因素**，尚非社会主义性质。  
2. **个别企业公私合营**——**内部**合作。  
3. **全行业公私合营**；方法：**和平赎买**（国家给钱，一定年限内获得利润）。  
前两步利润分配：**四马分肥**（国家所得税、企业公积金、工人福利费、资方红利）。

## 六、第四章 社会主义建设道路初步探索（1956 起建设）

- **根本思想**：根据本国情况**走自己的路**。  
- **良好开端**：《**论十大关系**》——  
  1. **以苏为鉴**  
  2. **独立自主**地探索适合中国情况的社会主义建设道路  
  3. 确定口号：**向国外学习**  
  4. **基本方针**：**调动一切积极因素为社会主义事业服务**

### 6.1 《关于正确处理人民内部矛盾的问题》

- 社会主义国家**政治生活的主题**：**正确处理人民内部矛盾**。  
- **基本矛盾**：仍是**生产力与生产关系**、**经济基础与上层建筑**（唯物史观讲义）；社会发展的**根本动力**；在社会主义社会中**非对抗性**，又相适应又相矛盾，在**人民根本利益一致**基础上（公有制，剥削关系消失等表述为课上讲解）。  
- **两类矛盾**：**敌我矛盾** → **专政**，分清敌我；**人民内部矛盾** → **民主**，分清是非。

**解决人民内部矛盾方针**：

| 领域 | 方针 |
|------|------|
| 政治 | **团结—批评—团结** |
| 物质 | **统筹兼顾** |
| 文化 | **百花齐放** |
| 人民与机关 | **民主集中** |
| 民主党派与中共 | 在**中国共产党领导**下**长期共存、互相监督** |
| 民族 | **民族平等，团结互助** |

### 6.2 中共八大（1956）与主要矛盾演变

**八大**：  
1. 人民对于建立**先进的工业国**的要求同**落后的农业国**的现实之间的矛盾  
2. 人民对于**经济文化迅速发展**的需要同当前经济文化**不能满足人民需要**的状况之间的矛盾  

**1981 十一届六中全会**：人民日益增长的**物质文化需要**同**落后的社会生产**之间的矛盾（课上称后面为“现在的”以十九大为准）。  

**2017 十九大至今**：人民日益增长的**美好生活需要**和**不平衡不充分的发展**之间的矛盾。

### 6.3 工业化道路

- **有别于苏联**的工业化道路；**两条腿走路**：重和轻，中央和地方，沿海和内地，大型和小型（**没有**“外资和内资并举”）。  
- **总方针**：以**农业为基础**，**工业为主导**，以**农轻重**为序发展国民经济。  
- **战略目标**：**四个现代化**——具有现代**国防、科学技术、工业、农业**的社会主义强国（口诀：**国防科技工农** / 国防科技大学工农）。

## 七、第五至八章（速成课下 + 时间线续）

### 7.1 第五章 中国特色社会主义理论体系

- **时代主题**：**和平与发展**。  
- **实践基础**：**改革和建设**（**没有革命**）。

#### 1978 十一届三中全会

- 讲话标题：《**解放思想，实事求是，团结一致向前看**》  
- 历史性决策：**改革开放** → 开启改革开放和社会主义现代化建设**新时期**  
- **重新确立**马克思主义思想路线：**实事求是**（勿与群众路线混淆：群众路线是**生命线、工作路线**）

#### 1981 十一届六中全会

- 指出社会主义阶段主要矛盾（过渡表述）：人民日益增长的**物质文化需要**与**落后的社会生产**之间的矛盾（与现行十九大表述区分）。

#### 1982 党的十二大

- 邓小平提出**建设有中国特色的社会主义**重大命题 → **主题**形成。  
- **邓小平理论**是中特理论体系的**开篇之作**。

#### 十三大

- **邓小平理论轮廓形成**；系统论述**社会主义初级阶段理论**；**基本路线**：**一个中心，两个基本点**。  
- **我国最基本、最大的国情**：**现在处于并将长期处于社会主义初级阶段**。

#### 1992 南方谈话

- **邓小平理论走向成熟** / **集大成之作**；提出**社会主义市场经济理论**——**计划和市场都是经济手段**，**没有制度属性**，可与不同社会制度结合；**发展才是硬道理**；**三个有利于**（见下）。  
- 把改革开放和社会主义现代化建设推向**新阶段**。

#### 1992 十四大

- 确立建立**社会主义市场经济体制**。

#### 1997 十五大

- 正式提出**邓小平理论**概念并**写入党章**。  
- **毛泽东思想**写入党章：**1945 年党的七大**。

#### 中特后续发展

- **三个代表**：**跨世纪发展**（1989—2002）  
- **科学发展观**：**新世纪新阶段**新发展

### 7.2 第六章 邓小平理论（要点全集）

**首要理论问题**：**什么是社会主义，怎样建设社会主义**。

**社会主义本质**：**解放和发展生产力，消灭剥削和两极分化，最终达到共同富裕**。  
- **根本任务**：**发展生产力**（解放和发展生产力）。

**基本路线**：**一个中心，两个基本点**  
- **中心**：**以经济建设为中心**  
- **基本点**：**四项基本原则** + **改革开放**  
  - 四项基本原则：坚持**社会主义道路**、坚持**无产阶级专政**（教材常表述为人民民主专政，以教材为准）、坚持**中国共产党领导**、坚持**马列主义、毛泽东思想**  
- **改革开放**：决定中国命运、实现中华民族伟大复兴的**关键一招**（全面小康是**关键一步** → 小步 vs 大招）
