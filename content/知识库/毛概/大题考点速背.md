## 【导论-3】马克思主义中国化时代化的历史进程

**1. 四个历史阶段及其意义**

**(1) 新民主主义革命时期**

- 以毛泽东同志为主要代表的中国共产党人，把马列主义同中国具体实际结合，开辟**农村包围城市、武装夺取政权**的正确道路，**创立毛泽东思想**
- 意义：浴血奋战、百折不挠，创造新民主主义革命伟大成就，**为实现中华民族伟大复兴创造了根本社会条件**

**(2) 社会主义革命和建设时期**

- 以毛泽东同志为主要代表的中国共产党人，提出马列主义同中国具体实际进行**"第二次结合"**，丰富发展毛泽东思想
- 意义：自力更生、发愤图强，创造社会主义革命和建设伟大成就，**为实现中华民族伟大复兴奠定了根本政治前提和制度基础**

**(3) 改革开放和社会主义现代化建设新时期**

- **十一届三中全会（1978）**——新中国成立以来党的历史上具有深远意义的伟大转折，开启改革开放和社会主义现代化建设新时期

- **十六大（2002）后，以胡锦涛同志为主要代表的中国共产党人**——形成**科学发展观**
- 意义：解放思想、锐意进取，创造改革开放和社会主义现代化建设伟大成就，**为实现中华民族伟大复兴提供了充满新的活力的体制保证和快速发展的物质条件**

- **十八大（2012）以来，以习近平同志为主要代表的中国共产党人**——坚持"两个结合"，系统回答三大时代课题，提出一系列原创性的治国理政新理念新思想新战略，创立**习近平新时代中国特色社会主义思想**，实现马克思主义中国化时代化**新的飞跃**
- 意义：自信自强、守正创新，创造新时代伟大成就，全面建成小康社会，党和国家事业取得**历史性成就、发生历史性变革**，推动我国**迈上全面建设社会主义现代化国家新征程**，**为实现中华民族伟大复兴提供了更为完善的制度保证、更为坚实的物质基础、更为主动的精神力量**

**2. 马克思主义中国化的三次飞跃（单选/判断）**

## 【1-2】毛泽东思想的主要内容和活的灵魂

**1. 毛泽东思想的主要内容（7方面）**

- 毛泽东思想紧紧围绕**中国革命和建设的主题**

1. **新民主主义革命理论**——两个基本点：①资产阶级分两部分（大资产阶级/官僚资产阶级 + 民族资产阶级）；②中国无资产阶级民主，只能以**长期的武装斗争**为主要形式，是无产阶级领导的以农民为主体的革命战争。三大法宝：**统一战线、武装斗争、党的建设**
2. **社会主义革命和社会主义建设理论**——人民民主专政（对人民民主+对敌人专政）
3. **革命军队建设和军事战略理论**——党指挥枪不是枪指挥党；全心全意为人民服务是唯一宗旨；三湾改编（1927）确立党对军队的领导；长时期主要作战形式是**游击战和带游击性的运动战**
4. **政策和策略理论**——政策和策略是党的生命
5. **思想政治工作和文化工作理论**——掌握思想教育是团结全党进行伟大政治斗争的**中心环节**；思想政治工作是经济工作和其他一切工作的**生命线**；领导同盟者两个条件：①率领被领导者向共同敌人作坚决斗争并取胜 ②给以物质利益至少不损害+政治教育
6. **党的建设理论**——特别注重从思想上建党；三大优良作风：**理论联系实际、密切联系群众、批评与自我批评**；"惩前毖后、治病救人"；"两个务必"
7. 国际战略和外交工作理论

**2. 毛泽东思想活的灵魂（三个基本方面）**

- 1981年十一届六中全会《历史决议》指出

**(1) 实事求是**——毛泽东思想的**精髓**、基本点

- 内涵：一切从实际出发，理论联系实际，坚持在实践中检验真理和发展真理
- 1937年《实践论》《矛盾论》系统哲学论证；延安整风（1942-1945）和七大（1945）确立

**(2) 群众路线**——党的生命线和根本工作路线

- 内涵：一切为了群众，一切依靠群众，从群众中来，到群众中去
- 全心全意为人民服务是我们党区别于其他一切政党的**根本标志**

**(3) 独立自主**——中华民族精神之魂，立党立国重要原则

- 内涵：坚持独立思考、走自己的路，立足点放在**依靠自己力量**基础上，同时积极争取外援、学习外国有益先进事物
- 1930年《反对本本主义》最早明确表述

**3. 如何坚持实事求是（3点）**

1. 深入实际了解事物本来面貌，把握内在必然联系，按客观规律办事
2. 清醒认识和正确把握我国基本国情
3. 不断推进实践基础上的理论创新

**4. 如何坚持群众路线（3点）**

1. 坚持人民是推动历史发展的根本力量
2. 坚持全心全意为人民服务的根本宗旨
3. 保持党同人民群众的血肉联系（关系党生死存亡的问题）

**5. 如何坚持独立自主**

1. 独立自主是中华民族优良传统，是立党立国重要原则
2. 坚持中国的事情由中国人民自己选择、自己处理
3. 坚持独立自主的和平外交政策，走和平发展道路
4. 独立自主是中华民族精神之魂

## 【2-2】新民主主义革命的总路线和基本纲领

**1. 总路线**

- 1939年《中国革命和中国共产党》第一次提出"新民主主义革命"
- **1948年《在晋绥干部会议上的讲话》**完整概括：**无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命**

**2. 四个问题**

- 首要问题：分清敌友 / 基本问题：农民问题 / 中心问题：无产阶级领导权 / 根本问题：国家政权

**3. 革命对象（三座大山）**

- **帝国主义**——首要对象 / **封建主义**——社会基础 / **官僚资本主义**——买办的、封建的国家垄断资本主义

**4. 革命动力**

- **无产阶级**（最基本动力）/ **农民阶级**（主力军）/ **城市小资产阶级**（可靠同盟者）/ **民族资产阶级**（两面性）

**5. 革命领导力量（中心问题）**

- 区别新旧民主主义革命的根本标志：领导权掌握在**无产阶级还是资产阶级手中**
- 无产阶级特点（为什么能领导）：

  ① **三重压迫**——最彻底

  ② **集中在少数大城市**——易组织

  ③ **出身破产农民**——与农民天然联盟

**6. 革命性质和前途**

- 性质：**资产阶级民主革命**（不是无产阶级社会主义革命）
- 新旧区别：新民主主义——**中国共产党**领导、**马克思列宁主义**指导、前途**社会主义**

**7. 新民主主义革命与社会主义革命关系**

- 民主主义革命是**必要准备**，社会主义革命是**必然趋势**；中间不容横插一个资产阶级专政

**8. 政治纲领**

- **国体**：无产阶级领导的，工农联盟为基础的，各革命阶级联合专政
- **政体**：民主集中制的人民代表大会制度

**9. 经济纲领（两没收一保护）**

1. **没收封建地主阶级的土地归农民所有**——主要内容
2. **没收官僚资本归新民主主义国家所有**——题中应有之义（双重性质）
3. **保护民族工商业**——极具特色

## 【2-3】新民主主义革命的道路和基本经验

**1. 革命道路**：**农村包围城市、武装夺取政权**

**2. 提出过程**

- 党成立初期：城市重心 → 1927年大革命失败后：转向农村，毛泽东创建井冈山革命根据地

**3. 道路形成的必然性**

- **为什么必须走**：①内无民主、外无独立，不能合法斗争 ②农业大国，农民占绝大多数
- **为什么能走**：①政治经济发展不平衡，统治薄弱环节（**根本原因**） ②农村受压迫深重 ③革命形势向前发展 ④红军力量 ⑤党的领导正确

**4. 道路内容**：处理**土地革命**（基本内容）、**武装斗争**（主要形式）、**农村革命根据地**（战略阵地）三者关系

**5. 三大法宝**

- 毛泽东《〈共产党人〉发刊词》：**统一战线、武装斗争、党的建设**
- 关系：统一战线和武装斗争是**两个基本武器**；党的组织是掌握两个武器的英勇战士
- 1949年《论人民民主专政》集中概括基本经验

**6. 统一战线**

- **两个联盟**：①工农联盟（**基础**） ②工人阶级与非劳动人民联盟
- **实践经验（4条）**：①建立巩固工农联盟 ②又联合又斗争 ③发展进步势力、争取中间势力、孤立顽固势力 ④坚持独立自主

**7. 武装斗争经验**

1. 坚持**党对军队的绝对领导**（建军根本原则）
2. 建设全心全意为人民服务的人民军队
3. 革命政治工作（官兵一致、军民一致、瓦解敌军优待俘虏）
4. 正确战略战术

**8. 党的建设经验**

1. 思想建设放在首位 2. 组织建设（民主集中制） 3. 作风建设（三大优良作风） 4. 联系政治路线加强党的建设

**9. 新民主主义革命理论意义（4点）**

1. 马列主义同中国实际结合的革命理论
2. 揭示革命规律，回答中国革命向何处去
3. 指导完成新民主主义革命，实现民族独立、人民解放
4. 改变世界面貌的伟大历史事件

## 【3-2】社会主义改造道路和历史经验

**1. 农业改造**

1. 积极引导走互助合作道路
2. 遵循**自愿互利、典型示范和国家帮助**
3. 分析阶级状况（贫农下中农占大多数→阶级基础）
4. **积极领导、稳步前进**
  - 步骤：**互助组**（萌芽）→ **初级社**（半社会主义）→ **高级社**（社会主义）

**2. 手工业改造**：方针积极引导、稳步前进；步骤：供销小组→供销合作社→生产合作社

**3. 资本主义工商业改造**

- 方法：**和平赎买**，国家资本主义过渡形式
- 步骤：初级形式国家资本主义（**四马分肥**：国家所得税、企业公积金、工人福利费、资方红利）→ 个别企业公私合营 → 全行业公私合营

**4. 为什么能赎买**：①民族资产阶级两面性 ②国家资本主义过渡

**5. 改造历史经验**

1. 工业化建设与社会主义改造**同时并举**（中心任务是工业化）
2. 积极引导、逐步过渡
3. 和平方法
4. 失误：要求过急、工作过粗、形式简单划一

## 【4-1】社会主义建设道路初步探索的重要理论成果

**1. 调动一切积极因素为社会主义事业服务**

- 《论十大关系》基本方针：**调动一切积极因素，为社会主义建设服务**——以苏为鉴，独立自主探索，标志良好开端
- **"六又"方针**：又有集中又有民主，又有纪律又有自由，又有统一意志又有个人心情舒畅生动活泼

**2. 社会主义社会矛盾思想**

- 1957年《关于正确处理人民内部矛盾的问题》

**(1) 基本矛盾**：生产关系和生产力、经济基础和上层建筑；**非对抗性**，可通过制度本身解决

**(2) 两类矛盾**：

- **敌我矛盾**——对抗性，**专政**解决
- **人民内部矛盾**——非对抗性，**民主**解决（总方针）

**(3) 正确处理人民内部矛盾方针**：

1. 思想领域：**"团结—批评—团结"**
2. 物质利益：统筹兼顾、适当安排
3. 科学文化：**"百花齐放、百家争鸣"**
4. 民主党派：**长期共存、互相监督**
5. 主题：社会主义国家**政治生活的主题**

**3. 走中国工业化道路**

- 主要指**重工业和轻工业、农业发展关系**
- 总方针：**以农业为基础，以工业为主导，以农轻重为序**
- **"两条腿走路"**：重轻工业、中央地方、沿海内地、大中小企业并举
- 陈云**"三个主体、三个补充"**
- **"两参一改三结合"**：干部参加劳动、工人参加管理；改革不合理规章；工人、领导干部、技术员结合

**4. 其他理论成果（对号入座级别）**

1. **社会主义两阶段**：不发达+比较发达（毛泽东）
2. **"四个现代化"**：现代农业、工业、国防、科学技术（关键在科技）
3. **"向科学进军"**；知识分子是工人阶级一部分（周恩来）
4. **"三线建设"**（备战、备荒、为人民）
5. **台湾问题**：周恩来"一纲四目"
6. **国际战略**：两个"中间地带"→"三个世界划分"（毛泽东）
7. **执政党建设**：反主观主义、宗派主义、官僚主义；民主集中制；群众路线

## 【6-1】邓小平理论首要的基本的理论问题和精髓

**1. 首要问题**：什么是社会主义、怎样建设社会主义

**2. 社会主义本质（南方谈话1992）**

> **解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕**

- 社会主义原则：第一发展生产，第二共同致富

**3. 本质理论意义（4点）**

1. 突出"解放生产力，发展生产力"，纠正忽视生产力发展错误
2. 突出"消灭剥削，消除两极分化，最终达到共同富裕"——成果全体人民共享
3. 廓清模糊观念，深化对科学社会主义认识
4. 对坚持社会主义基本制度基础上推进改革具有重大意义

**4. 怎样建设社会主义**：坚持四项基本原则（公有制+按劳分配；共产党领导+人民民主专政；马列主义毛泽东思想）

**5. 改革两条根本原则**：①公有制为主体 ②共同富裕

**6. 精髓**：**解放思想、实事求是**——党的思想路线，十一届三中全会（1978）重新确立

## 【6-2】邓小平理论的主要内容

**1. 社会主义初级阶段理论**

- 最大实际：**处在社会主义初级阶段**（十三大1987）
- 两层含义：①已进入社会主义 ②还处在不发达阶段
- 长期性：特指生产力落后条件下建设社会主义必然经历的阶段
- 意义：建设中国特色社会主义的**总依据**

**2. 党的基本路线（十三大1987）**

- **"一个中心、两个基本点"**：以经济建设为中心；四项基本原则是**立国之本**（政治基石）；改革开放是**强国之路**（活力源泉）
- **党的基本路线是党和国家的生命线、人民的幸福线**
- **如何坚持**：①紧紧围绕经济建设 ②把坚持四项基本原则同坚持改革开放结合

**3. 社会主义根本任务**：**发展生产力**，工作重点是经济建设

- "**科学技术是第一生产力**"

**4. "三步走"战略**：①1990年翻一番解决温饱 ②20世纪末小康 ③21世纪中叶基本实现现代化

**5. 改革开放理论**

- 是中国的**第二次革命**，社会主义制度的**自我完善和发展**
- 改革是社会主义社会发展的**直接动力**
- 对外开放是**基本国策**；**决定中国命运的关键一招**

**6. "三个有利于"**：①生产力 ②综合国力 ③人民生活水平

**7. 社会主义市场经济（南方谈话1992）**

- 十二届三中全会（1984）提出"公有制基础上有计划的商品经济"
- ①计划经济≠社会主义，市场经济≠资本主义 ②都是经济手段 ③不具有制度属性

**8. "两手抓"**：物质文明+精神文明；建设+法制；改革开放+惩治腐败

**9. "一国两制"**：核心是**坚持一个中国**；从解决台湾问题开始

**10. 时代主题**：**和平与发展**

- 外交基本目标：维护我国独立主权，促进世界和平发展
- **和平共处五项原则**；党际四原则
- 国际局势三句话：**冷静观察、稳住阵脚、沉着应付**

**11. 党的建设（7点）**：关键在党的领导；加强党建是法宝；重视理论；基层组织是基础；"四化"方针（革命化、年轻化、知识化、专业化）；党风关系生死存亡；制度问题带根本性

## 【7-1】"三个代表"重要思想的核心观点

**1. 先进生产力（7点）**

1. 根本任务是发展社会生产力
2. 实现现代化最根本的是通过改革促进先进生产力
3. 工人农民知识分子是根本力量；知识分子是**开拓者**
4. **人才资源是第一资源**
5. **科学技术是第一生产力**，是先进生产力集中体现和主要标志
6. 发展生产力依靠创新
7. 生产关系和上层建筑体现先进生产力发展要求

**2. 先进文化**

1. 就是发展中国特色社会主义文化，就是建设精神文明
2. 面向现代化、面向世界、面向未来，民族的科学的大众的文化
3. **坚持马克思主义在意识形态领域的指导地位**
4. 弘扬主旋律与提倡多样化统一
5. **弘扬民族精神是极为重要的任务**；核心是**爱国主义**
6. 思想道德建设是**重要内容和中心环节**（为人民服务为核心、集体主义为原则、诚实守信为重点）
7. **思想政治工作是经济工作和其他一切工作的生命线**
8. 教育是基础工程；新闻媒体是喉舌；始终把社会效益放在首位

**3. 人民根本利益**

1. 把人民根本利益作为出发点和归宿
2. 出发点和落脚点是**不断实现好维护好发展好**最广大人民根本利益
3. **人心向背是决定一个政党、一个政权兴亡的根本性因素**
4. 人民利益高于一切
5. 全国人民根本利益一致，可在这一基础上调节利益关系
6. 努力使各群体共同享有发展成果
7. **人民，只有人民，才是工作价值的最高裁决者**
8. 以是否符合最广大人民群众的根本利益为**最高衡量标准**

**4. 辩证关系**：发展先进生产力是**基础条件**；人民群众是**创造主体**和**根本力量**；归根到底满足人民需要

**5. 贯彻要求**：**关键**在坚持与时俱进 / **核心**在坚持党的先进性 / **本质**在坚持执政为民

## 【8-1】科学发展观的科学内涵

**1. 第一要义：推动经济社会发展**

- 坚持发展是硬道理的本质要求就是**坚持科学发展**
- 发展是解决中国一切问题的**"总钥匙"**

**2. 如何坚持科学发展（4点）**

1. 加快转变经济发展方式（主攻方向：结构战略性调整；重要支撑：科技创新；出发点和落脚点：保障改善民生；着力点：资源节约型、环境友好型社会）
2. 推动科技跨越式发展（**自主创新、建设创新型国家是国家发展战略的核心**）
3. 培养高素质创新型人才（人才问题是关键问题）
4. 善于抓住和用好机遇

**3. 核心立场：以人为本**

- "人"指人民群众（以劳动者为主体）；与中国古代民本有**实质区别**
- 集中体现为人民服务根本宗旨

**4. 如何坚持以人为本（4点）**

1. **发展为了人民** 2. **发展依靠人民** 3. **发展成果由人民共享** 4. 最终实现**人的全面发展**

**5. 基本要求：全面协调可持续**

- **全面**：发展要有全面性 / **协调**：协调性、均衡性 / **可持续**：持久性、连续性
- **如何坚持**：①五位一体全面发展（经济建设是中心和基础、政治建设是方向和保障、文化建设是灵魂和血脉、社会建设是支撑和归宿、生态文明建设是根基和条件） ②协调发展 ③可持续发展（生产发展、生活富裕、生态良好） ④建设生态文明

**6. 根本方法：统筹兼顾**

- **如何坚持（4点）**：
  - 统筹城乡、区域、经济社会、人与自然、国内发展和对外开放 
  - 兼顾各阶层利益（中央和地方、个人和集体、局部和整体、当前和长远） 
  - 提高战略思维、创新思维、辩证思维能力 
  - 立足当前、着眼长远
