## 一、集合基础

### 1.1 集合的基本概念

**集合**：把具有共同性质的一些东西汇集成一个整体。

- 元素：组成集合的每个对象，用 a \in A 表示 a 属于集合 A
- 表示法：列举法 {1,2,3} 或 叙述法 {x | x 是正奇数}

**重要集合**：
- 空集 \varnothing：不含任何元素的集合
- 全集 E：在一定范围内包含所有元素的集合
- 幂集 \mathcal{P}(A)：A 的所有子集组成的集合，|\mathcal{P}(A)| = 2^{|A|}

**子集**：A \subseteq B ⟺ \forall x(x \in A \to x \in B)
- A = B ⟺ A \subseteq B 且 B \subseteq A（证明集合相等的核心方法）

### 1.2 集合的运算

| 运算 | 符号 | 定义 |
|------|------|------|
| 并集 | A \cup B | {x | x\in A \lor x\in B} |
| 交集 | A \cap B | {x | x\in A \land x\in B} |
| 差集 | A - B | {x | x\in A \land x\notin B} |
| 补集 | \sim A | E - A |
| 对称差 | A \oplus B | (A-B)\cup(B-A) |

**运算性质**（类比逻辑等值式记忆）：
- 幂等律：A \cup A = A, A \cap A = A
- 交换律：A \cup B = B \cup A
- 结合律：(A \cup B) \cup C = A \cup (B \cup C)
- 分配律：A \cup (B \cap C) = (A \cup B) \cap (A \cup C)
- 德·摩根律：\sim(A \cup B) = \sim A \cap \sim B, \sim(A \cap B) = \sim A \cup \sim B

## 二、笛卡尔积与关系

### 2.1 序偶与笛卡尔积

**序偶**：<a, b>，有序对，<a,b> = <c,d> ⟺ a=c 且 b=d

**笛卡尔积**：A \times B = {<x,y> | x\in A \land y\in B}
- 若 |A|=m, |B|=n，则 |A\times B| = mn
- A \times (B \cap C) = (A \times B) \cap (A \times C)
- A \times (B \cup C) = (A \times B) \cup (A \times C)

**真题**（2024-2025）：
若 B \subseteq C，证明 A \times B \subseteq A \times C

证明：任取 <x,y> \in A\times B，则 x\in A 且 y\in B
由 B \subseteq C 得 y\in C，故 <x,y> \in A\times C
因此 A \times B \subseteq A \times C ✓

### 2.2 关系的基本概念

**二元关系**：A 到 B 的关系 R 是 A \times B 的子集
- 若 <a,b> \in R，记作 aRb
- A 上的关系：R \subseteq A \times A

**关系的表示**：
1. **集合表示**：R = {<1,2>, <2,3>, <3,1>}
2. **关系矩阵**：M_R = (m_{ij})，m_{ij}=1 若 <a_i,b_j>\in R，否则 0
3. **关系图**：以元素为顶点，有关系则画有向边

## 三、关系的性质与闭包

### 3.1 关系的五种性质

设 R 是 A 上的关系：

| 性质 | 定义 | 关系矩阵特征 | 关系图特征 |
|------|------|-------------|-----------|
| 自反 | \forall x\in A, xRx | 主对角线全 1 | 每个顶点有环 |
| 反自反 | \forall x\in A, \langle x,x\rangle \notin R | 主对角线全 0 | 每个顶点无环 |
| 对称 | xRy ⇒ yRx | 矩阵对称 | 有向边成对出现 |
| 反对称 | xRy 且 yRx ⇒ x=y | 对称位置不同时为1 | 无双向边 |
| 传递 | xRy 且 yRz ⇒ xRz | 略 | 有路径则有直达边 |

**例题**（2024-2025）：
已知 A, B 是自反的，证明 A \oplus B 是反自反的。

证明：对任意 x，因 A 自反故 <x,x>\in A，B 自反故 <x,x>\in B。
由对称差定义：<x,x> \in A \oplus B ⟺ (xRx 仅属于 A 或 仅属于 B)
但 <x,x> 同时属于 A 和 B，所以 <x,x> \notin A\oplus B
因此 A \oplus B 反自反 ✓

### 3.2 关系复合

**定义**：R \circ S = {<x,z> | \exists y (xRy 且 ySz)}

**复合的性质**：
- (R \circ S) \circ T = R \circ (S \circ T) 结合律
- (R \circ S)^{-1} = S^{-1} \circ R^{-1}

**例题**（2019-2020）：
R={<1,2>,<3,4>,<2,2>}，S={<4,2>,<2,5>,<3,1>,<1,3>}
求 R \circ S

解：
- <1,2>\in R 且 <2,5>\in S → <1,5>\in R\circ S
- <3,4>\in R 且 <4,2>\in S → <3,2>\in R\circ S
- <2,2>\in R 且 <2,5>\in S → <2,5>\in R\circ S

所以 R \circ S = {<1,5>, <3,2>, <2,5>}

### 3.3 传递闭包与 Warshall 算法

**传递闭包 t(R)**：包含 R 的最小传递关系。

**Warshall 算法**（必考！）：
输入：n \times n 关系矩阵 M
输出：传递闭包矩阵 t(M)



**例题**：A = {a,b,c,d}，R = {<a,b>, <b,a>, <b,c>, <c,d>}

初始矩阵：


k=1 (a列)：M[a][a]=0，M[b][a]=1 → 第b行 = 第b行 OR 第a行 → b行有a的列
→ 第b行变为 [1,0,1,0] OR [0,1,0,0] = [1,1,1,0]

k=2 (b列)：M[a][b]=1 → a行 = a行 OR b行 = [0,1,0,0] OR [1,1,1,0] = [1,1,1,0]
M[c][b]=0，M[d][b]=0

k=3 (c列)：M[a][c]=1 → a行 = [1,1,1,0] OR [0,0,0,1] = [1,1,1,1]
M[b][c]=1 → b行 = [1,1,1,0] OR [0,0,0,1] = [1,1,1,1]

k=4 (d列)：M[a][d]=1, M[b][d]=1 → ...

最终 t(R) = {<a,a>, <a,b>, <a,c>, <a,d>, <b,a>, <b,b>, <b,c>, <b,d>, <c,d>}

## 四、等价关系与划分

### 4.1 等价关系

**定义**：同时满足**自反、对称、传递**的关系。

**等价类**：[a]_R = {x | x \in A \land aRx}
- 性质：两个等价类要么相等，要么不相交

**商集**：A/R = {[a]_R | a \in A}

**划分与等价关系一一对应**：
- 每个等价关系对应唯一一个划分（等价类作为划分块）
- 每个划分对应唯一一个等价关系

**例题**（2022-2023期中，8分）：
A = {1,2,3,4}，S = {{1}, {2,3}, {4}} 是 A 的一个划分，求由 S 诱导的等价关系。

解：每个划分块内部的元素两两等价
- {1} → <1,1>
- {2,3} → <2,2>, <2,3>, <3,2>, <3,3>
- {4} → <4,4>

R = {<1,1>, <2,2>, <2,3>, <3,2>, <3,3>, <4,4>}

### 4.2 模同余关系

**定义**：整数集 I 上的模 m 等价关系：
R_m = {<x,y> | x \equiv y (mod m)}，即 m | (x - y)

**例题**（2022-2023期中，6分）：
R_j 是模 j 等价关系，R_k 是模 k 等价关系。
证明：I/R_k 细分 I/R_j ⟺ k 是 j 的整数倍

思路：I/R_k 细分 I/R_j 意味着每个模 k 的等价类包含在某个模 j 的等价类中。当 k 是 j 的倍数时，x\equiv y (mod k) ⇒ x\equiv y (mod j)，即模 k 等价类是模 j 等价类的子集。

### 4.3 相容关系

**相容关系**：满足**自反、对称**的关系（不要求传递）。

**相容类**：子集中任意两个元素都有相容关系。
**最大相容类**：加入任何其他元素都不再是相容类的相容类。

**覆盖**：相容关系对应一个覆盖（划分的推广，允许块之间有重叠）。

**例题**（2022-2023期中，5分）：
简述相容关系的定义，与覆盖的关系，与等价关系的不同。

答：相容关系是自反且对称的关系。每个相容关系对应一个覆盖（而非划分），因为覆盖允许块间重叠。与等价关系的区别：等价关系还要满足传递性，对应划分。

## 五、偏序关系与哈斯图

### 5.1 偏序关系

**定义**：同时满足**自反、反对称、传递**的关系，记作 \preceq。

**哈斯图**：偏序关系的简化关系图
- 省略自反环
- 省略传递边（由传递性可推出的边）
- 被覆盖的元素画在上方

**覆盖**：若 a \prec b 且不存在 c 使得 a \prec c \prec b，则称 b 覆盖 a
COV A = {<x,y> | y 覆盖 x}

### 5.2 特殊元素

| 元素 | 定义 |
|------|------|
| 最大元 | 大于等于所有元素 |
| 最小元 | 小于等于所有元素 |
| 极大元 | 没有比它更大的 |
| 极小元 | 没有比它更小的 |
| 上界 | 大于等于给定子集的所有元素 |
| 下界 | 小于等于给定子集的所有元素 |
| 上确界(最小上界) | 上界中的最小元素 |
| 下确界(最大下界) | 下界中的最大元素 |

**注意**：最大元/最小元如果存在则唯一；极大元/极小元可以有多个。

### 5.4 偏序集证明题

**2024-2025 真题**：
偏序关系 <A,\preceq> 中，a\preceq b, c\preceq d，{a,c} 的上确界为 e，{b,d} 的上确界为 f。证明 e \preceq f。

证明：
① e 是 {a,c} 的上确界 ⟹ a\preceq e 且 c\preceq e
② 由 a\preceq b 且 a\preceq e ⟹ a\preceq b 且 a\preceq e（这不能直接推出）
③ 正确思路：e 是 a 和 c 的上界，f 是 b 和 d 的上界
   a\preceq b \preceq f，故 a\preceq f（传递性）
   c\preceq d \preceq f，故 c\preceq f
④ 所以 f 也是 {a,c} 的一个上界
⑤ 但 e 是 {a,c} 的**最小**上界（上确界），所以 e \preceq f ✓

## 六、函数

### 6.1 函数定义

**函数 f: A \to B**：A 到 B 的**关系**，满足每个 a\in A 有唯一的 b\in B 使 <a,b>\in f。

- **满射**：值域 = B（每个 b 都有原像）
- **单射**：若 a_1 \neq a_2 则 f(a_1) \neq f(a_2)
- **双射**：既满射又单射

**例题**（2019-2020，7分）：
f: Z\times Z \to Z，f(m,n) = |m| - |n|，证明 f 是满射。

证明：对任意 k \in Z，要找 (m,n) 使 |m| - |n| = k
取 m = k, n = 0（若 k\ge 0）或 m = 0, n = k（若 k<0）
- 若 k\ge 0：f(k,0) = |k| - 0 = k
- 若 k<0：f(0,k) = 0 - |k| = -|k| = k（因 k<0 故 -|k| = k）
所以对任意 k\in Z 都存在原像，f 是满射 ✓

## 七、基数与可数集

### 7.1 基数

**基数**：集合的"大小"。有限集的基数 = 元素个数。
**等势**：存在双射 f: A \to B，记作 A \sim B

**可数集**：与自然数集 N 等势的集合（包括有限集和可数无限集）

### 7.2 基数相关证明题

**2022-2023 期末（5分）**：
定义 A + B = {<x,0> | x\in A} \cup {<y,1> | y\in B}
证明 |A \cup B| \le |A + B|

证明：构造 f: A \cup B \to A + B
对任意 z \in A \cup B：
- 若 z \in A，令 f(z) = <z,0>
- 若 z \in B 但 z \notin A，令 f(z) = <z,1>
（对于 z\in A\cap B，取 f(z)=<z,0>即可）

f 是单射（若 f(z_1)=f(z_2)，则 <z_1,0>=<z_2,0> 或 <z_1,1>=<z_2,1>，故 z_1=z_2）
所以 |A\cup B| \le |A+B| ✓

### 7.3 可数集证明

**2024-2025 真题**：
A = {n/(n+1) | n \in N - {2, 91, 255}}，证明 A 可数

证明：定义 f: N \to A，f(n) = n/(n+1)
f 是满射（对任意 n/(n+1)\in A，有 n 映射到它）
f 在 N-{2,91,255} 上是单射（若 n_1\neq n_2 则 n_1/(n_1+1)\neq n_2/(n_2+1)）
所以 A 与可数集 N 的某个子集等势，故 A 可数 ✓

## 八、易错点总结

1. **自反 vs 反自反**：自反是所有元素都有环，反自反是所有元素都没环——一个关系可以既不自反也不反自反
2. **对称 vs 反对称**：不是互斥的！一个关系可以同时对称和反对称（如恒等关系）
3. **等价关系偏序关系**：都满足自反和传递，但等价关系要求对称，偏序关系要求反对称
4. **哈斯图读图**：覆盖关系是直接相邻的，向上走表示更大
5. **上界 vs 上确界**：上界可以有很多，上确界是其中最小的那个（唯一）
6. **Warshall 算法**：三重循环，最外层是中间点 k
7. **最大元 vs 极大元**：最大元和所有元素可比且最大；极大元只是没有比它更大的
