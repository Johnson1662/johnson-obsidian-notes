## 一、代数系统基础概念

### 1.1 运算

**n 元运算**：从 A^n 到 B 的映射。若 B \subseteq A 则称运算封闭。

**二元运算**：最常用，将两个元素映射为一个元素。

**例题**：A = {x | x = 2^n, n\in N}，乘法是否封闭？加法呢？
- 乘法：2^r \cdot 2^s = 2^{r+s} \in A ✓ 封闭
- 加法：2+2^2 = 6 \notin A ✗ 不封闭

### 1.2 运算的性质

| 性质 | 定义 | 说明 |
|------|------|------|
| 封闭性 | \forall x,y\in A, x*y \in A | 运算结果仍在 A 中 |
| 交换律 | \forall x,y\in A, x*y = y*x | 顺序不影响结果 |
| 结合律 | \forall x,y,z\in A, (x*y)*z = x*(y*z) | 括号位置无关 |
| 分配律 | x*(y\triangle z) = (x*y)\triangle(x*z) | * 对 \triangle 分配 |

### 1.3 特殊元素

| 元素 | 定义 | 说明 |
|------|------|------|
| 幺元(单位元) | e*x = x*e = x | 唯一！记作 e |
| 零元 | \theta * x = x * \theta = \theta | 唯一！ |
| 逆元 | x * x^{-1} = x^{-1} * x = e | 若存在则唯一 |

**定理**：若运算满足结合律且存在幺元，则每个元素的逆元唯一。

### 1.4 代数系统

**代数系统**：非空集合 A + 若干运算 f_1,...,f_k，记作 \langle A, f_1,...,f_k \rangle

如 \langle Z, + \rangle 就是整数集和加法构成的代数系统。

## 二、群论基础

### 2.1 半群、独异点、群

| 结构 | 要求 |
|------|------|
| 半群 | 封闭 + 结合律 |
| 独异点(含幺半群) | 封闭 + 结合律 + 有幺元 |
| 群 | 封闭 + 结合律 + 有幺元 + 每个元素有逆元 |

**群的定义**：\langle G, * \rangle 满足：
1. 封闭：\forall a,b\in G, a*b \in G
2. 结合：\forall a,b,c\in G, (a*b)*c = a*(b*c)
3. 幺元：\exists e\in G, \forall a\in G, a*e = e*a = a
4. 逆元：\forall a\in G, \exists a^{-1}\in G, a*a^{-1} = a^{-1}*a = e

**群的阶**：群 G 的元素个数，记作 |G|。

**阿贝尔群(交换群)**：还满足交换律的群。

### 2.2 群的基本性质

**性质 1**：群中消去律成立
a*b = a*c ⇒ b = c（左消去）
b*a = c*a ⇒ b = c（右消去）

**性质 2**：有限群中必存在幂零元
（即存在某个元素 a 和正整数 n，使 a^n = e）

**性质 3**：任意元素 a 的阶（使 a^k = e 的最小正整数 k）整除群阶 |G|。

### 2.3 群的基本证明题

**2019-2020 真题**：设 \langle G,* \rangle 是群，对 \forall a,b,x,y \in G，若 a*x*b = a*y*b，则 x = y。

证明：
① a*x*b = a*y*b                    前提
② a^{-1}*(a*x*b) = a^{-1}*(a*y*b)  左乘 a^{-1}
③ (a^{-1}*a)*x*b = (a^{-1}*a)*y*b  结合律
④ e*x*b = e*y*b                   逆元定义
⑤ x*b = y*b                       幺元性质
⑥ (x*b)*b^{-1} = (y*b)*b^{-1}     右乘 b^{-1}
⑦ x*(b*b^{-1}) = y*(b*b^{-1})     结合律
⑧ x*e = y*e                       逆元定义
⑨ x = y                           幺元性质 ✓

**2022-2023 期末（6分）**：
设 \langle G, * \rangle 是有限群。证明对任意 a,b \in G，a*b 和 b*a 的阶相等。

证明：设 a*b 的阶为 n，即 (a*b)^n = e
则 (b*a)^{n+1} = b*a*(b*a)^n = b*(a*b)^n*a = b*e*a = b*a
即 (b*a)^{n+1} = b*a
两边右乘 (b*a)^{-1} 得 (b*a)^n = e
所以 b*a 的阶整除 n
同理可证 a*b 的阶整除 b*a 的阶
故两者阶相等 ✓

**2024-2025 真题**（较难）：
设 2024 阶群 \langle G, * \rangle 中 a,b \in G，证明：
(a^{2025} * b^{2023})^{2025} = (b^{2025} * a^{2023})^{2023}

分析：2024 阶群中，任一元素 x 满足 x^{2024} = e（拉格朗日定理推论）
故 a^{2025} = a^{2024}*a = e*a = a，a^{2023} = a^{-1}
同理 b^{2025} = b，b^{2023} = b^{-1}

所以左边 = (a*b^{-1})^{2025}，右边 = (b*a^{-1})^{2023}
由 (a*b^{-1})^{2025} = (a*b^{-1})^{2024}*(a*b^{-1}) = e*(a*b^{-1}) = a*b^{-1}
而 (b*a^{-1})^{2023} = (b*a^{-1})^{2024}*(b*a^{-1})^{-1} = e*(b*a^{-1})^{-1} = a*b^{-1}
故两边相等 ✓

## 三、子群

### 3.1 子群定义

**子群**：若 G 的子集 H 关于 G 的运算也构成群，则称 H 是 G 的子群，记作 H \leq G。

**判定定理**：H 是 G 的子群 ⟺
1. H 非空
2. \forall a,b \in H, a*b \in H（封闭）
3. \forall a \in H, a^{-1} \in H（逆元）

**等价判定**：\forall a,b \in H, a*b^{-1} \in H

### 3.2 子群证明题

**例题**（2019-2020）：
设 f 是由群 \langle G_1, \star \rangle 到群 \langle G_2, * \rangle 的同态映射，e' 为 G_2 的幺元，
Ker(f) = {x | x \in G_1, f(x)=e'}，证明 Ker(f) 是 G_1 的子群。

证明：
① Ker(f) 非空：f(e_1) = e'，故 e_1 \in Ker(f)
② 对任意 x,y \in Ker(f)：
   f(x \star y^{-1}) = f(x) * f(y^{-1}) = f(x) * (f(y))^{-1} = e' * e'^{-1} = e'
   故 x \star y^{-1} \in Ker(f)
由子群判定定理，Ker(f) \leq G_1 ✓

**2024-2025 真题**：
设非平凡群 G, H 的阶数分别为 m, n，H 为 G 的子群。
令 K = {aH | a \in G - H}，证明 |K| = m/n - 1

证明：
① 由 Lagrange 定理，n | m
② G 中 H 的左陪集个数为 |G|/|H| = m/n
③ 这些陪集中，H 本身对应的陪集是 H（即 eH = H）
④ 其余陪集对应 a \in G-H，共 m/n - 1 个
⑤ 故 |K| = m/n - 1 ✓

### 3.3 同态基本证明

**2019-2020 真题 1**：
\langle G, * \rangle 和 \langle H, \triangle \rangle 分别为 m 阶和 n 阶的群。
证明：若由 G 到 H 存在单一同态（单同态），则 m | n。

证明：
① 设 f: G \to H 是单同态
② 同态像 f(G) \leq H（同态像是子群）
③ |f(G)| 整除 |H| = n（Lagrange 定理）
④ f 是单射 ⇒ |f(G)| = |G| = m
⑤ 故 m | n ✓

## 四、循环群

### 4.1 定义

**循环群**：存在元素 a \in G 使 G = {a^k | k \in Z}，称 a 为生成元。

### 4.2 性质

**性质 1**：循环群必是阿贝尔群（交换群）。

**证明**：设 G = \langle a \rangle，对任意 a^i, a^j \in G：
a^i * a^j = a^{i+j} = a^{j+i} = a^j * a^i ✓

**性质 2**：循环群的子群仍是循环群。

**性质 3**：若 G 是 n 阶循环群，m|n，则 G 恰有一个 m 阶子群。

**2022-2023 期末（7分）**：
设 \langle G, * \rangle 是 n 阶循环群。证明：若 m 是 n 的因子，则 G 至少有一个 m 阶子群且也是循环群。

证明：
① 设 G = \langle a \rangle，a 的阶为 n
② 令 b = a^{n/m}，则 b^m = a^{n/m \cdot m} = a^n = e
③ b 的阶为 m（若 b^k = e 则 a^{nk/m} = e，故 n|nk/m 即 m|k）
④ H = \langle b \rangle = {e, b, b^2, ..., b^{m-1}} 是 G 的 m 阶子群
⑤ H 由 b 生成，故是循环群 ✓

## 五、群同态与同构

### 5.1 定义

**同态映射**：f: G_1 \to G_2，满足 f(a*b) = f(a)\triangle f(b)
- **单同态**：f 是单射
- **满同态**：f 是满射
- **同构**：f 是双射

**同构的性质**：
- 若 \langle A, \triangle \rangle 与 \langle B, * \rangle 同构，且 \langle B, * \rangle 与 \langle C, \# \rangle 同构
- 则 \langle A, \triangle \rangle 与 \langle C, \# \rangle 同构（同构的传递性）

### 5.2 同构的传递性证明

**2022-2023 期末（6分）**：
证明同构关系具有传递性。

证明：设 f: A \to B 是同构，g: B \to C 是同构
则 g\circ f: A \to C
① 双射：两个双射的复合仍是双射
② 同态性：
   (g\circ f)(x\triangle y) = g(f(x\triangle y)) = g(f(x)*f(y))
   = g(f(x))\# g(f(y)) = (g\circ f)(x)\# (g\circ f)(y)
故 g\circ f 是同构，传递性成立 ✓

### 5.3 同态像的交仍是子群

**2024-2025 真题**：
设 f, g 分别是群 \langle A,* \rangle 到群 \langle B,\triangle \rangle 的同态映射。
证明 \langle f(A)\cap g(A), \triangle \rangle 是 \langle B,\triangle \rangle 的子群。

证明：
① f(A)\cap g(A) 非空：f(e_A)=e_B, g(e_A)=e_B，故 e_B \in f(A)\cap g(A)
② 对任意 x,y \in f(A)\cap g(A)：
   x,y \in f(A) 且 x,y \in g(A)
   存在 a_1,a_2 \in A 使 f(a_1)=x, f(a_2)=y
   存在 a_3,a_4 \in A 使 g(a_3)=x, g(a_4)=y
   x\triangle y^{-1} = f(a_1)\triangle f(a_2)^{-1} = f(a_1*a_2^{-1}) \in f(A)
   x\triangle y^{-1} = g(a_3)\triangle g(a_4)^{-1} = g(a_3*a_4^{-1}) \in g(A)
   故 x\triangle y^{-1} \in f(A)\cap g(A)
由子群判定定理，f(A)\cap g(A) \leq B ✓

## 六、新运算构造群

### 6.1 题型：已知群和新运算，证明新运算也构成群

**2019-2020 真题（4分）**：
设 \langle G,* \rangle 是群。定义新运算 \triangle：x\triangle y = x*a*y，其中 a \in G 固定。
证明 \langle G, \triangle \rangle 也是群。

证明：
① 封闭：x\triangle y = x*a*y \in G（G 对 * 封闭）✓
② 结合律：
   (x\triangle y)\triangle z = (x*a*y)*a*z = x*a*(y*a*z) = x\triangle(y\triangle z) ✓
③ 求幺元：需要找 e_\triangle 使 x\triangle e_\triangle = e_\triangle\triangle x = x
   设 e_\triangle = a^{-1}，则：
   x\triangle a^{-1} = x*a*a^{-1} = x*e_G = x
   a^{-1}\triangle x = a^{-1}*a*x = e_G*x = x ✓
④ 求逆元：需要找 x' 使 x\triangle x' = a^{-1}
   设 x' = a^{-1}*x^{-1}*a^{-1}，则：
   x\triangle x' = x*a*a^{-1}*x^{-1}*a^{-1} = x*x^{-1}*a^{-1} = a^{-1}
   同理 x'\triangle x = a^{-1} ✓

故 \langle G, \triangle \rangle 是群。

## 七、吸收律与幂等律

**2022-2023 期末（6分）**：
设 \triangle 和 * 是集合 A 上的两个二元运算，且满足吸收律。
证明：\triangle 和 * 在 A 上满足幂等律。

**吸收律定义**：x \triangle (x * y) = x, x * (x \triangle y) = x

证明：
对任意 x \in A：
① x \triangle x = x \triangle (x * (x \triangle x))    （吸收律从右到左）
             = x                                    （吸收律）
② x * x = x * (x \triangle (x * x))                （吸收律从右到左）
        = x                                         （吸收律）
所以 x \triangle x = x 且 x * x = x，即幂等律成立 ✓

## 八、矩阵群

**2024-2025 真题**：
M = {A | det(A) = 1}，* 表示矩阵乘法，证明 \langle M, * \rangle 是群。

证明：
① 封闭：若 det(A)=1, det(B)=1，则 det(AB) = det(A)det(B) = 1·1 = 1，故 AB \in M ✓
② 结合律：矩阵乘法满足结合律 ✓
③ 幺元：单位矩阵 I，det(I)=1，I \in M，且 AI = IA = A ✓
④ 逆元：对 A \in M，A 可逆（因 det(A)=1≠0），A^{-1} 满足 det(A^{-1}) = 1/det(A) = 1
   故 A^{-1} \in M，且 AA^{-1} = A^{-1}A = I ✓

故 \langle M, * \rangle 是群 ✓

## 九、易错点总结

1. **群 vs 半群**：群要求有幺元和逆元，半群只要求封闭和结合
2. **阿贝尔群**：就是交换群，别忘了交换律的条件
3. **幺元唯一**：一个代数系统中幺元是唯一的
4. **逆元唯一**：给定元素的逆元唯一
5. **子群判定**：用 a*b^{-1} 判定法最简洁
6. **Lagrange 定理**：子群阶整除群阶，但逆命题不成立
7. **循环群的生成元**：n 阶循环群有 \varphi(n) 个生成元
8. **同态 vs 同构**：同构是同态 + 双射
