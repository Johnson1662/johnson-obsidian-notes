# 2 命题逻辑等值演算

## 一、等值式的概念

如果 $A\leftrightarrow B$ 为**永真式（重言式）**，则称 $A$ 和 $B$ 是等值的，记作 $A\Leftrightarrow B$（或 $A=B$），称为等值式。

> [!caution] $\Leftrightarrow$ 是元语言符号，不是连接词。

## 二、基本等值式（必须熟记）

| 名称 | 公式 |
|------|------|
| **双否定律** | $\lnot\lnot A \Leftrightarrow A$ |
| **幂等律** | $A\land A \Leftrightarrow A$，$A\lor A \Leftrightarrow A$ |
| **交换律** | $A\land B \Leftrightarrow B\land A$，$A\lor B \Leftrightarrow B\lor A$ |
| **结合律** | $(A\land B)\land C \Leftrightarrow A\land(B\land C)$，$(A\lor B)\lor C \Leftrightarrow A\lor(B\lor C)$ |
| **分配律** | $A\lor(B\land C) \Leftrightarrow (A\lor B)\land(A\lor C)$，$A\land(B\lor C) \Leftrightarrow (A\land B)\lor(A\land C)$ |
| **德摩根律** | $\lnot(A\land B) \Leftrightarrow \lnot A\lor\lnot B$，$\lnot(A\lor B) \Leftrightarrow \lnot A\land\lnot B$ |
| **吸收律** | $A\lor(A\land B) \Leftrightarrow A$，$A\land(A\lor B) \Leftrightarrow A$ |
| **零律** | $A\lor1 \Leftrightarrow 1$，$A\land0 \Leftrightarrow 0$ |
| **同一律** | $A\land1 \Leftrightarrow A$，$A\lor0 \Leftrightarrow A$ |
| **排中律** | $A\lor\lnot A \Leftrightarrow 1$ |
| **矛盾律** | $A\land\lnot A \Leftrightarrow 0$ |
| **蕴含等值式** ⭐ | $A\to B \Leftrightarrow \lnot A\lor B$ |
| **等价等值式** | $A\leftrightarrow B \Leftrightarrow (A\to B)\land(B\to A)$ |
| **假言易位** | $A\to B \Leftrightarrow \lnot B\to\lnot A$ |
| **等价否定等值式** | $A\leftrightarrow B \Leftrightarrow \lnot A\leftrightarrow\lnot B$ |
| **归谬论** | $(A\to B)\land(A\to\lnot B) \Leftrightarrow \lnot A$ |

## 三、例题

#### 例1：用等值演算法判断公式类型

**公式1**：判断 $(P\land\lnot\lnot Q)\to P$ 的类型

$$
\begin{aligned}
&(P\land\lnot\lnot Q)\to P \\
&\Leftrightarrow \lnot(P\land\lnot\lnot Q)\lor P \quad\text{（蕴含等值式）} \\
&\Leftrightarrow \lnot(P\land Q)\lor P \quad\text{（双否定律）} \\
&\Leftrightarrow \lnot P\lor\lnot Q\lor P \quad\text{（德摩根律）} \\
&\Leftrightarrow (\lnot P\lor P)\lor\lnot Q \quad\text{（交换律）} \\
&\Leftrightarrow 1\lor\lnot Q \Leftrightarrow 1 \quad\text{（排中律）}
\end{aligned}
$$

→ **重言式（永真式）**

**公式2**：判断 $(P\to Q)\to(\lnot Q\to\lnot P)$ 的类型
- 化简后有成真赋值（如 $100$）也有成假赋值（如 $011$）
- → **可满足式**

#### 例2：证明两个公式等值

证明：$Q\to (P \to R) \Leftrightarrow (P\land Q)\to R$

$$
\begin{aligned}
\text{左端} &\Leftrightarrow \lnot Q\lor (\lnot P\lor R) \quad\text{（蕴含等值式）} \\
&\Leftrightarrow \lnot(P\land Q)\lor R \quad\text{演算} \\
&\Leftrightarrow (P\land Q)\to R \quad\text{（蕴含等值式）}
\end{aligned}
$$

## 四、范式

#### 基本概念

| 术语 | 定义 |
|------|------|
| **命题常量** | 指定了具体含义的命题符号 |
| **命题变元** | 未指定具体含义的命题符号 |
| **文字** | 命题变元 $P$ 或其否定 $\lnot P$ |
| **析取式** | 有限个文字的析取（如 $P\lor Q$） |
| **合取式** | 有限个文字的合取（如 $P\land Q$） |
| **析取范式** | 有限个合取式的析取（外层 $\lor$，内层 $\land$） |
| **合取范式** | 有限个析取式的合取（外层 $\land$，内层 $\lor$） |

> [!note] 一个命题公式的析取范式和合取范式**不唯一**。

## 五、主析取范式与主合取范式

#### 极小项（小项）

- 是**合取式**
- 每个命题变元或其否定出现**且仅出现一次**
- 按字典顺序（或角标顺序）
- $N$ 个命题变元 $\to$ 有 $2^n$ 个小项

例：两个变元 $P,Q$ 的小项

| 小项 | 成真赋值 | 名称 |
|-----|---------|------|
| $\lnot P\land\lnot Q$ | $00$ | $m_0$ |
| $\lnot P\land Q$ | $01$ | $m_1$ |
| $P\land\lnot Q$ | $10$ | $m_2$ |
| $P\land Q$ | $11$ | $m_3$ |

#### 极大项（大项）

- 是**析取式**
- 每个命题变元或其否定出现**且仅出现一次**
- 按字典顺序
- $N$ 个命题变元 $\to$ 有 $2^n$ 个大项

例：两个变元 $P,Q$ 的大项

| 大项 | 成假赋值 | 名称 |
|-----|---------|------|
| $P\lor Q$ | $00$ | $M_0$ |
| $P\lor\lnot Q$ | $01$ | $M_1$ |
| $\lnot P\lor Q$ | $10$ | $M_2$ |
| $\lnot P\lor\lnot Q$ | $11$ | $M_3$ |

#### 定义
- **主析取范式**：析取范式中每个合取式都是小项
- **主合取范式**：合取范式中每个析取式都是大项

#### 求主范式的方法

**方法一：真值表法**
1. 写出所有小项及其成真赋值
2. 找出公式的成真赋值
3. 将对应的小项用 $\lor$ 连接 → 主析取范式
4. 找出未用到的小项，找其成假赋值对应的大项 → 主合取范式
![](assets/2%20命题逻辑等值演算/file-20260524202753699.png)

**方法二：等值演算法**
1. 去掉 $\to$ 和 $\leftrightarrow$（用蕴含等值式、等价等值式）
2. 将 $\lnot$ 内移（德摩根律）
3. 用分配律展开
4. 补全缺少的变元（如 $P = P\land(Q\lor\lnot Q)$）
![](assets/2%20命题逻辑等值演算/file-20260524203056086.png)

**例**：求 $P\to Q$ 的主析取范式和主合取范式

$$
P\to Q \Leftrightarrow \lnot P\lor Q
$$

- **主合取范式**：$\lnot P\lor Q$，写作 $M_2$
- **主析取范式**：$(\lnot P\land Q)\lor(\lnot P\land\lnot Q)\lor(P\land Q)$，写作 $m_0\lor m_1\lor m_3$

## 六、连接词的完备集

> [!def] 连接词完备集
> $S$ 是连接词集合。如果任意命题公式都仅用 $S$ 中的连接词就能表示，且与原公式等价，则 $S$ 是连接词完备集。

常见完备集（共8个）：
- $\{\lnot,\land,\lor\}$
- $\{\lnot,\land\}$
- $\{\lnot,\lor\}$
- $\{\lnot,\to\}$
- $\{\uparrow\}$（与非）：$P\uparrow Q \Leftrightarrow \lnot(P\land Q)$
- $\{\downarrow\}$（或非）：$P\downarrow Q \Leftrightarrow \lnot(P\lor Q)$
