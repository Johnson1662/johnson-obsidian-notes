# 二元关系

## 笛卡尔积
集合A与B的笛卡尔积记作A×B，是序对(x,y)的集合，其中x∈A，y∈B。
- 若|A|=m，|B|=n，则|A×B|=m×n

例：A={1,2}, B={a,b}，则A×B={(1,a),(1,b),(2,a),(2,b)}

## 关系的定义
A到B的关系R是A×B的子集。
- A上的关系：A到A的关系，即A×A的子集

特殊关系：
- 空关系：∅
- 全域关系：EA = A×A，包含所有可能的序对
- 恒等关系：IA = {(x,x) | x∈A}，只包含相同元素的序对

## 关系的表示
### 关系矩阵
n×n矩阵，若(x,y)∈R则第x行第y列为1，否则为0。

### 关系图
- 顶点：A中的元素
- 有向边：若(x,y)∈R，则从x到y画箭头

## 关系的性质
### 自反性
∀x∈A，(x,x)∈R
（每个元素都有自环）

### 反自反性
∀x∈A，(x,x)∉R
（每个元素都没有自环）

### 对称性
若(x,y)∈R，则(y,x)∈R
（有向边双向）

### 反对称性
若(x,y)∈R且(y,x)∈R，则x=y
（不同时存在相反的边，除非是同元素）

等价：若(x,y)∈R且x≠y，则(y,x)∉R

### 传递性
若(x,y)∈R且(y,z)∈R，则(x,z)∈R
（路径长度为2时，存在直接边）

## 关系运算
### 定义域
dom(R) = {x | ∃y, (x,y)∈R}

### 值域
ran(R) = {y | ∃x, (x,y)∈R}

### 逆关系
R⁻¹ = {(y,x) | (x,y)∈R}
（所有序对交换顺序）

### 复合关系（R²）
R∘R = {(x,z) | ∃y, (x,y)∈R且(y,z)∈R}
（传递闭包的一阶）

## 例题
设A={1,2,3,4}，R={(1,3),(1,4),(2,3),(2,4),(3,4)}

关系图：顶点1,2,3,4，边：1→3, 1→4, 2→3, 2→4, 3→4

关系矩阵（4×4）：
```
1 0 1 1
0 1 1 1
0 0 0 1
0 0 0 0
```

dom(R) = {1,2,3}
ran(R) = {3,4}

R⁻¹ = {(3,1),(4,1),(3,2),(4,2),(4,3)}

R² = {(1,4),(2,4)}（因为1→3→4，2→3→4）

性质判断：
- 不自反（缺少(1,1),(2,2)等）
- 反自反（没有(x,x)）
- 不对称（有(1,3)但无(3,1)）
- 反对称（没有相反的边对）
- 不传递（有(1,3)和(3,4)但(1,4)已在R中，满足；但检查所有组合）
