# 集合代数

## 基本概念
- 元素与集合关系：属于（$\in$）、不属于（$\notin$）
- 集合与集合关系：包含（$\subseteq$）、不包含、相等（=）

## 集合运算

### 并集（$A \cup B$）
由属于 $A$ 或属于 $B$ 的元素组成。

### 交集（$A \cap B$）
由 $A$ 和 $B$ 的公共元素组成。

### 差运算（$A-B$，相对补集）
由属于 $A$ 但不属于 $B$ 的元素组成。
- $A-B = A \cap B^c$

### 绝对补集（$A^c$ 或 $\sim A$）
全集 $U$ 减去 $A$：$\sim A = U - A$

### 对称差（$A \oplus B$）
由属于 $A$ 但不属于 $B$，或属于 $B$ 但不属于 $A$ 的元素组成。
- $A \oplus B = (A-B) \cup (B-A)$

### 幂集（$\mathcal{P}(A)$）
由 $A$ 的所有子集组成的集合。
- 若 $A$ 有 $n$ 个元素，则 $|\mathcal{P}(A)| = 2^n$
- $\mathcal{P}(A)$ 的元素本身是集合（$A$ 的子集）

## 运算律

基本运算律（与命题逻辑类似）：

- **交换律**：$A \cup B = B \cup A$，$A \cap B = B \cap A$
- **结合律**：$(A \cup B) \cup C = A \cup (B \cup C)$，$(A \cap B) \cap C = A \cap (B \cap C)$
- **分配律**：$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$，$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$
- **德摩根律**：$\sim(A \cup B) = \sim A \cap \sim B$，$\sim(A \cap B) = \sim A \cup \sim B$
- **吸收律**：$A \cup (A \cap B) = A$，$A \cap (A \cup B) = A$
- **零律**：$A \cup U = U$，$A \cap \emptyset = \emptyset$
- **同一律**：$A \cup \emptyset = A$，$A \cap U = A$
- **排中律**：$A \cup \sim A = U$
- **矛盾律**：$A \cap \sim A = \emptyset$

## 例题

### 集合运算

设 $U=\{a,b,c,d,e\}, A=\{a,b,c\}, B=\{b,c,d\}, C=\{c,d,e\}$

1. $A \cap B^c = \{a\}$
2. $A \cap B$ 的补集 = $U - A = \{d,e\}$
3. $(A \cup C) - B = \{a,b,d\} - \{b,c,d\} = \{a\}$
4. $(A \oplus B) \oplus C = (\{a,d\} \oplus \{c,d,e\}) = \{a,c,e\}$

### 幂集计算

1. $A=\{a,b,c\}$，$|A|=3$，$|\mathcal{P}(A)|=2^3=8$
   
   $\mathcal{P}(A) = \{\emptyset, \{a\}, \{b\}, \{c\}, \{a,b\}, \{a,c\}, \{b,c\}, \{a,b,c\}\}$

2. $A=\{1,2\}$，$|\mathcal{P}(A)|=2^2=4$
   
   $\mathcal{P}(A) = \{\emptyset, \{1\}, \{2\}, \{1,2\}\}$

3. $A=\emptyset$，$|\mathcal{P}(A)|=2^0=1$
   
   $\mathcal{P}(A) = \{\emptyset\}$

4. $A=\{a\}$，$|\mathcal{P}(A)|=2^1=2$
   
   $\mathcal{P}(A) = \{\emptyset, \{a\}\}$

## 证明集合相等或包含

使用运算律进行等价变换，证明 $A=B$ 或 $A \subseteq B$。

常用技巧：$A-B = A \cap B^c$（将差运算转为交和补）
