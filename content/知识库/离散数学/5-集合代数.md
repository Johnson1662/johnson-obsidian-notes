# 集合代数

## 基本概念
- 元素与集合关系：属于（∈）、不属于（∉）
- 集合与集合关系：包含（⊆）、不包含、相等（=）

## 集合运算
### 并集（A∪B）
由属于A或属于B的元素组成。

### 交集（A∩B）
由A和B的公共元素组成。

### 差运算（A-B，相对补集）
由属于A但不属于B的元素组成。
- A-B = A∩B的补

### 绝对补集（~A或A的补集）
全集E减去A：~A = E-A

### 对称差（A⊕B）
由属于A但不属于B，或属于B但不属于A的元素组成。
- A⊕B = (A-B)∪(B-A)

### 幂集（P(A)）
由A的所有子集组成的集合。
- 若A有n个元素，则P(A)有2^n个元素
- P(A)的元素本身是集合（A的子集）

## 运算律
基本运算律（与命题逻辑类似）：
- 交换律：A∪B = B∪A，A∩B = B∩A
- 结合律：(A∪B)∪C = A∪(B∪C)，(A∩B)∩C = A∩(B∩C)
- 分配律：A∪(B∩C) = (A∪B)∩(A∪C)，A∩(B∪C) = (A∩B)∪(A∩C)
- 德摩根律：~(A∪B) = ~A∩~B，~(A∩B) = ~A∪~B
- 吸收律：A∪(A∩B) = A，A∩(A∪B) = A
- 零律：A∪E = E，A∩∅ = ∅
- 同一律：A∪∅ = A，A∩E = A
- 排中律：A∪~A = E
- 矛盾律：A∩~A = ∅

## 例题
### 集合运算
设E={a,b,c,d,e}, A={a,b,c}, B={b,c,d}, C={c,d,e}
1. A∩B的补 = {d}
2. A∩B的补（绝对补）= E-A = {d,e}
3. (A∪C)-B = {a,b,d}-{b,c,d} = {a}
4. (A⊕B)⊕C = ({a,d}⊕{c,d,e}) = {a,c,e}

### 幂集计算
1. A={a,b,c}，|A|=3，|P(A)|=2^3=8
   P(A) = {∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c}}
2. A={1,2}，|P(A)|=2^2=4
   P(A) = {∅, {1}, {2}, {1,2}}
3. A=∅，|P(A)|=2^0=1
   P(A) = {∅}
4. A={a}，|P(A)|=2^1=2
   P(A) = {∅, {a}}

## 证明集合相等或包含
使用运算律进行等价变换，证明A=B或A⊆B。

常用技巧：A-B = A∩~B（将差运算转为交和补）
