     3|## 基本概念
     4|- 元素与集合关系：属于（∈）、不属于（∉）
     5|- 集合与集合关系：包含（⊆）、不包含、相等（=）
     6|
     7|## 集合运算
     8|### 并集（$A$∪B）
     9|由属于A或属于B的元素组成。
    10|
    11|### 交集（$A$∩B）
    12|由A和B的公共元素组成。
    13|
    14|### 差运算（$A$-B，相对补集）
    15|由属于A但不属于B的元素组成。
    16|- $A$-B = $A$∩B的补
    17|
    18|### 绝对补集（~A或A的补集）
    19|全集E减去A：~$A$ = E-$A$
    20|
    21|### 对称差（$A$⊕B）
    22|由属于A但不属于B，或属于B但不属于A的元素组成。
    23|- $A$⊕B = ($A$-B)∪(B-$A$)
    24|
    25|### 幂集（$P$($A$)）
    26|由A的所有子集组成的集合。
    27|- 若A有n个元素，则P($A$)有2^n个元素
    28|- $P$($A$)的元素本身是集合（A的子集）
    29|
    30|## 运算律
    31|基本运算律（与命题逻辑类似）：
    32|- 交换律：$A$∪B = B∪$A$，$A$∩B = B∩$A$
    33|- 结合律：($A$∪B)∪C = $A$∪(B∪C)，($A$∩B)∩C = $A$∩(B∩C)
    34|- 分配律：$A$∪(B∩C) = ($A$∪B)∩($A$∪C)，$A$∩(B∪C) = ($A$∩B)∪($A$∩C)
    35|- 德摩根律：~($A$∪B) = ~$A$∩~B，~($A$∩B) = ~$A$∪~B
    36|- 吸收律：$A$∪($A$∩B) = $A$，$A$∩($A$∪B) = $A$
    37|- 零律：$A$∪E = E，$A$∩∅ = ∅
    38|- 同一律：$A$∪∅ = $A$，$A$∩E = $A$
    39|- 排中律：$A$∪~$A$ = E
    40|- 矛盾律：$A$∩~$A$ = ∅
    41|
    42|## 例题
    43|### 集合运算
    44|设E={a,b,c,d,e}, $A$={a,b,c}, B={b,c,d}, C={c,d,e}
    45|$1$. $A$∩B的补 = {d}
    46|2. $A$∩B的补（绝对补）= E-$A$ = {d,e}
    47|3. ($A$∪C)-B = {a,b,d}-{b,c,d} = {a}
    48|4. ($A$⊕B)⊕C = ({a,d}⊕{c,d,e}) = {a,c,e}
    49|
    50|### 幂集计算
    51|$1$. $A$={a,b,c}，|$A$|=3，|$P$($A$)|=2^3=8
    52|   $P$($A$) = {∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c}}
    53|2. $A$={$1$,2}，|$P$($A$)|=2^2=4
    54|   $P$($A$) = {∅, {$1$}, {2}, {$1$,2}}
    55|3. $A$=∅，|$P$($A$)|=2^$0$=$1$
    56|   $P$($A$) = {∅}
    57|4. $A$={a}，|$P$($A$)|=2^$1$=2
    58|   $P$($A$) = {∅, {a}}

    60|## 证明集合相等或包含
    61|使用运算律进行等价变换，证明A=B或A⊆B。
    62|
    63|常用技巧：$A$-B = $A$∩~B（将差运算转为交和补）
