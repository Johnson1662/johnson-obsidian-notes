# 3 命题逻辑推理理论

> 来源：B站合集 BV1kTsizDE4Q（高数叔·紫云老师）

---

## 一、推理的定义

设 $A$ 和 $B$ 是两个命题公式，当且仅当 **$A\to B$ 是重言式**时，称由 $A$ 可推出 $B$，或 $B$ 是 $A$ 的有效结论。

前提可以有多个：$A_1, A_2, \ldots, A_n \Rightarrow B$

## 二、推理的三种方法

1. **真值表法**：列出前提和结论的真值表，验证 $A\to B$ 是否恒为真。
2. **等值演算法**：用等值演算证明 $A\to B$ 是重言式。
3. **自然系统P中的推理规则证明** ⭐（考试重点）

## 三、推理规则（12条）

| #   | 名称              | 公式                                                                        |
| --- | --------------- | ------------------------------------------------------------------------- |
| 1   | **前提引入规则（P规则）** | 推理过程中随时引入前提                                                               |
| 2   | **结论引入规则（T规则）** | 已推出的结论可作为后续前提                                                             |
| 3   | **置换规则**        | 等值式可互相替换                                                                  |
| 4   | **假言推理规则**      | $A\to B,\; A \Rightarrow B$                                               |
| 5   | **拒取式规则**       | $A\to B,\; \lnot B \Rightarrow \lnot A$                                   |
| 6   | **析取三段论**       | $A\lor B,\; \lnot A \Rightarrow B$                                        |
| 7   | **合取引入规则**      | $A,\; B \Rightarrow A\land B$                                             |
| 8   | **化简规则**        | $A\land B \Rightarrow A$（或 $B$）                                           |
| 9   | **附加规则**        | $A$（或$B$） $\Rightarrow A\lor B$                                           |
| 10  | **构造性二难规则**     | $A\to B,\; C\to D,\; A\lor C \Rightarrow B \lor D$                        |
| 11  | **破坏性二难规则**     | $A\to B,\; C\to D,\; \lnot B\lor\lnot D \Rightarrow \lnot A\lor\lnot C$   |
| 12  | **假言三段论**       | $A\to B,\; B\to C \Rightarrow A\to C$                                     |
| 13  | **等价三段论**       | $A\leftrightarrow B,\; B\leftrightarrow C \Rightarrow A\leftrightarrow C$ |
| 14  | **归结式推理**       | $P\lor Q,\; \lnot P\lor R \Rightarrow Q\lor R$                            |

## 四、证明方法

### 1. 直接证明法

**例1**：前提 $P\lor Q,\; Q\to S,\; P\leftrightarrow R$，结论 $S\lor R$

| 步骤 | 公式 | 规则 |
|------|------|------|
| ① | $P\lor Q$ | 前提引入 |
| ② | $P\lor Q \Leftrightarrow \lnot P\to Q$ | ① 置换规则 |
| ③ | $Q\to S$ | 前提引入 |
| ④ | $\lnot P\to S$ | ②③ 假言三段论 |
| ⑤ | $P\leftrightarrow R$ | 前提引入 |
| ⑥ | $(P\to R)\land(R\to P)$ | ⑤ 等价等值式置换 |
| ⑦ | $P\to R$ | ⑥ 化简 |
| ⑧ | $\lnot S\to P$ | ④ 假言易位 |
| ⑨ | $\lnot S\to R$ | ⑧⑦ 假言三段论 |
| ⑩ | $S\lor R$ | ⑨ 蕴含等值式置换 |

**例2**：自然语言推理

前提：如果马会飞或羊吃草，则母鸡就会变飞鸟。如果母鸡变飞鸟，那么烤熟的鸭子还会跑。烤熟的鸭子不会跑。

结论：羊儿不吃草。

符号化：$P$:马会飞，$Q$:羊吃草，$R$:母鸡变飞鸟，$S$:烤熟的鸭子会跑

前提：① $(P\lor Q)\to R$　② $R\to S$　③ $\lnot S$
结论：$\lnot Q$

| 步骤 | 公式 | 规则 |
|------|------|------|
| ① | $\lnot S$ | 前提引入 |
| ② | $R\to S$ | 前提引入 |
| ③ | $\lnot R$ | ①② 拒取式 |
| ④ | $(P\lor Q)\to R$ | 前提引入 |
| ⑤ | $\lnot(P\lor Q)$ | ③④ 拒取式 |
| ⑥ | $\lnot P\land\lnot Q$ | ⑤ 置换·摩根律 |
| ⑦ | $\lnot Q$ | ⑥ 化简 |

### 2. 归谬法（反证法）

将结论的否定作为附加前提引入，推出矛盾。

**例**：用归谬法证明上题

| 步骤 | 公式 | 规则 |
|------|------|------|
| ① | $\lnot(\lnot Q)$ | 附加前提引入 |
| ② | $Q$ | ① 置换·双否定律 |
| ③ | $P\lor Q$ | ② 附加规则 |
| ④ | $(P\lor Q)\to R$ | 前提引入 |
| ⑤ | $R$ | ③④ 假言推理 |
| ⑥ | $R\to S$ | 前提引入 |
| ⑦ | $S$ | ⑤⑥ 假言推理 |
| ⑧ | $\lnot S$ | 前提引入 |
| ⑨ | $S\land\lnot S$ | ⑦⑧ 合取引入（矛盾） |

矛盾，故原结论 $\lnot Q$ 成立。

### 3. 附加前提证明法（CP规则）

> [!def] 当结论是蕴含式 $S\to R$ 时，可将前件 $S$ 作为**附加前提**引入，然后证明 $R$ 成立。

**例**：前提：① $(P\land Q)\to R$　② $\lnot S\lor P$　③ $Q$，结论：$S\to R$

| 步骤 | 公式 | 规则 |
|------|------|------|
| ① | $S$ | **附加前提引入** |
| ② | $\lnot S\lor P$ | 前提引入 |
| ③ | $P$ | ①② 析取三段论 |
| ④ | $Q$ | 前提引入 |
| ⑤ | $P\land Q$ | ③④ 合取引入 |
| ⑥ | $(P\land Q)\to R$ | 前提引入 |
| ⑦ | $R$ | ⑤⑥ 假言推理 |

结论 $S\to R$ 得证 ✅
