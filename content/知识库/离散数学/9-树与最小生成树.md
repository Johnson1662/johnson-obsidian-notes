# 树与最小生成树

## 树的定义
连通且无回路的无向图称为树。
两个要点：连通、无回路

- 树枝：树中的边
- 树叶：度数为1的节点
- 分支节点（内点）：度数大于1的节点
- 森林：不连通，但每个连通分支都是树的图

## 树的性质
对于树T，若顶点数为n，边数为m，则：
**n = m + 1**
（3个顶点的树有2条边，4个顶点的树有3条边...）

## 例题
树T有2个2度顶点，2个3度顶点，1个4度顶点，其余为树叶。求阶数n、边数m、树叶数t。
解：由握手定理，总度数=2m
总度数 = 2×2 + 2×3 + 1×4 + 1×t = 14 + t
又 m = n - 1，且 n = 2+2+1+t = 5+t
所以 14+t = 2(n-1) = 2(5+t-1) = 8+2t
解得 t=6，n=11，m=10

## 最小生成树
图G的所有生成树中，带权最小的称为最小生成树。

### 避圈法（Kruskal算法）
步骤：
1. 将图G的所有边按权值从小到大排序
2. 依次选取权最小的边加入，保证不形成回路
3. 重复直到有n-1条边（n个顶点）

例：求下图G的最小生成树
边权排序：5,5,8,8,9,9,10,10...
- 加边ab(5)，无回路
- 加边ae(5)，无回路
- 加边ed(8)，无回路
- 加边bc(9)，无回路（已有4条边，n=5，完成）
最小生成树权值：5+5+8+9=27

### 破圈法
步骤：
1. 在图G中找一个圈
2. 删除该圈中权最大的边
3. 重复直到无圈（剩n-1条边）

## 最优二元树（Huffman树）
二元树：除树叶外，每个分支节点度数均为2。
最优二元树：带权路径长度（WPL）最小的二元树。

### Huffman算法
1. 将权值按从小到大排序
2. 取两个最小的权值，构造新节点（权值为两者之和）
3. 将新节点权值加入序列，删除已用的两个权值
4. 重复直到只剩一个节点

例：求带权为3,4,5,8,9的最优二元树
1. 排序：3,4,5,8,9
2. 取3,4 → 新节点7，序列：5,7,8,9
3. 取5,7 → 新节点12，序列：8,9,12
4. 取8,9 → 新节点17，序列：12,17
5. 取12,17 → 新节点29，完成
WPL计算：各叶子权值×路径长度之和
