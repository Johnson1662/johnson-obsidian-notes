## 2.1 SQL概述

### 2.1.1 SQL的发展历史

**SQL**（Structured Query Language）是一种介于关系代数和关系演算之间的语言，满足关系数据库的定义、操作和管理需求。

| SQL版本 | 发布时间 | 主要特性 |
|--------|----------|----------|
| SQL-86/89 | 1986/1989 | 第一版标准 |
| SQL-92 | 1992 | 大幅改进，兼容性增强 |
| SQL:1999 | 1999 | 加入面向对象特性 |
| SQL:2003 | 2003 | 引入XML支持 |
| SQL:2008 | 2008 | 增强索引和分区 |
| SQL:2011 | 2011 | 时间数据类型 |
| SQL:2016 | 2016 | JSON支持，行模式匹配 |

### 2.1.2 SQL的组成

SQL = **DDL** + **DML** + **DQL** + **DCL** + **TCL**

| 组成 | 全称 | 作用 | 关键字 |
|------|--------|------|--------|
| DDL | Data Definition Language | 数据定义 | CREATE, DROP, ALTER |
| DML | Data Manipulation Language | 数据操作 | INSERT, UPDATE, DELETE |
| DQL | Data Query Language | 数据查询 | SELECT |
| DCL | Data Control Language | 数据控制 | GRANT, REVOKE |
| TCL | Transaction Control Language | 事务控制 | COMMIT, ROLLBACK |

### 2.1.3 SQL的特点

1. **综合统一**：集数据定义、操作、查询、控制于一体
2. **非过程化**：用户只要说明"做什么"，不用说明"怎么做"
   - 课程代表名为'数据库'的学分 = 95
   - 而不是：先找到课程表，再找学分列，再更新
3. **面向集合的操作方式**：操作对象和结果都是元组的集合
4. **语法简洁，易学易用**：语义明确，接近自然语言

### 2.1.4 SQL的分类

| 类别 | 内容 | 是否独立 |
|--------|------|--------|
| 自立使用 | DDL, DML | 是 |
| 嵌入使用 | DQL, DML、DCL | 和主语言结合 |

## 2.2 数据定义语言（DDL）

### 2.2.1 模式与表的操作

#### 1. 创建模式
```sql
CREATE SCHEMA 模式名 AUTHORIZATION 用户名;
```

**示例**：
```sql
CREATE SCHEMA S_T AUTHORIZATION WANG;
```

#### 2. 删除模式
```sql
DROP SCHEMA 模式名 [CASCADE | RESTRICT];
```
- **CASCADE**：级联删除，同时删除模式中的所有对象
- **RESTRICT**：若模式中定义了对象，则拒绝删除（默认）

#### 3. 创建基本表
```sql
CREATE TABLE 表名 (
    列名1 数据类型 [列级完整性约束],
    列名2 数据类型 [列级完整性约束],
    ...,
    [表级完整性约束]
);
```

**数据类型**：

| 类型 | 描述 | 示例 |
|--------|------|------|
| 数值型 | INT, SMALLINT | 整数 |
| | DECIMAL(p,s), NUMERIC(p,s) | 定点数 |
| | FLOAT, REAL | 浮点数 |
| 字符串 | CHAR(n), VARCHAR(n) | 定长/变长字符串 |
| | CLOB | 字符大对象 |
| 日期时间 | DATE, TIME, TIMESTAMP | 日期/时间 |

**完整性约束**：

```sql
-- 主码约束
CREATE TABLE Student (
    Sno CHAR(9) PRIMARY KEY,        -- 列级主码
    Sname VARCHAR(20) NOT NULL,     -- 非空约束
    Sage INT,
    Ssex CHAR(2)
);

-- 外码约束
CREATE TABLE SC (
    Sno CHAR(9),
    Cno CHAR(4),
    Grade SMALLINT,
    PRIMARY KEY (Sno, Cno),          -- 表级复合主码
    FOREIGN KEY (Sno) REFERENCES Student(Sno)  -- 外码
);
```

#### 4. 修改表结构
```sql
ALTER TABLE 表名
    ADD 列名 数据类型 [完整性约束],
    DROP 列名 [CASCADE | RESTRICT],
    ALTER COLUMN 列名 数据类型;
```

#### 5. 删除表
```sql
DROP TABLE 表名 [CASCADE | RESTRICT];
```

### 2.2.2 索引的创建与删除

**索引的作用**：提高查询速度、保证数据唯一性

```sql
-- 创建索引
CREATE [UNIQUE] [CLUSTER] INDEX 索引名
ON 表名 (列名 [ASC | DESC] [, ...]);

-- 示例
CREATE UNIQUE INDEX Stusno ON Student(Sno);
CREATE CLUSTER INDEX Coucno ON SC(Cno DESC);

-- 删除索引
DROP INDEX 索引名;
```

**索引类型**：
- **唯一索引**：UNIQUE，保证列值唯一
- **聚簇索引**：CLUSTER，物理上按索引列排序存储
- **装置索引**：在基本表数据文件外立一个索引表

## 2.3 数据查询语言（DQL）

### 2.3.1 SELECT语句基本结构

```sql
SELECT [ALL | DISTINCT] <目标表达式列表>
FROM <表名或视图名列表>
[WHERE <表达式>]
[GROUP BY <列名1> [HAVING <表达式>]]
[ORDER BY <列名2> [ASC | DESC]];
```

**执行顺序**：
1. FROM - 确定数据来源
2. WHERE - 行级筛选
3. GROUP BY - 分组
4. HAVING - 组级筛选
5. SELECT - 列级筛选和计算
6. ORDER BY - 排序
7. LIMIT - 限制结果

### 2.3.2 单表查询

**选择所有列**：
```sql
SELECT * FROM Student;
```

**选择部分列**：
```sql
SELECT Sno, Sname FROM Student;
```

**列别名**：
```sql
SELECT Sname NAME, 'Year of Birth' BIRTH, 2014-Sage BIRTHDAY
FROM Student;
```

### 2.3.3 条件查询（WHERE）

**比较条件**：
```sql
SELECT Sname, Sage
FROM Student
WHERE Sage < 20;
```

**范围条件** [BETWEEN...AND...]：
```sql
SELECT *
FROM Student
WHERE Sage BETWEEN 20 AND 23;
-- 等价于：WHERE Sage >= 20 AND Sage <= 23
```

**集合条件** [IN]：
```sql
SELECT Sname, Ssex
FROM Student
WHERE Sdept IN ('CS', 'IS', 'MA');
```

**字符串匹配** [LIKE]：
- `%`：匹配任意长度的字符串（包括0个）
- `_`：匹配单个字符

```sql
-- 查找姓名为'李'的学生
SELECT * FROM Student WHERE Sname LIKE '李%';

-- 查找姓名第二字为'阳'的学生
SELECT * FROM Student WHERE Sname LIKE '_阳%';

-- 查找姓名中含有'华'字的学生
SELECT * FROM Student WHERE Sname LIKE '%华%';

-- 转义字符 ESCAPE
SELECT * FROM Course WHERE Cname LIKE 'DB\_Design' ESCAPE '\';
```

**空值判断** [IS NULL]：
```sql
SELECT Sname
FROM Student
WHERE Sno IS NULL;  -- 不能用 = NULL
```

**复合条件**：
```sql
SELECT *
FROM Student
WHERE (Sdept = 'CS' AND Sage < 20)
   OR Sdept = 'IS';
```

### 2.3.4 排序查询（ORDER BY）

```sql
SELECT Sno, Grade
FROM SC
WHERE Cno = '3'
ORDER BY Grade DESC;  -- 降序

-- 多列排序
SELECT * FROM Student
ORDER BY Sdept ASC, Sage DESC;
```

### 2.3.5 聚合函数

| 函数 | 功能 | 示例 |
|--------|------|------|
| COUNT | 计数 | COUNT(*) 或 COUNT(列名) |
| SUM | 求和 | SUM(Grade) |
| AVG | 求平均 | AVG(Grade) |
| MAX | 最大值 | MAX(Grade) |
| MIN | 最小值 | MIN(Grade) |

**示例**：
```sql
-- 统计学生总数
SELECT COUNT(*) FROM Student;

-- 统计选课的学生人数
SELECT COUNT(DISTINCT Sno) FROM SC;

-- 计算平均成绩
SELECT AVG(Grade) FROM SC WHERE Cno = '1';

-- 查询最高分
SELECT MAX(Grade) FROM SC WHERE Cno = '1';
```

**GROUP BY子句**：
```sql
SELECT Sno, COUNT(*)
FROM SC
GROUP BY Sno;

SELECT Cno, COUNT(Sno)
FROM SC
GROUP BY Cno;

-- 复合分组
SELECT Sno, Cno, COUNT(*)
FROM SC
GROUP BY Sno, Cno;
```

**HAVING子句**：
```sql
-- 查询选修了3门以上课程的学生
SELECT Sno
FROM SC
GROUP BY Sno
HAVING COUNT(*) > 3;

-- WHERE vs HAVING
-- WHERE先执行，HAVING后执行
-- WHERE不能用聚合函数，HAVING可以
SELECT Sdept, AVG(Sage)
FROM Student
WHERE Sdept IN ('CS', 'IS')  -- 行级筛选
GROUP BY Sdept
HAVING AVG(Sage) < 20;        -- 组级筛选
```

## 2.4 多表查询

### 2.4.1 连接查询

#### 1. 等值连接
```sql
SELECT Student.*, SC.*
FROM Student, SC
WHERE Student.Sno = SC.Sno;
```

**为表取别名**：
```sql
SELECT S.Sno, S.Sname, S.Ssex, S.Sage, S.Sdept, C.Cno, C.Grade
FROM Student S, SC C
WHERE S.Sno = C.Sno;
```

#### 2. 自然连接
```sql
-- 内连接（INNER JOIN）
SELECT S.Sno, S.Sname, C.Cno, C.Grade
FROM Student S
INNER JOIN SC C ON S.Sno = C.Sno;

-- 左外连接（LEFT JOIN）
SELECT S.Sno, S.Sname, C.Cno, C.Grade
FROM Student S
LEFT JOIN SC C ON S.Sno = C.Sno;

-- 右外连接（RIGHT JOIN）
SELECT S.Sno, S.Sname, C.Cno, C.Grade
FROM Student S
RIGHT JOIN SC C ON S.Sno = C.Sno;

-- 全外连接（FULL JOIN）
SELECT S.Sno, S.Sname, C.Cno, C.Grade
FROM Student S
FULL JOIN SC C ON S.Sno = C.Sno;
```

#### 3. 自连接
```sql
-- 查找每个学生的同学
SELECT S1.Sno, S1.Sname, S2.Sno, S2.Sname
FROM Student S1, Student S2
WHERE S1.Sdept = S2.Sdept AND S1.Sno < S2.Sno;
```

### 2.4.2 嵌套查询

#### 1. 带IN调前量词
```sql
-- 查询与"刘老"同一系的学生
SELECT Sno, Sname, Sdept
FROM Student
WHERE Sdept IN (
    SELECT Sdept
    FROM Student
    WHERE Sname LIKE '刘%'
);
```

#### 2. 带比较调前量词
```sql
-- 查询选课号1课程成绩大于90分的学生
SELECT Sno, Sname
FROM Student
WHERE Sno IN (
    SELECT Sno
    FROM SC
    WHERE Cno = '1' AND Grade > 90
);
```

#### 3. 带EXISTS调前量词
```sql
-- 查询所有选课的学生
SELECT Sname
FROM Student S
WHERE EXISTS (
    SELECT *
    FROM SC
    WHERE Sno = S.Sno
);

-- 查询未选课的学生
SELECT Sname
FROM Student S
WHERE NOT EXISTS (
    SELECT *
    FROM SC
    WHERE Sno = S.Sno
);
```

#### 4. 带ANY/SOME调前量词
```sql
-- 查询成绩比课程1任一学生成绩高的学生
SELECT Sno, Grade
FROM SC
WHERE Cno = '2' AND Grade > ANY (
    SELECT Grade
    FROM SC
    WHERE Cno = '1'
);
```

#### 5. 带ALL调前量词
```sql
-- 查询成绩比课程1所有学生成绩都高的学生
SELECT Sno, Grade
FROM SC
WHERE Cno = '2' AND Grade > ALL (
    SELECT Grade
    FROM SC
    WHERE Cno = '1'
);
```

### 2.4.3 集合查询

```sql
-- 查询计算系的学生或年龄小于20岁的学生
SELECT *
FROM Student
WHERE Sdept = 'CS'
UNION
SELECT *
FROM Student
WHERE Sage < 20;

-- 查询既选课1又选课2的学生
SELECT Sno
FROM SC
WHERE Cno = '1'
INTERSECT
SELECT Sno
FROM SC
WHERE Cno = '2';

-- 查询选课1但不选课2的学生
SELECT Sno
FROM SC
WHERE Cno = '1'
EXCEPT
SELECT Sno
FROM SC
WHERE Cno = '2';
```

## 2.5 数据更新（DML）

### 2.5.1 插入数据（INSERT）

```sql
-- 插入完整学生信息
INSERT INTO Student (Sno, Sname, Ssex, Sage, Sdept)
VALUES ('201215121', '李小明', '男', 20, 'CS');

-- 插入部分列
INSERT INTO Student (Sno, Sname, Sdept)
VALUES ('201215122', '刘大华', 'IS');

-- 插入多行
INSERT INTO Student
VALUES 
    ('201215123', '王小东', '男', 19, 'MA'),
    ('201215124', '张小红', '女', 21, 'CS');

-- 子查询插入
INSERT INTO SC (Sno, Cno, Grade)
SELECT '201215121', Cno, 0
FROM Course
WHERE Cpno IS NULL;
```

### 2.5.2 修改数据（UPDATE）

```sql
-- 修改单个学生的年龄
UPDATE Student
SET Sage = 22
WHERE Sno = '201215121';

-- 修改多个列
UPDATE Student
SET Sage = 21, Sdept = 'IS'
WHERE Sno = '201215121';

-- 批量修改
UPDATE SC
SET Grade = Grade * 1.1
WHERE Cno = '1' AND Grade < 60;
```

### 2.5.3 删除数据（DELETE）

```sql
-- 删除单个学生
DELETE FROM Student
WHERE Sno = '201215121';

-- 删除所有选课记录
DELETE FROM SC;

-- 带子查询删除
DELETE FROM SC
WHERE Sno IN (
    SELECT Sno
    FROM Student
    WHERE Sdept = 'CS'
);
```

## 2.6 视图（View）

### 2.6.1 视图的定义与创建

```sql
-- 创建视图
CREATE VIEW StudentScore AS
SELECT S.Sno, S.Sname, C.Cname, SC.Grade
FROM Student S
JOIN SC ON S.Sno = SC.Sno
JOIN Course C ON SC.Cno = C.Cno;

-- 带条件的视图
CREATE VIEW CS_Student AS
SELECT Sno, Sname, Sage
FROM Student
WHERE Sdept = 'CS'
WITH CHECK OPTION;  -- 添加的数据必须满足条件
```

### 2.6.2 视图的查询

```sql
-- 查询视图
SELECT * FROM StudentScore WHERE Cname = '数据库';

-- 在视图上再定义视图
CREATE VIEW VM1 AS
SELECT Sno, AVG(Grade) Avg_Grade
FROM StudentScore
GROUP BY Sno;
```

### 2.6.3 更新视图

```sql
-- 可更新视图的修改
UPDATE StudentScore
SET Grade = 95
WHERE Sno = '201215121' AND Cname = '数据库';
```

### 2.6.4 删除视图

```sql
DROP VIEW StudentScore CASCADE;
```

## 2.7 完整性约束

### 2.7.1 主码约束（PRIMARY KEY）

```sql
CREATE TABLE Student (
    Sno CHAR(9) PRIMARY KEY,
    Sname VARCHAR(20) NOT NULL,
    Ssex CHAR(2),
    Sage INT,
    Sdept VARCHAR(20)
);

-- 复合主码
CREATE TABLE SC (
    Sno CHAR(9) NOT NULL,
    Cno CHAR(4) NOT NULL,
    Grade SMALLINT,
    PRIMARY KEY (Sno, Cno)
);
```

### 2.7.2 外码约束（FOREIGN KEY）

```sql
CREATE TABLE SC (
    Sno CHAR(9) NOT NULL,
    Cno CHAR(4) NOT NULL,
    Grade SMALLINT,
    PRIMARY KEY (Sno, Cno),
    FOREIGN KEY (Sno) REFERENCES Student(Sno),
    FOREIGN KEY (Cno) REFERENCES Course(Cno)
);
```

**参照动作**：
```sql
FOREIGN KEY (Sno) REFERENCES Student(Sno)
    ON DELETE CASCADE      -- 级联删除
    ON UPDATE CASCADE;     -- 级联更新

FOREIGN KEY (Sno) REFERENCES Student(Sno)
    ON DELETE SET NULL      -- 设置为空
    ON UPDATE NO ACTION;    -- 拒绝更新
```

### 2.7.3 属性约束

```sql
CREATE TABLE Student (
    Sno CHAR(9) PRIMARY KEY,
    Sname VARCHAR(20) NOT NULL,           -- 非空约束
    Ssex CHAR(2) DEFAULT '男',          -- 默认值
    Sage INT CHECK (Sage BETWEEN 15 AND 45),  -- CHECK约束
    Sdept VARCHAR(20)
);
```

### 2.7.4 全局约束

```sql
CREATE TABLE SC (
    Sno CHAR(9),
    Cno CHAR(4),
    Grade SMALLINT,
    PRIMARY KEY (Sno, Cno),
    FOREIGN KEY (Sno) REFERENCES Student(Sno),
    FOREIGN KEY (Cno) REFERENCES Course(Cno),
    CHECK (Grade >= 0 AND Grade <= 100)  -- 全局CHECK约束
);
```

**查询约束信息**：
```sql
SELECT CONSTRAINT_NAME, TABLE_NAME, COLUMN_NAME
FROM INFORMATION_SCHEMA.KEY_COLUMN_USAGE
WHERE TABLE_NAME = 'Student';
```

## 2.8 事务与并发事务

### 2.8.1 事务的概念

**ACID特性**：
- **A**tomicity（原子性）：事务是一个不可分割的工作单元
- **C**onsistency（一致性）：事务必须使数据库从一个一致状态变换到另一个一致状态
- **I**solation（隔离性）：一个事务的执行不受其他事务干扰
- **D**urability（持久性）：事务一旦提交，对数据的改变就是永久的

### 2.8.2 SQL事务控制

```sql
-- 开始事务
BEGIN TRANSACTION;
-- 或 START TRANSACTION;

-- 执行SQL操作
INSERT INTO Account VALUES ('A-101', '1000.00');
UPDATE Account SET balance = balance - 50 WHERE account = 'A-101';
UPDATE Account SET balance = balance + 50 WHERE account = 'A-102';

-- 提交事务
COMMIT;

-- 回滚事务
ROLLBACK;
```

### 2.8.3 事务事务级别

| 隔离级别 | 丢失修改 | 脏读 | 不可重复读 | 幻读 |
|--------|----------|------|------------|------|
| READ UNCOMMITTED | 可能 | 可能 | 可能 | 可能 |
| READ COMMITTED | 不可能 | 不可能 | 可能 | 可能 |
| REPEATABLE READ | 不可能 | 不可能 | 不可能 | 可能 |
| SERIALIZABLE | 不可能 | 不可能 | 不可能 | 不可能 |

**设置隔离级别**：
```sql
SET TRANSACTION ISOLATION LEVEL READ COMMITTED;
```

### 2.8.4 并发控制问题

**并发操作带来的问题**：

1. **丢失修改**（Lost Update）
   - 两个事务同时读取并修改同一数据值
   - 后提交的覆盖先提交的，造成数据丢失

2. **不可重复读**（Non-repeatable Read）
   - 事务T1读取数据后，T2修改该数据并提交
   - T1再次读取得到不同结果

3. **读"脏"数据**（Dirty Read）
   - T1修改数据未提交，T2读取该数据
   - T1回滚，T2读到了"不存在"的数据

4. **幻读**（Phantom Read）
   - T1按条件读取记录后，T2插入/删除满足条件的记录
   - T1再次读取，记录数不同

### 2.8.5 锁协议

**封锁**（Locking）是实现并发控制的主要技术。

| 锁类型 | 说明 |
|--------|------|
| 共享锁（S锁） | 允许多个事务同时读取数据 |
| 排他锁（X锁） | 禁止其他事务读取或修改数据 |

**二阶段锁协议**：
- 读数据前加S锁，读完即可释放
- 写数据前加X锁，写完才释放
- 防止丢失修改和读"脏"数据
