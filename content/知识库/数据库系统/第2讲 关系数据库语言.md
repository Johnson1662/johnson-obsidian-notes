# 第2讲 关系数据库语言

## 第一部分：关系代数

### 什么是代数？

**代数（Algebra）**由**运算符**和**操作数**构成。

- **操作数**：变量（如 x）和常量（如 15）
- **运算符**：加法、减法、乘法、除法等
- **表达式**：将运算符应用于操作数和/或其他表达式
  - 例如：$(x + y) \times z$

### 关系代数概述

关系代数是关系模型的数据操作部分，以**关系**为输入输出。

**原子操作数：**

- **变量**：代表关系
- **常量**：有限关系

**主要操作：**

1. **集合操作**：并（Union）、交（Intersection）、差（Difference）
2. **移除部分元组/列的操作**：选择（Selection）、投影（Projection）
3. **组合两个关系的操作**：笛卡尔积（Cartesian Product）、连接（Join）
4. **重命名（Renaming）**

> SQL 的核心正是基于关系代数构建的。

### 为什么需要专门的查询语言？

关系代数虽然不如 C 或 Java 强大（例如无法判断关系中元组个数是否为奇数），但带来两大好处：

- **编程简单**：声明式查询，无需描述"怎么做"
- **优化空间大**：编译器可生成高度优化的执行代码

### 集合操作

关系上的集合操作要求参与操作的两个关系 **R 和 S** 满足：

- 模式（Schema）具有相同属性集
- 每个属性的类型（域）相同
- 属性顺序相同

| 操作               | 符号       | 含义                                           |
| ------------------ | ---------- | ---------------------------------------------- |
| 并（Union）        | $R \cup S$ | 在 R 或 S 中（或两者中）的元组，重复只保留一次 |
| 交（Intersection） | $R \cap S$ | 同时在 R 和 S 中的元组                         |
| 差（Difference）   | $R - S$    | 在 R 中但不在 S 中的元组                       |

**示例：** 设关系 R 和 S 如下：

| name          | address                  | gender | birthdate |
| ------------- | ------------------------ | ------ | --------- |
| Carrie Fisher | 123 Maple St., Hollywood | F      | 9/9/99    |
| Mark Hamill   | 456 Oak Rd., Brentwood   | M      | 8/8/88    |

| name          | address                     | gender | birthdate |
| ------------- | --------------------------- | ------ | --------- |
| Carrie Fisher | 123 Maple St., Hollywood    | F      | 9/9/99    |
| Harrison Ford | 789 Palm Dr., Beverly Hills | M      | 7/7/77    |

**并 $R \cup S$：**

| name          | address                     | gender | birthdate |
| ------------- | --------------------------- | ------ | --------- |
| Carrie Fisher | 123 Maple St., Hollywood    | F      | 9/9/99    |
| Mark Hamill   | 456 Oak Rd., Brentwood      | M      | 8/8/88    |
| Harrison Ford | 789 Palm Dr., Beverly Hills | M      | 7/7/77    |

**交 $R \cap S$：**

| name          | address                  | gender | birthdate |
| ------------- | ------------------------ | ------ | --------- |
| Carrie Fisher | 123 Maple St., Hollywood | F      | 9/9/99    |

**差 $R - S$：**

| name        | address                | gender | birthdate |
| ----------- | ---------------------- | ------ | --------- |
| Mark Hamill | 456 Oak Rd., Brentwood | M      | 8/8/88    |

**对应 SQL：**

```sql
-- 并
(SELECT * FROM R) UNION (SELECT * FROM S);

-- 交
(SELECT * FROM R) INTERSECT (SELECT * FROM S);

-- 差
(SELECT * FROM R) EXCEPT (SELECT * FROM S);
```

### 投影（Projection）

从关系 R 中选取部分列，生成新关系。

$$\pi_{A_1, A_2, ..., A_n}(R)$$

- 结果关系只包含 R 中属性 $\{A_1, A_2, ..., A_n\}$ 对应的列
- 关系代数中自动去除重复元组

**示例：** 对 Movies 关系投影 title、year、length 三列：

```sql
SELECT title, year, length FROM movies;

-- 若需去重（关系代数默认去重）：
SELECT DISTINCT title, year, length FROM movies;
```

---

### 选择（Selection）

从关系 R 中选取满足条件的元组，生成新关系。

$$\sigma_C(R) = \{t \mid t \in R \land C(t) = \mathrm{true}\}$$

- 结果关系的模式与 R 相同
- C 是涉及 R 属性的条件

**示例：** 选取片长 ≥ 100 分钟且制片厂为 Fox 的电影：

```sql
SELECT * FROM movies WHERE length >= 100 AND studioName = 'Fox';
```

**关系代数：**
$$\sigma_{\mathrm{length} \geq 100 \ \mathrm{AND}\ \mathrm{studioName} = 'Fox'}(\mathrm{Movies})$$

---

### 笛卡尔积（Cartesian Product）

$$R \times S$$

- 从 R 选一个元组、从 S 选一个元组，组成结果中的一个元组
- 结果关系的模式是 R 和 S 模式的并集
- 若 R 有 m 个元组，S 有 n 个元组，则结果有 $m \times n$ 个元组

**示例：**

R：

| A   | B   |
| --- | --- |
| 1   | 2   |
| 3   | 4   |

S：

| B   | C   | D   |
| --- | --- | --- |
| 2   | 5   | 6   |
| 4   | 7   | 8   |
| 9   | 10  | 11  |

$R \times S$：

| A   | R.B | S.B | C   | D   |
| --- | --- | --- | --- | --- |
| 1   | 2   | 2   | 5   | 6   |
| 1   | 2   | 4   | 7   | 8   |
| 1   | 2   | 9   | 10  | 11  |
| 3   | 4   | 2   | 5   | 6   |
| 3   | 4   | 4   | 7   | 8   |
| 3   | 4   | 9   | 10  | 11  |

**对应 SQL：**

```sql
SELECT * FROM R CROSS JOIN S;
SELECT * FROM R, S;  -- 旧式写法，不推荐
```

---

### 自然连接（Natural Join）

$$R \bowtie S$$

- 设 $A_1, A_2, ..., A_n$ 为 R 和 S 的共同属性
- 元组 r（来自 R）和元组 s（来自 S）**可成功配对**当且仅当两者在所有共同属性上取值相同
- 结果元组包含 R 和 S 模式并集的每个属性各一个

**示例：**

U：

| A   | B   | C   |
| --- | --- | --- |
| 1   | 2   | 3   |
| 6   | 7   | 8   |
| 9   | 7   | 8   |

V：

| B   | C   | D   |
| --- | --- | --- |
| 2   | 3   | 4   |
| 2   | 3   | 5   |
| 7   | 8   | 10  |

$U \bowtie v$：

| A   | B   | C   | D   |
| --- | --- | --- | --- |
| 1   | 2   | 3   | 4   |
| 1   | 2   | 3   | 5   |
| 6   | 7   | 8   | 10  |
| 9   | 7   | 8   | 10  |

**对应 SQL：**

```sql
SELECT * FROM U NATURAL JOIN V;
```

> **悬空元组（Dangling Tuple）**：在连接中无法与另一关系的任何元组配对的元组。

---

### θ-连接（Theta-Join）

θ-连接先用条件 C 做选择，再做笛卡尔积：

$$R \bowtie_C S = \sigma_C(R \times S)$$

**示例：** $U \bowtie_{A < D} V$

```sql
SELECT * FROM U INNER JOIN V ON A < D;
```

**示例：** $U \bowtie_{A < D \ \mathrm{AND}\ U.B \neq V.B} V$

```sql
SELECT * FROM U INNER JOIN V ON A < D WHERE U.B <> V.B;
```

---

### 重命名（Renaming）

$$\rho_{S(A_1, A_2, ..., A_n)}(R)$$

- 将关系 R 重命名为 S，属性重命名为 $A_1, A_2, ..., A_n$
- 元组内容不变

仅重命名关系（保留原属性名）：
$$\rho_S(R)$$

**用途：** 解决自连接等场景中属性名冲突的问题。

---

### 操作间的关系

某些操作可以用其他操作表示：

- $R \cap S = R - (R - S)$
- $R \bowtie_C S = \sigma_C(R \times S)$
- $R \bowtie S = \pi_L(\sigma_C(R \times S))$（其中 C 是共同属性相等的条件，L 是去重后的属性列表）

其余六个操作 **并、差、选择、投影、笛卡尔积、重命名** 相互独立，无法互相表示。

---

### 组合操作构造查询

关系代数操作可以嵌套，将前一操作的结果作为后一操作的输入。

**示例：** 查找 Fox 制片厂制作且片长至少 100 分钟的电影名称和年份。

**分步：**

1. 选择片长 ≥ 100 的 Movies 元组
2. 选择制片厂为 'Fox' 的 Movies 元组
3. 求 (1) 和 (2) 的交集
4. 对 (3) 投影 title 和 year

**关系代数表达式：**
$$\pi_{\mathrm{title, year}}(\sigma_{\mathrm{length} \geq 100 \ \mathrm{AND}\ \mathrm{studioName} = 'Fox'}(\mathrm{Movies}))$$

**对应 SQL：**

```sql
SELECT title, year
FROM Movies
WHERE length >= 100 AND studioName = 'Fox';
```

---

### 线性表示法

可以用赋值语句风格书写关系代数：

$$
\begin{array}{l}
R := \sigma_{\mathrm{length} \geq 100}(\mathrm{Movies}) \\
S := \sigma_{\mathrm{studioName} = 'Fox'}(\mathrm{Movies}) \\
T := R \cap S \\
\mathrm{Answer}(\mathrm{title, year}) := \pi_{\mathrm{title, year}}(T)
\end{array}
$$

### 基本查询：SELECT-FROM-WHERE

```sql
SELECT <列列表>
FROM <关系列表>
WHERE <条件>;
```

对应关系代数：$\pi_L(\sigma_C(R))$

- **FROM**：查询涉及的关系
- **WHERE**：元组必须满足的条件
- **SELECT**：结果中包含哪些属性

**示例：**

```sql
SELECT *
FROM Movies
WHERE studioName = 'Disney' AND year = 1990;
```

---

### 模式匹配（LIKE）

- `%` 匹配任意长度（包括零长度）的任意字符串
- `_` 匹配单个任意字符

**示例：**

```sql
-- 搜索以 "Star" 开头的电影
SELECT title FROM Movies WHERE title LIKE 'Star%';

-- 搜索标题中包含 's 的电影（如所有格）
SELECT title FROM Movies WHERE title LIKE '%''s%';
```

> 如果模式本身包含 `%` 或 `_`，使用 ESCAPE 指定转义字符：
>
> ```sql
> SELECT ... WHERE s LIKE 'x%%x%' ESCAPE 'x';  -- 匹配以 % 开头和结尾的字符串
> ```

### 日期与时间

```sql
DATE '1984-05-14'            -- 日期常量
TIME '15:00:02.5'           -- 时间常量
TIME '12:00:00-8:00'       -- 带时区（太平洋标准时间）
TIMESTAMP '1984-05-14 12:00:00'  -- 日期+时间
```

可使用 `<`, `>` 等比较日期和时间。

### 空值（NULL）

**NULL 的三种含义：**

- **值未知**：如未知的出生日期
- **值不适用**：如未婚演员的配偶属性
- **值被隐藏**：如未列出的电话号码

**涉及 NULL 的规则：**

1. 对 NULL 使用算术运算符（如 `+`, `*`），结果仍为 NULL
2. 对 NULL 使用比较运算符（如 `=`, `>`），结果为 **UNKNOWN**
3. NULL 不是常量，不能写作 `NULL = 3`（错误！）

**正确判断 NULL 的方式：**

```sql
x IS NULL      -- 如果 x 为 NULL，返回 TRUE
x IS NOT NULL -- 如果 x 不为 NULL，返回 TRUE
```

---

### 三值逻辑（TRUE / FALSE / UNKNOWN）

| x       | y       | x AND y | x OR y  | NOT x   |
| ------- | ------- | ------- | ------- | ------- |
| TRUE    | TRUE    | TRUE    | TRUE    | FALSE   |
| TRUE    | UNKNOWN | UNKNOWN | TRUE    | FALSE   |
| TRUE    | FALSE   | FALSE   | TRUE    | FALSE   |
| UNKNOWN | TRUE    | UNKNOWN | TRUE    | UNKNOWN |
| UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |
| UNKNOWN | FALSE   | FALSE   | UNKNOWN | UNKNOWN |
| FALSE   | TRUE    | FALSE   | TRUE    | TRUE    |
| FALSE   | UNKNOWN | FALSE   | UNKNOWN | TRUE    |
| FALSE   | FALSE   | FALSE   | FALSE   | TRUE    |

> **注意：** `WHERE length <= 120 OR length > 120` 不会返回 length 为 NULL 的元组——因为条件评估为 UNKNOWN，不满足 WHERE 子句。

### 结果排序（ORDER BY）

```sql
SELECT *
FROM Movies
WHERE studioName = 'Disney' AND year = 1990
ORDER BY length, title;  -- 默认升序
```

- `DESC`：降序
- `ASC`：升序（默认，可省略）
- 排序在 FROM、WHERE 等子句之后、SELECT 之前执行

### 多关系查询（连接）

**示例：** 查找《Star Wars》的制片人姓名。

```sql
SELECT name
FROM Movies, MovieExec
WHERE title = 'Star Wars' AND producerC# = cert#;
```

**使用元组变量（避免同名关系冲突）：**

```sql
-- 查找住在同一地址的两位明星
SELECT Star1.name, Star2.name
FROM MovieStar Star1, MovieStar Star2
WHERE Star1.address = Star2.address
  AND Star1.name < Star2.name;
```

对应关系代数：先做笛卡尔积，再做选择，最后投影。

### 子查询（Subquery）

子查询是嵌套在其他查询中的查询。

#### 返回标量的子查询

**示例：** 查找《Star Wars》的制片人姓名。

```sql
SELECT name
FROM MovieExec
WHERE cert# = (
    SELECT producerC#
    FROM Movies
    WHERE title = 'Star Wars'
);
```

#### 返回关系的子查询条件

| 操作符      | 含义                                    |
| ----------- | --------------------------------------- |
| `EXISTS R`  | R 非空时为 TRUE                         |
| `s IN R`    | s 等于 R 中某个值时为真（R 为一元关系） |
| `s > ALL R` | s 大于 R 中所有值                       |
| `s > ANY R` | s 大于 R 中至少一个值                   |

**等价关系：**

|     | =   | <>     | <    | <=    | >    | >=    |
| --- | --- | ------ | ---- | ----- | ---- | ----- |
| ANY | IN  | --     | <MAX | <=MAX | >MIN | >=MIN |
| ALL | --  | NOT IN | <MIN | <=MIN | >MAX | >=MAX |

> `NOT s >= ALL R` ≡ s 不是 R 中的最大值
> `NOT s > ANY R` ≡ s 是 R 中的最小值

**示例：** 查找 Harrison Ford 出演过的电影的制片人。

```sql
SELECT name
FROM MovieExec
WHERE cert# IN (
    SELECT producerC#
    FROM Movies
    WHERE (title, year) IN (
        SELECT movieTitle, movieYear
        FROM StarsIn
        WHERE starName = 'Harrison Ford'
    )
);
```

**等价写法（多关系查询）：**

```sql
SELECT DISTINCT name
FROM MovieExec, Movies, StarsIn
WHERE cert# = producerC#
  AND title = movieTitle
  AND year = movieYear
  AND starName = 'Harrison Ford';
```

#### 相关子查询（Correlated Subquery）

子查询的执行依赖于外层查询的当前元组，需多次求值。

**示例：** 查找被用作两个以上电影名称的标题。

```sql
SELECT title
FROM Movies Old
WHERE year < ANY (
    SELECT year
    FROM Movies
    WHERE title = Old.title
);
```

#### FROM 子句中的子查询

```sql
SELECT name
FROM MovieExec, (
    SELECT producerC#
    FROM Movies, StarsIn
    WHERE title = movieTitle
      AND year = movieYear
      AND starName = 'Harrison Ford'
) Prod
WHERE cert# = Prod.producerC#;
```

### 分组与聚合

#### 聚合操作符

| 操作符                | 含义               |
| --------------------- | ------------------ |
| `SUM`                 | 数值列求和         |
| `AVG`                 | 数值列求平均       |
| `MIN`                 | 最小值             |
| `MAX`                 | 最大值             |
| `COUNT`               | 计数（不自动去重） |
| `COUNT(DISTINCT col)` | 去重计数           |

**示例：**

```sql
-- 电影制片人的平均净资产
SELECT AVG(netWorth) FROM MovieExec;

-- StarsIn 中的元组数
SELECT COUNT(*) FROM StarsIn;

-- StarsIn 中不重复的明星数
SELECT COUNT(DISTINCT starName) FROM StarsIn;
```

> **注意：** NULL 值会被聚合操作符忽略（COUNT(\*) 除外，它统计元组数而非列值）。

#### GROUP BY 分组

按分组属性的值将元组划分为若干组，聚合操作在每组内分别执行。

**示例：** 计算每个制片厂的所有电影片长总和。

```sql
SELECT studioName, SUM(length)
FROM Movies
GROUP BY studioName;
```

**SELECT 子句规则：**

- 要么出现 `GROUP BY` 中的分组属性
- 要么是对其他列应用的聚合函数

```sql
-- 正确
SELECT studioName, SUM(length) FROM Movies GROUP BY studioName;

-- 等价于（无聚合时）
SELECT DISTINCT studioName FROM Movies;
```

#### HAVING 子句

在分组后筛选组（基于组的聚合属性）。

**示例：** 只输出至少制作过一部 1930 年之前电影的制片人的总片长。

```sql
SELECT name, SUM(length)
FROM MovieExec, Movies
WHERE producerC# = cert#
GROUP BY name
HAVING MIN(year) < 1930;
```

**HAVING 规则：**

1. HAVING 中的聚合只应用于当前组的元组
2. 只有 GROUP BY 列表中的属性可以不加聚合地出现在 HAVING 中

### 数据更新

#### 插入（INSERT）

```sql
-- 指定列插入
INSERT INTO StarsIn(movieTitle, movieYear, starName)
VALUES('The Maltese Falcon', 1942, 'Sydney Greenstreet');

-- 省略列名（需提供所有列的值）
INSERT INTO StarsIn
VALUES('The Maltese Falcon', 1942, 'Sydney Greenstreet');

-- 用子查询插入
INSERT INTO Studio(name)
SELECT DISTINCT studioName
FROM Movies
WHERE studioName NOT IN (SELECT name FROM Studio);
```

#### 删除（DELETE）

```sql
-- 删除符合条件的元组
DELETE FROM StarsIn
WHERE movieTitle = 'The Maltese Falcon'
  AND movieYear = 1942
  AND starName = 'Sydney Greenstreet';

-- 清空关系（删除所有元组）
DELETE FROM StarsIn;
```

#### 更新（UPDATE）

```sql
-- 更新符合条件的元组
UPDATE MovieExec
SET name = 'Pres. ' || name
WHERE cert# IN (SELECT presC# FROM Studio);
```
