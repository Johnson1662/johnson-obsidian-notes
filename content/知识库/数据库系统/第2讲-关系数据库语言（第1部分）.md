## 关系代数

### 什么是关系代数？

**关系代数**是关系模型的数据操作方面，用于查询和修改数据。它是一个关于关系的代数系统，输入和输出都是关系。

### 为什么需要专门的查询语言？

关系代数比C或Java等通用编程语言功能更弱，但这带来了两个巨大优势：
1. **编程简便性**：更容易编写查询
2. **优化能力**：编译器可以生成高度优化的代码

### 什么是代数？

**代数**由运算符和原子操作数组成。例如：
- **算术代数**：原子操作数是变量（如x）和常量（如15），运算符是加减乘除
- **表达式**：将运算符应用于原子操作数和其他表达式，如`(x + y) * z`

### 关系代数概述

#### 原子操作数
1. **变量**：代表关系
2. **常量**：有限关系

#### 运算类型
1. **集合运算**：并、交、差
2. **去除关系部分的运算**：选择、投影
3. **组合两个关系元组的运算**：笛卡尔积、连接
4. **重命名运算**

#### 查询
查询是关系代数的表达式。

## SQL简介

### SQL发音

### SQL是什么？
SQL是**结构化查询语言**（Structured Query Language），包含：
- **DML**（数据操作语言）
- **DDL**（数据定义语言）

- **ANSI SQL1986**：第一个标准
- **SQL-92（SQL2）**：重要更新
- **SQL-99（SQL3）**：引入更多特性
- **SQL:2003**：后续版本

## 集合运算

### 并运算（Union）
- **符号**：R∪S
- **含义**：在R中或在S中或同时在两者中的元素
- **特点**：如果在R和S中都出现，在并集中只出现一次

### 交运算（Intersection）
- **符号**：R∩S
- **含义**：同时在R和S中的元素

### 差运算（Difference）
- **符号**：R－S
- **含义**：在R中但不在S中的元素

### 集合运算的条件
对关系R和S进行集合运算需要满足：
1. R和S的模式必须有相同的属性集
2. 每个属性的类型（域）在R和S中必须相同
3. R和S的列必须排序，使属性顺序相同

### 示例

假设有两个关系：
- **关系R**：包含name和address属性
- **关系S**：包含gender和birthdate属性

由于R和S的属性不同，不能直接进行集合运算。需要先通过投影等操作使它们具有相同的属性集。

## 关系代数的核心运算

### 1. 选择运算（Selection）
- **符号**：σ_cond(R)
- **含义**：从关系R中选择满足条件cond的元组
- **示例**：σ_genre='drama'(Movies) 选择所有戏剧类型的电影

### 2. 投影运算（Projection）
- **符号**：π_attrs(R)
- **含义**：从关系R中选取指定的属性列
- **示例**：π_title,year(Movies) 选取电影的标题和年份

### 3. 笛卡尔积（Cartesian Product）
- **符号**：R×S
- **含义**：将R中的每个元组与S中的每个元组组合
- **示例**：Movies×StarsIn 生成电影和出演关系的所有组合

### 4. 连接运算（Join）
- **符号**：R⋈_cond S
- **含义**：根据条件cond连接两个关系
- **示例**：Movies⋈_{Movies.title=StarsIn.movieTitle} StarsIn

## 关系代数表达式示例

### 示例1：查询所有戏剧电影的标题
```
π_title(σ_genre='drama'(Movies))
```

### 示例2：查询1990年后上映的电影标题和年份
```
π_title,year(σ_year>1990(Movies))
```

### 示例3：查询出演了"Star Wars"的演员姓名
```
π_starName(σ_movieTitle='Star Wars'(StarsIn))
```

## SQL基础

### SQL查询的基本结构
```sql
SELECT 属性列表
FROM 关系列表
WHERE 条件
```

### 示例
```sql
-- 查询所有戏剧电影的标题
SELECT title
FROM movies
WHERE genre = 'drama';

-- 查询1990年后上映的电影标题和年份
SELECT title, year
FROM movies
WHERE year > 1990;

-- 查询出演了"Star Wars"的演员姓名
SELECT starname
FROM starsin
WHERE movietitle = 'Star Wars';
```

## 关系代数与SQL的关系

关系代数是SQL的理论基础：
1. **选择运算**对应SQL的WHERE子句
2. **投影运算**对应SQL的SELECT子句
3. **连接运算**对应SQL的JOIN操作
4. **集合运算**对应SQL的UNION、INTERSECT、EXCEPT

## 学习建议

对于初学者，建议：
1. **先掌握关系代数的基本概念**：理解集合运算、选择、投影等基本运算
2. **通过具体例子理解抽象概念**：使用电影数据库的例子来练习
3. **对比关系代数和SQL**：理解它们之间的对应关系
4. **多做练习**：编写关系代数表达式和SQL查询

> [!tip] 实践建议
> 建议在数据库系统中实际执行本讲中的SQL示例，观察查询结果，这样能更好地理解关系代数运算的实际效果。

## 关键概念总结

1. **关系代数**：关系模型的数据操作语言，是SQL的理论基础
2. **集合运算**：并、交、差，要求关系具有相同的属性集
3. **选择运算**：按条件选择元组
4. **投影运算**：选择特定的属性列
5. **连接运算**：组合两个关系的元组
6. **SQL**：结构化查询语言，是实际数据库系统的标准语言
