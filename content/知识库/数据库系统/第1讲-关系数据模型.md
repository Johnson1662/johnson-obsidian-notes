## 数据与数据库

### 数据（Data）
数据是数据库存储的基本对象，包括：
- 数字（number）
- 文本（text）
- 图形（graph）
- 图像（image）
- 音频（audio）
- 视频（video）

### 数据的语义
数据与其语义是不可分的。例如数字 "93"：
- 某门课的成绩
- 某个人的体重
- 计算机系学生人数

### 信息
**信息** = 带有语义的数据

### 有组织的数据示例

一条记录：`(张三, 男, 20020510, 天津市, 计算机, 2022)`

语义：学籍系统中的一条学生记录
- 姓名：张三
- 性别：男
- 出生日期：2002年5月10日
- 居住地：天津市
- 所在系：计算机
- 入学年份：2022

### 数据库（Database）

**数据库**（Database，简称DB）是：
- 长期存储在计算机内
- 有组织的
- 可共享的
- 数据的集合

### 数据库管理系统（DBMS）

**数据库管理系统**（DataBase Management System，DBMS）是：
- 位于用户与操作系统之间的一层数据管理软件
- 系统软件
- 大型复杂的软件系统

**功能**：数据定义、数据存储、数据操作、数据控制、事务管理、数据库维护...

```
应用程序
   ↓
  DBMS
   ↓
操作系统
   ↓
  硬件
```

### 数据库系统

**数据库系统**（Database System）是针对某种应用而开发的信息管理系统。

**构成**：
- 数据库（DB）
- DBMS
- 应用程序
- 数据库管理员（DBA）

**典型的数据库系统**：
- 银行交易系统
- 人力资源管理系统
- 电子购物系统

## 关系数据模型

### 什么是数据模型？

**数据模型**是描述数据或信息的记法，由三个部分组成：

1. **数据的结构**
2. **数据的操作**
3. **数据的约束**

### 重要数据模型
- **关系模型**：最重要的数据模型
- **对象-关系扩展**
- **图数据模型**：RDF、属性图
- **其他数据模型**：层次模型、网状模型、XML模型、面向对象模型

### 关系模型简介

#### 关系（Relation）

关系是二维表格。例如电影关系 **Movies**：

| title | year | length | genre |
|-------|------|--------|-------|
| Gone With the Wind | 1939 | 231 | drama |
| Star Wars | 1977 | 124 | sciFi |
| Wayne's World | 1992 | 95 | comedy |

#### 属性（Attributes）

属性是关系的列名，描述列中条目的含义。例如 Movies 表的属性：title, year, length, genre

#### 模式（Schemas）

模式是关系名及其属性的集合。例如：
- `Movies(title, year, length, genre)`

#### 元组（Tuple）

元组是关系的一行。例如：
- `(Gone With the Wind, 1939, 231, drama)`
- `(Star Wars, 1977, 124, sciFi)`

#### 域（Domain）

域是与关系每个属性关联的基本类型。例如：
- `Movies(title:string, year:integer, length:integer, genre:string)`

### 关系的键

#### 键约束

键是关系属性的集合，关系实例中没有两个元组在键的所有属性上具有相同的值。

#### 示例

Movies 表的键是 (title, year)，因为：
- 同一部电影可能在不同年份翻拍（如 King Kong 有1933年版、1976年版、2005年版）
- 所以需要 title + year 才能唯一确定一部电影

## 电影示例数据库

### 完整数据库模式

```sql
-- 电影表
Movies (
    title:string,        -- 电影标题
    year:integer,        -- 上映年份
    length:integer,      -- 时长（分钟）
    genre:string,        -- 类型
    studioName:string,   -- 制片厂名称
    producerC#:integer   -- 制片人证书号
)

-- 演员表
MovieStar (
    name:string,         -- 演员姓名
    address:string,      -- 地址
    gender:char,         -- 性别
    birthdate:date       -- 出生日期
)

-- 出演表
StarsIn (
    movieTitle:string,   -- 电影标题
    movieYear:integer,   -- 电影年份
    starName:string      -- 演员姓名
)

-- 导演表
MovieExec (
    name:string,         -- 导演姓名
    address:string,      -- 地址
    cert#:integer,       -- 证书号（主键）
    netWorth:integer     -- 净资产
)

-- 制片厂表
Studio (
    name:string,         -- 制片厂名称（主键）
    address:string,      -- 地址
    presC#:integer       -- 总裁证书号
)
```

## SQL语言

### SQL简介

SQL（发音为"sequel"）是描述和操作关系数据库的主要语言，有两个方面：

1. **数据定义语言（DDL）**：声明数据库模式
2. **数据操作语言（DML）**：查询和修改数据库

### 表声明示例

```sql
-- 创建导演表
CREATE TABLE movieexec (
    name CHAR(30),
    address VARCHAR(255),
    cert INT PRIMARY KEY,
    networth INT
);

-- 创建制片厂表
CREATE TABLE studio (
    name CHAR(50) PRIMARY KEY,
    address VARCHAR(255),
    presc INT,
    FOREIGN KEY (presc) REFERENCES movieexec(cert)
);

-- 创建电影表
CREATE TABLE movies (
    title CHAR(100),
    year INT,
    length INT,
    genre CHAR(10),
    studioname CHAR(30),
    producerc INT,
    PRIMARY KEY (title, year),
    FOREIGN KEY (studioname) REFERENCES studio(name),
    FOREIGN KEY (producerc) REFERENCES movieexec(cert)
);

-- 创建演员表
CREATE TABLE moviestar (
    name CHAR(30),
    address VARCHAR(255),
    gender CHAR(1),
    birthdate CHAR(10),
    PRIMARY KEY (name)
);

-- 创建出演表
CREATE TABLE starsin (
    movietitle CHAR(100),
    movieyear INT,
    starname CHAR(30),
    PRIMARY KEY (movietitle, movieyear, starname),
    FOREIGN KEY (movietitle, movieyear) REFERENCES movies(title, year),
    FOREIGN KEY (starname) REFERENCES moviestar(name)
);
```

## 数据类型

### 字符串类型
- `CHAR(n)`：固定长度字符串
- `VARCHAR(n)`：可变长度字符串

### 位串类型
- `BIT(n)`：固定长度位串
- `BIT VARYING(n)`：可变长度位串

### 逻辑类型
- `BOOLEAN`：TRUE, FALSE, UNKNOWN

### 整数类型
- `INT` 或 `INTEGER`
- `SMALLINT`

### 浮点数类型
- `FLOAT` 或 `REAL`
- `DOUBLE PRECISION`
- `DECIMAL(n, d)`：定点数
  - n位十进制数字
  - 小数点从右数d位
  - 例如：0123.45 类型为 DECIMAL(6, 2)
- `NUMERIC`：DECIMAL的同义词

### 日期和时间类型
- `DATE`：例如 `DATE '1948-05-14'`
- `TIME`：例如 `TIME '15:00:02.5'`

## 修改关系模式

### 删除关系
```sql
DROP TABLE R;
```

### 修改关系
```sql
-- 添加属性
ALTER TABLE MovieStar ADD phone CHAR(16);

-- 删除属性
ALTER TABLE MovieStar DROP birthdate;
```

### 默认值
```sql
-- 定义默认值
gender CHAR(1) DEFAULT '?',
birthdate DATE DEFAULT DATE '0000-00-00'

-- 添加属性时设置默认值
ALTER TABLE MovieStar ADD phone CHAR(16) DEFAULT 'unlisted';
```

## 关键概念总结

1. **数据库**：长期存储在计算机内、有组织的、可共享的数据集合
2. **DBMS**：位于用户与操作系统之间的一层数据管理软件
3. **数据库系统**：包括数据库、DBMS、应用程序和数据库管理员
4. **关系模型**：最重要的数据模型，由关系、属性、元组等概念组成
5. **SQL**：关系数据库的标准语言，包括DDL和DML

## 学习建议

对于初学者，建议：
1. 先理解数据库的基本概念，不要急于深入技术细节
2. 通过实际的例子来理解关系模型的概念
3. 多练习SQL语句，特别是CREATE TABLE和INSERT语句
4. 理解主键和外键的概念，这是关系数据库的核心
5. 了解数据库的发展历史，有助于理解当前技术的由来
