# 第1讲 关系数据模型

## 1. 数据库与DBMS

### 1.1 数据（Data）

数据是数据库存储的基本对象，常见的数据形式包括：

- **数字**（number）
- **文本**（text）
- **图形**（graph）
- **图像**（image）
- **音频**（audio）
- **视频**（video）

**数据的语义**：数据与其语义是不可分的。例如 `93` 可以是某门课的成绩、某个人的体重，或计算机系学生人数。

**有组织的数据示例**：

> (张三, 男, 20020510, 天津市, 计算机, 2022)
>
> 语义：学籍系统中的一条学生记录
> 含义：姓名, 性别, 出生日期, 居住地, 所在系, 入学年份

---

### 1.2 数据库（Database）

**数据库（Database，简称DB）**：长期存储在计算机内、**有组织的**、**可共享的**数据的集合。

---

### 1.3 数据库管理系统（DBMS）

**数据库管理系统（DBMS）**：位于用户与操作系统之间的一层数据管理软件。

- DBMS 是系统软件，也是大型复杂的软件系统
- **功能**：数据定义、数据存储、数据操作、数据控制、事务管理、数据库维护…

```
应用程序
   ↓
  DBMS
   ↓
操作系统
   ↓
 硬件
```

---

### 1.4 数据库系统（Database System）

针对某种应用而开发的信息管理系统（Information Management Systems）。

**构成**：

- 数据库（DB）
- 数据库管理系统（DBMS）
- 应用程序
- 数据库管理员（DBA）

**典型数据库系统**：银行交易系统、人力资源管理系统、电子购物系统…

## 2. DBMS 的诞生

### 2.1 三大标志性事件

| 事件          | 年份 | 贡献         |
| ------------- | ---- | ------------ |
| IMS 系统      | 1966 | 层次数据模型 |
| DBTG 报告     | 1969 | 网状数据模型 |
| Codd 发表论文 | 1970 | 关系数据模型 |

### 2.2 IMS 系统

**IMS（Information Management System）**：IBM 公司为阿波罗登月计划设计。

- 1968 年 8 月 14 日发布
- **挑战**：如何有效存储和管理土星 5 号运载火箭和阿波罗太空飞船所产生的大量数据清单？
- **贡献**：提出**层次数据模型**

### 2.3 DBTG 报告

- 1969 年 10 月，CODASYL 下属的数据库任务小组（Data Base Task Group，DBTG）发布技术报告
- **目的**：给 COBOL 语言增加数据处理能力
- **贡献**：提出**网状数据模型**

### 2.4 Codd 与关系模型

1970 年，IBM San Jose 实验室研究员 **E. F. Codd** 发表论文：

> _"A Relational Model of Data for Large Shared Data Banks"_
> 《大型共享数据库的关系数据模型》

**核心观点**：

- 当时流行的层次模型和网状模型混淆了：
  - 信息逻辑结构的描述
  - 物理存取方法的描述
- **贡献**：提出了**关系数据模型**，使数据以其自然结构描述，不叠加任何额外的机器表示结构

## 3. 事务处理（Transaction Processing）

**事务（Transaction）**：一组一个或多个数据库操作，作为一个原子单元执行（all-or-nothing）。

**ACID 特性**：

| 特性   | 英文        | 说明                                 |
| ------ | ----------- | ------------------------------------ |
| 原子性 | Atomicity   | 事务要么全部执行，要么全部不执行     |
| 一致性 | Consistency | 事务执行前后数据库保持一致状态       |
| 隔离性 | Isolation   | 并发执行的事务相互隔离，如同串行执行 |
| 持久性 | Durability  | 已完成事务的工作永远不会丢失         |

## 5. 关系数据模型（Relational Data Model）

### 5.1 什么是数据模型

**数据模型（Data Model）**：描述数据或信息的符号表示。

由三部分构成：

| 组成部分                | 说明         |
| ----------------------- | ------------ |
| **结构**（Structure）   | 数据的结构   |
| **操作**（Operations）  | 对数据的操作 |
| **约束**（Constraints） | 对数据的约束 |

**重要数据模型**：

| 模型                               | 说明                                       |
| ---------------------------------- | ------------------------------------------ |
| 关系模型（Relational Model）       | 本课程重点                                 |
| 对象-关系扩展（Object-relational） | —                                          |
| 图数据模型（Graph）                | RDF、属性图（Property Graph）              |
| 其他                               | 层次模型、网状模型、XML 模型、面向对象模型 |

---

### 5.2 关系模型简介

关系模型中的**关系（Relation）**类似于二维表，类似于 C 语言中的结构体数组。

**示例：Movies 关系**

| title              | year | length | genre  |
| ------------------ | ---- | ------ | ------ |
| Gone With the Wind | 1939 | 231    | drama  |
| Star Wars          | 1977 | 124    | sciFi  |
| Wayne's World      | 1992 | 95     | comedy |

**核心概念**：

| 概念 | 英文       | 说明                                                                          |
| ---- | ---------- | ----------------------------------------------------------------------------- |
| 关系 | Relation   | 二维表                                                                        |
| 属性 | Attributes | 列名，描述列中条目的含义                                                      |
| 模式 | Schema     | 关系名及其属性列表，如 `Movies(title, year, length, genre)`                   |
| 元组 | Tuple      | 关系中的一行，每个属性有一个分量，如 `(Gone With the Wind, 1939, 231, drama)` |
| 域   | Domain     | 与每个属性关联的特定基本类型，如 `title:string, year:integer`                 |

**关系数据库模式（Relational Database Schema）**：数据库中所有关系的模式集合。

---

### 5.3 关系的键（Keys of Relations）

**键（Key）**：关系的一组属性，满足：关系中任意两个元组在键的所有属性上取值不同。

- 键约束是最基本的约束之一
- 一个关系可能有多个候选键，通常选择一个作为**主键**（Primary Key）

**示例数据库模式**：

| 关系      | 模式                                                                                                | 中文   |
| --------- | --------------------------------------------------------------------------------------------------- | ------ |
| Movies    | `(title:string, year:integer, length:integer, genre:string, studioName:string, producerC#:integer)` | 电影   |
| MovieStar | `(name:string, address:string, gender:char, birthdate:date)`                                        | 演员   |
| StarsIn   | `(movieTitle:string, movieYear:integer, starName:string)`                                           | 出演   |
| MovieExec | `(name:string, address:string, cert#:integer, netWorth:integer)`                                    | 导演   |
| Studio    | `(name:string, address:string, presC#:integer)`                                                     | 制片厂 |

## 6. SQL 查询语言

### 6.1 SQL 概述

**SQL**（读作 "sequel"）：用于描述和操作关系数据库的主要语言。

**两个方面**：

- **数据定义语言（DDL）**：声明数据库模式
- **数据操作语言（DML）**：查询和修改数据库

---

### 6.2 建表（CREATE TABLE）

```sql
CREATE TABLE movieexec (
    name CHAR(30),
    address VARCHAR(255),
    cert INT PRIMARY KEY,  -- 主键
    networth INT
);
```

```sql
CREATE TABLE studio (
    name CHAR(50) PRIMARY KEY,  -- 主键
    address VARCHAR(255),
    presc INT,
    FOREIGN KEY (presc) REFERENCES movieexec(cert)  -- 外键
);
```

```sql
CREATE TABLE movies (
    title CHAR(100),
    year INT,
    length INT,
    genre CHAR(10),
    studioname CHAR(30),
    producerc INT,
    PRIMARY KEY (title, year),  -- 实体完整性
    FOREIGN KEY (studioname) REFERENCES studio(name),
    FOREIGN KEY (producerc) REFERENCES movieexec(cert)  -- 参照完整性
);
```

```sql
CREATE TABLE moviestar (
    name CHAR(30),
    address VARCHAR(255),
    gender CHAR(1),
    birthdate CHAR(10),
    PRIMARY KEY (name)
);
```

```sql
CREATE TABLE starsin (
    movietitle CHAR(100),
    movieyear INT,
    starname CHAR(30),
    PRIMARY KEY (movietitle, movieyear, starname),
    FOREIGN KEY (movietitle, movieyear) REFERENCES movies(title, year),
    FOREIGN KEY (starname) REFERENCES moviestar(name)
);
```

### 6.4 查询示例（SELECT）

```sql
-- 查询 Disney 在 1990 年出品的所有电影，按时长和标题排序
SELECT *
FROM movies
WHERE studioname = 'Disney' AND year = 1990
ORDER BY length, title;
```

## 7. 数据类型（Data Types）

| 类型类别     | SQL 类型                    | 说明                                                               |
| ------------ | --------------------------- | ------------------------------------------------------------------ |
| **字符串**   | `CHAR(n)`                   | 定长字符串                                                         |
|              | `VARCHAR(n)`                | 变长字符串                                                         |
| **位串**     | `BIT(n)`                    | 定长位串                                                           |
|              | `BIT VARYING(n)`            | 变长位串                                                           |
| **布尔值**   | `BOOLEAN`                   | TRUE, FALSE, UNKNOWN                                               |
| **整数**     | `INT` / `INTEGER`           | 整数                                                               |
|              | `SMALLINT`                  | 短整数                                                             |
| **浮点数**   | `FLOAT` / `REAL`            | 单精度浮点                                                         |
|              | `DOUBLE PRECISION`          | 双精度浮点                                                         |
| **定点数**   | `DECIMAL(n, d)` / `NUMERIC` | n 位十进制数，小数点在右数第 d 位，如 `0123.45` 为 `DECIMAL(6, 2)` |
| **日期时间** | `DATE`                      | 日期，如 `'1948-05-14'`                                            |
|              | `TIME`                      | 时间，如 `'15:00:02.5'`                                            |

> 日期和时间本质上是特殊形式的字符串。
