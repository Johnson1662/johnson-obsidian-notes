## 1. 关系数据库语言概述

### 1.1 什么是关系数据库语言

**关系数据库语言**是用于与关系数据库进行交互的语言，主要用于对数据库进行**查询**、**定义**、**操纵**和**控制**。它是用户与数据库管理系统（DBMS）之间的桥梁。

> **核心特征**：
> - **非过程化**：用户只需说明"做什么"，无需说明"怎么做"
> - **集合操作**：以集合为单位进行操作
> - **一体化**：数据定义、操纵、控制功能集成在同一个语言中

### 1.2 SQL简介

**SQL**（Structured Query Language，结构化查询语言）是关系数据库的标准语言，也是最广泛使用的关系数据库语言。

| 版本 | 发布时间 | 主要特性 |
|------|----------|----------|
| SQL-86 | 1986年 | ANSI标准的第一版 |
| SQL-89 | 1989年 | 小的修订 |
| SQL-92 | 1992年 | 重大修订，引入完整性约束、事务等 |
| SQL:1999 | 1999年 | 引入触发器、面向对象特性 |
| SQL:2003 | 2003年 | 引入XML支持、序列、窗口函数 |
| SQL:2011 | 2011年 | 时态数据库支持 |
| SQL:2016 | 2016年 | 行模式匹配、JSON支持 |

**SQL的主要特点**：

1. **综合统一**：集数据定义（DDL）、操纵（DML）、控制（DCL）于一体
2. **高度非过程化**：无需指定存取路径
3. **面向集合的操作方式**：操作对象和结果都是元组的集合
4. **以同一种语法结构提供多种使用方式**：既可独立使用，也可嵌入到高级语言中
5. **语言简洁，易学易用**：核心动词少（SELECT、CREATE、DROP等）

## 2. SQL的数据定义功能（DDL）

### 2.1 模式（Schema）定义

**模式**是一组数据库对象的集合，相当于一个命名空间。

```sql
-- 创建模式
CREATE SCHEMA "S-T" AUTHORIZATION WANG;

-- 创建模式并创建表
CREATE SCHEMA "S-T" AUTHORIZATION WANG
    CREATE TABLE Student (
        Sno CHAR(9) PRIMARY KEY,
        Sname CHAR(20) NOT NULL,
        Ssex CHAR(2),
        Sage SMALLINT,
        Sdept CHAR(20)
    );

-- 删除模式
DROP SCHEMA "S-T" CASCADE;  -- 级联删除，包含其中所有对象
DROP SCHEMA "S-T" RESTRICT; -- 受限删除，仅当模式中无对象时删除
```

### 2.2 基本表的定义、删除与修改

#### 2.2.1 定义基本表

```sql
CREATE TABLE Student (
    Sno CHAR(9) PRIMARY KEY,              -- 学号，主键
    Sname CHAR(20) UNIQUE NOT NULL,       -- 姓名，唯一且非空
    Ssex CHAR(2) DEFAULT '男',            -- 性别，默认值为'男'
    Sage SMALLINT CHECK (Sage >= 15 AND Sage <= 45),  -- 年龄检查约束
    Sdept CHAR(20)
);

CREATE TABLE Course (
    Cno CHAR(4) PRIMARY KEY,              -- 课程号
    Cname CHAR(40) NOT NULL,              -- 课程名
    Cpno CHAR(4),                         -- 先修课程
    Ccredit SMALLINT,
    FOREIGN KEY (Cpno) REFERENCES Course(Cno)  -- 外键约束
);

CREATE TABLE SC (
    Sno CHAR(9),
    Cno CHAR(4),
    Grade SMALLINT CHECK (Grade >= 0 AND Grade <= 100),  -- 成绩检查约束
    PRIMARY KEY (Sno, Cno),               -- 复合主键
    FOREIGN KEY (Sno) REFERENCES Student(Sno),
    FOREIGN KEY (Cno) REFERENCES Course(Cno)
);
```

#### 2.2.2 数据类型

| 类型 | 说明 | 示例 |
|------|------|------|
| CHAR(n) | 定长字符串 | CHAR(10) |
| VARCHAR(n) | 变长字符串 | VARCHAR(20) |
| INT / INTEGER | 整数 | INT |
| SMALLINT | 短整数 | SMALLINT |
| NUMERIC(p,s) | 定点数 | NUMERIC(6,2) |
| DECIMAL(p,s) | 定点数 | DECIMAL(6,2) |
| FLOAT(n) | 浮点数 | FLOAT |
| DATE | 日期 | DATE |
| TIME | 时间 | TIME |
| TIMESTAMP | 时间戳 | TIMESTAMP |

#### 2.2.3 修改基本表

```sql
-- 增加列
ALTER TABLE Student ADD S_entrance DATE;

-- 修改列的数据类型
ALTER TABLE Student ALTER COLUMN Sage INT;

-- 删除列
ALTER TABLE Student DROP COLUMN S_entrance;

-- 增加约束
ALTER TABLE Student ADD UNIQUE (Sname);

-- 删除约束
ALTER TABLE Student DROP CONSTRAINT constraint_name;
```

#### 2.2.4 删除基本表

```sql
DROP TABLE Student CASCADE;   -- 级联删除，相关依赖一并删除
DROP TABLE Student RESTRICT;  -- 受限删除，仅当无依赖时删除
```

### 2.3 索引的建立与删除

**索引**用于提高查询效率，类似于书的目录。

```sql
-- 创建索引
CREATE UNIQUE INDEX Stusno ON Student(Sno);      -- 唯一索引
CREATE UNIQUE INDEX Coucno ON Course(Cno);       -- 唯一索引
CREATE INDEX SCno ON SC(Cno ASC, Sno DESC);      -- 复合索引

-- 删除索引
DROP INDEX Stusno;
DROP INDEX SCno;
```

## 3. SQL的数据查询功能（DQL）

### 3.1 单表查询

#### 3.1.1 基本查询

```sql
-- 查询指定列
SELECT Sno, Sname FROM Student;

-- 查询所有列
SELECT * FROM Student;

-- 查询经过计算的值
SELECT Sname, 2024 - Sage AS BirthYear FROM Student;

-- 使用别名
SELECT Sname 姓名, Sage 年龄 FROM Student;
```

#### 3.1.2 条件查询

```sql
-- 比较条件
SELECT Sname, Sage FROM Student WHERE Sage >= 20 AND Sage <= 23;
SELECT Sname, Sdept FROM Student WHERE Sdept = '计算机系';

-- 范围条件
SELECT Sname, Sage FROM Student WHERE Sage BETWEEN 20 AND 23;
SELECT Sname, Sage FROM Student WHERE Sage NOT BETWEEN 20 AND 23;

-- 集合条件
SELECT Sname, Sdept FROM Student WHERE Sdept IN ('计算机系', '信息系', '数学系');
SELECT Sname, Sdept FROM Student WHERE Sdept NOT IN ('计算机系', '信息系', '数学系');

-- 字符匹配
SELECT * FROM Student WHERE Sname LIKE '刘%';
SELECT * FROM Student WHERE Sname LIKE '%阳%';
SELECT * FROM Student WHERE Sname LIKE '_毅%';

-- 空值判断
SELECT Sname FROM Student WHERE Grade IS NULL;
SELECT Sname FROM Student WHERE Grade IS NOT NULL;

-- 多重条件（AND/OR）
SELECT Sname, Ssex FROM Student WHERE Sdept = '计算机系' AND Sage < 20;
```

#### 3.1.3 排序

```sql
-- 单列排序
SELECT Sno, Grade FROM SC WHERE Cno = '3' ORDER BY Grade DESC;

-- 多列排序
SELECT * FROM Student ORDER BY Sdept, Sage DESC;
```

#### 3.1.4 聚集函数

| 函数 | 说明 |
|------|------|
| COUNT([DISTINCT|ALL] *) | 统计元组个数 |
| COUNT([DISTINCT|ALL] 列名) | 统计一列中值的个数 |
| SUM([DISTINCT|ALL] 列名) | 计算一列值的总和 |
| AVG([DISTINCT|ALL] 列名) | 计算一列值的平均值 |
| MAX([DISTINCT|ALL] 列名) | 求一列值的最大值 |
| MIN([DISTINCT|ALL] 列名) | 求一列值的最小值 |

```sql
SELECT COUNT(*) FROM Student;                          -- 统计学生总数
SELECT COUNT(DISTINCT Sno) FROM SC;                    -- 统计选修课程的学生数
SELECT MAX(Grade), MIN(Grade), AVG(Grade) FROM SC WHERE Cno = '1';
SELECT SUM(Grade) FROM SC WHERE Sno = '2021001';
```

#### 3.1.5 分组查询

```sql
-- 按组统计
SELECT Sdept, COUNT(*) FROM Student GROUP BY Sdept;

-- 带条件的分组
SELECT Sdept, AVG(Sage) FROM Student GROUP BY Sdept HAVING AVG(Sage) >= 20;

-- 多列分组
SELECT Sdept, Ssex, COUNT(*) FROM Student GROUP BY Sdept, Ssex;
```

### 3.2 连接查询

#### 3.2.1 等值与非等值连接

```sql
-- 等值连接
SELECT Student.Sno, Sname, Cname, Grade
FROM Student, SC, Course
WHERE Student.Sno = SC.Sno AND SC.Cno = Course.Cno;

-- 表别名简化
SELECT S.Sno, S.Sname, C.Cname, SC.Grade
FROM Student S, SC, Course C
WHERE S.Sno = SC.Sno AND SC.Cno = C.Cno;
```

#### 3.2.2 自然连接（SQL标准）

```sql
-- 使用JOIN...ON语法
SELECT S.Sno, S.Sname, C.Cname, SC.Grade
FROM Student S
INNER JOIN SC ON S.Sno = SC.Sno
INNER JOIN Course C ON SC.Cno = C.Cno;

-- 等价写法
SELECT S.Sno, S.Sname, C.Cname, SC.Grade
FROM Student S
JOIN SC ON S.Sno = SC.Sno
JOIN Course C ON SC.Cno = C.Cno;
```

#### 3.2.3 自身连接

```sql
-- 查询每门课的间接先修课
SELECT A.Cno, B.Cpno
FROM Course A
JOIN Course B ON A.Cpno = B.Cno;
```

#### 3.2.4 外连接

```sql
-- 左外连接：保留左边表的所有记录
SELECT Student.Sno, Sname, Cno, Grade
FROM Student
LEFT OUTER JOIN SC ON Student.Sno = SC.Sno;

-- 右外连接：保留右边表的所有记录
SELECT Student.Sno, Sname, Cno, Grade
FROM Student
RIGHT OUTER JOIN SC ON Student.Sno = SC.Sno;

-- 全外连接：保留两边表的所有记录
SELECT Student.Sno, Sname, Cno, Grade
FROM Student
FULL OUTER JOIN SC ON Student.Sno = SC.Sno;
```

#### 3.2.5 复合条件连接

```sql
SELECT Sname, Cname
FROM Student
JOIN SC ON Student.Sno = SC.Sno
JOIN Course ON SC.Cno = Course.Cno
WHERE SC.Grade >= 80 AND Course.Ccredit > 3;
```

### 3.3 嵌套查询

#### 3.3.1 带IN谓词的子查询

```sql
-- 查询与"刘晨"在同一个系的学生
SELECT Sno, Sname, Sdept
FROM Student
WHERE Sdept IN (
    SELECT Sdept
    FROM Student
    WHERE Sname = '刘晨'
);

-- 等价于
SELECT S1.Sno, S1.Sname, S1.Sdept
FROM Student S1, Student S2
WHERE S1.Sdept = S2.Sdept AND S2.Sname = '刘晨';
```

#### 3.3.2 带比较运算符的子查询

```sql
-- 查询比"信息系"某个学生年龄小的学生
SELECT Sname, Sage
FROM Student
WHERE Sage < ANY (
    SELECT Sage
    FROM Student
    WHERE Sdept = '信息系'
) AND Sdept <> '信息系';

-- 使用MIN函数优化
SELECT Sname, Sage
FROM Student
WHERE Sage < (
    SELECT MIN(Sage)
    FROM Student
    WHERE Sdept = '信息系'
) AND Sdept <> '信息系';
```

#### 3.3.3 带EXISTS谓词的子查询

```sql
-- EXISTS：存在满足条件的记录
SELECT Sname
FROM Student
WHERE EXISTS (
    SELECT *
    FROM SC
    WHERE Sno = Student.Sno AND Cno = '1'
);

-- NOT EXISTS：不存在满足条件的记录
SELECT Sname
FROM Student
WHERE NOT EXISTS (
    SELECT *
    FROM SC
    WHERE Sno = Student.Sno AND Cno = '1'
);

-- 关联子查询
SELECT Sname, Sno, Sdept
FROM Student S1
WHERE EXISTS (
    SELECT *
    FROM Student S2
    WHERE S2.Sdept = S1.Sdept AND S2.Sname = '刘晨'
);
```

#### 3.3.4 集合查询

```sql
-- UNION：并集（去重）
SELECT * FROM Student WHERE Sdept = '计算机系'
UNION
SELECT * FROM Student WHERE Sage <= 19;

-- UNION ALL：并集（保留重复）
SELECT Sno FROM SC WHERE Cno = '1'
UNION ALL
SELECT Sno FROM SC WHERE Cno = '2';

-- INTERSECT：交集
SELECT Sno FROM SC WHERE Cno = '1'
INTERSECT
SELECT Sno FROM SC WHERE Cno = '2';

-- EXCEPT / MINUS：差集（MySQL用NOT IN）
SELECT Sno FROM SC WHERE Cno = '1'
EXCEPT
SELECT Sno FROM SC WHERE Cno = '2';
```

### 3.4 派生表与CTE

#### 3.4.1 派生表（Derived Table）

```sql
-- FROM子句中的子查询
SELECT Sdept, AvgAge
FROM (
    SELECT Sdept, AVG(Sage) AS AvgAge
    FROM Student
    GROUP BY Sdept
) AS DeptAge
WHERE AvgAge >= 20;
```

#### 3.4.2 公共表表达式（CTE）

```sql
-- 简单CTE
WITH AvgGradeCTE AS (
    SELECT Sno, AVG(Grade) AS AvgGrade
    FROM SC
    GROUP BY Sno
)
SELECT S.Sno, S.Sname, A.AvgGrade
FROM Student S
JOIN AvgGradeCTE A ON S.Sno = A.Sno
WHERE A.AvgGrade >= 85;

-- 递归CTE
WITH RECURSIVE CoursePrereq AS (
    SELECT Cno, Cpno, 1 AS Level
    FROM Course
    WHERE Cpno IS NULL
    UNION ALL
    SELECT C.Cno, C.Cpno, CP.Level + 1
    FROM Course C
    JOIN CoursePrereq CP ON C.Cpno = CP.Cno
)
SELECT * FROM CoursePrereq;
```

### 3.5 SELECT语句执行顺序

| 执行顺序 | 子句 | 说明 |
|---------|------|------|
| 1 | FROM | 确定数据来源表 |
| 2 | WHERE | 行过滤条件 |
| 3 | GROUP BY | 分组 |
| 4 | HAVING | 组过滤条件 |
| 5 | SELECT | 选择列和计算 |
| 6 | ORDER BY | 排序 |
| 7 | LIMIT/OFFSET | 分页 |

## 4. SQL的数据操作功能（DML）

### 4.1 插入数据

```sql
-- 插入完整元组
INSERT INTO Student (Sno, Sname, Ssex, Sage, Sdept)
VALUES ('2021001', '张三', '男', 20, '计算机系');

-- 插入部分元组（省略允许NULL的列）
INSERT INTO Student (Sno, Sname, Sdept)
VALUES ('2021002', '李四', '信息系');

-- 插入子查询结果
INSERT INTO DeptAge (Dname, AvgAge)
SELECT Sdept, AVG(Sage)
FROM Student
GROUP BY Sdept;

-- 批量插入
INSERT INTO Student VALUES
('2021003', '王五', '男', 21, '数学系'),
('2021004', '赵六', '女', 19, '计算机系');
```

### 4.2 修改数据

```sql
-- 修改单个元组
UPDATE Student
SET Sage = 21
WHERE Sno = '2021001';

-- 修改多个元组
UPDATE Student
SET Sage = Sage + 1
WHERE Sdept = '计算机系';

-- 带子查询的更新
UPDATE SC
SET Grade = 0
WHERE Sno IN (
    SELECT Sno
    FROM Student
    WHERE Sdept = '信息系'
);

-- 多表更新（MySQL语法）
UPDATE Student S
JOIN SC ON S.Sno = SC.Sno
SET Grade = Grade + 5
WHERE Cno = '1' AND Grade < 60;
```

### 4.3 删除数据

```sql
-- 删除单个元组
DELETE FROM Student
WHERE Sno = '2021001';

-- 删除多个元组
DELETE FROM Student
WHERE Sdept = '信息系';

-- 删除所有记录（比TRUNCATE慢，可回滚）
DELETE FROM Student;

-- 带子查询的删除
DELETE FROM SC
WHERE Cno IN (
    SELECT Cno
    FROM Course
    WHERE Cname LIKE '%原理%'
);

-- TRUNCATE：快速清空（不可回滚，重置自增ID）
TRUNCATE TABLE Student;
```

## 5. 视图（View）

### 5.1 视图的定义与删除

**视图**是从一个或多个基本表（或视图）导出的虚拟表。

```sql
-- 创建视图
CREATE VIEW IS_Student
AS
SELECT Sno, Sname, Sage
FROM Student
WHERE Sdept = '信息系'
WITH CHECK OPTION;  -- 保证更新操作符合视图定义条件

-- 创建多表视图
CREATE VIEW IS_S1 (Sno, Sname, Grade)
AS
SELECT Student.Sno, Sname, Grade
FROM Student
JOIN SC ON Student.Sno = SC.Sno
WHERE Sdept = '信息系' AND Cno = '1';

-- 创建分组视图
CREATE VIEW S_G (Sno, Gavg)
AS
SELECT Sno, AVG(Grade)
FROM SC
GROUP BY Sno;

-- 删除视图
DROP VIEW IS_Student CASCADE;
DROP VIEW IS_S1 RESTRICT;
```

### 5.2 视图的查询

```sql
-- 查询视图
SELECT Sno, Sage FROM IS_Student;

-- 视图与基本表联合查询
SELECT IS_Student.Sno, Sname, Cname, Grade
FROM IS_Student
JOIN SC ON IS_Student.Sno = SC.Sno
JOIN Course ON SC.Cno = Course.Cno;
```

### 5.3 视图的更新

```sql
-- 可更新的视图：插入
INSERT INTO IS_Student VALUES ('2021010', '周八', 20);
-- 实际插入到Student表：('2021010', '周八', '信息系', 20)

-- 可更新的视图：修改
UPDATE IS_Student
SET Sage = 21
WHERE Sno = '2021010';

-- 可更新的视图：删除
DELETE FROM IS_Student WHERE Sno = '2021010';

-- 不可更新的视图（涉及聚合、分组、DISTINCT等）
-- 下面的操作会失败：
UPDATE S_G SET Gavg = 90 WHERE Sno = '2021001';
```

**视图更新的限制条件**：

| 视图类型 | 是否可更新 | 原因 |
|---------|-----------|------|
| 基本表行列子集 | ✓ | 可逆操作 |
| 分组视图（GROUP BY） | ✗ | 不可逆操作 |
| 聚集函数视图 | ✗ | 不可逆操作 |
| DISTINCT视图 | ✗ | 不可逆操作 |
| 多表连接视图 | 部分 | 需满足特定条件 |

## 6. 数据完整性约束

### 6.1 实体完整性

```sql
-- 主键约束
CREATE TABLE Student (
    Sno CHAR(9) PRIMARY KEY,  -- 或 PRIMARY KEY (Sno)
    Sname CHAR(20) NOT NULL
);

-- 复合主键
CREATE TABLE SC (
    Sno CHAR(9),
    Cno CHAR(4),
    PRIMARY KEY (Sno, Cno)
);
```

### 6.2 参照完整性

```sql
-- 外键约束
CREATE TABLE SC (
    Sno CHAR(9),
    Cno CHAR(4),
    FOREIGN KEY (Sno) REFERENCES Student(Sno),
    FOREIGN KEY (Cno) REFERENCES Course(Cno)
);

-- 指定级联操作
CREATE TABLE SC (
    Sno CHAR(9),
    Cno CHAR(4),
    FOREIGN KEY (Sno) REFERENCES Student(Sno)
        ON DELETE CASCADE      -- 级联删除
        ON UPDATE CASCADE,     -- 级联更新
    FOREIGN KEY (Cno) REFERENCES Course(Cno)
        ON DELETE SET NULL     -- 设为NULL
);
```

### 6.3 用户定义的完整性

```sql
-- NOT NULL约束
CREATE TABLE Student (
    Sno CHAR(9) NOT NULL,
    Sname CHAR(20) NOT NULL
);

-- UNIQUE约束
CREATE TABLE Student (
    Sno CHAR(9) UNIQUE,
    Email CHAR(50) UNIQUE
);

-- CHECK约束
CREATE TABLE Student (
    Sage SMALLINT CHECK (Sage BETWEEN 15 AND 50),
    Ssex CHAR(2) CHECK (Ssex IN ('男', '女'))
);

-- DEFAULT约束
CREATE TABLE Student (
    Sreg_date DATE DEFAULT CURRENT_DATE
);
```

### 6.4 断言（Assertion）

```sql
-- 创建断言：每个系的学生不超过100人
CREATE ASSERTION ASSE_SC_DB_NUM
CHECK (
    100 >= (
        SELECT COUNT(*)
        FROM Student
        GROUP BY Sdept
    )
);

-- 删除断言
DROP ASSERTION ASSE_SC_DB_NUM;
```

### 6.5 触发器（Trigger）

```sql
-- 创建触发器：插入SC记录时检查学生成绩
CREATE TRIGGER CheckGrade
BEFORE INSERT ON SC
FOR EACH ROW
BEGIN
    IF NEW.Grade < 0 OR NEW.Grade > 100 THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = '成绩必须在0-100之间';
    END IF;
END;

-- 创建触发器：记录修改日志
CREATE TRIGGER SC_Update_Log
AFTER UPDATE ON SC
FOR EACH ROW
BEGIN
    INSERT INTO SC_Log (Sno, Cno, OldGrade, NewGrade, UpdateTime)
    VALUES (OLD.Sno, OLD.Cno, OLD.Grade, NEW.Grade, CURRENT_TIMESTAMP);
END;

-- 创建触发器：防止删除特定课程
CREATE TRIGGER PreventDelete
BEFORE DELETE ON Course
FOR EACH ROW
BEGIN
    IF EXISTS (SELECT * FROM SC WHERE Cno = OLD.Cno) THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = '该课程已有学生选修，不能删除';
    END IF;
END;

-- 删除触发器
DROP TRIGGER CheckGrade;
```

## 7. 事务控制（TCL）

### 7.1 事务的ACID特性

| 特性 | 说明 |
|------|------|
| **A**tomicity（原子性） | 事务是不可分割的工作单位，要么全部执行，要么全部不执行 |
| **C**onsistency（一致性） | 事务执行前后，数据库必须保持一致状态 |
| **I**solation（隔离性） | 事务的执行不受其他事务干扰 |
| **D**urability（持久性） | 事务一旦提交，其结果是永久的 |

### 7.2 事务控制语句

```sql
-- 开始事务（隐式或显式）
START TRANSACTION;
-- 或设置自动提交为关闭
SET autocommit = 0;

-- 执行事务操作
UPDATE Account SET Balance = Balance - 100 WHERE AccNo = 'A001';
UPDATE Account SET Balance = Balance + 100 WHERE AccNo = 'A002';

-- 提交事务
COMMIT;

-- 回滚事务
ROLLBACK;

-- 设置保存点
SAVEPOINT sp1;
-- ...执行一些操作...
SAVEPOINT sp2;
-- 回滚到保存点
ROLLBACK TO sp1;

-- 提交后释放保存点
RELEASE SAVEPOINT sp1;
```

### 7.3 事务的隔离级别

| 隔离级别 | 脏读 | 不可重复读 | 幻读 | 性能 |
|---------|------|-----------|------|------|
| READ UNCOMMITTED | ✓ | ✓ | ✓ | 最高 |
| READ COMMITTED | ✗ | ✓ | ✓ | 高 |
| REPEATABLE READ | ✗ | ✗ | ✓ | 中 |
| SERIALIZABLE | ✗ | ✗ | ✗ | 最低 |

```sql
-- 设置隔离级别
SET TRANSACTION ISOLATION LEVEL READ COMMITTED;
SET SESSION TRANSACTION ISOLATION LEVEL REPEATABLE READ;
SET GLOBAL TRANSACTION ISOLATION LEVEL SERIALIZABLE;
```

## 8. 数据控制功能（DCL）

### 8.1 授权（GRANT）

```sql
-- 授予查询权限
GRANT SELECT ON TABLE Student TO U1;

-- 授予多个权限
GRANT SELECT, INSERT, UPDATE ON TABLE Student TO U2;

-- 授予所有权限
GRANT ALL PRIVILEGES ON TABLE Student TO U3;

-- 授予列级权限
GRANT UPDATE(Sage), SELECT ON TABLE Student TO U4;

-- 授予模式权限
GRANT USAGE ON SCHEMA "S-T" TO U5;

-- 授予创建表权限
GRANT CREATE TABLE TO U6;

-- 授权时可带GRANT OPTION
GRANT SELECT ON TABLE Student TO U7 WITH GRANT OPTION;
```

### 8.2 收回权限（REVOKE）

```sql
-- 收回基本权限
REVOKE UPDATE ON TABLE Student FROM U4;

-- 收回多个权限
REVOKE INSERT, DELETE ON TABLE Student FROM U2;

-- 级联收回（如果U7曾通过WITH GRANT OPTION授权给其他用户）
REVOKE SELECT ON TABLE Student FROM U7 CASCADE;

-- 严格收回（如果有向下授权，则拒绝执行）
REVOKE SELECT ON TABLE Student FROM U7 RESTRICT;

-- 收回所有权限
REVOKE ALL PRIVILEGES ON TABLE Student FROM U3;
```

### 8.3 角色（Role）的使用

```sql
-- 创建角色
CREATE ROLE StudentRole;

-- 给角色授权
GRANT SELECT, INSERT ON TABLE Student TO StudentRole;
GRANT SELECT ON TABLE Course TO StudentRole;

-- 将角色授予用户
GRANT StudentRole TO U1, U2, U3;

-- 角色的权限可以再回收
REVOKE INSERT ON TABLE Student FROM StudentRole;

-- 收回角色
REVOKE StudentRole FROM U1;

-- 删除角色
DROP ROLE StudentRole;
```

## 9. 高级SQL特性

### 9.1 窗口函数

```sql
-- RANK：相同值有相同排名，会跳过名次
SELECT Sname, Grade,
    RANK() OVER (ORDER BY Grade DESC) AS Rank
FROM SC WHERE Cno = '1';

-- DENSE_RANK：相同值有相同排名，不跳过名次
SELECT Sname, Grade,
    DENSE_RANK() OVER (ORDER BY Grade DESC) AS DenseRank
FROM SC WHERE Cno = '1';

-- ROW_NUMBER：连续排名，无跳过
SELECT Sname, Grade,
    ROW_NUMBER() OVER (ORDER BY Grade DESC) AS RowNum
FROM SC WHERE Cno = '1';

-- 窗口函数配合分区
SELECT Sname, Cname, Grade,
    AVG(Grade) OVER (PARTITION BY Cno) AS AvgGrade,
    RANK() OVER (PARTITION BY Cno ORDER BY Grade DESC) AS CRank
FROM SC JOIN Course ON SC.Cno = Course.Cno;

-- 移动窗口
SELECT Sno, Cno, Grade,
    AVG(Grade) OVER (
        PARTITION BY Sno
        ORDER BY Cno
        ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING
    ) AS MovingAvg
FROM SC;
```

### 9.2 PIVOT与UNPIVOT

```sql
-- 行转列（PIVOT）
SELECT Sno,
    MAX(CASE WHEN Cno = '1' THEN Grade END) AS C1_Grade,
    MAX(CASE WHEN Cno = '2' THEN Grade END) AS C2_Grade,
    MAX(CASE WHEN Cno = '3' THEN Grade END) AS C3_Grade
FROM SC
GROUP BY Sno;

-- Oracle/SQL Server的PIVOT语法
SELECT * FROM (
    SELECT Sno, Cno, Grade FROM SC
) PIVOT (
    MAX(Grade) FOR Cno IN ('1', '2', '3')
) AS PivotTable;

-- 列转行（UNPIVOT）
SELECT * FROM (
    SELECT Sno, C1_Grade, C2_Grade, C3_Grade
    FROM GradeTable
) UNPIVOT (
    Grade FOR Cno IN (C1_Grade, C2_Grade, C3_Grade)
) AS UnpivotTable;
```

### 9.3 公用表表达式（CTE）的进阶应用

```sql
-- 递归查询：组织架构
WITH RECURSIVE OrgTree AS (
    -- 锚点：顶层节点
    SELECT EmpID, EmpName, MgrID, 0 AS Level
    FROM Employee
    WHERE MgrID IS NULL
    UNION ALL
    -- 递归：子节点
    SELECT e.EmpID, e.EmpName, e.MgrID, ot.Level + 1
    FROM Employee e
    JOIN OrgTree ot ON e.MgrID = ot.EmpID
)
SELECT * FROM OrgTree ORDER BY Level, EmpID;

-- 多CTE链式调用
WITH Sales_CTE AS (
    SELECT ProductID, SUM(Quantity) AS TotalQty
    FROM Sales
    GROUP BY ProductID
), Ranked_CTE AS (
    SELECT ProductID, TotalQty,
        RANK() OVER (ORDER BY TotalQty DESC) AS SalesRank
    FROM Sales_CTE
)
SELECT * FROM Ranked_CTE WHERE SalesRank <= 10;
```

## 10. SQL优化基础

### 10.1 查询优化原则

| 原则 | 说明 |
|------|------|
| **减少数据扫描** | 使用WHERE条件过滤不必要的行 |
| **避免全表扫描** | 为常用查询条件列建立索引 |
| **减少排序操作** | 利用索引的有序性 |
| **避免重复计算** | 使用子查询缓存中间结果 |
| **减少数据传输** | 只选择需要的列，不使用SELECT * |

### 10.2 执行计划分析

```sql
-- MySQL查看执行计划
EXPLAIN SELECT Sname FROM Student WHERE Sdept = '计算机系';
EXPLAIN FORMAT=JSON SELECT Sname FROM Student WHERE Sdept = '计算机系';

-- Oracle查看执行计划
EXPLAIN PLAN FOR SELECT Sname FROM Student WHERE Sdept = '计算机系';
SELECT * FROM TABLE(DBMS_XPLAN.DISPLAY);

-- SQL Server查看执行计划
SET SHOWPLAN_ALL ON;
GO
SELECT Sname FROM Student WHERE Sdept = '计算机系';
```

### 10.3 索引优化策略

**适用索引的场景**：
- WHERE条件频繁使用的列
- JOIN连接的列
- ORDER BY和GROUP BY的列
- 选择性高的列（不同值多）

**不适用索引的场景**：
- 数据量小的表
- 更新频繁的列
- 选择性低的列（如性别，只有两个值）
- 经常使用函数的列

### 10.4 避免低效查询

```sql
-- 低效：OR导致索引失效
SELECT * FROM Student WHERE Sage = 20 OR Sage = 21;

-- 高效：使用UNION或IN
SELECT * FROM Student WHERE Sage IN (20, 21);

-- 低效：LIKE以%开头
SELECT * FROM Student WHERE Sname LIKE '%张%';

-- 高效：LIKE不以%开头
SELECT * FROM Student WHERE Sname LIKE '张%';

-- 低效：NOT IN子查询
SELECT * FROM Student WHERE Sno NOT IN (SELECT Sno FROM SC);

-- 高效：使用NOT EXISTS
SELECT * FROM Student S
WHERE NOT EXISTS (
    SELECT 1 FROM SC WHERE Sno = S.Sno
);
```

## 11. 嵌入式SQL

### 11.1 基本概念

**嵌入式SQL**是将SQL语句嵌入到高级语言（如C、Java、Python）中。

### 11.2 主机变量

```c
/* C语言中的嵌入式SQL示例 */
EXEC SQL BEGIN DECLARE SECTION;
    char Sno[10];
    char Sname[20];
    int Sage;
    char Sdept[20];
EXEC SQL END DECLARE SECTION;

/* 查询单个学生 */
strcpy(Sno, "2021001");
EXEC SQL SELECT Sname, Sage, Sdept
    INTO :Sname, :Sage, :Sdept
    FROM Student
    WHERE Sno = :Sno;

/* 游标查询 */
EXEC SQL DECLARE C1 CURSOR FOR
    SELECT Sno, Sname FROM Student WHERE Sdept = '计算机系';

EXEC SQL OPEN C1;
while (1) {
    EXEC SQL FETCH C1 INTO :Sno, :Sname;
    if (SQLCODE != 0) break;
    printf("%s %s\n", Sno, Sname);
}
EXEC SQL CLOSE C1;
```
