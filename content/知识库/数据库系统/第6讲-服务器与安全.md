## 三层架构

### 什么是三层架构？

**三层架构**是一种常见的数据库应用环境，将系统分为三个处理层次：

### 三层架构的组成

```
┌─────────────────────────────────────────────────────────┐
│                      用户层                              │
│  ┌─────────────────────────────────────────────────┐   │
│  │                 Web 浏览器                       │   │
│  │            (Chrome, Firefox, Edge)               │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
                          ↓ HTTP 请求
┌─────────────────────────────────────────────────────────┐
│                   Web 服务器层                           │
│  ┌─────────────────────────────────────────────────┐   │
│  │          Web 服务器 (Apache, Nginx)              │   │
│  │       - 处理 HTTP 请求                           │   │
│  │       - 返回 HTML/CSS/JS                         │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
                          ↓ 业务请求
┌─────────────────────────────────────────────────────────┐
│                  应用服务器层                             │
│  ┌─────────────────────────────────────────────────┐   │
│  │       应用服务器 (Tomcat, WebLogic)              │   │
│  │       - 执行业务逻辑                             │   │
│  │       - 处理用户请求                             │   │
│  │       - 生成 SQL 语句                            │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
                          ↓ SQL 查询
┌─────────────────────────────────────────────────────────┐
│                  数据库服务器层                           │
│  ┌─────────────────────────────────────────────────┐   │
│  │       数据库服务器 (MySQL, Oracle, openGauss)    │   │
│  │       - 执行 SQL 语句                            │   │
│  │       - 管理数据存储                             │   │
│  │       - 保证数据完整性                           │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

### 示例：学生选课系统

**用户操作：** 学生登录系统，查询可选课程

**数据流：**

1. **Web 浏览器**
   - 学生输入学号和密码
   - 点击"查询课程"按钮
   - 发送 HTTP 请求：`GET /api/courses?studentID=S001`

2. **Web 服务器**
   - 接收 HTTP 请求
   - 转发给应用服务器

3. **应用服务器**
   - 验证学生身份
   - 生成 SQL 查询：
   ```sql
   SELECT c.courseID, c.courseName, c.credit, c.hours
   FROM Course c
   WHERE c.courseID NOT IN (
       SELECT e.courseID FROM Enroll e WHERE e.studentID = 'S001'
   )
   ```

4. **数据库服务器**
   - 执行 SQL 查询
   - 返回结果集

5. **返回结果**

**查询结果：**

| courseID | courseName | credit | hours |
|----------|------------|--------|-------|
| C02 | 操作系统 | 4 | 64 |
| C03 | 计算机网络 | 3 | 48 |
| C04 | 编译原理 | 4 | 64 |

> [!note] 说明
> 学生 S001 已经选修了 C01（数据库系统），所以结果中不包含 C01

## 存储过程

### 什么是存储过程？

**存储过程**是一组预编译的SQL语句，存储在数据库服务器上，可以被应用程序调用。

### 存储过程示例

#### 示例1：查询学生选课信息

```sql
CREATE PROCEDURE GetStudentCourses(IN student_id CHAR(10))
BEGIN
    SELECT c.courseID, c.courseName, c.credit, e.grade
    FROM Course c
    JOIN Enroll e ON c.courseID = e.courseID
    WHERE e.studentID = student_id;
END;
```

**调用：**

```sql
CALL GetStudentCourses('S001');
```

**结果：**

| courseID | courseName | credit | grade |
|----------|------------|--------|-------|
| C01 | 数据库系统 | 3 | 90 |
| C02 | 操作系统 | 4 | 85 |

#### 示例2：计算学生平均成绩

```sql
CREATE PROCEDURE CalculateStudentGPA(
    IN student_id CHAR(10),
    OUT gpa DECIMAL(3,2)
)
BEGIN
    DECLARE total_credits INT;
    DECLARE total_points DECIMAL(10,2);
    
    -- 计算总学分和总绩点
    SELECT SUM(c.credit), SUM(c.credit * e.grade / 25)
    INTO total_credits, total_points
    FROM Course c
    JOIN Enroll e ON c.courseID = e.courseID
    WHERE e.studentID = student_id;
    
    -- 计算 GPA
    IF total_credits > 0 THEN
        SET gpa = total_points / total_credits;
    ELSE
        SET gpa = 0;
    END IF;
END;
```

**调用：**

```sql
CALL CalculateStudentGPA('S001', @gpa);
SELECT @gpa;
```

**计算过程：**

| courseID | grade | credit | grade/25 | credit × (grade/25) |
|----------|-------|--------|----------|---------------------|
| C01 | 90 | 3 | 3.6 | 10.8 |
| C02 | 85 | 4 | 3.4 | 13.6 |
| **总计** | - | **7** | - | **24.4** |

GPA = 24.4 / 7 = 3.49

**结果：** GPA = 3.49

#### 示例3：学生选课（带验证）

```sql
CREATE PROCEDURE EnrollCourse(
    IN student_id CHAR(10),
    IN course_id CHAR(10),
    OUT result VARCHAR(50)
)
BEGIN
    DECLARE course_count INT;
    DECLARE already_enrolled INT;
    DECLARE course_exists INT;
    
    -- 检查课程是否存在
    SELECT COUNT(*) INTO course_exists
    FROM Course WHERE courseID = course_id;
    
    IF course_exists = 0 THEN
        SET result = '课程不存在';
        RETURN;
    END IF;
    
    -- 检查是否已选修
    SELECT COUNT(*) INTO already_enrolled
    FROM Enroll 
    WHERE studentID = student_id AND courseID = course_id;
    
    IF already_enrolled > 0 THEN
        SET result = '已选修该课程';
        RETURN;
    END IF;
    
    -- 检查选课数量
    SELECT COUNT(*) INTO course_count
    FROM Enroll WHERE studentID = student_id;
    
    IF course_count >= 6 THEN
        SET result = '选课数量已达上限';
        RETURN;
    END IF;
    
    -- 执行选课
    INSERT INTO Enroll (studentID, courseID, enrollDate)
    VALUES (student_id, course_id, CURRENT_DATE);
    
    SET result = '选课成功';
END;
```

**调用示例：**

```sql
-- 成功选课
CALL EnrollCourse('S001', 'C03', @result);
SELECT @result;
-- 结果：选课成功

-- 重复选课
CALL EnrollCourse('S001', 'C01', @result);
SELECT @result;
-- 结果：已选修该课程

-- 课程不存在
CALL EnrollCourse('S001', 'C99', @result);
SELECT @result;
-- 结果：课程不存在
```

## 数据库安全

### 常见的安全威胁

#### 1. SQL注入攻击

**原理：** 通过输入恶意SQL代码

**示例：**

**正常输入：**
```sql
SELECT * FROM Student WHERE studentID = 'S001';
```

**恶意输入：**
```
输入：S001' OR '1'='1
```

**生成的SQL：**
```sql
SELECT * FROM Student WHERE studentID = 'S001' OR '1'='1';
```

**结果：** 返回所有学生记录！

**防范方法：**

```sql
-- 使用参数化查询
PREPARE stmt FROM 'SELECT * FROM Student WHERE studentID = ?';
SET @id = 'S001';
EXECUTE stmt USING @id;
```

#### 2. 权限控制

**最小权限原则：** 只授予用户完成任务所需的最小权限

**示例：**

```sql
-- 创建只读用户
CREATE USER 'readonly'@'localhost' IDENTIFIED BY 'password';
GRANT SELECT ON Student TO 'readonly'@'localhost';

-- 创建教务用户
CREATE USER 'admin'@'localhost' IDENTIFIED BY 'password';
GRANT SELECT, INSERT, UPDATE ON Student TO 'admin'@'localhost';
GRANT SELECT, INSERT, UPDATE ON Enroll TO 'admin'@'localhost';

-- 创建学生用户
CREATE USER 'student'@'localhost' IDENTIFIED BY 'password';
GRANT SELECT ON Course TO 'student'@'localhost';
GRANT SELECT ON Enroll TO 'student'@'localhost';
```

### 安全最佳实践

1. **使用强密码策略**
2. **实施最小权限原则**
3. **定期备份数据**
4. **使用加密技术**
5. **监控数据库活动**
6. **及时更新补丁**

## 学习建议

对于初学者，建议：
1. **理解三层架构的概念**：这是现代应用的基础架构
2. **掌握存储过程的基本语法**：学会创建和调用存储过程
3. **了解安全性的基本概念**：知道常见的安全威胁和防范措施
4. **实践存储过程的编写**：通过实际例子加深理解

> [!tip] 实践建议
> 建议在数据库系统中创建几个简单的存储过程，然后测试它们的性能和安全性，这样能更好地理解存储过程的作用。

## 关键概念总结

1. **三层架构**：Web服务器、应用服务器、数据库服务器
2. **存储过程**：预编译的SQL语句集合，存储在服务器上
3. **SQL注入**：通过输入恶意SQL代码进行攻击
4. **最小权限原则**：只授予用户完成任务所需的最小权限
