# 🧠 线性回归 (Linear Regression)

> 来源: [Google ML Crash Course](https://developers.google.com/machine-learning/crash-course/linear-regression)

## 1. 核心概念

- **模型 (Model)**: $y = w_1x_1 + b$
- **损失函数 (Loss Function)**:
  - **MSE (Mean Squared Error)**: 均方误差
- **收敛 (Convergence)**: 寻找损失最小值的过程

## 2. 梯度下降 (Gradient Descent)

- **学习率 (Learning Rate / Step Size)**: 控制每一步的大小。
  - 过小: 收敛太慢。
  - 过大: 容易越过最小值导致发散。
- **批量大小 (Batch Size)**:
  - **SGD (Stochastic Gradient Descent)**: Batch size = 1。
  - **Mini-batch SGD**: 常用平衡。

- 权重 ($w$) 和偏置 ($b$) 在训练时是 FP32。
