# 🏋️ AI健身教练 - 每日训练计划模板

## 用户档案

- **身高/体重**: 175cm / 60kg
- **目标**: 增肌/大肌肌
- **水平**: 零基础萌新 (严禁初期高强度)
- **器材**: 3kg哑铃×2, 俯卧撑支架, 瑜伽垫

---

## 可用动作库 (基于器材)

### 胸部 (Push)

#### 1. 跪姿俯卧撑

**怎么做 (详细步骤):**

1. **起始姿势**: 跪在瑜伽垫上，双手撑地(与肩同宽或略宽)，膝盖着地，小腿交叉抬起或脚着地
2. **下放身体**: 吸气，慢慢弯曲手肘，胸部向地面靠近，直到上臂与地面平行
3. **推起身体**: 呼气，用手掌推地，胸部发力将身体推回起始位置
4. **锁定**: 手臂伸直但不锁死肘关节，保持核心收紧

**呼吸**: 下吸上呼
**常见错误**: 塌腰(臀部翘起)、手肘外展太开(应呈45度角)、只做半程
**发力感**: 胸部中间有挤压感

---

#### 2. 钻石俯卧撑

**怎么做 (详细步骤):**

1. **起始姿势**: 跪姿或标准俯卧撑姿势，双手食指和拇指相对形成一个"钻石"形状放在胸骨下方
2. **下放身体**: 吸气，手肘向后弯曲，胸部向双手之间下降
3. **底部停顿**: 胸部接近手部时停顿1秒
4. **推起**: 呼气，用手掌推地回到起始位置

**呼吸**: 下吸上呼
**常见错误**: 手放得太高(应在胸下)、肘部外展(应贴近身体)
**发力感**: 胸部内侧和三头肌发力明显

---

#### 3. 哑铃卧推 (地面)

**怎么做 (详细步骤):**

1. **起始姿势**: 仰卧在瑜伽垫上，双膝弯曲脚踩地，双手各持一个哑铃放在胸部两侧，手肘弯曲约90度
2. **推起哑铃**: 呼气，双手同时将哑铃向上推，直到手臂伸直(哑铃不接触)
3. **顶峰收缩**: 在最高点停顿1秒，感受胸部挤压
4. **缓慢下放**: 吸气，控制速度将哑铃放回胸部两侧，手肘略低于身体

**呼吸**: 推起呼气，下放吸气
**常见错误**: 耸肩、腰部拱起离开地面、哑铃撞在一起
**发力感**: 整个胸肌尤其是中部

---

### 背部 (Pull)

#### 1. 哑铃俯身划船

**怎么做 (详细步骤):**

1. **起始姿势**: 双脚与肩同宽站立，手持哑铃，身体前倾约45度(背部挺直)，手臂自然下垂
2. **拉起哑铃**: 呼气，用手肘带动，将哑铃向臀部方向拉起，肩胛骨向后收紧
3. **顶峰收缩**: 在最高点停顿1秒，感受背部挤压
4. **缓慢下放**: 吸气，控制速度将哑铃放回起始位置，保持背部紧张

**呼吸**: 拉呼气，放吸气
**常见错误**: 用手臂拉而不是用手肘、身体晃动借力、耸肩
**发力感**: 背部中间(菱形肌)和背阔肌

---

#### 2. 超人式

**怎么做 (详细步骤):**

1. **起始姿势**: 俯卧在瑜伽垫上，双臂向前伸直，双腿伸直
2. **同时抬起**: 呼气，同时抬起双手和双脚，胸部离开地面，形成"飞行"姿势
3. **顶峰收缩**: 在最高点停顿2-3秒，感受下背部收缩
4. **缓慢放下**: 吸气，控制速度回到起始位置

**呼吸**: 抬起呼气，放下吸气
**常见错误**: 只抬头不抬手脚、动作过快失去控制
**发力感**: 下背部和臀部

---

#### 3. 哑铃罗马尼亚硬拉

**怎么做 (详细步骤):**

1. **起始姿势**: 双脚与肩同宽站立，手持哑铃放在大腿前侧，膝盖微屈(不要锁死)
2. **髋部后推**: 吸气，臀部向后推，身体前倾，哑铃沿大腿下滑，背部保持挺直
3. **感受拉伸**: 当哑铃滑到膝盖下方、感受到大腿后侧(腘绳肌)拉伸时停止
4. **髋部前推**: 呼气，臀部向前推，身体站直回到起始位置

**呼吸**: 下放吸气，站起呼气
**常见错误**: 弯腰驼背、膝盖过度弯曲变成深蹲、哑铃远离身体
**发力感**: 大腿后侧和下背部

---

### 肩部 (Push)

#### 1. 哑铃推举

**怎么做 (详细步骤):**

1. **起始姿势**: 站姿或坐姿，双脚与肩同宽，双手各持哑铃放在肩部两侧，手肘弯曲约90度，掌心向前
2. **向上推举**: 呼气，双手同时将哑铃向上推，直到手臂伸直(哑铃不接触)
3. **顶峰收缩**: 在最高点停顿1秒
4. **缓慢下放**: 吸气，控制速度将哑铃放回肩部两侧

**呼吸**: 推起呼气，下放吸气
**常见错误**: 耸肩、腰部过度反弓、用腿部借力
**发力感**: 肩部前束和中束

---

#### 2. 哑铃侧平举

**怎么做 (详细步骤):**

1. **起始姿势**: 站姿，双脚与肩同宽，双手各持哑铃放在身体两侧，掌心相对，手肘微屈
2. **向两侧抬起**: 呼气，双手同时向身体两侧抬起，直到手臂与地面平行(形成"T"字形)
3. **顶峰收缩**: 在最高点停顿1秒，感受肩部中束挤压
4. **缓慢下放**: 吸气，控制速度将哑铃放回身体两侧

**呼吸**: 抬起呼气，下放吸气
**常见错误**: 抬起过高(不应超过肩高)、身体晃动借力、手肘完全伸直
**发力感**: 肩部侧面(中束)

---

#### 3. 哑铃前平举

**怎么做 (详细步骤):**

1. **起始姿势**: 站姿，双脚与肩同宽，双手各持哑铃放在大腿前侧，掌心朝向身体
2. **向前抬起**: 呼气，双手交替或同时向前抬起，直到手臂与地面平行
3. **顶峰收缩**: 在最高点停顿1秒
4. **缓慢下放**: 吸气，控制速度将哑铃放回大腿前侧

**呼吸**: 抬起呼气，下放吸气
**常见错误**: 身体后仰借力、抬起过高、耸肩
**发力感**: 肩部前侧(前束)

---

### 腿部 (Legs)

#### 1. 高脚杯深蹲

**怎么做 (详细步骤):**

1. **起始姿势**: 双脚与肩同宽站立，双手捧住一个哑铃放在胸前(哑铃竖直，两端朝上)，手肘指向地面
2. **下蹲**: 吸气，臀部向后坐，同时屈膝下蹲，保持胸部挺起，背部挺直
3. **下蹲深度**: 蹲到大腿至少与地面平行(越低越好，只要保持背部挺直)
4. **站起**: 呼气，脚后跟发力，臀部向前推，回到站立位置

**呼吸**: 下吸上呼
**常见错误**: 膝盖内扣、重心前倾(应保持在脚后跟)、下蹲不够深
**发力感**: 大腿前侧(股四头肌)和臀部

---

#### 2. 哑铃箭步蹲

**怎么做 (详细步骤):**

1. **起始姿势**: 站姿，双脚并拢，双手各持哑铃放在身体两侧
2. **迈出前腿**: 吸气，一条腿向前迈出一大步，前腿屈膝下蹲，后腿膝盖接近地面(但不接触)
3. **检查姿势**: 前腿膝盖不超过脚尖太多，躯干保持直立
4. **回到起始**: 呼气，前脚蹬地，身体回到起始站立位置，然后换另一条腿

**呼吸**: 下蹲吸气，站起呼气
**常见错误**: 步幅太小、躯干前倾、前腿膝盖过度前伸
**发力感**: 大腿前侧和臀部，后腿也有参与

---

#### 3. 哑铃提踵

**怎么做 (详细步骤):**

1. **起始姿势**: 站姿，双脚与肩同宽，手持哑铃放在身体两侧，脚掌完全着地
2. **抬起脚跟**: 呼气，用小腿发力将脚后跟抬起，直到站在脚尖上
3. **顶峰收缩**: 在最高点停顿2秒，感受小腿肌肉收紧
4. **缓慢下放**: 吸气，控制速度将脚后跟放回地面，可以略低于地面获得更大拉伸

**呼吸**: 抬起呼气，下放吸气
**常见错误**: 动作过快失去控制、不完全下放
**发力感**: 小腿后侧(腓肠肌)

---

### 手臂 (Accessory)

#### 1. 哑铃弯举 (站姿)

**怎么做 (详细步骤):**

1. **起始姿势**: 站姿，双脚与肩同宽，双手各持哑铃放在身体两侧，掌心向前，手肘贴近身体
2. **弯曲手臂**: 呼气，弯曲手肘将哑铃向肩膀方向举起，保持上臂不动(只有前臂移动)
3. **顶峰收缩**: 在最高点停顿1秒，挤压二头肌
4. **缓慢下放**: 吸气，控制速度将哑铃放回身体两侧，直到手臂完全伸直

**呼吸**: 弯举呼气，下放吸气
**常见错误**: 身体晃动借力、耸肩、没有完全伸直手臂
**发力感**: 上臂前侧(二头肌)

---

#### 2. 颈后臂屈伸 (双手持哑铃)

**怎么做 (详细步骤):**

1. **起始姿势**: 坐姿或站姿，双手托住一个哑铃的一端(呈心形握住)，将哑铃举过头顶，手臂伸直
2. **弯曲手肘**: 吸气，弯曲手肘将哑铃缓慢放低到颈后，直到手肘呈90度
3. **伸直手臂**: 呼气，用手臂后侧发力将哑铃举回头顶，直到手臂伸直
4. **锁定**: 手臂伸直但不锁死肘关节

**呼吸**: 下放吸气，伸直呼气
**常见错误**: 手肘向外打开太多(应保持靠近头部)、动作过快、重量过大
**发力感**: 上臂后侧(三头肌)

---

#### 3. 哑铃锤式弯举

**怎么做 (详细步骤):**

1. **起始姿势**: 站姿，双脚与肩同宽，双手各持哑铃放在身体两侧，掌心相对(锤子的握法)，手肘贴近身体
2. **弯曲手臂**: 呼气，弯曲手肘将哑铃向肩膀方向举起，保持掌心始终相对
3. **顶峰收缩**: 在最高点停顿1秒
4. **缓慢下放**: 吸气，控制速度将哑铃放回身体两侧

**呼吸**: 弯举呼气，下放吸气
**常见错误**: 身体晃动、耸肩、手腕弯曲
**发力感**: 上臂外侧(肱肌)和前臂

---

### 核心 (Core)

#### 1. 平板支撑

**怎么做 (详细步骤):**

1. **起始姿势**: 俯卧在瑜伽垫上，用前臂和脚尖支撑身体，手肘在肩膀正下方
2. **身体成直线**: 抬起身体，从头到脚形成一条直线，臀部不要抬高或下沉
3. **收紧核心**: 腹部用力收紧，想象有人要打你的肚子
4. **保持**: 保持这个姿势，正常呼吸，不要憋气

**呼吸**: 保持自然呼吸，不要憋气
**常见错误**: 臀部抬得太高或塌腰、头部下垂或后仰、憋气
**发力感**: 整个腹部和腰部

---

#### 2. 死虫式

**怎么做 (详细步骤):**

1. **起始姿势**: 仰卧在瑜伽垫上，双膝弯曲呈90度抬起，大腿垂直于地面，小腿平行于地面，双臂向上伸直指向天花板
2. **对侧伸展**: 吸气，慢慢将右腿向前伸直(不接触地面)，同时左臂向后伸直过头，腰部始终贴紧地面
3. **回到起始**: 呼气，同时将右腿和左臂收回到起始位置
4. **交替进行**: 换左腿和右臂重复动作

**呼吸**: 伸展吸气，收回呼气
**常见错误**: 腰部拱起离开地面、动作过快失去控制、手脚接触地面
**发力感**: 腹部深处(腹横肌)

---

#### 3. 鸟狗式

**怎么做 (详细步骤):**

1. **起始姿势**: 四肢着地跪在瑜伽垫上，双手在肩膀正下方，膝盖在臀部正下方，背部保持平直
2. **对侧伸展**: 呼气，同时向前伸直右臂，向后伸直左腿，直到它们与身体成一条直线
3. **保持平衡**: 在最高点保持2-3秒，保持身体稳定不晃动
4. **回到起始**: 吸气，将手臂和腿收回到起始位置，然后换另一侧

**呼吸**: 伸展呼气，收回吸气
**常见错误**: 身体晃动、腰部塌陷或过度拱起、抬头太高
**发力感**: 腹部和腰部两侧

---

#### 4. 登山者

**怎么做 (详细步骤):**

1. **起始姿势**: 俯卧撑姿势，双手撑地，手臂伸直，身体成一条直线
2. **交替提膝**: 快速交替将膝盖向胸部方向提起，就像原地跑步一样
3. **保持核心**: 始终保持核心收紧，臀部不要抬得太高
4. **控制节奏**: 保持稳定的节奏，不要过快导致动作变形

**呼吸**: 保持自然呼吸
**常见错误**: 臀部抬得太高、动作过快失去控制、腰部塌陷
**发力感**: 整个腹部和髋部

## 肌群轮换计划 (Push/Pull/Legs + Core)

```
Day 1: 胸部 + 三头 + 肩前束 (Push)
Day 2: 背部 + 二头 + 肩后束 (Pull)
Day 3: 腿部 + 肩部 (Legs)
Day 4: 核心 + 恢复/有氧 (Core)
Day 5: 休息或重复Day 1
```

| 疲劳度      | 动作数 | 组数  | 次数    | 重量          | 组间休息 | 总时长  | 动作要求         |
| ----------- | ------ | ----- | ------- | ------------- | -------- | ------- | ---------------- |
| 精力充沛 💪 | 3个    | 3组   | 10-12次 | 3kg           | 60-90秒  | ~25分钟 | 标准完成         |
| 略有疲惫 😐 | 2-3个  | 3组   | 8-10次  | 3kg           | 90秒     | ~25分钟 | 降低容量         |

| 极度疲劳 🥱 | -      | -     | -       | -             | -        | -       | **建议完全休息** |

## 渐进超负荷追踪表 (30分钟高效版)

| 动作       | 当前重量  | 当前次数 | 组数 | 组间休息 | 下次目标 | 递增条件        |
| ---------- | --------- | -------- | ---- | -------- | -------- | --------------- |
| 跪姿俯卧撑 | 徒手/支架 | 10次     | 3组  | 60秒     | 12次     | 连续2次完成12次 |
| 哑铃推举   | 3kg×2     | 10次     | 3组  | 60秒     | 12次     | 连续2次完成12次 |
| 高脚杯深蹲 | 3kg       | 12次     | 3组  | 60秒     | 15次     | 连续2次完成12次 |
| 哑铃划船   | 3kg       | 10次     | 3组  | 60秒     | 12次     | 连续2次完成12次 |
| 平板支撑   | 徒手      | 30秒     | 3组  | 60秒     | 45秒     | 连续2次完成30秒 |

**递增信号**: 当连续2次训练都能以标准动作完成目标次数的上限(12次)，下次训练可以增加次数或减少休息时间。

**30分钟训练原则**: 组间休息缩短到60-90秒，选择2-3个核心动作，专注于动作质量而非数量。

## 常见问题 (Q&A)

**Q: 动作不标准怎么办?**
A: 新手期动作质量 > 重量 > 次数。宁可徒手做标准，也不要负重做变形。

**Q: 没有泵感/发力感怎么办?**
A: 放慢动作速度(2秒下-1秒停-2秒起)，减少重量，专注于目标肌群的收缩。

**Q: 练完第二天酸痛还能练吗?**
A: 轻微酸痛可以练其他肌群; 严重酸痛建议休息或做恢复性训练(拉伸/轻度有氧)。

**Q: 什么时候增加重量?**
A: 当前重量能标准完成3组×12次，连续2次训练都达标，可考虑增加重量(3kg→5kg或增加次数)。

**Q: 增肌饮食怎么安排?**
A: 每公斤体重1.6-2.2g蛋白质，热量盈余300-500大卡，练后30分钟内补充20-30g蛋白质。
