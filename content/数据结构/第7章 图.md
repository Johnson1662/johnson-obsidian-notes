# 7.1 图的定义和术语

## 1 图的定义

图是由顶点的**有穷非空**集合和顶点之间的边的集合组成的。通常用 $G(V,E)$ 表示，其中 $G$ 表示一个图，$V$ 是图 $G$ 中顶点的集合，$E$ 是边的集合
**注意：图不允许没有顶点，但边集可以为空**

# $7.3$ 图的遍历

对于任意一个图，从某个顶点出发进行深度优先或广度优先遍历，只能访问到与该起始顶点在同一个连通分量内的所有顶点。 如果图是不连通的（即包含多个独立的连通分量），则无法仅从一个顶点出发访问到所有顶点。 只有当图是连通图时，才能通过从任一顶点出发的一次遍历访问所有顶点。

### 1 含义

### 2 普里姆 $(Prim)$ 算法

针对顶点的贪心策略，边数较多时效率高，时间复杂度为 $O(n^2)$
```C
void prim(Matrix_Graph G) {
	int i, j, k;
	int min;

	int weight[MAX_SIZE]; // 用于存储候选边的权重
	int vex_index[MAX_SIZE];

	weight[0] = 0; // 置0表示对应的结点已经加入最小生成树中
	vex_index[0] = 0; // weight数组对应位置的边连接的结点对应的下标

	// 初始化为与第一个结点相连的边的权重
	for(i = 1; i < G.vertex_num; i ++) {
		weight[i] = G.arc[0][i];
		vex_index[i] = 0;
	}

	for(i = 1; i < G.vertex_num; i ++) {
		min = INT_MAX;
		j = 1;
		k = 0;
		while(j < G.vertex_num) {
			if(weight[j] != 0 && weight[j] < min) { // 该节点未加入生成树
			                                      // 并且对应的边权重小于目前的最小值
				min = weight[j];
				k = j;
			}
			j ++;
		}
		printf("(%d, %d)\n", vex_index[k], k); // 打印加入生成树的边
		weight[k] = 0; // 加入生成树的结点 weight数组中置为0

		// 添加符合要求的 与新加入结点相连接的边
		for(j = 1;j < G.vertex_num; j ++) {
			if(weight[j] != 0 && G.arc[k][j] < weight[j]) {
				weight[j] = G.arc[k][j];
				vex_index[j] = k;
			}
		}
	}
}
```

### 3 克鲁斯卡尔 $(Kruskal)$ 算法

针对边的贪心策略，在边数较少时效率高，时间复杂度为 $O(e\log e)$

```C
// 初始化边数组
typedef struct{
	int begin;
	int end;
	int weight;
} Edge;

Edge edges[MAX_EDGES];

void init_edges() {
	int k = 0;
	for(int i = 0; i < G.vertex_num; i ++)
		for(int j = i + 1; j < G.vertex_num; j ++) {
			if(G.arc[i][j] < INT_MAX) {
				edges[k].begin = i;
				edges[k].end = j;
				edges[k].weight = G.arc[i][j];
				k ++;
			}
		}
	sort_edges(edges, G.edge_num);
}

int find(int *parent, int index) {
	while(parent[index] > 0)
		index = parent[index];
	return index;
}

void kruskal(Matrix_Graph G) {
	init_edges();
	int parent[MAX_SIZE] = {0};
	int m, n;
	for(int i = 0;i < G.edge_num; i ++) {
		m = find(parent, edges[i].begin);
		n = find(parent, edges[i].end);
		if(m != n) {
			parent[m] = n;
			printf("(%d, %d) %d\n", edges[i].begin, edges[i].end, edges[i].weight);
		}
	}
}
```

## $7.5.1$ 拓扑排序

在一个表示工程的有向图中，用顶点表示活动，用弧表示活动之间的优先级，这样的有向图为顶点表示活动的网，我们称为 AOV 网(Activity on Vertex Network)
![file-20251201160833267](assets/file-20251201160833267-20260104152051-ffqz0db.png)
一个有向图的邻接矩阵中对角线以下元素均为零，意味着该图是一个上三角矩阵表示的图，这表明图中不存在从行索引大的节点指向行索引小的节点的边，即图中不存在环（有向圈）。 有向无环图（DAG）是能够进行拓扑排序的充要条件。

```C
// 采用邻接表存储（方便计算入度）
typedef struct EdgeNode{
	int edge_vex;
	struct EdgeNode *next;
} EdgeNode;

typedef struct VertexNode{
	int in; // 入度
	VertexType data;
	EdgeNode *head; // 结点出度链表的头指针
} VertexNode;

typedef VertexNode Adj_List[MAX_SIZE];

typedef struct{
	Adj_List adj_list;
	int vertex_num;
	int edge_num;
} Adj_Graph;

typedef Adj_Graph* Adj_List_Graph;

// 将邻接矩阵转换为邻接表
void create_adj_graph(Mat_Graph G, Adj_List_Graph *ALG) {
	int i, j;
	EdgeNode *e;
	*ALG = (Adj_List_Graph)malloc(sizeof(Adj_Graph));
	(*ALG)->vertex_num = G.vertex_num;
	(*ALG)->edge_num = G.edge_num;

	for(i = 0; i < G.vertex_num; i++) {
		(*ALG)->adj_list[i].in = 0;
		(*ALG)->adj_list[i].data = G.vertex[i];
		(*ALG)->adj_list[i].head = NULL;
	}

	for(i = 0; i < G.vertex_num; i++)
		for(j = 0; j < G.vertex_num; j++)
			if(G.arc[i][j] == 1) {
				// 头插法
				e = (EdgeNode *)malloc(sizeof(EdgeNode));
				e->edge_vex = j;
				e->next = (*ALG)->adj_list[i].head;
				(*ALG)->adj_list[i].head = e;
				(*ALG)->adj_list[j].in ++;
			}
}

// 拓扑排序
void topological_sort(Adj_List_Graph ALG) {
	int i, k;
	EdgeNode *e;
	int stack[MAXSIZE];
	int curr;
	for(i = 0; i < ALG->vertex_num; i++)
		if(ALG->adj_list[i].in == 0)
			push(i);
	while(is_empty() != 0) {
		curr = pop();
		printf(" %d ->", ALG->adj_list[curr].data);
		e = ALG->adj_list[curr].head;
		while(e != NULL) {
			k = e->edge_vex;
			ALG->adj_list[k].in --;
			if(ALG->adj_list[k].in == 0)
				push(k);
			e = e->next;
		}
	}

}
```

```C
void critical_path(Adj_List_Graph ALG) {

			// push
			top++;
			stack[top] = i;
		}

	for(i = 0; i < ALG->vertex_num; i++)
		etv[i] = 0;

	while(top != -1) {
		curr = stack[top];
		top --;
		printf(" %d ->", ALG->adj_list[curr].data);
		top2 ++;
		stack2[top2] = curr;
		e = ALG->adj_list[curr].head;
		while(e != NULL) {
			k = e->edge_vex;
			ALG->adj_list[k].in --;
			if(ALG->adj_list[k].in == 0) {
				top++;
				stack[top] = k;
			}
			if((etv[curr] + e->weight) > etv[k])
				etv[k] = etv[curr] + e->weight;
			e = e->next;
		}
	}
	printf(" end\n");

	printf("etv : ");
	for(i = 0; i < ALG->vertex_num; i++)
		printf("%d -> ", etv[i]);
	printf(" end\n");

	for(i = 0; i < ALG->vertex_num; i++)
		ltv[i] = etv[ALG->vertex_num - 1];

	while(top2 != -1) {
		curr = stack2[top2];
		top2 --;
		e = ALG->adj_list[curr].head;
		while(e != NULL) {
			k = e->edge_vex;
			if(ltv[k] - e->weight < ltv[curr])
				ltv[curr] = ltv[k] - e->weight;
			e = e->next;
		}
	}

	printf("ltv : ");
	for(i = 0; i < ALG->vertex_num; i++)
		printf("%d -> ", ltv[i]);
	printf(" end\n");

	for(i = 0; i < ALG->vertex_num; i++) {
		e = ALG->adj_list[i].head;
		while(e != NULL) {
			k = e->edge_vex;
			ete = etv[i];
			lte = ltv[k] - e->weight;
			if(ete == lte)
				printf("<V%d - V%d> len : %d\n", ALG->adj_list[i].data, ALG->adj_list[k].data, e->weight);
			e = e->next;
		}
	}
}
```

# $7.6$ 最短路径

## $7.6.1$ 从某个源点到其余各顶点的最短路径

### $Dijtskra$ 算法 $O(n^2)$

![file-20251127212741741](assets/file-20251127212741741-20260104152051-oz9nemo.png)

```C
int choose(int distance[], int found[], int vertex_num) {
	int min = INT_MAX, min_pos = -1;
	for(int i = 0; i < vertex_num; i ++) {
		if(distance[i] < min && found[i] == 0) {
			min = distance[i];
			min_pos = i;
		}
	}
	return min_pos;
}

void dijtskra(Matrix_Graph G, int begin) {
	// 求从begin结点出发，到达各结点的最短路径
	int found[MAX_SIZE]; // 已经找到最短路径的结点置为1
	int path[MAX_SIZE]; // 目前到达各结点的最短路径的前一个结点
	int distance[MAX_SIZE]; // 目前找到的从begin到各结点的最短距离

	// 初始化
	for(int i = 0; i < G.vertex_num; i ++) {
		found[i] = 0;
		path[i] = -1;
		distance[i] = G.arc[begin][i];
	}

	found[begin] = 1;
	distance[begin] = 0;

	int next;
	for(int i = 1; i < G.vertex_num; i ++) {
		next = choose(distance, found, G.vertex_num);
		found[next] = 1;
		for(int j = 0; j < G.vertex_num; j ++) {
			if(found[j] == 0) {
				if(distance[next] + G.arc[next][j] < distance[j]) {
					distance[j] = distance[next] + G.arc[next][j];
					path[j] = next;
				}
			}
		}
	}

	// 输出最短路径长度和具体路径
	for(int i = 1; i < G.vertex_num; i ++) {
		printf("v0 -> v%d : %d\n", i, distance[i]);
		int j = i;
		printf("v%d <- ", i);
		while(path[j] != -1) {
			printf("v%d <- ", path[j]);
			j = path[j];
		}
		printf("v0\n");
	}
}
```

## $7.6.2$ 每一对顶点之间的最短路径

### $Floyd$ 算法 $O(n^3)$

![file-20251127222452720](assets/file-20251127222452720-20260104152051-fsazbs0.png)

$D^{-1}、P^{-1}$ 分别表示初始状态下各结点之间的距离，和到达各结点的路径
$D^0、P^0$ 分别表示经过 v0 中转后各结点之间的距离，和到达各结点的路径

```C
void floyd(Matrix_Graph G) {
	int i, j, k; //i：中转顶点 j：起始顶点 k：终止顶点
	int dist[MAX_SIZE];
	int path[MAX_SIZE];
	for(i = 0; i < G.vertex_num; i++) {
		for(j = 0; j < G.vertex_num; j++) {
			dist[i][j] = G.arc[i][j];
			path[i][j] = j;
		}
	}

	for(i = 0; i < G.vertex_num; i ++)
		for(j = 0; j < G.vertex_num; j++)
			for(k = 0; k < G.vertex_num; k++)
				if(dist[j][k] > dist[j][i] + dist[i][k]) {
					dist[j][k] = dist[j][i] + dist[i][k];
					path[j][k] = path[j][i];
				}

	// 打印最短路径
	for(i = 0; i < G.vertex_num; i++) {
		for(j = i + 1; j < G.vertex_num; j++) {
			printf("v%d -> V%d weight : %d ", i, j, dist[i][j]);
			k = path[i][j];
			printf(" path: v%d", i);
			while(k != j) {
				printf(" -> v%d", k);
				k = path[k][j];
			}
			printf(" -> v%d\n", j);
		}
		printf("\n");
	}
}
```
